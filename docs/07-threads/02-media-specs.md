# Threads の画像・動画・文字数

> 公式ヘルプ・開発者文書の本文は未取得。値は二次資料中心で、資料間で不一致があります (#34)。

## 文字数

| 項目 | 値 | 確度 |
|---|---|---|
| 1投稿の文字数 | 500字とする資料(Emplifi)。公式の確認は未取得 | 🟡 |
| ハッシュタグ | 1投稿に **1つ**とする資料 | 🟡 |
| リンク | 可 | ⚪ |

## 画像

| 項目 | 値 | 確度 |
|---|---|---|
| 形式 | JPEG / PNG(GIF は静止画として公開) | 🟡 |
| 容量 | JPEG 8MB、PNG 3MB。100MB とする資料もあり不一致 | 🟡 |
| カルーセル | 2〜20枚 | 🟡 |
| 推奨サイズ | 1080×1350(4:5) | 🟡 |
| 比率 | 縦 4:5 を基本。1:1 も可 | 🟡 |

## 動画

| 項目 | 値 | 確度 |
|---|---|---|
| 形式 | MP4 / MOV | 🟡 |
| 長さ | 3秒〜5分 | 🟡 |
| 容量 | 500MB〜1GB と不一致 | 🟡 |
| 比率・解像度 | 9:16 推奨(1080×1920)。1:1、16:9 も可 | 🟡 |

## API での公開上限(公式文書の検索要約)

| 項目 | 値 | 確度 |
|---|---|---|
| 投稿 | **250件/24時間**(ローリング)。カルーセルは1件 | 🟡 |
| 返信 | 1,000件/24時間 | 🟡 |
| 削除 | 100件/24時間 | 🟡 |
| 位置情報検索 | 500件/24時間 | 🟡 |

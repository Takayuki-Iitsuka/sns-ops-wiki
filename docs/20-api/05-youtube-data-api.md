# YouTube Data API v3

> 検索要約と二次資料に基づく 🟡 (#38)。クォータ表は Google の公式文書で確認。

## 主な用途

| 用途 | API |
|---|---|
| 動画のアップロード | `videos.insert` |
| サムネイル設定 | `thumbnails.set` |
| メタデータ更新 | `videos.update` |
| 字幕 | `captions.insert` ほか |
| 再生リスト | `playlists`、`playlistItems` |
| コメント管理 | `commentThreads`、`comments` |
| 検索 | `search.list`(クォータが重い ⚪) |
| 分析 | YouTube Analytics API、Reporting API |

## 重要な制約(🟡)

### 未監査プロジェクトのアップロードは非公開に固定

> 2020年(皇紀2680年・令和2年)7月28日以降に作成された**未検証の API プロジェクトからアップロードされた動画は、非公開に制限される**。解除には**API 監査(利用規約への準拠確認)**を受ける。クォータの余裕とは無関係。

→ 自動アップロードを検討する場合は、まず**手動(YouTube Studio)で運用**し、API は読み取り・メタデータ更新など限定的な用途から。監査の申請手順は公式で確認。

### クォータ

| 項目 | 内容 | 確度 |
|---|---|---|
| 既定の1日クォータ | 10,000 ユニット | 🟡 |
| `videos.insert` のコスト | 従来 **1,600ユニット**(約6本/日)。**2026年6月1日に 1 ユニットへ下がった**とする資料と、100回/日の専用バケットとする資料がある(**不一致**) | 🟡 |
| `search.list` | 100 ユニット/回 | ⚪ |

→ 使用量は Google Cloud のクォータ画面で確認し、`videos.insert` を含む各メソッドのコストは**公式のクォータ表で確認してから**見積もる。

## 認証

OAuth 2.0。アップロードには `youtube.upload` スコープ ⚪。**チャンネル所有者の同意**が必要。サービスアカウントは使えない場合が多い(⚪)。

## 運用の指針

1. 長尺動画の投稿は**手動**で品質管理(サムネイル・字幕・チャプター)し、メタデータの一括更新などに API を使う。
2. 分析の自動取得(Analytics API)で週次レビューを効率化。
3. コメントの自動返信は**スパム扱いの危険**があるため、半自動(下書き)に留める。

# 物販・デジタル商品

> **このページで分かること**: BOOTH・SUZURI などで、デジタル商品(PDF・素材)やグッズを売るまでの流れと、手数料・権利・表記の注意点。
>
> **対象**: 作品や資料を販売したい初心者  **先に読むページ**: [README(比較)](README.md)

## 概要

SNS で集めた関心を、**商品として形にして売る**方法です。
大きく2種類あります。

1. **デジタル商品**: PDF・画像素材・テンプレートなど。在庫がなく、何度でも売れます。
2. **物理的なグッズ**: ステッカー・T シャツなど。自分で在庫を持つ方法と、注文が入ってから作る**オンデマンド**の方法があります。

初心者は、在庫のリスクがない**デジタル商品**か**オンデマンドのグッズ**から始めるのが安全です(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| ダウンロード商品 | 購入者がファイルをダウンロードする商品 |
| オンデマンド(受注生産) | 注文が入ってから作る方式。在庫を持たない |
| 倉庫発送 | 商品を倉庫に預け、発送を代行してもらう仕組み(BOOTH の倉庫サービスなど) |
| トリブン | SUZURI で、商品の原価に自分が上乗せする利益(⚪ 仕組みの詳細は公式で確認) |
| ライセンス | 購入者がその商品をどう使ってよいかの決まり(個人利用・商用利用など) |
| 特定商取引法に基づく表記 | 通信販売で販売者の情報を示す法律上のルール |

## サービスの特徴(⚪/🟡)

| サービス | 特徴 | 手数料の報告値 |
|---|---|---|
| BOOTH | 同人・創作の販売。デジタル(PDF・画像・音声)と物販。倉庫発送(あんしんBOOTHパック)などの仕組み | 利用料 5% + 決済手数料 3.5%(税抜)の合計 8.5% とする比較記事 🟡(古い値の可能性。下の改定を参照) |
| SUZURI | オンデマンドのグッズ作成・販売。在庫を持たない | 原価+トリブン(自分の上乗せ) |
| 自サイト+決済 | 手数料を抑えられるが、運用・法務を自前で | 決済サービスの手数料 |

### BOOTH の料金改定(🟡)

| 項目 | 改定前 | 改定後(2025年(皇紀2685年・令和7年)10月28日〜) | 確度 | 出典 |
|---|---|---|---|---|
| サービス利用料 | 5.6%+22円 | **5.6%+45円**(決済手数料込みとする解説あり) | 🟡 | [GameBusiness.jp](https://www.gamebusiness.jp/article/2025/07/24/24711.html) |
| 倉庫発送手数料 | 26円 | **商品価格×2.5%+商品個数×25円**(小数点以下切り上げ) | 🟡 | [BOOTH 公式のお知らせ(検索要約)](https://booth.pm/announcements/834) |

計算例(改定後の 🟡 値): 1,000円のデジタル商品が1つ売れると、1,000 × 5.6% + 45 = 101円 → 手元に約 899円。
**低価格の商品ほど、固定の 45円の割合が大きく**なります(300円なら約 62円で約2割)。

### SUZURI(⚪)

- 販売・管理の手数料はかからず、利益(トリブン)は自分で設定でき、送料は購入者が負担するとする解説があります(🟡 [リベシティ](https://library.libecity.com/articles/01HPX0X2X7XC589RS4GPZG2A0K))。
- 振込の条件・手数料は公式で未確認です(⚪ #41)。

## 手順: BOOTH でデジタル商品を売る(⚪ 画面の表記は変わる可能性)

1. pixiv アカウントで BOOTH にログインし、ショップを開設します。
2. ショップ名・アイコン・説明を設定します。
3. 振込先口座を登録します。
4. 「商品を追加」から**ダウンロード商品**を選びます。
5. 商品名・説明・価格・サムネイル画像を入力します。
6. 販売するファイル(PDF・ZIP など)をアップロードします。
7. **ライセンス(利用規約)**を説明欄に書きます。
8. 公開前に、自分のアカウントで購入画面とダウンロードの流れを確認します(⚪ テスト方法は公式で確認)。
9. 公開し、SNS で告知します。

## 手順: SUZURI でグッズを作る(⚪)

1. アカウントを作り、デザイン画像(透過 PNG など)をアップロードします。
2. 作りたいアイテム(T シャツ・ステッカーなど)を選び、配置を調整します。
3. トリブン(上乗せする利益)を決めます。
4. 公開し、商品ページの URL を SNS で告知します。
5. 売上の確認と振込申請の方法を公式で確認します。

## 売れるデジタル商品(⚪)

| 商品 | 例 |
|---|---|
| PDF 資料 | チェックリスト、テンプレ、まとめ |
| 画像素材 | 壁紙、素材集(**ライセンス明記**) |
| 電子書籍 | KDP と併用([03-kdp-ebooks](03-kdp-ebooks.md)) |
| 音声 | 解説音声 |
| テンプレート | 投稿計画、デザインテンプレ |

## 設計

1. **無料サンプル**を用意(SNS で配布)。
2. 商品ページの画像は**1枚目で価値を示す**(サイズは公式で確認)。
3. ライセンスを明記(個人利用/商用)。
4. 価格は競合と成果物の量で決める。固定手数料がある場合は低価格すぎないように(🟡 上の計算例)。
5. 追加更新の方針(無料アップデートの範囲)。

## 具体例: ライセンス表記

```
【ご利用について】
・個人の SNS アイコン、ブログでの利用: 可
・商用利用(販売物・広告): 不可(別途ご相談ください)
・再配布・素材としての転売: 不可
・クレジット表記: 任意
```

| 良い商品ページ | 悪い商品ページ |
|---|---|
| 1枚目に完成イメージ、中身の一覧、ファイル形式 | 画像がなく「素材です」だけ |
| ライセンスと対応ソフトを明記 | 使える範囲が分からない |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 100円などの低価格で、手数料の割合が高すぎた | 固定手数料を含めて手取りを計算し、セット販売にする |
| 他人のフォントを含むデータを販売 | フォントのライセンス(再配布の可否)を確認 |
| 購入者から「開けない」と問い合わせ | ファイル形式・対応ソフトを説明に書く |
| 住所を公開したくない | 特定商取引法の表記で、サービスの代替手段を確認(#41) |

## 注意

- 素材・フォント・画像の権利([image-sources-and-copyright](../01-common/image-sources-and-copyright.md))。
- 返金・不具合対応。
- 特定商取引法の表記(個人の住所・氏名の公開をどう扱うか: サービスの代替手段を確認 #41)。[法令・表示](../01-common/legal-compliance.md)
- 税務: 売上・経費の記録([税務と事業](../30-strategy/04-tax-and-business.md))。

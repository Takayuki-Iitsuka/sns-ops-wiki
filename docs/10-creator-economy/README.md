# クリエイターエコノミー: 収益化できるサービス

> **このページで分かること**: 作品・知識を直接売ったり、継続支援を受けたりできるサービスの比較と、目的に合ったサービスの選び方。
>
> **対象**: 初心者  **先に読むページ**: [収益化の比較(共通)](../01-common/monetization-comparison.md)

## 概要

SNS 単体の収益プログラムに頼らず、**自分の作品・知識を直接売る/継続支援を受ける**ためのサービス群です。

クリエイターエコノミー(creator economy)とは、個人の作り手がファンから直接お金を受け取って活動する経済の広がりのことです。
SNS の広告収益は条件(フォロワー数・再生数)が厳しいことが多いのに対し、ここで紹介するサービスは**少人数のファンからでも始められる**のが利点です(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| 手数料(プラットフォーム手数料) | サービスが売上から差し引く利用料 |
| 決済手数料 | カード・コンビニ払いなどの決済にかかる手数料 |
| 手取り | 手数料を引いたあとに受け取る金額 |
| 継続支援 | 月額で応援してもらう仕組み |
| ロイヤリティ | 電子書籍などで著者が受け取る割合 |
| 特定商取引法に基づく表記 | 通信販売での販売者情報の表示ルール |

## 選び方の目安(⚪)

| 状況 | 候補 |
|---|---|
| 文章・知識を売る | note、KDP |
| イラスト・創作の継続支援(国内) | FANBOX、Fantia |
| 海外のファンが多い | Patreon、Ko-fi([多言語・海外](../01-common/multilingual-and-global.md)) |
| グッズ・デジタル商品 | BOOTH、SUZURI |
| 動画中心 | YouTube メンバーシップ |
| 手数料を抑え自前で販売 | 自サイト+決済サービス(個人情報・税務の管理が必要) |

## はじめての人の進め方(⚪)

1. **無料の発信で反応を見る**: どの投稿に反応が多いかで、ファンが何にお金を払いたいかを探ります。
2. **小さく1つ始める**: 単品(有料記事・PDF)か、低価格の月額プラン1つから。
3. **手取りを計算する**: 手数料・振込手数料を引いた金額で価格を決めます。
4. **表記とルールを確認する**: 特定商取引法・広告表記・禁止コンテンツ。
5. **毎月記録する**: 売上・手数料・経費([税務と事業](../30-strategy/04-tax-and-business.md))。
6. **増やすのは慣れてから**: 2つ目のサービスは、1つ目が安定してから。

## 具体例: 同じ 1,000円で売ったときの手取り(🟡 報告値での試算 ⚪)

| サービス | 計算 | 手取りの目安 |
|---|---|---|
| note 有料記事(カード払い) | 1,000 − 50 − 95 | 855円(振込 270円は別) |
| BOOTH(改定後の報道値) | 1,000 − (56 + 45) | 899円 |
| KDP(1,100円税込・70%・2MB) | (1,000 − 2)× 70% | 約 699円 |

条件(決済手段・税・端数処理)で変わるため、目安として比べてください。

## 共通の設計

1. **無料→有料の導線**: 無料で価値を示し、有料の特典を明確に([集客の流れ](../30-strategy/02-funnel.md))。
2. **継続支援は更新頻度と限定性**を設計(解約を減らす)。[メンバーシップの設計](05-membership-design.md)
3. 規約(禁止コンテンツ、年齢制限)の確認。
4. 税務: 収益の記録、源泉・支払調書の扱い([tax-and-business](../30-strategy/04-tax-and-business.md))。
5. 広告・PR の表記([legal-compliance](../01-common/legal-compliance.md))。
6. 特定商取引法に基づく表記の要否。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 複数のサービスを同時に始めて管理しきれない | 1つに絞り、慣れてから増やす |
| 手数料を見ずに価格を決めた | 上の試算のように手取りで比べる |
| 住所の公開に困った | 各サービスの特定商取引法の表記の代替手段を確認(#41) |

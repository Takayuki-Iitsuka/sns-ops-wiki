# クリエイターエコノミー: 収益化できるサービス

SNS 単体の収益プログラムに頼らず、**自分の作品・知識を直接売る/継続支援を受ける**ためのサービス群です。

## 比較(🟡 手数料は資料間で不一致 #41)

| サービス | 主な用途 | 手数料の報告値 | 日本の決済 | ページ |
|---|---|---|---|---|
| note | 有料記事・マガジン・メンバーシップ | プラットフォーム利用料 10%(税抜)+決済手数料とする比較記事 | カード等 | [04-note](../04-note/07-monetization.md) |
| pixiv FANBOX | 継続支援・限定投稿 | 5%+決済手数料、または 10% と資料で不一致 | コンビニ等対応 | [01-fan-club](01-fan-club.md) |
| Fantia | 継続支援・単品販売 | 9〜12% と不一致 | コンビニ等対応 | [01-fan-club](01-fan-club.md) |
| Patreon | 継続支援(海外向け) | 5%(Lite)ほかプランで変動 | 為替の影響あり | [01-fan-club](01-fan-club.md) |
| Ko-fi | 投げ銭・ショップ | 無料プラン 0%/Gold 5%+決済手数料 | — | [01-fan-club](01-fan-club.md) |
| BOOTH | 物販・デジタル商品 | 利用料 5%(税抜)+決済 3.5%(税抜)=合計 8.5% とする比較記事 | カード等 | [02-goods-and-digital](02-goods-and-digital.md) |
| SUZURI ほか | オンデマンドのグッズ | トリブン(上乗せ)方式 | — | [02-goods-and-digital](02-goods-and-digital.md) |
| Kindle Direct Publishing | 電子書籍 | ロイヤリティ 35% / 70% | 日本円の価格帯制約 | [03-kdp-ebooks](03-kdp-ebooks.md) |
| YouTube メンバーシップ等 | 動画の継続支援 | プラットフォーム配分 | — | [05-youtube](../05-youtube/05-monetization.md) |
| アフィリエイト | 成果報酬 | プログラムごと | — | [04-affiliate](04-affiliate.md) |

> 手数料・価格帯・出金条件は**契約前に必ず公式の料金ページで確認**。ここは比較の枠組みです。

## 選び方の目安(⚪)

| 状況 | 候補 |
|---|---|
| 文章・知識を売る | note、KDP |
| イラスト・創作の継続支援(国内) | FANBOX、Fantia |
| 海外のファンが多い | Patreon、Ko-fi |
| グッズ・デジタル商品 | BOOTH、SUZURI |
| 動画中心 | YouTube メンバーシップ |
| 手数料を抑え自前で販売 | 自サイト+決済サービス(個人情報・税務の管理が必要) |

## 共通の設計

1. **無料→有料の導線**: 無料で価値を示し、有料の特典を明確に。
2. **継続支援は更新頻度と限定性**を設計(解約を減らす)。[メンバーシップの設計](05-membership-design.md)
3. 規約(禁止コンテンツ、年齢制限)の確認。
4. 税務: 収益の記録、源泉・支払調書の扱い([tax-and-business](../30-strategy/04-tax-and-business.md))。
5. 広告・PR の表記([legal-compliance](../01-common/legal-compliance.md))。
6. 特定商取引法に基づく表記の要否。

# 継続支援サービス

> **このページで分かること**: ファンから毎月支援を受けるサービス(pixiv FANBOX・Fantia・Patreon・Ko-fi)の違いと、登録から最初の支援を受けるまでの流れ。
>
> **対象**: 創作・発信で継続支援を受けたい初心者  **先に読むページ**: [README(比較)](README.md)、[継続課金の設計](05-membership-design.md)

## 概要

継続支援サービスは、ファンが**月額で応援**し、そのお礼として限定記事・作品・制作過程などを届ける仕組みです。
SNS の広告収益と違い、フォロワーが少なくても「濃いファン」がいれば始められるのが特徴です(⚪)。
ただし、**毎月の更新を約束する**ことになるため、続けられる量で設計することが一番大事です。

## 用語

| 用語 | 意味 |
|---|---|
| プラン(ティア, tier) | 月額の支援コース。金額ごとに特典が違う |
| 支援者(パトロン, patron) | 月額で支援してくれる人 |
| 限定投稿 | 支援者だけが見られる投稿 |
| プラットフォーム手数料 | サービスの利用料。売上から引かれる |
| 決済手数料 | カード会社などに払う手数料 |
| R-18 / 年齢制限 | 成人向けの内容の扱い。サービスごとにルールが違う |
| 単品販売 | 月額とは別に、作品を1つずつ売ること |

## 概要と使い分け

| サービス | 特徴 | 向く人 |
|---|---|---|
| pixiv FANBOX | pixiv 連携。月額プランごとの限定投稿。コンビニ決済等に対応とされる | イラスト・漫画・創作(国内) |
| Fantia | 月額プラン+単品販売。多ジャンル | 創作全般(国内) |
| Patreon | 海外標準。複数通貨。為替の影響 | 海外ファンが多い人 |
| Ko-fi | 投げ銭中心+ショップ。無料プランあり | 小さく始めたい人 |

手数料の報告値は [README](README.md) 参照(不一致あり #41)。

## 手数料の報告値(🟡 二次資料。公式の料金ページで必ず確認)

| サービス | 報告されている手数料 | 確度 | 出典 |
|---|---|---|---|
| pixiv FANBOX | 「10%」「5%+決済約3.6%+30円(2026年(皇紀2686年・令和8年)4月更新)」「8%+決済約3.6%」と資料で不一致。振込手数料が別にかかるとする資料あり | 🟡 | [app-tatsujin](https://app-tatsujin.com/?p=29675)、[税理士ドットコム](https://www.zeiri4.com/c_5/q_164420/) |
| Fantia | プラットフォーム 10%+決済 4.0%+30円 とする記事 | 🟡 | [app-tatsujin](https://app-tatsujin.com/?p=29675)(公式 [fantia.jp/help/fee](https://fantia.jp/help/fee) は未取得) |
| Patreon | 2025年(皇紀2685年・令和7年)8月4日以降の新規クリエイターは標準 10%。旧プラン(Lite 5%・Pro 8%・Premium 12%)が残る場合あり。決済手数料(米国で約 2.9%+$0.30)・為替手数料は別 | 🟡 | [Patreon 公式サポート(検索要約)](https://support.patreon.com/hc/en-us/articles/36426991446797) |
| Ko-fi | 無料プラン: 単発のチップ 0%、ショップ・メンバーシップ・依頼 5%。Gold(有料)で 0%。Gold の月額は資料で不一致。PayPal・Stripe の決済手数料は別 | 🟡 | [Ko-fi ヘルプ(検索要約)](https://help.ko-fi.com/hc/en-us/articles/360002506494) |

- Fantia は 2024年(皇紀2684年・令和6年)5月から Visa・Mastercard のカードが使えなくなったとする記事があります(🟡 検索要約)。ファンの支払い手段を確認してください。
- Ko-fi は、新しいアカウントで単発チップにも 5% がかかる設定が有効になっている場合がある、とする資料があります(🟡)。設定画面を確認してください。

## 設定の流れ(共通)

1. アカウント作成と本人確認、振込口座。
2. プラン設計(金額、特典、更新頻度)。
3. ページの画像・自己紹介(各サービスの推奨サイズは公式で確認 #41)。
4. 初回投稿・限定投稿のストック。
5. SNS で告知(X・Instagram・YouTube から誘導)。

## サービス別: 登録から最初の支援まで(⚪ 画面の表記は変わる可能性)

### pixiv FANBOX

1. pixiv アカウントでログインし、FANBOX のクリエイター登録をします。
2. ページ名・アイコン・カバー画像・紹介文を設定します。
3. 支援プランを作ります(金額・特典・説明)。
4. 振込先・本人情報を登録します。
5. 最初の限定投稿を2〜3本用意してから、ページを公開します。
6. pixiv・X のプロフィールに FANBOX のリンクを置きます。

### Fantia

1. アカウントを作り、ファンクラブ(クリエイターページ)を開設します。
2. プランを作り、必要なら単品販売の商品も登録します。
3. 振込先・本人情報を登録します。
4. 限定投稿を用意して公開し、SNS で告知します。

### Patreon

1. 英語の画面が基本です。クリエイターとして登録し、ページ名・カテゴリを決めます。
2. 通貨・支払い方式(月額か、作品ごとか ⚪)を選びます。
3. ティア(Tier)を作ります。海外向けにはドル建てで考えるのが一般的です(⚪)。
4. 税務情報(米国の税務フォーム)と受取方法を登録します(⚪ [税務](../30-strategy/04-tax-and-business.md))。
5. 英語の紹介文と限定投稿を用意して公開します。

### Ko-fi

1. アカウントを作り、PayPal または Stripe を接続します(🟡)。
2. 単発チップのボタンを有効にし、必要ならメンバーシップ・ショップを追加します。
3. 手数料の設定(単発チップの扱い)を確認します(🟡)。
4. Ko-fi のリンクを SNS のプロフィールに置きます。

## プラン設計の指針(⚪)

| 設計 | 内容 |
|---|---|
| 価格帯 | 3段階(低・中・高)が一般的。低価格の入口を作る |
| 特典 | 先行公開、限定コンテンツ、制作過程、質問回答、名前の掲載 |
| 更新頻度 | 約束した頻度を守れる範囲で(月2〜4回など) |
| 休止ルール | 事前に周知。休止中の扱い |
| 退会防止 | 月ごとの「ありがとう」投稿、進捗報告 |

## 具体例: イラストの支援プラン

| プラン | 月額(例) | 特典 |
|---|---|---|
| 応援 | 300円 | 月1回の制作日記 |
| 制作過程 | 800円 | 上+ラフ・線画の公開(月2回) |
| 高解像度 | 1,500円 | 上+完成画像の高解像度データ |

手取りの考え方: 800円 × 手数料約10%(🟡)なら、1人あたり約720円前後。決済手数料・振込手数料で、さらに少し減ります。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 特典を盛りすぎて更新が追いつかない | 最上位でも「月◯回まで」と上限を書く |
| 開設したのに投稿ゼロで支援が来ない | 公開前に限定投稿を2〜3本ためておく |
| 手数料を知らずに価格を決めた | 上の表と公式ページで手取りを計算 |
| 海外向けなのに日本語だけ | Patreon・Ko-fi では英語の紹介文を用意 |

## 注意

- **禁止コンテンツ・年齢制限・R-18 の扱い**はサービスごとに異なる。規約を確認。
- 画像・音源の権利([画像の出典と著作権](../01-common/image-sources-and-copyright.md))。
- 税務・支払調書の扱い([tax-and-business](../30-strategy/04-tax-and-business.md))。
- 支援者の**個人情報**の取り扱い(住所を扱う場合の管理)。
- 特典で**商品を送る**場合は、特定商取引法の表記や住所公開の問題を確認。

## チェックリスト

- [ ] 手数料と手取りを計算した

# アフィリエイト

> **このページで分かること**: アフィリエイト(成果報酬型広告)の仕組み、登録から報酬を受け取るまでの流れ、広告表記などのルール。
>
> **対象**: 初心者  **先に読むページ**: [法令・表示(共通)](../01-common/legal-compliance.md)

## 概要

紹介した商品・サービスの購入や登録に応じて報酬を得る仕組み。**広告表記が必須**です([legal-compliance](../01-common/legal-compliance.md))。

広告であることを隠した宣伝(ステルスマーケティング)は、2023年(皇紀2683年・令和5年)10月1日から景品表示法違反となりました(✅ [消費者庁](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/))。
規制の対象は広告主(商品・サービスを供給する事業者)ですが(✅ 同上)、紹介する側も**広告と分かる表示**をすることが、読者の信頼と広告主との関係を守ります。

## 用語

| 用語 | 意味 |
|---|---|
| アフィリエイト | 紹介した商品が売れたときなどに報酬が出る広告 |
| ASP(Affiliate Service Provider、アフィリエイト・サービス・プロバイダ) | 広告主と紹介者を仲介するサービス |
| 広告主 | 商品・サービスを提供し、報酬を払う企業 |
| 成果(コンバージョン) | 購入・登録など、報酬の対象になる行動 |
| 承認 | 成果が正式に認められること。キャンセルなどで「否認」もある |
| 紹介料率 | 売上に対する報酬の割合 |
| 追跡 ID(トラッキング ID) | 誰の紹介かを識別するリンクの ID |
| ステルスマーケティング(ステマ) | 広告であることを隠した宣伝 |

## 種類(⚪)

| 種類 | 例 |
|---|---|
| 物販 | Amazon アソシエイト、楽天アフィリエイト |
| ASP(広告仲介) | A8.net、もしもアフィリエイトなど |
| サービス紹介 | ソフト、サブスク、書籍 |
| 動画・SNS 連携 | YouTube ショッピング、TikTok Shop |

## 手順: 登録から報酬まで(⚪ 一般的な流れ)

1. **発信の場を整える**: ブログ・note・YouTube などに、ある程度の記事や動画を用意します。審査で中身を見られるプログラムがあるためです(⚪)。
2. **プログラムに申し込む**: ASP や Amazon アソシエイトなどに登録し、サイト・SNS の URL を申請します。
3. **審査を待つ**: 結果はメールなどで届きます。条件(期間内の成果など)があるプログラムもあります(⚪ 各規約で確認)。
4. **広告を選ぶ**: 自分が実際に使った・読者に役立つ商品を選びます。
5. **リンクを作る**: 管理画面で自分の追跡 ID 入りのリンクを作ります。
6. **広告表記をして掲載**: 記事・動画の冒頭、投稿の文頭に「PR」「広告」などを入れます。
7. **成果を確認**: 管理画面でクリック数・成果・承認状況を見ます。
8. **報酬の受け取り**: 振込先を登録し、最低支払額などの条件を確認します(⚪ プログラムごと)。
9. **記録**: 報酬・経費を記録します([税務と事業](../30-strategy/04-tax-and-business.md))。

### Amazon アソシエイト(日本)の注意(🟡/⚪)

- 運営規約は 2026年(皇紀2686年・令和8年)4月20日に改定され、有料広告経由の購入を紹介料の対象外とする、適格販売の成立期限を 180日以内と明確化する、第三者コンテンツ利用時の要件を厳しくする、などの変更があったと報じられています(🟡 [ネットショップ担当者フォーラム](https://netshop.impress.co.jp/n/2026/04/16/15928))。
- サイト上に**所定の文言**を表示する義務があります(⚪ 文言は [運営規約](https://affiliate.amazon.co.jp/help/operating/agreement/) で要確認。公式ページは未取得)。

## 運用ルール

1. **一目で分かる広告表記**(文頭の「PR」「広告」など)。ハッシュタグの末尾に埋もれさせない。
2. プログラム規約の表記義務を守る(Amazon は所定の文言が必要 ⚪ 要確認)。
3. **自分で使って検証**した感想だけを書く。誇大表現・効果の保証は避ける。
4. リンクの置き場: 記事、動画の概要欄、プロフィール。X・Instagram では**投稿ごとに表記**。
5. 短縮リンクの先を偽らない。
6. 医療・金融・投資は断定・勧誘に注意。
7. 各 SNS の規約で、アフィリエイトリンクの扱いが決まっている場合があります(⚪ [10-policies](../04-note/10-policies.md) など各ページで確認)。

## 具体例: 表記の書き方

```
【PR】この記事にはアフィリエイトリンクを含みます。
実際に3か月使ったキッチンスケールを紹介します。
良かった点: 0.1g 単位で量れる。
気になった点: 電池の持ちは短め。
```

| 良い例 | 悪い例 |
|---|---|
| 冒頭に「PR」。良い点と気になる点の両方 | 末尾のハッシュタグ群に #PR を混ぜる |
| 自分で使った期間と使い方を書く | 使っていない商品を「最高」と断言 |
| リンク先が何の商品か分かる | 短縮リンクだけで行き先が分からない |

## 計測

クリック数・成約率をプログラムの管理画面で確認。UTM ではなく各プログラムの追跡 ID を使う。
自分のサイト側でリンクごとの効果を比べたい場合は [リンクと UTM](../01-common/link-in-bio-and-utm.md) を参照してください。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 広告表記を忘れた | すぐ追記。告知投稿にも表記を足す |
| 紹介ばかりで読者が離れた | 広告でない役立つ発信を中心にする(目安: 広告は一部に ⚪) |
| 審査に落ちた | 記事数・内容・プロフィールを整えて再申請(条件は規約で確認) |
| 成果が「否認」された | キャンセル・規約違反の扱いを確認 |
| 報酬が振り込まれない | 最低支払額・振込先・本人確認を確認 |

## 税務

報酬は収入。支払調書、源泉徴収の有無を確認([tax-and-business](../30-strategy/04-tax-and-business.md))。

## 注意点

- このページは法的助言ではありません。表記のルールは広告主・プログラムの規約と、[企業案件・メディアキット](../30-strategy/07-sponsorship-and-media-kit.md) も参照してください。

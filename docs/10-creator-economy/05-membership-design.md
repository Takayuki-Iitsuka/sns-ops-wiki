# 継続課金(メンバーシップ)の設計

note メンバーシップ、YouTube メンバーシップ、FANBOX、Fantia、Patreon などに共通する設計です。

## 設計の要素

| 要素 | 決めること |
|---|---|
| 提供価値 | 限定コンテンツ、先行公開、質問回答、コミュニティ、制作過程 |
| 価格 | 入口(300〜500円)・中・高の3段階が一般的(⚪) |
| 頻度 | 約束する更新頻度。守れる範囲で |
| 特典の限界 | 運用できる量(人数が増えたときの負荷) |
| 解約理由対策 | 進捗報告、アンケート、コミュニティ |
| 休止・終了 | 周知方法、返金方針 |

## 指標

| 指標 | 意味 |
|---|---|
| 支援者数 | 総数 |
| 月次解約率 | 離脱の割合 |
| 平均継続月数 | 定着 |
| 1人あたり売上(ARPU) | 収益性 |
| 無料→有料の転換率 | 導線の効果 |

## 運用のコツ(⚪)

1. 支援者を**名前で呼ぶ**、コメントに返信。
2. 月初に「今月の予定」、月末に「報告」。
3. 特典は**過剰に約束しない**。
4. アンケートで要望を聞き、次の特典に反映。
5. 無料の公開コンテンツと有料の差が明確になるようにする。

## 注意

- 継続的な収益は所得として記録([tax-and-business](../30-strategy/04-tax-and-business.md))。
- 個人情報の管理。

# 継続課金(メンバーシップ)の設計

> **このページで分かること**: 月額で支援を受ける仕組み(メンバーシップ)を、無理なく続けられるように設計する考え方と手順。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [01-fan-club](01-fan-club.md)、[note の収益化](../04-note/07-monetization.md)

## 概要

note メンバーシップ、YouTube メンバーシップ、FANBOX、Fantia、Patreon などに共通する設計です。

継続課金は、毎月の収入が見通しやすくなる一方、**毎月の約束を守り続ける**責任があります。
始める前に「何を・どれくらいの頻度で・何人まで」届けられるかを決めることが、長く続けるための最大のポイントです(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| メンバーシップ | 月額で参加する会員制の仕組み |
| プラン(ティア) | 金額ごとのコース |
| 特典 | メンバーだけが受け取れる内容 |
| 解約率(チャーン) | その月にやめた人の割合 |
| ARPU(Average Revenue Per User、1人あたり売上) | 売上 ÷ 支援者数 |
| LTV(Life Time Value、顧客生涯価値) | 1人が続けている間に支払う合計(月額 × 平均継続月数) |
| 転換率 | 無料の読者・視聴者のうち有料になった割合 |

## 設計の要素

| 要素 | 決めること |
|---|---|
| 提供価値 | 限定コンテンツ、先行公開、質問回答、コミュニティ、制作過程 |
| 価格 | 入口(300〜500円)・中・高の3段階が一般的(⚪) |
| 頻度 | 約束する更新頻度。守れる範囲で |
| 特典の限界 | 運用できる量(人数が増えたときの負荷) |
| 解約理由対策 | 進捗報告、アンケート、コミュニティ |
| 休止・終了 | 周知方法、返金方針 |

## サービスごとの制約の例

| サービス | 制約 | 確度 | 出典 |
|---|---|---|---|
| note メンバーシップ | 公開できるプランは最大5つ。会費は途中で変更不可。開始には審査。初月無料機能あり | 🟡 | [メンバーシップをつくる](https://www.help-note.com/hc/ja/articles/22752829171225) |
| note メンバーシップ | プラットフォーム利用料 10%+事務手数料(決済手段により 5〜15%) | 🟡 | [手数料](https://www.help-note.com/hc/ja/articles/360011358873) |
| FANBOX・Fantia・Patreon・Ko-fi | 手数料は [01-fan-club](01-fan-club.md) を参照 | 🟡 | — |
| YouTube メンバーシップ | [YouTube の収益化](../05-youtube/05-monetization.md) を参照 | — | — |

**価格を後から変えられない**サービスがあるため(note では 🟡)、最初の価格は慎重に決めます。

## 手順: 設計から公開まで

1. **目的を決める**: 「制作を続ける資金」「ファンとの交流の場」など、1つに絞ります。
2. **届けられる量を棚卸し**: 1か月に無理なく作れる量を書き出します(例: 制作日記2本、ラフ4枚)。
3. **特典を決める**: 2.の量を超えない範囲で、プランごとに割り振ります。
4. **価格を決める**: 入口は低め、上位は特典が明確なものにします。手数料を引いた手取りも計算します。
5. **ルールを書く**: 更新頻度、休止のルール、退会・返金の方針、禁止事項(転載禁止など)。
6. **ストックを作る**: 公開前に限定コンテンツを2〜3本ためます。
7. **告知する**: 無料の発信で「どんな人に、何が届くか」を説明します。
8. **毎月振り返る**: 下の指標を記録します。

## 具体例: 3段階のプラン

| プラン | 月額(例) | 特典 | 運用の負荷 |
|---|---|---|---|
| 応援 | 300円 | 月末の活動報告 | 低 |
| 制作過程 | 800円 | 上+制作過程の公開(月2回) | 中 |
| 相談 | 2,000円 | 上+月1回の質問回答(1人1問まで) | 人数で増える → **上限人数**を決める |

| 良い設計 | 悪い設計 |
|---|---|
| 「月2回」など数字で約束 | 「たくさん更新します」 |
| 上位プランに人数上限 | 個別対応の特典を無制限に約束 |
| 休止時の扱いを先に書く | 体調不良で休んでも説明なし |

## 指標

| 指標 | 意味 |
|---|---|
| 支援者数 | 総数 |
| 月次解約率 | 離脱の割合 |
| 平均継続月数 | 定着 |
| 1人あたり売上(ARPU) | 収益性 |
| 無料→有料の転換率 | 導線の効果 |

計算の例(⚪ 架空の数字):

| 項目 | 計算 | 結果 |
|---|---|---|
| 月次解約率 | その月の退会 5人 ÷ 月初の支援者 100人 | 5% |
| 平均継続月数の目安 | 1 ÷ 解約率 0.05 | 約20か月 |
| LTV の目安 | 月額 800円 × 20か月 | 16,000円 |

## 運用のコツ(⚪)

1. 支援者を**名前で呼ぶ**、コメントに返信。
2. 月初に「今月の予定」、月末に「報告」。
3. 特典は**過剰に約束しない**。
4. アンケートで要望を聞き、次の特典に反映。
5. 無料の公開コンテンツと有料の差が明確になるようにする。
6. 交流の場を作る場合は、ルールとモデレーションを決める([コミュニティ運営](../01-common/community-management.md))。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 特典が多すぎて燃え尽きる | 特典を減らす場合は、事前に告知し理由を説明 |
| 入会直後に退会される | 入会直後に「まず読んでほしいもの」を案内する |
| 無料と有料の差が分からない | 有料だけの内容を一覧にして見せる |
| 価格を変えたくなった | 変更できないサービスでは新プランを作り移行を案内(note 🟡) |

## 注意

- 継続的な収益は所得として記録([tax-and-business](../30-strategy/04-tax-and-business.md))。
- 個人情報の管理([個人情報](../01-common/privacy-and-personal-info.md))。
- 限定コンテンツの転載・共有を禁止する旨を明記します。

# 読み方と確度ラベル

## 確度ラベル

| ラベル | 意味 | 扱い |
|---|---|---|
| ✅ | 公式ヘルプ・公式ブログ・規約等の一次資料で確認済み | そのまま利用可。ただし確認日を見る |
| 🟡 | 二次資料(解説記事・ニュース)のみで確認 | 実運用前に公式で確認 |
| ⚪ | 一般的な知識・経験則。出典なし | 参考程度。公式で確認 |

## 情報の鮮度

- SNS の仕様・収益化条件は数か月で変わります。各ページの `last_verified`(最終確認日)を必ず確認してください。
- 6か月以上前の項目は「古い可能性」として再確認します。

2026年(皇紀2686年・令和8年)11月3日に、X(docs.x.com)、Instagram・Threads(developers.facebook.com)、YouTube ヘルプ、LINE 開発者文書、消費者庁は**本文を直接取得して ✅ に更新**しました。`help.x.com`・`www.help-note.com` は bot 確認、`help.instagram.com` は JavaScript 描画で取得できず、TikTok・Bluesky・Twitch・KDP・国税庁などは未取得のため、**🟡(検索要約・二次資料)や ⚪(一般知識)が残っています**。取得状況と手順は [verification-queue.md](verification-queue.md) を参照。

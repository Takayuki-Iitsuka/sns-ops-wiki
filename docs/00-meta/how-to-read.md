# 読み方と確度ラベル

## 確度ラベル

| ラベル | 意味 | 扱い |
|---|---|---|
| ✅ | 公式ヘルプ・公式ブログ・規約等の一次資料で確認済み | そのまま利用可。ただし確認日を見る |
| 🟡 | 二次資料(解説記事・ニュース)のみで確認 | 実運用前に公式で確認 |
| ⚪ | 一般的な知識・経験則。出典なし | 参考程度。公式で確認 |

## 情報の鮮度

- SNS の仕様・収益化条件は数か月で変わります。各ページの `last_verified`(最終確認日)を必ず確認してください。
- 6か月以上前の項目は「古い可能性」として再確認します。

## 本ナレッジベースの現状(重要)

作成日(2026年11月3日)時点の実行環境では、`help.x.com`・`help.instagram.com`・`www.help-note.com` に直接アクセスできませんでした。そのため、**検索結果の要約(🟡)と一般知識(⚪)に基づく数値が多く、公式で確認済み(✅)の項目はありません**。確認手順は [verification-queue.md](verification-queue.md) を参照。

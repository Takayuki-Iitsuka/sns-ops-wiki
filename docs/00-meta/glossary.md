# 用語集

専門用語は「英語(日本語訳)」の順で記載。

| 用語 | 意味 |
|---|---|
| alt text(代替テキスト) | 画像の内容を文字で説明するテキスト。スクリーンリーダーや画像非表示時に使われる |
| aspect ratio(アスペクト比、縦横比) | 横:縦 の比。例: 4:5 は縦長 |
| carousel(カルーセル) | 複数枚をスワイプで見せる投稿形式 |
| CTA / call to action(行動喚起) | 「保存して」「プロフィールへ」など次の行動を促す文言 |
| engagement(エンゲージメント) | いいね・返信・保存・共有など反応の総称 |
| impression(インプレッション、表示回数) | 投稿が表示された回数 |
| reach(リーチ) | 投稿を見たユニークアカウント数 |
| CTR / click-through rate(クリック率) | 表示に対するクリックの割合 |
| hashtag(ハッシュタグ) | `#` 付きの検索・分類用タグ |
| thread(スレッド) | X で連続した投稿をつなげたもの |
| Reels(リール) | Instagram の縦型短尺動画 |
| Stories(ストーリーズ) | 24時間で消える Instagram の投稿 |
| membership(メンバーシップ) | 月額課金制の継続支援・限定コンテンツ |
| paywall(有料エリア) | 記事内の有料部分の境界 |
| KPI(重要業績評価指標) | 成果を測る指標 |
| stealth marketing(ステルスマーケティング、ステマ) | 広告であることを隠した宣伝 |
| 皇紀 | 神武天皇即位紀元。西暦＋660年(2026年は皇紀2686年) |

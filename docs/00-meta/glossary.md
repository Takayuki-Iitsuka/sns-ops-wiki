# 用語集

> **このページで分かること**: このナレッジベースで使う専門用語の意味(辞書として引くページ)。
>
> **対象**: すべての読者。用語を例つきで学びたい人は [初心者向け用語解説](../01-common/basic-terms-explained.md) から読んでください。

専門用語は「英語(日本語訳)」の順で記載。分野ごとに表を分けています。ブラウザのページ内検索(Ctrl+F)で探すと便利です。

## SNS 運用

| 用語 | 意味 |
|---|---|
| alt text(代替テキスト) | 画像の内容を文字で説明するテキスト。スクリーンリーダーや画像非表示時に使われる |
| aspect ratio(アスペクト比、縦横比) | 横:縦 の比。例: 4:5 は縦長 |
| safe area(安全領域) | トリミングされても欠けない中央部分 |
| carousel(カルーセル) | 複数枚をスワイプで見せる投稿形式 |
| CTA / call to action(行動喚起) | 「保存して」「プロフィールへ」など次の行動を促す文言 |
| engagement(エンゲージメント) | いいね・返信・保存・共有など反応の総称 |
| impression(インプレッション、表示回数) | 投稿が表示された回数 |
| reach(リーチ) | 投稿を見たユニークアカウント数 |
| CTR / click-through rate(クリック率) | 表示に対するクリックの割合 |
| conversion(コンバージョン、成果) | 購入・登録など最終的な行動 |
| funnel(ファネル、導線) | 認知から購入までの段階的な流れ |
| hashtag(ハッシュタグ) | `#` 付きの検索・分類用タグ |
| thread(スレッド) | X で連続した投稿をつなげたもの |
| quote post(引用ポスト) | 他の投稿を引用して投稿する形式 |
| Reels(リール) | Instagram の縦型短尺動画 |
| Stories(ストーリーズ) | 24時間で消える Instagram の投稿 |
| highlight(ハイライト) | ストーリーズを保存してプロフィールに残す機能 |
| membership(メンバーシップ) | 月額課金制の継続支援・限定コンテンツ |
| paywall(有料エリア) | 記事内の有料部分の境界 |
| affiliate(アフィリエイト、成果報酬型広告) | 紹介経由の成果に応じて報酬を得る仕組み |
| KPI(重要業績評価指標) | 成果を測る指標 |
| A/B test(A/B テスト) | 2案を比較して効果を測る手法 |
| repurposing(再利用、素材の転用) | 1つの題材を複数の形式・媒体に展開すること |
| stealth marketing(ステルスマーケティング、ステマ) | 広告であることを隠した宣伝 |
| Exif(撮影情報) | 写真に含まれる撮影日時・位置情報など |
| OGP / Open Graph Protocol | SNS での共有時に表示される画像・タイトルの設定 |
| API / Application Programming Interface(アプリケーション・プログラミング・インターフェース) | プログラムから公式にサービスを操作する窓口 |
| OAuth(オーオース) | パスワードを渡さず権限を委譲する認証の仕組み |
| rate limit(レート制限) | 一定時間あたりの呼び出し上限 |
| quota(クォータ) | 1日あたりの利用量の上限 |
| pay-per-use(従量課金、PPU) | 使った分だけ支払う料金体系 |
| webhook(ウェブフック) | サービス側から通知を受け取る URL |
| YPP / YouTube Partner Program(YouTube パートナープログラム) | YouTube の収益化プログラム |
| Shorts(ショート) | YouTube の縦型短尺動画 |
| hallucination(ハルシネーション) | 生成 AI が事実でない内容をもっともらしく出力すること |

## 投稿・機能

| 用語 | 意味 |
|---|---|
| handle(ハンドル) | `@` から始まるアカウント固有の名前。YouTube・X などで使う |
| professional account(プロフェッショナルアカウント) | Instagram のクリエイター・ビジネス向けアカウントの総称。インサイトなどが使える |
| professional mode(プロフェッショナルモード) | Facebook の個人プロフィールで発信者向け機能を使う設定 |
| trial reels(トライアルリール) | フォロワー以外にだけ試しに表示する Instagram のリール |
| topic tag(トピックタグ) | Threads の話題タグ。1投稿に1つ |
| text attachment(テキスト添付) | Threads で長文(最大10,000字)を投稿に付ける機能 |
| ghost post(ゴースト投稿) | Threads で24時間後に自動でアーカイブされるテキスト投稿 |
| spoiler(スポイラー) | 文字や画像をぼかして隠す機能 |
| reply settings / reply control(返信範囲) | 誰が返信できるかを投稿ごとに決める設定 |
| hide reply(返信の非表示) | 自分の投稿への返信を見えにくくする機能 |
| reply approval(返信の承認) | 承認するまで返信を公開しない設定 |
| Hidden Words(非表示ワード) | 指定した語を含むコメントや DM を自動で隠す Instagram の機能 |
| Restrict(制限) | 相手に通知せず、その人のコメントを他の人に見えなくする機能 |
| private reply(プライベート返信) | コメントした人へ DM で返信する仕組み |
| Stitch(ステッチ) | 他人の動画の冒頭を引用し、続けて自分の動画を流す TikTok の機能 |
| End screen(終了画面) | YouTube 動画の最後に置く、他の動画や登録への誘導 |
| custom feed(カスタムフィード) | Bluesky で利用者が作る独自のタイムライン |
| rich menu(リッチメニュー) | LINE のトーク画面下部に出る画像メニュー |
| weighted length(重み付き文字数) | 文字の種類ごとに1か2で数えた合計。X の上限は280 |
| t.co(短縮 URL) | X が URL を置き換える形式。どの URL も23字として数える |
| geo-gating(国の限定) | 投稿を表示する国を指定すること |
| grapheme(書記素) | 人が「1文字」と感じる単位。Bluesky の文字数はこれで数える |
| fediverse(フェディバース) | Mastodon など、互いにつながる分散型 SNS の総称 |
| Automated label / Parody label(自動化ラベル / パロディラベル) | bot アカウント、パロディアカウントであることを示す X の表示 |
| watermark(透かし) | 動画や画像に入るロゴや文字 |
| auto dubbing(自動吹き替え) | 音声を自動で他の言語に翻訳・合成する機能 |
| localization(ローカライズ) | 表現・単位などを相手の地域に合わせること |

## 分析・マーケティング

| 用語 | 意味 |
|---|---|
| KGI / Key Goal Indicator(重要目標達成指標) | 最終的に達成したいことを示す指標。KPI はその途中経過を測る |
| CVR / conversion rate(コンバージョン率) | 訪問者のうち、購入・登録などをした割合 |
| SMART(スマート) | 目標を具体的にする5つの観点(具体的・測定可能・達成可能・関連性・期限) |
| content pillar(コンテンツの柱) | 発信テーマの大分類。3つ程度に決めると企画が楽になる |
| owned media(オウンドメディア) | メール・自サイトなど、自分で管理できる媒体 |
| landing page(ランディングページ) | リンクをクリックした人が最初に着くページ |
| UTM parameter(UTM パラメータ) | 流入元を計測するために URL の末尾に付ける目印 |
| Engaged views(エンゲージ ビュー) | YouTube の YPP の資格と Shorts の収益分配に使う Shorts の視聴回数 |
| qualified views(対象となる閲覧) | 収益の計算に含まれる閲覧(Facebook) |
| skip rate(スキップ率) | リールが冒頭で飛ばされた割合 |
| social listening(ソーシャルリスニング) | SNS・Web 上の言及を集めて分析すること |
| search operator(検索演算子) | `from:` や `-` など、検索を絞り込む記号・命令 |
| risk register(リスク登録簿) | 起こり得る問題と対策の一覧 |

## 収益化・お金

| 用語 | 意味 |
|---|---|
| royalty(ロイヤリティ) | 売上のうち著者が受け取る割合(KDP など) |
| delivery costs(配信コスト) | KDP の 70% プランで、ファイルサイズに応じて引かれる費用 |
| Creator pool(クリエイター プール) | YouTube Shorts の広告収益を配分する原資 |
| Bits(ビッツ) | Twitch の投げ銭 |
| churn rate(解約率) | 一定期間に解約した会員の割合 |
| LTV / Life Time Value(顧客生涯価値) | 1人が続けている間に支払う合計額 |
| ASP / Affiliate Service Provider(アフィリエイト・サービス・プロバイダ) | 広告主と紹介者を仲介するサービス |
| GMV(流通総額) | EC の売上の合計 |
| CPM / cost per mille(1,000回表示あたりの単価) | 広告の価格を表示1,000回あたりで表す方法 |
| Paid partnership label(タイアップ投稿ラベル) | 企業案件であることを示す表示 |
| partnership ads(パートナーシップ広告) | クリエイターの投稿を企業が広告として配信する形式 |
| secondary use(二次利用) | 企業が投稿や素材を自社の広告などで使うこと |
| exclusivity(競合排除) | 一定期間、同業他社の案件を受けない約束 |
| spending limit(支出上限) | 請求サイクル内で使える上限額の設定 |
| トリブン | SUZURI で原価に上乗せする自分の利益 |
| 基準期間 / 特定期間 | 消費税の納税義務を判定する期間(個人は前々年/前年の1月1日〜6月30日)。→ [消費税とインボイス](../30-strategy/08-consumption-tax-and-invoice.md) |
| 2割特例 / 3割特例 | 納付税額を売上の消費税額の2割/3割にできる特例 |
| 簡易課税(みなし仕入率) | 売上の消費税にみなし仕入率を掛けて納税額を計算する方法 |
| 源泉徴収 | 支払う側が報酬から所得税を差し引いて納める仕組み |
| 按分 | 仕事と私用の両方に使う費用を、仕事の割合だけ経費にすること |

## API・技術

| 用語 | 意味 |
|---|---|
| endpoint(エンドポイント) | 操作ごとに決まった API の URL |
| scope(スコープ、権限範囲) | トークンで許す操作の範囲 |
| access token / refresh token(アクセストークン / リフレッシュトークン) | API を呼ぶための鍵 / 期限切れのアクセストークンを再発行するための長期の鍵 |
| PKCE(ピクシー) | 認可コードの横取りを防ぐ OAuth の拡張 |
| exponential backoff(指数バックオフ) | 待ち時間を倍々に増やして再試行する方法 |
| token bucket(トークンバケット方式) | 使った分が時間とともに回復するレート制限の方式 |
| quota bucket(クォータの枠) | 操作のグループごとに分かれた割り当て量の別枠 |
| container(コンテナ) | Meta API で公開前の投稿を入れる入れ物 |
| unaudited client(未監査のクライアント) | 監査を通っていないアプリ(TikTok)。公開範囲などが制限される |
| channel access token(チャネルアクセストークン) | LINE の API 呼び出しに使うトークン |
| app password(アプリパスワード) | 外部ツール専用に発行するパスワード(Bluesky など) |
| stream key(ストリームキー) | 配信ソフトとチャンネルを結ぶ秘密の文字列。漏れると第三者に配信される |
| encoder(エンコーダ、配信ソフト) | 映像を配信用に変換して送るソフト |
| RSS feed(RSS フィード) | 番組・記事の一覧を配信するデータ。ポッドキャストの配信に使う |
| `.env`(ドットエンブ) / `.gitignore` | 鍵を入れる手元専用のファイル / git に記録しないファイルの指定 |
| Content ID(コンテンツ ID) | YouTube の著作権の自動照合システム |
| C2PA / Content Credentials(コンテンツ認証情報) | 画像・動画の出所や編集履歴を記録する業界標準 |

## 安全・法務・アクセシビリティ

| 用語 | 意味 |
|---|---|
| passkey(パスキー) | 指紋・顔認証・画面ロックでログインする仕組み。フィッシングに強い |
| phishing(フィッシング) | 偽メール・偽サイトで認証情報を盗む詐欺 |
| backup code(バックアップコード) | スマホ紛失時に使う2段階認証の予備のコード |
| data portability(データポータビリティ) | 自分のデータを別のサービスへ持ち運べること |
| moderation(モデレーション) | 書き込みを見守り、ルールに沿って整理すること |
| Community Guidelines strike(違反警告) | YouTube の警告。90日間有効で、90日以内に3回でチャンネル削除の可能性 |
| Phone verification(電話認証) | YouTube で15分超の動画・カスタムサムネイル・ライブ配信に必要な本人確認 |
| contrast ratio(コントラスト比) | 文字色と背景色の明るさの差。読みやすさの指標 |
| reasonable accommodation(合理的配慮) | 障害のある人の求めに応じて、過重でない範囲で障壁を取り除くこと |
| Creative Commons / CC(クリエイティブ・コモンズ) | 作者が条件を組み合わせて利用を許可する共通ライセンス |
| opt-in / double opt-in(オプトイン / ダブルオプトイン) | 受信者が先に配信に同意する方式 / 確認メールのリンクを押して登録が完了する方式 |
| ESP / email service provider(メール配信サービス) | 登録・配信・停止を管理するサービス |

## 年・暦

| 用語 | 意味 |
|---|---|
| 皇紀 | 神武天皇即位紀元。西暦 + 660(2026年は皇紀2686年) |
| 和暦 | 元号による年。令和は西暦 − 2018 |
| 新暦・旧暦 | 現行の太陽暦と、明治5年(1872年)まで用いられた太陰太陽暦 |

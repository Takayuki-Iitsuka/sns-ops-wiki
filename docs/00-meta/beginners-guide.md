# はじめての SNS 運用

> **このページで分かること**: SNS 運用の全体像、作業の流れ、このナレッジベースをどの順番で読めばよいか。
>
> **対象**: これから SNS(ソーシャル・ネットワーキング・サービス)で発信を始める人、何から手を付ければよいか分からない人。**先に読むページ**: なし(ここが入口です)。

## 概要

SNS 運用とは、X・Instagram・YouTube などのサービスにアカウントを作り、**目的を決めて、計画的に投稿し、反応を見て改善し続けること**です。思いつきで投稿するだけでも楽しめますが、「誰に・何を・何のために」届けるかを決めると、少ない労力で成果が出やすくなります。

このナレッジベースは、特定のテーマ(料理、イラスト、地域情報など)に依存しない **SNS 運用そのものの知識**をまとめたものです。テーマが何であっても使える「型」と「仕様」と「ルール」を扱います。

## 用語(最初に知っておきたい5つ)

| 用語 | 意味 |
|---|---|
| account(アカウント) | サービス上のあなたの「名前と部屋」。プロフィール・投稿・フォロワーがひも付く |
| post(投稿) | 文章・画像・動画などを公開すること、またはその1件。X では「ポスト」、Instagram では「投稿」「リール」など呼び名が違う |
| follower(フォロワー) | あなたの投稿を継続的に受け取る設定をした人 |
| engagement(エンゲージメント) | いいね・返信・保存・共有など、投稿への反応の総称 |
| algorithm(アルゴリズム、表示の仕組み) | どの投稿を誰に見せるかをサービスが自動で決める仕組み。中身は非公開で、ときどき変わる |

もっと詳しい解説は [basic-terms-explained](../01-common/basic-terms-explained.md)、辞書として引くなら [用語集](glossary.md) を使ってください。

## SNS 運用の全体の流れ

SNS 運用は、次の6つの段階をぐるぐる回す作業です。

```
① 目的を決める → ② 場所(サービス)を選ぶ → ③ 準備する(アカウント・安全設定)
        ↑                                                  ↓
⑥ 振り返って直す ← ⑤ 反応に応える ← ④ 計画して投稿する
```

| 段階 | やること | 読むページ |
|---|---|---|
| ① 目的を決める | 「認知を広げたい」「商品を売りたい」「仲間を作りたい」など、ゴールと数字の目安を決める | [目標・KPI](../30-strategy/01-goals-kpi-roadmap.md)、[導線](../30-strategy/02-funnel.md) |
| ② 場所を選ぶ | 自分の発信形式(文章・画像・動画)と届けたい相手に合うサービスを1〜2個選ぶ | [サービスの選び方](../01-common/choosing-platforms.md) |
| ③ 準備する | アカウント作成、プロフィール、2段階認証、プライバシー設定 | [アカウント保護](../01-common/account-security.md)、[個人情報](../01-common/privacy-and-personal-info.md)、各サービスの初期設定 |
| ④ 計画して投稿する | 企画の柱を決め、投稿カレンダーを作り、画像・動画・文章を用意する | [企画](../01-common/content-planning.md)、[投稿の流れ](../01-common/posting-workflow.md)、[文章術](../01-common/writing-guide.md)、[画像の仕様](../01-common/image-specs-comparison.md) |
| ⑤ 反応に応える | コメントへの返信、困った反応への対処 | [コメント運用](../01-common/comments-and-engagement.md)、[炎上対応](../01-common/crisis-response.md) |
| ⑥ 振り返って直す | 週1回・月1回、数字を見て次の投稿を改善する | [分析・KPI](../01-common/analytics-kpi.md)、[週次レビュー](../../templates/weekly-review.md) |

最初の1か月の具体的な行動は [最初の30日](../01-common/first-30-days.md) にまとめています。

## 初心者がつまずきやすいポイント

| つまずき | なぜ起きるか | 対処 |
|---|---|---|
| 何を投稿すればよいか分からない | 目的と相手が決まっていない | [企画](../01-common/content-planning.md)の「柱(テーマの大分類)」を3つ決める |
| 全部のサービスを同時に始めて疲れる | 1人で運用できる量を超えている | まず1つに集中し、慣れてから2つ目を追加する |
| フォロワーが増えず、やめてしまう | 最初の数か月は伸びにくいのが普通 ⚪ | 数ではなく「投稿を続けられたか」を最初の目標にする |
| 画像が切れる・ぼやける | サービスごとに推奨サイズ・比率が違う | [書き出しプリセット](../01-common/export-presets.md)の値で書き出す |
| 乗っ取られた | パスワードの使い回し、2段階認証なし | [アカウント保護](../01-common/account-security.md)を最初に済ませる |
| 他人の画像や音楽を使って削除された | 著作権の理解不足 | [画像素材と著作権](../01-common/image-sources-and-copyright.md)を読む |
| 依頼を受けた投稿で PR 表記を忘れた | ステマ規制を知らない | [法令](../01-common/legal-compliance.md)を読む |

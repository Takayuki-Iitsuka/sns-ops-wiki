# 要検証リスト

## 確認方法

`help.x.com`・`www.help-note.com` は Cloudflare の bot 確認で、`help.instagram.com` は JavaScript 描画で、作成時の実行環境から本文を取得できませんでした。`support.google.com`・`developers.facebook.com`・`docs.x.com`・`atproto.com` などは、環境のネットワーク許可に含まれていません。次のいずれかで確認します。

- 利用者が公式ページを開き、本文を貼り付けて更新を依頼する(最も確実)。
- ネットワーク許可に該当ドメインを追加する(bot 確認のあるサイトは取得できない可能性が高い)。

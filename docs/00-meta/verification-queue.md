# 要検証リスト

公式ヘルプで確認できていない項目です。確認したら該当ページを ✅ に更新し、この表から消すか「完了」にします。

## 確認方法

`help.x.com`・`help.instagram.com`・`www.help-note.com` は作成時の実行環境から参照できませんでした(ネットワーク許可リスト外)。次のいずれかで確認します。

- セッションのネットワーク設定で上記ドメインを許可し、再度調査を依頼する
- 利用者が公式ページを開き、内容を貼り付けて更新を依頼する

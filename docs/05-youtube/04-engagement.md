# YouTube コメント・コミュニティ運用

> **このページで分かること**: コメント設定(保留・ブロックする単語・承認済みユーザー)の使い方、返信の基本、投稿(コミュニティ投稿)の使い方、荒らし・スパムへの対処。
>
> **対象**: 初心者  **先に読むページ**: [comments-and-engagement](../01-common/comments-and-engagement.md)

共通: [comments-and-engagement](../01-common/comments-and-engagement.md)

## 概要

コメントは、視聴者の疑問・要望・感想が直接届く場所です。丁寧に返信すると、視聴者との関係が深まり、次の企画のヒントも得られます。一方で、スパムや荒らしを放置すると、ほかの視聴者が離れます。YouTube には**自動で保留する仕組み**があるので、最初に設定しておくと手間が減ります。

## 用語

| 用語 | 意味 |
|---|---|
| 保留 | コメントを公開前に止め、チャンネル側が承認するまで表示しないこと |
| ブロックする単語 | 指定した語を含むコメントを自動で保留するリスト |
| 承認済みユーザー | コメントが自動で公開される信頼できる人のリスト |
| 非表示のユーザー | その人のコメントを全動画で見えなくする設定 |
| 固定(ピン留め) | 1件のコメントを一番上に表示すること |
| モデレーター | コメントやライブチャットの管理を手伝う人 |
| 投稿(旧コミュニティ投稿) | 動画以外のテキスト・画像・アンケートなどをチャンネルに載せる機能 |

## コメント設定(✅ answer/9483359)

### 動画ごとの設定

| 設定 | 内容 |
|---|---|
| オン / 一時停止 / オフ | 一時停止は既存コメントを残したまま新規を受け付けない。オフはコメント不可(オンに戻すと既存コメントが再表示) |
| 保留のレベル | 「なし」「基本」(不適切の可能性があるものを保留)「厳格」(保留の対象を広げる)「すべて保留」 |
| コメントできる人の制限 | チャンネル登録者とメンバーのみに限定可。登録期間「指定なし / 1時間 / 1日 / 1週間」を選べる |

保留されたコメントは**最長60日間** YouTube Studio に残り、承認するまで公開されません(✅)。

### チャンネル全体の設定

| 設定 | 内容 |
|---|---|
| 承認済みユーザー | この人のコメントは自動で公開(リンク・単語のフィルターも適用されない) |
| 非表示のユーザー | 指定した人のコメントを全動画で非表示 |
| ブロックする単語 | 指定語句を含む(ほぼ一致を含む)コメントを最長60日間保留 |
| リンクを含むコメントのブロック | URL やハッシュタグを含むコメントを保留(自分・モデレーター・承認済みユーザーは対象外) |
| デフォルトのコメント設定 | **新しい動画**に適用。既存動画には影響しない |

### 設定の手順(⚪ メニュー名は変わる可能性)

1. YouTube Studio →左下の「設定」→「コミュニティ」を開きます。
2. 「自動フィルタ」で、承認済みユーザー・非表示のユーザー・ブロックする単語・リンクのブロックを設定します。
3. 「デフォルト」で、新しい動画のコメント保留レベルを選びます。
4. 既存の動画は、「コンテンツ」で動画を選び、個別または一括編集で変更します。

## コメントへの対応の流れ(⚪ 運用例)

1. YouTube Studio →「コメント」で「返信済みでないもの」を確認します。
2. **保留中**のタブも確認し、問題なければ承認します。
3. 質問には短く具体的に返信します。よい質問は固定(ピン留め)します。
4. スパム・詐欺(「DM してください」「当選しました」など)は削除・報告し、送り主を非表示にします。
5. 繰り返し来る悪質な語は「ブロックする単語」に追加します。

**返信の例**

| コメント | 返信例 |
|---|---|
| 「冷凍で何日もちますか?」 | 「ご質問ありがとうございます。目安は2〜3週間です。詳しくは概要欄の保存方法をご覧ください。」 |
| 「材料の量が分かりにくい」 | 「ご指摘ありがとうございます。説明欄に分量の表を追記しました。」 |

## 機能(運用での使い方)

| 機能 | 使い方 | 確度 |
|---|---|---|
| 固定コメント | 動画の補足、訂正、リンク、質問を上部に | ⚪ |
| ハート | 良いコメントに反応 | ⚪ |
| コメントの保留 | 不適切な可能性のあるコメントをレビュー待ちに | ✅ |
| ブロックする単語 | NG ワード登録 | ✅ |
| 承認済みユーザー | 信頼できる人のコメントを自動承認 | ✅ |
| ライブチャット管理 | モデレーター、スローモード、メンバー限定 | ⚪ |
| 投稿 | アンケート・クイズ・画像・テキスト・動画・GIF・音楽 | ✅ |
| 再生リスト・終了画面 | 次の視聴へ導く | ✅ [08](08-upload-and-shorts.md) |

## 投稿(旧コミュニティ投稿)(✅ answer/9409631)

- アンケート、クイズ、GIF、テキスト、音楽、画像、動画を使って視聴者と交流できます。
- **使えない場合**: 管理対象のアカウント、**子ども向けに設定したチャンネル**、チャンネルでの役割によっては不可。**ドイツでは提供されていません**。
- 作成の手順・画像の枚数は別記事(未取得 ⚪)。YouTube Studio かアプリの作成アイコンから「投稿」を選ぶ流れです(⚪ 表記は変わる可能性)。

**使い方の例**: 次回の動画テーマを3択のアンケートで聞く / 動画公開の告知 / 撮影の裏側の写真。

## 運用のコツ(⚪ 経験則)

1. **公開直後の1時間**は返信に時間を割きます。
2. 質問に答える動画を作ります(コメントが企画の源泉)。
3. ライブ配信中はコメントを読み上げ、名前を呼びます。
4. 荒れやすい話題は**保留レベル「厳格」**や登録者限定を使い、議論の質を保ちます。
5. 誤りの指摘は素直に認め、固定コメントで訂正します。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| コメントが表示されないと言われた | 「保留中」を確認。ブロックする単語やリンクのブロックに当たっていないか(✅) |
| デフォルト設定を変えたのに古い動画が変わらない | デフォルトは新しい動画のみ。既存は一括編集で(✅) |
| 子ども向け動画にコメントが付かない | 子ども向け設定ではコメントが無効(✅) |
| スパムに返信してしまった | 削除・報告・非表示。返信すると目立たせてしまう |

## 注意

- **子ども向けに設定した動画ではコメントが無効**になります(✅ answer/9527654。以前は ⚪)。ほかにも終了画面・カード・通知ベル・Super Chat なども使えません([07-policies-and-checklist](07-policies-and-checklist.md))。
- 収益化後は、コメント欄の広告適性にも気を配ります(不適切な語を放置しない)(⚪)。
- 視聴者の個人情報(住所・学校名など)を含むコメントは非公開にします([privacy](../01-common/privacy-and-personal-info.md))。
- 炎上の兆候があれば [crisis-response](../01-common/crisis-response.md) の手順へ。

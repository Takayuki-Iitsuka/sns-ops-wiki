# YouTube コメント・コミュニティ運用

共通: [comments-and-engagement](../01-common/comments-and-engagement.md)

## 機能(⚪)

| 機能 | 使い方 |
|---|---|
| 固定コメント | 動画の補足、リンク、質問を上部に |
| ハート | 良いコメントに反応 |
| コメントの保留 | 不適切な可能性のあるコメントをレビュー待ちに |
| ブロックワード | NG ワード登録 |
| 承認済みユーザー | 信頼できる人のコメントを自動承認 |
| ライブチャット管理 | モデレーター、スローモード、メンバー限定 |
| コミュニティ投稿 | 投票・告知・画像(提供状況は要確認) |
| 再生リスト・終了画面 | 次の視聴へ導く |

## 運用のコツ

1. **公開直後の1時間**は返信に時間を割く(⚪)。
2. 質問に答える動画を作る(コメントが企画の源泉)。
3. ライブ配信中は読み上げ+名前を呼ぶ。
4. 荒れやすい話題は**コメントの保留**を使い、議論の質を保つ。
5. スパム・詐欺コメント(「DM してください」等)は削除・通報。

## 注意

- 子ども向け設定の動画ではコメントが無効になる(⚪)。
- 収益化後は、コメント欄の広告適性にも気を配る(不適切な語を放置しない)。

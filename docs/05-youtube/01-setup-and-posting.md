# YouTube 初期設定と投稿

## 初期設定チェックリスト

1. **Google アカウント**: 運用専用。2段階認証を有効化([account-security](../01-common/account-security.md))。
2. **チャンネル作成**: ブランドアカウント(複数管理者に対応)にすると共同運用・引き継ぎがしやすい(⚪)。
3. **チャンネル名・ハンドル(@)**: 検索される語を入れる。変更の頻度・制限は公式で確認 ⚪。
4. **プロフィール画像・バナー**: [02-media-specs](02-media-specs.md)
5. **概要欄(チャンネルの説明)**: 誰向けに何を発信するか、更新頻度、連絡先、リンク。
6. **チャンネルの確認(電話番号認証)**: カスタムサムネイルや長尺アップロード、ライブ配信に必要となる ⚪(🟡 カスタムサムネイルに電話確認が必要とする資料)。
7. **ライブ配信の有効化**: 初回は有効化に時間がかかる場合がある ⚪。
8. **対象ユーザー設定**: 子ども向けか否かの設定は**必須**。誤ると収益化や機能に影響 ⚪。
9. **既定のアップロード設定**: カテゴリ、言語、ライセンス、公開設定、既定の説明欄テンプレ。
10. **ブランディング**: 透かし(ウォーターマーク)、チャンネル予告トレーラー。

## 投稿の種類

| 種類 | 概要 | 使い所 |
|---|---|---|
| 長尺動画 | 横型が基本 | 解説・講座・レビュー |
| Shorts | 縦型、**3分まで**とする新しい資料 🟡 | 発見・切り抜き |
| ライブ配信 | リアルタイム | 交流、Super Chat |
| プレミア公開 | 予約公開+チャット | 新作の盛り上げ |
| コミュニティ投稿 | 画像・投票・テキスト | 告知・交流(提供条件は変化 ⚪) |
| ポッドキャスト | 音声主体 | 要確認 |

## アップロード手順(YouTube Studio)

1. 「作成」→「動画をアップロード」。
2. タイトル・説明・サムネイル・再生リスト・視聴者層(子ども向けか)・年齢制限。
3. 詳細: タグ、カテゴリ、言語、字幕、ライセンス、**合成コンテンツ(AI 生成)の開示** ⚪。
4. 動画の要素: 終了画面、カード、チャプター。
5. チェック(著作権、広告適性)。
6. 公開設定: 非公開 / 限定公開 / 公開 / **スケジュール**。

## Shorts を作る

- 縦型(9:16)で撮影・編集([02-media-specs](02-media-specs.md))。
- 最初の1〜2秒で内容を示す。繰り返し視聴を狙ったループ構成も有効(⚪)。
- 長尺動画の**切り抜き**を Shorts にし、概要欄/固定コメントで本編へ誘導。

## 運用のコツ

- 投稿頻度は継続できる範囲(週1〜)。定期更新は視聴習慣に有利(⚪)。
- 1本ごとに**チェックリスト**([07-policies-and-checklist](07-policies-and-checklist.md))で確認。
- 量産前にサムネイル・タイトルの型を作る。

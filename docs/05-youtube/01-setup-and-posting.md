# YouTube 初期設定と投稿

> **このページで分かること**: YouTube チャンネルの作り方、YouTube Studio(管理画面)の基本、最初に済ませる設定、投稿の種類の違い。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[アカウントの安全](../01-common/account-security.md)

## 概要

YouTube で発信するには、**Google アカウント**の中に**チャンネル**を作ります。チャンネルは「動画を並べるお店」のようなものです。作った後の管理(アップロード、編集、分析、収益化)は、ほぼすべて **YouTube Studio**(ユーチューブ スタジオ。クリエイター向けの管理画面)で行います。

最初に設定を整えておくと、あとで「長い動画が上げられない」「サムネイルが変えられない」「子ども向け設定を間違えて機能が使えない」といったつまずきを防げます。アップロードの詳しい手順は [08-upload-and-shorts](08-upload-and-shorts.md) にまとめています。

## 用語

| 用語 | 意味 |
|---|---|
| チャンネル | 動画・再生リスト・投稿をまとめて公開する場所。1つの Google アカウントで複数作れる |
| ブランド アカウント | ビジネス名や別名でチャンネルを作るときの Google アカウントの形式。複数人での管理に向く |
| ハンドル(@) | `@example` のような、チャンネル固有の短い名前。URL やメンションに使われる |
| YouTube Studio | アップロード・編集・コメント管理・アナリティクス・収益化を行う管理画面(studio.youtube.com、スマホは「YouTube Studio」アプリ) |
| チャンネルの確認(電話認証) | 電話番号で本人確認をすること。長い動画やカスタムサムネイルに必要 |
| 上級者向け機能 | 電話認証に加えて、チャンネル履歴・身分証明書・動画による確認で使える機能群 |
| 子ども向け(Made for Kids) | 動画が子ども向けかどうかの申告。法令(COPPA)対応のため必須 |

## 手順 1: チャンネルを作る(✅)

公式ヘルプ「YouTube チャンネルを作成する」の手順です。画面の表記は変わることがあります。

**個人名のチャンネル**

1. パソコンかスマホのブラウザで YouTube にログインします。
2. 右上のプロフィール写真 →「設定」を開きます。
3. 「アカウント」の「チャンネルを追加または管理する」を選びます。
4. 「チャンネルを作成」を選びます。
5. プロフィール写真、名前、ハンドルを入力します。
6. 「チャンネルを作成」を押して完了です。

**ビジネス名・別名のチャンネル(ブランド アカウント)**

1. YouTube にログインし、チャンネル一覧のページを開きます。
2. 「新しいチャンネルを作成」を押します。
3. プロフィール写真、名前、ハンドルを設定し、「チャンネルを作成」を押します。新しいブランド アカウントが作られます。

> **初心者へのおすすめ**: お店・団体・チームで運用する予定なら、最初からブランド アカウントで作ると、担当者の追加や引き継ぎがしやすくなります(⚪ 運用上の経験則)。保護者向け管理機能を使っているアカウントでは作成できないことがあります(✅)。

## 手順 2: 最初に済ませる設定

| # | 設定 | 内容 | 確度 | 出典 |
|---|---|---|---|---|
| 1 | Google アカウントの保護 | 運用専用のアカウントにし、2段階認証をオン。YPP(収益化)の申し込みにも必須 | ✅ | [05-monetization](05-monetization.md) |
| 2 | チャンネルの確認(電話認証) | **15分を超える動画のアップロード、カスタムサムネイル、ライブ配信、Content ID の申し立てへの再審査請求**が使えるようになる | ✅ | answer/171664 |
| 3 | 上級者向け機能 | 電話認証の後、チャンネル履歴を積むか、身分証明書・動画による確認で有効化。サムネイルのテストと比較などに必要 | ✅ | answer/171664 |
| 4 | チャンネル名 | **14日間に2回まで**変更可。変更すると認証バッジが外れる | ✅ | answer/2972003 |
| 5 | ハンドル | **3〜30文字**(漢字は1〜10文字、ひらがな・カタカナは2〜20文字)。`_` `-` `.` は使えるが先頭・末尾は不可。**14日間に2回まで**変更可 | ✅ | answer/11585688、answer/2972003 |
| 6 | プロフィール写真・バナー・透かし | 寸法は [02-media-specs](02-media-specs.md) | ✅ | answer/10456525 |
| 7 | チャンネルの説明・リンク | 誰向けに何を、どの頻度で発信するか。ホームに表示できるリンクは**最大14個** | ✅ | answer/2972003 |
| 8 | 視聴者層(子ども向けか) | **所在地を問わず申告が必要**。誤ると YouTube 上の措置や法的措置の対象になり得る | ✅ | answer/9528076 |
| 9 | アップロード動画のデフォルト設定 | カテゴリ、言語、ライセンス、公開設定、説明欄のテンプレートを先に決めておく | ⚪ 画面名は変わる可能性 | — |

電話認証は、YouTube アプリで15分を超える動画をアップロードしようとしたときにも案内されます。確認コードは SMS か自動音声で届きます(✅ answer/71673)。

左側のメニューに主な機能が並びます。初心者がまず使うのは次の6つです。

| メニュー | できること | 詳しいページ |
|---|---|---|
| ダッシュボード | 最新動画の成績、お知らせ | — |
| コンテンツ | 動画・Shorts・ライブの一覧。タイトルや公開設定の編集 | [08-upload-and-shorts](08-upload-and-shorts.md) |
| アナリティクス | 視聴回数、総再生時間、クリック率など | [06-analytics-and-tips](06-analytics-and-tips.md) |
| コメント | コメントの返信・承認・削除 | [04-engagement](04-engagement.md) |
| 字幕 | 字幕の追加・編集 | [03-text-and-discovery](03-text-and-discovery.md) |
| 収益化 | YPP の条件、申し込み、特典 | [05-monetization](05-monetization.md) |

2026年(皇紀2686年・令和8年)7月から新しい YouTube Studio のデザインが段階的に導入されており、画面の見た目が変わることがあります(✅ [answer/9002587](https://support.google.com/youtube/answer/9002587?hl=ja))。

## 投稿の種類

| 種類 | 概要 | 使い所 | 確度 |
|---|---|---|---|
| 長尺動画 | 横型(16:9)が基本。既定は15分まで、確認後は最大12時間 | 解説・講座・レビュー | ✅ answer/71673 |
| Shorts(ショート) | 縦型・正方形、**最大3分** | 発見・切り抜き | ✅ answer/10059070 |
| ライブ配信 | リアルタイム配信。16歳以上・チャンネルの確認が必要 | 交流、Super Chat | ✅ [08](08-upload-and-shorts.md) |
| プレミア公開 | 予約した時刻にみんなで初公開を見る形式+チャット | 新作の盛り上げ | ⚪ |
| 投稿(旧コミュニティ投稿) | テキスト・画像・アンケート・クイズ・動画など | 告知・交流 | ✅ [04](04-engagement.md) |
| ポッドキャスト | 再生リストをポッドキャストとして登録 | 音声主体の番組 | ⚪ [podcast](../01-common/podcast-and-audio.md) |

アップロードの具体的な手順は [08-upload-and-shorts](08-upload-and-shorts.md) を見てください。

## 具体例: チャンネルの説明文

**良い例(料理アカウント)**

```
平日20分でできる作り置きおかずを、毎週土曜に1本紹介しています。
材料は近所のスーパーで買えるものだけ。分量は2人分です。
レシピの全文は概要欄のリンク先にあります。
お仕事のご相談: (問い合わせフォームの URL)
```

**悪い例**: 「よろしくお願いします!」だけ。何のチャンネルか、いつ更新されるかが分からず、登録の理由になりません。

## よくある失敗と対処

| 失敗 | 原因 | 対処 |
|---|---|---|
| 15分を超える動画がアップロードできない | 電話認証をしていない | YouTube Studio かアプリで電話認証する。認証済みでも上がらない場合は、著作権の申し立てや違反警告を確認(✅ answer/71673) |
| サムネイルを変更できない | 電話認証をしていない | 同上(✅ answer/171664) |
| 個人の Google アカウントで作り、後から共同運用できない | ブランド アカウントにしていない | 最初の段階でブランド アカウントを選ぶ。既存チャンネルの移行は公式ヘルプで確認(⚪) |
| チャンネル名を何度も変えられない | 14日間に2回の上限 | 名前を決める前に候補を紙に書き、検索で重複を確認する |
| 子ども向けかどうかを適当に選んだ | 申告の意味を知らない | [07-policies-and-checklist](07-policies-and-checklist.md) の「子ども向け」を読み、動画単位でも見直す |

## 注意点

- パスワード・確認コード・バックアップコードは誰にも共有しません。共同運用は「権限」の付与で行います([account-security](../01-common/account-security.md))。
- チャンネル名・ハンドルで他人や企業になりすますことは禁止です。ハンドルの販売・譲渡も禁止されています(✅ answer/11585688)。
- 年齢制限など地域で条件が違う項目は、YouTube Studio に表示される内容を優先します。

## チェックリスト

- [ ] 運用専用の Google アカウントで、2段階認証がオン
- [ ] チャンネル(必要ならブランド アカウント)を作成
- [ ] 電話認証を済ませた
- [ ] ハンドル・チャンネル名・説明文・リンクを設定
- [ ] プロフィール写真・バナーを [02-media-specs](02-media-specs.md) の寸法で設定
- [ ] 視聴者層(子ども向けか)をチャンネル単位で設定
- [ ] アップロードのデフォルト設定(説明欄テンプレートなど)を作成

## 運用のコツ(⚪ 経験則)

- 投稿頻度は継続できる範囲(週1本からでよい)。定期的な更新は視聴習慣につながりやすいです。
- 1本ごとに [07-policies-and-checklist](07-policies-and-checklist.md) のチェックリストで確認します。
- 量産する前に、サムネイル・タイトルの「型」を決めておきます。

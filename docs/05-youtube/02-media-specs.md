# YouTube 動画・画像仕様

> 値は二次資料中心(🟡)。サムネイルなどは公式で確認 (#30)。横断比較は [video-specs-comparison](../01-common/video-specs-comparison.md)、[image-specs-comparison](../01-common/image-specs-comparison.md)。

## 動画

| 項目 | 値 | 確度 |
|---|---|---|
| 形式 | MP4 推奨(H.264 映像+AAC 音声) | 🟡 |
| 最大サイズ・長さ | 256GB または 12時間のいずれか小さい方とする資料 | 🟡 |
| 解像度・比率(長尺) | 16:9、1920×1080(4K は 3840×2160) | 🟡 |
| 縦型・正方形 | 可。Shorts は 9:16(1080×1920) | 🟡 |
| Shorts の長さ | **3分まで**(新しい資料)。60秒とする古い資料あり | 🟡 |
| ビットレート目安(アップロード) | 1080p で約8Mbps、4K で35〜45Mbps | 🟡 |
| フレームレート | 24〜60fps | 🟡 |
| 音声 | AAC-LC、ステレオ、384kbps とする資料 | 🟡 |

## サムネイル

| 項目 | 値 | 確度 |
|---|---|---|
| サイズ | 1280×720(幅640px以上) | 🟡 |
| 比率 | 16:9 | 🟡 |
| 容量 | 2MB 未満 | 🟡 |
| 形式 | JPEG / PNG(GIF 可とされる) | 🟡 ⚪ |
| 前提 | カスタムサムネイルにはチャンネル確認が必要 | 🟡 |
| Shorts のカスタムサムネ | 1080×1920 とする資料と 16:9 とする資料で不一致 | 🟡 #30 |

### サムネイル設計(⚪)

1. **右下に再生時間が重なる**ので、そこに文字を置かない。
2. 文字は**6語以内**、太く、背景とコントラスト。縮小表示(スマホの一覧・関連動画)で読めること。
3. 顔・対象を大きく、**1つの焦点**。
4. シリーズは**型を統一**(色・フォント・配置)して識別性を上げる。
5. タイトルと**同じことを言わず補完**する。
6. 誇大・誤解を招く表現は規約違反や信頼低下の原因。

## チャンネルバナー・プロフィール

| 項目 | 値 | 確度 |
|---|---|---|
| バナー | 2560×1440 で書き出し、6MB 以下とする資料 | 🟡 |
| 安全領域 | 中央 1546×423(TV/PC/モバイルで見える範囲) | 🟡 |
| 最小 | 2048×1152 とする資料 | 🟡 |
| プロフィール | 800×800、円形表示、4MB 以下とする資料 | 🟡 |

## 字幕ファイル

SRT など。**手動字幕は検索や視聴維持に有利**(⚪)。自動字幕は誤りを必ず確認。

# YouTube 動画・画像仕様

> **このページで分かること**: 動画の書き出し設定、アップロードできる長さ・容量、サムネイル・バナー・プロフィール写真・透かしの寸法、字幕ファイルの形式。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [動画の基本](../01-common/video-basics.md)

> YouTube ヘルプ(日本語版)の本文を 2026年(皇紀2686年・令和8年)11月3日に直接取得して確認しました(✅)。確認できなかった項目は 🟡/⚪ のまま。横断比較は [video-specs-comparison](../01-common/video-specs-comparison.md)、[image-specs-comparison](../01-common/image-specs-comparison.md)。

## 概要

YouTube は多くの形式の動画を受け付けますが、**推奨の設定で書き出す**と、処理が早く、画質の劣化も少なくなります。迷ったら「**MP4・H.264・AAC・撮影時と同じフレームレート・1080p で 8Mbps 前後**」を基準にしてください。画像(サムネイル・バナーなど)は、用途ごとに比率と最小サイズが決まっています。

## 用語

| 用語 | 意味 |
|---|---|
| コンテナ | 映像と音声を入れる「箱」の形式。MP4、MOV など |
| コーデック | 映像・音声を圧縮する方式。H.264(映像)、AAC(音声)など |
| ビットレート | 1秒あたりのデータ量(Mbps)。大きいほど高画質・大容量 |
| フレームレート(fps) | 1秒あたりのコマ数。30fps、60fps など |
| アスペクト比 | 縦横の比率。16:9(横長)、9:16(縦長) |
| 安全領域 | どの端末でも切れずに表示される範囲。文字やロゴはこの中に置く |
| HDR | 明暗の幅が広い映像形式。対応端末で鮮やかに見える |

## 動画のエンコード(✅ 「おすすめのエンコード設定」)

| 項目 | 推奨 |
|---|---|
| コンテナ | **MP4**。編集リストなし、**`moov` atom をファイルの先頭に**(ファストスタート) |
| 音声コーデック | AAC-LC、Opus、Eclipsa オーディオ |
| 音声チャンネル | ステレオ、ステレオ+5.1 など。サンプルレート **48kHz** |
| 映像コーデック | **H.264**、プログレッシブ(インターレース不可)、High Profile、2連続Bフレーム、**closed GOP**、CABAC、クロマ 4:2:0 |
| ビットレート | 可変(VBR)。上限なし。下記を参考に |
| フレームレート | **撮影時と同じ**で書き出す。24・25・30・48・50・60 fps が一般的。インターレースはアップロード前に解除 |
| 色空間 | 資料に記載あり(sRGB/Rec.709 を基本) |

**推奨映像ビットレート(SDR、標準フレームレート 24/25/30 → 高フレームレート 48/50/60)**

| 解像度 | 標準 | 高フレームレート |
|---|---|---|
| 360p | 1 Mbps | 1.5 Mbps |
| 480p | 2.5 Mbps | 4 Mbps |
| 720p | 5 Mbps | 7.5 Mbps |
| **1080p** | **8 Mbps** | **12 Mbps** |
| 1440p(2K) | 16 Mbps | 24 Mbps |
| 2160p(4K) | 35〜45 Mbps | 53〜68 Mbps |
| 8K | 80〜160 Mbps | 120〜240 Mbps |

**HDR**: 1080p で 10 Mbps(標準)/ 15 Mbps(高フレームレート)、4K は 44〜56 / 66〜85 Mbps。HDR の 480p 以下は非対応。

**音声ビットレート**: モノラル 128 kbps、**ステレオ 384 kbps**、5.1 512 kbps。

### 初心者向けの書き出し例(⚪ 上表から作った目安)

| 用途 | 設定 |
|---|---|
| スマホで撮った横長の解説動画 | MP4 / H.264 / 1920×1080 / 30fps / 8Mbps / AAC ステレオ 48kHz・384kbps |
| 縦長の Shorts | MP4 / H.264 / 1080×1920 / 30fps / 8Mbps 前後 / AAC |
| 動きの多いゲーム映像 | MP4 / H.264 / 1920×1080 / 60fps / 12Mbps / AAC |

編集アプリごとの設定場所は [export-presets](../01-common/export-presets.md)、[動画編集アプリ](../01-common/video-editing-apps.md)。

## サムネイル(✅ 「カスタム サムネイル」)

| 項目 | 値 |
|---|---|
| 推奨解像度 | **動画 3,840×2,160px、ショート動画 2,160×3,840px**(できるだけ大きく。埋め込みプレーヤーのプレビューにも使われる) |
| 最小幅 | 640px(動画・ショートとも) |
| 形式 | JPG、PNG など |
| 容量上限 | **モバイル**: 動画 **2MB**、ポッドキャスト 10MB。**パソコン**: 動画・ショート・ポッドキャストとも **50MB** |
| 比率 | **動画 16:9**、**ショート 9:16**、ポッドキャストの再生リスト 1:1 |
| 注意 | 16:9 のカスタムサムネイルを持つ**縦向き動画**は、ホーム・探索・登録チャンネルで**自動生成の 4:5 サムネイル**に置き換えられる(再生フィード・履歴・モバイル以外では表示) |
| ポリシー | ヌード、ヘイト、暴力、有害な内容は拒否・違反警告。繰り返すと**30日間**カスタムサムネイルを停止 |

> **「2MB 未満」はモバイルからの動画サムネイルの上限**。パソコンからは 50MB まで。以前の「2MB 未満」は不完全だった。

カスタムサムネイルを使うには**チャンネルの確認(電話認証)**が必要です(✅ [answer/171664](https://support.google.com/youtube/answer/171664?hl=ja))。

### サムネイル設計(⚪)

1. **右下に再生時間が重なる**ので、そこに文字を置かない。
2. 文字は**6語以内**、太く、背景とコントラスト。スマホの縮小表示で読める。
3. 顔・対象を大きく、焦点は1つ。
4. シリーズは型を統一(色・フォント・配置)。
5. 縦長動画は 4:5 の自動生成に置き換わる場面を考え、**重要要素は中央に**。

**作り方の例**: 3840×2160 のキャンバスで作り、PNG か JPG で書き出します。スマホからアップロードする場合は 2MB 以下に収めます(JPG の品質を下げる、または 1920×1080 に縮小)。

## チャンネルバナー・プロフィール・透かし(✅ 「チャンネルのブランディングを管理する」)

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| バナーの最小サイズ | **2048×1152px(16:9)** | ✅ | answer/10456525 |
| バナーの推奨サイズ | **2560×1440px**(特にテレビ向け) | ✅(以前の 🟡 と一致) | answer/10456525 |
| バナーの容量 | **6MB 以下** | ✅(以前の 🟡 と一致) | answer/10456525 |
| バナーの安全領域(文字・ロゴ) | **1235×338px**(中央) | ✅ | answer/10456525 |
| バナーの装飾 | 影・枠線・フレームを付けない | ✅ | answer/10456525 |
| プロフィール写真 | **98×98px で表示**できる画像。JPG・GIF・BMP・PNG(アニメーション GIF 不可)、**15MB 以下**。円形で表示 | ✅ | answer/10456525 |
| プロフィール写真の作成サイズ | 800×800px で作る例が多い | 🟡 | 二次資料 |
| 動画の透かし | **正方形、150×150px 以上、1MB 未満** | ✅ | answer/10456525 |

> **修正**: 以前は安全領域を「中央 1546×423」(🟡)と記載していましたが、公式ヘルプでは **1235×338px** です。旧値は古いガイドの数値とみられます。

**バナーの作り方**: 2560×1440 のキャンバスの中央 1235×338 に、チャンネル名と更新日などの文字を置きます。外側は端末によって切れるので、背景の模様だけにします。

## 字幕ファイル(✅ 「対応している字幕ファイル形式」)

| 区分 | 形式 |
|---|---|
| 基本(初めてなら推奨) | SubRip(**.srt**)、SubViewer(**.sbv** / .sub)、MPsub、LRC、Videotron Lambda(.cap、主に日本語字幕) |
| 高度(配置・スタイル) | SAMI、RealText、**WebVTT(.vtt)**、TTML、DFXP |
| 放送用 | Scenarist(.scc)、EBU-STL ほか |

**SRT の書き方の例**(連番、時刻、テキストの順。ミリ秒の区切りはカンマ)

```
1
00:00:00,599 --> 00:00:04,160
今日は作り置きおかずを3品作ります。
```

手動字幕は内容の正確さを担保できます(⚪ 検索や視聴維持への効果は経験則)。自動字幕は誤りを確認します。追加の手順は [03-text-and-discovery](03-text-and-discovery.md)。

## よくある失敗と対処

| 失敗 | 原因 | 対処 |
|---|---|---|
| 画質が粗い | ビットレートが低い、インターレースのまま | 上表のビットレートで書き出す。インターレースを解除 |
| 映像がカクカクする | 撮影と異なるフレームレートで書き出した | 撮影時と同じ fps にする(✅) |
| バナーの文字が切れる | 安全領域の外に文字がある | 中央 1235×338 に収める(✅) |
| スマホからサムネイルが上がらない | 2MB を超えている | パソコンから上げる(50MB まで)か、圧縮する(✅) |
| 縦長動画のサムネイルが意図と違う | 4:5 の自動生成に置き換わった | 9:16 のサムネイルを用意し、要素を中央に寄せる(✅) |

## チェックリスト

- [ ] MP4 / H.264 / AAC、撮影時と同じ fps で書き出した
- [ ] 1080p なら 8Mbps 前後(60fps なら 12Mbps)
- [ ] サムネイルは比率(16:9 または 9:16)と最小幅 640px を満たす
- [ ] バナーの文字は中央 1235×338 の中
- [ ] 字幕ファイル(SRT など)の時刻と表記を確認した

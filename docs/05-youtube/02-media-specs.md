# YouTube 動画・画像仕様

> YouTube ヘルプ(日本語版)の本文を 2026年(皇紀2686年・令和8年)11月3日に直接取得して確認しました(✅)。確認できなかった項目は 🟡/⚪ のまま。横断比較は [video-specs-comparison](../01-common/video-specs-comparison.md)、[image-specs-comparison](../01-common/image-specs-comparison.md)。

## 動画のエンコード(✅ 「おすすめのエンコード設定」)

| 項目 | 推奨 |
|---|---|
| コンテナ | **MP4**。編集リストなし、**`moov` atom をファイルの先頭に**(ファストスタート) |
| 音声コーデック | AAC-LC、Opus、Eclipsa オーディオ |
| 音声チャンネル | ステレオ、ステレオ+5.1 など。サンプルレート **48kHz** |
| 映像コーデック | **H.264**、プログレッシブ(インターレース不可)、High Profile、2連続Bフレーム、**closed GOP**、CABAC、クロマ 4:2:0 |
| ビットレート | 可変(VBR)。上限なし。下記を参考に |
| フレームレート | **撮影時と同じ**で書き出す。24・25・30・48・50・60 fps が一般的。インターレースはアップロード前に解除 |
| 色空間 | 資料に記載あり(sRGB/Rec.709 を基本) |

**推奨映像ビットレート(SDR、標準フレームレート 24/25/30 → 高フレームレート 48/50/60)**

| 解像度 | 標準 | 高フレームレート |
|---|---|---|
| 360p | 1 Mbps | 1.5 Mbps |
| 480p | 2.5 Mbps | 4 Mbps |
| 720p | 5 Mbps | 7.5 Mbps |
| **1080p** | **8 Mbps** | **12 Mbps** |
| 1440p(2K) | 16 Mbps | 24 Mbps |
| 2160p(4K) | 35〜45 Mbps | 53〜68 Mbps |
| 8K | 80〜160 Mbps | 120〜240 Mbps |

**HDR**: 1080p で 10 Mbps(標準)/ 15 Mbps(高フレームレート)、4K は 44〜56 / 66〜85 Mbps。HDR の 480p 以下は非対応。

**音声ビットレート**: モノラル 128 kbps、**ステレオ 384 kbps**、5.1 512 kbps。

## 動画のサイズ・長さ

| 項目 | 値 | 確度 |
|---|---|---|
| 標準アスペクト比(PC) | 16:9。縦長・正方形はプレーヤーが自動調整 | ✅ |
| **Shorts の長さ** | **最大3分**(ショート動画作成ツールで) | ✅ |
| アップロードの上限サイズ・長さ | 256GB または 12時間のうち小さい方とする資料 | 🟡(今回の取得分では未確認) |
| Shorts の解像度 | 縦向き 9:16(1080×1920 が一般的) | ⚪ |

## サムネイル(✅ 「カスタム サムネイル」)

| 項目 | 値 |
|---|---|
| 推奨解像度 | **動画 3,840×2,160px、ショート動画 2,160×3,840px**(できるだけ大きく。埋め込みプレーヤーのプレビューにも使われる) |
| 最小幅 | 640px(動画・ショートとも) |
| 形式 | JPG、PNG など |
| 容量上限 | **モバイル**: 動画 **2MB**、ポッドキャスト 10MB。**パソコン**: 動画・ショート・ポッドキャストとも **50MB** |
| 比率 | **動画 16:9**、**ショート 9:16**、ポッドキャストの再生リスト 1:1 |
| 注意 | 16:9 のカスタムサムネイルを持つ**縦向き動画**は、ホーム・探索・登録チャンネルで**自動生成の 4:5 サムネイル**に置き換えられる(再生フィード・履歴・モバイル以外では表示) |
| ポリシー | ヌード、ヘイト、暴力、有害な内容は拒否・違反警告。繰り返すと**30日間**カスタムサムネイルを停止 |

> **「2MB 未満」はモバイルからの動画サムネイルの上限**。パソコンからは 50MB まで。以前の「2MB 未満」は不完全だった。

### サムネイル設計(⚪)

1. **右下に再生時間が重なる**ので、そこに文字を置かない。
2. 文字は**6語以内**、太く、背景とコントラスト。スマホの縮小表示で読める。
3. 顔・対象を大きく、焦点は1つ。
4. シリーズは型を統一(色・フォント・配置)。
5. 縦長動画は 4:5 の自動生成に置き換わる場面を考え、**重要要素は中央に**。

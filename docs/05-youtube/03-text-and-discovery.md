# YouTube タイトル・説明文・字幕・発見性

## 文字数の目安(⚪ 要確認 #31)

| 項目 | 目安 |
|---|---|
| タイトル | 上限 100字。**表示は30〜40字程度で切れる**ので前半に主題 |
| 説明文 | 上限 5,000字。**冒頭2〜3行が折りたたみ前に表示される** |
| タグ | 合計 500字程度。重要度は低い(公式も補助的と説明 ⚪) |
| ハッシュタグ | 説明文・タイトルに付ける。上位3つがタイトル上に表示。**60個超だと無視される**とされる ⚪ |
| 再生リスト | シリーズ化に有効 |

## タイトル

1. 主題(検索される語)を前半に。
2. 読者の得を明示(「〜の方法」「〜とは」)。
3. 誇大表現(釣り)は避ける。離脱が増え評価が下がる。
4. シリーズ名・回数は後半。

## 説明文の構成(テンプレ)

```
1〜2行目: 動画の要点と価値(検索語を含める)
3〜5行目: 目次(チャプター)
関連動画/再生リスト
公式リンク(note・X・Instagram)
PR・広告がある場合はここに明記 → legal-compliance
ハッシュタグ(3つ程度)
```

## チャプター

- 説明文に `0:00 導入` のように**時刻つきで**3つ以上、最初は 0:00 から(⚪ 一般的な要件)。
- 検索結果に表示されることがある。視聴者の離脱ポイント把握にも役立つ。

## 字幕・アクセシビリティ

- 手動字幕(SRT)を用意し、誤りの多い自動字幕に頼らない。
- 画像の代替テキストに相当するものとして、**動画の内容を説明に書く**([alt-text](../01-common/alt-text.md))。
- 色だけに頼らない、点滅を避ける。

## 検索・推薦に向けて(⚪)

1. **検索意図**に合わせる([search-optimization](../01-common/search-optimization.md))。
2. 視聴維持を重視(冒頭で結論、無駄な前置きを削る)。
3. 再生リストと終了画面で次の動画へ。
4. サムネイル・タイトルの A/B 比較(YouTube Studio にテスト機能がある場合 ⚪)。

## 禁止される誘導

- 無関係な人気タグの詰め込み。
- 他人のチャンネル名の無断利用。

## AI の使用の開示(✅)

本物のように見える AI 生成・大幅改変のコンテンツは、アップロード時に YouTube Studio の「AI の使用」で開示する。詳細: [ai-rules-by-platform](../01-common/ai-rules-by-platform.md)。字幕・アクセシビリティは [alt-text 詳細ガイド](../01-common/alt-text.md)。

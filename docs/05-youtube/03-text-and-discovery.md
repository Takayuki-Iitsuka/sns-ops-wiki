# YouTube タイトル・説明文・字幕・発見性

> **このページで分かること**: タイトル・説明文・ハッシュタグ・タグ・チャプター・字幕の書き方と上限、サムネイルのテスト、AI 使用の開示。
>
> **対象**: 初心者  **先に読むページ**: [08-upload-and-shorts](08-upload-and-shorts.md)、[検索最適化](../01-common/search-optimization.md)

## 概要

視聴者は「**サムネイルとタイトル**」を見てクリックするかを決め、「**説明文・チャプター・字幕**」で内容を確かめます。YouTube の検索や「おすすめ」も、これらの文字情報を手がかりにします。正確で分かりやすい文字情報は、見つけてもらうための土台です。

## 用語

| 用語 | 意味 |
|---|---|
| ハッシュタグ(#) | `#料理` のように `#` を付けた語。タップすると同じタグの動画一覧へ移動する |
| タグ | 詳細設定に入力する検索補助の語。検索での役割は小さい(✅) |
| チャプター | 動画を区切った「章」。シークバー上に区切りと見出しが表示される |
| タイムスタンプ | `0:00` のような時刻表記。説明文に書くとその位置へ飛べるリンクになる |
| 自動字幕 | 音声認識で自動作成される字幕。誤りが出やすい |
| A/B テスト(テストと比較) | 複数のタイトル・サムネイルを出し分けて成績を比べる機能 |

## 文字数・個数の上限(✅ 2026-11-03 に確認。以前は ⚪ #31)

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| タイトル | **100文字**まで。無効な文字は使えない | ✅ | answer/57404 |
| 説明文 | **5,000文字**まで | ✅ | answer/57404 |
| タグ | 文字数上限はヘルプ本文に記載なし(合計500字程度とする資料)。**検索での役割は小さい** | ✅(役割)/ ⚪(字数) | answer/57404 |
| ハッシュタグの表示 | 説明欄のタグから**最大3つ**がタイトル付近に表示される | ✅ | answer/6390658 |
| ハッシュタグの数 | **60個を超えると、その動画のハッシュタグがすべて無効** | ✅ | answer/6390658 |
| チャプター | **0:00 から開始、3つ以上、昇順、各10秒以上** | ✅ | answer/9884579 |
| タイトルの表示幅 | 端末で切れる。前半30〜40字に主題を置くとよい | ⚪ | 経験則 |
| 説明文の折りたたみ | 冒頭2〜3行が「もっと見る」の前に表示される | ⚪ | 経験則 |

## タイトルの書き方

1. **主題(検索される語)を前半に**置きます。
2. 視聴者の得を示します(「〜の方法」「〜とは」「〜を比較」)。
3. 誇大表現(釣りタイトル)は避けます。内容と違うと離脱が増え、「誤解を招くメタデータ」としてポリシー違反にもなり得ます([07-policies-and-checklist](07-policies-and-checklist.md))。
4. シリーズ名・回数は後半に置きます。

**例(料理アカウント)**

| 良い例 | 悪い例 | 理由 |
|---|---|---|
| 作り置きおかず3品|平日20分・2人分【第12回】 | 【神回】これはヤバい…!! | 何の動画か分からない |
| 鶏むね肉をしっとり焼く方法|失敗の原因3つ | 鶏むね 鶏胸 チキン レシピ 簡単 時短 | 語の羅列は読みにくく、スパムに見える |

## 説明文の構成(テンプレ)

```
1〜2行目: 動画の要点と価値(検索語を含める)
3〜5行目: 目次(チャプター)
関連動画/再生リスト
公式リンク(note・X・Instagram)
PR・広告がある場合はここに明記 → legal-compliance
ハッシュタグ(3つ程度)
```

**記入例**

```
平日20分で作れる作り置きおかずを3品紹介します。分量は2人分です。

0:00 はじめに
0:35 鶏むね肉の甘酢炒め
4:10 にんじんのナムル
6:50 保存方法とまとめ

▼作り置きシリーズの再生リスト
(再生リストの URL)

#作り置き #時短レシピ #お弁当
```

説明文の冒頭はアップロードのデフォルト設定にテンプレートとして登録しておくと、毎回の入力が楽になります(⚪)。

## ハッシュタグ(✅ answer/6390658)

- 説明欄(またはタイトル)に `#語` の形で書きます。**タグの中にスペースは入れられません**。
- 説明欄のハッシュタグのうち**最大3つ**がタイトル付近に表示されます。
- **禁止**: 大量のタグ、動画と関係ない・誤解を招くタグ、嫌がらせ・差別・性的・冒とく的なタグ、同じ文章の繰り返し。
- 60個を超えると、その動画のハッシュタグがすべて無効になります。目安は3〜5個です(⚪)。

共通の考え方は [hashtags](../01-common/hashtags.md)。

## チャプター(✅ answer/9884579)

**要件**: 最初のタイムスタンプは `0:00`。**3つ以上**を昇順に並べ、**各チャプターは10秒以上**。

**手動で付ける手順**

1. YouTube Studio にログインし、左メニューの「コンテンツ」を開きます。
2. 動画を選び、「説明」欄に `0:00 はじめに` のようにタイムスタンプと見出しを1行ずつ書きます。
3. 「保存」を押します。

手動で付けると、その動画の**自動チャプターは無効**になります。自動チャプターは「すべて表示」の「チャプターの自動生成を行う」で設定し、新しい動画では既定でオンです。違反警告のあるチャンネルなどでは使えません(✅)。

## 字幕(✅ answer/2734796)

**YouTube Studio で字幕を追加する手順**

1. YouTube Studio →左メニュー「字幕」→ 動画を選びます。
2. 「言語を追加」で言語を選び、「字幕」欄の「追加」を押します。
3. 方法を選びます。
   - **ファイルをアップロード**: SRT などのファイルを選んで保存([02-media-specs](02-media-specs.md))。
   - **自動同期**: 話している言葉を入力するか文字起こしファイルを上げると、タイミングを自動で合わせます(数分かかる)。
   - **手動で入力**: 動画を再生しながら入力し、「公開」。

自動字幕は動画のデフォルト言語でのみ表示されます(✅)。固有名詞や数字の誤りが多いので、必ず確認・修正します(⚪)。

## アクセシビリティ

- 手動字幕(SRT)を用意し、誤りの多い自動字幕に頼りません。
- 画像の代替テキストに相当するものとして、**動画の内容を説明文に書きます**([alt-text](../01-common/alt-text.md))。
- 色だけに頼らない、激しい点滅を避けます。

## サムネイル・タイトルのテストと比較(✅ answer/13861714)

| 項目 | 内容 |
|---|---|
| 使える場所 | **パソコンの YouTube Studio のみ**。上級者向け機能が必要 |
| 比較できる数 | タイトル・サムネイル各**最大3つ** |
| 判定 | **総再生時間が最も長い**案を全員に表示。結果は「ベスト / ほぼ同じ / 有意な結果なし」 |
| 期間 | 数日〜**2週間以内** |
| 使えない動画 | Shorts、スケジュール済みライブ、公開前のプレミア、子ども向け・成人向け・非公開の動画 |

**手順**: 動画の編集画面で、タイトルまたはサムネイル欄の「A/B テスト」→ 形式(タイトルのみ / サムネイルのみ / 両方)→ 案を最大3つ追加 →「完了」。テスト中にタイトルなどを変えると自動で停止します。

## 検索・推薦に向けて(⚪)

1. **検索意図**に合わせます([search-optimization](../01-common/search-optimization.md))。
2. 視聴維持を重視します(冒頭で結論、無駄な前置きを削る)。
3. 再生リストと終了画面で次の動画へ案内します([08-upload-and-shorts](08-upload-and-shorts.md))。

## 禁止される誘導

- 無関係な人気タグ・ハッシュタグの詰め込み(✅ answer/6390658)。
- 他人のチャンネル名の無断利用、内容と一致しないタイトル・サムネイル。

## AI の使用の開示(✅ answer/14328491)

本物のように見える AI 生成・大幅改変のコンテンツは、アップロード時に YouTube Studio の「AI の使用」で開示します。

| 開示が必要な例 | 開示が不要な例 |
|---|---|
| 実在の人物が言っていないことを言ったように見せる | 明らかに非現実的な内容(ユニコーンに乗る人など)、AI アニメーション |
| 実在の場所に AI 生成の映像を加える | 美肌フィルタ、色調整、背景ぼかし |
| 実際の出来事のようにリアルな災害映像を作る | 台本・サムネイル・タイトルの作成支援、アイデア出し |
| AI で生成した音楽 | 字幕作成、アップスケール、自分の声のクローンによるナレーション |

**手順**: アップロード画面の「属性」→「AI の使用」で「はい / いいえ」を選びます。開示しても**視聴制限や収益化の資格には影響しません**。繰り返し意図的に開示しないと、ラベルの手動付与、削除、YPP の停止などの対象になり得ます(✅)。

詳細: [ai-rules-by-platform](../01-common/ai-rules-by-platform.md)。字幕・アクセシビリティは [alt-text 詳細ガイド](../01-common/alt-text.md)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| チャプターが表示されない | `0:00` 始まり・3つ以上・各10秒以上か確認(✅) |
| ハッシュタグが効かない | 60個超、スペース入り、無関係なタグを見直す(✅) |
| タイトルが途中で切れて意味が通らない | 主題を前半に移す(⚪) |
| 自動字幕の誤字が多い | 自動同期かファイルで字幕を作り直す |

## チェックリスト

- [ ] タイトルの前半に主題、100文字以内
- [ ] 説明文の1〜2行目に要点、チャプター(0:00 から3つ以上)
- [ ] ハッシュタグは3〜5個、動画と関係がある
- [ ] 字幕を確認・修正した
- [ ] 必要なら「AI の使用」を「はい」にした

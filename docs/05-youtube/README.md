# YouTube

> **このページで分かること**: YouTube の特徴、向いている用途、このフォルダのページの読む順番。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[サービスの選び方](../01-common/choosing-platforms.md)

## 概要

動画の検索・推薦・長期の資産化に強く、**収益化の仕組みが最も整ったサービス**の一つです(広告、メンバーシップ、Super Chat、Super Thanks、ショッピングなど)。一度公開した動画が、何か月・何年も検索から見られ続けることがあるのが特徴です(⚪)。

## 特徴

| 項目 | 内容 |
|---|---|
| 形式 | 長尺動画(既定15分、確認後は最大12時間 ✅)、Shorts(縦型短尺、最大3分 ✅)、ライブ配信、プレミア公開、投稿(旧コミュニティ投稿)、ポッドキャスト |
| 強み | 検索流入(資産性)、収益化の選択肢、視聴時間の長さ |
| 弱み | 制作コストが高い、収益化の条件(登録者・視聴時間)、規約の審査(再利用コンテンツ、著作権) |
| 向く用途 | 解説、講座、レビュー、ライブ配信、ブランディング |
| 収益化の入口 | 登録者 500人から YPP の第1段階(✅ [05](05-monetization.md)) |

## 用語

| 用語 | 意味 |
|---|---|
| YouTube Studio | 動画の管理・分析・収益化を行う管理画面 |
| Shorts(ショート) | 縦型・3分以内の短い動画 |
| YPP | YouTube パートナー プログラム(収益化の参加資格) |
| CTR | インプレッションのクリック率 |

1. [01-setup-and-posting](01-setup-and-posting.md) でチャンネルを作り、電話認証まで済ませる。

3. [08-upload-and-shorts](08-upload-and-shorts.md) で最初の1本を非公開アップロードする。
4. [03-text-and-discovery](03-text-and-discovery.md) でタイトル・説明・チャプター・字幕を整えて公開する。
5. [04-engagement](04-engagement.md) でコメント設定を整える。
6. 1週間後に [06-analytics-and-tips](06-analytics-and-tips.md) で振り返る。
7. 規約は [07-policies-and-checklist](07-policies-and-checklist.md)、収益化は [05-monetization](05-monetization.md)。

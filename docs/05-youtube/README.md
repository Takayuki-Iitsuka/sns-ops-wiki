# YouTube

動画の検索・推薦・長期の資産化に強く、**収益化の仕組みが最も整ったサービス**の一つです(広告、メンバーシップ、Super Chat、Super Thanks、ショッピングなど)。

## 特徴

| 項目 | 内容 |
|---|---|
| 形式 | 長尺動画、Shorts(縦型短尺)、ライブ配信、プレミア公開、コミュニティ投稿、ポッドキャスト |
| 強み | 検索流入(資産性)、収益化の選択肢、視聴時間の長さ |
| 弱み | 制作コストが高い、収益化の条件(登録者・視聴時間)、規約の審査(再利用コンテンツ、著作権) |
| 向く用途 | 解説、講座、レビュー、ライブ配信、ブランディング |

## 他サービスとの関係

- X・Instagram で**予告・切り抜き**、YouTube で本編、note で**深掘りや資料**という導線([funnel](../30-strategy/02-funnel.md))。
- Shorts は新規流入、長尺は信頼と収益の核になる(⚪)。

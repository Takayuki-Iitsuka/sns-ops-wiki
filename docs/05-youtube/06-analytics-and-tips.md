# YouTube の分析とコツ

> **このページで分かること**: YouTube アナリティクスの開き方、タブごとの見どころ、主要な指標の意味、数字が悪いときの直し方、週次の振り返り方。
>
> **対象**: 初心者  **先に読むページ**: [analytics-kpi](../01-common/analytics-kpi.md)

共通: [analytics-kpi](../01-common/analytics-kpi.md)

## 概要

**YouTube アナリティクス**は、YouTube Studio にある分析画面です。「どれだけ表示されたか → どれだけクリックされたか → どれだけ見続けられたか → 誰が見ているか」を順に確認できます。初心者は、まず **インプレッションのクリック率** と **視聴者維持率** の2つを見るだけで、改善点の大半が分かります(⚪ 経験則)。

## 用語

| 用語 | 意味 |
|---|---|
| インプレッション | サムネイルが視聴者に表示された回数 |
| インプレッションのクリック率(CTR) | インプレッションの後に動画が視聴された割合(✅) |
| 総再生時間 | 視聴された時間の合計(時間単位)(✅) |
| 平均視聴時間 | 1回の視聴あたりの平均の視聴時間(分)(✅) |
| 視聴者維持率 | 動画の各部分がどの程度見られたかを示すグラフ。平坦なら最後まで見られている(✅) |
| リピーター / 新しい視聴者 | 以前もチャンネルを見た人 / 期間内に初めて見た人(✅) |
| トラフィック ソース | どこから来たか(検索、おすすめ、外部など) |
| RPM / CPM | クリエイターの1,000回視聴あたり収益 / 広告主が払う1,000回表示あたりの単価(⚪ 一般的な定義) |

## アナリティクスの開き方(✅ answer/9002587)

- **チャンネル全体**: YouTube Studio →左メニュー「アナリティクス」。
- **動画ごと**: 「コンテンツ」→ 動画にマウスを合わせ、アナリティクスのアイコンを押す。
- スマホの YouTube Studio アプリでも見られますが、一部のレポートは使えない場合があります。

## タブごとの見どころ(✅ answer/9002587)

| タブ | 対象 | 見るもの |
|---|---|---|
| 概要 | チャンネル / 動画 | 全体像、リアルタイムの数値。動画では維持率の重要な区間 |
| コンテンツ | チャンネル | 視聴者がどう見つけたか、インプレッションと総再生時間の関係、人気コンテンツ |
| リーチ | 動画 | インプレッション数、クリック率、視聴回数、ユニーク視聴者数 |
| エンゲージメント | 動画 | 総再生時間、平均視聴時間、エンゲージ ビュー |
| 視聴者 | チャンネル / 動画 | 月間視聴者数、登録者数、新規・ライト・コアな視聴者の割合 |
| 収益 | チャンネル / 動画 | YPP 参加者向け。推定収益と確定収益 |
| トレンド | チャンネル | 視聴者と YouTube 全体の検索傾向。次の企画のヒント |

地域・トラフィック ソース・性別などの一部データは制限される場合があります。2026年(皇紀2686年・令和8年)7月から新しい YouTube Studio が段階的に導入され、画面が変わることがあります(✅)。

## YouTube Studio の主な指標

| 指標 | 意味 | 使い方 | 確度 |
|---|---|---|---|
| インプレッション | サムネイルが表示された回数 | 露出量 | ⚪ |
| インプレッションのクリック率(CTR) | 表示に対するクリックの割合。**全チャンネル・全動画の半数が 2〜10%** | サムネイル・タイトルの評価 | ✅ answer/7628154 |
| 総再生時間 | 視聴時間の合計 | 収益条件、評価 | ✅ |
| 平均視聴時間・視聴率 | どれだけ見られたか | 構成の評価 | ✅ |
| 視聴者維持率 | 時間ごとの離脱 | 冒頭・中盤の改善 | ✅ |
| トラフィックソース | 検索/関連/ブラウジング/外部 | 流入の傾向 | ⚪ |
| リーチ(Shorts) | Shorts の表示/視聴 | 発見 | ⚪ |
| 視聴者層 | 年齢・地域・時間帯 | 投稿時間・内容 | ⚪ |
| 収益(RPM/CPM) | 1000回あたり収益 | 収益性 | ⚪ |

**CTR の注意(✅ answer/7628154)**

- サムネイルが表示されても、インプレッションに数えられない場合があります。
- 外部サイトや終了画面からの表示は、CTR に全件は集計されません。
- **公開から1週間未満の動画や、視聴回数100回未満の動画**は値の振れ幅が大きいので、早すぎる判断は避けます。

## 見方のコツ(症状 → 対処)

1. **CTR が低い**: サムネイル・タイトルを見直す。[テストと比較](03-text-and-discovery.md)を使う。
2. **維持率が冒頭で急落**: 前置きを削り、結論を先に。
3. **終盤で落ちる**: まとめを短くする、次の動画を案内する。
4. **Shorts → 長尺**への移動を概要欄・固定コメントで促す。
5. 週次で上位/下位動画の違いを言語化([weekly-review](../../templates/weekly-review.md))。

**維持率グラフの読み方(⚪)**

| グラフの形 | 意味 | 対処 |
|---|---|---|
| 最初の30秒で大きく下がる | 期待と内容がずれている、前置きが長い | タイトル・サムネイルと冒頭を一致させる |
| 途中で山がある | その部分が繰り返し見られている | 人気の内容。次の動画のテーマ候補 |
| 途中で段差状に下がる | 話題の切り替えで離脱 | チャプター・予告で先の内容を示す |
| ほぼ平坦 | 最後まで見られている | 構成の型として保存 |

## 週次の振り返り手順(⚪ 運用例)

1. 「コンテンツ」タブで直近7日の上位3本・下位3本を選ぶ。
2. 各動画の CTR・平均視聴時間・主なトラフィック ソースを表に写す。
3. 上位と下位の違いを1行で書く(例「数字入りのタイトルが CTR 高い」)。
4. 次の1本で**1つだけ**変える点を決める。
5. 「トレンド」タブで、視聴者が検索している語を3つメモする。

記録には [weekly-review](../../templates/weekly-review.md) を使います。

## コツ(⚪ 経験則)

1. 1本ごとに**対象視聴者と目的**を決める。
2. 冒頭5〜15秒で価値を提示。
3. 定期的な公開で習慣化。
4. シリーズ化で再生リストを育てる。
5. 動画の末尾で**次に見る動画**を示す(終了画面)。
6. 音声品質を優先(映像より離脱要因になりやすい)。
7. 長尺と Shorts の役割を分ける。

## 実験の仕方

- サムネイル/タイトルを**1つずつ変えて**比較(同時に複数変えない)。
- 結果を記録し、型に反映。
- 公開から1週間以上たち、視聴回数が100回を超えてから判断する(✅ CTR の振れ幅の説明より)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 公開翌日の数字で一喜一憂する | 1週間・100回以上を目安に判断 |
| 指標を全部見て疲れる | CTR と維持率の2つから始める |
| 他人の CTR と比べる | ジャンル・流入元で大きく違う。自分の過去と比べる |
| 一度に複数を変えて原因が分からない | 1回の変更は1点だけ |

## チェックリスト(週次)

- [ ] 上位3本・下位3本の CTR と平均視聴時間を記録
- [ ] 維持率グラフで大きく下がる箇所を確認
- [ ] トラフィック ソースの変化を確認
- [ ] 次回変える点を1つ決めた

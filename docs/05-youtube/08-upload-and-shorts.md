# YouTube 動画・Shorts のアップロードとライブ配信

> **このページで分かること**: パソコンとスマホでの動画アップロード手順、各入力項目の意味、公開設定、Shorts の作り方、終了画面・カード、ライブ配信の要件。
>
> **対象**: 初心者  **先に読むページ**: [01-setup-and-posting](01-setup-and-posting.md)

## 概要

YouTube の投稿は「**アップロード**(ファイルを送る)」と「**公開**(視聴者が見られる状態にする)」の2段階です(✅ answer/57407)。アップロード中やアップロード後に、タイトル・説明・サムネイルなどの情報を入力し、最後に公開範囲を選びます。公開前には、著作権と広告適合性のチェックがバックグラウンドで自動的に行われます(✅)。

## 用語

| 用語 | 意味 |
|---|---|
| 公開 / 限定公開 / 非公開 | 誰でも見られる / URL を知っている人だけ / 自分と招待した人だけ(⚪ 一般的な説明) |
| スケジュール | 指定した日時に自動で公開する設定 |
| 終了画面(End screen) | 動画の最後に表示する、次の動画・登録ボタンなどの要素 |
| カード(情報カード) | 動画の途中で右上に出る、関連動画などへのリンク |
| エンコーダ | 配信ソフト(例: OBS)など、映像を変換してライブ配信に送る仕組み |
| 再生リスト | 動画をまとめた一覧。シリーズ化に使う |

## アップロードできる長さ・容量(✅)

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| 既定の長さの上限 | **15分** | ✅ | answer/71673 |
| 確認後の上限 | **256GB または 12時間の小さい方** | ✅ | answer/71673 |
| Shorts の長さ | **最大3分**(縦向き・正方形) | ✅ | answer/10059070 |
| 1日のアップロード本数 | 上限あり。数は国・地域やチャンネル履歴で異なり非公表。上限に達したら24時間後に再試行 | ✅ | answer/57407 |
| タイトル / 説明 | **100文字 / 5,000文字** | ✅ | answer/57404 |

## 手順 1: パソコンでアップロードする(⚪ ボタン名は変わる可能性)

1. YouTube Studio(studio.youtube.com)にログインします。
2. 右上の「作成」→「動画をアップロード」を押します。
3. 動画ファイルを選ぶか、画面にドラッグします。アップロードが始まります。
4. **詳細**: タイトル、説明、サムネイル、再生リストを入力します([03-text-and-discovery](03-text-and-discovery.md))。
5. **視聴者**: 「子ども向けである / 子ども向けではない」を必ず選びます。必要なら年齢制限を設定します。
6. **すべて表示**: 有料プロモーションの有無、改変・合成コンテンツ(AI の使用)の開示、自動チャプター、タグ、言語、字幕、撮影日と場所、ライセンス、カテゴリ、コメントの設定などを確認します(項目は ✅ answer/57404)。
7. **動画の要素**: 字幕、終了画面、カードを追加します(下の節を参照)。
8. **チェック**: 著作権や広告適合性の問題がないか結果を確認します。
9. **公開設定**: 非公開 / 限定公開 / 公開 / スケジュールを選び、「保存」または「公開」を押します。

> YPP 参加者は、チェックが終わるまで限定公開か非公開のままにしておけます(✅ answer/57407)。初心者も、いったん**非公開でアップロード → 自分で確認 → 公開**の流れにすると、ミスを公開前に見つけやすくなります(⚪)。

## 手順 2: スマホでアップロードする(✅ answer/57407)

**YouTube アプリ**

1. YouTube アプリを開き、作成アイコン(＋)をタップします。
2. 「動画」を選び、ファイルを選んで「次へ」をタップします。
3. タイトル・公開設定などを入力し、視聴者層を選んでアップロードします。

**YouTube Studio アプリ**

1. 上部の作成アイコンをタップし、ファイルを選びます。
2. タイトル、プライバシー設定、収益受け取りの設定などを入力し、「次へ」をタップします。
3. 視聴者(子ども向けかどうか)を選び、「動画をアップロード」をタップします。

## 手順 3: Shorts を作る

1. 縦向き 9:16(または正方形)、**3分以内**の動画を用意します(✅ answer/10059070)。
2. YouTube アプリの作成アイコン →「ショート」から撮影するか、端末内の動画を選びます(⚪ 表記は変わる可能性)。
3. 音楽・テキスト・フィルタを加え、タイトルを付けて公開します。
4. パソコンからは、通常のアップロードと同じ手順で縦長の短い動画を上げます。

**Shorts の構成のコツ(⚪ 経験則)**

- 最初の1〜2秒で「何の動画か」を見せます。前置きは入れません。
- 1本1メッセージ。最後まで見られやすい長さに絞ります。
- 長尺動画の見どころを切り抜き、説明や固定コメントで本編へ案内します。
- 字幕(テキスト)は画面の下端・右端のボタンに重ならない位置に置きます。

## 手順 4: 終了画面とカードを付ける(✅)

| 項目 | 終了画面 | 情報カード |
|---|---|---|
| 置き場所 | 動画の**最後の5〜20秒** | 動画の途中(タイムラインで指定) |
| 条件 | 動画が **25秒以上** | — |
| 最大数 | 16:9 の動画で**4つ** | **5枚** |
| 種類 | 動画、再生リスト、チャンネル登録、チャンネル、リンク | 動画、再生リスト、チャンネル、リンク(リンクは YPP 参加者) |
| 子ども向け動画 | **使えない** | **使えない** |
| 出典 | answer/6388789 | answer/6140493 |

**追加の手順**: YouTube Studio →「コンテンツ」→ 動画を選ぶ →「エディタ」→「終了画面」または「情報カード」→ 要素を追加 →「保存」。

> 終了画面を入れる予定なら、編集の段階で**最後の5〜20秒は文字や顔を置かない余白**にしておくと、要素で隠れません(⚪)。

## 手順 5: ライブ配信を始める

**要件(✅ answer/2474026)**

- **16歳以上**であること。
- **チャンネルの確認(電話認証)**が済んでいること。
- 過去90日間にライブ配信の制限を受けていないこと。
- 初回の有効化に時間がかかる場合があります(最大24時間とする資料あり ⚪ 要確認)。配信日の前日までに準備します。

**配信方法(✅)**

| 方法 | 向く用途 |
|---|---|
| モバイル | Vlog、簡単な告知(作成には別途要件あり) |
| ウェブカメラ | パソコンから手軽に配信 |
| エンコーダ | ゲーム実況、画面合成(オーバーレイ)、複数の機材 |
| ゲーム機 | 対応機種から本体で直接配信 |

ライブ配信の企画・運営は [live-streaming](../01-common/live-streaming.md) も参照してください。

## 具体例: 公開前の進め方(地域の店の場合)

1. 金曜: 新メニュー紹介の動画を**非公開**でアップロード。
2. 金曜: タイトル・説明・サムネイル・字幕・終了画面を設定し、スマホで見え方を確認。
3. 土曜 11:00 に**スケジュール**公開を設定。
4. 公開後: 同じ映像から30秒の Shorts を作り、本編へ誘導。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| アップロードが途中で止まる | 回線を安定させ、ファイルを MP4(H.264)で書き出し直す([02-media-specs](02-media-specs.md)) |
| 公開直後に画質が低い | 高解像度の処理が終わるまで時間がかかる場合がある(⚪)。スケジュール公開で余裕を持たせる |
| 「アップロード上限に達しました」 | 24時間後に再試行(✅ answer/57407) |
| 終了画面が設定できない | 動画が25秒未満、または子ども向け設定(✅) |
| ライブ配信ボタンが出ない | 年齢・電話認証・過去90日の制限を確認(✅) |

## 注意点

- 「子ども向け」の選択は必須で、選択によって使える機能が変わります([07-policies-and-checklist](07-policies-and-checklist.md))。
- 現実的に見える AI 生成・改変の映像は「AI の使用」で開示します([03-text-and-discovery](03-text-and-discovery.md))。
- 企業から対価を受けた紹介は「有料プロモーション」にチェックします([legal-compliance](../01-common/legal-compliance.md))。

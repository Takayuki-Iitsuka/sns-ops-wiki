# YouTube のルールとチェックリスト

> **このページで分かること**: コミュニティガイドラインの違反警告(ストライク)の仕組み、子ども向け設定、著作権・AI 開示などの注意領域、違反時の対応、動画ごとのチェックリスト。
>
> **対象**: 初心者  **先に読むページ**: [legal-compliance](../01-common/legal-compliance.md)

一次資料: コミュニティガイドライン、収益化ポリシー、著作権ポリシー(YouTube ヘルプ)。違反警告・子ども向け・AI 開示の本文は 2026年(皇紀2686年・令和8年)11月3日に取得して確認しました(✅)。収益化ポリシー・著作権ポリシーの全文は未取得(#29)。

## 概要

YouTube には、全員が守る**コミュニティガイドライン**、収益化する人が守る**チャンネル収益化ポリシー**、他人の権利を守る**著作権ポリシー**があります。違反すると、動画の削除、機能の一時停止、チャンネル削除につながります。仕組みを知っておけば、「知らずに違反した」を防げ、万一のときも落ち着いて対応できます。

## 用語

| 用語 | 意味 |
|---|---|
| コミュニティガイドライン | YouTube で禁止されている内容(暴力、ヘイト、スパムなど)の決まり |
| 事前警告 | 初回の違反で通常出される注意。罰則はない(✅) |
| 違反警告(ストライク) | 2回目以降の違反で出る警告。投稿などが一時的にできなくなる(✅) |
| ポリシー トレーニング | 違反したポリシーについての短い研修。受講で事前警告が失効する(✅) |
| 著作権侵害の警告 | 権利者の削除申請によるもの。コミュニティガイドラインとは別の仕組み(⚪) |
| COPPA | 米国の児童オンライン プライバシー保護法。子ども向け申告の根拠(✅) |

## 違反警告の仕組み(✅ answer/2802032)

| 段階 | 内容 |
|---|---|
| 事前警告 | 初回の違反。意図的でない誤りとみなされ、通常は事前警告のみ。任意のポリシー トレーニングを受けると**受講から90日後に失効**。90日以内に同じポリシーに違反すると違反警告になり得る |
| 1回目の違反警告 | **1週間**、動画のアップロード、ライブ配信の開始、カスタムサムネイルや投稿の作成などができない。警告自体は90日間残る |
| 2回目の違反警告 | 1回目から90日以内なら**2週間**投稿できない |
| 3回目の違反警告 | 90日以内に3回で、**チャンネルが削除**される可能性 |
| チャンネル停止 | 度重なる違反、または**悪質な不正行為が1回でも**あれば、事前警告なしで停止の可能性 |

- 各違反警告は**発出から90日間**有効です。
- **動画を削除しても違反警告は消えません**(✅)。

## 子ども向けの設定(✅ answer/9528076、answer/9527654)

- FTC(米国連邦取引委員会)との合意と COPPA などの法令に基づき、**所在地を問わず**全クリエイターが申告します。
- 誤ると YouTube 上の措置に加え、法的措置の対象になる可能性があります。
- 判断はクリエイター自身が行います。テーマ、子役の起用、子どもが好むキャラクター・おもちゃ、易しい言葉遣い、簡単な歌・遊びなどが判断要素です。一部を含むだけで自動的に子ども向けになるわけではありません。迷う場合は弁護士への相談が案内されています。

**子ども向けに設定すると使えない主な機能**: コメント、カード・終了画面、透かし、チャンネル メンバーシップ、Super Chat・Super Stickers、グッズ紹介とチケット販売、通知ベル、パーソナライズド広告、ミニプレーヤー、再生リストと「後で見る」への保存、ホームでの自動再生 など。

## 注意領域

| 領域 | 要点 | 運用での注意 | 確度 |
|---|---|---|---|
| コミュニティガイドライン | 違反で事前警告・違反警告。90日以内に3回でチャンネル削除の可能性 | 暴力・ヘイト・誤情報 | ✅ |
| 著作権 | 権利者の申し立て(Content ID/削除申請) | BGM・映像・画像の権利([music-and-licensing](../01-common/music-and-licensing.md)) | ⚪ |
| 再利用コンテンツ/低品質な量産 | 収益化から外れる場合あり | 独自の解説・編集を加える | ⚪ |
| 子ども向け | 設定の誤りは法令・機能に影響 | 視聴者層の設定 | ✅ |
| 合成・改変コンテンツ | 現実的な AI 生成/改変は「AI の使用」で開示。繰り返し怠ると削除・YPP 停止の可能性 | [ai-usage-policy](../01-common/ai-usage-policy.md)、[03](03-text-and-discovery.md) | ✅(以前は ⚪) |
| 広告適性 | 不適切な話題は収益が制限 | 表現・サムネイル | ⚪ |
| スパム・欺瞞 | 誤解を招くタイトル/サムネイル、無関係なハッシュタグの大量付与 | 内容と一致させる | ✅(ハッシュタグ)/ ⚪ |
| 案件・PR | 有料プロモーションの開示 | [legal-compliance](../01-common/legal-compliance.md) | ⚪ |
| サムネイル | ヌード・ヘイト・暴力などは拒否・違反警告。繰り返すと30日間カスタムサムネイル停止 | [02-media-specs](02-media-specs.md) | ✅ |

## 違反時の対応手順

1. **通知の内容を記録**します(日時、対象動画、ポリシー名、スクリーンショット)。
2. 該当ポリシーのヘルプを読み、何が問題だったかを確認します。
3. 事前警告なら、**ポリシー トレーニング**を受講します(✅ 受講から90日で失効)。
4. 誤判定と考える場合は**異議申し立て(再審査請求)**をします。正当なら該当部分を修正します。
5. 再発防止として、チェックリストに項目を追加します。
6. 他拠点(note・メール・X)に読者の逃げ道を用意しておきます([data-backup](../01-common/data-backup-and-portability.md))。

> 同じ問題の動画を慌てて大量に削除しても、**違反警告は消えません**(✅)。まず内容を確認します。

## 動画ごとのチェックリスト

**公開前**
- [ ] 目的と対象視聴者が明確
- [ ] 冒頭5〜15秒で価値を提示
- [ ] BGM・映像・画像の権利を確認([image-sources](../01-common/image-sources-and-copyright.md))
- [ ] 字幕を作成/確認
- [ ] サムネイルは 16:9(Shorts は 9:16)・幅 640px 以上(推奨 3840×2160)、文字は右下を避けた
- [ ] タイトルは前半に主題、説明文の冒頭に要点
- [ ] チャプター(0:00 から3つ以上、各10秒以上)、再生リスト、終了画面
- [ ] 子ども向け設定、年齢制限
- [ ] 広告・PR・合成コンテンツ(AI の使用)の開示
- [ ] ハッシュタグは動画と関係があり、少数
- [ ] 事実・数値の出典確認([sensitive-topics](../01-common/sensitive-topics-and-accuracy.md))
- [ ] 映り込み(他人の顔、住所が分かるもの)を確認([privacy](../01-common/privacy-and-personal-info.md))

**公開後**
- [ ] 1時間以内のコメント返信
- [ ] 保留中のコメントを確認
- [ ] X・Instagram・note で告知
- [ ] 1週間後に CTR・維持率・流入元を記録

**月次**
- [ ] 収益化条件の達成状況([05-monetization](05-monetization.md))
- [ ] 違反警告・著作権の申し立てがないか確認
- [ ] 規約・仕様の変更を [verification-queue](../00-meta/verification-queue.md) に追記

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| フリー素材と思った BGM で申し立てを受けた | 利用規約を保存し、異議申し立て。今後は出典を記録 |
| 子ども向けかどうか迷って「はい」にした | 判断要素を確認し直す。迷う場合は専門家へ(✅ 公式の案内) |
| AI 生成の現実的な映像を開示しなかった | 「AI の使用」を「はい」に変更(開示しても収益化に影響なし ✅) |
| 違反警告の動画を消せば済むと思った | 警告は残る。トレーニング・異議申し立てを検討 |

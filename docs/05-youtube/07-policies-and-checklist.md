# YouTube のルールとチェックリスト

一次資料: コミュニティガイドライン、収益化ポリシー、著作権ポリシー(YouTube ヘルプ。本文は未取得 #29)。

## 注意領域(⚪ 一般論)

| 領域 | 要点 | 運用での注意 |
|---|---|---|
| コミュニティガイドライン | 違反でストライク。累積でチャンネル停止の可能性 | 暴力・ヘイト・誤情報 |
| 著作権 | 権利者の申し立て(Content ID/削除申請) | BGM・映像・画像の権利 |
| 再利用コンテンツ/低品質な量産 | 収益化から外れる場合あり | 独自の解説・編集を加える |
| 子ども向け | 設定の誤りは法令・機能に影響 | 視聴者層の設定 |
| 合成・改変コンテンツ | 現実的な AI 生成/改変は開示が求められる ⚪ 要確認 | [ai-usage-policy](../01-common/ai-usage-policy.md) |
| 広告適性 | 不適切な話題は収益が制限 | 表現・サムネイル |
| スパム・欺瞞 | 誤解を招くタイトル/サムネイル | 内容と一致させる |
| 案件・PR | 有料プロモーションの開示 | [legal-compliance](../01-common/legal-compliance.md) |

## 違反時

1. 通知の内容を記録。
2. 異議申立てまたは該当部分の修正。
3. 再発防止。他拠点(note・メール・X)に読者の逃げ道を用意。

## 動画ごとのチェックリスト

**公開前**
- [ ] 目的と対象視聴者が明確
- [ ] 冒頭5〜15秒で価値を提示
- [ ] BGM・映像・画像の権利を確認([image-sources](../01-common/image-sources-and-copyright.md))
- [ ] 字幕を作成/確認
- [ ] サムネイル 1280×720、文字は右下を避けた
- [ ] タイトルは前半に主題、説明文の冒頭に要点
- [ ] チャプター、再生リスト、終了画面
- [ ] 子ども向け設定、年齢制限
- [ ] 広告・PR・合成コンテンツの開示
- [ ] 事実・数値の出典確認([sensitive-topics](../01-common/sensitive-topics-and-accuracy.md))

**公開後**
- [ ] 1時間以内のコメント返信
- [ ] X・Instagram・note で告知
- [ ] 1週間後に CTR・維持率・流入元を記録

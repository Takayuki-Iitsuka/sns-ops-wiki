# YouTube の収益化

> **このページで分かること**: YouTube パートナー プログラム(YPP)の2段階の条件、申し込み手順、使える収益機能、Shorts の収益分配、AdSense の支払い。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [01-setup-and-posting](01-setup-and-posting.md)、[収益化の比較](../01-common/monetization-comparison.md)

> YouTube ヘルプ「拡充版 YouTube パートナー プログラムの概要」(日本語版)を 2026年(皇紀2686年・令和8年)11月3日に直接取得して確認しました(✅)。**最終判断は YouTube Studio の「収益化」ページ**で行ってください。

## 概要

YouTube で収益を得る中心の仕組みが **YPP(YouTube Partner Program、YouTube パートナー プログラム)** です。登録者や視聴時間の条件を満たして申し込み、審査に通ると、視聴者からの支援(メンバーシップ・Super Chat など)や広告収益を受け取れます。条件は2段階あり、**登録者500人**から一部の機能が使えます。

収益は **AdSense(アドセンス。Google の支払いアカウント)** を通じて支払われます。

## 用語

| 用語 | 意味 |
|---|---|
| YPP | YouTube パートナー プログラム。収益化の参加資格 |
| 拡充版 YPP | 500人から申し込める第1段階。視聴者ファンディングとショッピング |
| 総再生時間 | 動画が見られた時間の合計(時間単位) |
| エンゲージ ビュー | YPP の資格と Shorts の収益分配で使う Shorts の視聴回数 |
| AdSense | 収益の受け取り・税務情報・支払い方法を管理する Google のアカウント |
| RPM | 1,000回視聴あたりのクリエイターの収益(⚪ 一般的な定義。[06](06-analytics-and-tips.md)) |
| Content ID | 権利者の素材を自動検出する仕組み。収益が権利者に移ることがある |

## YouTube パートナープログラム(YPP)の二段階(✅)

### 第1段階: 拡充版 YPP(視聴者ファンディングとショッピングへの早期アクセス)

**対象国を拠点とし、次のいずれかを満たす場合に申し込める**。

| 条件 A | 条件 B |
|---|---|
| チャンネル登録者 **500人以上** | チャンネル登録者 **500人以上** |
| 直近90日に**有効な公開動画を3本以上**アップロード | 直近90日に**有効な公開動画を3本以上**アップロード |
| 直近12か月の**対象動画の総再生時間 3,000時間以上** | 直近90日の**対象ショート動画の視聴回数 300万回以上** |

### 第2段階: 広告収益など追加の特典

**YPP に参加済みで、次のいずれかを満たす場合**に、広告と YouTube Premium からの収益分配などが利用できる。

| 条件 A | 条件 B |
|---|---|
| 登録者 **1,000人以上** | 登録者 **1,000人以上** |
| 直近12か月の対象動画の総再生時間 **4,000時間以上** | 直近90日の対象公開ショート動画の視聴回数 **1,000万回以上** |

### 共通の要件(✅)

- YouTube の**チャンネル収益化ポリシー**に準拠
- 拠点が**利用可能な国・地域**(**日本は含まれる**)
- Google アカウントで **2段階認証**がオン
- チャンネルにリンクされた有効な **YouTube 向け AdSense アカウント** 1つ
- 条件を満たしていないときは、YouTube Studio の「収益化」ページで「通知を受け取る」を選ぶと、満たした時点でメールが届く

### 審査(✅)

- 最初の申し込みが承認されなくても、オリジナルコンテンツを継続し、**30日後**以降に再申請。2回目以降の不承認は**90日後**以降に再申請。
- 収益化を継続するには、**YPP の活動要件**(定期的な活動)を満たす必要がある。満たさないと収益化が無効になる場合がある。

## 500人で解放される機能(✅)

| 機能 | 内容 |
|---|---|
| チャンネルメンバーシップ | 月額課金。バッジ・絵文字・限定特典 |
| Super Chat と Super Stickers | ライブチャットで目立つメッセージ・アニメ画像 |
| Super Thanks | 動画への投げ銭 |
| ジュエルとギフト | 縦型・横型ライブ配信中のギフト |
| ショッピング | 公式グッズストアのリンク、他ブランド商品の紹介 |

- これらを使うには、**課金型製品モジュールの確認と同意**が必要(✅)。
- Super Thanks は子ども向け設定の動画は対象外(🟡 別ページの検索要約)。子ども向けの動画では**メンバーシップ・Super Chat・Super Stickers・グッズ紹介も制限**されます(✅ [answer/9527654](https://support.google.com/youtube/answer/9527654?hl=ja))。

## 申請から開始まで(手順)

1. YouTube Studio →左メニュー「収益化」を開き、条件の達成状況を確認します(⚪ 表記は変わる可能性)。
2. 条件を満たしたら「申し込む」→ **YPP の規約(基本規約)に同意**します。
3. **AdSense アカウントを作成またはリンク**します。既に持っている場合は、新しく作らずに既存のものをリンクします(⚪ 1人1アカウントが原則とされる)。
4. **審査**を待ちます。結果はメールと Studio で通知されます(期間は数週間かかる場合 ⚪)。
5. 承認後、使いたい機能の**モジュール**(広告、課金型製品など)に同意します。
6. 動画ごとに広告の設定(動画の前・途中・後の広告など)を確認します(⚪)。

## Shorts の視聴回数の数え方(✅)

- **2025年(皇紀2685年・令和7年)3月31日から**、Shorts の再生が開始された回数が視聴回数になり、最短再生時間の要件はなくなった。
- ただし **YPP の資格と Shorts 広告の収益分配は「エンゲージ ビュー(エンゲージ ショート動画の視聴回数)」に基づく**(従来の指標が名称変更)。

## Shorts の収益分配の仕組み(✅ answer/12504220)

1. ショート フィードの動画の間に表示された広告の収益を、**月ごとに合算**します。
2. 音楽を使った動画の分は、使用トラック数に応じて音楽パートナーと分けます(1トラックなら半分、2トラックなら3分の1がクリエイター プールへ)。音楽を使わない動画の分はすべてプールへ入ります。
3. プールを国ごとに、各クリエイターの**エンゲージ ビューの割合**で割り当てます。
4. 割り当て額の **45%** がクリエイターに支払われます(音楽の有無は関係なし)。

**公式の架空の例**: ある国のプールが9万ドルで、自分の視聴回数の割合が1%なら割り当て900ドル、その45%の **405ドル** が支払額です。

## 収益の配分(長尺。⚪ 公式本文は未取得)

長尺の広告収益はクリエイター 55% とされる(広く公表)。Shorts は上記のとおり別のプール配分で 45%(✅)。長尺の数値は YouTube Studio / 公式で確認(#29)。

## AdSense の支払い(✅)

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| 日本円の**お支払い基準額** | **¥8,000**(残高がこの額に達した月に支払い) | ✅ | adsense/answer/1709871 |
| 確認基準額 | 身元確認 $0、住所確認 $10 相当額 | ✅ | adsense/answer/1709871 |
| 前月分の確定 | 毎月 **3日**ごろ | ✅ | adsense/answer/7164703 |
| 支払い情報の変更期限 | **20日** | ✅ | 同上 |
| 支払い処理 | **21〜26日**(21日が土日祝なら翌営業日) | ✅ | 同上 |

例: 6月分の収益は7月3日ごろに確定し、7月21日前後に支払われます(基準額に達している場合)。

## 収益を安定させる(⚪)

- 視聴時間の長い動画と、Shorts による発見のバランス。
- メンバーシップは特典の設計(限定動画、質問回答、早期公開)。
- 広告以外の収益(書籍、講座、グッズ)を持つ。[monetization-roadmap](../30-strategy/03-monetization-roadmap.md)

## 具体例: 500人到達時の進め方(イラストのチャンネル)

1. 「収益化」ページで「通知を受け取る」を設定しておく。
2. 500人・直近90日で3本・3,000時間を満たしたら申し込む。
3. 承認後、**Super Thanks** をオン(作業工程の動画に投げ銭)。
4. 毎月1回のライブで **Super Chat** と**メンバーシップ**(月1枚の限定ラフ公開など)を案内する。
5. 1,000人・4,000時間で広告収益の段階へ。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 審査に落ちた | 30日後に再申請可(2回目以降は90日後)。再利用コンテンツを減らし、独自の解説を加える(✅/⚪) |
| AdSense を新しく作ってしまった | 既存のアカウントがあるならそちらをリンク。重複は審査で問題になり得る(⚪) |
| 収益がしばらく支払われない | 基準額 ¥8,000 に達していない、または住所確認・税務情報が未完了(✅/⚪) |
| 子ども向け動画で Super Thanks が出ない | 子ども向けは対象外 |

## 税務・書類

AdSense の支払いに関する税務情報の入力が必要になる場合(⚪)。[tax-and-business](../30-strategy/04-tax-and-business.md)

## 注意

- 再利用コンテンツ・低品質な量産は収益化停止の理由になり得る([07-policies-and-checklist](07-policies-and-checklist.md))。
- 著作権の申し立て(Content ID)で収益が権利者に移ることがある。
- AI 使用を開示しても収益化の資格には影響しない(✅ [03](03-text-and-discovery.md))。

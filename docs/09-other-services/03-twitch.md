# Twitch

ライブ配信が中心のサービス。ゲーム実況だけでなく、創作・雑談・講座にも使われます。

## 収益化プログラム(🟡 二次資料。公式で確認 #42)

| プログラム | 条件(報告されている値) | 収益 |
|---|---|---|
| アフィリエイト | 従来: フォロワー50人、配信8時間、配信日数7日、平均視聴者3人(期間は30日)。新しい資料: フォロワー25人、配信4時間、4日、平均視聴者3人 | サブスク、Bits(投げ銭)、広告 |
| パートナー | アフィリエイト後、25時間、12回の配信、平均視聴者75人 とする資料(古い可能性) | より有利な配分、特典 |

- 達成状況は Creator Dashboard の「実績」で確認(⚪)。
- 条件は変更されているため、**Creator Dashboard の表示を信頼**。

## 配信の基本(⚪)

| 項目 | 目安 |
|---|---|
| 解像度・フレームレート | 1080p/30〜60fps(回線と PC に合わせる) |
| 配信ソフト | OBS Studio など |
| ビットレート | 回線の上りの 70% 以内 |
| オーバーレイ・パネル画像 | 公式の推奨サイズを確認 |

## 運用

1. 定時配信を決め、予定を告知(X・Instagram・YouTube)。
2. 配信のアーカイブ・切り抜きを YouTube/TikTok で再利用([funnel](../30-strategy/02-funnel.md))。
3. チャットのモデレーションとルール。
4. 音楽・ゲーム音の権利(アーカイブでの扱い)。

## 注意

- 権利者のポリシー(ゲーム・楽曲)。
- 広告・案件の開示。

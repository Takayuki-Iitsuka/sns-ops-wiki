# Twitch

> **このページで分かること**: Twitch(ツイッチ)の始め方、配信に必要な準備、アフィリエイト・パートナーの収益化条件、運用の注意点。
>
> **対象**: ライブ配信を始めたい初心者  **先に読むページ**: [ライブ配信(共通)](../01-common/live-streaming.md)

## 概要

ライブ配信が中心のサービス。ゲーム実況だけでなく、創作・雑談・講座にも使われます。

視聴者はチャットで配信者と会話しながら見るため、**「その場の一体感」**が魅力です。
収益化は、条件を満たすと参加できる**アフィリエイト(Affiliate)**から始まり、さらに上の**パートナー(Partner)**があります。

## 用語

| 用語 | 意味 |
|---|---|
| 配信(ストリーム) | リアルタイムの映像送信 |
| 配信ソフト | 画面やカメラを合成して Twitch に送るソフト。OBS Studio など |
| ストリームキー | 配信ソフトと自分のチャンネルを結ぶ秘密の鍵。**他人に見せない** |
| Creator Dashboard(クリエイターダッシュボード) | 配信の設定・分析・実績を見る管理画面 |
| 実績(Achievements) | 収益化条件の進み具合を表示する画面 |
| サブスク(Subscription) | 視聴者の月額支援 |
| Bits(ビッツ) | 視聴者が購入して配信者に送る投げ銭 |
| VOD(Video on Demand) | 配信の録画(アーカイブ) |
| レイド | 配信の終わりに、視聴者ごと他の配信者へ移動する機能 |
| モデレーター | チャットの荒らし対応を任せる人 |

## 手順: 配信を始める

1. Twitch のアカウントを作成し、**2段階認証**を有効にします(収益化に必要とする資料もあります 🟡。[セキュリティ](../01-common/account-security.md))。
2. プロフィール画像・バナー・自己紹介・パネル(チャンネル下の説明欄)を設定します。
3. 配信ソフト(OBS Studio など)をインストールします([ツール](../01-common/tools.md))。
4. Creator Dashboard で**ストリームキー**をコピーし、配信ソフトに貼り付けます(⚪ 項目名は要確認)。ストリームキーは公開しないでください。
5. 配信ソフトで「シーン」(画面の配置)を作ります: ゲーム画面・カメラ・チャット欄など。
6. 配信タイトル・カテゴリ・タグを設定します。
7. **テスト配信**をして、音量(声とゲーム音のバランス)と画質を確認します。
8. 本番の配信を始め、終了後に VOD の保存設定を確認します。

## 配信の基本(⚪)

| 項目 | 目安 |
|---|---|
| 解像度・フレームレート | 1080p/30〜60fps(回線と PC に合わせる) |
| 配信ソフト | OBS Studio など |
| ビットレート | 回線の上りの 70% 以内 |
| オーバーレイ・パネル画像 | 公式の推奨サイズを確認 |
| マイク | 声が聞き取れることが最優先。画質より音質 |
| 初めの設定 | 720p/30fps など軽い設定から始め、安定したら上げる |

## 収益化プログラム(🟡 二次資料。公式で確認 #42)

| プログラム | 条件(報告されている値) | 収益 |
|---|---|---|
| アフィリエイト | 従来: フォロワー50人、配信8時間、配信日数7日、平均視聴者3人(期間は30日)。新しい資料: フォロワー25人、配信4時間、4日、平均視聴者3人 | サブスク、Bits(投げ銭)、広告 |
| パートナー | アフィリエイト後、25時間、12回の配信、平均視聴者75人 とする資料(古い可能性) | より有利な配分、特典 |

- 達成状況は Creator Dashboard の「実績」で確認(⚪)。
- 条件は変更されているため、**Creator Dashboard の表示を信頼**。

補足(🟡 2026年(皇紀2686年・令和8年)の二次資料):

| 項目 | 内容 | 出典 |
|---|---|---|
| アフィリエイト条件の引き下げ | 2026年6月ごろに「25人・4時間・4日・平均3人」に変更と報道(5月とする資料も) | 🟡 [howsociable](https://howsociable.com/blog/twitch-affiliate-requirements)、[streamer.guide](https://streamer.guide/guides/twitch-affiliate-requirements) |
| 期間 | 直近30日の間にすべてを満たす | 🟡 同上 |
| パートナーの新しい条件 | 「申請前の2つの30日間それぞれで、6日以上・平均75人以上」とする資料があり、従来の「25時間・12日・75人」とは不一致 | 🟡 [howsociable](https://howsociable.com/blog/twitch-partner-requirements) |
| パートナーの審査 | 配信の継続性・視聴者数・エンゲージメントを総合的に見るとされる | 🟡 同上 |

公式ヘルプ(`help.twitch.tv`)は JavaScript 描画で本文を取得できていません。

## 具体例: 週の配信計画

| 曜日 | 内容 | 時間 |
|---|---|---|
| 火 | 作業配信(イラスト制作) | 20:00〜21:30 |
| 金 | 雑談+質問コーナー | 21:00〜22:00 |
| 日 | ゲーム実況 | 14:00〜16:00 |

→ 週3回 × 約1.5時間 = 約4.5時間。新しい資料のアフィリエイト条件(4時間・4日 🟡)に近づくには、月に4日以上配信すれば日数を満たせます。

| 良い例 | 悪い例 |
|---|---|
| 曜日と時間を固定し、X で予告 | 気まぐれに配信し、告知しない |
| 配信タイトルで内容が分かる | 「配信」だけのタイトル |

## 運用

1. 定時配信を決め、予定を告知(X・Instagram・YouTube)。
2. 配信のアーカイブ・切り抜きを YouTube/TikTok で再利用([funnel](../30-strategy/02-funnel.md))。
3. チャットのモデレーションとルール。信頼できる常連にモデレーターを任せる。
4. 音楽・ゲーム音の権利(アーカイブでの扱い)([音楽とライセンス](../01-common/music-and-licensing.md))。
5. 配信の最後にレイドを使い、他の配信者と交流する(⚪)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| ストリームキーを画面に映した | すぐ再発行(リセット)する |
| 声が小さく、ゲーム音が大きい | 配信ソフトの音量ミキサーで調整し、録画で確認 |
| 回線が不安定で映像が止まる | ビットレートと解像度を下げる |
| 視聴者0人で心が折れる | 最初は誰でも少ない。VOD や切り抜きで見つけてもらう |
| BGM のせいで VOD がミュートされた | 権利の明確な音源を使う |

## 注意

- 権利者のポリシー(ゲーム・楽曲)。ゲーム会社の配信ガイドラインを確認します。
- 広告・案件の開示([法令・表示](../01-common/legal-compliance.md))。
- 自宅が特定される映り込み(窓の外・郵便物)に注意します([個人情報](../01-common/privacy-and-personal-info.md))。

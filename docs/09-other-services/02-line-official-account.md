# LINE 公式アカウント

友だち登録した人に**直接メッセージを届ける**サービスです。到達率が高く、日本では会員・顧客との連絡に向きます。「収益化プログラム」ではなく、**自分の商品・サービスの販売や継続連絡**のための道具です。

## 料金プラン(🟡 代理店・ブログ系の整理。#40)

| プラン | 月額 | メッセージ | 追加配信 |
|---|---|---|---|
| コミュニケーション | 0円 | 月200通まで | 不可 |
| ライト | 5,000円(税別) | 月5,000通まで | 不可 |
| スタンダード | 15,000円(税別) | 月30,000通 | 従量課金 |

- メッセージ数は「配信回数 × 友だち数」で数える考え方(🟡)。
- 2026年10月1日に追加メッセージ料金の改定が予定されていたとの記述(🟡)。**最新は LINEヤフー for Business の公式料金ページで確認**。

## 主な機能(⚪)

| 機能 | 内容 |
|---|---|
| メッセージ配信 | 全体/セグメント |
| リッチメニュー | トーク画面下部のメニュー(画像) |
| リッチメッセージ/リッチビデオ | 画像・動画つき |
| 自動応答・チャット | 問い合わせ対応 |
| ショップカード・クーポン | 来店促進 |
| LINE VOOM | 投稿 |
| Messaging API | プログラムから配信・応答 |

## 画像(⚪ 要確認 #40)

- リッチメニュー: **2500×1686 または 2500×843** ✅(LINE 開発者文書の Messaging API のサンプル)。容量・形式の上限は未確認。
- リッチメッセージ: 1040px 幅など(仕様は変更あり)。公式で確認。

## 運用の指針(⚪)

1. 配信頻度を決め、**ブロック率**を監視(多すぎる配信は離脱要因)。
2. 友だち追加の導線(X・Instagram・note・YouTube から)。
3. 個人情報(電話・住所)の取り扱い。
4. 景品表示・特定電子メール法(メッセージの同意)に配慮 ⚪ 要確認。

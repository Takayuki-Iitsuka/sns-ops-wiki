# LINE 公式アカウント

> **このページで分かること**: LINE 公式アカウントの作り方、料金プランとメッセージ通数の数え方、リッチメニューなど主な機能、配信の考え方。
>
> **対象**: 初心者(店舗・個人事業・クリエイター)  **先に読むページ**: [サービスの選び方](../01-common/choosing-platforms.md)

## 概要

友だち登録した人に**直接メッセージを届ける**サービスです。到達率が高く、日本では会員・顧客との連絡に向きます。「収益化プログラム」ではなく、**自分の商品・サービスの販売や継続連絡**のための道具です。

X や Instagram は「おすすめ」に載るかどうかで届く人数が変わりますが、LINE 公式アカウントは**友だちのトーク画面に直接届く**のが強みです。
一方で、送りすぎると**ブロック**されやすく、送った通数に応じて費用がかかります。

## 用語

| 用語 | 意味 |
|---|---|
| 友だち | アカウントを追加してくれた人。配信先になる |
| ブロック | 友だちが受信を拒否すること。配信は届かなくなる |
| メッセージ通数 | 料金計算の単位。**送信対象になった人数**で数える(✅) |
| 追加メッセージ | 無料メッセージ通数を超えて送るメッセージ。従量課金 |
| リッチメニュー | トーク画面の下に出る、画像のメニュー |
| セグメント配信 | 条件で絞った一部の友だちに送ること |
| ビジネス ID | LINE 公式アカウントを作るときに登録する ID(✅) |
| LINE Official Account Manager | アカウントを管理する公式の管理画面 |
| Messaging API | プログラムから配信・応答する仕組み |

## 手順: アカウントを作る

LINE の開発者文書では、次の流れが示されています(✅ [Messaging API を始めよう](https://developers.line.biz/ja/docs/messaging-api/getting-started/))。

1. **ビジネス ID に登録**します。LINE アカウントまたはメールアドレスで登録できます(✅)。
2. 表示される**作成フォーム**に、アカウント名・業種などの必要事項を記入します(✅)。
3. 作成したアカウントは **LINE Official Account Manager** で確認できます(✅)。
4. プロフィール画像・あいさつメッセージ(友だち追加時の自動メッセージ)を設定します(⚪)。
5. 友だち追加用の QR コード・URL を取得し、店頭・SNS・名刺に載せます(⚪)。

プログラム連携をする場合のみ、続けて Messaging API を有効にします。このとき選ぶ**プロバイダー(管理単位)は、あとから変更できません**(✅ 同上)。迷ったら連携は後回しにします。

## 料金プラン

日本の料金プランの例(✅ [Messaging API の料金](https://developers.line.biz/ja/docs/messaging-api/pricing/)。月額固定費・追加メッセージ料金は税別):

| プラン | 月額固定費 | 無料メッセージ通数(月) | 追加メッセージ | 確度 |
|---|---|---|---|---|
| コミュニケーション | 0円 | 200通 | 不可 | ✅ |
| ライト | 5,000円 | 5,000通 | 不可 | ✅ |
| スタンダード | 15,000円 | 30,000通 | 〜3円/通(送信数により単価が変わる) | ✅ |

- 以前の記載(代理店・ブログ系の整理 🟡)でも同じ金額・通数でした。公式の開発者文書で一致を確認しました。
- 2026年(皇紀2686年・令和8年)10月1日に、追加メッセージ料金の改定が**実施された**とする公式のお知らせがあります。20万通/月までは1通3円、20万通を超えた分は1通2.5円(税別)とされます(🟡 [LINEヤフー for Business のお知らせ](https://www.lycbiz.com/jp/news/line-official-account/20261001/)の検索要約)。**最新は LINEヤフー for Business の公式料金ページで確認**してください。

### メッセージ通数の数え方(✅)

| ルール | 内容 |
|---|---|
| 数え方 | 送信対象になった**人数**で数える(1回の配信で吹き出しを複数送っても、1人1通) |
| 数えない | ブロックしているユーザーや存在しないユーザーなど、実際に届かない宛先 |
| 数える送り方(API) | プッシュ・マルチキャスト・ブロードキャスト・ナローキャスト |
| 数えない送り方(API) | 応答メッセージ(相手のメッセージへの返信) |
| 上限を超えたとき | 送信できず、エラーになる |

出典: [Messaging API の料金](https://developers.line.biz/ja/docs/messaging-api/pricing/)(✅)。

計算例: 友だち 300人に月4回配信 → 300 × 4 = 1,200通。コミュニケーションプラン(200通)では足りず、ライトプラン(5,000通)が必要です。

| 機能 | 内容 |
|---|---|

### リッチメニューの作り方(管理画面)

1. LINE Official Account Manager でリッチメニューの作成を開きます(⚪ 表記は要確認)。
2. テンプレート(分割の形)を選びます。
3. テンプレートに合うサイズで画像を作ります(例: 2500×1686 を6分割)。
4. 各領域にリンク・クーポン・テキストなどのアクションを設定します。
5. 表示期間を決めて保存し、スマホで動作を確認します。

## 具体例: 配信計画(地域の店)

| 週 | 配信内容 | 通数(友だち300人) |
|---|---|---|
| 1週目 | 今月の新商品(画像1枚+一言) | 300 |
| 3週目 | 友だち限定クーポン | 300 |
| 合計 | — | 600通 → ライトプランで収まる |

| 良い配信 | 悪い配信 |
|---|---|
| 月2〜4回、毎回「得する情報」がある(⚪) | 毎日同じ宣伝 |
| 1通に話題は1つ | 長文と画像を何通も連続 |

## 運用の指針(⚪)

1. 配信頻度を決め、**ブロック率**を監視(多すぎる配信は離脱要因)。
2. 友だち追加の導線(X・Instagram・note・YouTube から)。
3. 個人情報(電話・住所)の取り扱い([個人情報](../01-common/privacy-and-personal-info.md))。
4. 景品表示・特定電子メール法(メッセージの同意)に配慮 ⚪ 要確認。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 無料通数(200通)をすぐ使い切る | 「人数 × 回数」で事前に計算し、プランを選ぶ |
| 配信が多くブロックが増えた | 頻度を下げ、セグメント配信にする |
| リッチメニューの文字が小さく読めない | スマホで実際に表示して確認 |
| API 連携のプロバイダーを間違えた | 変更できない(✅)。連携前に管理者と相談 |

## 注意点

- 料金は税別表記です。消費税込みの予算で考えます。
- チャネルアクセストークンなどの秘密情報は公開しないでください([API の基本と安全](../20-api/01-concepts-and-security.md))。

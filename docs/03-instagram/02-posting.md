# Instagram 投稿ルート

## 形式一覧

| 形式 | 概要 | 使い所 |
|---|---|---|
| フィード（1枚） | 写真1枚 | 世界観・作品 |
| カルーセル | 複数枚スワイプ。最大20枚とされる ⚪ #10 | 解説・手順・まとめ（保存されやすい形式との見方 ⚪） |
| リール | 縦型短尺動画 | 発見・拡散 |
| ストーリーズ | 24時間で消える | 日常・告知・質問スタンプ |
| ライブ | リアルタイム | 交流・発表 |
| ガイド等 | 一部機能 | 要確認 |

## 基本手順（アプリ）

1. 「＋」から種類を選ぶ。
2. 写真/動画を選択（複数選択でカルーセル）。
3. 比率・トリミングを調整。重要部分が切れないか確認。
4. フィルター・編集。
5. キャプション、ハッシュタグ、場所、タグ付け、**代替テキスト**を設定（→ [05-alt-text](05-alt-text.md)）。
6. 共有（予約投稿は条件・提供範囲を要確認 ⚪）。

## 投稿設計

- **カルーセル**: 1枚目で結論/問い、最後に要約と CTA。
- **リール**: 最初の1〜3秒で内容を伝える。字幕を付ける（音なし視聴が多い ⚪）。
- **ストーリーズ**: 質問・投票スタンプで交流。

## 運用頻度の目安（⚪）

フィード週2〜3、ストーリーズ週数回、リール週1〜。継続可能な範囲を優先。

# Instagram のコツ(経験則 ⚪)

> **このページで分かること**: 見た目の統一、投稿内容の選び方、続けるための運用の工夫、避けるべきこと。公式の基準ではなく**一般的な経験則**(⚪)です。
>
> **対象**: 初心者  **先に読むページ**: [02-posting](02-posting.md)、[first-30-days](../01-common/first-30-days.md)

## 概要

Instagram の「伸びるコツ」は数多く語られますが、公式に保証されたものはほとんどありません。このページは、**多くの運用者が経験的に有効とする考え方**をまとめたものです。数値の裏付けが必要な仕様は [03-media-specs](03-media-specs.md) などの ✅ ページを参照してください。

大きな方針は次の3つです。

1. **誰に何を届けるか**を1文で言えるようにする
2. 見た目と投稿の**型**を決めて、迷う時間を減らす
3. 数字を見て**型を少しずつ直す**

## 用語

| 用語 | 意味 |
|---|---|
| 世界観 | 色・写真の雰囲気・文体などの統一感 |
| 型(テンプレート) | 毎回使い回す構成やデザインの決まり |
| 保存される投稿 | 後で見返したくなる実用的な投稿(手順・一覧・比較) |
| CTA(行動喚起) | 「保存して」「フォローして」など次の行動を促す文 |
| 投稿の柱(コンテンツピラー) | アカウントで繰り返し扱う2〜4個のテーマ |

## 手順 / 仕様

### 見た目

1. **色とフォントの統一**: 3色以内・フォント2種以内。
2. **4:5 の縦長**はフィードで画面を大きく占有(比率範囲は [03-media-specs](03-media-specs.md))。
3. **1枚目で伝える**: カルーセルは1枚目で結論または課題提示。
4. **余白と大きな文字**。

具体的な決め方は [brand-and-visual-guidelines](../01-common/brand-and-visual-guidelines.md) を参照してください。

### 内容

- 保存される投稿(手順・チェックリスト・比較表)を作る。
- ストーリーズで日常と質問、フィードで資産、リールで発見を担わせる。
- ハイライトを自己紹介ページとして整備([13-stories-and-highlights](13-stories-and-highlights.md))。

**投稿の柱を決める手順**

1. 自分が継続して出せる話題を10個書き出します。
2. フォロワーに役立つ・楽しめるものに丸を付けます。
3. 似たものをまとめて、2〜4個の柱にします(例: 料理アカウントなら「時短レシピ」「道具紹介」「季節の献立」)。
4. 1週間の投稿を柱ごとに割り振ります([content-planning](../01-common/content-planning.md))。

### 運用

- 週次で上位投稿を分析し、同じ型を再利用([08-analytics](08-analytics.md))。
- 他サービスへ誘導する場合はプロフィールのリンクとストーリーズを使う。
- まとめて作って予約する「作り置き」をすると、忙しい週でも途切れません。
- 1つの題材をカルーセル・リール・ストーリーズに作り替えると、制作の手間が減ります([posting-workflow](../01-common/posting-workflow.md))。

### 避けること

- 他人の画像・動画の無断使用
- ハッシュタグの過剰付与
- 購入したフォロワーやエンゲージメント
- ステマ(広告表記なしの案件投稿)

## 具体例

**地域の店の1週間(例)**

| 曜日 | 形式 | 内容 |
|---|---|---|
| 月 | ストーリーズ | 今週の営業日・アンケート「どの新商品が気になる?」 |
| 水 | カルーセル | 商品の選び方3つ(保存される投稿) |
| 金 | リール | 仕込みの様子15秒 |
| 土 | ストーリーズ | 店頭の様子・位置情報スタンプ |

**イラストアカウントの型(例)**

- 毎回同じ位置にサインとシリーズ名
- カルーセルは「完成 → 制作過程 → 使った道具」の順
- リールはタイムラプス+完成で静止

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 毎回デザインを一から考えて疲れた | テンプレートを3種類作り、使い回す |
| 話題が多すぎて何のアカウントか伝わらない | 投稿の柱を2〜4個に絞る |
| フォロワーを買ったら反応率が下がった | 規約違反のおそれ。削除して地道に運用([10-policies](10-policies.md)) |
| 流行の音源・型を追いかけて疲れた | 自分の柱に合うものだけ取り入れる |
| 数字が伸びず更新が止まった | 週次で1つだけ改善点を決め、続けることを優先 |

## 注意点

- このページの内容は経験則(⚪)です。表示の仕組み(アルゴリズム)は公開されておらず、変わることがあります。
- 「この時間に投稿すれば伸びる」といった一般論より、**自分のインサイト**を優先します。

# Instagram のコツ（経験則 ⚪）

## 見た目

1. **色とフォントの統一**: 3色以内・フォント2種以内。
2. **4:5 の縦長**はフィードで画面を大きく占有（比率範囲は [03-media-specs](03-media-specs.md)）。
3. **1枚目で伝える**: カルーセルは1枚目で結論または課題提示。
4. **余白と大きな文字**。

## 内容

- 保存される投稿（手順・チェックリスト・比較表）を作る。
- ストーリーズで日常と質問、フィードで資産、リールで発見を担わせる。
- ハイライトを自己紹介ページとして整備。

## 運用

- 週次で上位投稿を分析し、同じ型を再利用。
- 他サービスへ誘導する場合はプロフィールのリンクとストーリーズを使う。

## 避けること

- 他人の画像・動画の無断使用
- ハッシュタグの過剰付与
- 購入したフォロワーやエンゲージメント
- ステマ（広告表記なしの案件投稿）

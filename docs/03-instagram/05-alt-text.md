# Instagram の代替テキスト

> **このページで分かること**: alt text(代替テキスト)とは何か、Instagram での設定手順、書き方の型と文例、リール・ストーリーズでの代わりの工夫。
>
> **対象**: 初心者  **先に読むページ**: [alt-text 詳細ガイド](../01-common/alt-text.md)

## 概要

alt text(代替テキスト)は、**画像に何が写っているかを文字で説明するテキスト**です。目の見えない人・見えにくい人が使う **screen reader(スクリーンリーダー、画面読み上げ機能)** が読み上げます。通信状況が悪く画像が表示されないときにも役立ちます(⚪)。

Instagram では投稿時に画像ごとに入力できます。入力しないと自動生成されることがありますが、内容が不正確なことも多いため(⚪)、**自分で書くのがおすすめ**です。

## 用語

| 用語 | 意味 |
|---|---|
| alt text(代替テキスト) | 画像の内容を説明する文字 |
| screen reader(スクリーンリーダー) | 画面の文字を音声で読み上げる機能(iPhone の VoiceOver、Android の TalkBack など) |
| caption(キャプション) | 投稿の説明文。代替テキストとは別物 |
| subtitles / captions(字幕) | 動画の音声を文字にしたもの |

## 手順 / 仕様

### 設定方法 ⚪

⚪ メニュー名は変わる可能性があります。

1. 投稿の最終画面で「詳細設定」を開く。
2. 「代替テキストを書く」で、画像ごとに入力する。
3. 投稿後は編集から変更できる(要確認)。

投稿後に変更する場合(⚪):

1. 投稿の右上「…」→「編集」を選びます。
2. 画像の右下に出る「代替テキストを編集」を押します。
3. 入力して「完了」を押します。

### 仕様

| 項目 | 内容 | 確度 |
|---|---|---|
| 文字数上限(アプリ) | 100字とされる資料もあるが、**未確認** | ⚪ #8 |
| 文字数上限(API) | **最大1,000字** | ✅ 公式 |
| API での設定 | **`alt_text` フィールド(2025年(皇紀2685年・令和7年)3月24日追加)**。**画像投稿のみ**。リールとストーリーズは非対応 | ✅ 公式 |
| 自動生成 | 自動で代替テキストが付くことがあるが、精度は限定的 | ⚪ |

### API の仕様(✅ 公式リファレンス)

- `alt_text`: **最大1,000字**。**画像投稿のみ**(単体画像、またはカルーセル内の画像)。**リールとストーリーズは非対応**。
- リール・ストーリーズでは、**字幕・キャプション**で補う。

出典: [IG User Media](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media.md)、[Changelog](https://developers.facebook.com/documentation/instagram-platform/changelog.md)。

### 書き方の手順

1. **何の画像か**を最初に書きます(写真 / イラスト / 図解 / スクリーンショット)。
2. **主役**(人・物・料理など)とその様子を書きます。
3. 投稿の目的に関係する**細部**(色・数・文字)を足します。
4. 画像内に**文字**があれば、その要点を書きます。
5. 1〜3文程度にまとめます。キャプションと同じ文を繰り返さないようにします(⚪)。

共通原則: [alt-text](../01-common/alt-text.md)

- カルーセルは画像ごとに内容が違うので1枚ずつ。
- 画像内の文字(図解・スクショ)は、要点だけでも書く。

## 具体例

> 手書きの週間カレンダー。月曜に「X」、水曜に「note」、金曜に「写真3枚」と書かれた付箋が貼られている。

| 画像 | 良い例 | 悪い例 |
|---|---|---|
| 料理写真 | 白い皿に盛ったオムライス。表面にケチャップでハートが描かれ、横にブロッコリーが2つ添えてある。 | 「料理」 |
| 図解(手順) | 図解「洗濯物を早く乾かす3つのコツ」。1. 間隔を空けて干す、2. 厚手は外側、3. 扇風機を当てる。 | 「画像」 |
| 店内写真 | 木の棚に色とりどりのマグカップが並ぶ店内。手前に「新作」と書かれた札がある。 | 「#カフェ #雑貨 #おしゃれ」(ハッシュタグの羅列) |
| イラスト | 水彩風のイラスト。夕焼けの空の下、赤い傘をさした子どもが水たまりを跳び越えている。 | 「イラスト描きました」 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| ハッシュタグやキーワードを並べた | 代替テキストは説明文。検索対策の語を詰め込まない |
| 「画像」「写真」だけ | 主役と様子を1文で書く |
| カルーセルの1枚目にしか書かなかった | 全枚数に書く。図解は各ページの要点 |
| リールに代替テキスト欄がない | API でも非対応 ✅。**字幕**と、キャプションでの内容説明で補う |
| 長すぎて要点が分からない | 1〜3文に収める。詳しい内容はキャプションへ |

## 注意点

- 代替テキストに個人情報(名札の氏名・住所など)を書き起こさないようにします。
- 外部ツールから投稿する場合、ツールが `alt_text` に対応しているか確認します([20-api/03-instagram-graph-api](../20-api/03-instagram-graph-api.md))。
- 書いた内容は [alt-text-log](../../templates/alt-text-log.md) に記録すると、再投稿・転用のときに使い回せます。

## チェックリスト

- [ ] すべての画像(カルーセルは全枚数)に代替テキストを入れた
- [ ] 何の画像か・主役・細部・画像内の文字の順に書いた
- [ ] ハッシュタグの羅列になっていない
- [ ] リール・ストーリーズは字幕を付けた
- [ ] スクリーンリーダーで一度読み上げて確認した(⚪ 推奨)

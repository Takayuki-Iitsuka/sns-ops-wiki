# Instagram のルール・ポリシー

一次資料: Instagram コミュニティガイドライン、利用規約、Meta パートナー収益化ポリシー（入口: https://help.instagram.com/）。

## 注意領域 ⚪

| 領域 | 要点 |
|---|---|
| オリジナル性 | 他者コンテンツの再投稿は推奨度・収益化に影響し得る |
| 著作権・音楽 | 音源の商用利用の可否（ビジネスアカウントは使える音源が限定される場合あり。要確認） |
| ブランドコンテンツ | 「有料パートナーシップ」ラベル等の機能を使い、広告表記 [legal](../01-common/legal-compliance.md) |
| フォロワー購入・自動化 | 規約違反 |
| 年齢制限 | 規約の年齢要件を確認 |
| 暴力・ヘイト・危険な内容 | 削除対象 |

## 違反時

- 投稿削除、機能制限、アカウント停止。異議申立てを行う。

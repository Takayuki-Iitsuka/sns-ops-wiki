# Instagram キャプション・ハッシュタグ

## キャプション

| 項目 | 内容 | 確度 |
|---|---|---|
| 文字数上限 | **2,200字**(API のキャプション上限 ✅。アプリも同じと考えられるが確認は未) | ✅ |
| 折りたたみ | 冒頭の数行のみ表示される。**最初の1〜2行に要点** | ⚪ |
| 絵文字・改行 | 可読性向上に使う | ⚪ |
| リンク | キャプション内のURLはクリックできない（ストーリーズのリンクスタンプやプロフィールリンクを使う） | ⚪ 要確認 |

## ハッシュタグ

| 項目 | 内容 | 確度 |
|---|---|---|
| 上限 | **30個**(API の仕様 ✅)。@メンションは **20個** ✅ | ✅ |
| 推奨 | 少数（数個）に絞る方針が公式から示されたとの情報あり。**未確認** | ⚪ |
| 位置 | キャプション末尾、またはコメント欄 | ⚪ |
| 運用 | 自社タグ＋話題タグ＋地域タグ | ⚪ |

共通の原則: [hashtags](../01-common/hashtags.md)

## メンション・タグ付け

- 関係者・コラボ先をタグ付けして相互露出。無関係なアカウントを大量にタグ付けしない。
- 商品タグ・ブランドコンテンツ表示は [10-policies](10-policies.md)。

## 書き方テンプレ（⚪）

```
1行目: 結論または問い
2〜4行: 要点
最後: CTA（保存して見返してね／コメントで教えてください）
#自社タグ #話題タグ #地域タグ
```

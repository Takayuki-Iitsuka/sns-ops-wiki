# Instagram キャプション・ハッシュタグ

> **このページで分かること**: キャプション(投稿の説明文)の書き方、ハッシュタグの選び方と上限、メンション・タグ付け、リンクの置き場所。
>
> **対象**: 初心者  **先に読むページ**: [02-posting](02-posting.md)、[writing-guide](../01-common/writing-guide.md)

## 概要

Instagram は画像・動画が主役ですが、**キャプションは「なぜこの投稿を見るべきか」を伝える場所**です。フィードでは冒頭の数行しか表示されず、続きは「続きを読む」をタップしないと読めません(⚪)。そのため**最初の1〜2行に要点**を書くのが基本です。

ハッシュタグは「投稿を分類するラベル」です。以前のように大量に付ける方法は、上限の引き下げ(下記)もあり、**少数を厳選する**方向になっています。

## 用語

| 用語 | 意味 |
|---|---|
| caption(キャプション) | 投稿に付ける説明文 |
| hashtag(ハッシュタグ) | `#` 付きの分類用の語。タップすると同じタグの投稿一覧が開く |
| mention(メンション) | `@ユーザーネーム` で他のアカウントに言及すること。相手に通知される |
| tag(タグ付け) | 画像上に人物のアカウントを表示する機能 |
| CTA / call to action(行動喚起) | 「保存して」「コメントで教えて」など次の行動を促す文 |
| keyword(キーワード) | 検索で使われる語。キャプションやプロフィールに自然に含める |

## 手順 / 仕様

### キャプション

| 項目 | 内容 | 確度 |
|---|---|---|
| 文字数上限 | **2,200字**(API のキャプション上限 ✅。アプリも同じと考えられるが確認は未) | ✅ |
| 折りたたみ | 冒頭の数行のみ表示される。**最初の1〜2行に要点** | ⚪ |
| 絵文字・改行 | 可読性向上に使う | ⚪ |
| リンク | キャプション内のURLはクリックできない(ストーリーズのリンクスタンプやプロフィールリンクを使う) | ⚪ 要確認 |
| カルーセルの子要素 | 1枚ごとのキャプション・タグは API では**非対応**(投稿全体に1つ) | ✅ |

### ハッシュタグ

| 項目 | 内容 | 確度 |
|---|---|---|
| 上限 | **最大 5 個**に引き下げられたと報道(2025年(皇紀2685年・令和7年)12月〜)。**公式 API 文書は 30個・@メンション 20個**と記載(更新遅れの可能性) | 🟡/✅ #56 |
| 推奨 | 少数(数個)に絞る方針が公式から示されたとの情報あり。**未確認** | ⚪ |
| 位置 | キャプション末尾、またはコメント欄 | ⚪ |
| 運用 | 自社タグ+話題タグ+地域タグ | ⚪ |

2025年12月の報道では、Instagram の責任者が「投稿あたり最大5個に制限する」と発表し、**段階的に適用**するとされています 🟡([Social Media Today](https://www.socialmediatoday.com/news/instagram-implements-new-limits-on-hashtag-use/808309/))。日本のアカウントや API への適用時期は未確認です(#56)。**5個以内で設計**しておけば、どちらの上限でも問題ありません。

共通の原則: [hashtags](../01-common/hashtags.md)

### キャプションを書く手順

1. **1行目**: 結論か問いを書きます(例: 「洗い物が減る、フライパン1つの朝ごはん」)。
2. **2〜4行目**: 要点を箇条書きにします。改行と記号(・や①)で読みやすくします。
3. **補足**: 材料・価格・営業時間・撮影場所など、検索されそうな情報を自然な文で入れます(⚪)。
4. **最後**: CTA(「保存して見返してね」「質問はコメントへ」)。
5. **ハッシュタグ**: 関連性の高いものを5個以内で付けます。
6. 投稿前に、誤字・固有名詞・日付・価格を確認します。

### ハッシュタグの選び方(⚪ 経験則)

| 種類 | 例(料理アカウント) | 役割 |
|---|---|---|
| 内容タグ | #朝ごはん #作り置き | 何の投稿か |
| 対象タグ | #一人暮らしごはん | 誰向けか |
| 地域タグ | #○○市ランチ | 地域の店・イベント |
| 自社タグ | #○○キッチンのレシピ | シリーズ・過去投稿の一覧 |

- 投稿内容と関係ない人気タグは付けません(スパムと見なされる可能性 ⚪)。
- 自社タグは他の人が使っていないか、事前にタグを検索して確認します。

### メンション・タグ付け

- 関係者・コラボ先をタグ付けして相互露出。無関係なアカウントを大量にタグ付けしない。
- 商品タグ・ブランドコンテンツ表示は [10-policies](10-policies.md)。
- API の上限はメンション **20個**、コラボ(共同投稿者)は **3人** ✅([IG User Media](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media.md))。
- 一緒に作った投稿は、タグ付けより**コラボ投稿**の方が相手のフォロワーにも表示されやすいとされます(⚪)。

### リンクの置き場所

| 場所 | クリックできるか | 確度 |
|---|---|---|
| フィード・リールのキャプション | できないとされる | ⚪ 要確認 |
| プロフィールのリンク | できる(最大5件とされる) | 🟡 |
| ストーリーズのリンクスタンプ | できる | ⚪ |
| DM | できる | ⚪ |

キャプションでは「詳しくはプロフィールのリンクから」と案内します。計測は [link-in-bio-and-utm](../01-common/link-in-bio-and-utm.md)。

## 具体例

### 書き方テンプレ(⚪)

```
1行目: 結論または問い
2〜4行: 要点
最後: CTA(保存して見返してね/コメントで教えてください)
#自社タグ #話題タグ #地域タグ
```

### 良い例(地域の花屋)

```
母の日の花束、予算別に3つ選びました💐
・3,000円: カーネーション中心の小さめブーケ
・5,000円: 季節の花を合わせたブーケ
・8,000円: 鉢植え+メッセージカード
ご予約はプロフィールのリンクから(5/8まで)
#母の日ギフト #花束 #○○駅花屋
```

### 悪い例

```
今日のお花です!!!
#花 #flower #instagood #photooftheday #love #follow #いいね返し …(30個)
```

→ 何の投稿か分からず、関係のない人気タグばかりです。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 大事な情報が「続きを読む」の後ろにある | 1〜2行目に要点を移す |
| ハッシュタグを30個付けたら一部が反映されない | 5個以内に絞る(🟡 上限引き下げ) |
| キャプションに URL を書いたがクリックされない | プロフィールのリンクやストーリーズのリンクスタンプへ誘導 |
| メンションした相手から「知らない」と言われた | 事前に許可を取る。関係者のみメンション |
| 案件なのに「PR」を書き忘れた | タイアップ投稿ラベルと本文の表記を両方使う([legal-compliance](../01-common/legal-compliance.md)) |

## 注意点

- 文字数の数え方(全角・絵文字・改行)は公式に未確認です(#15)。上限ぎりぎりは避けます。
- ハッシュタグの上限は報道と公式 API 文書で異なります(#56)。
- 検索で見つけてもらう工夫は [search-optimization](../01-common/search-optimization.md) も参照してください。

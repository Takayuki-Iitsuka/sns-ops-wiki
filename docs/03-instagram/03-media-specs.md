# Instagram 画像・動画仕様

## フィード写真

| 項目 | 値 | 確度 |
|---|---|---|
| 幅 | 320〜1080px は元解像度を維持。**幅1080px以上のアップロードを推奨** | 🟡（公式ヘルプの検索要約） |
| 許容比率 | **1.91:1（横長）〜 4:5（縦長）**。範囲外は自動トリミング | 🟡（公式ヘルプの検索要約） |
| 3:4（1080×1440） | 2025年に追加されたとの二次情報あり。**未確認** | 🟡 #4 |
| 形式 | JPEG / PNG が一般的に挙げられる | ⚪ #9 |
| 容量 | 8MB〜30MB と資料により不一致 | ⚪ #9 |

## サイズ早見

| 用途 | サイズ | 比率 | 確度 |
|---|---|---|---|
| 正方形 | 1080×1080 | 1:1 | 🟡 |
| 縦長（推奨の1つ） | 1080×1350 | 4:5 | 🟡 |
| 横長 | 1080×566 | 1.91:1 | 🟡 |
| リール / ストーリーズ | 1080×1920 | 9:16 | ⚪ |
| プロフィール画像 | 320×320 以上、1:1 | 1:1 | ⚪ |

## カルーセル

- 全て同じ比率にすると見やすい。最初の1枚の比率が基準になるとされる ⚪（要確認）。

## 注意

- **グリッド（プロフィール画面）での見え方**: 近年プロフィールのサムネイル比率が変更されている可能性 ⚪。重要要素は中央に。
- 文字入り画像は安全領域（中央80%）に収める。

## リール・ストーリーズ・動画(🟡 二次資料。#18)

| 項目 | 値 | 確度 |
|---|---|---|
| リールの比率・解像度 | 9:16、1080×1920 | 🟡 |
| リールの長さ | 90秒・3分・15分・20分と資料により不一致(**アプリ内で確認**) | 🟡 |
| リールの容量 | 約4GB まで(アプリ)。API 公開は 100MB/300MB と不一致 | 🟡 |
| ストーリーズ | 9:16、1080×1920。上下の安全領域を空ける | ⚪ |
| カバー | JPEG(API は 8MB 以下)。プロフィールのグリッド表示の切り抜きに注意 | 🟡 |

## API 経由の公開

**画像は JPEG のみ・8MB**、公開上限 50件/24時間(カルーセルは1件)、素材は公開 URL に置く。詳細は [20-api/03-instagram-graph-api](../20-api/03-instagram-graph-api.md)。

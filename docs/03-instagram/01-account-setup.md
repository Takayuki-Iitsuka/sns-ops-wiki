# Instagram 初期設定

> **このページで分かること**: Instagram のアカウントを作り、プロフェッショナルアカウントに切り替え、プロフィール・安全設定を整えるまでの手順。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[アカウントの安全](../01-common/account-security.md)

## 概要

Instagram は写真と動画が中心のサービスです。最初の設定で決めることは次の3つです。

1. **誰として発信するか**(ユーザーネーム・名前・プロフィール画像)
2. **どの種類のアカウントにするか**(個人 / クリエイター / ビジネス)
3. **アカウントをどう守るか**(2段階認証・プライバシー設定)

最初にここを整えておくと、後から「ユーザーネームを変えたらリンクが切れた」「分析が見られない」といった手戻りを防げます。

## 用語

| 用語 | 意味 |
|---|---|
| username(ユーザーネーム) | `@` から始まる ID。URL(`instagram.com/ユーザーネーム`)にも使われる |
| name(名前) | プロフィールに表示される名前。ユーザーネームとは別に設定できる |
| bio(自己紹介) | プロフィールの説明文 |
| professional account(プロフェッショナルアカウント、プロアカウント) | ビジネス向け・クリエイター向けの機能が使える種類のアカウントの総称 |
| creator account(クリエイターアカウント) | 個人の発信者向けのプロアカウント |
| business account(ビジネスアカウント) | 店舗・企業・ブランド向けのプロアカウント |
| Accounts Center(アカウントセンター) | Instagram・Facebook・Threads など Meta のアカウントをまとめて管理する設定画面 |
| two-factor authentication(2段階認証) | パスワードに加えて確認コードを求める安全機能 |

## 手順 / 仕様

### 1. アカウントを作る

1. アプリをインストールし、「新しいアカウントを作成」を選びます(⚪ ボタンの表記は変わる可能性があります)。
2. **運用専用のメールアドレス**を使います。個人のメールと分けておくと、担当者の交代や引き継ぎが楽になります。
3. 生年月日を入力します。Instagram の利用は原則 **13歳以上** です(一部の国・地域では異なる年齢要件) 🟡([ヘルプ](https://help.instagram.com/517920941588885)の検索要約)。
4. ユーザーネームを決めます。後から変更できますが、変更すると古い URL へのリンクが使えなくなるため、**最初に慎重に決める**のがおすすめです(⚪)。
5. パスワードは他サービスと使い回さないものにします。パスワード管理アプリの利用を推奨します([account-security](../01-common/account-security.md))。

### 2. プロフェッショナルアカウントに切り替える

インサイト(分析)や API 連携、収益化機能の多くは**プロフェッショナルアカウント**が前提です。Meta の開発者文書でも、API が扱えるのは「ビジネスアカウントとクリエイターアカウントを含むプロフェッショナルアカウント」と明記されています ✅([Overview](https://developers.facebook.com/documentation/instagram-platform/overview.md))。

| 種類 | 向いている人 | 確度 |
|---|---|---|
| 個人 | 友人・家族との共有、閲覧が中心 | ⚪ |
| クリエイター | 個人で作品・情報を発信する人(イラスト、料理、写真など) | 🟡 |
| ビジネス | 店舗・企業・ブランド。連絡先ボタンや住所表示を使う | 🟡 |

切り替えの手順(🟡 [ヘルプ](https://help.instagram.com/ipad-app/2358103564437429)の検索要約。⚪ メニュー名は変わる可能性あり):

1. プロフィール画面の右上のメニュー(≡)を開きます。
2. 「アカウントの種類とツール」を選びます。
3. 「プロアカウントに切り替える」を選びます。
4. **カテゴリ**(例: 「デジタルクリエイター」「レストラン」など)を選びます。カテゴリはプロフィールに表示するかどうかを選べます(⚪)。
5. 「クリエイター」か「ビジネス」かを選び、案内に沿って完了します。

注意点(🟡 二次資料):

- **非公開アカウントは、プロアカウントへ切り替えると公開アカウントになります**。保留中のフォローリクエストは承認されます。
- 後から個人アカウントへ戻したり、クリエイター⇔ビジネスを変えたりできます。ただし戻すと過去のインサイトが見られなくなる場合があります(⚪ 要確認)。

### 3. プロフィールを整える

| 項目 | 内容 | 確度 |
|---|---|---|
| プロフィール画像 | 円形に切り抜かれる。顔・ロゴを中央に置く。1:1 で用意 | ⚪ |
| 名前 | 検索の対象になるとされる。発信内容が伝わる語を入れる(例: 「山田|手作りパン」) | ⚪ |
| 自己紹介(bio) | **150字**程度が上限とされる(公式本文は未確認) | 🟡 |
| リンク | プロフィール編集の「リンク」から**最大5件**追加できるとされる。最初の1件が表示され、残りはタップで表示 | 🟡 |
| 連絡先(ビジネス) | メール・電話・住所のボタン。**公開したくない情報は表示しない** | ⚪ |
| ハイライト | ストーリーズをプロフィールに固定する機能([13-stories-and-highlights](13-stories-and-highlights.md)) | ⚪ |

自己紹介の型(⚪):

```
1行目: 誰向けに何を発信しているか
2行目: 実績・特徴(数字があれば)
3行目: 更新頻度や投稿の種類
4行目: 行動の案内(例: ▼ 最新情報はリンクから)
```

リンク集サービスや UTM(流入元を計測するためのパラメータ)の付け方は [link-in-bio-and-utm](../01-common/link-in-bio-and-utm.md) を参照してください。

### 4. 安全とプライバシー

1. **2段階認証**を有効にします。認証アプリ方式が推奨です([account-security](../01-common/account-security.md))。
2. **ログイン通知**と「ログインのアクティビティ」を確認し、身に覚えのない端末があればログアウトさせます(⚪)。
3. **コメント・メンション・タグ付け**を誰に許可するか決めます(全員 / フォロー中の人 / なし など ⚪)。
4. **非表示ワード**(不快な語を含むコメントや DM を隠す機能)を設定します([06-engagement](06-engagement.md))。
5. **メッセージの受信設定**を確認します。フォローしていない人からの DM は「リクエスト」に入ります ✅([Overview](https://developers.facebook.com/documentation/instagram-platform/overview.md))。
6. 使っていない連携アプリのアクセスを解除します(⚪)。

### 5. Facebook ページとのリンク(必要な場合のみ)

- API を **Instagram ログイン**または**統合ログイン**で使う場合は Facebook ページは**不要**です ✅。
- API を **Facebook ログイン**で使う場合は、Instagram プロアカウントを **Facebook ページにリンク**する必要があります ✅([Overview](https://developers.facebook.com/documentation/instagram-platform/overview.md))。
- Meta Business Suite で投稿予約や受信箱をまとめたい場合もリンクすると便利です(⚪)。Facebook 側の手順は [08-facebook/01](../08-facebook/01-setup-and-posting.md)。

## 具体例

**良い例(地域のパン屋のビジネスアカウント)**

```
名前: ○○ベーカリー|△△駅のパン屋
自己紹介:
毎朝7時に焼き上がり。季節のパンを週替わりで紹介
定休日: 火曜
▼ 今週のメニューと地図はリンクから
```

**避けたい例**: 「よろしくお願いします🙏」だけの自己紹介。何のアカウントか分からず、フォローする理由が伝わりません。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 個人のメールで登録し、担当交代で引き継げない | 運用専用メールに変更し、復旧用の連絡先を最新にする |
| ユーザーネームを何度も変えて、名刺やチラシの URL が切れた | 変更は最小限に。印刷物には QR コードとユーザーネームを併記し、変更時は差し替え |
| 非公開のままプロアカウントに切り替えて驚いた | 切り替えると公開になる点を事前に確認する(🟡) |
| ビジネスアカウントで自宅の住所が表示された | プロフィール編集で連絡先の表示をオフにする |
| 2段階認証を設定せず乗っ取られた | 認証アプリ方式で設定し、バックアップコードを安全な場所に保管 |

## 注意点

- 画面の名称やメニューの位置はアプリの更新で頻繁に変わります(⚪)。見つからないときは設定画面の検索欄を使います。
- 年齢・地域によって使える機能が異なります。10代向けアカウントには保護設定が自動適用される場合があります(⚪ 要確認)。
- 複数人で運用する場合はパスワードを共有せず、Meta Business Suite の権限機能を使います([08-facebook/01](../08-facebook/01-setup-and-posting.md))。

# Instagram 運用チェックリスト

> **このページで分かること**: 初期設定・投稿前・投稿後・週次・月次・トラブル時に確認する項目の一覧。各項目の詳しい説明はリンク先のページにあります。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [README](README.md)

## 概要

チェックリストは「毎回考えなくても品質をそろえる」ための道具です。印刷したり、メモアプリにコピーしたりして使ってください。数値の確度は各リンク先のページに書いてあります。

## 用語

| 用語 | 意味 |
|---|---|
| 安全領域 | 切り抜きやボタンで隠れない画像の中央部分 |
| 代替テキスト | 画像の内容を説明する文字([05-alt-text](05-alt-text.md)) |
| タイアップ投稿ラベル | 企業案件であることを示す表示 |
| AI 情報ラベル | AI で生成・編集した内容であることを示す表示 |

## 初期設定

- [ ] 運用専用メールで登録し、ユーザーネームを決めた([01-account-setup](01-account-setup.md))
- [ ] プロアカウントに切り替え、カテゴリと連絡先の表示を確認([01-account-setup](01-account-setup.md))
- [ ] 2段階認証、ログイン通知
- [ ] プロフィール画像(円形に切り抜かれる)、bio、リンク
- [ ] ハイライトの整備(はじめに/シリーズ別)([13-stories-and-highlights](13-stories-and-highlights.md))
- [ ] コメントの非表示ワード登録([06-engagement](06-engagement.md))
- [ ] コメント・タグ付け・DM の受信範囲を決めた
- [ ] 投稿の柱(2〜4テーマ)と週の投稿計画を決めた([09-tips](09-tips.md))

## 投稿前

- [ ] 比率は 4:5 または 1:1([03-media-specs](03-media-specs.md))
- [ ] カルーセルは全枚数を同じ比率に(1枚目の比率に合わせて切り抜かれる ✅)
- [ ] 1枚目で結論または問い
- [ ] 重要な文字は安全領域(中央80%)
- [ ] 代替テキストを各画像に([05-alt-text](05-alt-text.md))
- [ ] 事実・固有名詞・日付の表記を確認
- [ ] ハッシュタグは少数に絞る(5個以内 🟡)([04-text-hashtags](04-text-hashtags.md))
- [ ] AI 生成画像は明記([ai-usage-policy](../01-common/ai-usage-policy.md))
- [ ] 広告・PR 表記の要否
- [ ] 第三者の顔・個人情報・位置情報が写り込んでいない([privacy-and-personal-info](../01-common/privacy-and-personal-info.md))
- [ ] 音源・素材の権利を確認([music-and-licensing](../01-common/music-and-licensing.md))

### リールの追加項目

- [ ] 9:16 で書き出し、冒頭1〜3秒で内容が分かる([12-reels](12-reels.md))
- [ ] 字幕・テロップを中央寄りに
- [ ] カバー画像の重要要素は中央(中央の 9:16 / 1:1 が使われる ✅)

### ストーリーズの追加項目

- [ ] 文字は上下の端を避けた([13-stories-and-highlights](13-stories-and-highlights.md))
- [ ] リンクスタンプにはリンク先の説明を添えた
- [ ] 現在地が分かる投稿は時間をずらす

## 投稿後

- [ ] 最初の1時間にコメントへ返信
- [ ] 保存・シェアを記録
- [ ] ストーリーズで告知・質問スタンプ
- [ ] 誤りに気づいたらキャプションで訂正を明記

## 週次・月次

- [ ] [週次レビュー](../../templates/weekly-review.md)
- [ ] 週1回、閲覧数・保存・シェア・フォローを記録し、当たり投稿の型を確認([08-analytics](08-analytics.md))
- [ ] 週1回、DM のリクエストフォルダを確認
- [ ] 月1回、ハッシュタグの入れ替え
- [ ] ハイライトの更新(古い価格・終了したイベントを削除)
- [ ] 月1回、インサイトの数字を長期保存用に記録(データは最大2年 ✅)
- [ ] 月1回、規約・収益化条件の変更を確認([10-policies](10-policies.md)、[07-monetization](07-monetization.md))
- [ ] 月1回、連携アプリとログイン中の端末を棚卸し

## トラブル時

- [ ] 違反通知のスクリーンショットと日時を記録([10-policies](10-policies.md))
- [ ] アカウントステータスで理由を確認し、必要なら異議申し立て
- [ ] 乗っ取りの疑いがあればパスワード変更・ログアウト・2段階認証の再設定([account-security](../01-common/account-security.md))
- [ ] 炎上時は [crisis-response](../01-common/crisis-response.md) の手順へ

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| チェックリストが長すぎて使わなくなった | 「投稿前」だけを毎回使い、他は週次・月次に回す |
| 項目を確認したつもりで漏れた | 投稿前にスマートフォンで実物を表示して確認する |

## 注意点

- 項目はアプリの仕様変更で古くなることがあります。月1回見直してください。

# Instagram インサイト（分析）

共通: [analytics-kpi](../01-common/analytics-kpi.md)

## 見る場所

- プロアカウントのプロフィール画面 →「インサイト」⚪
- 各投稿の下の「インサイトを見る」

## 主な指標

| 指標 | 意味 | 使い方 |
|---|---|---|
| リーチ | 見たユニークアカウント数 | 広がり |
| インプレッション/表示回数 | 総表示回数（名称・定義が変更される場合あり） | 露出量 |
| 保存 | 保存数 | 有益性 |
| シェア | 共有数 | 拡散 |
| プロフィールへのアクセス | | 興味 |
| フォロワー増減 | | 成長 |
| 視聴維持率（リール） | どこまで見られたか | 動画構成の改善 |

## 見方のコツ

- 保存・シェアの比率が高い形式を増やす。
- リールは冒頭の離脱が多ければ最初の3秒を作り直す。
- 時間帯別のフォロワーのアクティブ時間を確認。

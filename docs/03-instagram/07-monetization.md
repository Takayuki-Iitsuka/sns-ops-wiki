# Instagram の収益化

> **このページで分かること**: Instagram で収益を得る主な方法(ギフト、サブスクリプション、ボーナス、ブランドコンテンツ、アフィリエイト・物販)と、条件の確認方法・始める手順。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [01-account-setup](01-account-setup.md)、[monetization-comparison](../01-common/monetization-comparison.md)

> **条件の数値は資料により不一致**。公式(Meta クリエイター向け、Instagram ヘルプ)で確認 (#2, #3)。

## 概要

Instagram の収益は、大きく3つの出どころに分けられます(⚪ 整理の仕方)。

| 出どころ | 例 |
|---|---|
| **ファンから** | ギフト(投げ銭)、サブスクリプション(月額課金) |
| **Meta から** | ボーナス(招待制) |
| **企業・自分の商品から** | ブランドコンテンツ(企業案件)、アフィリエイト、自社商品の販売 |

初心者がまず知っておくべきことは、**Meta の収益化機能は「プロアカウント」「年齢」「国」「ポリシー遵守」などの条件があり、招待制のものもある**という点です。フォロワーが少ないうちは、**自分の商品・サービスへの誘導**や**企業案件**の方が現実的な場合が多いです(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| Gifts(ギフト) | 視聴者が Stars(スター、有料の仮想アイテム)を購入してリールに贈る仕組み |
| Subscriptions(サブスクリプション) | 月額料金を払ったファンに限定コンテンツを提供する仕組み |
| bonus(ボーナス) | Meta が成果に応じて支払う招待制のプログラム |
| branded content(ブランドコンテンツ) | 企業から対価を受けて作る投稿。「タイアップ投稿」ラベルを付ける |
| partnership ads(パートナーシップ広告) | クリエイターの投稿を企業が広告として配信する形式 |
| Partner Monetization Policies(パートナー収益化ポリシー) | 収益化機能を使う人が守るべき Meta のルール |
| Professional Dashboard(プロフェッショナルダッシュボード) | プロアカウント向けの管理画面。収益化の資格もここで確認する |

## 手順 / 仕様

### 手段と条件(🟡 二次資料)

| 手段 | 概要 | 報告されている条件 | 日本 |
|---|---|---|---|
| Gifts(ギフト) | リールで視聴者から投げ銭 | プロアカウント、18歳以上、規約遵守、フォロワー数は 500 / 1,000 / 5,000 と資料により不一致 | 対応との資料あり |
| Subscriptions(サブスクリプション) | 月額課金で限定コンテンツ | 10,000フォロワー以上とする資料あり | 対応との資料あり |
| ボーナス | 年末ボーナス等 | 招待制との情報 | 日本含むとの資料あり |
| ブランドコンテンツ | 企業案件 | 広告表記必須 | — |
| アフィリエイト・物販 | 外部誘導 | ステマ規制 | — |

### Meta の公式ブログで確認できた内容(✅、2023年(皇紀2683年・令和5年)11月6日付の記事)

| 項目 | 記載内容 | 出典 |
|---|---|---|
| ギフトの対象国 | **日本を含む**国々に拡大 | [Meta for Creators](https://creators.facebook.com/giving-more-creators-around-the-world-ways-to-earn-money) |
| ギフトの条件 | プロアカウント、**18歳以上**、パートナー収益化ポリシーを満たす、**フォロワー5,000人以上** | 同上 |
| ボーナス | 招待制。**日本では「年末ボーナス」**の名称でテスト(米国・韓国・日本) | 同上 |
| サブスクリプションの手数料 | Meta はクリエイターの手数料を**免除**(変更時は6か月前に通知) | 同上 |
| プロフィール広告 | 日本を含む国で、プロフィールの広告枠から収益を得るテスト(招待制) | 同上 |

> ⚠️ この記事は2023年時点の内容です。一方、Instagram ヘルプの検索要約には「ギフトはフォロワー500人以上」とする記載があり(🟡 [ヘルプ](https://help.instagram.com/738469380549477))、**現在の条件は一致していません**(#2)。**必ずアプリのプロフェッショナルダッシュボードで自分の資格を確認**してください。

### 自分の資格を確認する手順(⚪ メニュー名は変わる可能性)

1. プロアカウントのプロフィールで「プロフェッショナルダッシュボード」を開きます。
2. 「収益化」または「収益化のステータス」を開きます。
3. 各機能(ギフト、サブスクリプションなど)の利用可否と、満たしていない条件が表示されます。
4. 利用できる機能は、案内に従って**支払い用の口座(受取口座)**と税務情報を登録します。

関連する公式ヘルプ(🟡 本文未取得): [収益化ツールの資格要件](https://help.instagram.com/427415519366046)、[パートナー収益化ポリシー](https://help.instagram.com/512371932629820)、[サブスクリプションについて](https://help.instagram.com/856296695055001)。

### ブランドコンテンツ(企業案件)の進め方

1. 契約前に、報酬・納品物・修正回数・二次利用(広告配信の可否)を書面で決めます([sponsorship-and-media-kit](../30-strategy/07-sponsorship-and-media-kit.md))。
2. 投稿時に**「タイアップ投稿」(Paid partnership)ラベル**を付け、企業のアカウントをタグ付けします ✅([Meta for Creators](https://creators.facebook.com/earn-money/earn-from-brands/))。
3. 本文にも「PR」「広告」などを明記します。日本では**ステルスマーケティングは景品表示法違反**です(2023年10月1日から)✅([legal-compliance](../01-common/legal-compliance.md))。
4. 企業が投稿を広告として配信する場合は**パートナーシップ広告**になり、「広告」ラベルで表示されます ✅。追加の利用料を交渉できます。
5. 外部ツールから投稿する場合は API の `is_paid_partnership` を使います ✅([20-api/03-instagram-graph-api](../20-api/03-instagram-graph-api.md))。

### アフィリエイト・物販

- 外部のアフィリエイトや自社 EC へは、プロフィールのリンクやストーリーズのリンクスタンプから誘導します([link-in-bio-and-utm](../01-common/link-in-bio-and-utm.md))。
- Instagram 独自のアフィリエイト機能の日本での条件は未確認です(🟡 #53)。
- 詳しくは [10-creator-economy/04-affiliate](../10-creator-economy/04-affiliate.md)。

## 必ず確認すること

1. 現在の地域(日本)で機能が提供されているか。
2. 年齢・フォロワー数・アカウント種別(プロアカウントのみ等)。
3. 収益の支払い方法・税務書類。
4. コンテンツ・収益化ポリシー(オリジナル性、再投稿の扱い等)。

## 具体例

| アカウントの段階(⚪) | 現実的な収益の柱 |
|---|---|
| フォロワー数百人 | 自分の商品・サービス(教室、ハンドメイド品、店舗への来店)への誘導 |
| 数千人 | 上記+小規模な企業案件、アフィリエイト |
| 1万人前後〜 | 上記+ギフト・サブスクリプション(条件を満たせば) |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 「収益化の招待」を名乗る DM のリンクを開いた | 招待はアプリ内の正式な画面で届く。DM のリンクは開かない([account-security](../01-common/account-security.md)) |
| 案件で「PR」表記を忘れた | タイアップ投稿ラベル+本文表記。ステマは法律違反 |
| 他人の動画を再投稿して収益化を狙った | オリジナルでない内容は収益化の対象外になり得る(⚪)。自分の素材で作る |
| 二次資料の条件を信じて準備したが対象外だった | ダッシュボードで自分の資格を確認する |
| 受取口座や税務情報を後回しにした | 支払いが保留になる場合がある(⚪)。早めに登録 |

## 注意点

- 他人の動画の転載は収益化対象外となる可能性が高い ⚪。
- 案件は [legal-compliance](../01-common/legal-compliance.md) の広告表記を遵守。
- 収益は所得になります。確定申告などは [tax-and-business](../30-strategy/04-tax-and-business.md) を参照してください。
- 料金・手数料は変更されることがあります。公式の最新情報を確認します。

# Instagram のコメント運用

共通方針: [comments-and-engagement](../01-common/comments-and-engagement.md)

## 機能

| 機能 | 使い方 |
|---|---|
| コメント返信 | 通知から返信。ピン留めで良いコメントを上部に ⚪ |
| 非表示ワード | NG ワードを登録して自動非表示 |
| コメント制限 | 特定の相手のコメントを自分以外に非表示 |
| 制限（Restrict） | 相手に気づかれずに制限 |
| DM | 個別連絡。メッセージリクエストの扱い |
| ストーリーズの質問スタンプ | 回答を次の投稿のネタに |
| コラボ投稿 | 共同投稿者として両方のフィードに表示 ⚪ |

## コツ

- 投稿直後にコメントへ返信。質問で終えると会話が続く。
- DM は営業一斉送信を避ける。
- ネガティブなコメントは事実確認後に簡潔に。感情的反論は避ける。

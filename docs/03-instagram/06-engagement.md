# Instagram のコメント運用

> **このページで分かること**: コメントへの返信・非表示・削除、迷惑な相手への対処(制限・ブロック)、DM(ダイレクトメッセージ)の受信箱の仕組み、コメントへの自動返信の注意点。
>
> **対象**: 初心者  **先に読むページ**: [comments-and-engagement](../01-common/comments-and-engagement.md)

共通方針: [comments-and-engagement](../01-common/comments-and-engagement.md)

## 概要

コメントや DM は、フォロワーと関係を作る大切な場所です。一方で、スパムや心ない言葉が届くこともあります。初心者は次の2つを最初に決めておくと迷いません。

1. **返信のルール**: いつ・誰が・どこまで返すか
2. **守りのルール**: 非表示ワード、制限、ブロック、通報をどの場面で使うか

## 用語

| 用語 | 意味 |
|---|---|
| DM / Direct Message(ダイレクトメッセージ) | 1対1またはグループでやり取りする非公開のメッセージ |
| message request(メッセージリクエスト) | フォローしていない相手からの DM が入る場所 |
| Hidden Words(非表示ワード) | 指定した語を含むコメントや DM を自動で隠す機能 |
| Restrict(制限) | 相手に通知せず、その人のコメントを本人と相手以外に見えなくする機能 |
| Block(ブロック) | 相手が自分のプロフィールや投稿を見たり連絡したりできないようにする機能 |
| pin(ピン留め) | 選んだコメントを一番上に固定する機能 |
| private reply(プライベート返信) | コメントした人へ DM で個別に返信する仕組み |

## 手順 / 仕様

### 機能

| 機能 | 使い方 |
|---|---|
| コメント返信 | 通知から返信。ピン留めで良いコメントを上部に ⚪ |
| 非表示ワード | NG ワードを登録して自動非表示 |
| コメント制限 | 特定の相手のコメントを自分以外に非表示 |
| 制限(Restrict) | 相手に気づかれずに制限 |
| DM | 個別連絡。メッセージリクエストの扱い |
| ストーリーズの質問スタンプ | 回答を次の投稿のネタに |
| コラボ投稿 | 共同投稿者として両方のフィードに表示 ⚪ |

### 公式文書で確認できた仕組み(API)

| 項目 | 内容 | 確度 | 出典 |
|---|---|---|---|
| コメント管理でできること | 取得・返信・削除・**非表示/再表示**・投稿ごとの**コメント欄のオン/オフ** | ✅ | [Comment Moderation](https://developers.facebook.com/documentation/instagram-platform/comment-moderation.md) |
| プライベート返信 | コメントした人へ**1通だけ**、コメントから**7日以内**に DM を送れる(ライブは配信中のみ) | ✅ | [Private Replies](https://developers.facebook.com/documentation/instagram-platform/private-replies.md) |
| プライベート返信の届き先 | 相手がフォローしていれば受信箱、していなければ**リクエスト**フォルダ | ✅ | 同上 |
| DM の受信箱 | **メイン・一般・リクエスト**に分かれる。フォロワーからの新しい会話は既定でメインに入る | ✅ | [Overview](https://developers.facebook.com/documentation/instagram-platform/overview.md) |

### コメントに返信する手順(アプリ ⚪)

1. 通知(ハートのアイコン)またはプロフィールの投稿を開きます。
2. コメントの下の「返信する」をタップし、返信を書きます。相手のユーザーネームが自動で入ります。
3. 良い質問や役立つ補足は、コメントを長押し(または左にスワイプ)して**ピン留め**します(⚪)。

### 迷惑なコメントへの対処(段階別 ⚪)

| 段階 | 状況 | 対応 |
|---|---|---|
| 1 | 特定の語を含むスパム | **非表示ワード**に登録(設定 →「プライバシー設定」→「非表示ワード」など) |
| 2 | 同じ人がしつこく否定的なコメント | **制限**: 相手に通知されず、コメントが他の人に見えなくなる |
| 3 | 嫌がらせ・なりすまし | **ブロック**し、必要なら**報告(通報)** |
| 4 | 脅迫・個人情報の暴露 | 画面を保存して記録し、通報。必要に応じて警察・専門家へ相談([crisis-response](../01-common/crisis-response.md)) |

一時的にコメントが殺到した場合は、投稿ごとに**コメントをオフ**にするか、コメントできる人を絞ります(⚪)。

### DM の運用

1. **リクエスト**フォルダも定期的に確認します。取引の問い合わせが入っていることがあります。
2. よくある質問は、保存済みの返信やよくある質問の設定で効率化します(⚪)。
3. 営業目的の一斉送信はしません。スパム扱いや制限の原因になり得ます(⚪)。
4. お金・個人情報・パスワードを求める DM には応じません。公式を名乗る DM も、まず本物か確認します([account-security](../01-common/account-security.md))。

### コメントへの自動返信を使う場合

- 「コメントで『レシピ』と書いた人に DM でリンクを送る」といった仕組みは、API のプライベート返信で作れます ✅。
- **1人1通・7日以内**の制限があります ✅。
- 相手が求めていない DM を送らないよう、投稿で仕組みを明示します(⚪)。

## 具体例

**良い返信(料理アカウント)**

> コメント: 「卵がうまく巻けません…」
> 返信: 「ありがとうございます!火を少し弱めて、半熟のうちに巻くと失敗しにくいです。次のリールで手元を詳しく撮りますね」

**避けたい返信**: 「動画をよく見てください」だけ。冷たく受け取られやすく、会話が止まります。

**否定的なコメントへの返信の型(⚪)**

1. 事実を確認する(本当に誤りがあるか)
2. 誤りなら認めて訂正する(キャプションに追記)
3. 意見の違いなら、感謝と自分の考えを短く書く
4. 攻撃的な相手とは議論しない(制限・非表示を使う)

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| リクエストフォルダに仕事の依頼が埋もれていた | 週1回はリクエストを確認する |
| 否定的なコメントに感情的に反論し、炎上した | 一晩置いてから返信。事実確認と訂正を優先 |
| 自動返信の DM がスパム扱いされた | 求めた人だけに送る。1人1通・7日以内の制限を守る ✅ |
| 非表示ワードを設定せず、同じスパムが毎日届く | よく来る語を非表示ワードに登録 |
| 返信を後回しにして数週間放置 | 返信の時間帯を決める(例: 投稿後1時間と夜に1回) |

## 注意点

- 返信の早さが表示に影響するかは公式に確認できていません(⚪)。**無理のない頻度**で続けます。
- DM のスクリーンショットを公開する場合は、相手の許可を取り、名前やアイコンを隠します([privacy-and-personal-info](../01-common/privacy-and-personal-info.md))。
- コミュニティ運営の考え方は [community-management](../01-common/community-management.md) も参照してください。

## チェックリスト

- [ ] 返信のルール(時間帯・担当)を決めた
- [ ] 非表示ワードを登録した
- [ ] 制限・ブロック・通報の使い分けを決めた
- [ ] DM のリクエストフォルダを定期確認している
- [ ] 自動返信を使う場合、1人1通・7日以内の制限を理解した

## コツ

- 投稿直後にコメントへ返信。質問で終えると会話が続く。
- DM は営業一斉送信を避ける。
- ネガティブなコメントは事実確認後に簡潔に。感情的反論は避ける。

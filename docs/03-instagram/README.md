# Instagram

写真・動画によるビジュアル訴求が中心。世界観づくり、商品・サービスの見せ方、ファン形成に向く(⚪)。

> **このページで分かること**: Instagram の特徴、初心者が読む順番、各ページの内容。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[サービスの選び方](../01-common/choosing-platforms.md)

## 概要

Instagram は Meta が運営する、写真と動画を中心にした SNS です。フィード(写真・カルーセル)、リール(縦型短尺動画)、ストーリーズ(24時間で消える投稿)など、目的の違う形式を組み合わせて使います。

分析(インサイト)や API 連携、収益化の多くは**プロフェッショナルアカウント**が前提です ✅([Overview](https://developers.facebook.com/documentation/instagram-platform/overview.md))。最初に切り替えておくと後から困りません。

## 特徴

| 項目 | 内容 |
|---|---|
| 主な形式 | フィード(写真・カルーセル)、リール(縦型短尺動画)、ストーリーズ(24時間)、ライブ |
| 強み | ビジュアル、保存・共有、ショッピング連携 |
| 弱み | 投稿内リンクの制約、制作コスト、アルゴリズムの変動 |
| 向く用途 | ブランディング、商品訴求、ファン化 |

## 用語

| 用語 | 意味 |
|---|---|
| フィード | プロフィールに残る通常の投稿 |
| カルーセル | 複数の画像・動画をスワイプで見せる投稿(最大20件 ✅ API) |
| リール | 縦型の短尺動画 |
| ストーリーズ | 24時間で消える投稿 ✅ |
| ハイライト | ストーリーズをプロフィールに残す機能 |
| インサイト | プロアカウント向けの分析機能 |

用語の詳しい説明は [basic-terms-explained](../01-common/basic-terms-explained.md) と [glossary](../00-meta/glossary.md) を参照してください。

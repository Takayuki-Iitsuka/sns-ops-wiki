# Instagram での古事記・日本書紀の発信設計

テーマ全体は [05-theme-kojiki](../05-theme-kojiki/README.md)。

## Instagram の役割

**ビジュアルの世界観と保存される資料**。図解・カルーセルで「見返す価値」を作り、ハイライトを辞典として整える。

## 形式の割り当て

| 柱 | 形式 | 構成の要点 |
|---|---|---|
| 物語のあらすじ | カルーセル(8〜10枚) | 1枚目に問い、4コマ、書紀の違い、まとめ |
| 神名・用語辞典 | 単枚/カルーセル | 神名(大)・読み・一言・典拠 |
| 古事記 vs 書紀 | カルーセル | 左右比較、色と記号で区別 |
| 原文を読む | カルーセル | 白文→訓読→語釈 |
| 系譜 | 単枚 | 家系図は文字を大きく |
| 地名・神社 | 写真＋キャプション | 撮影・掲載ルールを確認 |
| 暦と行事 | ストーリーズ＋フィード | 前日予告・当日 |
| 学びの記録 | ストーリーズ | 質問スタンプ |

## ハイライト構成(案)

「はじめに」「神名辞典」「古事記 vs 書紀」「暦と記紀」「FAQ」「note」。

## 画像サイズの具体案(⚪、公式の許容範囲内)

| 型 | サイズ | 備考 |
|---|---|---|
| カルーセル(縦長) | 1080×1350(4:5) | 公式の範囲内 🟡 |

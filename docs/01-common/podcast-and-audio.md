# ポッドキャスト・音声配信

> **このページで分かること**: ポッドキャスト(音声番組)の仕組み(RSS・ホスティング)、Spotify・YouTube での配信、収録機材と録音のコツ、編集・公開の手順、権利の注意。
>
> **対象**: 初心者  **先に読むページ**: [video-basics](video-basics.md)

## 概要

ポッドキャストは、**通勤・家事・運動中など「ながら」で聞かれる**音声番組です。顔を出さずに続けられ、話し手の人柄や専門性が伝わりやすい形式です。一度作った回が長く聞かれ続けることも多く、SNS の短い投稿とは違う「深い関係」を作れます(⚪)。

最近は、音声だけでなく**動画付きのポッドキャスト**(ビデオポッドキャスト)も増えています。YouTube でもポッドキャストを扱えるようになり、音声番組と動画の境目は小さくなっています。

## 用語

| 用語 | 意味 |
|---|---|
| podcast(ポッドキャスト) | 定期的に配信される音声(または動画)番組 |
| episode(エピソード) | 番組の1回分 |
| RSS feed(RSS フィード) | 番組の情報とエピソードの一覧を配信するデータ。各アプリはこれを読み込む |
| hosting(ホスティング) | 音声ファイルと RSS を置いておくサービス |
| distribution(配信先) | Spotify、Apple Podcasts、YouTube など、リスナーが聞くアプリ |
| cover art(カバーアート) | 番組の正方形の画像 |
| show notes(ショーノート) | エピソードの説明文(話題・リンク・出典) |
| loudness(ラウドネス) | 聞こえ方の音量の大きさ。回ごとにそろえる |
| dynamic mic / condenser mic | ダイナミックマイク(周囲の音を拾いにくい)/ コンデンサーマイク(繊細に拾う) |

## 仕組み: ホスティングと配信先

```
録音・編集 → ホスティング(音声ファイル+RSS) → 各アプリ(Spotify、Apple Podcasts、YouTube など)
```

1. ホスティングサービスに音声をアップロードすると、**RSS フィード**が作られる。
2. 各アプリに RSS を登録(提出)すると、新しいエピソードが自動で反映される。
3. ホスティングを変えても、RSS の引っ越し手続きでリスナーを引き継げる場合が多い(⚪)。

## 主な配信先

| 配信先 | 特徴 | 確度 |
|---|---|---|
| Spotify(Spotify for Creators) | ホスティング機能あり。動画ポッドキャストにも対応。収益化は Spotify Partner Program(18歳以上・対象国・Spotify Payouts アカウントなど) | 🟡 Spotify の規約(検索要約) |
| YouTube | 再生リストをポッドキャストとして設定、または **RSS フィードを提出**して取り込む | ✅(RSS) / 🟡(再生リスト) |
| Apple Podcasts | RSS を提出して配信 | ⚪ |
| その他のアプリ | RSS を読み込むアプリ各種 | ⚪ |

### YouTube に RSS フィードを提出する(✅ YouTube ヘルプ)

1. YouTube Studio の[コンテンツ]>[ポッドキャスト]を開く。
2. ポッドキャストの[詳細]から、RSS の設定で RSS フィードを接続する。
3. フィードのメールアドレスに届く**確認コード**で所有権を確認する(アドレスが分からなければホスティング事業者に問い合わせる)。
4. 各エピソードは、カバーアートを静止画にした動画として作られ、**最初は非公開**でアップロードされる。確認してから公開する。

| 注意点(✅) | 内容 |
|---|---|
| 広告 | ポッドキャストのコンテンツに広告を含めることはできない。ブランドコンテンツ・スポンサー(話し手が読む宣伝を含む)は**開示が必要** |
| 音声の差し替え | 公開後に音声は更新できない。差し替えると新しい動画が作られ、古い動画は非公開になる |
| 削除 | YouTube で動画を削除してもフィードから消えず、再アップロードされる。フィード側でも削除する |
| 表示先 | YouTube と YouTube Music のみ |
| 文字 | タイトル・説明に `<` `>` や HTML は使えない |
| 対応地域 | RSS の取り込みは一部の国・地域のみ(⚪ 日本の対象は要確認) |

## 収録機材(⚪ 一般的な目安)

| 段階 | 機材 | ポイント |
|---|---|---|
| まず始める | スマホ+イヤホンマイク | 静かな部屋、口元から一定の距離 |
| 少し整える | USB マイク(パソコンに直接つなぐ) | ダイナミック型は生活音を拾いにくい |
| 本格的に | XLR マイク+オーディオインターフェース | 複数人の収録、音質の調整がしやすい |
| あると良い | ポップガード、マイクスタンド、密閉型ヘッドホン | 破裂音・振動・音漏れを防ぐ |

## 録音のコツ

1. **部屋を選ぶ**: 布の多い部屋(カーテン・クローゼット)は反響が少ない。
2. **距離を一定に**: マイクと口の距離を拳1〜2個分に保つ(⚪)。
3. **試し録り**: 30秒録って聞き、音量・雑音を確認。
4. **予備の録音**: 大事な回はスマホでも同時に録る。
5. **遠隔の対談**: 各自が手元で録音し、後で合わせると音質が良い(⚪)。相手に録音・公開の同意を取る。

## 編集と公開の手順

1. 不要な部分(長い沈黙、言い直し)を切る。切りすぎると不自然になる。
2. **音量をそろえる**(回ごと・話者ごと)。
3. 冒頭に番組名と今回の内容(30秒以内 ⚪)。
4. ショーノートを書く: 話題の目次、時間、紹介したリンク、出典。
5. カバーアートを用意(正方形。サイズは各サービスの指定を確認 ⚪)。
6. ホスティングにアップロードし、配信日時を設定。
7. SNS で告知(音声の一部を切り出した短い動画+字幕が効果的 ⚪)。

## 多言語への展開

- YouTube の**自動吹き替え**は、元の言語が日本語の場合は**英語のみ**に対応(✅)。120分を超える動画、音楽のみの動画などは対象外(✅)。公開前に確認できる設定がある(✅)。
- 詳しくは [multilingual-and-global](multilingual-and-global.md)。

## 具体例: 番組の企画

| 項目 | 例(料理アカウント) |
|---|---|
| 番組名 | 「週末の作り置きラジオ」 |
| 1回の長さ | 15〜20分 |
| 頻度 | 隔週 |
| 構成 | オープニング → 今週の1品 → リスナーの質問 → 次回予告 |
| SNS との連携 | 回の要点を Instagram のカルーセルに、質問は X や Threads で募集 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 生活音・エアコンの音が入る | 録音中は家電を止め、ダイナミックマイクを使う |
| 回ごとに音量が違う | 編集で音量をそろえる工程を手順に入れる |
| 有名な曲をオープニングに使った | 権利を確認した音源か自作の音にする([music-and-licensing](music-and-licensing.md)) |
| ゲストの同意を取らずに公開した | 収録前に公開範囲・編集の扱いを確認する |
| 配信先ごとに手作業でアップロードして混乱 | ホスティング+RSS で一元化する |
| スポンサーの紹介を開示しなかった | 番組内と説明文で明示する([legal-compliance](legal-compliance.md)) |

# 収益化手段の比較

> **このページで分かること**: SNS で収入を得る方法の全体像(プラットフォームからの分配、投げ銭、月額課金、自分で売る、案件)と、選び方・注意点。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[monetization-roadmap](../30-strategy/03-monetization-roadmap.md)

> **条件・手数料は頻繁に変わります。数値は 🟡/⚪ です。必ず公式で確認してください**(→ [要検証リスト](../00-meta/verification-queue.md))。

## 概要

SNS の収益化は、大きく次の3つに分かれます。

1. **プラットフォームからもらう**: 広告収益の分配、投げ銭(ギフト)、月額課金(サブスクリプション)。条件(フォロワー数・視聴時間など)を満たして申請する。
2. **自分で売る**: 有料記事、デジタル商品、グッズ、電子書籍、講座。SNS は「知ってもらう場所」、販売は別の場所で行う。
3. **企業から受け取る**: 案件(タイアップ)、アフィリエイト。広告表記が必須。

初心者がつまずきやすいのは「フォロワーが増えれば自動的に収入になる」と考えることです。実際には、**条件を満たして申請し、審査に通り、規約を守り続ける**必要があり、金額も月ごとに大きく変動します。最初は1つの手段に絞り、小さく試すのがおすすめです。

## 用語

| 用語 | 意味 |
|---|---|
| revenue share(収益分配) | 広告収益などをプラットフォームとクリエイターで分ける仕組み |
| tipping / gifts(投げ銭、ギフト) | 視聴者がその場で送るお金・アイテム。例: YouTube の Super Chat |
| subscription / membership(月額課金、メンバーシップ) | 毎月定額で支援・限定コンテンツを受け取る仕組み |
| affiliate(アフィリエイト、成果報酬型広告) | 紹介リンク経由の購入などに応じて報酬を得る |
| sponsorship(案件、タイアップ) | 企業から依頼・報酬を受けて行う投稿 |
| YPP(YouTube パートナープログラム) | YouTube の収益化プログラム |

## 共通の注意

1. 収益化は**プログラムの利用条件**(フォロワー数、視聴時間、年齢、地域、規約遵守)を満たした上での申請が必要。
2. **案件・アフィリエイトは広告表記が必須**。[legal-compliance](legal-compliance.md)
3. 税務: 継続的な収益は所得として申告対象。[tax-and-business](../30-strategy/04-tax-and-business.md)
4. 収益は変動する。**資産(読者・メールリスト・自サイト・電子書籍)**を持つ。
5. 自動化・API 利用は規約と費用を確認。[20-api](../20-api/README.md)

## 選び方の目安(⚪)

| 目的 | 向く場所 |
|---|---|
| 認知・拡散 | X、Instagram、TikTok、Threads、YouTube Shorts |
| 検索・資産性 | YouTube(長尺)、note、Web |
| 世界観・ビジュアル | Instagram、Pinterest |
| 深い解説・有料コンテンツ | note、KDP、YouTube |
| ファン化・継続課金 | note メンバーシップ、FANBOX、Fantia、YouTube メンバーシップ |
| 確実な連絡 | LINE 公式アカウント、メール |

## 始め方の手順(⚪ 一般的な進め方)

1. **目的を決める**: 「月に○円」より先に、「誰に何を届けて対価をもらうか」を1文で書く。
2. **今の規模で使える手段を選ぶ**: フォロワー条件がない手段(有料記事、デジタル商品、アフィリエイト)から始めると、規模が小さくても試せる。
3. **公式の条件を確認する**: 各サービスの収益化ページで、年齢・地域・条件を確認し、確認日をメモする。
4. **小さく出す**: 価格を低めに、1商品・1企画から。
5. **記録する**: 売上、手数料、経費を台帳に残す(確定申告で必要)。
6. **見直す**: 3か月ごとに、手間に対する収益を比べて続けるか判断する。

## 具体例(汎用)

| アカウントの例 | 最初の一手 | 次の一手 |
|---|---|---|
| 料理アカウント | レシピをまとめた有料記事(note) | メンバーシップで月替わりの献立 |
| イラストアカウント | 壁紙・素材のデジタル販売(BOOTH など) | 継続支援(FANBOX など)、グッズ |
| 地域の店 | LINE 公式アカウントで来店クーポン | Instagram のショッピング連携(⚪) |
| 解説系の動画 | 説明文でのアフィリエイト(広告表記あり) | YPP、メンバーシップ |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 収益化の条件を古い記事で判断した | 公式ヘルプとアプリ内の表示で確認する |
| 案件の投稿に広告表記を付け忘れた | 依頼を受けた時点で表記の位置を決める([legal-compliance](legal-compliance.md)) |
| 1つの SNS の収益に依存し、仕様変更で激減 | メールリストや自サイトなど、自分で持つ連絡手段を育てる |
| 手数料を差し引いた手取りを計算していなかった | 価格 − 手数料 − 決済手数料 − 経費 で計算する |
| 確定申告の記録がない | 月ごとに売上と経費を記録する |

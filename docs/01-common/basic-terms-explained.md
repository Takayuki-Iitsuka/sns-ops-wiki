# 初心者向け用語解説

> **このページで分かること**: SNS 運用でよく出てくる言葉の意味を、例を交えて説明します。[用語集](../00-meta/glossary.md) が「辞書」なら、このページは「解説書」です。
>
> **対象**: 専門用語が分からず、他のページが読みにくいと感じた人。**先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)

## 概要

SNS 運用の説明には、英語のカタカナ語が多く出てきます。このページでは、よく使う言葉を「投稿」「数字」「画像・動画」「お金」「ルール」「技術」の6つの分野に分けて、**どんな場面で使うか**と一緒に説明します。

表記は「英語(日本語訳)」の順です。サービスによって呼び名が違うものは、その違いも書いています。

## 1. 投稿に関する言葉

| 用語 | 説明 | 例 |
|---|---|---|
| post(投稿、ポスト) | SNS に公開する1件の発信。X では「ポスト」、YouTube では「動画」と呼ぶことが多い | 「今日のポストは画像付きにした」 |
| caption(キャプション) | 画像や動画に添える説明文 | Instagram の写真の下に書く文章 |
| feed(フィード) | 投稿が時系列やおすすめ順に並ぶ画面 | アプリを開くと最初に出る一覧 |
| timeline(タイムライン) | X などで投稿が流れる画面。フィードとほぼ同じ意味 | 「タイムラインに流れてきた」 |
| thread(スレッド) | 複数の投稿をつなげて1つの話にしたもの | 長い説明を5つのポストに分けて連結 |
| carousel(カルーセル) | 複数の画像・動画をスワイプして見せる投稿 | 「手順を10枚のカルーセルにまとめた」 |
| Reels / Shorts(リール / ショート) | 縦型の短い動画。Instagram・Facebook ではリール、YouTube ではショート | 30秒の料理動画 |
| Stories(ストーリーズ) | 一定時間(多くは24時間)で消える投稿 ⚪ | 日常のひとこまを気軽に共有 |
| repost / share(リポスト / 共有) | 他人の投稿を自分のフォロワーに広めること。X ではリポスト(旧リツイート) | 「良い情報だったのでリポストした」 |
| quote(引用) | 他人の投稿に自分のコメントを付けて広めること | 引用ポスト |
| reply(返信) | 投稿へのコメント | 「質問に返信した」 |
| mention(メンション) | `@ユーザー名` で特定の人に呼びかけること。相手に通知が届く | 「@shop_example さんの商品です」 |
| hashtag(ハッシュタグ) | `#` を付けた言葉。同じ話題の投稿をまとめて探せる | `#料理初心者` → [ハッシュタグ](hashtags.md) |
| CTA / call to action(行動喚起) | 読んだ人に次の行動を促す一言 | 「保存して後で見返してね」 |

## 2. 数字(分析)に関する言葉

数字の言葉は、サービスによって定義が少しずつ違います。比べるときは同じサービス内で比べてください。

| 用語 | 説明 | たとえると |
|---|---|---|
| impression(インプレッション、表示回数) | 投稿が画面に表示された回数。同じ人が2回見たら2回 | チラシが目に入った回数 |
| reach(リーチ、到達数) | 投稿を見た人の数(重複を除く) | チラシを見た人数 |
| view(視聴回数、再生回数) | 動画が再生された回数。数え方はサービスごとに異なる | テレビ番組の視聴 |
| engagement(エンゲージメント) | いいね・返信・保存・共有などの反応の合計 | 拍手や質問の数 |
| engagement rate(エンゲージメント率) | 反応数 ÷ 表示回数(またはリーチ) | 見た人のうち拍手した人の割合 |
| save(保存) | 後で見るためにブックマークされた数。「役に立つ」の目安 | 付箋を貼られた数 |
| CTR / click-through rate(クリック率) | リンクやサムネイルが押された割合 | 店の前を通った人のうち入店した割合 |
| watch time(総再生時間) | 動画が見られた時間の合計 | — |
| retention(視聴維持率) | 動画が最後まで(どこまで)見られたか | 映画を途中で帰らなかった人の割合 |
| conversion(コンバージョン、成果) | 購入・登録など、最終的にしてほしい行動 | 来店して買ってくれた |
| KPI(重要業績評価指標) | 目標に近づいているかを測るための数字 | 「月に保存数100」 |

計算例: 表示回数 2,000 回、反応が 60 件なら、エンゲージメント率は 60 ÷ 2,000 = 0.03 = **3%** です。→ [分析・KPI](analytics-kpi.md)

## 3. 画像・動画に関する言葉

| 用語 | 説明 | 例 |
|---|---|---|
| resolution(解像度) | 画像の大きさを縦横のピクセル数で表したもの | 1080×1350 px |
| pixel / px(ピクセル) | 画像を作る最小の点 | — |
| aspect ratio(アスペクト比、縦横比) | 横:縦 の比率 | 1:1 は正方形、4:5 は少し縦長、9:16 はスマホ全画面の縦長 |
| crop(トリミング) | 画像の一部を切り取ること。サービスが自動で切る場合もある | プロフィール画像は円形に切り取られる |
| safe area(安全領域) | 切り取られたり、ボタンや文字に隠れたりしない中央部分 | リールの下部は説明文が重なる |
| thumbnail(サムネイル) | 動画や記事の「表紙」となる小さな画像 | YouTube の一覧に出る画像 |
| alt text(代替テキスト、ALT) | 画像の内容を文字で説明したもの。目の不自由な人の読み上げ機能などで使われる | 「白い皿に盛られたナポリタン」 → [代替テキスト](alt-text.md) |
| JPEG / PNG / WebP | 画像のファイル形式。写真は JPEG、文字や図は PNG が一般的 ⚪ | — |
| MP4 / H.264 | 動画のファイル形式と圧縮方式。多くの SNS で使える形式 | → [動画の基礎](video-basics.md) |
| fps / frame rate(フレームレート) | 1秒あたりのコマ数 | 30fps |
| bitrate(ビットレート) | 1秒あたりのデータ量。高いほど高画質だが容量が増える | — |
| subtitles / captions(字幕) | 動画内の話し言葉を文字にしたもの | 音を出さずに見る人にも伝わる |

詳しい数値は [画像の仕様比較](image-specs-comparison.md)、[動画の仕様比較](video-specs-comparison.md)、[書き出しプリセット](export-presets.md) を見てください。

## 4. お金(収益化)に関する言葉

| 用語 | 説明 |
|---|---|
| monetization(収益化) | 発信からお金を得ること。広告収入、有料会員、販売、案件など |
| revenue sharing(収益分配) | サービスの広告収入などの一部を投稿者に分配する仕組み |
| membership / subscription(メンバーシップ / サブスクリプション) | 月額で支援してもらい、限定コンテンツを届ける仕組み |
| tip / gift(投げ銭 / ギフト) | 視聴者からの一回ごとの支援 |
| affiliate(アフィリエイト、成果報酬型広告) | 紹介した商品が売れると報酬が入る仕組み |
| sponsorship / tie-up(案件 / タイアップ) | 企業から依頼を受けて商品などを紹介すること。**広告表示が必要** |
| media kit(メディアキット) | 案件を受けるための自己紹介資料(実績・数字・料金) |

→ [収益化の比較](monetization-comparison.md)、[案件とメディアキット](../30-strategy/07-sponsorship-and-media-kit.md)

## 5. ルールに関する言葉

| 用語 | 説明 |
|---|---|
| terms of service(利用規約) | サービスを使うための約束事。違反すると投稿削除や停止がある |
| community guidelines(コミュニティガイドライン) | どんな投稿が許されないかを示したルール |
| stealth marketing(ステルスマーケティング、ステマ) | 広告であることを隠した宣伝。日本では景品表示法で規制されている → [法令](legal-compliance.md) |
| copyright(著作権) | 作品を作った人の権利。他人の画像・音楽・文章を無断で使うと侵害になりうる → [画像素材と著作権](image-sources-and-copyright.md) |
| portrait rights(肖像権) | 自分の顔や姿を無断で撮影・公開されない権利 |
| shadowban(シャドウバン) | 通知なく投稿の表示が減ったと利用者が感じる現象を指す俗語。サービスが公式に用いる語とは限らない ⚪ |
| 2FA / two-factor authentication(2段階認証) | パスワードに加えて、もう1つの確認(コードなど)を求める仕組み → [アカウント保護](account-security.md) |

## 6. 技術に関する言葉

| 用語 | 説明 |
|---|---|
| algorithm(アルゴリズム) | どの投稿を誰に見せるかを決める仕組み |
| API(アプリケーション・プログラミング・インターフェース) | プログラムからサービスを操作するための公式の窓口 → [API](../20-api/README.md) |
| scheduled post(予約投稿) | 日時を指定して自動で公開する機能 |
| UTM parameter(UTM パラメータ) | リンクの末尾に付けて、どこから来た人かを計測する文字列 → [リンク設計](link-in-bio-and-utm.md) |
| link in bio(プロフィールのリンク) | プロフィール欄に置く外部リンク |
| OGP(Open Graph Protocol) | URL を共有したときに表示される画像・タイトルの設定 |
| generative AI(生成 AI) | 文章や画像を自動で作る AI → [AI 利用のルール](ai-rules-by-platform.md) |

## よくある勘違い

| 勘違い | 実際 |
|---|---|
| 「インプレッション = 見た人数」 | インプレッションは表示回数。人数はリーチ |
| 「ハッシュタグは多いほどよい」 | 上限や推奨はサービスで違う。関係ないタグは逆効果になりうる → [ハッシュタグ](hashtags.md) |
| 「ネットにある画像は自由に使ってよい」 | 多くは著作権がある。利用条件を確認する |
| 「PR 表記は案件だけ」 | 自分の商品の宣伝や、無償提供を受けた紹介でも必要になる場合がある → [法令](legal-compliance.md) |

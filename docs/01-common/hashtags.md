# ハッシュタグの効率的な使い方

> **このページで分かること**: ハッシュタグとは何か、サービス別の上限・推奨数、選び方の手順、書き方のルール、効果の測り方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: なし。検索全般は [search-optimization](search-optimization.md)

> 2025年(皇紀2685年・令和7年)から2026年(皇紀2686年・令和8年)にかけて**ハッシュタグの扱いが大きく変わりました**。Instagram は上限が 5 個に引き下げられたと報じられ、公式担当者は「ハッシュタグでリーチは増えない」と述べています(🟡)。古い「30個付ける」運用は通用しません。

## 概要

hashtag(ハッシュタグ)は、`#` の後ろに言葉を付けたものです(例: `#時短レシピ`)。投稿に付けると、その言葉で検索した人や、そのタグを見ている人に見つけてもらいやすくなり、自分の投稿を**束ねるラベル**にもなります。

ただし最近は、各サービスが**本文・キャプション・字幕・画像の内容そのもの**から投稿を理解するようになり、タグを大量に付ける効果は小さくなっています(🟡)。今の基本は「**少なく・関連の強いものだけ**」です。

## 用語

| 用語 | 意味 |
|---|---|
| hashtag(ハッシュタグ) | `#` + 言葉。タップすると同じタグの投稿一覧が出る |
| topic tag(トピックタグ) | Threads などでの、投稿に付ける話題のタグ |
| CamelCase / PascalCase(キャメルケース / パスカルケース) | 英単語の頭を大文字にしてつなぐ書き方(例: `#SnsOps`) |
| reach(リーチ) | 投稿を見た人数 |
| hashtag stuffing(タグの詰め込み) | 関係の薄いタグを大量に付けること。スパム扱いの原因 |
| branded hashtag(自社タグ、シリーズタグ) | 自分の投稿だけを束ねるための独自タグ |
| screen reader(スクリーンリーダー) | 画面の文字を読み上げる機能 |

## 1. 最新の状況(サービス別)

| サービス | 上限・推奨 | 確度 | 備考 |
|---|---|---|---|
| **Instagram** | 投稿・リールとも**最大 5 個**に段階的に引き下げ(2025年12月19日以降と報道)。ストーリーズは対象外とする報道。**一方、公式 API 文書は「30個」と記載** | 🟡 報道 / ✅ API 文書(更新遅れの可能性) | #56。分析では **4〜5個**が最適とする調査(160万投稿)。6個以上は到達が下がる傾向。一部のユーザーには **3個** の上限がテストされたとの報道も(🟡 Social Media Today) |
| **X** | 明確な上限なし。実務の目安は**1〜3個** | 🟡 | 公式の推奨は未取得。数字のみのタグは不可、スペース・句読点でタグが切れる |
| **TikTok** | 3〜5個が目安。**検索はキャプション・字幕・動画内の言葉**も使う | ⚪ | 公式の推奨は未確認 |
| **YouTube** | 説明文・タイトルに付ける。説明欄のタグのうち**最も興味を引くとみなされたものが3つまでタイトルに表示**。**1つの動画・再生リストに60個を超えるタグを付けると、すべてのタグが無効** | ✅ YouTube ヘルプ | 旧記載「60個超だと無視されるとされる ⚪ #31」を公式で確認し ✅ に更新 |
| **Threads** | **1つ**(トピックタグ)とする二次資料 | 🟡 #34 | |
| **Bluesky** | 本文の一部として使える(facets) | ⚪ | |
| **note** | 記事の公開設定で追加(上限は未確認) | ⚪ #13 | |
| **Facebook** | 効果は限定的とされる | ⚪ | |

### YouTube の公式の禁止事項(✅ 抜粋)

- タグに**スペースは使えない**(複数語はつなげる。例: `#TwoWords`)。
- タグを詰め込みすぎると、関連の低い視聴者に表示されやすくなり、**検索結果から削除される**ことがある。
- 動画と直接関係のないタグ、嫌がらせ・ヘイト・性的・下品なタグは、削除・年齢制限の対象。

## 2. 基本方針: 「少数・関連・検索意図」

1. **数より関連性**: 無関係な人気タグは逆効果(スパム扱い、離脱)。
2. **検索される語**を選ぶ(読者が検索する言葉)。タグだけに頼らず、**本文・キャプション・字幕・名前欄にも主題語**を入れる([search-optimization](search-optimization.md))。
3. **役割を分ける**: 下の4層から1〜2個ずつ。
4. **効果を測る**: タグごとの反応を記録し、入れ替える。

## 3. タグの4層(5個以内の配分例)

| 層 | 役割 | 例の数 | 例 |
|---|---|---|---|
| ① 分野(広い) | 大きな話題に紐づく | 1 | `#SNS運用` |
| ② トピック(具体) | 具体的な主題 | 1〜2 | `#Instagramリール` |
| ③ コミュニティ | 同じ関心の人の集まり | 0〜1 | `#個人事業主` |
| ④ 自社・シリーズ | 自分の投稿を束ねる | 1 | `#○○運用日記` |

- Instagram(5個以内)の例: ①1 + ②2 + ④1 = **4個**(1個の余裕)。
- X(1〜3個)の例: ② + ④。

### 具体例(汎用)

| アカウント | 投稿 | タグの例 | 層 |
|---|---|---|---|
| 料理アカウント | 10分でできる作り置き | `#作り置き` `#時短レシピ` `#お弁当おかず` `#○○の台所` | ① ② ② ④ |
| 地域の店 | 新メニューの告知 | `#○○市カフェ` `#季節限定` `#○○店` | ② ② ④ |
| イラスト | 作品の公開 | `#イラスト` `#水彩` `#○○の絵日記` | ① ② ④ |

## 4. 書き方のルール

| 項目 | 内容 |
|---|---|
| 区切り | タグは**スペース・句読点・記号で切れる**。複数語は **CamelCase / PascalCase**(例: `#SnsOps`)か、日本語のみで連結 |
| 数字 | **数字のみのタグ**は使えない(X など) |
| 全角・半角 | 英数字は**半角**に統一。表記ゆれを避ける |
| 文字数 | 長すぎるタグは読まれない。**15字以内**を目安(⚪) |
| 位置 | キャプション・本文の**末尾**にまとめる(読みやすさ)。X は文中の主題語を直接タグにする方法もある |
| アクセシビリティ | CamelCase にすると**スクリーンリーダー**が語を区切って読める([alt-text](alt-text.md)) |
| 自社タグ | 表記を固定。商標・他社名との混同に注意 |

### よくある書き間違い

| 書いたもの | 実際にタグになる部分 | 直し方 |
|---|---|---|
| `#SNS 運用` | `#SNS` だけ | `#SNS運用` |
| `#時短・レシピ` | `#時短` だけ | `#時短レシピ` |
| `#2026` | タグにならない(数字のみ) | `#2026年の目標` など語を足す |
| `#ＳＮＳ運用` と `#SNS運用` | 別のタグとして扱われ得る | 半角に統一 |

## 5. 選定の手順(15分)

1. **目的**を決める(発見される / 束ねる / イベント参加)。
2. **候補を10〜20個**出す(関連語、競合の使用、サジェスト)。
3. 各候補で**検索**し、次を確認:
   - 投稿の質・内容が自分の分野に合うか
   - 最近(直近1か月)の投稿があるか(死んだタグを除く)
   - 規模(大・中・小のバランス)
   - **制限・隠されたタグ**でないか(関連のない投稿・不適切な投稿が多いタグは避ける)
4. **5個以内**に絞り、層ごとに配分。
5. 台帳(下)に記録。

## 6. 効果測定

| 指標 | 見方 |
|---|---|
| Instagram のインサイト | 投稿の「**ハッシュタグ経由**」の表示/リーチ(あれば) |
| X のアナリティクス | インプレッション・エンゲージ率(タグの有無で比較) |
| 保存・シェア・プロフィールアクセス | タグが呼ぶ質 |
| **A/B** | 同じ型の投稿を、タグ **0個 / 2個 / 5個**で3回ずつ比較 |

- **短期の揺れ**が大きいので、最低でも**各条件5本**で傾向を見る(⚪)。
- 結果を週次レビューに記録([weekly-review](../../templates/weekly-review.md))。指標の考え方は [analytics-kpi](analytics-kpi.md)。

## 8. 運用上の注意

1. **無関係な流行タグ・「相互フォロー」系の大量タグ**はスパムとみなされるリスク。
2. 広告・PR は**ハッシュタグの末尾に埋もれさせない**。`#PR` は目立つ位置に、または本文冒頭に([legal-compliance](legal-compliance.md))。
3. 他者・他社の商標タグの無断使用に注意。
4. イベントタグは**公式の指定表記**に合わせる。
5. 政治・社会問題のタグは、拡散・炎上のリスクを考慮([sensitive-topics-and-accuracy](sensitive-topics-and-accuracy.md))。
6. 自動付与ツールの使用は、規約と精度に注意([20-api/08](../20-api/08-automation-and-tools.md))。

## よくある失敗と対処

| 失敗 | 起きること | 対処 |
|---|---|---|
| 昔の記事を見て30個付けた | Instagram で投稿できない・スパム扱い(🟡) | 5個以内 |
| 人気タグだけを付けた | すぐ埋もれる・関係ない人に届く | 中・小規模の具体的なタグを混ぜる |
| 毎回同じタグをコピペ | 投稿の内容と合わないタグが混ざる | 投稿ごとに②トピック層を変える |
| YouTube の説明欄にタグを大量に並べた | すべてのタグが無効、削除の可能性(✅) | 関連の強いものを数個 |
| タグの途中にスペース | 途中で切れる | つなげて書く |

# ブランドとビジュアルの指針

> **このページで分かること**: 投稿の「見た目の一貫性」(配色・書体・ロゴ・画像の型)の決め方と、使い回せるテンプレートの作り方。
>
> **対象**: 初心者(毎回デザインに迷う人)〜小規模チーム  **先に読むページ**: なし。サイズは [image-specs-comparison](image-specs-comparison.md) と [export-presets](export-presets.md)

## 概要

フィードを流し見している人は、1投稿を1秒前後で判断します(⚪ 一般論)。いつも同じ色・同じ文字の雰囲気だと「あのアカウントだ」と気づいてもらいやすくなります。これが **brand(ブランド)の一貫性**です。

一貫性は「センス」ではなく**ルールを先に決めること**で作れます。このページでは、次の順で決めます。

1. 配色・書体・ロゴなどの**要素**を決める。
2. よく使う画像の**型(テンプレート)**を作る。
3. 読みやすさ(**アクセシビリティ**)を確認する。
4. ルールを1枚の**ガイド**にまとめ、素材の出典を台帳に残す。

## 用語

| 用語 | 意味 |
|---|---|
| brand guideline(ブランドガイドライン) | 色・書体・ロゴ・文体などの使い方をまとめた決まり |
| color palette(カラーパレット、配色) | 使う色の組み合わせ。色はカラーコード(例: `#1A73E8`)で記録する |
| font / typeface(フォント、書体) | 文字のデザイン。ライセンス(使ってよい範囲)がある |
| template(テンプレート) | 中身だけ差し替えて使い回す画像の雛形 |
| safe area(安全領域) | 切り抜き・UI の重なりがあっても欠けない中央の範囲 |
| grid(グリッド) | 要素をそろえる見えない線 |
| contrast ratio(コントラスト比) | 文字色と背景色の明るさの差。数字が大きいほど読みやすい |
| accessibility(アクセシビリティ) | 障害の有無や環境にかかわらず、情報を受け取れること |

## ブランドの要素

| 要素 | 決めること | 目安 |
|---|---|---|
| 配色 | メイン1、サブ1、アクセント1、背景、文字 | 3色以内+無彩色(⚪) |
| 書体 | 見出し、本文 | 2種以内。**商用利用・埋め込みのライセンス確認** |
| ロゴ・アイコン | 正方形・円形に切り抜かれても読める | 余白を確保 |
| 余白とグリッド | 安全領域を中央80% | 縮小表示に耐える |
| トーン | 写真/イラスト/図解の傾向 | 一貫させる |
| 文体 | 敬体/常体、口調、絵文字の可否 | [writing-guide](writing-guide.md) |

## 手順: 1時間でブランドの最小セットを作る

1. **参考を集める(15分)**: 好きなアカウントや雑誌のスクリーンショットを10枚集め、共通点(色数、文字の太さ、余白)をメモする。※ 真似るのは「考え方」で、デザインそのものをコピーしない。
2. **色を決める(10分)**: メイン色1つ → 相性の良いサブ色1つ → 目立たせたい所だけに使うアクセント色1つ。背景(白・黒・薄いグレーなど)と文字色を決め、**カラーコードを記録**する。
3. **書体を決める(10分)**: 見出し用(太め)と本文用(読みやすい)を1つずつ。**商用利用・SNS 画像への使用が許可されているか**をライセンスで確認する。
4. **アイコンを作る(10分)**: 円形に切り抜かれても欠けないよう、要素を中央に寄せる。小さく(40px 程度)表示しても判別できるか確認する(⚪)。
5. **型を2つ作る(15分)**: 下の「型」から、最もよく使う2つを選んでテンプレート化する。
6. **1枚のガイドにまとめる**: 下の「ブランドガイド(雛形)」に書き込む。

### ブランドガイド(雛形)

```
アカウント名:
ひとことで言うと:(例: 忙しい人向けの時短レシピ)
メイン色: #______  サブ色: #______  アクセント: #______
背景: #______  文字: #______
見出し書体: ______(ライセンス確認日: ____)
本文書体: ______(ライセンス確認日: ____)
写真/イラスト/図解の比率: __ / __ / __
文体: です・ます / だ・である  絵文字: 使う(1投稿__個まで)/ 使わない
NG: (例: 原色の赤を背景にしない、斜体を使わない)
```

## 画像の「型」を作る

| 型 | 構成 | 用途 |
|---|---|---|
| 見出しカード | タイトル大・サブ小 | 記事・動画のサムネ、告知 |
| 解説カード | 見出し+要点3つ+出典 | カルーセル |
| 比較カード | 左右対比 | 比較・ビフォーアフター |
| 引用カード | 短い引用+出典 | 名言・コメント紹介 |
| 数字カード | 大きな数字+説明 | 統計・成果 |
| 図解 | 矢印・ステップ | 手順 |

型ごとに**テンプレート**(比率別)を作り、中身だけ差し替える運用にすると、制作時間と品質のばらつきが減ります。

- 比率別に用意するもの: 1:1、4:5、16:9、9:16(各サービスの比率は [image-specs-comparison](image-specs-comparison.md) §3)。
- 文字の最小サイズの目安は [mobile-viewing-optimization](mobile-viewing-optimization.md)(1080px 幅で本文 44px 以上など)。

## 具体例(汎用)

| 例 | 色 | 書体 | 型 |
|---|---|---|---|
| 料理アカウント | 背景は白、メインは温かい橙、アクセントは深緑 | 見出しは丸ゴシック、本文はゴシック | 写真+見出しカード、手順の図解 |
| 地域の店 | 店の看板と同じ色をメインに | 見出しは太字ゴシック | 告知(日時を大きく)、商品写真 |
| イラスト | 作品を邪魔しない無彩色の枠 | 細めのゴシックで署名のみ | 作品+制作過程の比較カード |

## アクセシビリティ

- 文字と背景のコントラスト比 4.5:1 以上を目安(WCAG 2.1 の達成基準 1.4.3。大きな文字は 3:1 以上 🟡 W3C 解説の検索要約)。
- 色だけで意味を区別しない(記号・形を併用)。
- 画像内の文字を**キャプションと代替テキストにも書く**([alt-text](alt-text.md))。
- 動画には字幕([video-basics](video-basics.md))。

> コントラスト比は、無料の「コントラストチェッカー」(ブラウザの開発者ツールにも付属)で2色を入力すると計算できます(⚪)。

## 縦書き・ルビ

縦書きやルビが必要なら、組版ツール(例: LuaLaTeX と jlreq)で PDF 化→画像変換が選択肢(⚪)。数字は漢数字/英数字の向きに注意。

## よくある失敗と対処

| 失敗 | 起きること | 対処 |
|---|---|---|
| 毎回違う色・書体を使う | アカウントの印象が残らない | ガイドを作り、テンプレートからしか作らない |
| 書体を5種類以上使う | ごちゃごちゃして読みにくい | 2種以内 |
| 薄いグレーの文字を写真の上に置く | スマホで読めない | 背景に半透明の帯を敷く、コントラスト比を確認 |
| フリー素材サイトのフォントを確認せずに使う | 商用不可だった | ライセンスを読み、台帳に記録 |
| アイコンの文字が端にある | 円形に切られて欠ける | 中央の円の中に収める |
| 端まで文字を置く | 自動トリミングや UI で欠ける | 安全領域(中央80%)の中に置く |

## 注意点

- 他社・他者のロゴや配色を真似しすぎると、商標やなりすましの問題になり得ます(⚪ [legal-compliance](legal-compliance.md))。
- 季節の企画などでブランド色から外すときも、ロゴ・書体のどちらかは残すと一貫性が保てます(⚪)。

## チェックリスト

- [ ] 色をカラーコードで記録した(5色以内)
- [ ] 書体は2種以内で、ライセンスを確認した
- [ ] アイコンが円形・小サイズでも判別できる
- [ ] よく使う型のテンプレートが比率別にある
- [ ] 文字と背景のコントラスト比を確認した
- [ ] ブランドガイドを1枚にまとめた

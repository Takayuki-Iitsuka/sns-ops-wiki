# アカウント保護

## 最低限やること

1. **一意で長いパスワード**(パスワードマネージャーを使う)。使い回さない。
2. **2段階認証(two-factor authentication)** を有効化。可能なら認証アプリ（またはパスキー/セキュリティキー）。SMS は最終手段。
3. **バックアップコードを安全な場所に保管**(このリポジトリや公開場所には書かない)。
4. **登録メールアドレスの保護**: メールが乗っ取られると全アカウントが危険。
5. **連携アプリの棚卸し**: 使わないアプリの連携を定期的に解除。
6. **ログイン通知を有効化**。

## 詐欺・乗っ取り対策

- 「アカウント停止」「著作権違反」を装ったDM・メールのリンクは開かない。公式アプリや公式サイトから確認。
- 案件・コラボ依頼を装った不審なファイル・リンクに注意。
- 公式を名乗るアカウントでも、**認証済み表示だけで信用しない**。

## 複数人運用

- 共有アカウントのパスワード共有は避け、サービスの権限機能(メンバー招待等)を使う。
- 退任者の権限を即時削除。

## 万一のとき

1. パスワード変更、全端末からログアウト、連携アプリ解除
2. 公式の乗っ取り申告フォームへ
3. 他サービスで同じパスワードを使っていれば全て変更

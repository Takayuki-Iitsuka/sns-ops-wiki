# 画像制作ワークフロー

> **このページで分かること**: SNS 用の画像を「企画 → 素材 → レイアウト → 書き出し → 検査 → 保管 → 投稿」の順に作る具体的な流れと、ファイルの命名・保管のルール。
>
> **対象**: 初心者(画像づくりの手順が決まっていない人)  **先に読むページ**: [brand-and-visual-guidelines](brand-and-visual-guidelines.md)

仕様(サイズ・比率)は [image-specs-comparison](image-specs-comparison.md)。ここでは**作り方の流れ**を扱う。

## 概要

画像づくりを毎回その場の思いつきで進めると、サイズの間違い・素材の権利の確認漏れ・元ファイルの紛失が起きやすくなります。手順を決めておくと、**速く・同じ品質で・安全に**作れます。

## 全体の流れ

```
企画 → 素材の確保(権利) → レイアウト → 書き出し → 検査 → 命名・保管 → 投稿
```

| 工程 | やること | 詳しいページ |
|---|---|---|
| 企画 | 何を伝える画像か、どの型か | [content-planning](content-planning.md) |
| 素材の確保 | 自作 / 許諾済み / ライセンス確認 | [image-sources-and-copyright](image-sources-and-copyright.md) |
| レイアウト | テンプレートに配置、安全領域を守る | [brand-and-visual-guidelines](brand-and-visual-guidelines.md) |
| 書き出し | サービス別の値で保存 | [export-presets](export-presets.md) |
| 検査 | 実機確認、チェックリスト | [image-checklist](../../templates/image-checklist.md) |
| 命名・保管 | 規則どおりの名前で非公開に保存 | 本ページ §4 |
| 投稿 | alt text を付けて投稿 | [alt-text](alt-text.md)、[posting-workflow](posting-workflow.md) |

## 用語

| 用語 | 意味 |
|---|---|
| master(マスター、原本) | 編集できる状態の元ファイル。ここから各サービス用を書き出す |
| layer(レイヤー) | 文字・写真・図形を別々の層に分けて重ねる仕組み |
| canvas(キャンバス) | 作業する画面の大きさ(px) |
| template(テンプレート) | 中身だけ差し替えて使う雛形 |
| safe area(安全領域) | 切り抜き・UI で欠けない中央の範囲 |
| sRGB | Web 表示の標準の色空間 |
| Exif(撮影情報) | 写真に含まれる撮影日時・機種・位置情報 |
| JPEG 品質 | JPEG の圧縮の強さ(数字が大きいほど高画質・大容量) |

## 1. 作業キャンバス

| 方針 | 内容 |
|---|---|
| マスターは大きく | 長辺 2000〜3000px 前後で作り、各サービス向けに縮小して書き出す(⚪) |
| 比率別のテンプレ | 1:1 / 4:5 / 1.91:1 / 9:16 のテンプレを用意し、安全領域(中央80%)の枠を入れる |
| 色空間 | sRGB で書き出す(Web 表示の標準 ⚪。Instagram・Threads の API は他の色空間を sRGB に変換する ✅) |
| レイヤー保存 | マスターファイルは非公開で保管 |

### テンプレートの作り方(手順)

1. 編集アプリで、比率ごとに新規キャンバスを作る(例: 4:5 なら 2160×2700px。書き出し時に 1080×1350 へ縮小)。
2. 中央80%に**ガイド線(安全領域)**を引く。9:16 は上約10%・下約15%・右約15%も避ける([export-presets](export-presets.md))。
3. ブランドの色・書体・ロゴを置き、文字の箱(見出し・本文)を配置する。
4. 「テンプレート_4x5_見出しカード」のように名前を付けて保存する。

## 2. 書き出し

| 用途 | 形式 | 目安 |
|---|---|---|
| 写真 | JPEG | 品質 80〜90 前後 ⚪ |
| 文字・図・イラスト | PNG | 文字がにじまない |
| アニメーション | GIF(X) / 動画 | 容量上限は仕様を確認 |
| 書き出し後の縮小 | 長辺・容量の上限を超えない | [仕様比較](image-specs-comparison.md) |

> **Instagram に API(予約投稿ツールなど)で投稿する予定がある**なら、公開 API は **JPEG のみ**なので、文字入り画像も高品質の JPEG で書き出します(✅ Instagram API 文書)。

## 3. 位置情報(Exif)の削除

写真は、撮影位置・機種などが含まれる(Exif)。公開前に削除する(⚪)。多くの投稿アプリで自動削除されるが、仕様は確認し、**自宅付近の写真は特に注意**。

確認・削除の方法(⚪ 名称は OS・アプリで違う):

1. パソコン: ファイルのプロパティ(詳細情報)を開き、位置情報の欄を見る。「プロパティや個人情報を削除」などの機能で消す。
2. スマホ: 写真の情報画面で位置が表示されるか見る。共有時に「位置情報を含めない」を選ぶ。カメラの設定で位置情報の記録をオフにする方法もある。
3. 編集アプリで書き出し直すと、撮影情報が消える場合が多い(書き出し設定で確認)。

> 位置情報以外にも、**窓の外の景色、郵便物の宛名、車のナンバー、制服**などから場所が特定されることがあります([privacy-and-personal-info](privacy-and-personal-info.md))。

## 4. 命名・保管

```
YYYYMMDD_媒体_用途_連番.拡張子   例: 20261103_ig_carousel_01.png
```

- フォルダ: `素材/` `作業中/` `公開済み/`(リポジトリには入れず、非公開で保管)
- 権利台帳: 素材名・出典・ライセンス・確認日

### 媒体の略記(例)

| 略記 | 媒体 | 略記 | 媒体 |
|---|---|---|---|
| `x` | X | `yt` | YouTube |
| `ig` | Instagram | `tt` | TikTok |
| `th` | Threads | `fb` | Facebook |
| `note` | note | `bsky` | Bluesky |

### フォルダ構成(例)

```
SNS画像/
├─ 素材/        ← 写真・購入素材・フォント(ライセンスの控えも一緒に)
├─ テンプレート/ ← 比率別の雛形
├─ 作業中/      ← マスター(レイヤー付き)
└─ 公開済み/    ← 書き出した投稿用ファイル(年月ごと)
```

バックアップの考え方は [data-backup-and-portability](data-backup-and-portability.md)。

## 5. 品質検査

[image-checklist](../../templates/image-checklist.md) を使う。さらに:

- スマホの実機で実寸確認(縮小表示で文字が読めるか)。
- ダークモード/ライトモードで見え方を確認。
- 代替テキストと本文に、画像内の文字を書く。

## 6. 自動化(任意)

画像のリサイズ・書き出しの自動化は、Python(Pillow)などで可能。**大量処理の前に1枚で試す**。リポジトリに入れる場合はソースのみ、画像の実ファイルは入れない。例は [export-presets](export-presets.md) の「自動化」。

## 具体例: カルーセル1本を作る(汎用)

1. 企画: 「作り置き3品」の解説、8枚、柱は「教える」。
2. 素材: 自分で撮った料理写真(位置情報なし)。
3. レイアウト: 4:5 テンプレートの「解説カード」に写真と要点を配置。
4. 書き出し: 1080×1350、JPEG 品質85、sRGB。
5. 検査: スマホで文字が読めるか、1枚目で内容が分かるか。
6. 保管: `20261103_ig_carousel_01.jpg`〜`_08.jpg` を `公開済み/2026-11/` へ。
7. 投稿: 各画像に alt を付け、キャプションに要点を書く。

## よくある失敗と対処

| 失敗 | 起きること | 対処 |
|---|---|---|
| 小さなキャンバスで作って拡大 | ぼやける | マスターは長辺 2000px 以上 |
| マスターを保存せず書き出しだけ残す | 修正できない | レイヤー付きで保存 |
| ファイル名が「最終_修正2_本当に最終」 | どれが公開版か分からない | 命名規則を守る |
| 素材の出典を記録しない | 後で権利を確認できない | 素材を入れた時点で台帳へ |
| 自宅で撮った写真をそのまま投稿 | 位置が特定される | Exif と写り込みを確認 |

## チェックリスト

- [ ] 比率別のテンプレートを使った
- [ ] 素材の権利を確認し、台帳に記録した
- [ ] 安全領域の中に文字・顔が入っている
- [ ] サービス別の値で書き出した
- [ ] 位置情報と写り込みを確認した
- [ ] 命名規則どおりの名前で、非公開の場所に保存した

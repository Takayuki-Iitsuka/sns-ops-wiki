# サービスの選び方

> **このページで分かること**: X・Instagram・YouTube・TikTok・Threads・Facebook・note などの特徴の違いと、自分に合うサービスを選ぶ手順。
>
> **対象**: どの SNS から始めるか迷っている初心者。**先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)

## 概要

SNS にはそれぞれ「得意な形式」と「使われ方」があります。文章が得意な人が動画中心のサービスを選ぶと、毎回の制作が大きな負担になります。逆に、得意な形式に合うサービスを選べば、少ない労力で続けられます。

選ぶときの基本は次の3点です。

1. **自分が作りやすい形式**(文章・写真・イラスト・短い動画・長い動画・音声)
2. **届けたい相手がいる場所**
3. **最終的な目的**(知ってもらう/売る/仲間を作る/収益を得る)

> 下の比較は一般的な傾向(⚪)です。利用者数や年齢層の具体的な数値は調査会社や時期によって大きく異なるため、ここでは書きません。数値が必要な場合は、各社の公式発表や公的統計(総務省「情報通信白書」など)を確認してください。

## 用語

| 用語 | 意味 |
|---|---|
| platform(プラットフォーム) | 投稿の場となるサービスのこと。X、Instagram など |
| short-form video(短尺動画) | 数十秒〜数分の縦型動画。リール、Shorts、TikTok など |
| long-form(長尺) | 数分〜数十分以上の動画や長い記事 |
| discoverability(発見されやすさ) | フォローしていない人に投稿が届く度合い |
| owned media(自社メディア、自分の場所) | ブログやメールなど、運営会社の方針変更に左右されにくい自分の発信先 |

## サービス別の特徴(一般的な傾向 ⚪)

| サービス | 主な形式 | 向いている発信 | 特徴 | 詳細 |
|---|---|---|---|---|
| X(旧 Twitter) | 短い文章、画像、動画 | 速報、日々の気づき、会話 | 拡散(リポスト)の仕組みがあり、話題が広がりやすい。文章中心でも始めやすい | [X](../02-x/README.md) |
| Instagram | 写真、カルーセル、リール(縦動画)、ストーリーズ | 見た目で伝わるもの(作品、商品、風景、料理) | 世界観をそろえたプロフィールが重視される。保存・共有されやすい「役立つ投稿」も強い | [Instagram](../03-instagram/README.md) |
| Threads | 短い文章、画像 | 会話、気軽な発信 | Instagram のアカウントで始められる。文章中心 | [Threads](../07-threads/README.md) |
| YouTube | 長尺動画、Shorts、ライブ | 解説、手順、ドキュメント、エンタメ | 検索から長期間見られやすい。制作負担は大きいが資産になりやすい | [YouTube](../05-youtube/README.md) |
| TikTok | 短尺の縦型動画 | 短い驚き・発見、エンタメ | フォロワーが少なくても表示される機会がある、とされる ⚪ | [TikTok](../06-tiktok/README.md) |
| Facebook | 文章、写真、動画、グループ | 地域、同窓・趣味のコミュニティ、店舗 | 実名文化。グループ機能でコミュニティを作れる | [Facebook](../08-facebook/README.md) |
| note | 長い文章(記事)、マガジン | 考え、ノウハウ、体験談、有料記事 | 記事を売る・定期購読(メンバーシップ)の仕組みがある | [note](../04-note/README.md) |
| Bluesky | 短い文章、画像 | 会話 | 分散型の仕組みを持つ新しいサービス | [Bluesky](../09-other-services/01-bluesky.md) |
| LINE 公式アカウント | メッセージ配信 | 店舗・事業の常連客への連絡 | 友だち登録した人に直接届く | [LINE](../09-other-services/02-line-official-account.md) |
| Twitch | ライブ配信 | ゲーム配信、雑談、作業配信 | ライブ中心。視聴者との会話が主役 | [Twitch](../09-other-services/03-twitch.md) |

## 選ぶ手順

### 手順1: 自分の得意な形式を確かめる

次の質問に「はい」と答えた数が多い形式が、あなたの得意な形式です。

| 形式 | 質問 |
|---|---|
| 文章 | 文章を書くのが苦にならない/考えを言葉にするのが好き |
| 写真・イラスト | 見た目で伝わるものを作っている/撮影や描画が好き |
| 短い動画 | スマホで撮影・編集できる/テンポよく話せる |
| 長い動画 | 1つのテーマをじっくり説明できる/編集に時間をかけられる |
| 音声・ライブ | 話すのが好き/決まった時間に配信できる |

### 手順2: 相手がいる場所を確かめる

1. 届けたい相手が使っていそうな言葉(例: 「キャンプ 初心者」)で、各サービスを検索します。
2. 同じジャンルで活動しているアカウントが多く、反応があるサービスを候補にします。
3. 競合が多すぎる場合は、テーマを少し絞ります(例: 「キャンプ」→「ソロキャンプの料理」)。

### 手順3: 目的との相性を確かめる

| 目的 | 相性のよい組み合わせの例 ⚪ |
|---|---|
| まず知ってもらう(認知) | 拡散・おすすめ表示が強いサービス(X、TikTok、Instagram のリール、YouTube の Shorts) |
| じっくり信頼を得る | 長い形式(YouTube 長尺、note、ニュースレター) |
| 商品・サービスを売る | 見た目で伝わる Instagram + 販売ページ、LINE 公式アカウントで再来店 |
| 仲間・コミュニティを作る | Facebook グループ、Discord など → [コミュニティ運営](community-management.md) |
| 発信で収益を得る | 収益化の仕組みがあるサービス → [収益化の比較](monetization-comparison.md) |

### 手順4: 1つ(多くても2つ)に決める

- 最初は **メイン1つ** に集中します。
- 2つ目を足すなら、メインと**同じ素材を転用しやすい**ものにします(例: Instagram のリール ⇔ YouTube Shorts ⇔ TikTok)。→ [企画の再利用](content-planning.md)
- 外部サービスの方針変更に備えて、いずれは**自分の連絡手段**(メール、ブログ)も持つと安心です。→ [ニュースレター](newsletter-and-email.md)

## 具体例

| 発信者の例 | 得意な形式 | 選び方の例 |
|---|---|---|
| 手作り雑貨を売りたい人 | 写真 | メイン: Instagram。補助: X で制作の様子、販売は外部ショップ |
| 仕事のノウハウを伝えたい人 | 文章 | メイン: X または Threads。まとまった内容は note |
| 料理の手順を見せたい人 | 短い動画 | メイン: Instagram リール。同じ動画を YouTube Shorts・TikTok に転用 |
| 地域の店舗 | 写真・お知らせ | Instagram + LINE 公式アカウント(常連向け)+ Googleマップのビジネスプロフィール |
| 趣味の解説をじっくりしたい人 | 長い動画 | メイン: YouTube。告知用に X |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 流行っているからという理由だけで選ぶ | 自分が作りやすい形式を優先する |
| 全サービスに同じ文章・同じサイズで投稿する | サービスごとの推奨比率・文字数に合わせる。→ [画像の仕様](image-specs-comparison.md)、[動画の仕様](video-specs-comparison.md) |
| 1つに絞れず、すべてが中途半端になる | 3か月はメイン1つ。数字を見てから追加する |
| 1つのサービスだけに頼り、停止や仕様変更で困る | 投稿のバックアップを取り、自分の連絡手段を持つ。→ [バックアップ](data-backup-and-portability.md) |

## 注意点

- 年齢制限があります。多くのサービスは13歳以上を条件にしています ⚪(各サービスの規約で確認)。収益化機能は18歳以上などの条件が付くことがあります。→ 各サービスの収益化ページ
- 料金がかかるプランや機能もあります。→ [料金プラン](../40-pricing/README.md)

# コメント・返信・コミュニティ運用

> **このページで分かること**: コメントや DM への返し方、困ったコメントの扱い、返信のルール作り、テンプレートと記録の方法。
>
> **対象**: 初心者(コメントが付き始めた人)/ 複数人で返信する人  **先に読むページ**: なし。荒れたときは [crisis-response](crisis-response.md)

## 概要

コメントは、読者が時間を使って話しかけてくれた「会話の入口」です。丁寧に返すと、次の効果が期待できます(⚪ 一般論)。

- 読者との信頼関係ができ、また見に来てもらいやすくなる。
- 質問から、次の投稿のネタ(読者が本当に知りたいこと)が見つかる。
- 会話が続く投稿は、他の人の目にも留まりやすい。

一方で、すべてに完璧に返そうとすると疲れてしまいます。**返す・返さない・隠す・報告するの基準を先に決める**ことが、長く続けるコツです。

## 用語

| 用語 | 意味 |
|---|---|
| comment(コメント) / reply(返信、リプライ) | 投稿に付く公開の書き込み / それへの返事 |
| DM / direct message(ダイレクトメッセージ) | 1対1の非公開メッセージ |
| mention(メンション) | `@ユーザー名` で相手に通知を送ること |
| hide(非表示) | コメントを他の人から見えなくする機能。相手には気づかれにくい(⚪ サービスによる) |
| mute(ミュート) | 相手の投稿・通知を自分に見せなくする機能 |
| block(ブロック) | 相手が自分に関われないようにする機能 |
| report(報告、通報) | 規約違反をサービスに知らせる機能 |
| community(コミュニティ) | 共通の関心で集まる読者の集まり |
| moderation(モデレーション) | 書き込みを見守り、ルールに沿って整理すること |

## 基本方針

1. **早めに、短く、人間らしく返す**: 投稿直後の反応時間帯に返信。定型文の連続は避ける。
2. **名前を呼び、内容に触れる**: 「ありがとうございます」だけで終えず、コメントの要点に反応する。
3. **質問で終える**: 会話が続きやすい。
4. **返信を次の投稿のネタにする**(許可を得るか、匿名化)。

## 対応の分類

| 種類 | 対応 | 例 |
|---|---|---|
| 好意的 | 感謝＋具体的に返す | 「刺さった点を教えていただけて嬉しいです」 |
| 質問 | 回答＋まとめ投稿候補 | FAQ 化する |
| 批判・意見 | 事実を確認し、冷静に。感情的に反論しない | 事実誤認なら訂正 |
| 炎上リスク | 返信前に1人以上で確認。すぐ削除せず記録 | 手順は [crisis-response](crisis-response.md)、各サービスは [10-policies](../02-x/10-policies.md) 参照 |
| スパム・誹謗中傷 | 非表示・ブロック・通報(各サービスの機能) | |

### 迷ったときの判断フロー

```
コメントが来た
 ├─ 個人情報・脅迫・差別・明らかなスパム? → はい → 記録(スクショ)→ 非表示/ブロック/報告
 ├─ 事実の誤りの指摘? → はい → 一次資料で確認 → 正しければお礼+訂正
 ├─ 質問? → はい → 回答(長くなるなら投稿にする)
 ├─ 批判・反対意見? → はい → 一晩置く → 返すなら1回だけ冷静に
 └─ 好意的 → 内容に触れて返信
```

## 手順: 返信のルールを作る

1. **返信する時間帯を決める**: 例「投稿後1時間」と「夜に15分」。それ以外は通知を切ってよい。
2. **返す範囲を決める**: 例「質問と、内容に触れたコメントには必ず返す。スタンプだけのものはいいねで返す」。
3. **NG の基準を決める**: 下の「運用ルール」を参考に、非表示・ブロックの基準を書いておく。
4. **(複数人運用)担当と承認を決める**: 誰が返すか、どんな内容は上長(または2人目)の確認が必要か。
5. **プロフィールや固定投稿に方針を書く**(任意): 例「個別のご相談には DM でお答えできません」。

## 運用ルール(テンプレ)

- 返信担当と承認フローを決める(個人運用なら「投稿から一晩置く」ルール)。
- NG ワード(政治・宗教・医療的助言・個人情報)に触れる話題は避ける。
- 個人情報(住所・電話・メールアドレス)をコメントに書かない・求めない。
- 反応が少ない時期は無理にエンゲージメント集めの定型投稿をしない。

## 返信テンプレ(雛形)

```
〇〇さん、コメントありがとうございます。
「◇◇」という点、まさに狙いでした。△△の場面で試されたんですね。
うまくいかない点があれば、ぜひ教えてください。
```

### 場面別の文例

| 場面 | 文例 |
|---|---|
| 質問への回答 | 「ご質問ありがとうございます。結論は〇〇です。理由は△△で、詳しくはプロフィールのリンクの記事にまとめています」 |
| 間違いの指摘(正しかった) | 「ご指摘ありがとうございます。確認したところ誤りでした。本文を修正しました」 |
| 意見の違い | 「ご意見ありがとうございます。そういう見方もありますね。今回は〇〇の資料をもとに書いています」 |
| 答えられない相談 | 「個別のご事情についてはお答えが難しいため、専門の窓口へのご相談をおすすめします」 |
| 宣伝・営業 DM | 返信しない。必要なら「お問い合わせはフォームからお願いします」と1回だけ |

## 具体例: 良い返信と悪い返信

| 悪い例 | 理由 | 良い例 |
|---|---|---|
| 「ありがとうございます!」を全員に同じ文で | 機械的に見える | 「〇〇さん、△△の部分を試してくださったんですね。ありがとうございます」 |
| 批判に長文で反論 | 炎上の火種になる | 一晩置いてから、事実だけを短く |
| 誤りの指摘を黙って削除 | 隠したと受け取られる | お礼+訂正を明記 |
| コメントで住所や電話番号を聞く | 個人情報が公開される | 必要なら DM や問い合わせフォームへ誘導 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 全コメントに返そうとして疲れる | 返す範囲を決める。いいねだけで返すのも可 |
| 夜中の通知で反射的に返信 | 時間帯を決め、通知を切る |
| 返信の文面が毎回同じ | 相手の言葉を1つ引用してから返す |
| 誹謗中傷を消してしまい証拠がない | 先にスクリーンショット(日時・URL 入り)を保存してから非表示 |
| 嫌なコメントを何度も読み返してしまう | 非表示・ミュートを使い、対応は記録だけにする。つらいときは休む |

## 注意点

- 非表示・ブロック・報告の機能名と効果はサービスごとに違います(⚪ 各サービスの `engagement` ページ: [X](../02-x/06-engagement.md) / [Instagram](../03-instagram/06-engagement.md) / [note](../04-note/06-engagement.md))。
- コメントを次の投稿で紹介するときは、本人の許可を取るか、名前を伏せます([privacy-and-personal-info](privacy-and-personal-info.md))。
- 医療・法律・お金の個別相談には答えず、専門の窓口を案内します(⚪)。

## 測り方

返信率・返信までの平均時間・コメント1件あたりの会話の往復数を [週次レビュー](../../templates/weekly-review.md) に記録。

| 指標 | 計算 | 目安 |
|---|---|---|
| 返信率 | 返信したコメント ÷ 返信対象のコメント | 対象(質問など)は100%(⚪) |
| 返信までの時間 | コメントから返信までの平均 | 自分で決めた時間帯内 |
| 往復数 | 1つのコメントで続いたやり取りの回数 | 増えていれば会話が生まれている |

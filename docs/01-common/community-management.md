# コミュニティ運営

> **このページで分かること**: フォロワー同士が交流できる場(Discord・LINE オープンチャット・Facebook グループなど)の選び方、立ち上げの手順、ルールの作り方、モデレーション、トラブル対応。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [comments-and-engagement](comments-and-engagement.md)

## 概要

SNS のフォロワーは「発信者 → 読者」の一方向の関係が中心です。コミュニティは、**読者同士がつながり、会話が生まれる場**です。質問し合う、作品を見せ合う、イベントに集まるなど、参加者が自分ごととして関わるようになり、長く応援してくれる関係が育ちます。

一方で、**人が集まるほどトラブルも増えます**。荒らし、勧誘、個人情報の書き込み、参加者同士の対立などです。始める前に「何のための場か」「誰が管理するか」「ルールは何か」を決めておくことが、続けるための一番の準備です。

## 用語

| 用語 | 意味 |
|---|---|
| community(コミュニティ) | 共通の関心で集まる参加者の場 |
| server(サーバー) | Discord のコミュニティの単位 |
| channel(チャンネル) | 話題ごとに分けた部屋 |
| role(ロール、役割) | 参加者に付ける権限のまとまり(管理者、モデレーター、メンバーなど) |
| moderation(モデレーション) | ルールに沿って投稿・参加者を管理すること |
| moderator(モデレーター) | モデレーションを担当する人 |
| code of conduct(行動規範、ルール) | 参加者が守る約束ごと |
| onboarding(オンボーディング) | 新しく来た人を案内する仕組み |

## サービスの比較

| サービス | 特徴 | 規模・条件 | 向く使い方 | 確度 |
|---|---|---|---|---|
| Discord | チャンネル・ロール・ボイスチャットなど機能が多い。コミュニティ機能を有効にするには、認証レベルの設定、不適切な画像のフィルター、ルールのチャンネルなどが必要 | 参加人数の条件は未確認 | 創作・ゲーム・学習など活発な交流 | 🟡 Discord ヘルプ(検索要約) |
| LINE オープンチャット | LINE の友だち以外とトークルームで交流。匿名のプロフィールで参加できる | 最大5,000人(2019年(皇紀2679年・令和元年)の公式発表)、10,000人に拡張できるとする資料もある。共同管理者は最大100人とする資料 | 地域・趣味の情報交換、気軽な参加 | 🟡 報道・二次資料 |
| Facebook グループ | 公開/非公開の設定、参加時の質問、管理者ツール | ⚪ | 地域・同業者・年齢層の高い層 | ⚪ [08-facebook](../08-facebook/03-engagement-and-groups.md) |
| YouTube のメンバーシップ・コメント | 動画を中心とした交流、メンバー限定の投稿 | ⚪ | 動画の視聴者との交流 | ⚪ [YouTube のエンゲージメント](../05-youtube/04-engagement.md) |
| note のメンバーシップ | 記事を中心とした交流、掲示板 | ⚪ | 読者との深い関係 | ⚪ [membership-design](../10-creator-economy/05-membership-design.md) |

- 参加人数の上限や機能は変わります。**作成画面とヘルプで最新を確認**してください。

## 立ち上げの手順

1. **目的を1文で書く**: 例「作り置きの写真を見せ合い、質問し合う場」。
2. **対象者を決める**: 誰に来てほしいか、誰は対象外か(年齢、地域など)。
3. **サービスを選ぶ**: 対象者がすでに使っているサービスを優先する。
4. **公開範囲を決める**: 誰でも参加 / 承認制 / 有料メンバー限定。
5. **ルールを書く**(下の雛形)。
6. **管理体制を決める**: 管理者2人以上、モデレーター、対応できる時間帯。
7. **部屋(チャンネル)を最小限で作る**: 「はじめに」「自己紹介」「雑談」「質問」程度から(⚪ 多すぎると会話が分散する)。
8. **少人数で試運転**: 親しい読者10〜20人程度で始め、ルールを直す(⚪)。
9. **公開して案内する**: SNS のプロフィールや固定投稿から。

## ルールの雛形

```
【このコミュニティのルール】
目的: ○○について、楽しく情報交換する場です。

1. 他の参加者を尊重してください。攻撃・差別・からかいは禁止です。
2. 個人情報(住所・電話番号・本名・顔写真など)を書き込まないでください。
3. 宣伝・勧誘・外部サービスへの誘導は、許可された部屋以外では禁止です。
4. 他人の作品・画像を無断で転載しないでください。
5. 運営への連絡は「お問い合わせ」の部屋か DM でお願いします。

違反があった場合は、注意 → 一時停止 → 退出 の順に対応します。
重大な違反(脅迫、違法な内容など)は、すぐに退出していただきます。
```

- ルールは**短く、具体的に**。違反時の対応の段階も書いておくと、運営の判断がぶれにくくなります(⚪)。
- サービス自体の規約(Discord のコミュニティガイドライン、LINE の利用規約など)が前提です。

## モデレーションの実務

| 場面 | 対応 |
|---|---|
| 新しい人が来た | 「はじめに」の部屋でルールと使い方を案内。自己紹介の例を見せる |
| ルール違反の投稿 | 投稿を非表示・削除し、本人に理由を短く伝える |
| 荒らし・スパム | 削除し、参加を停止・退出させる。同じ手口に備えて単語のフィルターを設定 |
| 参加者同士の言い争い | 公開の場で長く議論せず、運営が間に入る。必要なら一時的に発言を制限 |
| 個人情報の書き込み | すぐに削除し、書き込んだ人と書かれた人に連絡 |
| 危険・違法な内容 | 証拠を保存して削除。サービスへの通報、必要に応じて警察などに相談 |

- **自動化機能**を活用します。例: YouTube のライブチャットでは、ブロックする単語、不適切な可能性のあるメッセージの保留、低速モード、モデレーターの指名ができる(✅ YouTube ヘルプ)。Discord・LINE にも同様の機能がある(⚪ 各ヘルプで確認)。
- **記録を残す**: いつ、誰に、何をしたか。判断の一貫性と、後から説明するために必要です。
- **運営の負担を見積もる**: 1日に確認する時間を決め、無理なら規模を小さく保つ。

## 盛り上げ方(⚪)

1. **お題を出す**: 「今週の1枚」「今月の質問」など、参加しやすい定期企画。
2. **最初の反応を運営がする**: 投稿に反応がないと、次の投稿が減る。
3. **参加者を紹介する**: 許可を得て、良い投稿を SNS で紹介。
4. **イベント**: オンラインの作業会、ライブ配信([live-streaming](live-streaming.md))。
5. **声を聞く**: 定期的にアンケートを取り、部屋やルールを見直す。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 部屋を作りすぎて、どこも静か | 部屋を減らし、会話を1か所に集める |
| 管理者が1人で、休むと荒れる | 管理者を2人以上にし、モデレーターを置く |
| ルールがあいまいで、対応が人によって違う | 違反の例と対応の段階を書く |
| 宣伝目的の参加者が増えた | 承認制にする、参加時の質問を設ける |
| 運営者が参加者と個人的に深く関わりすぎた | 運営としての連絡窓口を決め、私的なやり取りと分ける |
| 閉鎖時にデータや連絡手段を失った | 閉鎖の告知期間を設け、別の連絡手段(メールなど)を案内([newsletter-and-email](newsletter-and-email.md)) |

## 注意点

- **未成年の参加**: 年齢制限の有無を決め、大人と未成年の個人的なやり取りが起きにくい設計にする(⚪)。
- **個人情報**: 参加者の名簿・やり取りの扱いは [privacy-and-personal-info](privacy-and-personal-info.md)。
- **有料コミュニティ**: 特定商取引法の表示、提供内容の明示([legal-compliance](legal-compliance.md))。
- **炎上時**: 外部で話題になったら [crisis-response](crisis-response.md)。

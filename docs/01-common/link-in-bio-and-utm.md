# プロフィールのリンクと UTM 計測

> **このページで分かること**: SNS から自分のサイト・note・ショップ・LINE などへ人を送るリンクの置き方と、「どの投稿から何人来たか」を測る UTM パラメータの付け方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [analytics-kpi](analytics-kpi.md)

SNS から note・YouTube・EC・LINE へ**人を送る道**を設計し、**どこから来たか**を測ります。

## 概要

SNS の投稿は流れて消えますが、**プロフィールのリンク**は常に残る「入口」です。ここをどこに向けるかで、フォロワーが次に何をするか(記事を読む、商品を買う、メールに登録する)が決まります。

もう一つ大切なのが**計測**です。リンクに UTM パラメータという目印を付けておくと、Google アナリティクス 4(GA4)などの解析ツールで「Instagram のプロフィールから来た人」「X の固定ポストから来た人」を区別できます。測れないと、どの SNS に力を入れるべきか判断できません。

## 用語

| 用語 | 意味 |
|---|---|
| link in bio(リンクインバイオ) | プロフィール欄に置く1つのリンク。複数の行き先をまとめたページを指すことが多い |
| UTM parameter(UTM パラメータ) | URL の末尾に付ける計測用の目印(`?utm_source=...`) |
| GA4 / Google Analytics 4 | Google の無料のアクセス解析ツール |
| query string(クエリ文字列) | URL の `?` 以降の部分 |
| short URL(短縮 URL) | 長い URL を短く置き換えたもの |
| conversion(コンバージョン、成果) | 購入・登録など、最終的にしてほしい行動 |

## 1. リンクの置き場所

| サービス | 主な置き場所 | 注意 |
|---|---|---|
| X | プロフィール、固定ポスト | **本文に URL を入れる API 投稿は単価が高い**($0.200 vs $0.015 ✅)。プロフィール・固定ポストに集約する設計も |
| Instagram | プロフィールのリンク、ストーリーズのリンクスタンプ | キャプション内の URL はクリックできない(⚪) |
| YouTube | 説明文の冒頭、固定コメント、終了画面、カード | 説明文の冒頭2〜3行が表示される |
| TikTok | プロフィールのリンク(条件あり ⚪) | |
| note | 記事末尾、プロフィール | |
| Threads | プロフィール | |

## 2. リンクインバイオ(1つのリンクに複数の行き先)

| 方法 | 内容 | 費用 |
|---|---|---|
| 目次記事(note) | note の「はじめに」記事に全リンクを集約 | 無料 |
| 専用ツール | リンク集サービス(複数) | 無料〜有料 |
| 自サイトの1ページ | 完全に自前、計測も自由 | 自サイトの費用 |

- **1か所に集約**し、各サービスのプロフィールからは同じ URL へ(更新は1か所)。
- 上位3つ(最重要の行き先)を先頭に。

### リンク集ページの作り方(手順)

1. 行き先を書き出す(例: 最新記事、ショップ、メール登録、YouTube、問い合わせ)。
2. **今いちばん来てほしい行き先**を1位にする。5〜7個までに絞る(⚪ 多すぎると選ばれない)。
3. 各ボタンの文言を「何が得られるか」で書く(「ショップ」より「季節の新作を見る」)。
4. 各ボタンの URL に UTM を付ける(下の §3)。
5. スマホで開き、全ボタンを実際に押して確認する。
6. 月に1回、クリック数を見て順番を入れ替える。

## 3. UTM パラメータ

URL に付ける**計測用のタグ**。Google アナリティクス(GA4)などで、流入元を区別できます(✅ GA4 ヘルプ)。

| パラメータ | 意味 | 例 |
|---|---|---|
| `utm_source` | 流入元 | `x`、`instagram`、`youtube` |
| `utm_medium` | 媒体の種類 | `social`、`bio`、`story`、`description` |
| `utm_campaign` | 企画・キャンペーン | `2611_launch` |
| `utm_content` | 同じ企画内の区別 | `carousel_01`、`reel_02` |
| `utm_term` | キーワード(広告) | 任意 |

例: `https://example.com/?utm_source=instagram&utm_medium=bio&utm_campaign=2611_launch`

### 公式ヘルプで確認できたこと(✅ GA4 ヘルプ)

| 項目 | 内容 | 確度 |
|---|---|---|
| 必ず付けるもの | `utm_source`・`utm_medium`・`utm_campaign` の3つは常に使う。欠けるとレポートに `(not set)` と表示される | ✅ |
| 大文字と小文字 | **区別される**(`Instagram` と `instagram` は別の値)。すべて小文字に統一するのが推奨 | ✅ |
| その他のパラメータ | `utm_id`(キャンペーン ID)、`utm_source_platform` など | ✅ |
| 見る場所 | GA4 の[集客]>[トラフィック獲得]で、セッションの参照元/メディア・キャンペーンを確認 | ✅ |
| つなぎ方 | `?` で URL と区切り、`=` で名前と値、`&` で複数のパラメータをつなぐ。順序は自由 | ✅ |

### 命名規則

- **小文字・半角英数字・アンダースコア**で統一(表記ゆれを避ける)。GA4 は大文字と小文字を別の値として扱う(✅)。
- 日付は `YYMM`(例: `2611`)など短く。
- **スプレッドシートに台帳**を作る(同じ値を使い回すため)。

### 台帳の例

| 用途 | utm_source | utm_medium | utm_campaign | utm_content | 完成 URL |
|---|---|---|---|---|---|
| Instagram プロフィール | instagram | bio | always | linkpage | (生成した URL) |
| X 固定ポスト | x | pinned | 2611_launch | post_01 | |
| YouTube 説明文 | youtube | description | 2611_launch | video_12 | |
| メールマガジン | newsletter | email | 2611_launch | issue_05 | |

## 4. 短縮 URL・QR コード

| 項目 | 内容 |
|---|---|
| 短縮 URL | 長い UTM を短くできる。**行き先が分からない短縮は不信感**につながる。独自ドメインが望ましい |
| QR コード | 印刷物・動画の中に。**必ず実機で読み取りテスト**。URL に UTM を付けて計測 |
| 外部ツールの共有リンク | 有効期限があるリンクは避ける |

## 5. 計測の見方

| 見たいこと | 方法 |
|---|---|
| どの SNS から来たか | GA4 の流入元(`utm_source`) |
| どの投稿が効いたか | `utm_content` で区別 |
| 購入・登録までの転換 | イベント(コンバージョン)を設定 |
| 各サービスの内部指標 | リンククリック(Instagram のインサイト、X のアナリティクス、YouTube の流入元) |

- 内部指標と GA4 は**数え方が違う**ので、同じ数にはならない。傾向を見る。

## 具体例

| 良い例 | 悪い例 |
|---|---|
| `?utm_source=instagram&utm_medium=bio&utm_campaign=always` | `?utm_source=Instagram&utm_medium=Bio`(大文字混在、campaign なし) |
| ボタン名「新作の一覧を見る」 | ボタン名「こちら」 |
| リンク集の1位が「今月の企画」 | 10個以上のボタンが同じ大きさで並ぶ |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| UTM なしのリンクを貼り、流入元が分からない | 台帳から UTM 付き URL をコピーして使う |
| 大文字・小文字・表記ゆれで集計が分かれる | すべて小文字・決めた語だけを使う |
| 短縮 URL のサービスが終了してリンク切れ | 独自ドメインか、元の URL を台帳に残す |
| プロフィールのリンク先が古い企画のまま | 月1回の点検日を決める |
| GA4 とアプリ内の数が合わず悩む | 数え方が違う前提で、増減の傾向を見る |

## 6. 注意

- **note には GA4 を直接設置できない**場合がある(⚪ 要確認)。note 内の計測は note の機能を使う。
- UTM 付きの URL を**ステマ・PR の判断に影響させない**(広告表記は別)。
- **個人情報**(メールアドレス等)を URL に入れない。
- **プライバシー**: 計測ツールの設置と同意([privacy-and-personal-info](privacy-and-personal-info.md))。

## チェックリスト

- [ ] プロフィールのリンクは1か所(リンク集)に集約した
- [ ] 全リンクに `utm_source`・`utm_medium`・`utm_campaign` を付けた
- [ ] 値はすべて小文字で、台帳に記録した
- [ ] スマホで全ボタンを押して確認した
- [ ] 月1回、クリック数を見て並びを見直す日を決めた

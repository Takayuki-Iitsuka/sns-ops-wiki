# プロフィールのリンクと UTM 計測

SNS から note・YouTube・EC・LINE へ**人を送る道**を設計し、**どこから来たか**を測ります。

## 1. リンクの置き場所

| サービス | 主な置き場所 | 注意 |
|---|---|---|
| X | プロフィール、固定ポスト | **本文に URL を入れる API 投稿は単価が高い**($0.200 vs $0.015 ✅)。プロフィール・固定ポストに集約する設計も |
| Instagram | プロフィールのリンク、ストーリーズのリンクスタンプ | キャプション内の URL はクリックできない(⚪) |
| YouTube | 説明文の冒頭、固定コメント、終了画面、カード | 説明文の冒頭2〜3行が表示される |
| TikTok | プロフィールのリンク(条件あり ⚪) | |
| note | 記事末尾、プロフィール | |
| Threads | プロフィール | |

## 2. リンクインバイオ(1つのリンクに複数の行き先)

| 方法 | 内容 | 費用 |
|---|---|---|
| 目次記事(note) | note の「はじめに」記事に全リンクを集約 | 無料 |
| 専用ツール | リンク集サービス(複数) | 無料〜有料 |
| 自サイトの1ページ | 完全に自前、計測も自由 | 自サイトの費用 |

- **1か所に集約**し、各サービスのプロフィールからは同じ URL へ(更新は1か所)。
- 上位3つ(最重要の行き先)を先頭に。

## 3. UTM パラメータ

URL に付ける**計測用のタグ**。Google アナリティクス(GA4)などで、流入元を区別できます(⚪)。

| パラメータ | 意味 | 例 |
|---|---|---|
| `utm_source` | 流入元 | `x`、`instagram`、`youtube` |
| `utm_medium` | 媒体の種類 | `social`、`bio`、`story`、`description` |
| `utm_campaign` | 企画・キャンペーン | `2611_launch` |
| `utm_content` | 同じ企画内の区別 | `carousel_01`、`reel_02` |
| `utm_term` | キーワード(広告) | 任意 |

例: `https://example.com/?utm_source=instagram&utm_medium=bio&utm_campaign=2611_launch`

### 命名規則

- **小文字・半角英数字・アンダースコア**で統一(表記ゆれを避ける)。
- 日付は `YYMM`(例: `2611`)など短く。
- **スプレッドシートに台帳**を作る(同じ値を使い回すため)。

## 4. 短縮 URL・QR コード

| 項目 | 内容 |
|---|---|
| 短縮 URL | 長い UTM を短くできる。**行き先が分からない短縮は不信感**につながる。独自ドメインが望ましい |
| QR コード | 印刷物・動画の中に。**必ず実機で読み取りテスト**。URL に UTM を付けて計測 |
| 外部ツールの共有リンク | 有効期限があるリンクは避ける |

## 5. 計測の見方

| 見たいこと | 方法 |
|---|---|
| どの SNS から来たか | GA4 の流入元(`utm_source`) |
| どの投稿が効いたか | `utm_content` で区別 |
| 購入・登録までの転換 | イベント(コンバージョン)を設定 |
| 各サービスの内部指標 | リンククリック(Instagram のインサイト、X のアナリティクス、YouTube の流入元) |

- 内部指標と GA4 は**数え方が違う**ので、同じ数にはならない。傾向を見る。

## 6. 注意

- **note には GA4 を直接設置できない**場合がある(⚪ 要確認)。note 内の計測は note の機能を使う。
- UTM 付きの URL を**ステマ・PR の判断に影響させない**(広告表記は別)。
- **個人情報**(メールアドレス等)を URL に入れない。
- **プライバシー**: 計測ツールの設置と同意([privacy-and-personal-info](privacy-and-personal-info.md))。

# ニュースレター・メールマガジン

> **このページで分かること**: SNS とは別に「自分で持つ連絡手段」としてメールを持つ意義、配信サービス(Substack など)の選び方、登録の集め方、特定電子メール法の基本。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [link-in-bio-and-utm](link-in-bio-and-utm.md)

## 概要

SNS のフォロワーは、**サービスの仕様変更・アカウント停止・おすすめの仕組みの変化**で、急に届かなくなることがあります。フォロワーは「そのサービスの中の関係」で、自分の名簿ではありません。

メールマガジン(ニュースレター)は、読者が登録したメールアドレスに直接届けられる、**自分で持つ連絡手段**です。届く率が SNS の表示より安定しやすく、別のサービスに引っ越しても読者を連れて行ける点が強みです(⚪)。LINE 公式アカウントも同じ役割を持ちます([02-line-official-account](../09-other-services/02-line-official-account.md))。

ただし、**宣伝・販売を含むメールは法律で送り方が決まっています**(特定電子メール法・特定商取引法)。最初に同意の取り方と配信停止の仕組みを整えます。

## 用語

| 用語 | 意味 |
|---|---|
| newsletter(ニュースレター) | 定期的に送るお知らせ・読み物のメール。日本では「メルマガ」とも |
| ESP / email service provider(メール配信サービス) | 登録フォーム・配信・停止の管理をするサービス |
| opt-in(オプトイン、事前同意) | 受信者が先に「送ってよい」と同意すること |
| double opt-in(ダブルオプトイン) | 登録後に確認メールのリンクを押して初めて登録が完了する方式 |
| unsubscribe(配信停止) | 受信者が配信をやめる手続き |
| open rate(開封率) | 届いたメールのうち開かれた割合(計測の仕組み上、正確でないことがある ⚪) |
| bounce(バウンス、不達) | アドレスの誤り等で届かなかったメール |
| 特定電子メール | 営利団体・営業を営む個人が、広告・宣伝のために送るメール |

## 自前の連絡手段を持つ意義

| 観点 | SNS のフォロワー | メールの読者 |
|---|---|---|
| 名簿の持ち主 | サービス | 自分(配信サービスから書き出せることが多い ⚪) |
| 届き方 | おすすめの仕組みに左右される | 受信箱に届く(迷惑メール判定はある) |
| アカウント停止時 | 連絡できなくなる | 連絡を続けられる |
| 向く内容 | 短い発信、拡散 | 深い読み物、告知、販売 |

## 配信サービスの選び方

| 観点 | 確認すること |
|---|---|
| 料金 | 無料の範囲、読者数・配信数による課金、有料購読の手数料 |
| 有料購読 | 有料の読者限定配信ができるか、決済の手数料 |
| 書き出し | 読者リスト(CSV など)を書き出せるか |
| 日本語 | 管理画面・登録フォーム・配信停止ページの日本語表示 |
| 法令対応 | 送信者情報・配信停止リンクを自動で入れられるか |
| 計測 | 開封・クリックの計測、UTM の付与 |

### 主なサービス(料金は変わるため要確認)

| サービス | 特徴 | 料金・手数料 | 確度 |
|---|---|---|---|
| Substack | ニュースレター+Web 記事+有料購読 | 無料で配信可。有料購読は**売上の10%**+決済(Stripe)手数料 | 🟡 Substack FAQ(検索要約) |
| note | 記事+メンバーシップ(メール配信ではなく note 内の通知) | [04-note](../04-note/07-monetization.md) | 🟡 |
| LINE 公式アカウント | メッセージ配信(メールではない) | [02-line-official-account](../09-other-services/02-line-official-account.md) | 🟡 |
| 汎用のメール配信サービス | 企業向け、テンプレート・自動配信 | 各社の料金表 | ⚪ |

- Stripe の手数料は国・契約時期で異なる(🟡 二次資料で不一致)。**自分の決済画面で確認**してください。

## 特定電子メール法の基本(✅ e-Gov 法令検索)

正式名称は「特定電子メールの送信の適正化等に関する法律」(2002年(皇紀2662年・平成14年)法律第26号)です。

| 項目 | 内容 | 条文 |
|---|---|---|
| 対象 | 営利団体・営業を営む個人が、**自己または他人の営業の広告・宣伝のために送るメール**(特定電子メール) | 第2条第2号 |
| 送ってよい相手 | 原則として、**あらかじめ送信に同意(または求め)を通知した人**。ほかに、アドレスを通知した人、取引関係にある人、アドレスを公表している団体・営業者など | 第3条第1項 |
| 同意の記録 | 同意を受けた送信者は、**同意を証する記録を保存**しなければならない | 第3条第2項 |
| 配信停止 | 「送らないで」と通知を受けたら、その意思に反して送ってはならない | 第3条第3項 |
| 表示義務 | **送信者の氏名または名称**、**配信停止の通知を受けるためのメールアドレス等**、その他省令で定める事項を正しく表示する | 第4条 |
| 送信者情報の偽装の禁止 | 送信元のメールアドレス等を偽って送ってはならない | 第5条 |
| 罰則 | 第5条違反などは1年以下の拘禁刑または100万円以下の罰金。法人は3,000万円以下の罰金 | 第34条・第37条 |

- 「その他省令で定める事項」(送信者の住所、苦情・問い合わせの連絡先など)の詳細は、総務省・消費者庁のガイドラインで確認してください(⚪ 要確認)。
- **通信販売の電子メール広告**は、特定商取引法でも原則として**相手の承諾が必要**で、提供を受けない旨の意思表示があれば送れない(✅ 特定商取引法 第12条の3)。
- 登録時に集めるメールアドレスは個人情報です。利用目的を示します([privacy-and-personal-info](privacy-and-personal-info.md)、✅ 個人情報保護法 第21条)。

## 始める手順

1. **目的と頻度を決める**: 例「月2回、新作と作り方のコツ」。続けられる頻度に。
2. **配信サービスを選ぶ**(上の観点で比較)。
3. **登録フォームを作る**: 何が届くか、頻度、利用目的、配信停止の方法を書く。同意のチェックや登録ボタンで**同意の記録が残る**ようにする。
4. **ダブルオプトインを有効にする**(使えるサービスでは推奨 ⚪)。打ち間違い・なりすまし登録を防げる。
5. **署名(フッター)を整える**: 送信者名、問い合わせ先、配信停止リンク。
6. **SNS から誘導する**: プロフィールのリンク、固定投稿、記事の末尾。リンクには UTM を付ける([link-in-bio-and-utm](link-in-bio-and-utm.md))。
7. **初回のメール**を用意する(登録のお礼、これから届くもの)。
8. **振り返る**: 登録数、配信停止数、クリック数を月ごとに記録。

## 具体例

### 登録フォームの文例

```
月2回、新作のお知らせと作り方のコツをメールでお届けします。
・ご登録のメールアドレスは、このお知らせの配信にのみ使用します。
・配信はいつでも、メール末尾のリンクから停止できます。
[メールアドレス]  [登録する]
```

### 件名の例

| 良い例 | 避けたい例 |
|---|---|
| 「11月の新作3点と、焼き菓子の保存のコツ」 | 「【重要】必ずお読みください」(中身と不一致) |
| 「次回ライブ配信は11月20日 20時から」 | 「お知らせ」 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 名刺交換・問い合わせをくれた人に、同意なく宣伝メールを送った | 登録フォームで同意を取った人だけに送る |
| 配信停止リンクがない・分かりにくい | フッターに分かりやすく置く(表示義務) |
| 登録の同意の記録が残っていない | 登録日時・経路が残るサービスを使い、書き出して保管 |
| 他サービスの名簿を許可なく取り込んだ | 移行時は元の同意の範囲を確認する |
| 配信が不定期で、忘れた頃に届き迷惑扱いされる | 頻度を決め、登録フォームに書く |

## 注意点

- **購入した名簿・収集したアドレスへの送信はしない**(同意がない)。
- 共同運営・外部委託の場合も、**誰が送信者か**を明確にする。
- 公開リポジトリやスプレッドシートの共有設定に、読者のアドレスを置かない([CONTRIBUTING](../../CONTRIBUTING.md))。

# 文章術

> **このページで分かること**: SNS の投稿や記事を「最後まで読まれる・伝わる」文章にするための型、1行目の作り方、読みやすさの工夫、引用・翻訳の注意、推敲の手順。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)

## 概要

SNS の文章は、**スマホの小さな画面で、流し読みされる**ことを前提に書きます。読者は1行目で読むかどうかを決め、長い段落は飛ばします。

上手な文章は才能ではなく、**型を使い、短く区切り、見直す**ことで誰でも書けるようになります。このページの指針は一般的なもの(⚪)です。サービスごとの文字数の上限は各サービスのページ(例: [X の文章とハッシュタグ](../02-x/04-text-hashtags.md))を確認してください。

## 用語

| 用語 | 意味 |
|---|---|
| PREP(プレップ) | Point(結論)→ Reason(理由)→ Example(例)→ Point(結論)の順で書く型 |
| hook(フック、つかみ) | 冒頭で読者を引きつける一文 |
| CTA / call to action(行動喚起) | 「保存して」「リンクから」など次の行動を促す一文 |
| 推敲(すいこう) | 書いた文章を読み直して直すこと |
| 表記ゆれ | 同じ言葉の書き方が混ざること(「下さい」と「ください」など) |
| 意訳 | 原文の意味を優先して自然な言葉に訳すこと |

## 共通の型

| 型 | 構成 | 用途 |
|---|---|---|
| PREP | 結論 → 理由 → 具体例 → 結論 | 説明・主張 |
| 問い→答え | 問い → 展開 → 答え | 解説・考察 |
| 物語型 | 状況 → 事件 → 転換 → 余韻 | 物語の紹介、体験談 |
| 比較型 | 共通点 → 相違点 → 解釈 | A と B の比較 |
| リスト型 | 番号付きの要点 | 保存されやすい |

### 型を使った文例(汎用)

**PREP(料理アカウント)**

```
作り置きは「味を薄めに」が長持ちのコツです。
濃い味は時間がたつほど塩辛く感じやすいからです。
たとえば煮物は、食べる前に少し足すくらいでちょうどよくなります。
まずは薄めに作ってみてください。
```

**リスト型(イラストアカウント)**

```
線画がガタガタになる人へ、3つの見直しポイント
1. 線は一度で引かず、短く重ねない
2. 画面を回転させて、引きやすい向きにする
3. 手ぶれ補正の強さを1段上げる
保存して、次に描くときに試してみてください。
```

## 1行目の設計

- 疑問(「なぜ〜か」)、意外な事実、数字、場面の提示から始める。
- 釣り(誇大・誤導)は避ける。中身と一致させる。

| 良い1行目 | 避けたい1行目 |
|---|---|
| 「10分でできる、冷蔵で日持ちする副菜3つ」 | 「こんにちは!今日もよろしくお願いします」 |
| 「線画が震える原因は、ペンより“向き”でした」 | 「【衝撃】誰も知らない秘密を教えます」(中身と不一致) |
| 「今週末だけ、焼き菓子を店頭で販売します」 | 「お知らせです」 |

## 読みやすさ

1. 1文は短く(40字前後を目安 ⚪)。
2. 改行・箇条書きで視覚的に区切る(スマホ前提)。
3. 難読語は初出で読みを添える。漢字表記を優先しつつ、読めない人を置き去りにしない。
4. 専門用語は初出で**平易な言い換えを添える**(例: 「ハルシネーション(AI がもっともらしい誤りを出すこと)」)。
5. 受動態・二重否定を減らす。

### 書き換えの例

| 直す前 | 直した後 | 直した点 |
|---|---|---|
| 「本日は新商品の発売日となっておりますので、ぜひご来店いただけたらと思っております。」 | 「今日は新商品の発売日です。ぜひお店に来てください。」 | 1文を短く、回りくどさを減らした |
| 「できないことはないと思います」 | 「できます」 | 二重否定をやめた |
| 「エンゲージメントが高い」 | 「いいねや保存が多い」 | 専門用語を言い換えた |

## 引用・翻訳を扱う文章の注意

- 引用は**短く、出典付き**。引用部分は区別して表示(引用符や段落分け)。
- 翻訳・要約は**意訳であること**を示す。
- 「〜と言われている」ではなく、**誰が・どこで**言うかを示す。
- 年は「西暦(皇紀・和暦)」で書く(例: 2026年(皇紀2686年・令和8年))。
- 他言語で発信する場合の注意は [multilingual-and-global](multilingual-and-global.md)。

## 推敲チェック

- [ ] 結論が最初の3行にある
- [ ] 固有名詞(人名・地名・製品名)の表記が統一
- [ ] 誤字脱字、送り仮名
- [ ] 出典が示されている
- [ ] 断定の程度が適切
- [ ] 読者の次の行動が1つに絞られている

### 推敲の手順

1. 書き終えたら**少し時間を置く**(数分でもよい)。
2. **声に出して読む**(読みにくい所、息が続かない所が分かる)。
3. **スマホで表示**して、改行の位置と長さを確認する。
4. 上のチェックリストを通す。
5. 迷った言い回しは**短い方**を選ぶ。

## 声と口調

- 丁寧語を基本に、**親しみと敬意**を両立。
- 揶揄や皮肉は避ける。宗教・政治などの話題では特に。
- アカウント全体で口調をそろえる(「です・ます」と「だ・である」を混ぜない)。口調の決め方は [brand-and-visual-guidelines](brand-and-visual-guidelines.md)。

## サービスごとの書き分け(⚪)

| サービス | 文章の特徴 |
|---|---|
| X | 短く、1投稿1メッセージ。長い内容はスレッドに分ける |
| Instagram | 画像が主役。キャプションは冒頭の1〜2行が表示されるので要点を先に |
| Threads | 会話のように気軽に。問いかけが向く |
| note・ブログ | 見出しで区切り、導入で結論を示す |
| YouTube 説明文 | 冒頭に動画の要点、続けてチャプター・リンク |
| メールマガジン | 件名で中身が分かるように([newsletter-and-email](newsletter-and-email.md)) |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 前置きが長く、本題が見えない | 結論を1行目か2行目に置く |
| 1投稿に伝えたいことを詰め込む | 1投稿1メッセージ。残りは別の投稿に |
| 内輪の言葉・略語ばかり | 初めて見た人が分かる言葉に言い換える |
| 毎回口調が違う | 口調のルールを1枚にまとめる |
| 誇張したタイトルで反応は来たが批判も来た | 中身と一致する表現にする |

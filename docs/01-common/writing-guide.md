# 文章術

## 共通の型

| 型 | 構成 | 用途 |
|---|---|---|
| PREP | 結論 → 理由 → 具体例 → 結論 | 説明・主張 |
| 問い→答え | 問い → 展開 → 答え | 解説・考察 |
| 物語型 | 状況 → 事件 → 転換 → 余韻 | 物語の紹介、体験談 |
| 比較型 | 共通点 → 相違点 → 解釈 | A と B の比較 |
| リスト型 | 番号付きの要点 | 保存されやすい |

## 1行目の設計

- 疑問(「なぜ〜か」)、意外な事実、数字、場面の提示から始める。
- 釣り(誇大・誤導)は避ける。中身と一致させる。

## 読みやすさ

1. 1文は短く(40字前後を目安 ⚪)。
2. 改行・箇条書きで視覚的に区切る(スマホ前提)。
3. 難読語は初出で読みを添える。漢字表記を優先しつつ、読めない人を置き去りにしない。
4. 専門用語は初出で**平易な言い換えを添える**(例: 「ハルシネーション(AI がもっともらしい誤りを出すこと)」)。
5. 受動態・二重否定を減らす。

## 引用・翻訳を扱う文章の注意

- 引用は**短く、出典付き**。引用部分は区別して表示(引用符や段落分け)。
- 翻訳・要約は**意訳であること**を示す。
- 「〜と言われている」ではなく、**誰が・どこで**言うかを示す。
- 年は「西暦(皇紀・和暦)」で書く(例: 2026年(皇紀2686年・令和8年))。

## 推敲チェック

- [ ] 結論が最初の3行にある
- [ ] 固有名詞(人名・地名・製品名)の表記が統一
- [ ] 誤字脱字、送り仮名
- [ ] 出典が示されている
- [ ] 断定の程度が適切
- [ ] 読者の次の行動が1つに絞られている

## 声と口調

- 丁寧語を基本に、**親しみと敬意**を両立。
- 揶揄や皮肉は避ける。宗教・政治などの話題では特に。

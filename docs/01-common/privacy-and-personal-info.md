# 個人情報・プライバシーの扱い

> 一般的な整理です(⚪)。法令の条文は e-Gov 法令検索、個人情報保護委員会の資料で確認し、迷う場合は専門家へ(#61)。

## 1. SNS 運用で個人情報が関わる場面

| 場面 | 例 | リスク |
|---|---|---|
| **DM・メッセージ** | 質問、注文、相談 | 氏名・住所・連絡先が含まれる |
| **フォーム・応募** | プレゼント企画、問い合わせ、メルマガ登録 | 取得する情報の目的・保管 |
| **コメントの引用** | 読者のコメントを紹介 | 本人の許可なく晒すと問題 |
| **写真・動画** | 参加者・来店者・子どもの映像 | 肖像権・プライバシー、位置の特定 |
| **取材・インタビュー** | 取材相手の情報 | 事前の同意 |
| **位置情報** | 自宅の近く、生活圏の特定 | ストーカー・特定の被害 |
| **分析・計測** | Cookie、GA4、ピクセル | 外部送信の同意・通知 |
| **会員・購入者名簿** | メンバーシップ、物販 | 安全管理 |
| **未成年** | 若年ユーザーとのやり取り | 連絡先の交換を求めない |

## 2. 基本のルール(日本の個人情報保護法の考え方 ⚪)

1. **利用目的を特定し、通知・公表**する(例: 「応募の当選連絡に使用します」)。
2. **目的の範囲内**で使う。目的外の利用は本人の同意が必要。
3. **必要最小限**の情報だけ取得する(住所が不要なら聞かない)。
4. **安全管理**: 保管場所の限定、アクセス権限、暗号化、不要になったら削除。
5. **第三者提供**には原則として同意が必要。委託先の管理。
6. **本人からの開示・訂正・削除の求め**に応じる窓口を用意。
7. **漏えい時の対応**(委員会・本人への報告が必要な場合がある)。

## 3. 運用の実務

| 項目 | 推奨 |
|---|---|
| DM で個人情報を求めない | 注文・住所は専用フォームや決済サービスで |
| フォームの文言 | 利用目的・保管期間・問い合わせ先を明記 |
| 応募企画の管理 | 当選連絡後に**個人情報を削除**(期限を決める) |
| コメントの引用 | 許可を得るか、匿名化(アカウント名も伏せる) |
| 写真の公開 | 写り込みを確認、位置情報(Exif)を削除、**子どもの顔は特に慎重** |
| ツール連携 | 個人情報を外部ツールに流さない([11-tool-integrations](../20-api/11-tool-integrations.md)) |
| 公開リポジトリ | **個人情報を書かない**([CONTRIBUTING](../../CONTRIBUTING.md)) |
| 端末・アカウント | 2段階認証、画面ロック([account-security](account-security.md)) |

## 4. 特定商取引法・景品表示法との関係

- 販売では**特定商取引法に基づく表記**に氏名・住所・電話番号が関わる。個人事業主は**公開を避けたい**場合があるため、プラットフォームの代替手段(請求があれば開示する旨の表記など)を各サービスの規約で確認(⚪ #23 付近)。
- プレゼント企画は**景品表示法**の景品規制の対象となる場合がある(⚪)。

## 5. 外部送信(Cookie・計測)

- ウェブサイトにアクセス解析・広告のタグを入れる場合、**利用者への通知・同意**が関わる場合がある(電気通信事業法の外部送信規律など。⚪ 要確認)。
- SNS のプロフィールリンクから自サイトへ誘導する場合は、サイト側の**プライバシーポリシー**を用意。

## 6. 事故が起きたら

1. 該当の投稿・ファイルを**非公開/削除**(記録を残す)。
2. 影響範囲を把握(誰の何が、どこに)。
3. 本人へ連絡、必要なら窓口(個人情報保護委員会など)へ。
4. 再発防止([crisis-response](crisis-response.md)、[risk-register](../30-strategy/05-risk-register.md))。

# 個人情報・プライバシーの扱い

> **このページで分かること**: SNS 運用で個人情報に触れる場面と、日本の個人情報保護法の基本的な考え方、DM・応募企画・写真・計測での実務。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [legal-compliance](legal-compliance.md)

> 一般的な整理です(⚪)。法令の条文は e-Gov 法令検索、個人情報保護委員会の資料で確認し、迷う場合は専門家へ(#61)。

## 概要

SNS 運用では、思っている以上に他人の情報を扱います。DM で届く住所、プレゼント企画の応募者名、写真に写り込んだ人の顔、アクセス解析のデータなどです。

一度ネットに出た情報は**完全には消せません**。そのため、「集めない」「見せない」「早く消す」の3つを基本にします。個人情報保護法の義務は事業として扱う場合に関わることが多いですが、個人の運用でも同じ考え方で扱うと、トラブルと信頼の低下を防げます。

## 用語

| 用語 | 意味 |
|---|---|
| personal information(個人情報) | 氏名・顔写真など、特定の個人を識別できる情報 |
| 個人データ | 個人情報を検索できるように整理した名簿・データベースの中の情報 |
| 利用目的 | 集めた情報を何に使うか |
| third-party provision(第三者提供) | 集めた個人データを他の人・会社に渡すこと |
| 漏えい | 個人データが外部に流出すること |
| Exif(撮影情報) | 写真に含まれる撮影日時・位置情報など |
| Cookie(クッキー) | ウェブサイトが閲覧者のブラウザに保存する小さなデータ。計測・広告に使われる |
| 外部送信 | サイトを見た人の情報を、解析・広告ツールなど外部へ送ること |

## 1. SNS 運用で個人情報が関わる場面

| 場面 | 例 | リスク |
|---|---|---|
| **DM・メッセージ** | 質問、注文、相談 | 氏名・住所・連絡先が含まれる |
| **フォーム・応募** | プレゼント企画、問い合わせ、メルマガ登録 | 取得する情報の目的・保管 |
| **コメントの引用** | 読者のコメントを紹介 | 本人の許可なく晒すと問題 |
| **写真・動画** | 参加者・来店者・子どもの映像 | 肖像権・プライバシー、位置の特定 |
| **取材・インタビュー** | 取材相手の情報 | 事前の同意 |
| **位置情報** | 自宅の近く、生活圏の特定 | ストーカー・特定の被害 |
| **分析・計測** | Cookie、GA4、ピクセル | 外部送信の同意・通知 |
| **会員・購入者名簿** | メンバーシップ、物販 | 安全管理 |
| **未成年** | 若年ユーザーとのやり取り | 連絡先の交換を求めない |
| **コミュニティ・ライブ** | Discord・オープンチャットのメンバー、配信のコメント | 画面共有・アーカイブへの写り込み([community-management](community-management.md)) |

## 2. 基本のルール(日本の個人情報保護法の考え方 ⚪)

1. **利用目的を特定し、通知・公表**する(例: 「応募の当選連絡に使用します」)。取得したら、あらかじめ公表している場合を除き、速やかに利用目的を本人に通知または公表する(✅ 個人情報保護法 第21条)。
2. **目的の範囲内**で使う。目的外の利用は本人の同意が必要。
3. **必要最小限**の情報だけ取得する(住所が不要なら聞かない)。
4. **安全管理**: 保管場所の限定、アクセス権限、暗号化、不要になったら削除。
5. **第三者提供**には原則として同意が必要(✅ 同法 第27条。法令に基づく場合などの例外あり)。委託先の管理。
6. **本人からの開示・訂正・削除の求め**に応じる窓口を用意。
7. **漏えい時の対応**: 個人の権利利益を害するおそれが大きい一定の事態では、個人情報保護委員会への報告と本人への通知が必要(✅ 同法 第26条。対象の事態は委員会規則で定める)。

## 3. 運用の実務

| 項目 | 推奨 |
|---|---|
| DM で個人情報を求めない | 注文・住所は専用フォームや決済サービスで |
| フォームの文言 | 利用目的・保管期間・問い合わせ先を明記 |
| 応募企画の管理 | 当選連絡後に**個人情報を削除**(期限を決める) |
| コメントの引用 | 許可を得るか、匿名化(アカウント名も伏せる) |
| 写真の公開 | 写り込みを確認、位置情報(Exif)を削除、**子どもの顔は特に慎重** |
| ツール連携 | 個人情報を外部ツールに流さない([11-tool-integrations](../20-api/11-tool-integrations.md)) |
| 公開リポジトリ | **個人情報を書かない**([CONTRIBUTING](../../CONTRIBUTING.md)) |
| 端末・アカウント | 2段階認証、画面ロック([account-security](account-security.md)) |

### プレゼント企画の個人情報の流れ(手順例)

1. 応募は「フォロー+リポスト」など、**個人情報を集めない形**にする。
2. 当選者にだけ DM で連絡し、住所は**専用フォーム**で受け取る(DM に書いてもらわない)。
3. フォームに「利用目的(賞品の発送のみ)」「保管期間(発送後○日で削除)」「問い合わせ先」を書く。
4. 発送が終わったら、期限どおりにフォームの回答とメモを削除する。
5. 削除した日を記録する。

## 4. 特定商取引法・景品表示法との関係

- 販売では**特定商取引法に基づく表記**に氏名・住所・電話番号が関わる。個人事業主は**公開を避けたい**場合があるため、プラットフォームの代替手段(請求があれば開示する旨の表記など)を各サービスの規約で確認(⚪ #23 付近)。
- 特定商取引法 第11条ただし書には、請求により表示事項を記載した書面・電磁的記録を遅滞なく提供する旨を表示すれば一部を省略できる規定がある(✅)。どの事項を省略できるかは省令で定められるため、消費者庁の資料で確認(⚪)。
- プレゼント企画は**景品表示法**の景品規制の対象となる場合がある(⚪)。上限の表は [legal-compliance](legal-compliance.md)。

## 5. 外部送信(Cookie・計測)

- ウェブサイトにアクセス解析・広告のタグを入れる場合、**利用者への通知・同意**が関わる場合がある(電気通信事業法の外部送信規律など。⚪ 要確認)。
- 外部送信の規律は電気通信事業法 第27条の12 に置かれている(✅ 条文の所在。対象となる事業者・通知の方法は総務省の資料で確認 ⚪)。
- SNS のプロフィールリンクから自サイトへ誘導する場合は、サイト側の**プライバシーポリシー**を用意。

## 6. 事故が起きたら

1. 該当の投稿・ファイルを**非公開/削除**(記録を残す)。
2. 影響範囲を把握(誰の何が、どこに)。
3. 本人へ連絡、必要なら窓口(個人情報保護委員会など)へ。
4. 再発防止([crisis-response](crisis-response.md)、[risk-register](../30-strategy/05-risk-register.md))。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 当選者に DM で住所を送ってもらい、DM 履歴に残り続ける | 専用フォームで受け取り、期限を決めて削除 |
| 店内の写真に他のお客さんの顔が写っていた | 公開前に確認し、ぼかすか撮り直す |
| 自宅近くの写真で生活圏が特定された | 位置情報を削除し、窓の外の景色・郵便物・制服に注意 |
| 読者のコメントのスクリーンショットをアカウント名付きで紹介 | 許可を取るか、名前とアイコンを隠す |
| 画面共有・ライブ配信で通知や DM が映った | 配信前に通知を切り、不要なアプリを閉じる |

## チェックリスト

- [ ] 集める情報は必要最小限か(住所・電話番号は本当に必要か)
- [ ] 利用目的・保管期間・問い合わせ先を書いたか
- [ ] 削除の期限を決め、実行日を記録したか
- [ ] 写真の写り込み(顔・ナンバー・住所・位置情報)を確認したか
- [ ] 計測ツールを入れたサイトにプライバシーポリシーがあるか

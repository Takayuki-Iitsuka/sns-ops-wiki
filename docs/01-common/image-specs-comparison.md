## 実務の運用ルール(⚪ 経験則)

1. **元画像は大きめに作る**: 長辺 2000px 前後で作り、各サービス用に書き出す。
2. **重要な要素は中央80%に収める**: 自動トリミングされても欠けない(安全領域)。
3. **文字は大きく、少なく**: スマホ表示を基準にする。
4. **写真は JPEG、図・文字入りは PNG**: 劣化と容量のバランス。
5. **ファイル名で管理**: `YYYYMMDD_媒体_用途_連番.拡張子`(例: `20261103_ig_carousel_01.png`)。
6. **書き出し前にチェックリスト**: [templates/image-checklist.md](../../templates/image-checklist.md)

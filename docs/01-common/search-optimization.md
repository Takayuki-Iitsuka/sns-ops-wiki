# 検索される設計

> **このページで分かること**: SNS 内の検索・YouTube 検索・Web 検索で見つけてもらうための言葉の選び方と、置き場所(名前欄・タイトル・説明・字幕・見出し)。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [writing-guide](writing-guide.md)、[hashtags](hashtags.md)

**検索で見つけてもらう**ための基本です。X・Instagram・TikTok・YouTube・note・Web 検索のそれぞれで、検索の対象になる場所が異なります。

## 概要

SNS の投稿は、タイムラインやおすすめ欄で見られるだけでなく、**検索から何か月も後に見つけられる**ことがあります。特に YouTube・note・Web 記事は、検索からの流入が長く続く「資産」になりやすい形式です。

検索で見つけてもらうコツは、難しい技術ではなく「**読者が実際に入力する言葉**を、**検索の対象になる場所**に、**自然な文章で**入れる」ことです。人気の言葉を無関係に詰め込むと、読者の期待とずれ、逆効果になります。

## 用語

| 用語 | 意味 |
|---|---|
| SEO / search engine optimization(検索エンジン最適化) | 検索結果で見つけてもらいやすくする工夫 |
| keyword(キーワード、検索語) | 読者が検索窓に入力する言葉 |
| search intent(検索意図) | その言葉で検索した人が本当に知りたいこと |
| title link(タイトルリンク) | Google の検索結果に表示される青い見出し |
| chapter(チャプター) | YouTube 動画の区切りと見出し |
| 表記ゆれ | 同じ意味の言葉の書き方の違い(例: 「スマホ」「スマートフォン」) |

## 原則

1. **読者が検索する言葉**で題名・見出し・本文冒頭を作る。
2. **一つの記事・動画に一つの主題**。タイトルに主題を入れる。
3. **見出し(H2・H3)**を意味のある文にする(note の目次にも使われる ⚪)。
4. **更新履歴**を書き、古い情報を直す。
5. **画像の代替テキスト**と本文のキャプション([alt-text](alt-text.md))。
6. **表記ゆれ**(漢字/かな/カタカナ/別名)を想定し、初出で併記する。

## 検索語の探し方(手順)

1. 読者が困っていることを3つ書き出す(例: 「作り置き 日持ち」「イラスト 線画 ガタガタ」)。
2. 各 SNS や YouTube の検索窓に入力し、**表示される候補(サジェスト)**をメモする。
3. 実際に検索し、上位に出る投稿・動画が**どんな答え方をしているか**を見る(検索意図の確認)。
4. 自分が答えられる言葉を1つ選び、タイトル・冒頭・見出しに入れる。
5. 投稿後、各サービスの分析画面で「検索からの流入」や検索語を確認する(表示があるサービスのみ ⚪)。

## サービス別の検索対象(⚪)

| サービス | 検索の対象 | 工夫 |
|---|---|---|
| X | 本文、ハッシュタグ、プロフィール | 固有名詞を本文に入れる |
| Instagram | **名前欄**、ユーザーネーム、キャプション、ハッシュタグ | 名前欄に主題語 |
| TikTok | **動画内の言葉・字幕**、キャプション、タグ | 字幕に主題語 |
| YouTube | タイトル、説明文、字幕、チャプター | タイトル前半に主題、説明の冒頭に要点 |
| note | タイトル、本文、ハッシュタグ、Web 検索 | 目次記事、見出し |
| Web 検索 | ページのタイトル・見出し・本文 | タイトル30字前後で主題と価値(⚪ 目安) |

### YouTube で公式に確認できた工夫(✅)

| 項目 | 内容 | 確度 |
|---|---|---|
| チャプター | 説明欄にタイムスタンプと見出しの一覧を書く。**最初は 00:00**、**3つ以上**、昇順、各チャプターは**10秒以上** | ✅ |
| 自動チャプター | 新しくアップロードした動画では既定で有効。手動で入力すると自動生成は無効になる | ✅ |
| 翻訳したタイトルと説明 | YouTube Studio の[字幕]から言語を追加して入力。他の言語の視聴者の検索結果に表示される | ✅ |

### Web 検索のタイトル(✅ Google 検索セントラル)

- 各ページに**固有で、説明的かつ簡潔な**タイトルを付ける。キーワードの繰り返し(詰め込み)は避ける(✅)。
- `<title>` の長さに上限はないが、検索結果では**端末の幅に合わせて省略される**(✅)。上の「30字前後」は省略されにくい目安(⚪)。
- サイト名は先頭か末尾に、区切り記号(`-`、`:`、`|`)で簡潔に入れる(✅)。

## 表記ゆれ対策(例)

| 主題 | 検索されうる表記 | 方針 |
|---|---|---|
| 同じ語の別表記 | 漢字/かな/カタカナ/英語 | 本文は正確な表記、見出しや説明に別表記を併記 |
| 略称と正式名 | 略称・正式名称 | 初出で併記 |
| 製品名・人名の旧称 | 旧称・新称 | 併記し、更新日を記載 |

## SNS 内の検索

- **名前欄・ユーザーネーム・bio** に主題語を入れる(Instagram は名前欄が検索に使われる ⚪)。
- ハッシュタグは [hashtags](hashtags.md)。
- 固定投稿・ハイライトで「検索結果から見ても分かる」入口を作る。

## Web 検索(note・自サイト)

- タイトルで主題と価値を示し、導入文で結論を。
- 公式・一次資料の**引用リンク**を適切に置く。
- 検索順位を追う場合は、サービスの計測機能と検索コンソール(自サイトの場合)を使う。

## 具体例

| 良い例 | 悪い例 |
|---|---|
| タイトル「作り置きおかず 5品｜冷蔵で何日もつかの目安つき」 | タイトル「今日のごはん」 |
| Instagram の名前欄「地域のパン屋｜焼き上がり情報」 | 名前欄が店名のローマ字だけ |
| YouTube の説明冒頭に「この動画では○○を3ステップで解説します」 | 説明冒頭が SNS のリンクだけ |
| 字幕に主題の言葉が自然に出てくる | 字幕なし、キャプションにハッシュタグを30個 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 人気の言葉を内容と関係なく入れた | 検索意図に答えられる言葉だけを使う |
| 同じ主題の記事を何本も作り、どれも中途半端 | 1本にまとめて更新し続ける |
| タイトルが長く、肝心の言葉が省略された | 主題の言葉を前半に置く |
| YouTube のチャプターが表示されない | 00:00 始まり・3つ以上・各10秒以上を確認 |
| 古い情報の記事が検索で読まれ続ける | 更新日と変更点を書いて直す |

## やってはいけないこと

- 関連のない人気語の詰め込み
- 他サイトの文章の流用
- 過度な誇張タイトル(検索意図とのずれ)

## チェックリスト

- [ ] 読者が実際に検索する言葉を1つ決めた
- [ ] その言葉をタイトル前半・冒頭・見出しに自然に入れた
- [ ] 表記ゆれを初出で併記した
- [ ] YouTube はチャプターと説明冒頭を整えた
- [ ] 更新日を書いた

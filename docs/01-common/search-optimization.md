# 検索される設計

「古事記 神話」「天の岩戸 意味」など、**検索で見つけてもらう**ための基本です。

## 原則

1. **読者が検索する言葉**で題名・見出し・本文冒頭を作る(神名の表記ゆれ: 岩戸/石屋戸、須佐之男/素戔嗚 など)。
2. **一つの記事に一つの主題**。タイトルに主題を入れる。
3. **見出し(H2・H3)**を意味のある文にする(note の目次にも使われる ⚪)。
4. **更新履歴**を書き、古い情報を直す。
5. **画像の代替テキスト**と本文のキャプション([alt-text](alt-text.md))。

## 表記ゆれ対策

| 主題 | 検索されうる表記 | 方針 |
|---|---|---|
| 天の岩戸 | 天岩戸、天の石屋戸、天岩屋戸 | 本文は典拠の表記、見出しに別表記を併記(初出で) |
| 須佐之男命 | 素戔嗚尊、スサノオ | 同上。カタカナ表記も1回は入れる |
| 大国主神 | 大己貴神、オオクニヌシ | 別名の一覧を記事化 |

## SNS 内の検索

- **名前欄・ユーザーネーム・bio**に主題語を入れる(Instagram は名前欄が検索に使われる ⚪)。
- ハッシュタグは [08-hashtag-sets](../05-theme-kojiki/08-hashtag-sets.md)。
- 固定投稿・ハイライトで「検索結果から見ても分かる」入口を作る。

## Web 検索(note・サイト)

- タイトル 30字前後で主題と価値を示す(⚪ 目安)。
- 導入文で結論を示し、見出し構成を明確に。
- 公式・一次資料の**引用リンク**を適切に置く。
- 検索順位を追う場合は、サービスの計測機能と検索コンソール(自サイトの場合)を使う。

## やってはいけないこと

- 関連のない人気語の詰め込み
- 他サイトの文章の流用
- 過度な誇張タイトル(検索意図とのずれ)

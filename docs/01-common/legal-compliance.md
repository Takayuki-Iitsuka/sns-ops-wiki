# 法令・コンプライアンス(日本)

> **このページで分かること**: SNS 運用で関わる日本の主な法律(ステマ規制、景品規制、特定商取引法、特定電子メール法、著作権、個人情報)の「どこに気を付ければよいか」の地図です。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)

> 法律の一般的な整理です。個別判断は専門家・消費者庁へ。条文・告示は e-Gov 法令検索で確認してください。

## 概要

SNS は個人でも始められますが、**宣伝・販売・プレゼント企画・メール配信**を始めた時点で、事業者と同じ法律が関わることがあります。「知らなかった」では済まないため、最初に地図を持っておくことが大切です。

このページは「どの法律が、どの場面で関わるか」を示す入口です。条文の解釈が必要な場面では、必ず一次資料(消費者庁・e-Gov 法令検索)を読み、迷ったら専門家に相談してください。

## 用語

| 用語 | 意味 |
|---|---|
| 景品表示法(けいひんひょうじほう) | 不当な表示や過大な景品から消費者を守る法律。正式名称は「不当景品類及び不当表示防止法」 |
| stealth marketing(ステルスマーケティング、ステマ) | 広告であることを隠した宣伝 |
| 景品類 | 取引に付けて提供する物品・金銭など(プレゼント企画の賞品が当たることがある) |
| 特定商取引法(特商法) | 通信販売などの取引ルールを定める法律 |
| 特定電子メール法 | 広告・宣伝のメールの送り方を定める法律。正式名称は「特定電子メールの送信の適正化等に関する法律」 |
| opt-in(オプトイン、事前同意) | 受け取る人が先に「送ってよい」と同意する方式 |

## 場面別: どの法律が関わるか

| 場面 | 主に関わる法律・ルール | このページの節 |
|---|---|---|
| 企業から商品を受け取って紹介する | 景品表示法(ステマ規制) | ステマ規制 |
| フォロー&リポストでプレゼント | 景品表示法(景品規制)、各サービスの規約 | 景品規制 |
| 自作グッズ・有料コンテンツを売る | 特定商取引法 | 特定商取引法 |
| メルマガ・ニュースレターを送る | 特定電子メール法、特定商取引法 | メール広告 |
| 他人の画像・音楽・文章を使う | 著作権法 | 著作権・引用 |
| 他人の写真・個人情報を扱う | 個人情報保護法、肖像権 | 肖像権・プライバシー |
| 健康・お金の話題 | 医薬品医療機器等法、金融商品取引法など | 医療・金融 |

## ステルスマーケティング(ステマ)規制

- **景品表示法**に基づく告示により、事業者が広告であることを隠した表示は不当表示として規制される。**2023年(皇紀2683年・令和5年)10月1日から、ステルスマーケティングは景品表示法違反となる** ✅(消費者庁の公式ページの記載)。
- 対策: 広告・PR・提供を受けた投稿には、**一般消費者が一目で分かる表記**を付ける。
  - 例: 文頭に `【PR】` `#広告` `#PR`、「○○社から提供を受けて投稿」
  - 「#pr」を大量のハッシュタグの末尾に埋もれさせない、読み飛ばされない位置・大きさにする。
- 各サービスの「ブランドコンテンツ」「有料プロモーション表示」機能がある場合は併用(各 `10-policies.md`)。

### 初心者が迷いやすい点(⚪ 一般的な整理)

- **無償提供(商品だけもらった)でも**、企業が投稿内容に関与していれば広告に当たる場合があります。金銭の有無だけで判断しないでください。
- 動画では、**冒頭の画面表示と説明文の両方**に表記すると見落とされにくくなります。
- ストーリーズやライブなど**消える・流れる形式**でも表記が必要です。

## 景品規制(プレゼント企画)

プレゼント企画は、**商品の購入や来店を条件にするかどうか**で扱いが変わります(✅ 消費者庁「景品規制の概要」)。

| 種類 | 内容 | 景品の上限 | 確度 |
|---|---|---|---|
| 一般懸賞 | 購入者などを対象に、くじ・クイズ等で当選者を決める | 取引価額 5,000円未満: 取引価額の20倍 / 5,000円以上: 10万円。総額は売上予定総額の2% | ✅ |
| 共同懸賞 | 地域の複数事業者が共同で行う懸賞 | 最高 30万円、総額は売上予定総額の3% | ✅ |
| 総付景品 | 購入者・来店者全員などに提供 | 取引価額 1,000円未満: 200円 / 1,000円以上: 取引価額の10分の2 | ✅ |
| オープン懸賞 | 購入・来店を条件にせず、SNS などで誰でも応募できる | 景品規制の対象外。具体的な上限額の定めはない(2006年(皇紀2666年・平成18年)4月に撤廃) | ✅ |

- 「フォロー&リポストで応募」は、購入を条件にしなければオープン懸賞に近い形と考えられますが、**事業の内容や条件の付け方で判断が変わる**ため、迷ったら消費者庁の資料・専門家で確認してください(⚪)。
- 景品規制とは別に、**各 SNS の規約**(キャンペーンのルール、スパム扱い)にも従います。
- 応募者の個人情報の扱いは [privacy-and-personal-info](privacy-and-personal-info.md)。

## 著作権・引用

- 他人の画像・文章・音楽の無断使用は侵害のおそれ。**引用は要件**(必要性・主従関係・出典明示等)を満たす場合のみ。
- 画像は自作、ライセンス明記の素材、許諾済みのものを使う。生成 AI の出力も利用規約・既存著作物への類似に注意。
- スクリーンショット・他人の投稿の転載は規約と権利に注意。
- 詳しくは [image-sources-and-copyright](image-sources-and-copyright.md)、音楽は [music-and-licensing](music-and-licensing.md)。

## 肖像権・プライバシー

- 他人の顔・車のナンバー・住所が分かる画像は公開前に確認。位置情報(Exif)は削除する。
- 個人情報保護法の基本は [privacy-and-personal-info](privacy-and-personal-info.md)。

## 特定商取引法・景品

- 物販や有料コンテンツの継続販売は、**特定商取引法に基づく表記**が必要となる場合がある。プレゼント企画は景品規制の対象となる場合あり(⚪ 要確認)。
- 通信販売の広告には、**価格(送料)、支払時期・方法、引渡時期、申込みの撤回・解除(返品)に関する事項**などを表示する(✅ 特定商取引法 第11条)。請求があれば遅滞なく書面・電磁的記録で提供する旨を表示すれば、一部を省略できる(✅ 同条ただし書)。
- 誇大広告(著しく事実と違う、実際より著しく優良・有利と誤認させる表示)は禁止(✅ 同法 第12条)。
- 販売プラットフォーム(BOOTH、note など)を使う場合も、**表記の場所と内容は各サービスのヘルプ**で確認する(⚪)。

## メール広告(メルマガ・ニュースレター)

- **広告・宣伝のメールは、原則として事前に同意した人にだけ送れる**(✅ 特定電子メール法 第3条)。同意の記録を保存する義務がある(✅ 同条第2項)。
- メールには **送信者の氏名・名称、配信停止の連絡先** などを表示する(✅ 同法 第4条)。送信者情報を偽る送信は禁止(✅ 第5条)。
- 通信販売の電子メール広告も、原則として相手の承諾が必要(✅ 特定商取引法 第12条の3)。
- 詳しくは [newsletter-and-email](newsletter-and-email.md)。

## 医療・金融・投資等の表現

- 効果効能の断定、投資勧誘、医療的助言は法規制・サービス規約の対象になりやすい。避けるか、専門家の確認を得る。
- 書き方の指針は [sensitive-topics-and-accuracy](sensitive-topics-and-accuracy.md)。

## よくある失敗と対処

| 失敗 | なぜ問題か | 対処 |
|---|---|---|
| `#PR` をハッシュタグの最後に小さく付けた | 一般消費者が広告と気付けない | 文頭・冒頭画面に表記する |
| 「購入者限定で高額賞品プレゼント」 | 一般懸賞の上限を超えるおそれ | 消費者庁の表で上限を確認する |
| 名刺交換した相手にメルマガを送り始めた | 同意の範囲・記録が不明確 | 登録フォームで同意を取り、記録を残す |
| 販売ページに返品の扱いを書いていない | 特商法の表示事項が欠ける | 表示事項の一覧で点検する |
| 他人のイラストを「引用」として丸ごと掲載 | 引用の要件(主従関係など)を満たさない | 許諾を取るか、リンクで紹介する |

## チェックリスト

- [ ] 依頼・提供を受けた投稿に、一目で分かる広告表記がある
- [ ] プレゼント企画の種類(オープン懸賞か一般懸賞か)を確認した
- [ ] 販売ページに特定商取引法の表示事項がある
- [ ] メール配信は事前同意と配信停止の手段がある
- [ ] 他人の画像・音楽・文章の権利を確認した
- [ ] 個人情報・位置情報が写り込んでいない

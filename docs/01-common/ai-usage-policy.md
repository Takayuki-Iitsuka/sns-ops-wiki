# 生成 AI の利用方針

## 原則

1. **事実の根拠にしない**: 生成 AI の出力は誤り(ハルシネーション)を含み得る。**出典は必ず一次資料で確認**する。
2. **透明性**: 画像・文章に AI を使った場合は、その旨を適切な形で示す。
3. **権利**: 既存の作品に酷似する生成物、学習元の不明な素材は使わない。
4. **配慮**: 宗教・実在の人物の描写は [sensitive-topics](sensitive-topics-and-accuracy.md) に従う。

## 用途別

| 用途 | 可否・条件 |
|---|---|
| 文章の下書き・構成案 | 可。人が事実・表現を確認して書き直す |
| 校正・誤字チェック | 可 |
| 要約・翻訳の補助 | 可。原文との照合を必須に |
| 固有名詞・数値・日付の確認 | **AI のみで確定しない**。一次資料で確認 |
| 画像生成 | 条件付き。AI 生成の明記、権利・規約の確認 |
| 翻訳 | 補助として可。**最終訳は人が責任を持つ**。既存訳の丸写しを避ける |

## 表示

- 画像: キャプション/画像内に「AI 生成」または「イラスト: AI 補助」と明記。
- サービスによっては**AI 生成コンテンツのラベル**機能・規約がある(⚪ 要確認)。各サービスの `10-policies.md` を参照。

## プロンプト・出力の記録

- 使ったツール、日付、プロンプトの要点、修正点を台帳に残す。
- ツールの**利用規約(商用利用・生成物の権利)**を確認し、記録する。

## 避けること

- 他人の作風をそのまま真似る指示
- 実在の人物の写真風画像
- 出典のない「AI が教えてくれた」知識の掲載

# 生成 AI の利用方針

> **このページで分かること**: SNS 運用で生成 AI(文章・画像・音声を作る AI)を安全に使うための原則、用途ごとの可否、表示の仕方、記録の残し方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: なし。サービスごとの開示ルールと設定は [ai-rules-by-platform](ai-rules-by-platform.md)

## 概要

生成 AI(generative AI)は、下書き・要約・画像作りを速くしてくれる便利な道具です。一方で、次の3つのリスクがあります。

1. **間違いをもっともらしく書く**(ハルシネーション)。
2. **他人の権利を侵害する**生成物ができることがある(既存の作品に似た画像など)。
3. **AI で作ったと分からない**と、見る人を誤解させる(本物の写真・本人の発言だと思われる)。

このページは「どのサービスでも共通の自分たちのルール」です。各サービスが定める開示義務・ラベル機能は [ai-rules-by-platform](ai-rules-by-platform.md) で確認します。

## 用語

| 用語 | 意味 |
|---|---|
| generative AI(生成 AI) | 指示文から文章・画像・音声・動画を作る AI |
| prompt(プロンプト) | AI への指示文 |
| hallucination(ハルシネーション、幻覚) | AI が事実でない内容をもっともらしく出力すること |
| primary source(一次資料) | 公式ヘルプ、法令、原典など、情報の出どころそのもの |
| disclosure(開示) | 「AI を使った」と見る人に知らせること |
| label(ラベル) | サービスが投稿に付ける「AI 生成」などの表示 |
| terms of service(利用規約) | AI ツールの使い方・商用利用・生成物の権利を定めた約束事 |

## 原則

1. **事実の根拠にしない**: 生成 AI の出力は誤り(ハルシネーション)を含み得る。**出典は必ず一次資料で確認**する。
2. **透明性**: 画像・文章に AI を使った場合は、その旨を適切な形で示す。
3. **権利**: 既存の作品に酷似する生成物、学習元の不明な素材は使わない。文化庁の「AIと著作権に関する考え方について」は、文化審議会 著作権分科会 法制度小委員会が2024年(皇紀2684年・令和6年)3月15日に取りまとめたものです(✅ 文化庁ページで取りまとめ日・主体を確認。中身の論点は [ai-rules-by-platform](ai-rules-by-platform.md) §5)。
4. **配慮**: 宗教・実在の人物の描写は [sensitive-topics](sensitive-topics-and-accuracy.md) に従う。
5. **最終責任は人**: AI が書いたものでも、投稿した人(運用者)が責任を負う前提で確認する(⚪)。

## 用途別の可否

| 用途 | 可否・条件 |
|---|---|
| 文章の下書き・構成案 | 可。人が事実・表現を確認して書き直す |
| 校正・誤字チェック | 可 |
| 要約・翻訳の補助 | 可。原文との照合を必須に |
| 固有名詞・数値・日付の確認 | **AI のみで確定しない**。一次資料で確認 |
| 画像生成 | 条件付き。AI 生成の明記、権利・規約の確認 |
| 翻訳 | 補助として可。**最終訳は人が責任を持つ**。既存訳の丸写しを避ける |
| 代替テキスト(alt)の下書き | 可。画像と照合して直す([alt-text](alt-text.md) §6) |
| ハッシュタグ・タイトル案 | 可。最終判断は人。無関係なタグを混ぜない([hashtags](hashtags.md)) |
| コメントへの自動返信 | 原則しない。サービスの規約・API の制限も確認([ai-rules-by-platform](ai-rules-by-platform.md) §4) |
| 体験談・レビュー・お客様の声 | **作らない**(実体験でない体験談は不当表示になり得る ⚪。[legal-compliance](legal-compliance.md)) |

## 手順: AI を使って1本の投稿を作る流れ

1. **目的を決める**: 何を AI に任せ、何を人がやるかを書き出す(例: 構成案は AI、事実確認と最終文は人)。
2. **入力を確認**: 個人情報・顧客情報・未公開の数字・パスワードを**プロンプトに入れない**。
3. **生成する**: 出力は「下書き」として扱う。
4. **事実確認**: 固有名詞・数値・日付・引用を一次資料で照合する。照合できない部分は削る。
5. **権利確認**: 画像は既存の作品・キャラクター・実在人物に似ていないか確認する。
6. **表示**: 必要に応じてキャプションに AI 利用を書き、サービスの AI ラベル設定をオンにする。
7. **記録**: 台帳(下記)に残す。

## 表示

- 画像: キャプション/画像内に「AI 生成」または「イラスト: AI 補助」と明記。
- サービスによっては**AI 生成コンテンツのラベル**機能・規約がある。たとえば YouTube は、本物のように見える AI 生成・改変コンテンツに開示を求めています(✅ YouTube ヘルプ)。各サービスの詳細は [ai-rules-by-platform](ai-rules-by-platform.md) と各サービスの `policies` ページを参照。

### 表示の文例

```
この画像は AI(ツール名)で生成しました。
```

```
文章の下書きに AI を使い、人が事実確認して編集しています。
```

```
背景のみ AI で拡張しています。人物・商品は実写です。
```

## プロンプト・出力の記録

- 使ったツール、日付、プロンプトの要点、修正点を台帳に残す。
- ツールの**利用規約(商用利用・生成物の権利)**を確認し、記録する。

### 台帳(雛形)

| 日付 | ツール名・版 | 用途 | プロンプトの要点 | 人が直した点 | 開示の有無 | 規約の確認日 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

> 台帳は非公開の場所に置きます。プロンプトに個人情報が入っていた場合は、記録から削除します。

## 具体例

| 場面 | 良い使い方 | 悪い使い方 |
|---|---|---|
| 解説投稿 | AI に構成案を出させ、各項目を公式ヘルプで確認して書く | AI の説明をそのまま貼る(数値が古い・誤り) |
| 告知画像 | AI で背景素材を作り、文字は自分で配置。キャプションに「背景は AI 生成」 | 他社キャラクター風の絵を生成して使う |
| 商品紹介 | 実物の写真を使い、AI は文章の校正だけ | AI で「使ってみた感想」を作る |

## よくある失敗と対処

| 失敗 | 起きること | 対処 |
|---|---|---|
| AI の出した数値・日付をそのまま投稿 | 誤情報として指摘・拡散される | 一次資料で照合。できなければ書かない([crisis-response](crisis-response.md)) |
| 有名作品の作風を指定して生成 | 権利侵害・炎上のおそれ | 作風の指定をやめ、自分の言葉で要素を指示 |
| 顧客名や未公開情報をプロンプトに貼る | 情報漏えい | 入力前に伏せ字にする。ツールの履歴・学習設定を確認 |
| 開示を忘れる | 「本物と偽った」と受け取られる | 投稿前チェックリストに「AI 開示」を入れる |
| ツールの規約を読んでいない | 商用利用不可の生成物を収益化してしまう | 台帳に規約の確認日を書く |

## 避けること

- 他人の作風をそのまま真似る指示
- 実在の人物の写真風画像
- 出典のない「AI が教えてくれた」知識の掲載

## 注意点

- AI ツールの規約・機能・料金は頻繁に変わります。料金は [40-pricing/05-ai-and-creative-tools](../40-pricing/05-ai-and-creative-tools.md)。
- 「AI 生成物に著作権が発生するか」「どこまでが侵害か」は個別の事情で判断が分かれます。迷う場合は専門家に相談してください(⚪)。

# 画像の説明文(alt text、代替テキスト)

## なぜ書くか

- 視覚障害のある人のスクリーンリーダー対応(アクセシビリティ)。
- 画像が読み込めない場合の代替表示。
- 検索エンジン・アルゴリズムが内容を理解する手がかりになる可能性(⚪ 効果は未検証)。

## 書き方の原則

1. **見えているものを事実で書く**: 「誰が・何を・どこで・どうしている」。
2. **画像内の文字は全文書く**(チラシ、スクリーンショット、図表)。
3. **「画像」「写真」を冒頭に付けない**(読み上げで自明)。必要なら種別だけ(例: グラフ、イラスト)。
4. **装飾的で情報がない画像は無理に書かない**(対応サービスのみ)。
5. **1〜2文、長くても数百字**。詳細は本文に書く。
6. **宣伝文句やキーワードの詰め込み禁止**。

## 例

| 悪い例 | 良い例 |
|---|---|
| `写真` | `机の上のノートパソコンと、SNS運用の週次計画を書いた付箋3枚` |
| `グラフ` | `折れ線グラフ。10月のフォロワー数が1週目の120人から4週目の310人に増加` |

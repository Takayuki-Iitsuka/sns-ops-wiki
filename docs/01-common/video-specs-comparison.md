# 動画仕様の横断比較

> **公式で確認済み(✅)の値は 0 件**です。資料間で食い違う値は併記し、[要検証リスト](../00-meta/verification-queue.md) に載せています。書き出し値は [export-presets](export-presets.md)、制作の考え方は [video-basics](video-basics.md)。

## 1. 縦型・短尺動画

| サービス | 形式 | 比率・解像度 | 長さ | 容量 | 確度・備考 |
|---|---|---|---|---|---|
| Instagram リール | MP4 / MOV(H.264+AAC が一般的) | 9:16、1080×1920 | 資料により 90秒〜3分〜20分と不一致 | 約4GB とする資料が多い。API 公開は 100MB/300MB と不一致 | 🟡 |
| YouTube Shorts | MP4 など | 9:16、1080×1920 | **3分まで**とする新しい資料。60秒とする古い資料あり | — | 🟡 |
| TikTok | MP4 / MOV(H.264+AAC) | 9:16、1080×1920 | 10分(一部アカウント60分)とする資料が多い | モバイル 約72MB(Android)/ 約288MB(iOS)、Web 1GB〜と不一致 | 🟡 |
| Threads | MP4 / MOV | 9:16 推奨(1:1、16:9 も可) | 3秒〜5分 | 500MB〜1GB と不一致 | 🟡 |
| X | MP4 / MOV | 1:3〜3:1。推奨 1280×720、720×1280、720×720(docs.x.com) | 通常アカウント 約2分20秒 | 512MB(通常)。Premium は拡張 | 🟡 |
| Facebook リール | MP4 など | 9:16 | 未確認 | 未確認 | ⚪ |
| Bluesky | MP4 | — | 3分(従来)/ 10分(新)と不一致 | 100MB(従来)/ 300MB(新) | 🟡 |

## 2. 横型・長尺動画

| サービス | 形式 | 比率・解像度 | 長さ・容量 | 確度 |
|---|---|---|---|---|
| YouTube | MP4(H.264+AAC)が一般的 | 16:9(1920×1080、3840×2160) | 最大 256GB または 12時間のいずれか小さい方とする資料 | 🟡 |
| Facebook | 未確認 | 16:9 | 未確認 | ⚪ |
| X | 上記 | 16:9(1280×720 推奨) | 上記 | 🟡 |

## 3. エンコードの一般的な推奨(🟡 二次資料)

| 項目 | 推奨 |
|---|---|
| コンテナ・コーデック | MP4、映像 H.264、音声 AAC |
| フレームレート | 24〜60fps(X は 60fps 以下、30 または 60) |
| ビットレート | YouTube の目安: 1080p で約8Mbps、4K で35〜45Mbps(アップロード推奨値) |
| 音声 | AAC-LC、ステレオ、384kbps とする資料あり |
| カラー | sRGB / Rec.709 |

## 4. サムネイル・カバー

| サービス | 用途 | 推奨 | 確度 |
|---|---|---|---|
| YouTube | 動画サムネイル | 1280×720、2MB 未満、JPEG/PNG。**カスタムには電話番号の確認が必要**とする資料 | 🟡 |
| YouTube Shorts | カスタムサムネイル | 1080×1920 とする資料と 16:9 とする資料が不一致 | 🟡 |
| Instagram | リールのカバー | JPEG、8MB 以下(API)。プロフィールグリッドの切り抜きは仕様変更あり | 🟡 |
| TikTok | カバー | 動画の一コマ/画像 | ⚪ |

## 5. 運用上の注意

1. **長さの上限は変更が頻繁**: 投稿前にアプリ内で確認し、検証結果を [verification-queue](../00-meta/verification-queue.md) に記録する。
2. **API 投稿は UI より上限が厳しいことがある**(Instagram の 100MB/300MB の不一致など)。API を使う場合は [20-api](../20-api/README.md) を参照。
3. **縦型は安全領域**: 上部・下部にUI(ユーザー名、キャプション、ボタン)が重なる。**上下約10〜15%、右側約15%**を空ける(⚪ 経験則。各アプリで実機確認)。
4. **字幕を焼き込む**場合は、ここに重ならない位置に。
5. 複数サービスに同じ動画を出すなら、**縦型 1080×1920 の1本を基準**に、透かし(他社ロゴ)を入れない。他サービスのウォーターマーク付き動画は推奨度が下がる可能性(⚪ 要確認)。

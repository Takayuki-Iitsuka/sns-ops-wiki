# 慎重な話題の扱いと正確さ

宗教、政治、歴史認識、医療、投資、災害、実在の人物など、**誤りや言い方が信頼や安全に直結する話題**の運用指針です。

## 書き分けの基本

| 区分 | 書き方 |
|---|---|
| 確認できる事実 | 出典を示す |
| 専門家・研究者の解釈 | 「〜という説がある(誰の説か)」 |
| 信仰・慣習 | 「〜と伝えられている」「〜とされる」 |
| 自分の意見 | 「私は〜と考えます」と明示 |

## 避けること

1. 特定の団体・個人への攻撃、差別につながる表現。
2. 根拠のない断定、効果効能の保証、投資・医療の助言。
3. 出典不明の情報の拡散(まとめ記事、匿名の投稿)。
4. 悲惨な出来事・災害を宣伝に使うこと。
5. 他人の個人情報、位置の特定につながる情報。

## 正確さの確保

1. 投稿前に**出典を2点以上**で確認(一次資料＋解説)。
2. 数字・日付は**調べた元を台帳に記録**。
3. 訂正は**速やかに、元の投稿へ返信**。
4. 専門家に確認できるときは確認を依頼する。
5. 出典の更新(法令・規約・仕様)は定期的に見直す([verification-queue](../00-meta/verification-queue.md))。

## 訂正の雛形

```
訂正とお詫び:
先の投稿で「…」と書きましたが、正しくは「…」です(出典: …)。
ご指摘ありがとうございました。
```

## 画像・生成 AI

- 実在の人物・宗教的な対象を写実的に描く場合は慎重に。象徴的な表現を検討。
- 生成 AI の画像は明記([ai-usage-policy](ai-usage-policy.md))。

## 批判・指摘への対応

事実の指摘は感謝して確認・訂正。解釈の違いは出典を示して丁寧に、深追いしない。攻撃には [crisis-response](crisis-response.md)。

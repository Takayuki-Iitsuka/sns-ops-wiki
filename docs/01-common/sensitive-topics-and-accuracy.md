# 慎重な話題の扱いと正確さ

> **このページで分かること**: 誤りや言い方が信頼・安全に直結する話題(宗教・政治・医療・投資・災害・実在の人物など)で、事実・解釈・意見を書き分け、正確さを確保し、間違えたときに訂正する方法。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [writing-guide](writing-guide.md)

宗教、政治、歴史認識、医療、投資、災害、実在の人物など、**誤りや言い方が信頼や安全に直結する話題**の運用指針です。

## 概要

SNS では、短い文章が切り取られて広まります。慎重な話題で誤った情報や断定的な言い方をすると、**誰かを傷つけたり、健康・お金の判断を誤らせたり、アカウントの信頼を一度に失ったり**することがあります。各サービスの規約でも、医療の誤情報や災害時のデマなどは制限の対象になりやすい分野です(⚪ 各サービスの `10-policies.md` を参照)。

大切なのは「書かないこと」ではなく、**確認したこと・他人の解釈・自分の意見を区別して書くこと**と、**間違えたら早く直すこと**です。

## 用語

| 用語 | 意味 |
|---|---|
| primary source(一次資料) | 当事者・公的機関・原典など、情報の出どころそのもの |
| secondary source(二次資料) | 一次資料を紹介・解説したもの(報道、解説記事) |
| misinformation(誤情報) | 意図せず広まる誤った情報 |
| disinformation(偽情報) | 意図的に作られた誤った情報 |
| fact check(事実確認、ファクトチェック) | 情報が正しいかを資料で確かめること |
| correction(訂正) | 誤りを認めて正しい情報に直すこと |

## 書き分けの基本

| 区分 | 書き方 |
|---|---|
| 確認できる事実 | 出典を示す |
| 専門家・研究者の解釈 | 「〜という説がある(誰の説か)」 |
| 信仰・慣習 | 「〜と伝えられている」「〜とされる」 |
| 自分の意見 | 「私は〜と考えます」と明示 |

### 書き分けの文例(汎用)

| 区分 | 文例 |
|---|---|
| 事実 | 「○○省の資料(2026年(皇紀2686年・令和8年)版)では、△△と示されています。」 |
| 解釈 | 「□□大学の研究者は、この結果を『〜』と説明しています。」 |
| 慣習 | 「この地域では、〜する習わしがあると伝えられています。」 |
| 意見 | 「私は、まず〜から試すのがよいと考えます。」 |

## 避けること

1. 特定の団体・個人への攻撃、差別につながる表現。
2. 根拠のない断定、効果効能の保証、投資・医療の助言。
3. 出典不明の情報の拡散(まとめ記事、匿名の投稿)。
4. 悲惨な出来事・災害を宣伝に使うこと。
5. 他人の個人情報、位置の特定につながる情報。

## 正確さの確保

1. 投稿前に**出典を2点以上**で確認(一次資料＋解説)。
2. 数字・日付は**調べた元を台帳に記録**。
3. 訂正は**速やかに、元の投稿へ返信**。
4. 専門家に確認できるときは確認を依頼する。
5. 出典の更新(法令・規約・仕様)は定期的に見直す([verification-queue](../00-meta/verification-queue.md))。

### 投稿前の確認手順(5ステップ)

1. **誰が言っているか**: 発信元(公的機関・当事者・報道機関・個人)を確認する。
2. **いつの情報か**: 日付を見る。古い情報が再び拡散されていることがある。
3. **元の資料に当たる**: 「〜によると」と書かれていたら、その元の資料を開く。
4. **別の資料で裏を取る**: 立場の違う資料でも同じことが書かれているか。
5. **画像・動画を確かめる**: 古い写真や別の場所の映像が使われていないか(画像の逆検索などで確認 ⚪)。

### 災害・緊急時の注意(⚪)

- 公的機関(自治体・気象・消防など)の**公式アカウント・公式サイトの情報**を優先し、その投稿を共有する。
- 「拡散希望」の未確認情報を善意で広めない。
- 救助要請などの個人情報を含む投稿の扱いに注意する。
- 宣伝・通常の投稿は控えめにし、予約投稿を止めることも検討する([crisis-response](crisis-response.md))。

## 訂正の雛形

```
訂正とお詫び:
先の投稿で「…」と書きましたが、正しくは「…」です(出典: …)。
ご指摘ありがとうございました。
```

- 元の投稿を**削除するか残すか**: 誤りが広がる危険が大きい場合は削除し、訂正の投稿でその旨を書く。そうでなければ元の投稿に返信で訂正を付け、経緯が分かるようにする(⚪)。
- 編集機能がある場合も、**何をいつ直したか**を書き添える。

## 画像・生成 AI

- 実在の人物・宗教的な対象を写実的に描く場合は慎重に。象徴的な表現を検討。
- 生成 AI の画像は明記([ai-usage-policy](ai-usage-policy.md))。
- 生成 AI の文章は誤り(ハルシネーション)を含むことがあるため、**事実の部分は必ず一次資料で確認**する。

## 批判・指摘への対応

事実の指摘は感謝して確認・訂正。解釈の違いは出典を示して丁寧に、深追いしない。攻撃には [crisis-response](crisis-response.md)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| まとめ記事の数字をそのまま引用した | 元の資料(公的機関・論文)を開いて確認する |
| 「絶対に効く」「必ず儲かる」と書いた | 断定を避け、条件と出典を示す。法規制の対象にもなり得る([legal-compliance](legal-compliance.md)) |
| 訂正を新しい投稿だけで行い、元の投稿が拡散し続けた | 元の投稿に返信で訂正を付ける |
| 冗談のつもりの表現が差別と受け取られた | 慎重な話題では皮肉・揶揄を使わない |
| 災害時に通常の宣伝投稿が予約どおり出た | 緊急時は予約投稿を止める手順を決めておく |

## 自己チェック

- [ ] 事実・解釈・意見の区別が付いている
- [ ] 断定表現を避けた
- [ ] 画像の描き方に配慮した
- [ ] 広告・PR の表記が必要か確認した
- [ ] 出典を2点以上で確認し、台帳に記録した
- [ ] 情報の日付を確認した

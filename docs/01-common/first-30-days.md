# 最初の30日の行動計画

> **このページで分かること**: SNS 運用を始めてから30日間、毎週なにをすればよいか。1日ごとの作業量の目安と、30日後の振り返り方。
>
> **対象**: これからアカウントを作る、または作ったばかりの初心者。**先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[サービスの選び方](choosing-platforms.md)

## 概要

最初の30日の目的は「**フォロワーを増やすこと**」ではなく、「**無理なく続けられる型を作ること**」です。最初の1か月で大きな数字が出ることはまれです ⚪。この時期に、準備・投稿・返信・振り返りの一連の流れを体に覚えさせると、2か月目以降の伸び方が変わります。

ここでは1日30〜60分程度を想定した計画を示します ⚪。仕事や学業と両立する場合は、週の投稿数を減らして調整してください。

## 用語

| 用語 | 意味 |
|---|---|
| content pillar(コンテンツの柱) | 発信テーマの大分類。3つ程度に決めると企画が楽になる |
| posting cadence(投稿頻度) | 週に何回投稿するか。続けられる回数にする |
| batch production(まとめ制作) | 複数の投稿を一度に作り置きすること |
| KPI(重要業績評価指標) | 成果を測る数字。最初は「投稿数」などの行動指標でよい |
| insight / analytics(インサイト / 分析) | サービスが提供する反応の数値(表示回数・保存数など) |

## 30日の全体像

| 週 | テーマ | 主な作業 | ゴール |
|---|---|---|---|
| 0日目(準備) | 決める | 目的・相手・サービスを決める | 目的を1文で書ける |
| 1週目 | 整える | アカウント作成、安全設定、プロフィール、最初の3投稿 | 「見られても困らない」状態になる |
| 2週目 | 続ける | 週3〜5投稿、毎日の返信、他アカウントの観察 | 投稿の手順に迷わなくなる |
| 3週目 | 試す | 形式を変えて試す(画像/動画/文章、時間帯) | 反応の違いに気づく |
| 4週目 | 振り返る | 数字の確認、続ける/やめるの判断、2か月目の計画 | 次の月の計画ができる |

## 手順

### 0日目: 決める(1〜2時間)

1. **目的を1文で書く**。例: 「手作りアクセサリーを知ってもらい、月に数件の注文につなげる」。
2. **届けたい相手(ペルソナ)を書く**。年齢層、興味、どんなときに SNS を見るか。
3. **コンテンツの柱を3つ決める**。例: 「作品紹介」「作り方のコツ」「制作の裏側」。→ [企画](content-planning.md)
4. **使うサービスを1つ(多くても2つ)選ぶ**。→ [サービスの選び方](choosing-platforms.md)
5. **続けられる投稿頻度を決める**。初心者は週3回程度から始めるのが無難です ⚪。

### 1週目: 整える

| 日 | 作業 | 参照 |
|---|---|---|
| 1日目 | 運用用メールアドレスの用意、アカウント作成、**2段階認証の設定** | [アカウント保護](account-security.md) |
| 2日目 | プロフィール(名前・自己紹介・アイコン・リンク)を整える | 各サービスの初期設定ページ、[リンク設計](link-in-bio-and-utm.md) |
| 3日目 | プライバシー設定(位置情報、DM、コメント制限)を確認する | [個人情報](privacy-and-personal-info.md) |
| 4日目 | 同じジャンルのアカウントを10個ほどフォローし、投稿の形式・長さ・頻度を観察する | [調査の方法](../30-strategy/06-research-method.md) |
| 5日目 | 最初の投稿(自己紹介)を作って公開する | [投稿の流れ](posting-workflow.md) |
| 6日目 | 2本目(柱1)を公開。画像サイズ・ALT を確認 | [書き出しプリセット](export-presets.md)、[代替テキスト](alt-text.md) |
| 7日目 | 3本目(柱2)を公開。1週間の作業時間をメモする | — |

### 2週目: 続ける

1. **週の始めに投稿計画を立てる**。[投稿計画シート](../../templates/post-plan.md) を使います。
2. **まとめて作る**。週末などに2〜3本を作り置きすると、平日が楽になります。
3. **返信は24時間以内を目安に**。最初のうちは1件1件の反応が大切です ⚪。→ [コメント運用](comments-and-engagement.md)
4. **他の人の投稿にも反応する**。同じジャンルの投稿に、宣伝ではない感想コメントを送ります。
5. **使った作業時間を記録する**。続けられるかどうかの判断材料になります。

### 3週目: 試す

1. **1つだけ条件を変えて比べる**(A/B テストの考え方)。例: 同じ柱で「画像1枚」と「カルーセル(複数枚)」。
2. **投稿時間を変えてみる**。朝・昼・夜で反応がどう違うか見ます。
3. **ハッシュタグの付け方を見直す**。→ [ハッシュタグ](hashtags.md)
4. 変えた条件と結果を [週次レビュー](../../templates/weekly-review.md) に書きます。

### 4週目: 振り返る

1. **数字を確認する**: 投稿数、表示回数、反応数、保存・共有、フォロワーの増減。→ [分析・KPI](analytics-kpi.md)
2. **反応がよかった投稿の共通点を3つ書く**(形式、話題、時間帯など)。
3. **やめることを1つ決める**(反応がなく、手間がかかる作業)。
4. **2か月目の計画を作る**: 柱の見直し、投稿頻度、試すこと1つ。→ [月次レビュー](../../templates/monthly-review.md)

## 具体例: 週3回投稿の1週間

| 曜日 | 作業 | 目安時間 ⚪ |
|---|---|---|
| 月 | 今週の計画(3本の企画を決める) | 20分 |
| 火 | 投稿①を公開、返信 | 15分 |
| 水 | 返信、他アカウントの観察 | 10分 |
| 木 | 投稿②を公開、返信 | 15分 |
| 金 | 返信 | 10分 |
| 土 | 投稿③を公開、来週分の素材(写真など)をまとめて作る | 60分 |
| 日 | 週次レビュー(数字を見る、気づきを書く) | 20分 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 初日に10本投稿して、2週目に止まる | 投稿頻度は「最も忙しい週でも守れる数」に合わせる |
| フォロワー数ばかり見て落ち込む | 最初の30日は「投稿を続けた日数」「返信した数」を目標にする |
| 毎回ゼロから作って時間がかかる | テンプレート(画像の型、文章の型)を作る。→ [ブランドの指針](brand-and-visual-guidelines.md) |
| 反応がない投稿をすぐ消す | 消さずに記録し、原因を考える材料にする(規約違反や誤りは除く) |
| 一度に多くの条件を変えて、何が効いたか分からない | 1回に変える条件は1つだけにする |
| 安全設定を後回しにする | 1日目に必ず2段階認証を設定する |

## 注意点

- フォロワーや「いいね」を**お金で買うサービスは使わない**でください。多くのサービスで規約違反になり、アカウント停止の原因になります ⚪(各サービスの規約ページを参照)。
- 依頼を受けた投稿や、自分の商品の宣伝では、**広告であることの表示**が必要な場合があります。→ [法令](legal-compliance.md)
- 体調や本業を優先してください。休むときは「◯日まで休みます」と一言投稿しておくと安心です。

## チェックリスト(30日後)

- [ ] 2段階認証が有効になっている
- [ ] プロフィールに「誰向けに何を発信するか」が書いてある
- [ ] 予定した投稿数の7割以上を公開できた
- [ ] 反応がよかった投稿の共通点を書き出した
- [ ] 2か月目の計画(柱・頻度・試すこと)を決めた

# 多言語・海外向けの発信

> **このページで分かること**: 日本語以外の読者にも届けるための考え方(英語併記・別アカウント・翻訳機能)、文字数の違い、時差を考えた投稿時間、翻訳ツールを使うときの注意。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [writing-guide](writing-guide.md)、[search-optimization](search-optimization.md)

## 概要

イラスト、料理、旅行、手仕事、地域の文化などは、言葉が分からなくても伝わりやすく、**海外の読者が自然に集まる**ことがあります。少し英語を添えるだけで、検索や共有の範囲が広がります。

ただし、翻訳の誤り、文化の違い、時差、海外向け販売の規約・法律など、気を付ける点もあります。最初から完璧な多言語対応を目指すより、**「英語の一言+画像・動画で伝わる内容」から小さく始める**のがおすすめです(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| localization(ローカライズ) | 言葉だけでなく、表現・単位・日付の書き方などを相手の地域に合わせること |
| machine translation(機械翻訳) | ソフトウェアによる自動翻訳 |
| auto dubbing(自動吹き替え) | 音声を自動で別の言語に翻訳・合成する機能 |
| time zone(タイムゾーン、時間帯) | 地域ごとの標準時。日本標準時(JST)は協定世界時(UTC)より9時間進んでいる(⚪) |
| daylight saving time(夏時間) | 一部の国で夏の間だけ時計を1時間進める制度 |
| CJK | 中国語・日本語・韓国語の文字の総称 |

## 進め方の選択肢

| 方法 | 内容 | 向く場合 | 手間 |
|---|---|---|---|
| 日本語のみ+伝わる素材 | 画像・動画中心で言葉に頼らない | まず様子を見たい | 小 |
| **英語を一言併記** | 本文やキャプションの最後に英語の短い説明 | 海外からの反応が増えてきた | 小〜中 |
| 投稿ごとに日英併記 | 全文を両方の言語で | 読者が半々 | 中 |
| 言語別のアカウント | 日本語用・英語用を分ける | 海外の読者が多い、販売もする | 大 |
| サービスの翻訳機能 | YouTube の翻訳タイトル・字幕・自動吹き替えなど | 動画中心 | 小〜中 |

## サービス別の機能と仕様

### YouTube(✅ YouTube ヘルプ)

| 機能 | 内容 |
|---|---|
| 翻訳したタイトルと説明 | YouTube Studio の[字幕]で言語を追加し、タイトルと説明を入力。**他の言語の視聴者の検索結果に表示**され、視聴者に合った言語で表示される |
| 自動吹き替え | 音声を他の言語に翻訳。**元の言語が日本語の場合は英語のみ**。120分を超える動画、音楽のみ、話すのが速すぎる動画などは対象外。「手動で公開」にすると公開前に確認できる |
| 字幕 | 言語ごとに字幕を追加できる(⚪ 詳細は各ヘルプ) |

### X の文字数(✅ X 開発者文書)

- X は文字に**重み**を付けて数え、上限は**280**。ラテン文字(英字)は1、**日本語などの CJK は2**として数えるため、日本語だけなら約140字(✅)。
- URL は長さに関係なく**23文字**として数える(✅)。
- 日英併記すると、思ったより早く上限に達します。英語は短い一言にするか、スレッドに分けます。

### その他(⚪)

- Instagram・Threads・TikTok などにも、閲覧者の言語に合わせた翻訳表示の機能がある(⚪ 表記・対応は要確認)。**自動翻訳は読者側で行われるため、元の文が分かりやすいことが大切**です。

## 時差と投稿時間(⚪ 一般知識)

| 地域 | 日本との時差の目安 | 日本時間で見た夕方〜夜(現地 18〜22時)の例 |
|---|---|---|
| アメリカ東部 | 日本より13〜14時間遅い(夏時間で変わる) | 日本の朝 7〜12時ごろ |
| アメリカ西部 | 日本より16〜17時間遅い(夏時間で変わる) | 日本の昼 10〜15時ごろ |
| イギリス | 日本より8〜9時間遅い(夏時間で変わる) | 日本の深夜 2〜7時ごろ |
| 台湾・香港・中国 | 日本より1時間遅い | 日本の夜 19〜23時ごろ |

- 夏時間の切り替え時期は国ごとに違います。**世界時計アプリで確認**してください。
- 海外の読者向けの投稿は、**予約投稿**を使えば日本の深夜に起きている必要はありません。
- 各サービスの分析画面で、フォロワーの国・活動時間を確認できる場合があります(⚪)。

## 翻訳ツールを使うときの注意

1. **意味の確認**: 翻訳した英文を、別のツールで日本語に戻し(逆翻訳)、意味がずれていないか確かめる。
2. **固有名詞・料理名・地名**: 誤訳されやすい。ローマ字表記+短い説明にする(例: `Nikujaga (Japanese simmered meat and potatoes)`)。
3. **敬語・冗談・言葉遊び**: 訳すと伝わらない、失礼になることがある。シンプルな文にする。
4. **単位と書き方**: 日付(`2026/11/03` は国によって読み方が違う)、温度(℃/℉)、通貨は明記する。
5. **秘密情報を貼らない**: 未公開の企画、個人情報、契約内容を翻訳ツールに入力しない。ツールの利用規約で入力内容の扱いを確認する(⚪)。
6. **AI の誤り**: 生成 AI の翻訳はもっともらしい誤りを含むことがある([ai-usage-policy](ai-usage-policy.md))。
7. **大切な文章は人が確認**: 販売条件・規約・謝罪文など。

## 具体例

### 英語を一言併記する例(料理アカウント)

```
作り置きの基本、3つのコツをまとめました。
保存して、週末の作り置きに使ってください。

Three tips for Japanese-style meal prep. Save this for your weekend cooking!
```

| 良い例 | 避けたい例 |
|---|---|
| 英語は短く、写真の内容と一致 | 日本語全文を機械翻訳して貼り付け、確認していない |
| 料理名にローマ字+説明 | 料理名を直訳して意味不明になる |
| ハッシュタグは日本語と英語を少数ずつ | 英語の人気タグを無関係に大量に付ける |

## 海外向けの販売・規約の注意(⚪)

- 海外への販売は、**送料・関税・返品・決済**の条件を明記し、各販売サービスの対応国を確認する。
- 国・地域によって、**広告表記・個人情報・年齢制限のルールが異なる**。日本の法令は [legal-compliance](legal-compliance.md)。
- 文化・宗教・歴史に関わる表現は、地域によって受け取り方が大きく違う([sensitive-topics-and-accuracy](sensitive-topics-and-accuracy.md))。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 日英併記で X の文字数を超えた | 英語は一言に、詳細はスレッドや画像内に |
| 機械翻訳のまま公開して誤解された | 逆翻訳で確認し、短い文に直す |
| 海外のコメントに返信できず放置 | よく来る質問の英語の返信文を用意しておく |
| 時差を考えず、海外の深夜に告知 | 予約投稿で現地の時間に合わせる |
| 日付の書き方で混乱 | 月を英語で書く(例: `Nov 3, 2026`) |

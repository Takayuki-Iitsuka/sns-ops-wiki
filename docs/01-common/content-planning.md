# コンテンツ企画の型

> **このページで分かること**: 「何を投稿すればよいか分からない」を解消するための企画の型(コンテンツの柱、カレンダー、シリーズ)と、サービス別の投稿の雛形。
>
> **対象**: 初心者(ネタ切れ・投稿が続かない人)  **先に読むページ**: [beginners-guide](../00-meta/beginners-guide.md)(はじめての SNS 運用)

特定の題材に依存しない、SNS 運用の企画手法です。題材固有の内容は別の wiki で管理します。

## 概要

投稿が続かない原因の多くは「毎回ゼロから考えている」ことです(⚪)。企画を**型**にしておくと、次の良いことがあります。

- ネタを考える時間が減り、制作に時間を使える。
- 投稿の種類が偏らず、読者が飽きにくい。
- 反応を「柱ごと」に比べられるので、改善しやすい。

このページの流れは、**柱を決める → カレンダーに並べる → シリーズで続ける → 雛形で作る → 記録して見直す**です。

## 用語

| 用語 | 意味 |
|---|---|
| content pillar(コンテンツの柱) | 投稿をいくつかの種類に分けたもの。偏りを防ぐための分類 |
| editorial calendar(編集カレンダー、投稿カレンダー) | いつ何を出すかを並べた予定表 |
| series(シリーズ、連載) | 同じ形式で続ける企画 |
| stock(ストック) | 公開前に作りためた投稿 |
| CTA / call to action(行動喚起) | 「保存してね」「リンクから読んでね」など次の行動を促す一言 |
| repurposing(再利用、転用) | 1つの素材を別の形式・サービス向けに作り直すこと |
| carousel(カルーセル) | 複数枚の画像を横にめくる投稿 |
| thread(スレッド) | 複数の投稿をつなげた連投 |

## 1. コンテンツの柱(content pillars)

投稿を「柱」に分類し、偏りを防ぎます。**3〜5本の柱**を決め、週に2〜3本の柱を回すのが目安(⚪)。

| 柱の種類 | 内容 | 向く形式 | 主な目的 |
|---|---|---|---|
| 教える | 解説、ハウツー、用語集 | スレッド、カルーセル、記事 | 信頼・保存 |
| 見せる | 作品、制作過程、日常 | 画像、動画 | 親近感 |
| 比べる | 比較、ランキング、まとめ | 表、カルーセル | 保存・共有 |
| 問う | 質問、投票、意見募集 | X 投票、ストーリーズ | 交流 |
| 伝える | 時事、イベント、告知 | 短文、ストーリーズ | 時事性 |
| 売る | 商品、サービス、導線 | 記事、動画 | 収益 |

ルール:
1. 各投稿に柱を記録し、**直近10本の偏り**を見る。
2. 「売る」柱は全体の**1〜2割**に抑える(売り込みが続くと離脱 ⚪)。
3. 「教える」柱で**信頼の核**を作る。

### 柱の決め方(手順)

1. 自分(自社)が**詳しいこと・続けられること**を5つ書き出す。
2. 読者が**困っていること・知りたいこと**を5つ書き出す(コメント、検索サジェスト、知人への質問から)。
3. 両方に重なるものを3〜5つ選び、上の「柱の種類」のどれに当たるかを決める。
4. 柱ごとに**ネタを10個**出せるか試す。出せない柱は外す。

### 具体例(汎用)

| アカウント例 | 柱1(教える) | 柱2(見せる) | 柱3(問う) | 柱4(売る) |
|---|---|---|---|---|
| 料理アカウント | 時短のコツ | 今日の一品 | 「どっち作る?」投票 | レシピ本・教室の案内 |
| 地域の店 | 商品の選び方 | 仕込み・店内の様子 | 新メニューの意見募集 | 営業日・予約の案内 |
| イラスト | 描き方のコツ | 作品・制作過程 | 次に描くテーマの投票 | グッズ・依頼の案内 |

## 2. 年間・月間カレンダー

1. **12か月の主題**を1つずつ決める(季節、行事、業界の節目、自分の締切)。
2. 主題に沿って**月に3〜5回のミニ連載**を組み、最終回に記事やまとめを置く。
3. 節目の**2週間前から予告**、当日に本編、翌日に関連話題。
4. 週のリズム(例): 月=予告、火=解説、水=スレッド/カルーセル、木=動画、金=質問、土=深掘り記事、日=振り返り。継続できる頻度から始め、2〜4週ごとに見直す。

> 上の週のリズムは「毎日投稿」の例です。初心者は**週2〜3回程度**から始め、続けられたら増やすほうが安全です(⚪ [faq](faq.md))。

### カレンダー(雛形: 1か月)

| 週 | 月の主題との関係 | 投稿1 | 投稿2 | 投稿3 | 備考(締切・行事) |
|---|---|---|---|---|---|
| 1週 | 予告 | 教える | 見せる | 問う |  |
| 2週 | 本編 | 教える | 比べる | 見せる |  |
| 3週 | 本編 | 教える | 見せる | 売る |  |
| 4週 | まとめ | まとめ記事 | 振り返り | 次月予告 |  |

## 3. シリーズ企画

| 項目 | 内容 |
|---|---|
| 目的 | 読者の習慣化、記事・電子書籍・講座への発展 |
| 設計 | 全体の回数、1回の形式、更新曜日を決める |
| 開始条件 | **10回分のストック**ができてから公開する |
| 終了後 | 再編集して note 有料マガジン、電子書籍、PDF にする |

- シリーズ名と通し番号を付ける(例: 「時短のコツ #3」)。続きを探しやすくなります。
- 専用のハッシュタグで束ねる方法もあります([hashtags](hashtags.md) §3 の「自社・シリーズ」層)。

## 4. 企画の作り方

```
題材 → 読者の悩み → 一言でいうと → 根拠・出典 → 画像/動画案 → 形式 → 柱
```

記入例(汎用):

```
題材: 作り置き
読者の悩み: 平日の夕食づくりに時間がかかる
一言でいうと: 日曜に30分で3品作れば平日が楽になる
根拠・出典: 自分の実践記録(手順と所要時間)
画像/動画案: 3品の完成写真+手順の図解
形式: Instagram カルーセル 8枚
柱: 教える
```

## 5. 投稿の雛形(汎用)

### X: 短文

```
【テーマ名】見出し(状況を1行)
要点2文。
問い、または次の行動。
(出典)
#タグ1 #タグ2
```

### X: スレッド(5〜7ポスト)

1. 結論と問い  2. 前提  3. 展開  4. 補足・反論  5. 解釈の分かれる点  6. 要約と導線

### Instagram: カルーセル(8〜10枚)

1枚目=問い/結論、2〜6=本編、7=補足、8=まとめ、9=保存・フォロー・次回予告。

### note: 記事の骨格

```
タイトル(悩み＋解決＋数字)→ 導入(誰向け・何が分かる)→ 見出し3〜5 → まとめ → 参考文献
有料の場合: 無料部分で価値を示し、有料ラインを設定
```

### 動画

[video-basics](video-basics.md)。編集アプリは [video-editing-apps](video-editing-apps.md)。

### 1つの素材を使い回す(repurposing)

```
note 記事(元) → X スレッド(要点) → Instagram カルーセル(図解) → ショート動画(1つのコツ)
```

形式ごとに**作り直す**のがコツです(同じ文章の貼り付けではなく、サービスに合わせて短く・図にする ⚪ [posting-workflow](posting-workflow.md))。

## 6. 管理

[投稿計画シート](../../templates/post-plan.md) に柱・形式・結果を記録し、[週次レビュー](../../templates/weekly-review.md) で偏りと反応を確認する。数字の見方は [analytics-kpi](analytics-kpi.md)。

## よくある失敗と対処

| 失敗 | 起きること | 対処 |
|---|---|---|
| 最初から毎日投稿を目標にする | 2週間で息切れ | 週2〜3本から。ストックを先に作る |
| 柱が1本だけ | 読者が飽きる・ネタが尽きる | 3〜5本に分ける |
| 「売る」投稿ばかり | フォロー解除が増える | 1〜2割に抑える |
| 思いつきで投稿 | 何が良かったか分からない | 柱・形式を記録してから投稿 |
| 流行りのネタだけを追う | 自分の強みと関係ない人が集まる | 柱に当てはまるときだけ乗る |
| シリーズを1回目だけ出して止まる | 読者の期待を裏切る | 10回分のストックができてから公開 |

## 注意点

- 時事・季節の話題は、事実と日付を一次資料で確認します([sensitive-topics-and-accuracy](sensitive-topics-and-accuracy.md))。
- 他人の投稿・画像を企画に使うときは権利を確認します([image-sources-and-copyright](image-sources-and-copyright.md))。

# 運用ツールの選び方

> 具体的な製品名・料金・機能は変わるため、**選定基準**を中心に整理します。採用時は公式で確認(⚪)。

## 分類と選定基準

| 分類 | 用途 | 選定基準 |
|---|---|---|
| 画像制作 | 図解・カード・サムネ | テンプレ、書き出し形式、フォントの商用利用、日本語縦書き対応 |
| 動画編集 | リール・ショート | 縦型、字幕、書き出しサイズ |
| 組版 | 縦書きの原文カード | 縦書き・ルビ・禁則。LuaLaTeX と jlreq は縦書き PDF の有力な手段(⚪) |
| 予約投稿 | 投稿の事前設定 | 公式 API 準拠か、規約適合か、セキュリティ |
| 分析 | KPI の集計 | 公式インサイトのエクスポート、スプレッドシート |
| メモ・台帳 | 出典台帳・権利台帳 | 非公開、検索、バックアップ |
| 校正 | 誤字チェック | 日本語の精度 |
| 版管理 | この wiki | Git と GitHub |

## 非公式ツールの注意

- 自動フォロー/自動投稿などを行うツールは**規約違反**となる場合がある。
- アカウント認証情報を入力する前に、運営者・権限・レビューを確認。
- 認証トークンの範囲を最小限に。使わなくなったら**連携を解除**。

## おすすめの組み合わせ(最小構成 ⚪)

1. 画像: 1つのデザインツール(テンプレ運用)
2. 台帳: 非公開の表計算＋メモ
3. 予約: 各サービスの公式機能
4. 分析: 公式インサイト＋週次レビュー
5. 版管理: この wiki(public)＋非公開リポジトリ

## 学習のしかた

1. 公式ヘルプの「はじめに」を通読。
2. 小さなテスト投稿で試す。
3. 手順を **wiki に記録**して再現可能にする。

# 運用ツールの選び方

> **このページで分かること**: SNS 運用で使うツールの種類と、選ぶときの基準、安全に連携するための注意点、最小構成。
>
> **対象**: 初心者  **先に読むページ**: [posting-workflow](posting-workflow.md)

> 具体的な製品名・料金・機能は変わるため、**選定基準**を中心に整理します。採用時は公式で確認(⚪)。料金の比較は [40-pricing](../40-pricing/README.md)。

## 概要

ツールは、作業を速くし、ミスを減らすための道具です。ただし、ツールを増やしすぎると「使い方を覚える時間」「料金」「アカウント連携の危険」が増えます。

初心者は、**各サービスの公式機能(予約投稿・インサイト)と、デザイン・表計算のツールを1つずつ**から始め、困りごとがはっきりしてから追加するのがおすすめです。

## 用語

| 用語 | 意味 |
|---|---|
| scheduler(予約投稿ツール) | 日時を指定して投稿を自動で公開するツール |
| insights / analytics(インサイト、分析) | 表示回数・反応などの数値を見る機能 |
| integration(連携) | ツールに SNS アカウントの操作権限を与えること |
| OAuth(オーオース) | パスワードを渡さずに権限だけを渡す仕組み |
| permission scope(権限の範囲) | 連携したツールができること(閲覧のみ、投稿、DM など) |
| export(書き出し、エクスポート) | データやファイルを外部の形式で保存すること |

## 分類と選定基準

| 分類 | 用途 | 選定基準 |
|---|---|---|
| 画像制作 | 図解・カード・サムネ | テンプレ、書き出し形式、フォントの商用利用、日本語縦書き対応 |
| 動画編集 | リール・ショート | 縦型、字幕、書き出しサイズ([video-editing-apps](video-editing-apps.md)) |
| 組版 | 縦書きの原文カード | 縦書き・ルビ・禁則。LuaLaTeX と jlreq は縦書き PDF の有力な手段(⚪) |
| 予約投稿 | 投稿の事前設定 | 公式 API 準拠か、規約適合か、セキュリティ |
| 分析 | KPI の集計 | 公式インサイトのエクスポート、スプレッドシート |
| モニタリング | 言及・評判の把握 | 対応サービス、通知の速さ、費用([social-listening](social-listening.md)) |
| メモ・台帳 | 出典台帳・権利台帳 | 非公開、検索、バックアップ |
| 校正 | 誤字チェック | 日本語の精度 |
| 版管理 | この wiki | Git と GitHub |

## ツールを選ぶ手順

1. **困りごとを1文で書く**(例: 「平日に投稿時間を確保できない」)。
2. **公式機能で解決できるか確認する**(多くのサービスに予約投稿・インサイトがある ⚪)。
3. 足りなければ候補を2〜3個に絞り、次の表で比べる。
4. **無料版・試用期間で1〜2週間**使う。
5. 採用したら、使い方とアカウント連携の内容を wiki やメモに記録する。
6. 3か月ごとに「使っているか」「料金に見合うか」を見直す。

## 非公式ツールの注意

- 自動フォロー/自動投稿などを行うツールは**規約違反**となる場合がある。
- アカウント認証情報を入力する前に、運営者・権限・レビューを確認。
- 認証トークンの範囲を最小限に。使わなくなったら**連携を解除**。
- **パスワードを直接入力させるツールは避ける**。公式の連携画面(OAuth)で権限を確認できるものを選ぶ(⚪)。
- API の仕組みと安全な使い方は [concepts-and-security](../20-api/01-concepts-and-security.md)。

## おすすめの組み合わせ(最小構成 ⚪)

1. 画像: 1つのデザインツール(テンプレ運用)
2. 台帳: 非公開の表計算＋メモ
3. 予約: 各サービスの公式機能
4. 分析: 公式インサイト＋週次レビュー
5. 版管理: この wiki(public)＋非公開リポジトリ

### 段階ごとの追加の目安(⚪)

| 段階 | 追加を検討するもの |
|---|---|
| 始めたばかり | 上の最小構成だけ |
| 週3回以上投稿し、複数サービスを運用 | 予約投稿ツール(複数サービス対応) |
| 動画を定期的に作る | 動画編集アプリ([video-editing-apps](video-editing-apps.md)) |
| 言及や評判を追いたい | 通知設定・検索の保存・モニタリングツール([social-listening](social-listening.md)) |
| 複数人で運用 | 権限を分けられるツール、共有の台帳([account-security](account-security.md)) |

## 学習のしかた

1. 公式ヘルプの「はじめに」を通読。
2. 小さなテスト投稿で試す。
3. 手順を **wiki に記録**して再現可能にする。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| ツールを増やしすぎて、どれも使いこなせない | 困りごと1つにつき1ツール。使わないものは解約 |
| 連携したまま忘れたツールが投稿・DM の権限を持っていた | 各サービスの「連携しているアプリ」を定期的に確認し、不要なものを解除 |
| 無料期間の終了に気付かず課金された | 試用開始日と終了日を予定表に入れる |
| ツールの終了でデータが失われた | 定期的に書き出す([data-backup-and-portability](data-backup-and-portability.md)) |
| フォント・素材の商用利用条件を確認していなかった | ツール内素材のライセンスを確認([image-sources-and-copyright](image-sources-and-copyright.md)) |

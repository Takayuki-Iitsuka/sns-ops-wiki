# 動画編集アプリの比較と書き出し設定

> **このページで分かること**: スマホ・パソコンの動画編集アプリ(CapCut、Instagram の Edits、YouTube Create、スマホ標準アプリ、PC ソフト)の特徴、選び方、SNS 向けの書き出し設定、利用規約で確認すべき点。
>
> **対象**: 初心者  **先に読むページ**: [video-basics](video-basics.md)

## 概要

縦型の短い動画なら、**スマホの編集アプリだけで十分に作れます**。カット、字幕、音楽、テキスト、トランジション(場面の切り替え効果)まで、多くのアプリが無料で対応しています。

アプリ選びで大切なのは、機能の多さよりも、**①書き出しの画質と透かしの有無、②アプリ内の素材(音楽・テンプレート)を使える範囲、③利用規約(自分の動画の扱い)**の3点です。料金や機能は頻繁に変わるため、ここでは選び方の観点を中心に整理します。料金は [40-pricing](../40-pricing/05-ai-and-creative-tools.md) を参照してください。

## 用語

| 用語 | 意味 |
|---|---|
| timeline(タイムライン) | 動画・音声・文字を時間順に並べる編集画面 |
| cut / trim(カット、トリム) | 不要な部分を切り取ること |
| transition(トランジション) | 場面の切り替え効果 |
| auto captions(自動字幕) | 音声を認識して自動で字幕を作る機能 |
| template(テンプレート) | 決まった構成・効果のひな形 |
| watermark(透かし) | 動画に入るアプリやサービスのロゴ |
| export(書き出し) | 編集した動画を1つのファイルにすること |
| keyframe(キーフレーム) | 位置・大きさなどの変化の始点と終点を指定する編集機能 |
| proxy(プロキシ) | 編集を軽くするための低画質の仮ファイル |

## アプリの比較

| アプリ | 端末 | 特徴 | 確度・注意 |
|---|---|---|---|
| CapCut | スマホ、パソコン、Web | テンプレート・自動字幕・効果が豊富。無料版と有料版(Pro) | 🟡 2025年(皇紀2685年・令和7年)6月の利用規約の更新で、利用者のコンテンツの利用許諾の条項が議論になった(運営は「該当部分は変わっていない」と説明)。料金は ⚪ |
| Edits(Instagram) | iOS、Android | Instagram が提供する無料の編集アプリ。2025年4月に公開、**書き出しに透かしが入らない**とする報道 | 🟡 報道 |
| YouTube Create | スマホ | YouTube が提供する編集アプリ。2024年(皇紀2684年・令和6年)の報道では**日本は提供対象外** | 🟡 報道(日本の現状は ⚪ 要確認) |
| スマホ標準アプリ | iPhone の写真アプリ、Android の Google フォトなど | 切り取り・回転・簡単な調整。追加のアプリ不要 | ⚪ |
| 各 SNS のアプリ内編集 | Instagram、TikTok、YouTube Shorts など | 投稿と同じ画面で編集。サービス内の音源を使いやすい | ⚪ |
| パソコンのソフト | DaVinci Resolve、Adobe Premiere Pro、Final Cut Pro、Clipchamp など | 長尺動画・細かい調整・色の補正。学習の時間が必要 | ⚪ 料金・対応 OS は各公式で確認 |

## 選び方の手順

1. **作る動画を決める**: 短尺の縦動画か、長尺の横動画か。
2. **主な投稿先を決める**: 1つのサービスが中心なら、そのサービスのアプリ内編集や公式アプリ(Edits など)が手軽。
3. **必要な機能を3つまで書く**: 例「自動字幕」「テキストの位置調整」「BGM の音量調整」。
4. **無料で試す**: 同じ素材で2つのアプリを試し、書き出した動画をスマホで比べる。
5. **規約を確認する**(下の §規約)。
6. 決めたら、**テンプレート(字幕の位置・フォント・色)を保存**して毎回使う。

## 書き出し設定(SNS 向けの基準)

| 項目 | 推奨 | 理由・出典 |
|---|---|---|
| 解像度・比率 | 縦型 1080×1920(9:16)、横型 1920×1080(16:9) | 各サービスの標準([video-specs-comparison](video-specs-comparison.md)) |
| フレームレート | **撮影時と同じ**(30fps が基本、動きが速ければ 60fps) | YouTube のエンコード設定 ✅ |
| 形式 | MP4(H.264 + AAC) | X・Instagram・Threads・YouTube が対応 ✅ |
| ビットレート | 1080p・30fps で 8Mbps 程度、60fps で 12Mbps 程度 | YouTube の推奨 ✅ |
| Instagram リール(API) | H.264 または HEVC、23〜60fps、映像 VBR 最大 25Mbps、最大 300MB | ✅ Instagram の API 仕様 |
| 色 | SDR(HDR はオフ) | 端末による見え方の差を減らす([mobile-viewing-optimization](mobile-viewing-optimization.md) ⚪) |
| 音声 | AAC、48kHz(YouTube の推奨)、音量をそろえる | ✅ YouTube のエンコード設定 |

- アプリによっては「画質: 高」「ファイルサイズ: 小」など、**数値ではなく段階**で選びます。迷ったら **1080p・30fps・高画質** を選びます(⚪)。
- サービスごとの値は [export-presets](export-presets.md)。

### スマホでの書き出し手順(一般的な流れ ⚪ 表記はアプリで異なる)

1. 編集画面の右上などにある[書き出し][エクスポート][保存]を押す。
2. 解像度を **1080p** に、フレームレートを撮影時と同じにする。
3. 「HDR」の項目があればオフにする(SDR で書き出す)。
4. 透かし(ウォーターマーク)・エンディングのロゴが付く設定なら外す(有料機能の場合もある)。
5. 書き出したファイルを写真アプリで再生し、音ずれ・字幕の位置を確認する。

## 利用規約で確認すべき点

| 観点 | 確認すること |
|---|---|
| 自分の動画の扱い | アップロード・編集したコンテンツに対し、運営にどんな利用許諾を与えるか(範囲・期間・取り消せるか) |
| アプリ内の音楽 | **商用利用・収益化動画で使えるか**、他の SNS に投稿してよいか([music-and-licensing](music-and-licensing.md)) |
| テンプレート・素材 | 商用利用の可否、クレジット表記の要否 |
| 透かし・ロゴ | 無料版で入るか。他の SNS では**他社ロゴ入りの動画が不利になる可能性**(⚪) |
| AI 機能 | 生成した映像・音声の権利と、投稿先での AI 開示ルール([ai-rules-by-platform](ai-rules-by-platform.md)) |
| データ | 顔・声などの情報の扱い、クラウド保存の有無、アカウント削除時の扱い |
| 年齢 | 利用できる年齢 |

- 利用規約は**更新されることがあります**。採用時と大きな更新の通知が来たときに読み直し、確認日をメモします。
- 仕事・案件の動画は、**依頼主の素材や未公開情報をクラウドの編集アプリに上げてよいか**を事前に確認します(⚪)。

## 具体例: 料理の30秒リールを作る流れ

1. スマホの標準カメラで縦に撮影(30fps)。
2. 編集アプリで不要な部分をカットし、3〜5カットに並べる。
3. 自動字幕を付け、**材料名・数字の誤り**を手で直す。
4. 字幕を安全領域内(上下・右側を避けて中央付近)に置く。
5. BGM は投稿先のアプリ内音源を使うか、権利を確認した音源を小さめの音量で。
6. 1080p・30fps・SDR で書き出し、スマホで確認して投稿。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 書き出したら画質が落ちた | 1080p・高画質で書き出す。低いビットレートを避ける |
| 他社のロゴ入りのまま別の SNS に投稿 | 透かしなしで書き出す、元の素材から作り直す |
| アプリ内の音楽で作った動画を別の SNS に出してミュートされた | 投稿先ごとに音源の使用範囲を確認する |
| HDR で書き出して色が白っぽくなった | SDR で書き出す |
| 自動字幕の誤字に気付かず公開 | 固有名詞・数字を中心に見直す |
| 案件の未公開素材をクラウド編集した | 依頼主にクラウド利用の可否を確認する |

## チェックリスト

- [ ] 書き出し設定を 1080p・撮影時と同じフレームレート・SDR にした
- [ ] 透かし・他社ロゴが入っていない
- [ ] アプリ内の音楽・素材の使用範囲を確認した
- [ ] 利用規約(コンテンツの扱い・AI 機能)を確認し、確認日を記録した
- [ ] 自動字幕を見直した
- [ ] 書き出した動画をスマホで再生して確認した

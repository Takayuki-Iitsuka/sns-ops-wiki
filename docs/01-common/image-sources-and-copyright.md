# 画像素材と著作権

> 一般的な整理です。個別の素材は**提供元の利用条件**で確認してください。

## 素材の区分

| 区分 | 例 | 使い方 |
|---|---|---|
| 自作 | 自分で描く/撮る | 最も安全。人物・位置情報に注意 |
| パブリックドメイン | 保護期間が満了した古い作品 | 原作の権利は満了でも、**写真・複製に権利が残る場合**がある |
| オープンデータ/CC | 公的機関・美術館の公開画像 | **ライセンス条件**(表示、改変可否、商用可否)を確認 |
| 有料素材 | ストックフォト、フォント | 規約(用途、再配布、商用)を確認 |
| 生成 AI | 画像生成 | [ai-usage-policy](ai-usage-policy.md) |
| 他人の画像 | SNS 上の画像 | 無断使用は不可。許諾が必要 |

## 公的機関・美術館の公開画像(入口。条件は個別に確認 ⚪)

| 各美術館のオープンアクセス | 各館の利用規約 |

## 古い図版を使うときのチェック

1. 作者の没年(保護期間の満了)
2. 所蔵機関の**複製・二次利用の条件**
3. 画像データの**ライセンス表記**
4. 商用利用の可否(収益化する場合は特に)
5. クレジット表記の要否と書式

## フォント

- 商用利用・SNS 画像への使用・電子書籍への埋め込みの可否を確認。
- ライセンスの控えを台帳に保存。

## 施設・地域の写真

- 施設・境内・店舗の撮影・掲載ルールは**施設ごと**。公式サイトで確認し、必要なら許可を得る。
- 人物が写る場合は肖像権・プライバシー([legal-compliance](legal-compliance.md))。

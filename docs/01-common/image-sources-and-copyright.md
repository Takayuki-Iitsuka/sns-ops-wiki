# 画像素材と著作権

> **このページで分かること**: SNS で使う画像・フォントの「使ってよいか」の確かめ方、素材の種類ごとの注意、引用のルール、権利の記録(台帳)の付け方。
>
> **対象**: 初心者(ネットの画像を使ってよいか迷う人)  **先に読むページ**: なし。法令全般は [legal-compliance](legal-compliance.md)

> 一般的な整理です。個別の素材は**提供元の利用条件**で確認してください。判断に迷う場合は専門家に相談してください。

## 概要

写真・イラスト・図・フォントには、多くの場合**著作権**があります。「ネットで公開されている」「無料でダウンロードできた」ことは、「自由に使ってよい」という意味ではありません。

基本の考え方は次の3つです。

1. **一番安全なのは自作**(自分で撮る・描く)。
2. 他人の素材は、**ライセンス(利用条件)を読んで、条件どおりに使う**。
3. 使った素材は**台帳に記録**し、後から確認できるようにする。

## 用語

| 用語 | 意味 |
|---|---|
| copyright(著作権) | 作品を作った人が持つ、複製・公開などを決められる権利 |
| license(ライセンス、利用許諾) | 権利者が「この条件なら使ってよい」と示したもの |
| public domain / PD(パブリックドメイン) | 保護期間の満了などで、著作権がない状態の作品 |
| Creative Commons / CC(クリエイティブ・コモンズ) | 「表示」「非営利」「改変禁止」「継承」などの条件を組み合わせた共通ライセンス |
| credit(クレジット、表示) | 作者名・出典の表示 |
| commercial use(商用利用) | 収益化・宣伝・販売など、お金に関わる使い方 |
| quotation(引用) | 自分の文章の中で、他人の著作物を条件を守って使うこと |
| moral rights(著作者人格権) | 作者の名前の表示や、作品を勝手に改変されないことなどの権利 |
| portrait rights(肖像権) | 自分の顔や姿を無断で撮影・公開されない権利(法律の条文ではなく判例で認められている ⚪) |

## 素材の区分

| 区分 | 例 | 使い方 |
|---|---|---|
| 自作 | 自分で描く/撮る | 最も安全。人物・位置情報に注意 |
| パブリックドメイン | 保護期間が満了した古い作品 | 原作の権利は満了でも、**写真・複製に権利が残る場合**がある |
| オープンデータ/CC | 公的機関・美術館の公開画像 | **ライセンス条件**(表示、改変可否、商用可否)を確認 |
| 有料素材 | ストックフォト、フォント | 規約(用途、再配布、商用)を確認 |
| 生成 AI | 画像生成 | [ai-usage-policy](ai-usage-policy.md) |
| 他人の画像 | SNS 上の画像 | 無断使用は不可。許諾が必要 |

## 著作権の保護期間(日本、✅ 著作権法)

| 種類 | 保護期間 | 条文 |
|---|---|---|
| 原則(個人の作品) | 著作者の**死後70年**を経過するまで(共同著作物は最後に亡くなった著作者の死後) | 第51条 |
| 無名・変名(ペンネームで本人が不明) | **公表後70年** | 第52条 |
| 団体名義(会社・団体の名前で公表) | **公表後70年**(創作後70年以内に公表されなければ創作後70年) | 第53条 |
| 映画 | **公表後70年**(同上) | 第54条 |

- 期間は、亡くなった日・公表された日の属する年の**翌年の1月1日から**数えます(第57条 ✅)。
- 外国の作品の戦時加算など**例外**があり、過去の法改正で期間が延びたかどうかでも結論が変わるため、古い作品は個別に確認します(⚪)。

## 引用のルール(✅ 著作権法 第32条・第48条)

- 第32条: 公表された著作物は**引用して利用することができる**。ただし、引用は「**公正な慣行に合致する**」もので、「報道、批評、研究その他の**引用の目的上正当な範囲内**」でなければならない。
- 第48条: 引用する場合は、**出所(出典)を明示**しなければならない。
- 実務でよく挙げられる条件(⚪ 一般的な解説): ①自分の文章が「主」で引用は「従」、②引用部分がはっきり区別できる(かぎ括弧・枠)、③引用する必然性がある、④改変しない、⑤出典を書く。

> **画像をまるごと「引用」として載せるのは、条件を満たしにくい**ことが多いです。迷ったら許諾を取るか、使わないのが安全です(⚪)。

## 古い図版を使うときのチェック

1. 作者の没年(保護期間の満了)
2. 所蔵機関の**複製・二次利用の条件**
3. 画像データの**ライセンス表記**
4. 商用利用の可否(収益化する場合は特に)
5. クレジット表記の要否と書式

## 手順: 素材を使う前の確認(5分)

1. **出どころを確かめる**: 誰が作ったか、配布元はどこか。転載サイトではなく**元の配布元**のページを開く。
2. **ライセンスを読む**: 商用利用、改変(切り抜き・文字入れ)、クレジット表記、SNS での使用、再配布の可否。
3. **人物・ロゴ・建物が写っていないか**: 写っていれば、肖像権・商標・施設の撮影ルールも確認。
4. **ライセンスの控えを保存**: ページのスクリーンショットや PDF(日付が分かる形)。
5. **台帳に記録**(下の雛形)。
6. **クレジットを書く**(必要な場合): 例 `写真: 作者名 / 配布元(CC BY 4.0)`。

### CC ライセンスの読み方(⚪ 一般的な整理)

| 記号 | 意味 | SNS での注意 |
|---|---|---|
| BY(表示) | 作者名などのクレジットが必要 | キャプションか画像内に書く |
| NC(非営利) | 商用利用は不可 | 収益化アカウント・宣伝では使わない |
| ND(改変禁止) | 改変不可 | 切り抜き・文字入れも改変に当たり得る |
| SA(継承) | 改変物も同じライセンスで公開 | 自分の作品にも同条件が付く |
| CC0 | 権利を放棄(PD に近い) | 表示不要でも、出典を記録しておく |

## フォント

- 商用利用・SNS 画像への使用・電子書籍への埋め込みの可否を確認。
- ライセンスの控えを台帳に保存。
- パソコンに最初から入っているフォントでも、利用条件は OS・提供元の規約で確認します(⚪)。

## 施設・地域の写真

- 施設・境内・店舗の撮影・掲載ルールは**施設ごと**。公式サイトで確認し、必要なら許可を得る。
- 人物が写る場合は肖像権・プライバシー([legal-compliance](legal-compliance.md)、[privacy-and-personal-info](privacy-and-personal-info.md))。

## 具体例

| 場面 | OK の例 | NG の例 |
|---|---|---|
| 投稿の背景写真 | 商用可のストックフォトを、規約どおりクレジット付きで使う | 検索で見つけた写真を保存して使う |
| 他の人の作品紹介 | 本人の投稿を**サービスの共有機能**(引用ポスト・シェア)で紹介 | 画像を保存して自分の投稿として再アップ |
| 古い絵画 | 作者の没後70年以上で、所蔵館が自由利用を認める画像データ | 所蔵館が商用不可としている画像データを収益化に使う |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 「フリー素材」と書いてあったので確認しなかった | 「無料」と「条件なし」は別。規約を読む |
| まとめサイトの画像を使った | 元の配布元を探し、そこで条件を確認 |
| NC の素材を収益化アカウントで使った | 差し替える。台帳に「商用」欄を設ける |
| クレジットを忘れた | 気づいた時点で追記。テンプレートにクレジット欄を作る |
| 指摘を受けた | すぐ非公開にし、権利者に連絡([crisis-response](crisis-response.md)) |

# 動画・リールの基礎

> サービスごとの**公式の動画仕様(長さ・容量・形式)は未確認**です(→ [要検証リスト](../00-meta/verification-queue.md) #18)。以下は制作上の一般的な指針(⚪)。

## 縦型動画の設計

| 項目 | 指針 |
|---|---|
| 比率 | 縦 9:16(1080×1920)が基本 |
| 冒頭 | 最初の1〜3秒で内容を示す(題材名・問い) |
| 字幕 | 常に付ける(音なし視聴が多い ⚪)。大きく、安全領域に |
| 長さ | 短く。必要な情報だけ。上限は各サービスの仕様を確認 |
| 音声 | 権利クリアな音源のみ。ナレーションは自分の声 |
| 構成 | 問い → 物語 → 答え → 次回予告 |

## 神話解説動画の型

1. **一枚絵＋ナレーション**: 画像を切り替えながら30〜60秒で場面を語る。
2. **原文朗読＋訓読の字幕**: 縦書きの字幕を重ねる。
3. **地図で見る記紀**: 地名の位置を地図で示す。

## 音源・BGM

- 商用利用の可否・クレジット表記を確認。サービス内の音源には**利用範囲の制約**(ビジネスアカウントなど)がある場合あり(⚪ 要確認)。
- 朗読の音源は、**自分で録音**するのが最も安全。

## 制作ワークフロー

[image-production-workflow](image-production-workflow.md) を動画にも準用: 台本 → 素材(権利) → 編集 → 書き出し → 実機確認 → 命名・保管。

## 字幕とアクセシビリティ

- 字幕のコントラスト、フォントサイズを確保。
- 動画の要点を**キャプション(本文)にも書く**。

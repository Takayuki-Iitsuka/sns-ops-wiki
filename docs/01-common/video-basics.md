# 動画・リールの基礎

> **このページで分かること**: 縦型の短い動画(リール・ショート・TikTok)と横型の長い動画(YouTube など)の作り方の基本、構成の型、字幕・音・安全領域の考え方。
>
> **対象**: 初心者  **先に読むページ**: [mobile-viewing-optimization](mobile-viewing-optimization.md)

> 公式の動画仕様は未確認(→ [video-specs-comparison](video-specs-comparison.md)、[要検証リスト](../00-meta/verification-queue.md) #18)。以下は制作上の一般的な指針(⚪)。書き出し値は [export-presets](export-presets.md)。

## 概要

動画は、文章や画像よりも「人柄」「手順」「動き」を伝えやすい形式です。一方で、**最初の数秒で見るかどうかが決まり、音なしで見られることも多い**という特徴があります。

初心者は、スマホで撮影・編集できる **縦型 9:16 の短い動画(15〜60秒程度 ⚪)** から始めると、撮影の負担が小さく、複数のサービスに展開しやすくなります。慣れてきたら、検索で長く見られる横型の長尺動画に広げます。

## 用語

| 用語 | 意味 |
|---|---|
| vertical video(縦型動画) | 縦長(9:16)の動画。スマホの全画面で見られる |
| short-form(短尺動画) | リール・ショート・TikTok などの短い動画 |
| long-form(長尺動画) | 数分〜数十分の動画。YouTube の通常動画など |
| hook(フック、つかみ) | 冒頭で視聴者を引きつける部分 |
| caption / subtitle(字幕) | 画面に表示する文字。音声の書き起こし |
| SRT | 字幕ファイルの形式の一つ。時間と文字を記録する |
| safe area(安全領域) | アプリの UI が重ならない中央の領域 |
| frame rate / fps(フレームレート) | 1秒あたりのコマ数。30fps・60fps など |
| B-roll(Bロール) | 説明に重ねる補助的な映像(手元、風景など) |

## 縦型・短尺

| 項目 | 指針 |
|---|---|
| 比率 | 9:16(1080×1920)が基本 |
| 冒頭 | 最初の1〜3秒で内容を示す(題名・問い・結果) |
| 字幕 | 常に付ける(音なし視聴が多い ⚪)。大きく、**安全領域**(上下左右のUIを避ける) |
| 長さ | 必要な情報だけ。上限は各サービスの仕様(YouTube Shorts は最大3分 ✅) |
| 音声 | 権利クリアな音源のみ。ナレーションは自分の声 |
| 構成 | 問い → 展開 → 答え → 次の行動 |
| ループ | 最後と最初をつなぐと再視聴されやすい(⚪) |

## 横型・長尺(YouTube など)

| 項目 | 指針 |
|---|---|
| 比率 | 16:9(1920×1080) |
| 冒頭 | 5〜15秒で価値を示す |
| 構成 | チャプターで区切る。要点→詳細→まとめ。YouTube のチャプターは 00:00 始まり・3つ以上・各10秒以上(✅) |
| サムネイル・タイトル | 動画の約束を誇張せず示す([05-youtube](../05-youtube/03-text-and-discovery.md)) |
| 音質 | 映像より優先(ノイズ、音量の統一) |
| 書き出し | フレームレートは撮影時と同じ(✅ YouTube のエンコード設定) |

## 動画の型(汎用)

1. **一枚絵+ナレーション**: 画像を切り替えながら30〜60秒。
2. **画面録画+解説**: ツールの使い方。カーソルを大きく。
3. **インタビュー/対談**: 字幕とチャプター。
4. **ビフォーアフター**: 比較の一画面。
5. **切り抜き**: 長尺から要点を縦型で。

### 30秒動画の台本の例(料理アカウント)

| 秒 | 映像 | 字幕・ナレーション |
|---|---|---|
| 0〜2 | 完成した料理のアップ | 「10分で作れる作り置き」 |
| 2〜8 | 材料を並べる | 「材料は3つだけ」 |
| 8〜22 | 手順を3カット | 「1. 切る 2. 和える 3. 冷やす」 |
| 22〜27 | 保存容器に入れる | 「冷蔵で○日が目安(出典: …)」 |
| 27〜30 | 完成+文字 | 「保存して試してね」 |

## 撮影の基本(スマホ ⚪)

1. **レンズを拭く**(指紋で白くぼやける)。
2. **明るい場所**で撮る。窓に向かって撮ると逆光になるので、窓を横か背中側に。
3. **手ぶれを防ぐ**: 両手で持つ、肘を体に付ける、三脚やスマホスタンドを使う。
4. **縦で撮る**(縦型動画の場合)。横で撮って縦に切り抜くと画質が落ちる。
5. **音を確認する**: 換気扇・エアコン・外の音。話すならマイクを口に近づける。
6. 1カットは長めに撮っておき、編集で切る。

## 音源・BGM

- 商用利用の可否・クレジット表記を確認。サービス内の音源には**利用範囲の制約**(ビジネスアカウントなど)がある場合あり(⚪ 要確認)。
- ナレーション・朗読は**自分で録音**するのが最も安全。
- 詳しくは [music-and-licensing](music-and-licensing.md)。

## 制作ワークフロー

[image-production-workflow](image-production-workflow.md) を動画にも準用: 台本 → 素材(権利) → 編集 → 書き出し → 実機確認 → 命名・保管。

編集アプリの選び方と書き出し設定は [video-editing-apps](video-editing-apps.md)。

## 字幕とアクセシビリティ

- コントラスト、フォントサイズを確保。字幕ファイル(SRT)を用意できるサービスでは別ファイルで。
- 動画の要点を**キャプション(本文)にも書く**。
- 点滅・激しい動きを避ける。
- 自動字幕は**固有名詞・数字を誤りやすい**ので、必ず見直す(⚪)。

## 再利用

縦型 1080×1920 を基準に、各サービス向けに書き出す。他サービスの**透かし付き動画の転載は避ける**(推奨度低下の可能性 ⚪)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 冒頭に挨拶や自己紹介が長く、すぐ離脱される | 結果や問いを最初の1〜3秒に置く |
| 字幕がボタンやキャプションに隠れる | 安全領域を空ける([mobile-viewing-optimization](mobile-viewing-optimization.md)) |
| 音が小さい・雑音が大きい | マイクを近づけ、静かな場所で録る。編集で音量をそろえる |
| 流行曲を使って削除・ミュートされた | 権利を確認した音源だけを使う |
| 編集アプリの透かし入りのまま他サービスに投稿 | 透かしなしで書き出す([video-editing-apps](video-editing-apps.md)) |
| 撮影したのにデータが見つからない | 命名規則と保管場所を決める |

## チェックリスト

- [ ] 冒頭1〜3秒で内容が分かる
- [ ] 字幕を付け、誤字・固有名詞を見直した
- [ ] 字幕・重要な要素が安全領域内にある
- [ ] 音源の権利を確認した
- [ ] スマホ実機で、音あり・音なしの両方で確認した
- [ ] 他サービスの透かしが入っていない

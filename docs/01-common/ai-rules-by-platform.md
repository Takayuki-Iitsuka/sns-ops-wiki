# AI 利用のルールと設定(サービス別)

> **このページで分かること**: 生成 AI を使った投稿で、サービスごとに「開示(AI 使用の表示)が必要か」「どこで設定するか」、日本の法令・ガイドラインの論点、運用ルールの例。
>
> **対象**: 初心者〜中級者(AI で画像・文章・音声を作って投稿する人)  **先に読むページ**: [ai-usage-policy](ai-usage-policy.md)(共通の方針)

生成 AI を使った投稿には、**開示(ラベル)のルール**と**設定の項目**がサービスごとにあります。全体方針は [ai-usage-policy](ai-usage-policy.md)。

## 概要

多くのサービスは、**本物と見分けがつかない AI 生成・加工コンテンツ**に「AI で作った」と分かる表示を求めるか、自動でラベルを付けるようになっています。理由は、見る人が「実際の出来事」「本人の発言」だと誤解するのを防ぐためです。

一方で、**アイデア出し・下書き・色調整など制作の補助**は、開示が不要とされることが多いです(YouTube は公式に明記 ✅)。ルールは2026年(皇紀2686年・令和8年)時点でも変化が続いているため、投稿前に各サービスの最新のヘルプを確認してください。

このページの使い方:

1. §1 の比較表で、投稿するサービスの開示の要否を確認する。
2. §2〜§4 でサービスごとの詳しい条件を見る。
3. §5 で日本の法令上の論点を確認する。
4. §7 の運用ルールと §8 の文例を使って投稿する。

## 用語

| 用語 | 意味 |
|---|---|
| disclosure(開示) | 「AI を使った」と見る人に知らせること |
| AI label(AI ラベル) | サービスが投稿に表示する「AI 生成」などの表示 |
| synthetic / altered content(合成・改変コンテンツ) | AI などで作った、または大きく加工した映像・画像・音声 |
| C2PA / Content Credentials(コンテンツ認証情報) | 画像・動画に「どう作られたか」の情報を埋め込む業界標準 |
| IPTC メタデータ | 写真に埋め込む説明情報の標準。AI 生成を示す項目がある |
| watermark(透かし) | 画像・動画に入れる、作成元を示す印 |
| opt-out(オプトアウト) | 自分のデータを学習などに使わないよう申し出ること |
| paid partnership(タイアップ、PR 表示) | 広告・案件であることの表示。AI の開示とは別の仕組み |

> ✅ は YouTube ヘルプ、Instagram API 文書、X の changelog を直接確認。他は報道・解説記事(🟡)です(#27, #57)。

## 1. 比較表

| サービス | 開示の要否 | 設定場所 | 確度 |
|---|---|---|---|
| **YouTube** | **本物のように見える AI 生成・大幅改変のコンテンツは開示が必要** | アップロード時、YouTube Studio の「**AI の使用**」設定 | ✅ |
| **Instagram**(API) | 自己申告のパラメータ **`is_ai_generated=true`** | 公開 API(カルーセルは親にのみ指定) | ✅ |
| **Instagram・Facebook・Threads**(アプリ) | Meta は C2PA/IPTC などの信号で AI を検出してラベルを付与。**自己申告の設定**もあり。AI 生成の人物のプロフィールには「AI」ラベル(2026年8月31日〜)との報道は未確認 | 投稿画面の AI 関連設定(要確認) | 🟡 |
| **TikTok** | **リアルな AI 生成コンテンツはラベルが必要**。C2PA メタデータで自動ラベルも。未開示の AI 広告は却下の対象 | 投稿画面の AI 生成コンテンツのスイッチ | 🟡 |
| **X** | **一般的な開示義務は確認できず**。武力紛争の映像に AI ラベルを求める(有料クリエイター対象)と報道。「Made with AI」ラベルのテスト報道。Grok 生成の画像・動画に透かし | 設定は要確認 | 🟡 |
| **note** | AI 利用に関するガイドライン(要確認) | — | ⚪ #28 |
| **LINE・Bluesky** | 要確認 | — | ⚪ |

## 2. YouTube の公式ルール(✅ 「生成 AI コンテンツの使用に関する開示」)

### 開示が必要なもの

- **実在する人物が実際には発言・行動していないことを、発言・行動しているように**見せている。
- **実際の出来事や場所の映像を改変**している。
- **現実には起こっていないシーンをリアルに生成**している。
- **動画の中心となる音楽を作成**する。

### 開示が不要なもの

- **非現実的な内容**(ユニコーンに乗る人、グリーンスクリーンで宇宙を漂う人、アニメ)。
- **軽微な編集**(美顔フィルター、色調整、背景のぼかし、字幕作成、シャープネス調整・アップスケーリング・音声の修復)。
- **制作の補助**(動画案のアウトライン、スクリプト、サムネイル、タイトル、インフォグラフィックの作成・改善、アイデア出し)。
- 自分の声のクローンによるナレーションや吹き替え、ゲームプレイ映像。
- 車が動いているように見せる背景の AI 生成・拡張。

### 開示が必要な具体例

- AI 生成の音楽
- AI で生成した実在する場所の追加映像(旅行動画にマウイ島のサーファーの AI 動画を追加など)
- 実在する2人のプロテニス選手の試合の**リアルな**動画
- 実際には言われていないアドバイスを言ったかのように見せる
- 実在の都市に向かう竜巻などの気象現象をリアルに描写

→ 開示すると視聴者に**ラベル**が表示される。

## 3. Instagram の API(✅)

- `is_ai_generated=true` で自己申告(画像・動画)。カルーセルは**親コンテナ**にのみ。子に指定するとエラー。
- ブランド案件は別に `is_paid_partnership`(Facebook ログイン経由)。AI 表記と PR 表記は**別の仕組み**。

## 4. X と Grok(🟡 / ✅)

| 論点 | 内容 | 確度 |
|---|---|---|
| 投稿での開示 | 一般的な義務はなし。**武力紛争の映像は AI ラベルが必要(有料クリエイター)**と報道 | 🟡 |
| Grok 生成物 | 画像・動画に**透かし**が付くと報道 | 🟡 |
| 自動返信 | **API では、元の投稿者があなたを呼び出した場合にのみ返信可** | ✅ docs.x.com |
| `paid_partnership` | PR の表示フィールド(Post 作成時) | ✅ |
| 実在人物の性的画像 | xAI は生成機能を無効化と発表。日本政府が安全対策強化を要請と報道 | 🟡 |
| 学習への利用 | 投稿が Grok の学習に使われる設定が X の設定にある(オプトアウトの方法は要確認) | ⚪ #57 |

## 5. 日本の法令・ガイドライン

| 論点 | 内容 | 確度 |
|---|---|---|
| 著作権 | 生成・利用の段階では、**人が作った場合と同じ基準**で侵害が判断される。既存の作品に似た画像を公開すれば侵害のおそれ。**文化庁「AIと著作権に関する考え方」(2024年(皇紀2684年・令和6年)3月15日取りまとめ)** | 🟡 解説記事経由(取りまとめ日・主体=文化審議会 著作権分科会 法制度小委員会は ✅ 文化庁ページ) |
| 利用者の責任 | AI が生成した内容をそのまま SNS に投稿しても、**責任は利用者本人**(大学のガイドラインの整理) | 🟡 |
| 商用利用 | 使うサービスの**利用規約**(商用可否・生成物の権利)を確認。商用不可の画像を読み込んで追加学習すると商用不可になる指摘 | 🟡 |
| AI 事業者ガイドライン | 経産省・総務省のガイドライン。表示に関する最新は公式で確認 | ⚪ |
| 肖像権・パブリシティ | 実在人物の生成画像は権利侵害のおそれ | ⚪ |
| ステマ | AI で作った「体験談」は、**実体験でなければ不当表示**になり得る | ⚪ [legal-compliance](legal-compliance.md) |

## 6. AI ツールの設定(⚪ 要確認)

| 設定 | 内容 | 場所の例 |
|---|---|---|
| **学習へのデータ利用** | 自分の投稿・入力が AI の学習に使われるか | X(Grok の設定)、Meta(AI の学習に対する異議申立て)、YouTube(第三者による学習の設定)、各 AI ツールの「データ共有」 |
| **会話履歴の保存** | 機密情報を入力しない。履歴を残さない設定 | 各 AI ツール |
| **画像の生成物の権利** | 商用利用可否 | 各サービスの規約 |
| **地域・年齢設定** | 日本での提供機能が異なる | 各サービス |
| **API のログ** | リクエストの保存期間 | 各 API の規約 |

→ 設定の場所と文言は変わるため、**各サービスの設定画面で確認**し、結果を台帳に記録する。

## 7. 運用ルール(推奨)

1. **画像・動画**: 本物と誤解されうるものは、**必ず開示**(サービスの設定+キャプション)。
2. **文章**: 下書きに使うのは可。**事実・出典は人が確認**([sensitive-topics-and-accuracy](sensitive-topics-and-accuracy.md))。
3. **体験談・レビュー**: AI で作らない(ステマ・景表法)。
4. **実在の人物**: 生成しない(本人の許可がある場合を除く)。
5. **機密・個人情報**: AI に入力しない(顧客情報、未公開の数字)。
6. **台帳**: 使用ツール、日付、プロンプトの要点、人が直した点を記録。
7. **Grok・Gemini などの出力の画像**: 透かしや規約を確認。

## 8. キャプションの開示文例

```
この画像は AI(○○)で生成しました。
```

```
文章の下書きに AI を使い、人が事実確認して編集しています。
```

## 手順: 投稿前の開示の流れ(共通)

1. **AI を使った部分を書き出す**: 例「背景を生成」「声を合成」「文章の下書き」。
2. **開示が必要か判断する**: §1 の表と §2 の YouTube の基準を目安に、「本物と誤解される可能性があるか」で考える。迷ったら開示する。
3. **サービスの設定をオンにする**: YouTube は Studio の「AI の使用」(✅)、Instagram の API は `is_ai_generated`(✅)。アプリの設定の場所は ⚪(表記は変わる可能性)。
4. **キャプションにも書く**: §8 の文例を使う。ラベルが表示されない場所(画像の転載先など)でも伝わるように。
5. **台帳に記録する**: ツール・日付・開示の方法([ai-usage-policy](ai-usage-policy.md) の台帳)。

## 具体例: 開示が要る?要らない?(YouTube の基準を当てはめた例)

| 投稿の内容 | 判断 | 根拠 |
|---|---|---|
| AI でアイデアを出し、自分で撮影した料理動画 | 不要 | 制作の補助(✅ YouTube) |
| 実在の街に AI 生成の竜巻が近づく映像 | **必要** | 実在の場所の出来事をリアルに生成(✅ YouTube) |
| 手描き風の AI イラスト(明らかに非現実的) | 不要(YouTube の基準) | 非現実的な内容(✅)。ただし他サービス・キャプションでの表示は推奨(⚪) |
| AI で作った BGM が中心の動画 | **必要** | 中心となる音楽の作成(✅ YouTube) |
| 自分の声のクローンでナレーション | 不要(YouTube の基準) | 自分の声のクローン(✅) |

## よくある失敗と対処

| 失敗 | 起きること | 対処 |
|---|---|---|
| キャプションに書いたがサービスの設定を忘れた | ラベルが付かず、規約違反とみなされるおそれ | 設定とキャプションの両方 |
| 「AI 生成」と書けば何でも許されると思った | 権利侵害・肖像権の問題は残る | 開示と権利確認は別の作業 |
| AI の開示と PR 表示を混同 | どちらかが抜ける | AI は `is_ai_generated` など、PR は `paid_partnership` など別に設定 |
| 学習への利用設定を確認していない | 意図せず投稿が学習に使われる | §6 の設定を各サービスで確認 |
| 古い解説記事のルールを信じた | 現行ルールと違う | 公式ヘルプで確認(本ページの ✅ を優先) |

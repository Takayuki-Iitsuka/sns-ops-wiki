# 音楽・音源の権利

動画・リール・ライブで BGM を使うときの整理です。**公式の規約と管理団体の情報で確認**してください(⚪ #62)。

## 1. 権利の種類

| 権利 | 内容 | 例 |
|---|---|---|
| **著作権(楽曲)** | 作詞・作曲の権利 | 管理団体(JASRAC、NexTone など)が管理することが多い |
| **著作隣接権(原盤)** | 録音物(演奏・音源)の権利 | レコード会社 |
| **実演家の権利** | 歌手・演奏者 | |

→ **曲そのもの**と**録音された音源**は別の権利。「弾いてみた」「歌ってみた」でも楽曲の権利が関わる。

## 2. サービス内の音源ライブラリ

| サービス | 内容 | 注意 |
|---|---|---|
| Instagram / Facebook | アプリ内の音源ライブラリ | **ビジネスアカウントは使える音源が限定される**場合がある(⚪) |
| TikTok | 商用音源ライブラリ | 商用アカウントは**商用で使える音源のみ**(⚪) |
| YouTube | オーディオライブラリ、Shorts の音源 | 収益化動画では利用範囲が変わる(⚪) |
| X | 音源機能は限定的 | — |

- **サービス内で選んだ音源**は、そのサービス内での利用が想定されている。**他サービスへの転用**(保存して別の SNS に投稿)は権利上の問題になり得る。

## 3. 管理団体とプラットフォームの契約(⚪ 要確認)

- 日本では、プラットフォームと管理団体(JASRAC など)の**包括契約**があり、一定の利用は許諾済みとされる場合がある。ただし、**範囲(個人投稿か、商用か、収益化か)**が異なる。
- 「JASRAC 管理曲だから自由に使える」ではない。**原盤(音源)の権利**は別。

## 4. 実務の選択肢

| 方法 | 安全度 | 内容 |
|---|---|---|
| **自作の曲・自分で録音** | 高 | 権利は自分 |
| **商用利用可のロイヤリティフリー音源** | 高 | **ライセンス条件**(クレジット、SNS 配信、収益化)を確認し、台帳に記録 |
| **サービス内の音源**(各アプリで投稿) | 中 | そのアプリ内のみ。ビジネス用途の制限に注意 |
| **市販曲・流行曲を無断で使う** | 低 | 削除・収益化停止・警告の恐れ |
| **音声なし+字幕** | 高 | 権利の問題を回避 |

## 5. 収益化と Content ID(⚪)

- YouTube では、権利者が**Content ID**で自動検出し、収益を権利者に移したり、動画をブロックしたりすることがある。
- 収益化動画では、**ライセンスのない BGM を使わない**。
- ライブ配信のアーカイブや切り抜きでも同様。

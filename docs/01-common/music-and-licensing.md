# 音楽・音源の権利

> **このページで分かること**: 動画・リール・ライブで音楽を使うときに関わる権利の種類と、安全に使うための選択肢・記録のしかた。
>
> **対象**: 初心者  **先に読むページ**: [video-basics](video-basics.md)

動画・リール・ライブで BGM を使うときの整理です。**公式の規約と管理団体の情報で確認**してください(⚪ #62)。

## 概要

音楽は動画の印象を大きく左右しますが、**権利の問題が最も起きやすい素材**でもあります。1曲の中に「曲を作った人の権利」と「録音した人の権利」が重なっており、片方の許可だけでは足りないことがあります。

問題が起きると、動画の削除、音声のミュート、収益が権利者に移る、ライブ配信の機能制限などにつながります。初心者は「**自分で作った音、またはライセンス条件を確認した音源だけを使う**」を基本にすると安全です。

## 用語

| 用語 | 意味 |
|---|---|
| copyright(著作権) | 作詞・作曲など作品そのものの権利 |
| neighboring rights(著作隣接権) | 録音物(原盤)、実演、放送などに関わる権利 |
| master / 原盤(げんばん) | 録音された音源そのもの。レコード会社などが権利を持つことが多い |
| royalty-free(ロイヤリティフリー) | 一度の許諾・購入で、使うたびの使用料が不要な素材。**無条件に自由という意味ではない** |
| license(ライセンス、利用許諾) | 権利者が示す「使ってよい条件」 |
| Content ID(コンテンツ ID) | YouTube の自動照合システム。権利者の登録データと動画を照合する |
| 包括契約 | 管理団体とサービスが結ぶ、まとめての利用許諾契約 |

## 1. 権利の種類

| 権利 | 内容 | 例 |
|---|---|---|
| **著作権(楽曲)** | 作詞・作曲の権利 | 管理団体(JASRAC、NexTone など)が管理することが多い |
| **著作隣接権(原盤)** | 録音物(演奏・音源)の権利 | レコード会社 |
| **実演家の権利** | 歌手・演奏者 | |

→ **曲そのもの**と**録音された音源**は別の権利。「弾いてみた」「歌ってみた」でも楽曲の権利が関わる。

## 2. サービス内の音源ライブラリ

| サービス | 内容 | 注意 |
|---|---|---|
| Instagram / Facebook | アプリ内の音源ライブラリ | **ビジネスアカウントは使える音源が限定される**場合がある(⚪) |
| TikTok | 商用音源ライブラリ | 商用アカウントは**商用で使える音源のみ**(⚪) |
| YouTube | オーディオライブラリ、Shorts の音源 | 収益化動画では利用範囲が変わる(⚪) |
| X | 音源機能は限定的 | — |

- **サービス内で選んだ音源**は、そのサービス内での利用が想定されている。**他サービスへの転用**(保存して別の SNS に投稿)は権利上の問題になり得る。
- 動画編集アプリ内の音源も同じ考え方です。アプリの利用規約で「どこに投稿してよいか」を確認してください([video-editing-apps](video-editing-apps.md))。

## 3. 管理団体とプラットフォームの契約(⚪ 要確認)

- 日本では、プラットフォームと管理団体(JASRAC など)の**包括契約**があり、一定の利用は許諾済みとされる場合がある。ただし、**範囲(個人投稿か、商用か、収益化か)**が異なる。
- 「JASRAC 管理曲だから自由に使える」ではない。**原盤(音源)の権利**は別。
- JASRAC と利用許諾契約を結ぶ主な動画サービスとして YouTube・Instagram・Facebook・ニコニコ動画・Twitch などを挙げる報道がある(🟡 2026年(皇紀2686年・令和8年)5月の記事)。**最新の一覧は JASRAC 公式で確認**(⚪ 要確認)。

## 4. 実務の選択肢

| 方法 | 安全度 | 内容 |
|---|---|---|
| **自作の曲・自分で録音** | 高 | 権利は自分 |
| **商用利用可のロイヤリティフリー音源** | 高 | **ライセンス条件**(クレジット、SNS 配信、収益化)を確認し、台帳に記録 |
| **サービス内の音源**(各アプリで投稿) | 中 | そのアプリ内のみ。ビジネス用途の制限に注意 |
| **市販曲・流行曲を無断で使う** | 低 | 削除・収益化停止・警告の恐れ |
| **音声なし+字幕** | 高 | 権利の問題を回避 |

### 素材サイトの音源を使う手順

1. 利用規約(ライセンス)のページを開く。
2. 次の5点を確認する: **商用利用**、**SNS・動画配信**、**収益化動画**、**クレジット表記の要否**、**改変(切り取り・速度変更)**。
3. ダウンロードしたファイル名と規約の URL・確認日を台帳(§6)に書く。
4. 必要ならクレジットを説明文に書く。
5. 投稿後、Content ID などの申し立てが来たら、台帳の記録をもとに対応する。

## 5. 収益化と Content ID

- YouTube では、権利者が**Content ID**で自動検出し、収益を権利者に移したり、動画をブロックしたりすることがある。動画はアップロード時に自動でスキャンされ、権利者の設定により**ブロック・収益化・トラッキング**のいずれかが行われる(✅ YouTube ヘルプ)。措置は地域ごとに異なる場合がある(✅)。
- Content ID を使えるのは一定の基準を満たす権利者(✅)。申し立てには異議申し立ての手続きがある(✅)。
- 収益化動画では、**ライセンスのない BGM を使わない**。
- ライブ配信のアーカイブや切り抜きでも同様。YouTube では、ライブ配信が著作権で保護された別のライブ配信と一致した場合や、著作権侵害の警告を受けた場合に、**ライブ配信機能が制限**されることがある(✅ YouTube ヘルプ)。

## 具体例

| 場面 | 良い例 | 避けたい例 |
|---|---|---|
| 料理のリール | アプリ内の音源をそのアプリで使う / 調理音だけ | 流行曲を別アプリで編集して複数 SNS に投稿 |
| 解説動画(収益化) | 商用・収益化可の素材を台帳に記録して使う | 「フリー」と書かれたサイトの曲を規約を読まずに使う |
| ライブ配信 | BGM なし、または配信可のライセンス曲 | 市販 CD を流しながら配信 |
| 歌ってみた | サービスの許諾範囲と原盤の扱いを確認 | 市販音源(原盤)をそのまま伴奏に使う |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 「ロイヤリティフリー=何でも自由」と考えた | 商用・収益化・クレジット条件を個別に確認する |
| Instagram で使えた音源を YouTube にも流用した | サービス内音源はそのサービス内だけで使う |
| 規約が変わり、以前の条件が分からない | 台帳に確認日と規約 URL を残す(スクリーンショットも) |
| Content ID の申し立てが来て慌てた | 台帳の記録を確認し、正当なら異議申し立て、心当たりがあれば音源を差し替える |

## 注意点

- 生成 AI で作った音楽は、サービスごとに開示ルールがある(✅ [ai-rules-by-platform](ai-rules-by-platform.md))。
- 権利の判断が難しい場合は、権利者・管理団体に問い合わせるか、使わない判断をする。

# ライブ配信の基本

> **このページで分かること**: 主要サービスのライブ配信の始め方・条件、スマホ配信とパソコン(配信ソフト)配信の違い、機材、推奨設定、チャットのモデレーション、収益、規約上の注意。
>
> **対象**: 初心者  **先に読むページ**: [video-basics](video-basics.md)

## 概要

ライブ配信は、**視聴者とリアルタイムで会話できる**形式です。質問に答える、作業の様子を見せる、新商品を紹介するなど、編集した動画よりも人柄や熱量が伝わります。投げ銭(ギフト)やメンバーシップなど、ライブならではの収益もあります。

一方で、**やり直しがきかない**ため、個人情報の映り込み、音楽の権利、荒らしコメントなどへの準備が必要です。初心者は、**スマホ1台・短時間(15〜30分 ⚪)・告知してから**の配信で練習するのがおすすめです。

## 用語

| 用語 | 意味 |
|---|---|
| live streaming(ライブ配信) | 映像・音声をリアルタイムで届けること |
| encoder(エンコーダ、配信ソフト) | パソコンの映像を配信用に変換して送るソフト。OBS Studio など |
| stream key(ストリームキー) | 配信ソフトとサービスをつなぐ秘密の文字列。**他人に見せない** |
| RTMP / RTMPS | 配信ソフトからサービスへ映像を送る方式。RTMPS は暗号化版 |
| bitrate(ビットレート) | 1秒あたりのデータ量。回線の上り速度に合わせる |
| keyframe interval(キーフレーム間隔) | 圧縮の基準になるコマの間隔 |
| latency(遅延) | 配信者の動きが視聴者に届くまでの時間 |
| moderator(モデレーター) | チャットを管理する補助役 |
| archive(アーカイブ) | 配信終了後に残る録画 |
| simulcast(同時配信) | 複数のサービスに同時に配信すること |

## サービス別の始め方と条件

| サービス | 配信方法 | 主な条件 | 確度・出典 |
|---|---|---|---|
| **YouTube** | ウェブカメラ(パソコン)、モバイル、エンコーダ(配信ソフト)、ゲーム機 | **過去90日間にライブ配信の制限を受けていない**、**チャンネルの確認**、**16歳以上** | ✅ YouTube ヘルプ |
| YouTube(モバイル) | YouTube アプリ | 追加の要件あり(登録者数の条件は公式ページで数値を確認できず) | ⚪ 要確認 |
| X | アプリの作成画面から「ライブ」/ パソコンは Media Studio Producer・Live Studio(配信ソフト連携) | 公開アカウント。パソコン配信の Live Studio は Premium または認証済みアカウントとする報道 | 🟡 help.x.com(検索要約)、報道 |
| Instagram | アプリのライブ | 最長4時間(2020年(皇紀2680年・令和2年)10月の発表)、アーカイブは30日 | 🟡 報道 |
| TikTok | アプリの LIVE、パソコンは TikTok LIVE Studio | 18歳以上。フォロワー条件は 50人 / 1,000人 と資料で不一致。ギフトは追加条件 | 🟡 二次資料(不一致) |
| Twitch | 配信ソフト、アプリ | 条件なしで配信可(収益化は [03-twitch](../09-other-services/03-twitch.md)) | ⚪ |

- YouTube は、アクティブなライブ配信が**1チャンネルあたり10個まで、ストリームキー1個あたり3個まで**(✅)。
- 条件はアプリの表示が最新です。**配信前にアプリ内の案内を確認**してください。

## スマホ配信とパソコン配信の違い

| 項目 | スマホ配信 | パソコン配信(配信ソフト) |
|---|---|---|
| 始めやすさ | アプリだけで始められる | ソフトの設定が必要 |
| 画面の工夫 | 限られる | 画面共有、テロップ、複数カメラ、BGM 管理 |
| 安定性 | 通信環境に左右される | 有線 LAN で安定しやすい |
| 向く内容 | 外出先、雑談、店頭の紹介 | 講座、ゲーム、作業配信、対談 |

## 機材(⚪ 一般的な目安)

| 段階 | 映像 | 音声 | その他 |
|---|---|---|---|
| まず始める | スマホ(背面カメラが高画質) | スマホ内蔵マイク、静かな部屋 | スマホスタンド、充電器 |
| 少し整える | スマホ+三脚 / パソコンのウェブカメラ | ピンマイク、USB マイク | リングライトなどの照明 |
| 本格的に | ミラーレスカメラ+キャプチャーデバイス | オーディオインターフェース+マイク | 有線 LAN、配信ソフト |

- **音は映像より大事**です。聞き取りにくい配信はすぐ離脱されます(⚪)。
- 収録の機材は [podcast-and-audio](podcast-and-audio.md) も参照。

## YouTube ライブの推奨設定(✅ YouTube ヘルプ)

| 項目 | 推奨 |
|---|---|
| プロトコル | RTMP / RTMPS(**RTMPS を推奨**) |
| 映像コーデック | H.264、H.265(HEVC)、AV1 |
| フレームレート | 最高 60fps |
| キーフレーム間隔 | **2秒を推奨**(4秒以下) |
| ビットレートの方式 | CBR(固定) |
| 音声 | AAC または MP3。ステレオは 44.1kHz・128Kbps |

| 解像度 / フレームレート | H.264 の推奨ビットレート | AV1・H.265 の推奨 |
|---|---|---|
| 720p / 30fps | 8 Mbps | 6 Mbps |
| 1080p / 30fps | 14 Mbps | 10 Mbps |
| 1080p / 60fps | 17 Mbps | 12 Mbps |

- 回線の**上り速度に余裕**がない場合は 720p から始めます(⚪)。

## 配信の手順(初回)

1. **企画**: テーマ、長さ、話す順番(3〜5項目)をメモにする。
2. **告知**: 1〜3日前に日時を SNS で告知。YouTube は予約配信(待機所)を作ると URL を先に共有できる(⚪)。
3. **環境の確認**: 通知をオフ、不要なアプリを閉じる、背景に個人情報(郵便物・窓の外・書類)がないか確認。
4. **テスト配信**: 限定公開や非公開で数分配信し、音量・映像・遅延を確認(⚪)。
5. **本番**: 最初の1〜2分は遅れて来る人を待ちつつ、今日の内容を話す。
6. **終了**: 次回の予定と、アーカイブ・関連リンクを案内。
7. **振り返り**: 視聴者数・視聴時間・チャットの内容を記録し、切り抜きや要点投稿に再利用。

## チャットのモデレーション

YouTube で使える主な機能(✅ YouTube ヘルプ「チャットを管理する」):

| 機能 | 内容 |
|---|---|
| モデレーター | 標準モデレーターと管理モデレーターを指名できる |
| ブロックする単語 | 指定した語や近い語を含むメッセージをブロック |
| 不適切な可能性のあるメッセージの保留 | 「なし」「標準」「厳格」から選ぶ |
| 低速モード | 投稿の間隔を制限 |
| 登録者限定・メンバー限定のチャット | 参加できる人を絞る |
| タイムアウト・非表示 | 配信中に特定のユーザーを一時停止・非表示(本人には通知されない) |

- 配信前に**チャットのルール**(例: 個人情報を書かない、他の視聴者を攻撃しない)を概要欄や固定メッセージに書きます。
- 他のサービスにも同様の機能があります(⚪ 各アプリで確認)。運営全般は [community-management](community-management.md)。

## 収益

| サービス | 主な手段 | 確度 |
|---|---|---|
| YouTube | Super Chat・Super Stickers(**払い戻し不可** ✅)、メンバーシップ、広告 | ✅ / 🟡 |
| TikTok | LIVE ギフト(年齢・追加条件あり) | 🟡 |
| Instagram | ギフト・バッジ(条件は不一致) | 🟡 |
| X | サブスクリプション等(要確認) | 🟡 |
| Twitch | サブスク、Bits、広告 | 🟡 [03-twitch](../09-other-services/03-twitch.md) |

- 収益の全体像は [monetization-comparison](monetization-comparison.md)。投げ銭を**強く求める呼びかけ**は避けます(各サービスの規約 ⚪)。

## 規約・権利の注意

- **音楽**: 市販曲を流すと、配信の停止やアーカイブのミュート・削除につながる。YouTube では、ライブ配信が著作権で保護された別のライブ配信と一致した場合などに**ライブ配信が制限**される(✅)。詳しくは [music-and-licensing](music-and-licensing.md)。
- **未成年**: YouTube では、16歳未満が大人の同伴なしに配信する場合などに制限がある(✅)。
- **1日の上限**: YouTube はライブ配信の作成数が1日の上限に達すると、24時間後に再試行(✅)。
- **ゲーム・映像作品**: 権利者の配信ガイドラインを確認する(⚪)。
- **案件**: 配信中の PR も広告表記が必要([legal-compliance](legal-compliance.md))。
- **ストリームキーの管理**: 漏れると他人に配信される。画面共有や画面録画に映さない。漏れたら再発行する(⚪)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 音が小さい・反響する | マイクを口に近づける。カーテン・布のある部屋で配信 |
| 映像がカクカクする | ビットレート・解像度を下げる。有線 LAN にする |
| 通知や DM が画面に映った | 配信前に通知をオフ。画面共有は特定のウィンドウだけに |
| 誰も来ない | 事前告知と、定期的な曜日・時間の固定 |
| 荒らしコメントで雰囲気が悪化 | モデレーターを置き、ブロックする単語・保留を設定 |
| BGM でアーカイブがミュートされた | 配信可のライセンス曲か BGM なしにする |

## チェックリスト

- [ ] 配信の条件(年齢・チャンネルの確認など)を満たしている
- [ ] 告知を出し、配信の URL を共有した
- [ ] 背景・画面共有に個人情報が映らない
- [ ] 通知をオフにした
- [ ] テスト配信で音量・映像を確認した
- [ ] チャットのルールとモデレーション設定を済ませた
- [ ] BGM・映像素材の権利を確認した
- [ ] ストリームキーを画面に映していない

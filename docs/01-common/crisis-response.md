# 炎上・トラブル対応

> **このページで分かること**: 批判が集まった・誤りを指摘された・誹謗中傷を受けたときに、最初の1時間で何をするか、どう判断するか、どこに相談できるか。
>
> **対象**: すべての運用者(**トラブルが起きる前に一度読んでおく**ことを推奨)  **先に読むページ**: [comments-and-engagement](comments-and-engagement.md)

## 概要

「炎上」とは、投稿に批判や非難が短時間に集中し、拡散が止まらなくなる状態のことです。どんなに注意していても、誤解・言葉の選び方・事実の誤りで起こり得ます。

被害を小さくするために大事なのは、**慌てて動かないこと**と**事前に手順を決めておくこと**です。感情的な返信や無言の削除は、火に油を注ぐことがあります(⚪)。

このページの流れ: **初動(止める・記録する・分類する)→ 対応を選ぶ → 発信する → 事後の振り返り**。

## 用語

| 用語 | 意味 |
|---|---|
| 炎上 | 批判が集中して拡散が続く状態 |
| 初動 | 問題に気づいてから最初の対応(目安は1時間以内 ⚪) |
| 訂正 | 誤りを認めて正しい情報を示すこと |
| 謝罪 | 相手に与えた不快・損害について詫びること |
| 誹謗中傷 | 根拠のない悪口で相手の名誉や信用を傷つけること |
| 削除依頼 | サービスや管理者に、違法・有害な書き込みの削除を求めること |
| 証拠保全 | 投稿の URL・日時・内容をスクリーンショットなどで残すこと |
| 予約投稿 | 指定した時刻に自動で公開される投稿 |

## 初動(最初の1時間)

1. **投稿を止める**: 予約投稿を一時停止。感情的な返信はしない。
2. **事実を確認**: 何が、どの投稿で、誰が、どの規模で問題にしているか。スクリーンショットを保存(非公開)。
3. **分類**する:

| 分類 | 例 | 対応 |
|---|---|---|
| 事実誤認の指摘 | 数値・日付・固有名詞の誤り | 訂正 |
| 解釈の対立 | 学説・意見の違い | 出典を示して丁寧に、深追いしない |
| 配慮不足 | 宗教的表現への批判 | 謝罪と修正の検討 |
| 権利侵害の指摘 | 画像の無断使用 | 即時非公開、権利者へ連絡 |
| 悪意のある攻撃 | 誹謗中傷、粘着 | ブロック・通報、記録 |

### 記録のとり方(証拠保全)

1. 問題の投稿・コメントを開き、**URL・投稿日時・投稿者名**が写るようにスクリーンショットを撮る。
2. 別に URL をテキストでメモする。
3. 時系列の表(下)に記録する。
4. 保存先は**非公開**の場所。相手の個人情報を含むので、公開しない。

| 日時 | 何が起きたか | URL | 対応 | 担当 |
|---|---|---|---|---|
|  |  |  |  |  |

### 規模の見積もり(⚪ 目安)

| 規模 | 状態 | 対応の目安 |
|---|---|---|
| 小 | 数件の指摘。拡散していない | 個別に返信、または様子見 |
| 中 | 引用・共有が続いている | 訂正・補足投稿を検討。複数人で判断 |
| 大 | ニュース・まとめに取り上げられる | 一時休止。公式な説明文を準備。専門家に相談 |

## 対応の選択肢

| 選択肢 | 使うとき |
|---|---|
| 何もしない | 少数の批判で拡大していない |
| 返信で補足 | 誤解がある |
| 訂正投稿 | 事実誤り([訂正の雛形](sensitive-topics-and-accuracy.md)) |
| 削除 | 権利侵害、重大な誤り。削除前に記録し、必要なら経緯を告知 |
| 謝罪 | 配慮不足を認める場合。言い訳を付けない |
| 一時休止 | 心身の負担、拡大している場合 |

## 発信の文例

### 訂正

```
【訂正】◯月◯日の投稿で「A」と書きましたが、正しくは「B」でした。
(出典: ◯◯)ご指摘くださった方、ありがとうございました。本文は修正済みです。
```

### 謝罪

```
◯月◯日の投稿で、◯◯への配慮を欠いた表現がありました。
不快な思いをされた方に、お詫び申し上げます。該当の投稿は削除し、今後は◯◯を確認してから投稿します。
```

- 「誤解を招いたなら」「そんなつもりはなかった」などの**条件付き・言い訳の表現は避ける**(⚪)。
- 何が悪かったか・何を直したか・今後どうするかの3点を書く。

### 一時休止

```
しばらく投稿をお休みします。いただいたご意見は確認しています。再開時にお知らせします。
```

## 避けること

- 売り言葉に買い言葉の返信
- 投稿の無言削除(隠蔽と受け取られる場合がある)
- 複数アカウントでの擁護(なりすまし扱いの危険)
- 個人情報の晒し

## よくある失敗と対処

| 失敗 | 起きること | 対処 |
|---|---|---|
| 深夜にすぐ反論した | 発言が切り取られ拡散 | 一晩置く。返信前に1人に読んでもらう |
| 予約投稿を止め忘れた | 騒ぎの最中に宣伝投稿が出る | 初動で予約を全停止 |
| 謝罪文に言い訳を入れた | 二次炎上 | 3点(何が・何を直した・今後)に絞る |
| 証拠を残さずにブロック・削除 | 後で相談・削除依頼ができない | 先にスクリーンショットと URL |
| 1人で抱え込む | 判断を誤る・心身を壊す | 信頼できる人・窓口に早めに相談 |

## 事後

1. 原因を分析し、チェックリスト/規約に反映。
2. [risk-register](../30-strategy/05-risk-register.md) を更新。
3. 心身の休息を取る。必要なら信頼できる人に相談。
4. 同じ型の投稿の前に確認する項目を [posting-workflow](posting-workflow.md) のチェックに追加する。

## 緊急の連絡先(入口)

- 各サービスの通報フォーム(各 `10-policies.md`。例: [X](../02-x/10-policies.md)、[Instagram](../03-instagram/10-policies.md)、[note](../04-note/10-policies.md))
- 誹謗中傷: 違法情報センター、法務省の人権相談、弁護士(⚪ 窓口は最新を確認)

| 窓口 | できること | 確度 |
|---|---|---|
| 違法・有害情報相談センター(総務省の事業) | 削除依頼の方法などを**助言**する(削除の代行ではない) | 🟡 自治体の案内ページ |
| 法務省の人権相談(インターネット人権相談、みんなの人権110番) | 相談・助言に加え、事案により法務局がプロバイダ等へ**削除要請** | 🟡 同上 |
| 誹謗中傷ホットライン(セーファーインターネット協会) | 一定の基準に当たる書き込みについて、プロバイダに対応を促す連絡 | 🟡 同上 |
| 警察相談専用電話 `#9110` | 脅迫・身の危険があるとき(緊急時は110番) | 🟡 県警の資料 |
| 弁護士・法テラス | 発信者情報の開示請求、損害賠償など法的手段 | ⚪ |

> 窓口の名称・受付時間・電話番号は変わることがあります。利用前に各公式サイトで確認してください。

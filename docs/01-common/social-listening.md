# ソーシャルリスニング

> **このページで分かること**: 自分のアカウント・商品・活動について、SNS や Web で何が言われているかを把握する方法(検索演算子、通知設定、アラート、ツール)と、見つけた声への対応の考え方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [analytics-kpi](analytics-kpi.md)

## 概要

自分の投稿へのコメントは通知で届きますが、**自分をメンション(@)せずに話題にしている投稿**は、探さないと見つかりません。感想、質問、不満、誤解、なりすまし、無断転載などが、気付かないうちに広がっていることがあります。

ソーシャルリスニングは、こうした声を**定期的に探して記録し、改善や早めの対応につなげる**活動です。大きな予算は不要で、検索の工夫と通知設定だけでも始められます。

## 用語

| 用語 | 意味 |
|---|---|
| social listening(ソーシャルリスニング) | SNS や Web 上の声を収集・分析すること |
| mention(メンション、言及) | 投稿の中で名前やアカウントに触れること |
| search operator(検索演算子) | 検索を絞り込むための記号や命令(`site:`、`-` など) |
| alert(アラート) | 指定した言葉が新しく見つかったときの通知 |
| sentiment(感情、ポジ・ネガ) | 声が好意的か否定的か |
| impersonation(なりすまし) | 他人を装ったアカウント |
| 表記ゆれ | 同じ名前の別表記(カタカナ・英語・略称など) |

## 探す言葉を決める(手順)

1. **自分の名前の表記**をすべて書き出す: アカウント名、表示名、ローマ字、略称、よくある誤字。
2. **商品・企画・シリーズ名**を書き出す。
3. **関連する話題の言葉**(業界の言葉、競合ではなく「同じ分野」の言葉)を数個。
4. 除外したい言葉(同じ名前の無関係な話題)を書き出す。
5. 表にまとめ、検索・アラートで使う(下の台帳)。

## Google 検索の演算子(✅ Google 検索ヘルプ)

| 演算子 | 使い方 | 例 |
|---|---|---|
| `"..."` | 完全一致で検索 | `"焼き菓子の店 ○○"` |
| `site:` | 特定のサイト・ドメインに絞る | `site:note.com ○○` |
| `-` | 語句を除外 | `○○ -求人` |
| `before:` / `after:` | 指定日より前/後に更新されたページ | `○○ after:2026/10/01` |
| `filetype:` | ファイル形式を指定 | `○○ filetype:pdf` |

- **演算子と検索語の間にスペースを入れない**(✅)。例: `site:example.com`。
- `OR` は上記のヘルプページには記載がない(⚪ 使えるが公式ページでは未確認)。

## X の検索

- X の API では、`from:`(特定アカウントの投稿)、`-`(除外)、`OR`、`lang:`(言語)、`has:media`(画像・動画付き)、`#`(ハッシュタグ)、`"..."`(フレーズ)などの演算子が使える(✅ X API v2 の検索。API のアクセスレベルで利用できる演算子が異なる)。
- アプリの検索窓でも同様の書き方や「高度な検索」が使える(⚪ アプリでの挙動は公式ページ未確認)。
- 例(アプリでの使い方の例 ⚪): `"○○" -from:自分のID`(自分以外が○○に触れた投稿)。

## サービスごとの通知・検索の設定(⚪ 表記は変わる可能性)

| サービス | できること |
|---|---|
| X | 通知でメンションを確認、検索の保存、キーワードのミュート |
| Instagram | タグ付け・メンションの通知、ハッシュタグの検索、コメントのフィルター |
| YouTube | YouTube Studio のコメント管理、チャンネル名の検索 |
| TikTok | メンション・コメントの通知、検索 |
| Threads | メンションの通知、検索 |
| note | 通知、記事の検索 |

## Google アラート(✅ Google 検索ヘルプ)

指定した言葉の新しい検索結果をメールで受け取れます。

1. Google アラート(https://www.google.com/alerts)を開く。
2. 上部のボックスに言葉を入力する。
3. [オプションを表示]で設定を変える。
4. [アラートを作成]を押す。

| 設定項目(✅) | 選び方の目安(⚪) |
|---|---|
| 頻度 | 最初は「1日1回以下」 |
| ソース | 自動 / ニュース / ブログ / ウェブ など |
| 言語・地域 | 日本語・日本 |
| 件数 | 「上位の結果のみ」から始める |
| 配信先 | 運用用のメールアドレス |

- Google アラートは **SNS の投稿をすべて拾うものではありません**(⚪)。SNS 内の検索と組み合わせます。

## ツールを使う場合

| 種類 | 内容 | 選び方 |
|---|---|---|
| 各サービスの公式機能 | 通知、検索の保存、インサイト | まずこれで十分か確認 |
| 予約投稿ツールの付属機能 | メンションの一覧、受信箱の統合 | 公式 API を使っているか([tools](tools.md)) |
| 専用のモニタリングツール | 複数サービス・Web の横断、感情分析、レポート | 対応サービス、料金、日本語の精度 |

- 有料ツールは月額が高いことが多い(⚪)。**小規模なら検索と通知の組み合わせで十分**な場合が多いです。
- API の利用条件・費用は [20-api](../20-api/README.md)。

## 記録と振り返り

### 台帳の例

| 日付 | サービス | 内容の要約 | 種類 | 対応 | 担当 |
|---|---|---|---|---|---|
| 11/03 | X | 商品の届き方への質問 | 質問 | 返信済み、FAQ に追加 | |
| 11/03 | Web | 記事が無断転載されていた | 権利 | 連絡済み | |

- 種類の例: 感想(好意的)/ 質問 / 不満・要望 / 誤解 / なりすまし / 無断転載 / 危険(脅迫など)。
- **週1回、件数と種類を集計**し、よくある質問は FAQ や固定投稿に反映します([weekly-review](../../templates/weekly-review.md))。

## 見つけた声への対応(⚪)

| 種類 | 対応 |
|---|---|
| 好意的な感想 | 必要なら感謝を伝える。紹介するときは許可を取る |
| 質問 | メンションされていなくても、相手が嫌がらない形で答える。FAQ に追加 |
| 不満・要望 | 事実を確認し、改善できることは改善して知らせる |
| 誤解・誤情報 | 公式の情報(固定投稿など)で正しい情報を示す。個人を責めない |
| なりすまし | 各サービスの通報窓口へ。フォロワーに注意喚起 |
| 無断転載 | 証拠を保存し、相手かサービスに連絡([image-sources-and-copyright](image-sources-and-copyright.md)) |
| 危険・脅迫 | 証拠を保存し、サービスへの通報、必要に応じて警察に相談([crisis-response](crisis-response.md)) |

- **メンションされていない投稿への返信**は、相手を驚かせることがあります。内容と関係性を考えて判断します(⚪)。
- 見るのがつらい言葉に向き合い続けると疲れます。ミュート機能を使い、担当や時間を決めます。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 自分の名前の別表記を検索していなかった | 表記ゆれを台帳に書き出す |
| 否定的な投稿に感情的に反論した | 一晩置き、事実の確認と丁寧な説明に絞る |
| 毎日長時間エゴサーチして疲れた | 週1回・時間を決めてまとめて確認 |
| なりすましに気付くのが遅れた | 自分の名前でアカウント検索を定期的に行う |
| 高額なツールを契約したが使わなかった | 公式機能と無料のアラートから始める |

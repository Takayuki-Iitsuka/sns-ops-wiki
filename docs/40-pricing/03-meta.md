# Meta の料金(Meta One・Meta Verified)

> 日本の公式画面は未取得。Forbes Japan・Impress Watch・ITmedia などの報道に基づく 🟡 です(#48)。アプリ・地域・アカウントによって表示価格が異なります。

## 1. Meta One(2026年(皇紀2686年・令和8年)9月に発表、日本でも提供)

Instagram・Facebook・WhatsApp を横断するサブスクリプション。**Meta AI の利用枠の拡大**が主な付加価値と報道されています。

| プラン | 月額(税込) | 内容 | 確度 |
|---|---|---|---|
| **Instagram Plus** | 319円 | 単体 | 🟡 Impress Watch |
| **Facebook Plus** | 319円 | 単体 | 🟡 |
| **WhatsApp Plus** | 239円 | 単体 | 🟡 |
| **Meta One Core** | 949円 | 個人向けバンドル(AI 枠) | 🟡 |
| **Meta One Premium** | 2,900円 | 個人向け上位 | 🟡 |
| **クリエイター・ビジネス向けバンドル** | 2,000円〜 | 運用者向け | 🟡 Forbes Japan |

- 「月額 299円から」は米国の $2.99 を円に置き換えた数字との指摘。日本は 239円からとする報道。
- **広告は消えない**。加入してもリーチやフォロワーは自動で増えない(解説記事・報道)。
- **Meta Verified とは別枠**(Meta One の影響を受けない)。

## 2. Meta Verified(認証バッジ)

| 項目 | 内容 | 確度 |
|---|---|---|
| 日本の価格(2023年7月開始時) | iOS・Android アプリ **1,990円/月**、Web **1,592円/月** | 🟡 古い報道 |
| 特典 | 認証バッジ、なりすまし対策、サポートへのアクセス、検索・コメント・おすすめでの表示向上 | 🟡 |
| 対象 | 18歳以上、政府発行 ID、個人または**プロフェッショナル(クリエイター)プロフィール**(ビジネスは対象外とされた) | 🟡 |
| 契約 | Instagram と Facebook は別々 | 🟡 |
| 2026年の価格 | 確認できず | — |

## 3. 運用者の見方(⚪)

| 論点 | 見方 |
|---|---|
| 認証バッジ | なりすまし対策が目的なら有用。リーチ向上の効果は**保証されない** |
| Meta One の AI 枠 | Meta AI で画像・文章を作る頻度が高い場合に検討。外部 AI(Gemini など)と比較 |
| コスト | 月 数百〜数千円。収益が出る前は**無料機能を使い切ってから**検討 |
| 税務 | 事業の経費にできるか記録([tax-and-business](../30-strategy/04-tax-and-business.md)) |

# Meta の料金(Meta One・Meta Verified)

> **このページで分かること**: Instagram・Facebook・WhatsApp の有料サブスク(Meta One)と認証バッジ(Meta Verified)の違い、価格の報告値、入るべきかの判断。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [料金プラン(索引と読み方)](README.md)

> 日本の公式画面は未取得。Forbes Japan・Impress Watch・ITmedia などの報道に基づく 🟡 です(#48)。アプリ・地域・アカウントによって表示価格が異なります。

## 概要

Instagram・Facebook・Threads は**無料で投稿・閲覧**できます。有料のものは主に2つです。

1. **Meta One**: Meta AI の利用枠などを増やすサブスク。2026年(皇紀2686年・令和8年)9月に発表と報道。
2. **Meta Verified**: 本人確認を行い、認証バッジやサポートを受けられるサブスク。

どちらも**入らなくても投稿・収益化の基本機能は使えます**。入ってもフォロワーやリーチが自動で増えるわけではありません(報道・解説記事 🟡)。

## 用語

| 用語 | 意味 |
|---|---|
| Meta One(メタ ワン) | Instagram・Facebook・WhatsApp を横断するサブスクの総称(報道) |
| Meta Verified(メタ ベリファイド) | 本人確認と認証バッジのサブスク |
| verified badge(認証バッジ) | 本人であることが確認されたことを示すマーク |
| impersonation(なりすまし) | 他人のふりをするアカウント |
| 税込 | 消費税を含む価格。下の表の円価格は報道で「税込」とされたもの |

## 1. Meta One(2026年(皇紀2686年・令和8年)9月に発表、日本でも提供)

Instagram・Facebook・WhatsApp を横断するサブスクリプション。**Meta AI の利用枠の拡大**が主な付加価値と報道されています。

| プラン | 月額(税込) | 内容 | 確度 |
|---|---|---|---|
| **Instagram Plus** | 319円 | 単体 | 🟡 Impress Watch |
| **Facebook Plus** | 319円 | 単体 | 🟡 |
| **WhatsApp Plus** | 239円 | 単体 | 🟡 |
| **Meta One Core** | 949円 | 個人向けバンドル(AI 枠) | 🟡 |
| **Meta One Premium** | 2,900円 | 個人向け上位 | 🟡 |
| **クリエイター・ビジネス向けバンドル** | 2,000円〜 | 運用者向け | 🟡 Forbes Japan |

- 「月額 299円から」は米国の $2.99 を円に置き換えた数字との指摘。日本は 239円からとする報道。
- **広告は消えない**。加入してもリーチやフォロワーは自動で増えない(解説記事・報道)。
- **Meta Verified とは別枠**(Meta One の影響を受けない)。

## 2. Meta Verified(認証バッジ)

| 項目 | 内容 | 確度 |
|---|---|---|
| 日本の価格(2023年7月開始時) | iOS・Android アプリ **1,990円/月**、Web **1,592円/月** | 🟡 古い報道 |
| 特典 | 認証バッジ、なりすまし対策、サポートへのアクセス、検索・コメント・おすすめでの表示向上 | 🟡 |
| 対象 | 18歳以上、政府発行 ID、個人または**プロフェッショナル(クリエイター)プロフィール**(ビジネスは対象外とされた) | 🟡 |
| 契約 | Instagram と Facebook は別々 | 🟡 |
| 2026年の価格 | 確認できず | — |

## 3. 運用者の見方(⚪)

| 論点 | 見方 |
|---|---|
| 認証バッジ | なりすまし対策が目的なら有用。リーチ向上の効果は**保証されない** |
| Meta One の AI 枠 | Meta AI で画像・文章を作る頻度が高い場合に検討。外部 AI(Gemini など)と比較 |
| コスト | 月 数百〜数千円。収益が出る前は**無料機能を使い切ってから**検討 |
| 税務 | 事業の経費にできるか記録([tax-and-business](../30-strategy/04-tax-and-business.md)) |

## 5. 計算例(🟡 の報道値に基づく試算)

| 例 | 計算 | 年額 |
|---|---|---|
| Instagram Plus だけ(319円/月 🟡) | 319 × 12 | 3,828円 |
| Meta One Core(949円/月 🟡) | 949 × 12 | 11,388円 |
| Meta Verified を Instagram と Facebook の両方(アプリ 1,990円/月 🟡 古い報道) | 1,990 × 2 × 12 | 47,760円 |

→ 年額にすると負担が分かりやすくなります。**別々の契約を重ねていないか**を年1回見直します。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 認証バッジでリーチが伸びると期待する | 効果は保証されない。目的(なりすまし対策・サポート)で判断 |
| Meta One と Meta Verified を同じものだと思う | 別枠の契約(🟡)。それぞれの請求を確認 |
| Instagram と Facebook の両方で契約していることを忘れる | 年1回、アプリストア・Web の契約一覧を確認 |
| 古い価格で判断する | 契約画面で現在の価格・税込/税抜を確認(2026年の Meta Verified の価格は未確認) |

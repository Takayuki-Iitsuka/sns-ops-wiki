# X と Grok の料金・連携関係

> **このページで分かること**: X の有料プラン(X Premium)、X API、Grok、xAI API の4つの契約の違いと料金、つながり(クレジット還元など)、選び方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [料金プラン(索引と読み方)](README.md)
>
> **確認時点**: 2026年(皇紀2686年・令和8年)11月3日。表の中の年は西暦のみで表記します。

X と Grok(xAI)は**関係が複雑**です。まず「何が別の契約で、何がつながっているか」を整理します。

## 概要

X で有料になり得るものは、**利用者として X を使う契約(X Premium)**と、**プログラムから X を操作する契約(X API)**の2系統です。さらに、X の AI である Grok にも、**利用者向けのプラン**と**開発者向けの API(xAI API)**があります。名前が似ていても請求先・管理画面が違うため、「どれにお金を払っているのか」を最初に区別することが大切です。

- 投稿するだけなら**無料**で始められます。
- 料金の確度: **X API は ✅(docs.x.com の公式料金ページ)**、X Premium・Grok・xAI API は 🟡(報道・比較記事)です。
- ドル建ての料金は**円に換算せず原通貨**で書いています。円での支払額は為替・決済手段で変わります。税込か税抜かは、各契約画面で確認してください(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| X Premium(エックス プレミアム) | X の利用者向けの有料プラン。Basic / Premium / Premium+ の段階がある |
| X API | プログラムから投稿・取得などを行う仕組み。従量課金(使った分だけ支払う) |
| credit(クレジット、前払い残高) | 先に購入しておき、API の利用ごとに差し引かれる残高 |
| pay-as-you-go(従量課金) | 月額固定ではなく、使った回数・量に応じて支払う方式 |
| spending limit(支出上限) | 請求サイクル内で使える上限額。使いすぎを防ぐ設定 |
| Grok(グロック) | xAI が提供する AI。X の中でも、単体のアプリ・サイトでも使える |
| xAI API | Grok をプログラムから使うための API |
| token(トークン) | AI が文章を処理する単位。API の料金は 100万トークンあたりで表されることが多い |

## 1. 4つの契約を区別する

| # | 契約・サービス | 何のためか | 支払い先・管理画面 | 料金の確度 |
|---|---|---|---|---|
| ① | **X Premium**(Basic / Premium / Premium+) | X の利用者向け機能(長文、長い動画、認証、収益分配の条件、Grok の枠など) | X(Web)/ アプリストア経由 | 🟡 |
| ② | **X API** | プログラムから X を操作 | **Developer Console**(console.x.com)、クレジット前払い | ✅ |
| ③ | **Grok の利用者向けプラン**(無料 / SuperGrok / Heavy) | チャット・画像・動画の生成 | grok.com・アプリ(X の契約と別立ての面あり) | 🟡 |
| ④ | **xAI API** | Grok をプログラムから使う | **console.x.ai**、クレジット | 🟡 |

→ ①②③④は**別々の請求**になり得る。「X Premium に入れば全部使える」ではない。

## 2. つながり(✅ は docs.x.com の公式記述)

```
X API の支出 ──(累計支出に応じて 10〜20% を還元)──▶ xAI API のクレジット   ✅
   │                               ▲ 条件: xAI の team を X の開発者アカウントにリンク(console.x.com)
   ├─ X MCP(200以上のエンドポイントを AI から呼べる)                    ✅
   ├─ Docs MCP / llms.txt(AI がドキュメントを読む)                       ✅
   └─ 返信モデレーション: X Activity API で受信 → Grok(xAI API)で分類 → Hide Replies で非表示  ✅(2026年10月1日)

X Premium(①) ──(Grok の利用枠・機能が上位プランで拡大)──▶ X 上の Grok       🟡
SuperGrok(③) ──(別契約。X Premium+ との関係は資料により不一致)         🟡
```

### xAI クレジットの還元(✅ 公式の料金ページ)

X API のクレジットを購入すると、**請求サイクル内の累計支出**に応じて xAI API のクレジットが付与される。

| 累計支出(請求サイクル内) | 還元率 |
|---|---|
| $0 〜 $199 | 0% |
| $200 〜 $499 | 10% |
| $500 〜 $999 | 15% |
| $1,000 以上 | 20% |

- 率は**累計全体**に適用され、差分だけが付与される。請求サイクルが変わると累計は $0 に戻る。
- **受け取りには、xAI の team と X の開発者アカウントのリンクが必要**(console.x.com のアカウント設定)。
- 個人運用の規模では、通常 $200 に届かないため**還元は 0%**(月数十ドル規模なら対象外)。

## 3. X Premium(🟡)

| 項目 | 内容 | 確度 |
|---|---|---|
| 構成 | **Basic / Premium / Premium+** の3段階(2026年) | 🟡 個人サイト |
| 米国の価格 | Basic $3、Premium $8、Premium+ $40(月額)とする記事。年払いの記載もあるが不一致 | 🟡 |
| 日本の価格 | Premium+ は **2025年(皇紀2685年・令和7年)2月18日の改定で Web 1か月 6,080円**(従来 2,590円)と報道(公式ヘルプの価格更新ページに対応)。Basic・Premium の 2026年の円価格は**確認できず** | 🟡 |
| 価格の不一致 | Premium を「1,270円(2025年7月に値下げ)」とする報道と、裏付けが見つからない検索結果が併存 | 🟡 #44 |
| 決済手段 | Web とアプリストアで価格が異なる場合がある | ⚪ |

### 運用に効く特典(✅ は API 文書)

| 特典 | 内容 | 確度 |
|---|---|---|
| 動画 | Post 動画 **125分・16GB・1080p**(通常は20分・8GB・720p) | ✅ docs.x.com([02-x-api](../20-api/02-x-api.md)) |
| 収益分配(Original Content Rewards) | **Premium 系の契約が必須**(認証済みフォロワー500人以上、直近90日の認証済みインプレッション50万以上、18歳以上と報道) | 🟡 複数の報道で一致 |
| Grok の利用枠 | Premium+ は上限が高い | 🟡 |
| 長文・編集・分析 | 契約によって差 | ⚪ |

> 旧収益分配は 2026年(皇紀2686年・令和8年)9月7日に終了し、9月8日から新プログラムの申請が始まったと報道(自動移行なし、報酬算定方法は詳細不明)。[X 収益化](../02-x/07-monetization.md)

## 4. X API の料金(✅ 公式。2026年11月3日取得)

詳細は [20-api/02-x-api](../20-api/02-x-api.md)。要点:

| 操作 | 単価 |
|---|---|
| 投稿作成 | **$0.015** |
| **URL を含む投稿** | **$0.200** |
| 他人の Post 読み取り | $0.005/件 |
| **自分のデータの読み取り(Owned Reads)** | **$0.001/件** |
| メディアメタデータ(alt text) | $0.005/件 |
| 無料クレジット | 初回カード保存で $20、初回自動チャージのマッチ最大 $50(3か月で失効) |

## 7. Grok と SNS 運用(ルール・リスク)

| 論点 | 内容 | 確度 |
|---|---|---|
| X 上の Grok への質問 | 利用枠は Premium 系で拡大 | 🟡 |
| 自動返信 | **X API では、元の投稿者があなたを呼び出した場合にのみ返信可**。Grok 以外の bot も同様 | ✅ docs.x.com(2026年2月23日) |
| 生成画像の透かし | Grok 生成の画像・動画に透かしが付くと報道 | 🟡 |
| 日本での規制動向 | 2026年(皇紀2686年・令和8年)1月、内閣府が X に対し、Grok による性的に加工された画像の生成・拡散への安全対策強化を要請と報道。xAI は実在人物の性的画像生成を無効化と発表 | 🟡 報道 |
| 学習への利用 | X の設定に、投稿が Grok の学習に使われる設定がある(オプトアウト可否は要確認) | ⚪ #57 |
| 実在人物の画像 | 生成・加工は規約と法令(肖像権・名誉毀損)に注意 | [ai-rules-by-platform](../01-common/ai-rules-by-platform.md) |

## 8. 運用者の選び方(⚪)

| 目的 | おすすめ |
|---|---|
| 投稿だけ | 無料でも可。動画が長い・収益化したいなら Premium 系 |
| 収益分配を狙う | Premium 系+認証済みフォロワー(条件は #1) |
| 自動化・分析 | X API 従量課金(支出上限を設定)。自分のデータは Owned Reads で安い |
| 文章・画像の補助 | Grok 無料→必要なら SuperGrok。他社(Gemini、ChatGPT、Claude)との比較は [05-ai-and-creative-tools](05-ai-and-creative-tools.md) |
| X API と Grok を併用 | 還元は累計 $200 から。小規模なら期待しない |

## 9. 計算例(⚪ 為替は仮定)

| 例 | 計算 | 結果 |
|---|---|---|
| X API で1日1回、URL 付きで投稿(30日) | 30 × $0.200(✅ 単価) | **$6.00/月** |
| 同じ投稿を URL なしで | 30 × $0.015(✅ 単価) | **$0.45/月** |
| 円の目安(**仮に 1ドル = 150円 とした場合**) | $6.00 × 150 | 約 900円(実際は為替・カード会社の手数料で変わる) |

- 「1ドル = 150円」は**計算方法を示すための仮の値**です。実際の為替レートではありません。
- 見積りの詳細は [月額の見積り例](06-cost-planning.md)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| X Premium に入れば API も Grok の上位機能も使えると思う | 4つの契約は別。目的ごとに必要な契約を確認する |
| X API の自動チャージを有効にしたまま放置 | 支出上限(spending limit)を設定し、明細を月1回確認 |
| URL 付き投稿の単価を見落とす | URL 付きは通常の投稿より高い(✅)。プロフィール・固定投稿に URL を寄せる設計も検討 |
| 円の価格を古い記事で判断する | 契約前に X のアプリ・Web の購入画面で現在の価格と税込/税抜を確認 |
| iPhone のアプリ内で契約して割高になる | Web と価格を比べる(差がある場合がある ⚪) |

# その他サービスの料金

> **このページで分かること**: note・LINE 公式アカウント・創作支援系サービスの料金と手数料の報告値、税込/税抜の読み方、手取りの計算例。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [料金プラン(索引と読み方)](README.md)
>
> **確認時点**: 2026年(皇紀2686年・令和8年)11月3日。表の中の年は西暦のみで表記します。

> note・LINE・創作支援系は公式の料金ページ本文を未取得で、🟡 です(#49, #40, #41)。

## 概要

このページのサービスは、料金の形が2種類あります。

1. **月額料金**(note プレミアム、LINE 公式アカウントのプランなど): 使っても使わなくても毎月かかる。
2. **販売手数料**(有料記事、支援サイト、販売サイト): 売れたときだけ、売上から差し引かれる。

初心者は、まず**月額のかからない無料プラン**で始め、売上や配信先が増えてから有料プランを検討するのが安全です(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| 税抜(税別) | 消費税を含まない価格。支払額は消費税を加えた額になる |
| 税込 | 消費税を含む価格 |
| プラットフォーム利用料 | 販売サービスが売上から差し引く手数料 |
| 決済手数料 | クレジットカードなどの決済にかかる手数料 |
| 従量課金 | 使った量(LINE なら追加のメッセージ通数)に応じて支払う方式 |
| ロイヤリティ | 電子書籍などで、売上のうち著者が受け取る割合 |

## note

| プラン | 料金 | 内容 | 確度 |
|---|---|---|---|
| 無料 | 0円 | 記事投稿、有料記事の販売(手数料あり) | 🟡 |
| **note プレミアム** | **500円/月** | 定期購読マガジン・共同運営マガジン・予約投稿などの機能 | 🟡 |
| **note pro** | **80,000円/月(税抜)** または **880,000円/年(税抜)** | 法人・ブランド向け。ロゴ・ブランドカラー、独自ドメイン、メンバー権限管理、RSS の全文配信。note プレミアムの機能も使える。利用開始月は無料だが、無料期間のみの利用は不可 | 🟡 note ヘルプ記事の検索要約 |
| 販売手数料 | **プラットフォーム利用料 10%(税抜)+決済手数料**とする比較記事 | 🟡 個人ブログ系 | #5 |
| 手数料の内訳(報告値) | 事務手数料(決済手数料): クレジットカード 5%・携帯キャリア決済 15%・PayPay 7%。プラットフォーム利用料: 有料記事など 10%、定期購読マガジン 20%。振込手数料 270円 | 検索要約([04-note/07](../04-note/07-monetization.md)) | 🟡 #5 |

→ 個人運用は**無料 or プレミアム**が現実的。note pro は法人向けの価格帯。

## 無料のサービス

TikTok、Bluesky、Threads(利用料なし。Meta One は任意)、Facebook ページ(基本無料)、Twitch(視聴は無料)。

## SNS ごとの「投稿者が使う有料機能」まとめ(⚪)

| サービス | 有料機能 | 優先度 |
|---|---|---|
| X | Premium(長文・長尺動画・収益分配の前提) | 収益化を狙うなら高 |
| YouTube | なし(投稿は無料)。視聴用の Premium は別 | — |
| Instagram | Meta Verified、Meta One | 低〜中 |
| note | プレミアム(定期購読マガジン・予約投稿) | 中 |

## 計算例(⚪ 消費税率10%で計算した試算。報告値 🟡 に基づく)

| 例 | 計算 | 結果 |
|---|---|---|
| LINE ライト 5,000円(税別 🟡)の支払額 | 5,000 × 1.10 | 5,500円/月(税込の目安) |
| note pro 80,000円/月(税抜 🟡)の支払額 | 80,000 × 1.10 | 88,000円/月(税込の目安) |
| BOOTH で 1,000円の商品が1つ売れた(改定後の報告値 5.6%+45円 🟡) | 1,000 × 0.056 + 45 = 101円 | 手取り 899円(振込手数料は別。旧値 8.5% なら 915円) |
| note の有料記事 500円が1部売れた(報告値: 10% + 決済手数料 🟡) | 500 × 0.10 = 50円 + 決済手数料 | 手取りは 450円より少ない |

- 手数料の計算方法(税込価格に掛けるか、税抜に掛けるか、端数処理)はサービスによって違う場合があります(⚪ 要確認)。
- 実際に販売する前に、各サービスの公式ヘルプで現在の料率を確認してください。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 税別の価格を税込だと思って予算を組む | 「税別」「税抜」とあれば消費税を足して考える |
| LINE の無料通数を超えて配信できず困る | 配信予定の人数 × 回数で月の通数を計算してからプランを選ぶ |
| 手数料が違うサービスを比べずに選ぶ | 同じ価格で売ったときの手取りを計算して比べる |
| 無料期間だけ使うつもりで有料プランに申し込む | 無料期間の条件(note pro は無料期間のみの利用は不可 🟡)を確認 |

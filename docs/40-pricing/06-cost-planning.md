# 月額の見積り例と費用を抑える設計

> **このページで分かること**: X API・生成 AI・サブスクの月額を自分で見積もる方法、運用タイプ別の目安、費用を抑える設計、費用対効果の測り方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [料金プラン(索引と読み方)](README.md)

> 数値は公式の価格表(✅ X API、Google Cloud)と、🟡 の報道値からの**試算**です。為替は換算せず、原通貨で示します。

## 概要

費用の見積りは、次の3つに分けて足し算すると分かりやすくなります。

```
月の費用 = 固定費(サブスクの月額) + 変動費(API・従量課金) + 一時費用(機材・素材)÷ 使う月数
```

- **固定費**: note プレミアム、AI の有料プラン、予約ツールなど。毎月同じ額。
- **変動費**: X API、生成 AI の API、LINE の追加配信など。使った量で変わる。
- **一時費用**: マイク・照明などの機材、素材の買い切り。月あたりに割って考えると比較しやすい(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| 固定費 | 使う量に関係なく毎月かかる費用 |
| 変動費 | 使う量に応じて増減する費用 |
| 単価 | 1回・1枚・1件あたりの料金 |
| spending limit(支出上限) | 請求サイクル内で使える上限額を決める設定 |
| 費用対効果 | かけた費用に対して得られた効果(時間の削減、収益など) |
| 為替レート | 外貨(ドルなど)と円の交換比率。日々変わる |

## 手順: 自分の月額を見積もる

1. 使っている(使う予定の)サービスを**全部書き出す**。
2. それぞれを固定費・変動費・一時費用に分ける。
3. 変動費は「**1か月の回数 × 単価**」で計算する(下の表を参照)。
4. ドル建ては「**ドル額 × 為替レート**」で円の目安を出す。為替レートは**契約時点の実際の値**を使い、手数料分の余裕を持たせる(⚪)。
5. 税抜の料金には消費税を足す(⚪ 消費税率は10%で計算するのが一般的。税込表示ならそのまま)。
6. 合計を[月次レビュー](../../templates/monthly-review.md)の「費用」欄に記録し、毎月比べる。

## 1. X API の見積り(✅ 単価に基づく計算)

| シナリオ | 計算 | 月額 |
|---|---|---|
| 1日1投稿(URL なし)× 30日 | 30 × $0.015 | **$0.45** |
| 1日1投稿(**URL あり**)× 30日 | 30 × $0.200 | **$6.00** |
| 1日3投稿(URL あり)× 30日 | 90 × $0.200 | **$18.00** |
| 1日3投稿(**本文に URL なし**)× 30日 | 90 × $0.015 | **$1.35** |
| 自分の直近1,000投稿を分析(Owned Reads) | 1,000 × $0.001 | **$1.00** |
| 他人の投稿を10,000件読む | 10,000 × $0.005 | **$50.00** |
| 画像30枚の alt text 付与(Media Metadata) | 30 × $0.005 | **$0.15** |

- **URL 付き投稿が高い**ので、投稿の頻度と URL の有無が費用の主因。note への導線は**プロフィール・固定投稿**に寄せ、毎回の投稿に URL を入れない設計も検討(ただし効果とのトレードオフ)。**API での返信は「呼び出された場合のみ」**([02-x-api](../20-api/02-x-api.md))なので、「リンクを返信に置く」運用を API で自動化することはできない。
- **spending limit(請求サイクルの上限)**を必ず設定。自動チャージは必要なときだけ。
- 無料クレジット: 初回 $20+マッチ最大 $50(3か月で失効)。

## 2. 生成 AI(画像・動画)の見積り(✅ Google Cloud の単価)

| シナリオ | 計算 | 月額 |
|---|---|---|
| Imagen 4 Fast で画像 30枚 | 30 × $0.02 | **$0.60** |
| Gemini 3.1 Flash Image(1K)で 30枚 | 30 × $0.067 | **$2.01** |
| Gemini 3 Pro Image(2K)で 30枚 | 30 × $0.134 | **$4.02** |
| Veo 3.1 Lite(1080p・動画のみ)で 10本 | 10 × $0.05 × (「1 count」の単位) | **単位が確定してから算出**(#59) |

→ 画像は**API を使えば1枚数円**。サブスク(Google AI Pro 2,900円など)と**どちらが安いか**は、月の生成枚数で決まる。

## 3. 運用タイプ別の月額(参考。原通貨・🟡 を含む)

| タイプ | 内訳(例) | 目安 |
|---|---|---|
| **ミニマム** | 全サービスの無料機能+公式の予約機能+AI の無料枠 | **0円** |
| **標準(個人)** | note プレミアム 500円 + AI を1つ(約 $20)+ 画像ツール(無料) | **約 3,000円前後+α** |
| **発信強化** | 上記 + X Premium(収益分配狙い)+ Canva Pro + 予約ツール(Buffer $5/ch) | **約 5,000〜10,000円規模** |
| **自動化あり** | 上記 + X API($1〜20)+ 自動化ツール($0〜30) | **+ $1〜50** |
| **法人・ブランド** | note pro 80,000円/月(税抜)ほか | **10万円規模〜** |

※ X Premium の日本円は未確認のため、合計は幅を持たせている。

## 4. 費用を抑える設計(⚪)

1. **無料機能を先に使い切る**(予約投稿、分析、テンプレート)。
2. **AI は1つに集約**。足りない機能は無料枠で補う。
3. **API は読み取りを節約**: 自分のデータ(Owned Reads)に限定、24時間(UTC)内の重複は課金されない(✅ X)。
4. **投稿に URL を入れる頻度**を設計(X API の単価差)。
5. **iPhone のアプリ内課金は割高**になる場合があるため、Web 経由で契約(YouTube Premium 1,280円 vs 1,680円 🟡)。
6. **年払い**は割安な場合があるが、**iPhone アプリ内では不可**の場合あり。
7. **収益と経費を月次で記録**。赤字が続くなら有料を減らす。
8. **失効する無料クレジット**(X API の $20/$50 は3か月)は使い切る計画を。

## 5. 費用対効果の測り方

| 費用 | 測る指標 |
|---|---|
| 有料ツール | 作業時間の削減(分/週)、ミスの減少 |
| 認証・Premium | 収益分配の額、リーチの変化(因果は不明) |
| 広告 | 1クリック・1購入あたりの費用 |
| AI | 制作時間、公開本数 |

[analytics-kpi](../01-common/analytics-kpi.md) の週次レビューに「今週の費用」を1行加える。

## 6. 計算例: 標準(個人)タイプを円で見積もる(⚪ 為替は仮定)

| 項目 | 区分 | 計算 | 円の目安 |
|---|---|---|---|
| note プレミアム(🟡 500円/月) | 固定費 | 500 | 500円 |
| AI アシスタント1つ(🟡 約 $20/月) | 固定費 | $20 × 150(仮定) | 3,000円 |
| X API: 1日1投稿・URL あり(✅ $0.200/件) | 変動費 | 30 × $0.200 = $6 → $6 × 150(仮定) | 900円 |
| 画像生成 API: Imagen 4 Fast 30枚(✅ $0.02/枚) | 変動費 | 30 × $0.02 = $0.60 → × 150(仮定) | 90円 |
| マイク(一時費用、架空 6,000円を12か月で割る) | 一時費用 | 6,000 ÷ 12 | 500円 |
| **合計** | | | **約 4,990円/月** |

- 「1ドル = 150円」は**計算方法を示すための仮の値**です。実際の為替レートで計算し直してください。
- 税込/税抜の扱いは各サービスで確認し、必要なら消費税分を足します。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 固定費だけ見て、API の変動費を見落とす | 変動費は「回数 × 単価」で毎月計算し、支出上限を設定 |
| 為替を固定で考える | 実際の請求額(カード明細)を月次で記録し、見積りとの差を確認 |
| 機材を買った月だけ赤字に見えて慌てる | 一時費用は使う月数で割って考える |
| 費用だけ記録して効果を記録しない | 「今週の費用」と「削減できた時間」を一緒に記録 |
| 小さな月額を多数契約して合計が大きくなる | 年1回、契約一覧を作って年額で見直す |

# AI・制作・予約自動化ツールの料金

> **このページで分かること**: AI アシスタント、画像・動画制作ツール、予約投稿・分析ツール、ノーコード自動化ツールの料金の報告値と、選び方の原則。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [料金プラン(索引と読み方)](README.md)、[ツール](../01-common/tools.md)
>
> **確認時点**: 2026年(皇紀2686年・令和8年)11月3日。表の中の年は西暦のみで表記します。

> 為替・地域・年払い/月払いで変わります。すべて 🟡(比較記事)。ドル建ては換算せず原通貨で記載します(#50〜#52)。

## 概要

SNS 運用のツールは「**時間を買う**」ためのものです。多くのツールに無料プランがあり、最初は無料で十分なことがほとんどです(⚪)。有料にするのは、「作業時間が明らかに減る」「無料の上限(枚数・予約数・チャンネル数)に届いた」ときです。

このページの料金は、公式の料金ページを直接確認できていないため **🟡(比較記事の報告値)** です。海外のツールは**ドル建て**で、円の支払額は為替とカード会社の手数料で変わります。海外ツールの表示価格が**税抜で、購入時に消費税が加算される**場合もあります(⚪ 要確認)。

## 用語

| 用語 | 意味 |
|---|---|
| monthly / annual billing(月払い / 年払い) | 年払いは月あたりが安くなることが多いが、途中解約で返金されない場合がある |
| per seat / per user(1ユーザーあたり) | 使う人数分の料金がかかる方式 |
| channel(チャンネル) | 予約ツールで連携する SNS アカウント1つ分 |
| applet / task / operation | 自動化ツールで料金を数える単位(IFTTT / Zapier / Make) |
| free trial(無料トライアル) | 期間内に解約しないと自動で有料になることが多い |
| brand kit(ブランドキット) | ロゴ・色・フォントを保存してデザインを統一する機能 |

## 1. AI アシスタント(個人向け)

| サービス | 基本プラン | 上位プラン | 確度 |
|---|---|---|---|
| ChatGPT | Plus $20/月 | **Pro $100**(Plus の約5倍の利用量)、**Pro $200**(約20倍)(2026年4月〜) | 🟡 |
| Claude | Pro $20/月 | Max 5× $100、Max 20× $200 | 🟡 |
| Gemini(Google AI) | Pro 2,900円(日本)/ $19.99(米国) | Ultra 5x 14,500円・Ultra 20x 32,000円(日本) | 🟡 [02-google](02-google.md) |
| Grok | SuperGrok 約 $30 | Heavy 約 $300 | 🟡 [01-x-and-grok](01-x-and-grok.md) |
| Meta AI | Meta One Core 949円 など | — | 🟡 [03-meta](03-meta.md) |

- 基本プランは**どれも月 約 $20 前後**で、違いは得意分野(文章、長文、画像、Google 連携、X 連携)。
- **1つに絞らず**、無料枠を組み合わせ、有料は**1つだけ**にするのが費用面で安全(⚪)。

## 4. 自動化(ノーコード)ツール

| ツール | 無料 | 有料の例 | 数え方 | 確度 |
|---|---|---|---|---|
| IFTTT | **アプレット2つ**まで(1トリガー1アクション、約60分ごと) | Pro $3.49〜3.99/月(20アプレット)。**X(Twitter)アプレットは Pro 以上**とする比較表 | アプレット | 🟡 |
| Zapier | 無料枠は記事により不一致(100タスク / 2ステップ制限) | Starter $29.99/月(750タスク)、Professional 約 $73.50/月(2,000タスク) | トリガーを除く各ステップが1タスク | 🟡 |
| Make | 月 1,000 クレジット | Zapier より安いとする意見 | モジュール実行ごとに1オペレーション | 🟡 |

- **X API が従量課金になった**ため、X 連携を含むツールは、**ツール側の料金+X API 料金**(ツールが自前の API 枠を持つか確認)の両方を見る。
- 連携の設計は [20-api/11-tool-integrations](../20-api/11-tool-integrations.md)。

## 5. 選び方の原則(⚪)

1. **公式機能で足りるなら有料ツールは不要**(Meta Business Suite、YouTube Studio、各サービスの予約)。
2. 有料にするのは「**時間を買う**」場合のみ。月の作業時間が実際に減るかを2週間で測る。
3. **無料トライアルは解約日をカレンダーに**登録。
4. 複数サービスに同じ機能を重複して契約しない(Gemini Pro と ChatGPT Plus と Claude Pro と SuperGrok を全部契約しない)。
5. 経費は記録([tax-and-business](../30-strategy/04-tax-and-business.md))。

## 6. 計算例(🟡 の報告値に基づく試算。為替は仮定)

| 例 | 計算 | 結果 |
|---|---|---|
| AI アシスタントを1つだけ(約 $20/月) | $20 × 12 | $240/年 |
| 同じ機能を4つ契約した場合 | $20 × 4 × 12 | $960/年 |
| Buffer を3チャンネル($5/ch 🟡) | 3 × $5 | $15/月 |
| 円の目安(**仮に 1ドル = 150円**) | $15 × 150 | 約 2,250円/月 |

- 「1ドル = 150円」は計算方法を示すための仮の値です。
- 年額で並べると、重複契約の無駄が見えやすくなります。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 無料トライアルの解約を忘れる | 申し込んだ日に、解約期限の前日をカレンダーに登録 |
| 同じ機能の AI を複数契約する | 有料は1つに絞り、ほかは無料枠を使う |
| 予約ツールが対象外のサービスに対応していると思う | 対応サービス一覧を公式で確認(Later は X・Bluesky 対象外とする記載 🟡) |
| X 連携の自動化でツール代だけを見る | X API の料金が別にかかるか確認([X API](../20-api/02-x-api.md)) |
| 年払いにしてすぐ使わなくなる | 2週間〜1か月は月払いで試してから年払いにする |

# 配慮事項・誤情報対策

古事記・日本書紀は、神道、皇室、国家史と深く関わる題材です。**学術的な事実と信仰・伝承を区別して書く**ことが、信頼の土台になります。

## 書き分けの基本

| 区分 | 書き方 |
|---|---|
| テキストに書かれていること | 「古事記は〜と伝える」「日本書紀の一書では〜」 |
| 研究者の解釈 | 「〜という説がある(誰の説か)」 |
| 信仰・伝承 | 「〜と信じられてきた」「神社では〜と伝える」 |
| 史実かどうか | 断定を避け、根拠を示す。神話の物語を史実と混同しない |
| 自分の意見 | 「私は〜と考えます」と明示 |

## 避けること

1. **政治・宗教の主張の押し付け**、特定の団体への肩入れ・攻撃。
2. **皇室・天皇に関する不確かな話の拡散**、歴史認識をめぐる煽り。
3. **俗説のまとめ売り**(ネット上の根拠不明の説)。出典不明の情報は使わない。
4. **神仏を軽んじる表現**、ネタ化しすぎる画像・語り口。
5. **特定の民族・地域・集団への差別につながる表現**(神話中の「蛮族」的な描写など、引用時は文脈を添える)。

## 神の描写(画像・生成 AI)

- 神や皇室の人物を**写実的に描く**場合、信仰への配慮が必要。可能なら象徴的な表現(シルエット、記号、風景)を使う。
- 生成 AI の画像は、その旨を明記する([ai-usage-policy](../01-common/ai-usage-policy.md))。

## 神社・参拝に関する情報

- 参拝作法・授与品・撮影可否は**神社ごとに異なる**。公式サイトを確認し、「神社により異なる」と書く。
- 神社の紹介で**広告・アフィリエイト**を使う場合は広告表記([legal-compliance](../01-common/legal-compliance.md))。
- 神職・氏子への取材・掲載は**事前の許可**を取る。

## 誤情報の対策

1. 投稿前に**典拠(巻・段)を2点以上**で確認(原文＋解説書)。
2. 数字(登場する神の数、年代)は**調べた元を台帳に記録**。
3. 訂正は**速やかに、元の投稿へ返信**([post-templates](06-post-templates.md))。
4. 専門家に確認できるときは**監修・確認の依頼**を検討(クレジットの扱いは相手と合意)。

## 批判・指摘への対応

- 事実の指摘は感謝し、典拠を確認して訂正する。
- 解釈の違いは、「諸説あります」で終わらせず、**典拠を示して議論**する。
- 攻撃的な議論には深入りしない。[crisis-response](../01-common/crisis-response.md)

# コンテンツの柱

投稿を「柱」に分類して企画を偏らせない。**週に2〜3本の柱を回す**のが目安。

## 柱の一覧

| # | 柱 | 内容 | 向く形式 | 主な目的 |
|---|---|---|---|---|
| 1 | 物語のあらすじ | 1話完結で場面を解説(例: 天の石屋戸) | X スレッド、IG カルーセル | 認知・保存 |
| 2 | 神名・用語辞典 | 神一柱・用語一語を1枚に | IG 画像、X 画像 | 認知・検索 |
| 3 | 古事記 vs 日本書紀 | 同じ場面の違いを比較 | IG カルーセル、note | 差別化・信頼 |
| 4 | 原文を読む | 原文・訓読・語釈・ルビ | IG、note | 信頼・深み |
| 5 | 系譜・相関図 | 神々・天皇の系図を図解 | IG 画像、note | 保存・共有 |
| 6 | 地名・神社・ゆかりの地 | 記紀の舞台と現在の神社 | IG、X | 検索・旅行需要 |
| 7 | 暦と行事 | 新嘗祭、大祓などと記紀の関係 | X、IG | 時事性 |
| 8 | ことばと現代 | 慣用句・地名・文化への影響 | X | 拡散 |
| 9 | 学びの記録 | 読書メモ、制作の裏側、質問への回答 | X、note | 親近感・継続 |
| 10 | 告知・収益導線 | note 記事、電子書籍、講座 | X、IG ストーリーズ | 収益 |

## 柱の設計ルール

1. 各投稿に**柱の番号**を付けて記録し、直近10本の偏りを見る。
2. **1投稿1メッセージ**。複数の神が出ても、焦点は1柱(はしら)の神に。
3. 柱 3・4 は**信頼の核**。全体の2割以上を確保する。
4. 柱 10 は**全体の1〜2割**に抑える(売り込みが続くと離脱する ⚪)。

## 企画の作り方

```
題材 → 典拠(巻・段) → 古事記と書紀の差異 → 一言でいうと → 画像案 → 形式
```

1. 典拠の確認: [01-source-texts](01-source-texts.md)
2. 表記: [02-terminology](02-terminology.md)
3. 画像: [07-visual-guidelines](07-visual-guidelines.md)
4. 配慮: [09-sensitivity](09-sensitivity.md)

## 企画ストック

- 「身近な疑問から入る」案: なぜ神社に鳥居があるのか(天の石屋戸との関係)、因幡の白兎はなぜ皮を剥がれたのか、なぜ「出雲」は神在月なのか。
- 「数字・比較から入る」案: 古事記と書紀の登場神数の違い(⚪ 数は調べてから)、神生みで生まれた神の一覧。
- 「地名から入る」案: 日向、出雲、大和、熊野の記紀上の位置づけ。
- 「季節から入る」案: [05-content-calendar](05-content-calendar.md)

企画の候補は [10-series-plans](10-series-plans.md) の連載案にも積む。

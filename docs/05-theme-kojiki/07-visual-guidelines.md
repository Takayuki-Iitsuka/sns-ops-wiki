# 画像デザインの指針

サービス別の仕様は [image-specs-comparison](../01-common/image-specs-comparison.md)、制作工程は [image-production-workflow](../01-common/image-production-workflow.md)。ここでは**テーマ固有**の設計を定める。

## ブランドの方向性(案)

| 要素 | 案 | 理由 |
|---|---|---|
| 配色 | 朱(鳥居)、墨(文字)、白(紙)、金(差し色) | 神道・和の連想。コントラストが取りやすい |
| 書体 | 見出しは明朝体(または筆文字)、本文はゴシック | 読みやすさと格式の両立 |
| 文字組 | 縦書きと横書きを役割で分ける | 原文は縦書き、解説は横書き |
| 余白 | 広め | 画面の縮小表示に耐える |
| 装飾 | 控えめ(和柄は薄く) | 文字の可読性を優先 |

> フォントは**ライセンスを確認**(商用利用・埋め込み・再配布)。配布元の規約を台帳に記録。

## 画像の型

| 型 | 構成 | 用途 |
|---|---|---|
| 神名カード | 神名(大)＋読み＋一言＋典拠 | 柱2 |
| 場面カード | 場面名＋一枚絵＋要約 | 柱1 |
| 比較カード | 左: 古事記 / 右: 日本書紀 | 柱3 |
| 原文カード | 白文＋訓読(縦書き)＋語釈 | 柱4 |
| 系図カード | 家系図(線は太く、神名は大きく) | 柱5 |
| 地図カード | 簡略地図＋地名の記紀上の位置 | 柱6 |

## ルビ・縦書き

- ルビ(振り仮名)は**初出で必ず**。小さすぎないこと(スマホで読める最小サイズを実機確認)。
- 縦書きは、**数字・英字の向き**に注意。漢数字で統一(「第七段」)。
- 組版を自動化する場合は LuaLaTeX と jlreq での PDF 化、画像変換が選択肢(⚪)。

## 一枚絵(挿絵)の方針

1. **自作イラスト**、**パブリックドメインの古い図版**、**ライセンスが明確な素材**のいずれかを使う。
2. 生成 AI を使う場合は [ai-usage-policy](../01-common/ai-usage-policy.md) に従い、**AI 生成である旨を明記**。神の姿の描写は [09-sensitivity](09-sensitivity.md) に配慮。
3. 神社の写真は撮影・掲載の可否を確認([image-sources-and-copyright](../01-common/image-sources-and-copyright.md))。

## アクセシビリティ

- 文字と背景のコントラスト比を確保(目安 4.5:1 以上 ⚪ WCAG の基準)。
- 画像の文字を**キャプションと代替テキストにも書く**([alt-text](../01-common/alt-text.md))。
- 色だけで意味を区別しない(古事記=朱、書紀=藍の場合も記号を併用)。

## 制作チェック

[image-checklist](../../templates/image-checklist.md) に加え、次を確認。

- [ ] 神名の漢字・読みが典拠と一致
- [ ] 年の表記が「西暦(皇紀・和暦)」
- [ ] 典拠(巻・段)を画像内または本文に記載
- [ ] 画像の権利(挿絵・写真・フォント)の台帳を更新

# 年中行事と投稿カレンダー

> 日付は一般に知られた行事の日取りです(⚪)。**神社ごとに日取りが異なる神事**があるため、特定の神社に言及する際は当該神社の公式情報で確認。

## 月別の題材案

| 月 | 行事・節目 | 記紀との接点(題材案) |
|---|---|---|
| 1月 | 元日、初詣 | 天照大御神、歳神、国の始まり |
| 2月 | 節分、建国記念の日(2月11日) | 神武天皇の即位、橿原。紀年の読み方 |
| 3月 | 雛祭、春分 | 国生み、国土の誕生、春の神 |
| 4月 | 春の例大祭の季節 | 木花之佐久夜毘売(桜) |
| 5月 | 端午、新緑 | 倭建命、武勇の物語 |
| 6月 | 夏越の大祓(6月30日) | 禊、祓、黄泉からの帰還と伊邪那岐命 |
| 7月 | 七夕、祇園 | 天安河、神話と星 |
| 8月 | お盆、夏の暑さ | 黄泉国、死と再生 |
| 9月 | 秋分、月見 | 月読命 |
| 10月 | 神無月、神嘗祭(10月17日) | 出雲(神在月)、国譲り、大国主神 |
| 11月 | 新嘗祭(11月23日)、七五三 | 稲作の起源、天孫降臨と稲穂、天皇の祭祀 |
| 12月 | 冬至、年越の大祓(12月31日) | 天の石屋戸(光の復活) |

## 年間プランの作り方

1. 12か月の**主題を1つずつ**決める(上表から)。
2. 主題に沿って、月に**ミニ連載(3〜5回)**を組み、最終回を note にまとめる。
3. 行事の**2週間前から予告**、当日に本編、翌日に関連話題。

## 週のリズム(例 ⚪)

| 曜日 | X | Instagram | note |
|---|---|---|---|
| 月 | 今週の予告・神名1柱 | — | — |
| 火 | 用語解説 | 神名辞典(1枚) | — |
| 水 | スレッド(あらすじ) | カルーセル | — |
| 木 | 引用・原文 | リール(任意) | — |
| 金 | 質問・投票 | ストーリーズ | — |
| 土 | 地名・神社 | 写真投稿 | 週1記事(深掘り) |
| 日 | 振り返り・週次レビュー | — | — |

継続できる頻度から始め、2〜4週間で見直す。

## 2026年(皇紀2686年・令和8年)の起点

- 年末に向け、**11月23日の新嘗祭**、**12月の天の石屋戸**、**12月31日の年越の大祓**、**元日**の流れで、今期の最終月の企画を前倒しで準備する。
- 次年(2027年・皇紀2687年・令和9年)の年間計画は、12月中に作成する。

# 原典・底本・参考文献・著作権

> 書誌情報・著作権の状態は**一次資料(図書館・出版社・著作権者)で確認**してから引用すること。ここは出発点です。

## 二書の基本情報

| 項目 | 古事記 | 日本書紀 |
|---|---|---|
| 成立 | 和銅5年(712年・皇紀1372年)に太安万侶が撰録して献上と序文に記される | 養老4年(720年・皇紀1380年)に舎人親王らが撰進 |
| 構成 | 上・中・下の三巻 | 全三十巻(ほかに系図一巻があったが現存しない) |
| 文体 | 変体漢文(和化漢文)。音を借りた万葉仮名の表記を含む | 純漢文に近い編年体 |
| 特徴 | 物語的。一つの筋で語る。稗田阿礼が誦習した伝承を撰録 | 国家の正史。「一書(あるふみ)に曰く」で異伝を併記 |
| 範囲 | 天地初発から推古天皇まで | 神代から持統天皇まで |

(以上 ⚪。成立年・巻数・範囲は広く知られた通説。引用前に校訂本の解説で確認。)

## 原文(白文・訓読)の入手先 ⚪(要確認)

| 資料 | 場所 | メモ |
|---|---|---|
| 国立国会図書館デジタルコレクション | https://dl.ndl.go.jp/ | 古い刊本・影印の閲覧。公開範囲は資料ごとに異なる |

| 青空文庫 | https://www.aozora.gr.jp/ | 著作権が消滅した作品。古事記・日本書紀の収録状況と底本は個別に確認 |
| 各大学・研究機関の公開データベース | — | 神道・国文学の電子テキスト。利用条件を確認 |

## 底本を決める

1. 引用・訓読の元にする**校訂本を1つ決める**(例: 岩波文庫、新編日本古典文学全集など。版・編者・刊行年を記録)。
2. 本文の異同(写本間の違い)がある箇所は、**どの本文に拠ったかを書く**。
3. 記録は [source-ledger](#出典台帳の書き方) に残す。

## 著作権の整理

| 対象 | 著作権 | 運用 |
|---|---|---|
| 古事記・日本書紀の**原文** | 成立が古く保護期間は満了(パブリックドメイン) ⚪ | 自由に引用可 |
| 校訂本の**編集・注釈・解説** | 著者・編者・出版社の著作物 | 引用の要件を守る。丸写し禁止 |
| **現代語訳** | 訳者の著作物。保護期間は原則として著作者の死後70年(2018年(皇紀2678年・平成30年)12月30日以降の改正後) ⚪ 要確認 | **自分で訳す**のが最も安全。既存訳の転載は避ける |
| 古い訳(戦前〜戦後) | 訳者の没年次第。満了しているか個別に確認 | 確認できなければ使わない |
| 図版・写真 | 撮影者・所蔵者の権利 | [image-sources-and-copyright](../01-common/image-sources-and-copyright.md) |

## 引用のルール(⚪)

- 引用は**必要最小限**、自分の文章が主で引用が従になるようにする。
- 出典を**巻・段・頁**まで書く。例: 「古事記 上巻 天の石屋戸」「日本書紀 巻第一 神代上 第七段 一書第○」
- 二次文献(解説書)の説は**誰の説か**を明記し、通説と異説を区別する。

## 出典台帳の書き方

投稿の下調べごとに、次を残す(非公開の作業メモで可。公開する場合は書誌情報のみ)。

```
投稿ID: 2026-11-xx-ig-01
題材: 天の石屋戸
典拠: 古事記 上巻 / 日本書紀 巻第一 第七段 本文・一書
底本: (書名・編者・出版社・刊行年・版)
訳: 自作 / 引用(頁)
参考: (解説書の書誌)
確認日: 2026-11-xx
```

## 参考文献の候補(刊行年・版は要確認)

- 古事記: 岩波文庫、新編日本古典文学全集、講談社学術文庫、角川ソフィア文庫など、複数社から校訂本・現代語訳が刊行されている(⚪)。
- 日本書紀: 岩波文庫(全5冊と記憶。**要確認**)、新編日本古典文学全集、講談社学術文庫など。
- 概説: 研究者による入門書・事典。**監修者の肩書と刊行年**を確認して採用する。

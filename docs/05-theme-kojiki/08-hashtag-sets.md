# ハッシュタグ候補のセット

> 各タグの**投稿量・質・最近の使われ方**は、導入前に実際に検索して確認する。人気のタグが有効とは限らない。上限・推奨数は各サービスの `04-text-hashtags.md`(多くが要確認)。

## 役割別の候補

| 役割 | 候補 | メモ |
|---|---|---|
| 本命(題材) | `#古事記` `#日本書紀` `#記紀神話` | 検索の中心 |
| 広い話題 | `#日本神話` `#神話` `#神道` | 母数が大きい |
| 神名・場面 | `#天照大御神` `#須佐之男命` `#大国主神` `#天の岩戸` | 神名は表記の揺れに注意 |
| ゆかりの地 | `#出雲` `#高千穂` `#伊勢神宮` `#神社巡り` | 地名は具体的に |
| 学び系 | `#歴史好きと繋がりたい` `#読書記録` `#古典` | 「繋がりたい」系はスパム化に注意 |
| 季節・行事 | `#新嘗祭` `#大祓` `#神無月` | カレンダーと連動 |
| 自社タグ | (例)`#記紀まろ解説`(要決定) | 表記を固定 |

## セットの作り方(1投稿 2〜5個を目安 ⚪)

```
本命1 + 広い話題1 + 具体(神名/場面/地名)1〜2 + 自社タグ1
```

例(天の石屋戸): `#古事記 #日本神話 #天の岩戸 #(自社タグ)`

## 運用

1. 月1回、**タグ別の反応**(インプレッション、保存)を比較し、入れ替える。
2. 表記揺れ(例: 岩戸/石屋戸、須佐之男/素戔嗚)で**検索される側**を見て選ぶ。典拠表記と異なる場合は、本文は典拠通り、タグは検索されやすい側にする。
3. 無関係な人気タグ(流行語、他ジャンル)は付けない。
4. 宗教的な語を商品告知に使うときは [09-sensitivity](09-sensitivity.md) を確認。

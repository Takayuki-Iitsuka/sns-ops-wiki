# 年表と年の換算

## 年の表記ルール

年は「**西暦(皇紀◯年・和暦)**」の形で併記する。

- 例: 2026年(皇紀2686年・令和8年)
- 例: 712年(皇紀1372年・和銅5年)

## 換算

| 換算 | 式 |
|---|---|
| 皇紀 | 西暦 + 660 |
| 令和 | 西暦 − 2018(2019年 = 令和元年) |
| 平成 | 西暦 − 1988(1989年 = 平成元年。平成は2019年4月30日まで) |

注意: 改元の年は、改元日の前後で和暦が分かれる(例: 2019年は平成31年と令和元年)。

| 事項 | 西暦 | 皇紀 | 和暦等 | 備考 |

| 神武天皇の即位(日本書紀の紀年による) | 紀元前660年 | 皇紀元年 | — | 書紀の紀年。史実の年代とは別に扱う |
| 古事記の撰録・献上 | 712年 | 皇紀1372年 | 和銅5年 | 太安万侶 |
| 日本書紀の撰進 | 720年 | 皇紀1380年 | 養老4年 | 舎人親王 |

## 使い方の指針

1. **紀年は書紀の記述による旨を明記**する。神武天皇即位の年代を史実として断定しない。
2. 年中行事は新暦と旧暦の差に注意(神事の日取りは神社ごとに異なる)。
3. 「◯◯周年」は起算年を確認(満年か数え年か)。2026年(皇紀2686年・令和8年)時点で古事記の成立から1314年、日本書紀から1306年。
4. 投稿の画像に年を入れる場合も、上記の併記形式に統一する。

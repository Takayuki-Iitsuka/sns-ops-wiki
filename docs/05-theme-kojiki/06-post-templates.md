# 投稿の雛形と例文

> 例文の事実部分は、投稿前に必ず典拠(巻・段)で確認する。例文は書式の見本であり、内容の正確性を保証しない。

## X: 短文(あらすじ1場面)

```
【古事記】天の石屋戸(あまのいわやと)

弟の乱暴に怒った天照大御神は、石屋(いわや)に籠ってしまう。
世界は暗闇に。

神々はどうやって、女神を外へ呼び戻したのか。

(典拠: 古事記 上巻)
#古事記 #日本神話
```

型: 【書名】場面名(ルビ) → 状況2文 → 問い → 典拠 → タグ1〜2。

## X: スレッド(全6ポスト)

1. 結論と問い(「なぜ…か」)
2. 前提(登場する神・場所を簡潔に)
3. 展開(古事記の筋)
4. 日本書紀の違い(本文・一書)
5. 解釈の分かれる点(通説と異説を区別)
6. 要約＋次回予告＋ note への導線

## Instagram: カルーセル(10枚)

| 枚 | 内容 |
|---|---|
| 1 | タイトル(場面名＋一言) |
| 2 | 登場する神(顔ぶれ) |
| 3〜6 | 物語を4コマで |
| 7 | 日本書紀では? |
| 8 | 原文(白文＋訓読) |
| 9 | まとめ |
| 10 | 保存・フォロー・次回予告 |

キャプション: 1行目に問い → 要点3行 → CTA → ハッシュタグ。

## note: 記事の構成(約3,000〜5,000字 ⚪)

```
タイトル: 【古事記入門】天の石屋戸 ― 光はなぜ戻ったのか
見出し画像: 1280×670
導入(300字): 誰向け/何が分かる
1. あらすじ
2. 登場する神々
3. 日本書紀の伝え方(本文と一書)
4. 原文を読む(白文・訓読・語釈)
5. 解釈と研究史(通説/異説)
6. ゆかりの地(高千穂など、神社は公式情報を確認)
7. まとめ・参考文献
有料の場合: 3以降を有料ラインに
```

## 返信テンプレ(質問への回答)

```
〇〇さん、ご質問ありがとうございます。
ご指摘の点は、古事記では「…」、日本書紀の本文では「…」と伝えます(典拠: 巻・段)。
諸説ありますので、詳しくは参考文献(書名)をご覧ください。
```

## 誤りを訂正するテンプレ

```
訂正とお詫び:
先の投稿で「…」と書きましたが、正しくは「…」です(典拠: …)。
ご指摘ありがとうございました。
```

訂正は**元の投稿へ返信**し、固定ポスト化は不要。過ちは速やかに認める。

## 禁止表現(自己規制 ⚪)

- 「〜に決まっている」「真実は〜だ」など、解釈の断定。
- 特定の神社・宗教団体への優劣表現。
- 根拠のない「パワースポット」「運気」の保証。

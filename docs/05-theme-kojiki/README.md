# テーマ運用ガイド: 古事記・日本書紀

個人が「古事記」「日本書紀」を題材に SNS で発信し、**認知拡大と収益化**を目指すための、テーマ固有の運用ガイドです。サービス共通の仕様は `01-common`、各サービスは `02`〜`04`、全体戦略は [06-strategy](../06-strategy/README.md) を参照。

## このテーマの強みと課題

| 観点 | 強み | 課題 |
|---|---|---|
| 題材 | 原典がパブリックドメイン。物語性が強く、画像化しやすい | 神名が難読で入口が高い |
| 需要 | 神社巡り、御朱印、歴史、ファンタジー、ゲーム・漫画の元ネタなど多方面から検索される(⚪) | 競合アカウントも多い(⚪ 要調査) |
| 信頼 | 一次資料に当たることで差別化できる | 誤情報・俗説の混入に注意が必要 |
| 収益化 | 記事・電子書籍・講座・書籍紹介など複数の導線が可能 | 宗教的配慮、現代語訳の著作権 |

## 方針(要約)

1. **一次資料主義**: 原文(古事記・日本書紀)に当たり、どの箇所か(巻・段)を明示する。
2. **古事記と日本書紀の違いを軸にする**: 同じ神話でも伝承が異なる点が、解説の独自価値になる。
3. **やさしい入口 → 深い解説**: X・Instagram で入口、note で深掘り。
4. **歴史用語は漢字表記**、年は西暦に**皇紀・和暦を併記**。
5. **権利と配慮**: 現代語訳は自作、画像は権利クリア、宗教的表現に配慮。

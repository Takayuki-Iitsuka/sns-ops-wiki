# 神名・用語の表記ルール

## 基本ルール

1. **歴史用語は漢字表記を優先**する。初出で読みを括弧に添える。例: 伊邪那岐命(いざなきのみこと)。
2. 古事記と日本書紀で表記が異なる神は、**どちらの書に拠るかを明示**する。
3. 一つの投稿・連載の中では**表記を統一**する(古事記表記か書紀表記か)。
4. 神名の読みは**諸説・複数の訓み**がある場合があるため、底本の訓に従い、底本名を記録する。
5. 「〜の神」「〜命」「〜尊」の敬称を、書により使い分ける(古事記は「命」「神」、書紀は「尊」「命」が目立つ ⚪)。

## 表記の迷いやすい点

| 論点 | 方針 |
|---|---|
| 「古事記」の読み | 「こじき」。「ふることふみ」とも訓まれた。初出は括弧で補足 |
| 「日本書紀」の読み | 「にほんしょき」。「やまとぶみ」と訓む伝統もある |
| 「記紀」 | 古事記と日本書紀の総称。「記紀神話」 |
| 「天皇」表記 | 古事記は個々の天皇を「天皇」と記す箇所があるが、時代により称号の扱いが論じられる。史実と伝承を区別して書く |
| 「神」と「かみ」 | 本文は漢字、読みを添える場合のみ平仮名 |
| 数え方 | 神は「柱(はしら)」で数える |

# Facebook(ページ・グループ・リール)

実名制のコミュニティ型サービスで、**ページ運営・グループ・リール・イベント**が中心です。広告配信と Meta の収益化プログラムの基盤でもあります。

## 特徴

| 項目 | 内容 |
|---|---|
| 形式 | 投稿、写真、動画、リール、ストーリーズ、ライブ、イベント、グループ |
| 強み | 年齢層が広い、コミュニティ(グループ)、広告・Meta Business Suite、イベント集客 |
| 弱み | 若年層の利用が少ない傾向(⚪)、オーガニック到達の低下 |
| 向く用途 | 地域・店舗・イベント、成熟した読者向け、広告運用 |

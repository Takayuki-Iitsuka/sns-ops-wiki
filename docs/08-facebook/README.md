# Facebook(ページ・グループ・リール)

実名制のコミュニティ型サービスで、**ページ運営・グループ・リール・イベント**が中心です。広告配信と Meta の収益化プログラムの基盤でもあります。

> **このページで分かること**: Facebook の特徴、初心者の読む順番、各ページの内容。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[サービスの選び方](../01-common/choosing-platforms.md)

## 概要

Facebook で発信するには、実名の個人アカウントを作ったうえで、**ページ**を作るか、プロフィールを**プロフェッショナルモード**にします ✅([Meta for Creators](https://creators.facebook.com/tools/facebook-pages-and-profiles))。店舗・団体・イベントの告知、参加者同士が話す**グループ**、Instagram と連携した**リール**の配信に向いています。

## 特徴

| 項目 | 内容 |
|---|---|
| 形式 | 投稿、写真、動画、リール、ストーリーズ、ライブ、イベント、グループ |
| 強み | 年齢層が広い、コミュニティ(グループ)、広告・Meta Business Suite、イベント集客 |
| 弱み | 若年層の利用が少ない傾向(⚪)、オーガニック到達の低下 |
| 向く用途 | 地域・店舗・イベント、成熟した読者向け、広告運用 |

## 用語

| 用語 | 意味 |
|---|---|
| ページ | 店舗・団体・発信者のための公開ページ |
| プロフェッショナルモード | 個人プロフィールで発信者向け機能を使う設定 |
| グループ | 共通の関心を持つ人が交流する場 |
| Meta Business Suite | Facebook・Instagram をまとめて管理するツール |
| プロフェッショナルダッシュボード | 成果・収益化の資格・コメントを管理する画面 |

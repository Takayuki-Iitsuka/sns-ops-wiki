# Facebook の収益化

> **このページで分かること**: Facebook で収益を得る主な方法(コンテンツ収益化、Stars、サブスクリプション、ブランドコンテンツ、広告・外部誘導)、公式に確認できた条件、資格の確認と始め方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [01-setup-and-posting](01-setup-and-posting.md)、[monetization-comparison](../01-common/monetization-comparison.md)

> 条件は資料間で不一致が大きく、**公式(Meta Business Suite の「収益化」)での確認が必須**です (#35)。2026年(皇紀2686年・令和8年)11月3日に Meta for Creators の公式ページを取得し、一部を ✅ に更新しました。

## 概要

Facebook の収益化機能は、**ページ**または**プロフェッショナルモードのプロフィール**で使えます ✅([01-setup-and-posting](01-setup-and-posting.md))。どの機能も、**パートナー収益化ポリシー**と**コンテンツ収益化ポリシー**を守ることが前提です ✅。

収益の出どころ(⚪ 整理の仕方):

| 出どころ | 例 |
|---|---|
| Meta から(成果報酬) | コンテンツ収益化(リール・写真・テキスト・ストーリーズの成果に応じた支払い) |
| ファンから | Stars(投げ銭)、サブスクリプション(月額) |
| 企業から | ブランドコンテンツ(タイアップ投稿)、パートナーシップ広告 |
| 自分の事業 | 広告で集客、外部サービス(EC・note・YouTube)への誘導 |

## 用語

| 用語 | 意味 |
|---|---|
| Content Monetization(コンテンツ収益化) | 公開コンテンツの成果に応じて Meta が支払うプログラム |
| qualified views(対象となる閲覧) | 収益の計算に含まれる閲覧。繰り返し再生や短すぎる閲覧は除外 |
| Stars(スター) | ファンが購入して贈る仮想アイテム |
| Subscriptions(サブスクリプション) | ファンが月額で支援する仕組み |
| in-stream ads(インストリーム広告) | 動画の前・途中・後に入る広告 |
| Partner Monetization Policies(パートナー収益化ポリシー) | 収益化する人が守るルール |
| payout account(受取口座) | 収益を受け取る口座の設定 |

## 手順 / 仕様

### 報告されている手段・条件(🟡 二次資料)

| 手段 | 概要 | 報告されている条件 | 日本 |
|---|---|---|---|
| コンテンツ収益化(Content Monetization) | リールなど動画のコンテンツ収益 | 資料により 10,000フォロワーなど不一致 | 提供国に日本を含むとする資料 |
| Stars(投げ銭) | ライブ・動画での投げ銭 | 500フォロワーで30日以上とする資料 | 要確認 |
| ファン向けサブスクリプション | 月額課金 | 10,000フォロワーとする資料 | 要確認 |
| パフォーマンスボーナス | 招待制 | 限られた地域 | 要確認 |
| 広告(自社) | 商品・サービスの集客 | — | 可 |
| 外部誘導 | note・YouTube・EC | — | 可 |

### 公式ページで確認できた条件(✅ 2026年11月3日取得)

| 手段 | 確認できた内容 | 出典 |
|---|---|---|
| コンテンツ収益化 | **招待制**。プロフェッショナルダッシュボード →「収益化」→「コンテンツ収益化」から**参加希望フォーム**を送れる。リール・写真・テキスト投稿・ストーリーズが対象 | [Content Monetization](https://creators.facebook.com/tools/facebook-content-monetization) |
| コンテンツ収益化(旧制度との関係) | インストリーム広告・リール広告・パフォーマンスボーナスを**1つに統合**したプログラム。移行後は旧プログラムに戻れない | [Introducing](https://creators.facebook.com/introducing-facebook-content-monetization) |
| 対象となる閲覧 | 繰り返し再生、**5秒未満の閲覧**、**10秒未満のコンテンツ**、非公開コンテンツ、他人のページからのクロスポスト(Instagram からは除く)、ポリシー違反のコンテンツなどは対象外 | [New tips](https://creators.facebook.com/blog/new-tips-to-help-you-earn-on-facebook-content-monetization/) |
| Stars | パートナー収益化ポリシーを満たす、**フォロワー500人以上の状態が30日以上連続**、提供国に居住、Stars の規約に同意。**1 Star につき1セント** | [Stars](https://creators.facebook.com/tools/stars)(2022年(皇紀2682年・令和4年)ごろの記載) |
| サブスクリプション | **フォロワー10,000人以上、または再訪問者250人以上**、かつ直近60日で**投稿エンゲージメント50,000**または**再生時間180,000分**のいずれか。提供国一覧に**日本は含まれず**、一覧外の国では**招待制** | [Subscriptions](https://creators.facebook.com/tools/subscriptions) |
| インストリーム広告(オンデマンド動画) | 18歳以上、直近60日で**再生時間60,000分**、**アクティブな動画5本以上** | [In-stream ads](https://creators.facebook.com/tools/ad-breaks/v2/) |
| インストリーム広告(ライブ) | 直近60日で再生時間600,000分(うちライブ60,000分以上)、動画5本以上(うち過去のライブ3本以上) | 同上 |

> インストリーム広告はコンテンツ収益化に統合される方針が示されています(上記)。古い条件のページが残っている可能性があるため、**自分の資格はダッシュボードで確認**してください。

### Creator Fast Track(🟡)

他の SNS で実績のある人向けに、一定期間の定額支払いとコンテンツ収益化への即時参加を提供するプログラムです([Meta for Creators](https://creators.facebook.com/creator-fast-track))。対象国は米国・カナダ・英国・オーストラリアとする報道があり、**日本は対象外とみられます** 🟡([Meta Newsroom](https://about.fb.com/news/2026/03/creator-fast-track-grow-your-audience-earn-money-on-facebook/) の検索要約)。

### 資格を確認して始める手順(⚪ メニュー名は変わる可能性)

1. ページ(またはプロフェッショナルモード)で**プロフェッショナルダッシュボード**を開きます。
2. 「収益化」タブを開き、各機能の資格と未達の条件を確認します ✅(ダッシュボードで資格を確認できることは公式に記載)。
3. 使える機能があれば「始める」から規約に同意します。
4. **受取口座**と税務情報を登録します。
5. 収益はダッシュボードまたは Meta Business Suite の**インサイト**で確認します ✅([Introducing](https://creators.facebook.com/introducing-facebook-content-monetization))。

### ブランドコンテンツ(企業案件)

1. 企業との契約内容(報酬・納品物・広告配信の可否)を書面で決めます([sponsorship-and-media-kit](../30-strategy/07-sponsorship-and-media-kit.md))。
2. 投稿に**「タイアップ投稿」(Paid partnership)ラベル**を付けます ✅([Meta for Creators](https://creators.facebook.com/earn-money/earn-from-brands/))。
3. 本文にも PR 表記をします。ステマは景品表示法違反です([legal-compliance](../01-common/legal-compliance.md))。
4. 企業が広告として配信する場合は**パートナーシップ広告**(「広告」ラベル)になります ✅。

### 設計(⚪)

- Facebook の収益プログラムに依存せず、**ページ・グループから他サービスへ誘導**する。
- 地域・店舗・イベントでは**広告**と**イベント**の集客が現実的。

## 確認方法

Meta Business Suite →「収益化」で現在の対象と条件が表示される(⚪)。表示内容をこのページに反映。

## 具体例

| 目的 | 現実的な方法(⚪) |
|---|---|
| 地域の店の売上 | イベント機能で告知、少額の広告で近隣に配信、予約ボタン |
| 講座・教室の集客 | グループで交流、ページから申し込みページへ誘導 |
| 動画発信者の収益 | コンテンツ収益化の参加希望フォームを送りつつ、Stars とブランド案件 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 「収益化の招待」を名乗るメッセージのリンクを開いた | 正式な招待はアプリ・Business Suite・ダッシュボードなど公式の画面で届く ✅。メッセージのリンクは開かない |
| 他人の動画を再投稿したが収益が出ない | オリジナルでない内容・他人のページからのクロスポストは対象外 ✅ |
| 「最後まで見て」と煽る投稿を量産した | 意味のない誘導は避けるよう公式が推奨 ✅。内容の質で勝負 |
| 10秒未満の動画ばかり投稿した | 10秒未満のコンテンツは対象外 ✅ |
| 受取口座の設定を忘れた | 支払いが保留になる(公式の対象外理由の1つ)✅。早めに登録 |

## 注意点

- 条件・対象国は頻繁に変わります。このページの ✅ も**取得日時点**の公式ページの記載です。
- 収益は所得です。確定申告などは [tax-and-business](../30-strategy/04-tax-and-business.md) を参照してください。
- フォロワーや再生を購入すると、収益化の資格を失う可能性があります(公式の記載。🟡 検索要約)。

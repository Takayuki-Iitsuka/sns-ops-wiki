# Facebook の画像・動画仕様

> **このページで分かること**: Facebook の投稿画像・プロフィール写真・カバー写真・リンクプレビュー(OGP)・リール・通常動画のサイズと、切れない作り方。
>
> **対象**: 初心者  **先に読むページ**: [image-specs-comparison](../01-common/image-specs-comparison.md)

> **アプリの画像仕様は公式本文が未取得**です(画像の多くは一般的に知られる設計値 ⚪)。**リールは開発者文書で ✅ 確認済み**。公式で確認 (#35)。

## 概要

Facebook では、同じ画像でも**スマートフォンとパソコンで切り抜き方が変わる**場所(カバー写真など)があります。初心者は次の3点を押さえれば十分です。

1. 投稿画像は **1:1 または 4:5**(Instagram と共通で作れる ⚪)
2. リンクの共有画像(OGP)は **約1.91:1(1200×630)**
3. リールは **9:16(1080×1920)** ✅

## 用語

| 用語 | 意味 |
|---|---|
| OGP / Open Graph Protocol | URL を共有したときに表示される画像・タイトルを決める設定 |
| cover photo(カバー写真) | ページ上部の横長の画像 |
| aspect ratio(アスペクト比) | 横:縦 の比 |
| codec(コーデック) | 動画・音声の圧縮方式(H.264、AAC など) |
| GOP(グループ・オブ・ピクチャー) | 動画圧縮の単位。Closed GOP は区切りが独立している形式 |

## 手順 / 仕様

### 画像

| 用途 | 推奨 | 確度 |
|---|---|---|
| リンク共有(OGP) | 1200×630(約1.91:1) | ⚪ |
| 投稿画像(正方形/縦長) | 1080×1080 / 1080×1350 | ⚪ |
| プロフィール写真 | 正方形。円形に切り抜き | ⚪ |
| カバー写真 | 横長。端末で切り抜きが変わる。中央に主要要素 | ⚪ |
| 形式 | JPEG / PNG | ⚪ |

### リール(✅ 開発者文書)

出典: [Reels Publishing API](https://developers.facebook.com/documentation/video-api/guides/reels-publishing.md)。

| 項目 | 値 | 確度 |
|---|---|---|
| ファイル形式 | .mp4 を推奨 | ✅ |
| 比率 | **9:16** | ✅ |
| 解像度 | **1080×1920 推奨**、最小 540×960 | ✅ |
| フレームレート | 24〜60 FPS(固定フレームレート) | ✅ |
| 長さ(API) | **3〜90秒**。ページのストーリーズとして公開するリールは**60秒以内** | ✅ |
| 映像 | H.264 / H.265(VP9・AV1 も対応)、4:2:0、Closed GOP(2〜5秒)、プログレッシブ | ✅ |
| 音声 | AAC Low Complexity、48kHz、ステレオ、128kbps 以上 | ✅ |
| API の公開上限 | ページあたり **24時間で30件** | ✅ |
| 長さ(アプリ) | 「**3秒以上、上限なし**」。縦・横どちらも可(2023年(皇紀2683年・令和5年)ごろの公式ページ) | ✅(記載時期に注意) |

→ アプリと API で長さの条件が違います。**外部ツールから投稿する場合は 90 秒以内**で作るのが安全です。

### 通常の動画

| 用途 | 推奨 | 確度 |
|---|---|---|
| リール | 9:16、1080×1920 | ✅(上表) |
| 通常動画 | 16:9、1920×1080、H.264+AAC | ⚪ |
| 長さ・容量(通常動画) | 未確認 | ⚪ |

### OGP(リンクプレビュー)

note の記事などを共有する際、画像タイトルが表示される。**note の見出し画像 1280×670**は約1.91:1で適合(🟡)。

自分のブログやサイトの記事を共有する場合の手順(⚪):

1. 記事ページの HTML に `og:image`(画像)・`og:title`(タイトル)・`og:description`(説明)を設定します。多くのブログサービスでは「アイキャッチ画像」「見出し画像」を設定すれば自動で入ります。
2. 画像は 1.91:1(例: 1200×630)で作り、文字は中央に置きます。
3. 共有前に、Meta の「シェアデバッガー」で表示を確認します。古い画像が出る場合は再取得します(⚪ ツール名は変わる可能性)。

### 切れない画像の作り方

1. 投稿画像は Instagram と同じ 4:5 / 1:1 で作ると使い回せます(⚪)。
2. カバー写真は、**上下左右の端に文字を置かない**ようにします。スマートフォンとパソコンで切り抜き位置が変わるためです(⚪)。
3. プロフィール写真は円形に切り抜かれるので、ロゴは中央に小さめに置きます。
4. 書き出し設定は [export-presets](../01-common/export-presets.md) を参照してください。

## 具体例

| 目的 | おすすめ(⚪) |
|---|---|
| イベント告知 | 4:5 の告知画像+本文に日時・場所 |
| ブログ記事の共有 | OGP 画像 1200×630 を記事側に設定 |
| 店舗紹介動画 | リール 9:16、30〜60秒 |
| 講座の録画 | 通常動画 16:9 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| カバー写真の文字がスマートフォンで切れた | 文字を中央に寄せ、両方の端末で確認 |
| リンクプレビューの画像が表示されない | リンク先の `og:image` を設定し、シェアデバッガーで再取得 |
| 外部ツールからのリール投稿が失敗した | 90 秒以内・9:16・最小 540×960 を確認 ✅ |
| 横長動画をリールにして小さく表示された | 9:16 で撮影・書き出し |

## 注意点

- アプリの画像仕様・通常動画の上限は公式本文を確認できていません(#35)。
- リールのアプリ仕様は記載時期が古いページに基づいています。アプリ内で確認してください。

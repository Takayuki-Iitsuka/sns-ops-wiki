# Facebook 初期設定と投稿

## 初期設定

1. **個人アカウント**(実名)から**ページ**を作成する。収益化・広告・API はページ単位。
2. ページ名・カテゴリ・説明・連絡先・URL(ユーザーネーム)。
3. プロフィール写真・カバー写真([02-media-specs](02-media-specs.md))。
4. **Meta Business Suite**: 投稿の予約、インサイト、受信箱、広告を一元管理。
5. 管理者・編集者の権限を最小限に。2段階認証([account-security](../01-common/account-security.md))。
6. Instagram アカウントとのリンク(Meta Business Suite/アカウントセンター)。
7. プライバシー・メッセージの自動返信。

## 投稿の種類(⚪)

| 種類 | 概要 |
|---|---|
| テキスト・リンク | リンクプレビュー(約 1.91:1 の画像) |
| 写真 | 複数枚アルバム |
| 動画 | 通常動画、リール |
| ストーリーズ | 24時間 |
| ライブ | リアルタイム |
| イベント | 集客・告知 |
| グループ投稿 | コミュニティ |

## 投稿手順

1. Meta Business Suite または ページから作成。
2. 本文・メディア・リンク・タグ付け・位置。
3. 予約または公開。クロスポスト(Instagram など)も設定可能 ⚪。
4. 広告・PR は表記([legal-compliance](../01-common/legal-compliance.md))。

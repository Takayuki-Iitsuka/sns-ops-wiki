# Facebook のコメント・グループ運用

> **このページで分かること**: ページのコメント・メッセージへの対応、迷惑行為への対処、Facebook グループの作り方・ルール作り・参加承認・モデレーションの手順。
>
> **対象**: 初心者  **先に読むページ**: [comments-and-engagement](../01-common/comments-and-engagement.md)

共通: [comments-and-engagement](../01-common/comments-and-engagement.md)

## 概要

Facebook の強みは**グループ**(共通の関心を持つ人が集まる場)です。ページは「お知らせを出す場所」、グループは「参加者同士が話す場所」と考えると分かりやすいです(⚪)。

グループは**個人でもページでも作成できます** ✅([Meta for Creators](https://creators.facebook.com/tools/groups))。ページにグループをリンクすると、ページの訪問者をグループへ案内できます。

## 用語

| 用語 | 意味 |
|---|---|
| Group(グループ) | 共通の関心を持つ人が投稿・交流する場 |
| admin(管理者) | グループの設定・メンバー・投稿を管理する人 |
| moderator(モデレーター) | 投稿・コメントの承認や削除を担当する人 |
| membership questions(参加質問) | 参加リクエスト時に答えてもらう質問 |
| Admin Assist(管理アシスト) | 条件に応じて投稿や参加リクエストを自動で処理する機能 |
| keyword filter(キーワードフィルター) | 指定した語を含むコメントを非表示にする機能 |
| PSID(ページスコープ ID) | ページごとに割り振られる利用者の識別子(API 用) |

## 手順 / 仕様

### ページのコメント・メッセージ

| 機能 | 使い方 |
|---|---|
| 受信箱(Meta Business Suite) | コメント・メッセージを一元管理 |
| 自動返信/よくある質問 | 営業時間・FAQ の自動回答 |
| キーワードフィルター | 不適切語を非表示 |
| 禁止ユーザー | 荒らしの対応 |

公式で確認できたこと(✅):

- プロフェッショナルダッシュボードで、コメントの検索・**いいね・非表示・削除・返信・報告**ができる。**トップファンバッジ**などで熱心なフォロワーを表彰できる([Meta for Creators](https://creators.facebook.com/professional-dashboard))。
- ページで返信・削除をするには `MODERATE` タスク(権限)が必要 ✅([Pages API Overview](https://developers.facebook.com/documentation/pages-api/overview.md))。
- ページはコメントした人に **@メンション**で公開返信できる ✅(同上)。

### コメントへの対応手順(⚪)

1. 受信箱(Business Suite)または通知でコメントを確認します。
2. 質問には返信し、同じ質問が多ければ投稿本文に追記します。
3. スパム・不適切な語は**キーワードフィルター**に登録して自動で非表示にします。
4. 繰り返し荒らす人は**非表示 → 禁止(ページからのブロック)**の順で対応します。
5. 脅迫・個人情報の暴露は記録して報告します([crisis-response](../01-common/crisis-response.md))。

### グループの公式情報(✅ [Meta for Creators](https://creators.facebook.com/tools/groups))

| 項目 | 内容 |
|---|---|
| 作成できる人 | **個人またはページ** |
| ページへのリンク条件 | ページの管理者であること、自分またはページがグループの管理者であること、ページに**年齢制限がない**こと |
| リンクできる数 | 1つのページに**最大200グループ** |
| グループのインサイト | メンバー**250人以上**のグループで利用可(自分またはページが管理者の場合) |

### グループを作る手順(⚪ メニュー名は変わる可能性)

1. メニューから「グループ」→「新しいグループを作成」を選びます。ページとして作る場合はページに切り替えてから作成します。
2. **グループ名**を決めます。「○○市 子育て情報交換」のように目的が分かる名前にします。
3. **プライバシー**を選びます。
   - **公開**: 誰でも投稿を見られる
   - **プライベート**: メンバーだけが投稿を見られる
4. 説明文に目的と対象者を書きます。
5. カバー写真を設定します。
6. ページにリンクする場合は、ページの設定からグループをリンクします ✅(条件は上表)。

### グループ運用(⚪)

1. **目的とルール**を最初に明示(固定投稿)。
2. 参加承認の質問(スパム対策)。
3. 管理者・モデレーターを複数名で。
4. 週次の定例投稿(質問・雑談・成果共有)で習慣化。
5. 有料メンバーシップ型の運営は規約確認 ⚪。

**参加質問**は最大3問とする資料があります 🟡([TechCrunch](https://techcrunch.com/?p=1489120))。「ルールに同意しますか」「参加の目的は」など、スパムを見分けられる質問にします。

**ルールの例(⚪)**

```
1. 互いに敬意を持って書き込みましょう(攻撃・差別は削除します)
2. 宣伝・勧誘は月1回の「告知スレッド」のみ
3. 住所・電話番号など個人情報を書き込まないでください
4. 他の人の写真を無断で転載しないでください
5. ルール違反は警告のうえ、退会していただく場合があります
```

### モデレーションの段階(⚪)

| 段階 | 対応 |
|---|---|
| 1 | 投稿の承認制(新規メンバーの最初の投稿など) |
| 2 | キーワードで自動的に保留・却下(管理アシスト) |
| 3 | 個別に警告(コメントまたはメッセージ) |
| 4 | 一時的な投稿停止(ミュート) |
| 5 | 削除・ブロック |

## 具体例

**定例投稿の例(料理好きのグループ)**

| 曜日 | 投稿 |
|---|---|
| 月 | 「今週作りたいもの」スレッド |
| 水 | 管理者からの豆知識 |
| 金 | 「作ってみた」写真の共有スレッド |
| 月1回 | 告知・宣伝OKのスレッド |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| ルールを決めずに始め、宣伝投稿だらけになった | 固定投稿でルールを明示し、宣伝は専用スレッドへ |
| 管理者が1人で疲れてしまった | モデレーターを複数名にし、当番を決める |
| 参加承認をせず、スパムアカウントが増えた | 参加質問を設定し、答えていない申請は承認しない |
| グループのインサイトが見られない | メンバー250人以上で利用可 ✅ |
| 個人情報の書き込みが放置された | 見つけたらすぐ削除し、本人に連絡。ルールで禁止を明記 |

## 個人情報・安全

- 住所・電話など個人情報の投稿を禁止するルール。
- 勧誘・宣伝の扱いを明確に。
- 未成年が参加する可能性があるグループでは、出会い目的の連絡や個人間取引を禁止します(⚪)。

## 注意点

- コミュニティ運営全般の考え方は [community-management](../01-common/community-management.md) を参照してください。
- グループの機能・名称は頻繁に変わります。参加質問の数や管理アシストの条件は公式で確認します(⚪)。

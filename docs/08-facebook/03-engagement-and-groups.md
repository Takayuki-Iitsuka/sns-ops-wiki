# Facebook のコメント・グループ運用

共通: [comments-and-engagement](../01-common/comments-and-engagement.md)

## ページのコメント・メッセージ

| 機能 | 使い方 |
|---|---|
| 受信箱(Meta Business Suite) | コメント・メッセージを一元管理 |
| 自動返信/よくある質問 | 営業時間・FAQ の自動回答 |
| キーワードフィルター | 不適切語を非表示 |
| 禁止ユーザー | 荒らしの対応 |

## グループ運用(⚪)

1. **目的とルール**を最初に明示(固定投稿)。
2. 参加承認の質問(スパム対策)。
3. 管理者・モデレーターを複数名で。
4. 週次の定例投稿(質問・雑談・成果共有)で習慣化。
5. 有料メンバーシップ型の運営は規約確認 ⚪。

## 個人情報・安全

- 住所・電話など個人情報の投稿を禁止するルール。
- 勧誘・宣伝の扱いを明確に。

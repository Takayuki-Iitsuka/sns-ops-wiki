# 収益化の段階的な計画

> **このページで分かること**: SNS 運用で得られる収益の種類、どの順番で始めるか(S0〜S5 の段階)、手数料を引いた手取りの計算方法、価格の決め方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [目標・KPI・ロードマップ](01-goals-kpi-roadmap.md)、[サービス間の導線設計](02-funnel.md)、[収益化の比較](../01-common/monetization-comparison.md)

> **プラットフォームの収益化条件は未確認が多い**です(→ [要検証リスト](../00-meta/verification-queue.md))。条件を満たしても、**まず自前の資産(記事・書籍・動画・会員)で収益を作る**設計にします。

## 概要

収益化には大きく2種類あります。

1. **プラットフォームからの分配**: 広告収益の分配やギフトなど。条件(フォロワー数・視聴時間など)を満たす必要があり、**条件や配分は運営の都合で変わります**。
2. **自分の商品・サービスの販売**: 有料記事、電子書籍、グッズ、講座、案件など。条件はなく小さく始められますが、**価値を伝える導線**が必要です。

初心者は、いきなり収益を狙うより「無料で役に立つ投稿を積む → 読者が付く → 小さく売る」の順で進めるほうが失敗しにくいです(⚪ 一般論)。

## 用語

| 用語 | 意味 |
|---|---|
| monetization(収益化) | 発信から収入を得ること |
| platform fee(プラットフォーム手数料) | 販売サービスが売上から差し引く利用料 |
| payment fee(決済手数料) | クレジットカードなどの決済にかかる手数料 |
| 手取り | 売上から手数料・振込手数料を引いて、実際に受け取る金額 |
| subscription / membership(サブスクリプション、メンバーシップ) | 月額で継続課金する仕組み |
| churn rate(解約率) | 一定期間に解約した会員の割合 |
| affiliate(アフィリエイト、成果報酬型広告) | 紹介したリンク経由の購入などに応じて報酬が出る仕組み |
| tie-in / sponsorship(タイアップ、案件) | 企業から依頼されて紹介する投稿([案件とメディアキット](07-sponsorship-and-media-kit.md)) |

## 段階的な計画

| 段階 | 目安 | 施策 |
|---|---|---|
| S0 | 開始〜 | 無料で価値を積む。入口記事・プロフィールを整備 |
| S1 | 週次運用が定着 | アフィリエイト(広告表記)。自前の導線(メール/LINE)の準備 |
| S2 | 常連読者が出現 | note 有料記事、デジタル商品 |
| S3 | シリーズ完結 | 電子書籍化、メンバーシップ |
| S4 | 読者基盤が安定 | 講座、グッズ、YouTube/TikTok の収益化申請 |
| S5 | 多角化 | 他メディア、イベント |

### 各段階の「次に進む目安」(⚪ 経験則。数値ではなく状態で判断)

| 段階 | 次に進む目安 | やってはいけないこと |
|---|---|---|
| S0 → S1 | 週次の投稿が1か月以上続いている。保存・コメントが付く型がある | 読者がいない段階で高額商品を作る |
| S1 → S2 | 同じ人から繰り返し反応がある(常連がいる)。「もっと詳しく」という声がある | 無料投稿をやめて有料だけにする |
| S2 → S3 | 有料記事が継続的に売れる。続編の要望がある | 毎月の更新を約束できないのにメンバーシップを始める |
| S3 → S4 | 自前の連絡手段(メール・LINE)に登録者がいる | 申請条件だけを目的に投稿を量産する |
| S4 → S5 | 運用を手伝う人や仕組みがある | 1人で全部を抱えて燃え尽きる |

## 手取りの計算(計算例は架空 ⚪)

手取りは次の式で考えます。手数料率は**サービスごとに違い、変わることがある**ため、販売前に各サービスの公式ヘルプで確認します(#5、#41)。

```
手取り = 販売価格 − プラットフォーム手数料 − 決済手数料 − 振込手数料(1回ごと)
```

| 前提(架空) | 計算 | 結果 |
|---|---|---|
| 価格 500円の記事を 20部、手数料合計を仮に 15% とする | 500 × 20 = 10,000円 → 10,000 × 0.15 = 1,500円 | 手数料引き後 8,500円 |
| 振込手数料を仮に 1回 300円 とする | 8,500 − 300 | **手取り 8,200円** |
| 月額 500円の会員 30人、手数料合計を仮に 15%、月の解約率 5% | 15,000 × 0.85 = 12,750円/月。翌月は 30 × 0.95 ≒ 28人 | 新規が解約を上回らないと減っていく |

- 上の「15%」「300円」は**計算方法を示すための仮の値**で、実際の料率ではありません。
- 実際の手数料の報告値は [その他サービスの料金](../40-pricing/04-other-services.md)(🟡)を参照してください。

## 価格設計の考え方(⚪)

- **成果物の明確さ**: ページ数・回数・テンプレ・図解で価値を示す。
- 低価格から試し、反応で調整。値付けの上限・下限は各サービスの規定を確認。
- 無料の**試し読み**で有料部分の価値を示す。
- **かかった時間から逆算**する: 「制作時間 × 自分の時給の目安 ÷ 見込み販売数」で下限の目安を出します。
- **値下げより特典**: 値下げを繰り返すと、先に買った人の信頼を失います。期間限定の特典や、まとめ買いのセットで調整します。

## イベント・ツアー(⚪ 要確認)

有料で旅行を手配・募集する行為は、**旅行業法の登録が必要となる場合**がある。実施前に観光庁・都道府県の窓口で確認(#23)。

## 広告・PR・アフィリエイト

成果報酬リンクは**一目で分かる広告表記**([legal-compliance](../01-common/legal-compliance.md))。プログラム規約の表記ルールも守る。企業から依頼された投稿も同じです([案件とメディアキット](07-sponsorship-and-media-kit.md))。

## 税務

収益が出たら、**会社員の副業でも確定申告が必要になる場合**があります。例えば給与を1か所から受け、全額が源泉徴収される人は、給与所得・退職所得以外の所得の合計額が **20万円を超えると確定申告が必要** です(✅ [国税庁 No.1900](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm))。「所得」は売上ではなく、**売上から必要経費を引いた金額**です。詳しくは [個人の収益と税務](04-tax-and-business.md)、消費税は [消費税とインボイス](08-consumption-tax-and-invoice.md)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 収益化条件の達成だけを目標にする | 条件は変わる。自前の商品・連絡手段を並行して育てる |
| 手数料・振込手数料を考えずに価格を決める | 上の式で手取りを計算してから決める |
| メンバーシップを始めて更新が止まる | 更新頻度は「無理なく守れる量」の半分から始める |
| 広告表記を忘れる | 投稿前のチェックリストに「PR 表記」を入れる |
| 売上を記録していない | 月1回、売上と手数料を台帳に記録([税務](04-tax-and-business.md)) |

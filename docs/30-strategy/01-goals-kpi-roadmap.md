# 目標・KPI・ロードマップ

> **このページで分かること**: SNS 運用の目標の立て方、KPI(重要業績評価指標)の選び方と計算方法、開始から1年程度のフェーズ別ロードマップ。
>
> **対象**: 初心者(これから始める人、始めたが伸び悩んでいる人)  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[分析と KPI](../01-common/analytics-kpi.md)

> 数値目標は**仮置き**です。開始後の実績(傾向)に合わせて見直します。公開リポジトリには実数を書かず、非公開の台帳で管理します(→ [CONTRIBUTING](../../CONTRIBUTING.md))。このページの数値例はすべて**架空**です。

## 概要

目標がないまま投稿を続けると、「何が良くて何が悪かったのか」を判断できません。目標と KPI を決めると、次の3つができるようになります。

1. **やることの優先順位が決まる**(例: 今月は保存される投稿を増やす)。
2. **振り返りができる**(週次・月次で「目標に近づいたか」を確認できる)。
3. **やめる判断ができる**(効果のない施策に時間を使い続けない)。

全体の考え方は「最終目標(KGI)→ 中間の指標(KPI)→ 毎週の行動」の3段に分けることです。数値はサービスの集計方法によって変わるため、**サービス間で単純比較せず、同じサービス内の傾向**を見ます(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| KGI / Key Goal Indicator(重要目標達成指標) | 最終的に達成したいこと。例: 「有料記事の月間販売を一定数にする」 |
| KPI / Key Performance Indicator(重要業績評価指標) | KGI に近づいているかを測る中間の指標。例: 保存率、プロフィールアクセス |
| impression(インプレッション、表示回数) | 投稿が画面に表示された回数。同じ人が2回見ると2回と数えることが多い |
| reach(リーチ) | 投稿を見たユニークアカウント数(人数に近い) |
| engagement(エンゲージメント) | いいね・返信・保存・共有などの反応の合計 |
| CTR / click-through rate(クリック率) | 表示またはリーチに対して、リンクがクリックされた割合 |
| CVR / conversion rate(コンバージョン率、成約率) | ページ訪問者のうち、購入・登録などをした割合 |
| SMART(スマート) | 目標を具体的にするための5つの観点(下記) |
| 行動目標 / 結果目標 | 自分で必ずできること / 相手の反応次第で決まること |

## フェーズ(ロードマップの目安 ⚪)

| フェーズ | 期間の目安 | 主目的 | 主な行動 |
|---|---|---|---|
| 0. 基盤 | 2〜4週 | 設計と土台 | プロフィール整備、シリーズ選定、ストック10本、台帳作成 |
| 1. 認知 | 〜3か月 | 型の確立 | 週3〜5投稿、柱の検証、週次レビュー |
| 2. 信頼 | 3〜6か月 | 深掘りと常連化 | note 週1、メルマガ/メンバー募集の準備、コメント運用 |
| 3. 収益 | 6か月〜 | 収益導線 | 有料記事、電子書籍、書籍紹介 |
| 4. 拡張 | 12か月〜 | 多角化 | 講座、グッズ、イベント、他媒体 |

- 期間は**目安**です。週に使える時間や投稿形式で大きく変わります。期間ではなく「次のフェーズへ進む条件」で判断します。
- 進む条件の例: 「フェーズ1 → 2」は「週3投稿を4週連続で守れた」「保存率の高い型が2つ見つかった」など。
- 最初の1か月の具体的な進め方は [最初の30日](../01-common/first-30-days.md) を参照してください。

## 手順: 目標と KPI の決め方

1. **目的を一文で書く**。例: 「料理の作り置きを知りたい人に、自分のレシピを届けて、半年後に有料レシピ集を販売する」。
2. **KGI を1つ決める**。期限を付けます。例: 「6か月後に note の有料レシピ集を販売開始し、初月に一定数売る」。
3. **KGI を分解して KPI を2〜3個選ぶ**(下の「KPI ツリー」)。多すぎると判断できません。
4. **行動目標を決める**。例: 「週3回投稿」「週1回コメントに全返信」「月1本 note の無料記事」。
5. **計測方法を決める**。どの画面(各サービスのインサイト・アナリティクス)のどの数字を、いつ記録するかを決めます。
6. **振り返りの日を決める**。週次は [週次レビュー](../../templates/weekly-review.md)、月次は [月次レビュー](../../templates/monthly-review.md) を使います。
7. **3か月ごとに見直す**。目標が高すぎても低すぎても修正して構いません。

### SMART で目標を具体的にする(⚪ 一般的な手法)

| 観点 | 意味 | 悪い例 → 良い例 |
|---|---|---|
| Specific(具体的) | 何をするか明確 | 「伸ばす」→「保存率を上げる」 |
| Measurable(測定可能) | 数字で確認できる | 「好評」→「保存数 ÷ リーチ」 |
| Achievable(達成可能) | 時間・能力の範囲内 | 「毎日3投稿」→「週3投稿」 |
| Relevant(関連性) | KGI につながる | 「いいね数」だけ →「プロフィールアクセス」も見る |
| Time-bound(期限) | いつまでか | 「いつか」→「3か月後の月末」 |

### KPI ツリー(架空の例: 料理アカウント)

```
KGI: 6か月後に有料レシピ集を販売し、初月に一定数売る
 ├─ 認知: Instagram のリーチ(週単位の傾向)
 ├─ 関心: 保存率(保存 ÷ リーチ)  ← 「後で作りたい」と思われたか
 ├─ 行動: プロフィールのリンククリック → note の入口記事の閲覧
 └─ 収益: note の有料記事の購入率(購入 ÷ 記事閲覧)
行動目標: 週3投稿(うち1本はカルーセルの手順図解)、週1回コメント返信
```

## KPI(段階別)

| 目的 | 指標 | 見方 |
|---|---|---|
| 認知 | インプレッション/リーチ | 伸びの傾向、形式別比較 |
| 関心 | 保存率・シェア率・プロフィールアクセス | 内容の有用性 |
| 信頼 | note の閲覧、スキ、フォロー、コメントの質 | 常連化 |
| 行動 | リンククリック、メール登録、メンバー登録 | 導線の効果 |
| 収益 | 売上、購入率、解約率、1読者あたり売上 | 収益性 |

### 計算式と計算例(数値は架空 ⚪)

| 指標 | 計算式(一般的な定義) | 計算例 |
|---|---|---|
| エンゲージメント率 | エンゲージメント数 ÷ インプレッション(またはリーチ)× 100 | 300 ÷ 10,000 × 100 = **3%** |
| 保存率 | 保存数 ÷ リーチ × 100 | 80 ÷ 4,000 × 100 = **2%** |
| CTR(クリック率) | リンククリック ÷ インプレッション × 100 | 50 ÷ 10,000 × 100 = **0.5%** |
| CVR(購入率) | 購入数 ÷ 記事閲覧数 × 100 | 6 ÷ 300 × 100 = **2%** |
| 解約率(月) | その月の解約数 ÷ 月初の会員数 × 100 | 2 ÷ 40 × 100 = **5%** |

- **分母がサービスによって違う**ことに注意します。エンゲージメント率をインプレッションで割るかリーチで割るかは、サービスやツールで異なります(⚪)。自分の台帳では**どちらか一方に統一**します。
- 指標の定義は各サービスの分析ページ(例: [X の分析](../02-x/08-analytics.md)、[Instagram の分析](../03-instagram/08-analytics.md))で確認してください。

## 目標の置き方

1. **行動目標**(コントロール可能): 投稿数、記事数、返信の速度。まずこれを100%守ることを目指します。
2. **結果目標**(コントロール困難): フォロワー、売上。行動目標を満たした上で追います。結果が出なくても、行動目標を守れていれば「型の検証が進んだ」と評価します。
3. **学習目標**: 検証する仮説を月ごとに1つ決めます。例: 「手順をカルーセル5枚にすると、1枚画像より保存率が上がるか」。

## 週次・月次・四半期の運用

| 頻度 | 内容 | 成果物 |
|---|---|---|
| 週次 | [週次レビュー](../../templates/weekly-review.md) | 次週の施策3つ |
| 月次 | 柱の偏り、タグ入れ替え、収益導線の点検([月次レビュー](../../templates/monthly-review.md)) | 月次メモ |
| 四半期 | フェーズ見直し、シリーズの追加/終了 | ロードマップ更新 |

所要時間の目安は、週次 15〜30分、月次 60分、四半期 半日程度です(⚪ 経験則)。

## 具体例

| 種類 | 悪い例 | 良い例 |
|---|---|---|
| 目標 | 「フォロワーを増やす」 | 「3か月で、保存率の高い投稿の型を2つ見つける(週3投稿を継続)」 |
| KPI | いいね数だけを見る | 保存率とプロフィールアクセスを見る(目的が「note へ送る」なら) |
| 期限 | 決めない | 「四半期末に見直す」 |
| 比較 | X と Instagram の数字を並べて比べる | 同じサービス内で、先月と今月を比べる |

## よくある失敗と対処

| 失敗 | なぜ起きるか | 対処 |
|---|---|---|
| 指標を10個以上追う | 全部大事に見える | 目的に合う2〜3個に絞る |
| フォロワー数だけで一喜一憂する | 目立つ数字だから | 行動目標の達成率と、比率(保存率など)を見る |
| 毎日数字を見て方針を変える | 1日の変動は偶然が大きい | 判断は週次以上の単位で行う |
| 目標を高くしすぎて燃え尽きる | 他人の実績と比べる | 継続できる頻度を先に決める([リスク登録簿](05-risk-register.md) #8) |
| 公開の場に実数を書く | 記録場所が分かれていない | 実数は非公開の台帳へ。ここは桁と傾向のみ |

## 注意点

- 指標の名前や集計方法は、サービスの仕様変更で変わることがあります。数字の急変は、まず仕様変更を疑います(⚪)。
- 「フォロワーを買う」「相互フォローを大量に依頼する」などの不自然な増やし方は、各サービスの規約に反する場合があります([X のポリシー](../02-x/10-policies.md)、[Instagram のポリシー](../03-instagram/10-policies.md))。

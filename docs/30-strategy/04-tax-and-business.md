# 個人の収益と税務・事業の基礎

> **このページで分かること**: SNS で収益が出たときの所得税の基本(収入と所得の違い、副業の確定申告と「20万円」の条件、開業届、青色申告、経費、源泉徴収)。消費税・インボイスは [消費税とインボイス](08-consumption-tax-and-invoice.md) で扱います。
>
> **対象**: 初心者(会社員の副業、個人で始めた人)  **先に読むページ**: [収益化の段階的な計画](03-monetization-roadmap.md)

> **一般的な整理です。個別の判断は税務署・税理士へ。** 法令・数値は国税庁(https://www.nta.go.jp/)で最新を確認してください。このページの ✅ は、国税庁タックスアンサーの「2026年(皇紀2686年・令和8年)4月1日現在法令等」の表示があるページを 2026-11-03 に確認したものです。税制は毎年のように改正されるため、申告の前に必ず最新のページを見てください。

## 概要

SNS の収益(有料記事、広告分配、案件の報酬、グッズ販売など)は、金額が小さくても**税金の対象になり得ます**。初心者がまず押さえることは次の4つです。

1. **「収入」と「所得」は違う**。所得 = 収入 − 必要経費。
2. **会社員の副業は「所得20万円」が確定申告の目安の1つ**(条件あり)。
3. **記録は最初から付ける**(後からまとめるのは大変)。
4. **迷ったら税務署・税理士に相談する**。

## 用語

| 用語 | 意味 |
|---|---|
| 収入(総収入金額) | 受け取った売上・報酬の合計 |
| 必要経費 | 収入を得るために直接かかった費用 |
| 所得 | 収入 − 必要経費(雑所得・事業所得の場合) |
| 確定申告 | 1年間(1月1日〜12月31日)の所得と税額を計算して税務署に申告すること |
| 雑所得 | 他の9種類の所得のどれにも当たらない所得。副業の原稿料などが例 |
| 事業所得 | 事業(継続的・規模のある商売)から生じる所得 |
| 開業届(個人事業の開業・廃業等届出書) | 事業を始めたことを税務署に届け出る書類 |
| 青色申告 | 帳簿を付けることを条件に、控除などの特典を受けられる申告方法(届出が必要) |
| 白色申告 | 青色申告の承認を受けていない申告 |
| 源泉徴収 | 支払う側が報酬から所得税を差し引いて、代わりに納める仕組み |
| 按分(あんぶん) | 仕事と私用の両方に使う費用を、仕事の割合だけ経費にすること |

## 1. 収入と所得の違い

| 区分 | 計算 | 確度 |
|---|---|---|
| 業務に係る雑所得 | 総収入金額 − 必要経費 | ✅ [No.1500](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1500.htm) |
| 業務に係る雑所得の意味 | 副業に係る収入のうち「営利を目的とした継続的なもの」。例として原稿料、シェアリングエコノミーに係る所得 | ✅ No.1500 |

**計算例(架空)**: 1年間の有料記事の売上 30万円、手数料と経費 12万円 → 所得 **18万円**。

## 2. 会社員の副業と「20万円」の条件

| 項目 | 内容 | 確度 |
|---|---|---|
| 確定申告が必要な人(1か所から給与、全額源泉徴収の場合) | 給与所得・退職所得以外の**所得**の合計額が **20万円を超える**人 | ✅ [No.1900](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm) |
| 給与が多い人 | 給与の年間収入金額が **2,000万円を超える**人は確定申告が必要 | ✅ No.1900 |
| 2か所以上から給与 | 年末調整されなかった給与の収入金額と、給与・退職所得以外の所得の合計額が20万円を超える人(150万円以下などの例外あり) | ✅ No.1900 |
| 申告期間 | 原則として、翌年 **2月16日から3月15日まで** | ✅ [No.2020](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2020.htm) |
| 住民税 | 所得税の確定申告が不要でも、**住民税の申告は別に必要になる場合がある**とされる。お住まいの市区町村で確認 | ⚪ 要確認 |
| 医療費控除などで申告する場合 | 確定申告をするなら、20万円以下の副業所得も含めて申告する、と一般に案内される | ⚪ 要確認 |

**よくある誤解**:

- 「売上が20万円以下なら申告不要」ではありません。基準は**所得**(売上 − 経費)です。
- 「20万円以下なら税金がかからない」でもありません。所得税の確定申告が不要になる条件の1つ、という意味です。
- 学生・主婦(主夫)・無職など、給与所得者でない人は No.1900 の条件ではなく、[No.2020](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2020.htm) の一般的な条件で判断します。

## 収益が出たら考えること

| 論点 | 概要 |
|---|---|
| 所得区分 | 事業所得、雑所得など。継続性・規模・帳簿の有無で判断される(⚪ 区分の具体的な基準は要確認。業務に係る雑所得の定義は ✅ No.1500) |
| 確定申告 | 会社員の副業の所得が年20万円を超える場合などに必要(✅ No.1900。上の表) |
| 開業届 | 事業として行う場合に提出。青色申告承認申請書と合わせて検討(下の表 ✅) |
| 青色申告 | 帳簿付けの要件を満たすと特典がある(下の表 ✅) |
| 帳簿 | 売上・経費・領収書を継続して記録 |
| 消費税・インボイス | 売上規模により課税事業者になる。登録の判断は専門家へ([消費税とインボイス](08-consumption-tax-and-invoice.md)) |
| 住民税・社会保険 | 副業の扱いは勤務先・自治体で異なる場合あり(⚪) |
| 就業規則 | 会社員は副業の可否を確認(⚪) |

## 3. 開業届と青色申告

| 書類 | 提出期限 | 確度 |
|---|---|---|
| 個人事業の開業・廃業等届出書(開業届) | 事業の開始等の事実があった日の属する**年分の確定申告期限まで** | ✅ [No.2090](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2090.htm) |
| 所得税の青色申告承認申請書 | 原則、青色申告をしようとする年の **3月15日まで**。その年の1月16日以後に新たに事業を始めた場合は、開始の日から **2か月以内** | ✅ No.2090、[No.2070](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm) |

> 古い解説記事では開業届の期限を別の表現で説明している場合があります。**提出前に国税庁の最新ページで確認**してください(⚪)。都道府県税事務所など、税務署以外への届出が必要な場合もあります(✅ No.2090 に案内あり)。

### 青色申告特別控除(✅ [No.2070](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm))

| 控除額 | 主な要件 |
|---|---|
| **65万円** | 事業所得などを生ずべき事業を営む人が、正規の簿記(複式簿記)で記帳し、貸借対照表と損益計算書を添付して期限内に申告。さらに **e-Tax(電子申告)** で申告するか、**電子帳簿保存**の要件を満たす |
| **55万円** | 上記の正規の簿記・書類添付・期限内申告(e-Tax・電子帳簿保存は不要) |
| **10万円** | 上記以外の青色申告者 |

- 青色申告特別控除は**事業所得・不動産所得・山林所得**が対象で、**雑所得には使えません**(⚪ 一般知識。No.2070 の要件の文言から)。開業届を出すかどうかは、継続性や規模を踏まえて判断します。

## 4. 経費(必要経費)

| 項目 | 内容 | 確度 |
|---|---|---|
| 経費にできるもの | 売上原価など収入を得るために直接要した費用、販売費・一般管理費などその年に生じた業務上の費用 | ✅ [No.2210](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm) |
| 計上する時期 | 支払った時ではなく、その年の12月31日までに**債務が確定**した金額 | ✅ No.2210 |
| 家事関連費(私用と兼用) | 原則は経費にならない。業務に直接必要だったことが**明らかに区分できる部分だけ**経費になる。区分は取引の記録などに基づく | ✅ No.2210 |

### 経費になり得る例(⚪ 判断は専門家へ)

書籍(資料代)、通信費、ソフトウェア(フォント・編集)、取材交通費、機材。**事業との関連と按分**を記録。SNS 運用では、ほかに画像・動画ツールや AI の有料プラン([料金](../40-pricing/README.md))、撮影小道具、レンタルスペース代などが候補です。

**按分の計算例(架空 ⚪)**: スマートフォンの通信費が月 8,000円で、記録に基づき業務の利用が 4割なら、8,000 × 0.4 = **3,200円/月** を経費とする、という考え方です。割合の根拠(利用時間の記録など)を残します。高額な機材は、一度に全額を経費にできず数年に分ける(減価償却)場合があります(⚪ 要確認)。

## 5. 報酬の源泉徴収(案件・寄稿・講演)

| 項目 | 内容 | 確度 |
|---|---|---|
| 対象 | 原稿料・講演料など。名目が謝金・取材費でも実態が同じなら対象 | ✅ [No.2795](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm) |
| 税率 | 1回の支払金額が100万円以下: **10.21%**。100万円超: 超えた部分 20.42% + 102,100円 | ✅ No.2795 |
| 消費税との関係 | 原則は消費税込みの額が対象。請求書で報酬と消費税額が明確に区分されていれば、報酬額のみを対象にしてよい | ✅ No.2795 |

**計算例**: 原稿料 50,000円(消費税を区分した請求)→ 50,000 × 10.21% = **5,105円**が差し引かれ、報酬部分の振込は 44,895円(+消費税額)。差し引かれた税は確定申告で精算されます(✅ No.2020)。SNS の投稿制作の報酬が源泉徴収の対象になるかは、契約内容によります(⚪ 支払う企業に確認)。

## 記録の仕方

1. 売上: 入金日・サービス・金額・手数料を月次で記録。
2. 経費: 領収書・明細を保存。品目と用途を書く。
3. 公開リポジトリには**実額を書かない**。非公開の表計算で管理。
4. 源泉徴収された額は、支払明細や支払調書で確認して記録します。
5. 業務に係る雑所得でも、前々年の収入金額が **300万円を超える**と、現金預金取引等関係書類の保存が必要です(✅ No.1500)。**1,000万円を超える**と収支内訳書などの添付が必要です(✅ No.1500)。

| 記録する列(例) | 記入例(架空) |
|---|---|
| 日付 | 2026-11-05 |
| 区分 | 売上 / 経費 |
| 相手・サービス | note(有料記事) |
| 金額 | 1,000 |
| 手数料・源泉税 | 150 |
| 用途・メモ | 「作り置き献立」記事 |
| 証憑 | 明細の PDF を保存したフォルダ名 |

## プラットフォームからの支払い

- note、各社の収益は**支払調書・明細**の有無、源泉徴収の有無を各サービスの規約で確認(#5, #6)。
- 海外サービス経由の収益は、源泉税・税務書類(W-8BEN 等)の手続きがあり得る(⚪ 要確認)。

## 法的な表記

- 継続的な物販・有料サービスは、**特定商取引法に基づく表記**の要否を確認。個人の住所・電話番号の公開が課題になる場合、サービス側の代替手段を確認。
- 利用規約・プライバシーポリシーを自サイトで用意する場合は、雛形を専門家に確認。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 売上と所得を混同する | 所得 = 収入 − 必要経費。経費の記録を残す |
| 年末にまとめて領収書を探す | 月1回、明細をダウンロードして保存する |
| 私用の支出をすべて経費にする | 業務で使った部分だけ、根拠を残して按分する |
| 源泉徴収された額を忘れる | 支払明細を保存し、申告で精算する |
| 古いブログ記事の情報で判断する | 国税庁の「現在法令等」の日付を確認する |

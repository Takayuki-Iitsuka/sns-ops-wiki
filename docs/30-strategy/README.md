# 全体戦略(認知拡大と収益化)

> **このページで分かること**: 戦略フォルダの全体像、ページの読む順番、意思決定の原則。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)

## 概要

個人が X・Instagram・note・YouTube などを連携させて**認知拡大 → 信頼 → 収益化**へ進めるための戦略をまとめます。個々の操作方法(投稿の仕方など)は各サービスのフォルダにあり、このフォルダは「**何を目指して、どの順番で進めるか**」を扱います。

## 全体像

```
[認知]  X(拡散) ・ Instagram(ビジュアル) ・ 短尺動画
   ↓ プロフィール/固定投稿/ストーリーズ
[信頼]  note(深掘り) ・ 無料記事・解説 ・ YouTube 長尺
   ↓ メール/メンバーシップ/有料記事
[収益]  有料記事・電子書籍・講座・書籍紹介・グッズ・企業案件
```

## 用語

| 用語 | 意味 |
|---|---|
| KPI(重要業績評価指標) | 目標に近づいているかを測る指標 |
| funnel(ファネル、導線) | 認知から購入・登録までの段階的な流れ |
| monetization(収益化) | 発信から収入を得ること |
| media kit(メディアキット) | 企業向けに自分の発信をまとめた資料 |
| risk register(リスク登録簿) | 起こり得る問題と対策の一覧 |

## 初心者の読む順番

1. [目標・KPI](01-goals-kpi-roadmap.md) で、目的と指標を決める。
2. [調査方法](06-research-method.md) で、需要と差別化を調べる。
3. [導線設計](02-funnel.md) で、サービスの役割分担を決める。
4. [リスク登録簿](05-risk-register.md) で、乗っ取り対策などを先に済ませる。
5. 読者が付いてきたら、[収益化の計画](03-monetization-roadmap.md) → [税務](04-tax-and-business.md) → [消費税とインボイス](08-consumption-tax-and-invoice.md)。
6. 企業から相談が来たら、[案件とメディアキット](07-sponsorship-and-media-kit.md)。

## 意思決定の原則

1. **資産(読者・記事・書籍)を積む**: 仕様変更に左右されるプラットフォーム収益に依存しない。
2. **一次資料と信頼**: 解説・情報発信では**正確さ**が最大の差別化。
3. **小さく検証 → 拡大**: 1シリーズで型を作ってから展開。
4. **継続可能な頻度**: 燃え尽きを避ける。
5. **権利と配慮の遵守**: [legal-compliance](../01-common/legal-compliance.md)、[sensitive-topics](../01-common/sensitive-topics-and-accuracy.md)

# サービス間の導線設計

> **このページで分かること**: funnel(ファネル、導線)の考え方、各サービスの役割分担、導線の作り方の手順と具体例、どこで離脱しているかの見つけ方。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [目標・KPI・ロードマップ](01-goals-kpi-roadmap.md)、[サービスの選び方](../01-common/choosing-platforms.md)

## 概要

funnel(ファネル)は「漏斗(じょうご)」の意味です。多くの人に知ってもらい(認知)、その一部が興味を持ち(関心)、さらに一部が信頼して(信頼)、最後に一部が購入や登録をする(行動)、という**段階ごとに人数が減っていく流れ**を表します。

導線設計とは、この流れを**意図して作る**ことです。各サービスには得意な役割があるため、1つのサービスですべてを済ませるより、**入口・深掘り・収益の場所を分けてつなぐ**ほうが安定します(⚪ 一般論)。

```
認知(多い) ▶ 関心 ▶ 信頼 ▶ 行動(少ない)
X・Instagram・TikTok   note・YouTube 長尺   メール・LINE   有料記事・商品
```

## 用語

| 用語 | 意味 |
|---|---|
| funnel(ファネル、導線) | 認知から購入・登録までの段階的な流れ |
| CTA / call to action(行動喚起) | 「プロフィールのリンクから読めます」など、次の行動を促す一文 |
| landing page(ランディングページ、着地ページ) | リンクをクリックした人が最初に着くページ。例: note の「はじめに」記事 |
| link in bio(プロフィールリンク) | プロフィール欄に置くリンク。Instagram では投稿本文のリンクがクリックできないため重要 |
| UTM パラメータ | URL の末尾に付けて「どこから来たか」を計測する文字列 |
| owned media(オウンドメディア、自前の媒体) | メール・自サイトなど、自分で管理できる媒体。規約変更の影響を受けにくい |
| 離脱 | 次の段階に進まずに去ること |

## 役割分担

| サービス | 役割 | 強み | 手放す前提 |
|---|---|---|---|
| X | 入口・拡散・交流 | 速報性、会話 | 投稿は流れる。資産にならない |
| Instagram | ビジュアルの世界観・保存 | 画像、カルーセル、ハイライト | 外部リンクの制約 |
| note | 深掘り・資産・収益 | 長文、有料販売 | 拡散は他媒体頼み |
| (将来)メール/自サイト | 自前の資産 | 仕様変更に強い | 立ち上げ・運用の手間 |
| YouTube(⚪) | 深掘り・検索からの流入 | 長尺動画が検索で長く見られる | 制作の手間が大きい |
| TikTok・Shorts・リール(⚪) | 新しい人への露出 | おすすめ表示で未フォロー層に届く | 短い。深い説明は別の場所へ |
| LINE 公式アカウント(⚪) | 再来訪・お知らせ | 通知が届きやすい | 配信数に応じて費用([料金](../40-pricing/04-other-services.md)) |

## 導線の設計

```
X/IG の投稿 ──(プロフィールのリンク・固定投稿)──▶ note の入口記事(目次)
                                                    │
                      ┌──────────────────────────────┤
                      ▼                              ▼
                 無料記事で信頼               有料記事/メンバーシップ
                      │
                      ▼
              メール登録(将来)→ 電子書籍/講座の案内
```

## 手順: 導線を作る

1. **ゴールを1つ決める**。例: 「note の有料記事を買ってもらう」「LINE 公式アカウントに登録してもらう」。
2. **着地ページを作る**。リンク先は商品ページそのものではなく、「自己紹介+おすすめ記事+商品の案内」をまとめた**入口記事**にします。初めての人でも迷いません。
3. **プロフィールを揃える**。名前・肩書・一言・リンクを全サービスで統一します。
4. **固定投稿を置く**。X は自己紹介と目次の投稿を固定し、Instagram はハイライトに同じ内容を置きます。
5. **投稿ごとに CTA を1つだけ入れる**。「保存して」「プロフィールから続きへ」など、1投稿1つにします。
6. **計測を仕込む**。リンクに UTM パラメータを付けるか、サービスの分析画面で流入元を確認できるようにします([プロフィールリンクと UTM](../01-common/link-in-bio-and-utm.md))。
7. **月1回、段階ごとの数字を並べて離脱箇所を探す**(下の計算例)。

## 具体策

1. **プロフィール**: 3サービスで表記を統一(名前・肩書・一言・リンク)。リンクは note の「はじめに」記事へ。
2. **固定投稿**: X に自己紹介と目次、Instagram はハイライトで同じ内容。
3. **再利用**: 1題材を X(要点)→ IG(図解)→ note(詳細)へ展開([posting-workflow](../01-common/posting-workflow.md))。
4. **誘導の頻度**: 投稿の1〜2割に抑える。売り込みが続くと離脱(⚪ 経験則)。
5. **UTM パラメータ**: 計測できる環境なら、リンクに流入元を付ける(⚪)。
6. **自前の資産化**: メール(メルマガ)やサイトを早めに用意。プラットフォーム障害・規約変更の備え([ニュースレター・メール](../01-common/newsletter-and-email.md))。

### UTM パラメータの例(⚪ 一般的な書式)

```
https://example.com/start?utm_source=instagram&utm_medium=social&utm_campaign=profile
```

| パラメータ | 意味 | 記入例 |
|---|---|---|
| `utm_source` | 流入元のサービス | `x`、`instagram`、`youtube` |
| `utm_medium` | 媒体の種類 | `social`、`email` |
| `utm_campaign` | 施策名 | `profile`、`launch_recipe_book` |

- 計測には、リンク先が UTM を読み取れる分析ツールを使っている必要があります。note など一部のサービスでは UTM の結果を直接見られない場合があります(⚪ 要確認)。
- 表記ゆれ(`X` と `x`)があると別々に集計されるため、**小文字で統一**します。

## 具体例(架空)

### 例1: 料理アカウント(Instagram → note)

| 段階 | 場所 | 内容 |
|---|---|---|
| 認知 | Instagram リール | 30秒の作り置き手順 |
| 関心 | Instagram カルーセル | 材料と手順を5枚で図解(保存を促す) |
| 信頼 | note の無料記事 | 1週間の作り置き献立と買い物リスト |
| 行動 | note の有料記事 | 1か月分の献立集 |

### 例2: イラストアカウント(X → 支援サイト・販売)

| 段階 | 場所 | 内容 |
|---|---|---|
| 認知 | X | 完成イラストとタイムラプス |
| 関心 | X の固定投稿 | 作品一覧と依頼・販売の案内 |
| 信頼 | 制作過程の連載 | ラフ → 線画 → 仕上げの解説 |
| 行動 | 支援サイト・販売サイト | 高解像度データ、素材集([創作支援](../10-creator-economy/01-fan-club.md)) |

### 例3: 地域の店(Instagram・LINE → 来店)

| 段階 | 場所 | 内容 |
|---|---|---|
| 認知 | Instagram・Google の店舗情報 | 新商品の写真 |
| 関心 | Instagram ストーリーズ | 今日の入荷、営業時間 |
| 信頼 | LINE 公式アカウント | 登録者向けのお知らせ |
| 行動 | 来店・予約 | 予約ページ |

## 流入元ごとの指標

| 経路 | 見る指標 |
|---|---|
| X → note | note の流入元(X)、リンククリック |
| IG → note | プロフィールリンククリック(インサイト) |
| note → 購入 | 購入率、無料→有料の離脱箇所 |

詳しくは [analytics-kpi](../01-common/analytics-kpi.md)。

### 離脱箇所の見つけ方(計算例。数値は架空 ⚪)

| 段階 | 人数・回数 | 前の段階からの割合 |
|---|---|---|
| 投稿のリーチ | 20,000 | — |
| プロフィールアクセス | 400 | 2% |
| リンククリック | 80 | 20% |
| 入口記事の閲覧 | 70 | 88%(読み込み前に戻る人がいる) |
| 有料記事の購入 | 2 | 約3% |

- 割合が**極端に低い段階**が改善対象です。上の例ならプロフィールアクセス(2%)とリンククリック後の購入(約3%)が候補です。
- 改善は1回に1か所だけ変えます。複数を同時に変えると、何が効いたか分かりません。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| リンク先がサービスごとにバラバラ | 入口記事を1つ作り、全サービスのリンクをそこへ集める |
| 毎回の投稿で商品を宣伝する | 誘導は投稿の1〜2割に抑え、残りは役に立つ投稿にする |
| リンク先が商品ページで、初めての人が離脱 | 自己紹介と無料記事を挟む |
| 1つのサービスだけに依存 | メール・LINE など自前で連絡できる手段を早めに用意 |
| 計測しないまま改善する | まず流入元が分かる状態にする |

## 注意点

- Instagram の投稿本文のリンクはクリックできない、などのサービスごとの制約があります。最新の仕様は各サービスのページを確認してください([Instagram の投稿](../03-instagram/02-posting.md))。
- 広告・アフィリエイトのリンクを含む場合は、**広告であることの表示**が必要です([法令](../01-common/legal-compliance.md))。

# 消費税とインボイス制度の基礎

> **このページで分かること**: 個人の SNS 運用者が消費税を納める必要があるかの判断の基本(1,000万円の基準、基準期間)、インボイス制度と登録の考え方、2割特例・3割特例・簡易課税の概要。
>
> **対象**: 初心者(案件の報酬や販売の売上がある人)  **先に読むページ**: [個人の収益と税務・事業の基礎](04-tax-and-business.md)

> **一般的な整理です。登録するかどうかなど個別の判断は、税務署・税理士に相談してください。** ✅ は国税庁ページ(「2026年(皇紀2686年・令和8年)4月1日現在法令等」など)を 2026-11-03 に確認したものです。インボイス制度は改正が続いているため、判断の前に最新のページを確認してください。

## 概要

消費税は、売上に含まれる消費税から、仕入れ・経費で払った消費税を差し引いて納める税です。ただし、**売上が小さい事業者は納める義務が免除**されます(免税事業者)。

インボイス制度は、取引先(買手)が消費税の控除を受けるために「インボイス(適格請求書)」が必要になる制度です。インボイスを発行するには登録が必要で、**登録すると免税事業者ではなくなり、消費税の申告が必要**になります。

SNS 運用者が関係しやすい場面は、**企業から案件の報酬を受け取るとき**です。企業から「登録番号はありますか」と聞かれることがあります。

## 用語

| 用語 | 意味 |
|---|---|
| 課税売上高 | 消費税がかかる売上の合計(税抜) |
| 免税事業者 | 消費税の納税義務が免除されている事業者 |
| 課税事業者 | 消費税を申告・納税する事業者 |
| 基準期間 | 納税義務を判定するために見る期間。個人は**前々年** |
| 特定期間 | 個人は**前年の1月1日から6月30日まで** |
| インボイス(適格請求書) | 登録番号や税率・税額など決まった項目を書いた請求書・領収書 |
| インボイス発行事業者(適格請求書発行事業者) | 登録を受け、インボイスを発行できる事業者 |
| 仕入税額控除 | 買手が、支払った消費税を自分の納税額から差し引くこと |
| 簡易課税 | 売上の消費税に「みなし仕入率」を掛けて納税額を計算する方法 |

## 1. 消費税を納める必要があるか(✅ [No.6501](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6501.htm))

| 項目 | 内容 | 確度 |
|---|---|---|
| 免除の原則 | 基準期間の課税売上高が **1,000万円以下**なら、原則として納税義務が免除される | ✅ |
| 基準期間 | 個人事業者は**その年の前々年** | ✅ |
| 特定期間の判定 | 基準期間が1,000万円以下でも、特定期間(前年1月1日〜6月30日)の課税売上高が **1,000万円を超える**と免除されない(給与等支払額で判定することも可) | ✅ |
| インボイス登録との関係 | 登録を受けている場合は、1,000万円以下でも**納税義務は免除されない** | ✅ |

**判定の例(架空)**: 2026年の課税売上高が 1,000万円を超えた場合、その2年後の 2028年(皇紀2688年・令和10年)が課税事業者の候補になります(基準期間 = 前々年)。また 2027年の1〜6月の売上(特定期間)も確認します。

## 2. インボイス制度(✅ [国税庁 制度の概要](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice_about.htm))

| 項目 | 内容 | 確度 |
|---|---|---|
| 開始日 | **2023年(皇紀2683年・令和5年)10月1日** | ✅ |
| 発行の条件 | インボイスを交付するには、事前にインボイス発行事業者の**登録**が必要。登録すると課税事業者として申告が必要 | ✅ |
| 記載事項 | ①交付先の氏名・名称 ②売手の氏名・名称と**登録番号** ③取引年月日 ④取引内容(軽減税率の対象品目である旨) ⑤税率ごとの対価の合計と適用税率 ⑥税率ごとの消費税額等 | ✅ |
| 書類の名称 | 名称は問わない。所定の事項が書かれていればインボイスになる | ✅ |
| 買手側 | 仕入税額控除を受けるには、原則としてインボイスの保存が必要 | ✅ |
| 登録番号の形式 | 「T」+ 13桁の数字とする解説が多い | ⚪ 要確認 |

### 免税事業者から仕入れた買手の経過措置(✅ [令和8年度改正の特集](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm))

インボイスがない取引でも、買手は一定の割合を控除できます。この割合が下がるほど、**免税事業者に依頼する企業側の負担が増えます**。

| 期間 | 控除できる割合 |
|---|---|
| 2023年10月1日から3年間 | 80% |
| 2026年10月1日から2年間 | 70% |
| 2028年10月1日から2年間 | 50% |
| 2030年(皇紀2690年・令和12年)10月1日から1年間 | 30% |
| 2031年(皇紀2691年・令和13年)10月1日以降 | 0% |

## 3. 登録した人の負担を軽くする特例

| 特例 | 内容 | 確度 |
|---|---|---|
| **2割特例** | 免税事業者がインボイス登録で課税事業者になった場合などに、**納付税額を売上の消費税額の2割**とできる。2023年10月1日から **2026年9月30日まで**の日の属する課税期間に適用。個人は令和5年分(10〜12月)〜令和8年分 | ✅ [2割特例](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice_2tokurei.htm) |
| **3割特例** | インボイス登録で免税事業者から課税事業者になった**個人事業者**が、**2027年(皇紀2687年・令和9年)分と 2028年分**の申告で、納付税額を売上税額の3割とできる(法人は不可。基準期間の課税売上高 1,000万円以下などの要件) | ✅ [改正特集](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm) |
| **簡易課税** | 基準期間の課税売上高 **5,000万円以下**で、適用を受けたい課税期間の初日の前日までに届出。サービス業は第5種でみなし仕入率 **50%** | ✅ [No.6505](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6505.htm) |

- 2割特例を適用した翌課税期間から簡易課税に移る場合は、届出の期限に特例があります(✅ 2割特例のページ)。
- SNS 運用の報酬が第何種事業に当たるかは、取引の内容によります(⚪ 税務署に確認)。

### 計算例(架空。国税と地方消費税を合わせた単純化した計算 ⚪)

前提: 1年間の課税売上高(税抜)300万円、消費税率 10% → 売上の消費税額 30万円。

| 方法 | 計算 | 納付額の目安 |
|---|---|---|
| 2割特例 | 30万円 × 20% | **6万円** |
| 3割特例 | 30万円 × 30% | **9万円** |
| 簡易課税(第5種) | 30万円 −(30万円 × 50%) | **15万円** |

実際の計算(端数処理、税率ごとの区分など)は申告書の手引きや税理士に確認してください。

## 4. 登録するかどうかの考え方(⚪ 判断は専門家へ)

| 状況 | 検討のポイント |
|---|---|
| 取引先が主に**企業**(案件、寄稿) | 企業がインボイスを求めるか確認。登録しない場合、報酬の条件が変わる可能性がある |
| 売上が主に**一般の読者**(有料記事、グッズ) | 読者は仕入税額控除をしないことが多く、インボイスを求められにくい。ただし販売プラットフォーム経由の取引の扱いはサービスごとに確認 |
| 売上が 1,000万円に近い | 登録しなくても課税事業者になる可能性がある(上の判定) |

- 登録の手続きは「適格請求書発行事業者の登録申請書」で行います。免税事業者は登録希望日を書いて提出します(✅ [No.2090](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2090.htm))。
- **登録すると氏名と登録番号が国税庁の公表サイトで公開されます**(⚪ 要確認。公開範囲と、屋号・住所の扱いを確認)。

## 5. 海外サービスへの支払い・受け取り(⚪ 要確認)

海外の AI・ツールへの支払い、海外プラットフォームからの収益は、消費税の扱い(リバースチャージ方式など)や源泉税の手続きが関係する場合があります。金額が大きくなる前に税理士に相談してください。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 「今年の売上」で納税義務を判断する | 個人は**前々年**(基準期間)と前年前半(特定期間)で判断 |
| 登録したのに消費税の申告を忘れる | 登録すると売上が小さくても申告が必要 |
| 請求書に登録番号・税率・税額を書いていない | 記載事項6項目を雛形に入れる([メディアキット雛形](../../templates/media-kit.md) の請求欄) |
| 価格を税込/税抜のどちらで出したか曖昧 | 見積書・請求書に「税込」「税抜」を明記 |

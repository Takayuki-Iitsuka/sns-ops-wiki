# 競合・市場の調査方法

> **このページで分かること**: 自分の分野の発信者(競合)や読者の需要を調べる手順、調査シートの書き方、調べた結果から仮説を立てて小さく検証する方法。
>
> **対象**: 初心者(何を投稿すればよいか迷っている人)  **先に読むページ**: [目標・KPI・ロードマップ](01-goals-kpi-roadmap.md)、[企画の立て方](../01-common/content-planning.md)

> 他人のアカウントを**批評・攻撃する目的ではなく、市場の理解と差別化のため**に行う。調査結果の公開は、個人を特定・揶揄する形にしない。

## 概要

調査の目的は2つです。

1. **需要を知る**: 読者が何を知りたがっているか、どんな形式が好まれているか。
2. **差別化を見つける**: 他の発信者がまだ十分に扱っていない切り口(空白領域)はどこか。

調査は最初に1回やれば終わりではありません。**最初に2〜3時間、その後は月1回30分**程度の見直しを続けるのが現実的です(⚪ 経験則)。

## 用語

| 用語 | 意味 |
|---|---|
| benchmark(ベンチマーク、比較対象) | 参考にするアカウントや指標 |
| competitor(競合) | 同じ読者に向けて発信している人・アカウント |
| white space(空白領域) | 需要がありそうなのに、扱う人が少ない題材・形式 |
| hypothesis(仮説) | 「〜すれば〜になるはず」という検証前の考え |
| social listening(ソーシャルリスニング) | SNS 上の話題・声を継続して集めること([詳細](../01-common/social-listening.md)) |
| search suggestion(検索候補、サジェスト) | 検索窓に文字を入れると出る候補。よく検索される言葉の手がかり |

## 手順

1. **検索**: 各サービスで自分の分野のキーワードを検索し、上位の発信者を10件程度リストアップ。
2. **分類**: 形式(解説・イラスト・漫画・レビュー・考察)、頻度、反応の傾向を記録。
3. **強み・弱みの整理**: 内容の正確性、図解の質、導線、収益化の方法。
4. **空白領域**: 競合が少ないが需要がありそうな題材を探す(⚪ 仮説として扱い、小さく投稿して検証)。
5. **仮説の検証**: 小さく投稿して反応を見る。

### 各手順のコツ

| 手順 | コツ |
|---|---|
| 1. 検索 | キーワードは「分野名」だけでなく「分野名 + 初心者」「分野名 + やり方」など、読者が困っている言葉も試します。サービスごとに検索結果が違うので、X・Instagram・YouTube・note など複数で調べます |
| 2. 分類 | 反応の数字を写すのではなく、「高い/普通/低い」の3段階で記録します |
| 3. 整理 | 「自分ならどう改善するか」を1行書くと、企画のネタになります |
| 4. 空白 | コメント欄の質問(「〜はどうするの?」)は、まだ答えられていない需要の手がかりです |
| 5. 検証 | 1つの仮説につき、同じ条件で3〜5投稿試してから判断します |

## 需要を調べる方法(⚪)

| 方法 | 見るもの | 注意 |
|---|---|---|
| 各サービスの検索 | 上位の投稿、関連キーワード、ハッシュタグの投稿数の傾向 | 表示は人によって変わる(個人に合わせた表示) |
| 検索エンジンの検索候補 | 「分野名 + 何」と一緒に検索される言葉 | 地域・時期で変わる |
| コメント・質問 | 競合や自分の投稿に来た質問 | 個人名は記録しない |
| 自分のインサイト | 保存・共有が多い投稿、検索からの流入 | 少数の投稿で決めつけない |
| 書籍・雑誌・公式情報 | 分野の定番の話題 | 正確さの確認にも使う |

### 記入例(架空: 料理分野の調査)

| 項目 | 記入 |
|---|---|
| アカウント(公開の名称) | (例)作り置きの解説をしている A さん |
| 形式 | Instagram カルーセル(手順を5〜7枚で図解) |
| 頻度 | 週4回程度 |
| 反応の傾向(高低のみ) | 保存が多い。コメントは少なめ |
| 強み | 材料と手順が1枚で分かる。色使いが統一されている |
| 弱み/空白 | 「1人分」「冷凍の日数」の情報が少ない |
| 収益化の方法(公開情報から) | プロフィールからレシピ本の紹介(PR 表記あり) |
| 学べる点 | 1枚目に完成写真と「何分でできるか」を置く型 |

→ この例から立てる仮説: 「1人分・冷凍保存の目安を入れたカルーセルは、保存率が上がる」。

## 仮説の立て方と検証(⚪)

| 項目 | 書き方 | 例 |
|---|---|---|
| 仮説 | 「〇〇にすると、△△が上がる」 | 1枚目に所要時間を書くと、保存率が上がる |
| 変える点 | **1つだけ** | 1枚目の文言 |
| 変えない点 | 投稿時間・形式・題材の系統 | 平日19時、カルーセル5枚 |
| 期間・本数 | 2〜3週間、3〜5投稿 | 3週間で4投稿 |
| 判断基準 | 何がどうなれば「当たり」か | 直近の平均より保存率が明らかに高い |
| 結果 | 月次レビューに記録 | [月次レビュー](../../templates/monthly-review.md) |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 人気アカウントの投稿をそのまま真似る | 「型」(構成・順番)だけを学び、題材・文章・画像は自分で作る |
| 調査に時間をかけすぎて投稿しない | 調査は時間を区切る(最初は2〜3時間) |
| 数字の大きいアカウントだけ見る | 自分と近い規模のアカウントも見る。始め方の参考になる |
| 1回の反応で結論を出す | 3〜5投稿の傾向で判断する |
| 他人を批判する投稿にしてしまう | 調査結果は自分の企画に使う。公開で比較・批評しない |

## 注意

- **公開情報のみ**を使う。ログイン必須の情報や、非公開アカウントは対象外。
- 数値を転載せず、傾向をメモする。
- 画像・文章の**模倣はしない**。構成の「型」を学び、題材と表現は独自にする。
- 調査にツールを使う場合は各サービスの規約(スクレイピング禁止の有無)を確認([10-policies](../02-x/10-policies.md))。

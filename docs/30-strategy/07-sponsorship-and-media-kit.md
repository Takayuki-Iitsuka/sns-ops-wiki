# 案件(スポンサー)とメディアキット

> **このページで分かること**: 企業からの案件(タイアップ)を受けるまでの流れ、メディアキット(媒体資料)の作り方、料金の考え方と計算例、契約の確認事項、PR 表記、納品後の報告と請求。
>
> **対象**: 初心者〜中級者(初めて案件の相談が来た人、受ける準備をしたい人)  **先に読むページ**: [収益化の段階的な計画](03-monetization-roadmap.md)、[法令](../01-common/legal-compliance.md)

企業からの案件を受ける際の準備と契約の確認事項です(⚪ 一般論。個別の契約は専門家へ #63)。

## 概要

案件とは、企業から依頼を受け、報酬や商品提供の対価として商品・サービスを紹介する投稿です。受ける前に次の3つを用意すると、やり取りがスムーズになり、トラブルも防げます。

1. **メディアキット**: 自分の発信の特徴をまとめた資料。
2. **料金の基準**: 自分の制作時間から考えた見積りの方法。
3. **確認事項のリスト**: 契約前に確認すること(下のチェックリスト)。

また、**広告であることを隠した投稿(ステマ)は、2023年(皇紀2683年・令和5年)10月1日から景品表示法違反**になっています(✅ [消費者庁](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/))。PR 表記は必ず付けます。

## 用語

| 用語 | 意味 |
|---|---|
| media kit(メディアキット、媒体資料) | 発信者の特徴・読者像・実績・料金の目安をまとめた資料 |
| tie-in / sponsored post(タイアップ、案件) | 企業の依頼で作る紹介投稿 |
| CPM / cost per mille(1,000回表示あたりの単価) | 広告の価格を表示1,000回あたりで表す方法 |
| engagement rate(エンゲージメント率) | 反応の数 ÷ 表示回数(またはリーチ)。定義は [KPI](01-goals-kpi-roadmap.md) |
| secondary use(二次利用) | 企業が投稿や素材を自社の広告・サイトなどで使うこと |
| exclusivity(競合排除) | 一定期間、同業他社の案件を受けない約束 |
| 源泉徴収 | 支払う側が報酬から所得税を差し引く仕組み([税務](04-tax-and-business.md)) |
| invoice(インボイス、適格請求書) | 登録番号などを記載した請求書([消費税とインボイス](08-consumption-tax-and-invoice.md)) |

## 案件の流れ(⚪ 一般的な順序)

1. **問い合わせを受ける**: DM・メールで依頼が届きます。企業名・担当者・連絡先が確認できるか見ます(なりすましに注意)。
2. **内容を聞く**: 商品、目的、投稿の種類・本数、期間、予算、PR 表記の方法を聞きます。
3. **受けるか判断する**: 下の「案件を受けるかの基準」で判断します。
4. **見積りを出す**: 下の料金の考え方で計算し、見積書を出します(税込/税抜を明記)。
5. **契約する**: 契約書・発注書で条件を文書に残します。
6. **制作・確認**: 下書きを企業に確認してもらいます(修正回数を事前に決める)。
7. **公開**: PR 表記を付けて投稿します。
8. **報告**: 指標をまとめて報告します。
9. **請求・入金確認**: 請求書を送り、入金を確認して記録します。

### 問い合わせへの返信例(架空)

```
お問い合わせありがとうございます。〇〇(アカウント名)です。
ご依頼内容を検討するため、次の点を教えていただけますか。
1. 紹介する商品・サービスと、投稿の目的
2. 投稿先(Instagram / X など)、形式、本数、公開希望日
3. ご予算の目安、二次利用の有無
4. PR 表記の方法(「PR」表記とサービスの表示機能を使う予定です)
媒体資料を添付します。よろしくお願いいたします。
```

## 1. メディアキット(媒体資料)

案件を依頼する側が知りたい情報を、**1〜2ページ**にまとめます。雛形: [templates/media-kit.md](../../templates/media-kit.md)。

| 項目 | 内容 |
|---|---|
| 自己紹介 | 発信テーマ、強み、実績 |
| 読者像 | 年齢層・地域・関心(インサイトの傾向。実数は公開しない) |
| 成果の目安 | 平均リーチ・エンゲージ率の**範囲**(桁と傾向) |
| 提供メニュー | 投稿の種類(X、Instagram、note、YouTube)、本数、期間 |
| 実績 | 過去の案件(許可を得て)、掲載・受賞 |
| 条件 | 修正回数、納期、PR 表記、二次利用、競合排除 |
| 料金 | 目安・見積りの方法 |
| 連絡先 | 窓口、請求書の発行(インボイス登録の有無) |

- **公開リポジトリには実数・顧客名を書かない**。非公開で作成([CONTRIBUTING](../../CONTRIBUTING.md))。
- 企業に渡すメディアキットには実数を書いてよいですが、**いつ時点の数字か**を必ず書きます(数字は変わるため)。

## 2. 料金の考え方(⚪)

| 要素 | 内容 |
|---|---|
| 制作工数 | 企画・撮影・編集・修正の時間 × 時給 |
| 露出(リーチ・インプレッション) | 1,000回あたりの単価(CPM)の考え方 |
| 反応(エンゲージメント・クリック) | 質の高い読者へのリーチ |
| 二次利用 | 企業が広告で使う権利(期間・媒体)は**別料金** |
| 独占・競合排除 | 同業他社の案件を断る期間は**加算** |
| 緊急・短納期 | 加算 |
| 成果報酬 | アフィリエイト等([04-affiliate](../10-creator-economy/04-affiliate.md)) |

- 市場の相場は変動する。複数の案件の見積りを記録し、自分の基準を作る。

### 見積りの計算例(数値はすべて架空 ⚪)

| 方法 | 計算 | 結果 |
|---|---|---|
| 工数から | (企画 2時間 + 撮影 3時間 + 編集 3時間 + 修正 2時間)× 時給 2,000円 | 20,000円 |
| 露出から | 想定表示回数 10,000回 ÷ 1,000 × 仮の単価 1,500円 | 15,000円 |
| 加算 | 二次利用 3か月 +30%、競合排除 1か月 +20% を工数の額に加算 | 20,000 × 1.5 = 30,000円 |

- 2つの方法で出した額のうち**高い方を基準**にし、加算を足す、などの自分のルールを決めます。
- 見積書には「**税抜 30,000円(消費税 3,000円)**」のように税抜・税額を分けて書くと、源泉徴収の計算が明確になります(✅ [国税庁 No.2795](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm): 報酬と消費税額が明確に区分されていれば報酬額のみが源泉徴収の対象)。

## 3. 契約の確認項目(チェックリスト)

- [ ] 成果物(投稿の種類・本数・形式・素材)
- [ ] 納期、修正回数、承認フロー
- [ ] **PR 表記**(「PR」「広告」を契約に明記。ステマ対策 ✅ [legal-compliance](../01-common/legal-compliance.md))
- [ ] 紹介内容の根拠(効果効能の表現。企業の資料と法令)
- [ ] **著作権の帰属**(制作物、画像、動画)と二次利用の範囲・期間
- [ ] 肖像権・商標の使用許諾
- [ ] 競合排除(期間・範囲)
- [ ] 報酬(金額、支払期日、振込手数料、源泉徴収の有無)
- [ ] 請求書・インボイスの要否
- [ ] キャンセル・延期時の取り扱い
- [ ] 公開後の削除・修正の要求への対応
- [ ] 守秘義務
- [ ] 個人情報の取り扱い
- [ ] トラブル時の連絡窓口
- [ ] 表示機能(X の `paid_partnership` ✅、Instagram の有料パートナーシップ表示 ✅、YouTube の有料プロモーション開示 ⚪)

## 4. PR 表記の運用

| サービス | 表記・機能 |
|---|---|
| X | 本文の冒頭に「PR」。API では `paid_partnership: true` ✅ |
| Instagram | 有料パートナーシップ表示。API は `is_paid_partnership`(Facebook ログイン経由)✅ |
| YouTube | 有料プロモーションの開示(動画の設定)⚪ |
| TikTok | ブランドコンテンツのスイッチ ⚪ |
| note・ブログ | 記事冒頭に「PR」 |

「#PR」を大量のハッシュタグの中に埋もれさせない([hashtags](../01-common/hashtags.md))。

| 良い例 | 悪い例 |
|---|---|
| 冒頭に「【PR】〇〇社から提供を受けて紹介します」 | 本文の最後に、ハッシュタグ20個の中に「#pr」 |
| 動画の冒頭の画面表示と説明文の両方に「PR」 | 説明文の「もっと見る」を開かないと見えない位置だけ |

## 5. 案件を受けるかの基準

- 自分の読者にとって**本当に価値があるか**(信頼を損なわない)。
- 自分で**使った/確認した**ものだけ紹介する。
- 医療・金融・投資・健康食品などは**法規制が厳しい**(薬機法・景品表示法・金融商品取引法など ⚪)。断る基準を決めておく。
- 「PR 表記をしないでほしい」と言われたら**受けない**(ステマ規制 ✅)。

## 6. 報告書(納品後)

| 項目 | 内容 |
|---|---|
| 投稿の URL・画像 | スクリーンショット |
| 指標 | インプレッション、エンゲージ、クリック(企業が求める範囲) |
| 所感・次回への提案 | 学び |

指標は**公開から何日後の数字か**(例: 7日後)を書きます。

## 7. 税務

報酬は収入として記録。源泉徴収・支払調書・インボイス([tax-and-business](04-tax-and-business.md)、[消費税とインボイス](08-consumption-tax-and-invoice.md))。原稿料などの源泉徴収は1回100万円以下なら 10.21%(✅ [No.2795](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm))。インボイスを求める企業もあるため、登録の有無をメディアキットに書いておきます(✅ [インボイス制度](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice_about.htm))。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 口頭や DM だけで条件を決める | 発注書・契約書・メールで条件を文書に残す |
| 修正回数を決めずに受け、作業が増え続ける | 「修正2回まで、以降は追加料金」などを事前に合意 |
| 二次利用を無料で許可してしまう | 期間・媒体を決めて別料金にする |
| 税込/税抜を書かずに見積もる | 見積書に必ず明記する |
| 怪しい依頼(先にお金を払わせる等)に応じる | 企業の実在・連絡先を確認し、先払いを求める依頼は断る |

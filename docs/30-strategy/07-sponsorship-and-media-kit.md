# 案件(スポンサー)とメディアキット

企業からの案件を受ける際の準備と契約の確認事項です(⚪ 一般論。個別の契約は専門家へ #63)。

## 1. メディアキット(媒体資料)

案件を依頼する側が知りたい情報を、**1〜2ページ**にまとめます。

| 項目 | 内容 |
|---|---|
| 自己紹介 | 発信テーマ、強み、実績 |
| 読者像 | 年齢層・地域・関心(インサイトの傾向。実数は公開しない) |
| 成果の目安 | 平均リーチ・エンゲージ率の**範囲**(桁と傾向) |
| 提供メニュー | 投稿の種類(X、Instagram、note、YouTube)、本数、期間 |
| 実績 | 過去の案件(許可を得て)、掲載・受賞 |
| 条件 | 修正回数、納期、PR 表記、二次利用、競合排除 |
| 料金 | 目安・見積りの方法 |
| 連絡先 | 窓口、請求書の発行(インボイス登録の有無) |

- **公開リポジトリには実数・顧客名を書かない**。非公開で作成([CONTRIBUTING](../../CONTRIBUTING.md))。

## 2. 料金の考え方(⚪)

| 要素 | 内容 |
|---|---|
| 制作工数 | 企画・撮影・編集・修正の時間 × 時給 |
| 露出(リーチ・インプレッション) | 1,000回あたりの単価(CPM)の考え方 |
| 反応(エンゲージメント・クリック) | 質の高い読者へのリーチ |
| 二次利用 | 企業が広告で使う権利(期間・媒体)は**別料金** |
| 独占・競合排除 | 同業他社の案件を断る期間は**加算** |
| 緊急・短納期 | 加算 |
| 成果報酬 | アフィリエイト等([04-affiliate](../10-creator-economy/04-affiliate.md)) |

- 市場の相場は変動する。複数の案件の見積りを記録し、自分の基準を作る。

## 3. 契約の確認項目(チェックリスト)

- [ ] 成果物(投稿の種類・本数・形式・素材)
- [ ] 納期、修正回数、承認フロー
- [ ] **PR 表記**(「PR」「広告」を契約に明記。ステマ対策 ✅ [legal-compliance](../01-common/legal-compliance.md))
- [ ] 紹介内容の根拠(効果効能の表現。企業の資料と法令)
- [ ] **著作権の帰属**(制作物、画像、動画)と二次利用の範囲・期間
- [ ] 肖像権・商標の使用許諾
- [ ] 競合排除(期間・範囲)
- [ ] 報酬(金額、支払期日、振込手数料、源泉徴収の有無)
- [ ] 請求書・インボイスの要否
- [ ] キャンセル・延期時の取り扱い
- [ ] 公開後の削除・修正の要求への対応
- [ ] 守秘義務
- [ ] 個人情報の取り扱い
- [ ] トラブル時の連絡窓口
- [ ] 表示機能(X の `paid_partnership` ✅、Instagram の有料パートナーシップ表示 ✅、YouTube の有料プロモーション開示 ⚪)

## 4. PR 表記の運用

| サービス | 表記・機能 |
|---|---|
| X | 本文の冒頭に「PR」。API では `paid_partnership: true` ✅ |
| Instagram | 有料パートナーシップ表示。API は `is_paid_partnership`(Facebook ログイン経由)✅ |
| YouTube | 有料プロモーションの開示(動画の設定)⚪ |
| TikTok | ブランドコンテンツのスイッチ ⚪ |
| note・ブログ | 記事冒頭に「PR」 |

「#PR」を大量のハッシュタグの中に埋もれさせない([hashtags](../01-common/hashtags.md))。

## 5. 案件を受けるかの基準

- 自分の読者にとって**本当に価値があるか**(信頼を損なわない)。
- 自分で**使った/確認した**ものだけ紹介する。
- 医療・金融・投資・健康食品などは**法規制が厳しい**(薬機法・景品表示法・金融商品取引法など ⚪)。断る基準を決めておく。

## 6. 報告書(納品後)

| 項目 | 内容 |
|---|---|
| 投稿の URL・画像 | スクリーンショット |
| 指標 | インプレッション、エンゲージ、クリック(企業が求める範囲) |
| 所感・次回への提案 | 学び |

## 7. 税務

報酬は収入として記録。源泉徴収・支払調書・インボイス([tax-and-business](04-tax-and-business.md))。

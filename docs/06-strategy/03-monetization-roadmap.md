# 収益化の段階的な計画

> **プラットフォームの収益化条件は未確認** (→ [要検証リスト](../00-meta/verification-queue.md))。条件を満たしても、**まずは自前の資産(記事・書籍)**で収益を作る設計にする。

## 収益源の一覧(古事記・日本書紀テーマ向け ⚪)

| 収益源 | 内容 | 立ち上げやすさ | 注意 |
|---|---|---|---|
| note 有料記事 | 連載の深掘り、原文解説 | 高 | 手数料・価格は #5, #6 |
| note メンバーシップ | 月額で限定記事・質問回答 | 中 | 更新負荷、解約率 |
| 電子書籍(Kindle 等) | 神名辞典、入門書 | 中 | 現代語訳は自作。校正・表紙 |
| 書籍紹介(アフィリエイト) | 読書ガイド・参考文献紹介 | 高 | 広告表記が必須 |
| 講座・オンライン読書会 | 原文読解の講座 | 中 | 告知・決済・著作権 |
| グッズ | 神名カード、ポスター、暦 | 中 | 素材の権利、在庫、規約 |
| 取材・ガイド | 神社巡りの案内 | 低 | 旅行業法に注意(下記) |
| 執筆・監修・寄稿 | 他媒体の記事 | 中 | 実績の積み上げ |
| プラットフォーム分配 | X・Instagram の収益プログラム | 条件次第 | 不安定。依存しない |

## 段階的な計画

| 段階 | 目安 | 施策 |
|---|---|---|
| S0 | 開始〜 | 無料で価値を積む。note で入口記事を整備 |
| S1 | 週次運用が定着 | 書籍紹介(広告表記) |
| S2 | 常連読者が出現 | note 有料記事(連載のまとめ) |
| S3 | 連載完結 | 電子書籍化、メンバーシップ |
| S4 | 読者基盤が安定 | 講座、グッズ、イベント |

## 価格設計の考え方(⚪)

- **成果物の明確さ**: 「何ページ/何回分」「テンプレ」「図解」で価値を示す。
- 低価格から試し、読者の反応で調整。値付けの上限・下限は note の規定を確認。
- 無料で**試し読み**(最初の1章)を出し、有料部分の価値を示す。

## 旅行業法・イベント(⚪ 要確認)

- 有料で神社巡りのツアーを募集・手配する行為は、**旅行業法の登録が必要となる場合**がある。実施前に観光庁・都道府県の窓口で確認。
- イベント開催は会場・保険・個人情報の取り扱いを確認。

## 広告・PR・アフィリエイト

- 書籍紹介などの成果報酬リンクは、**一目で分かる広告表記**(例: 文頭に「PR」)。[legal-compliance](../01-common/legal-compliance.md)
- Amazon アソシエイト等は**プログラム規約の表記ルール**がある(⚪ 要確認)。

# サービス間の導線設計

## 役割分担

| サービス | 役割 | 強み | 手放す前提 |
|---|---|---|---|
| X | 入口・拡散・交流 | 速報性、会話 | 投稿は流れる。資産にならない |
| Instagram | ビジュアルの世界観・保存 | 画像、カルーセル、ハイライト | 外部リンクの制約 |
| note | 深掘り・資産・収益 | 長文、有料販売 | 拡散は他媒体頼み |
| (将来)メール/自サイト | 自前の資産 | 仕様変更に強い | 立ち上げ・運用の手間 |

## 導線の設計

```
X/IG の投稿 ──(プロフィールのリンク・固定投稿)──▶ note の入口記事(目次)
                                                    │
                      ┌──────────────────────────────┤
                      ▼                              ▼
                 無料記事で信頼               有料記事/メンバーシップ
                      │
                      ▼
              メール登録(将来)→ 電子書籍/講座の案内
```

## 具体策

1. **プロフィール**: 3サービスで表記を統一(名前・肩書・一言・リンク)。リンクは note の「はじめに」記事へ。
2. **固定投稿**: X に自己紹介と目次、Instagram はハイライトで同じ内容。
3. **再利用**: 1題材を X(要点)→ IG(図解)→ note(詳細)へ展開([posting-workflow](../01-common/posting-workflow.md))。
4. **誘導の頻度**: 投稿の1〜2割に抑える。売り込みが続くと離脱。
5. **UTM パラメータ**: 計測できる環境なら、リンクに流入元を付ける(⚪)。
6. **自前の資産化**: メール(メルマガ)やサイトを早めに用意。プラットフォーム障害・規約変更の備え。

## 流入元ごとの指標

| 経路 | 見る指標 |
|---|---|
| X → note | note の流入元(X)、リンククリック |
| IG → note | プロフィールリンククリック(インサイト) |
| note → 購入 | 購入率、無料→有料の離脱箇所 |

詳しくは [analytics-kpi](../01-common/analytics-kpi.md)。

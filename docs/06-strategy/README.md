# 全体戦略(認知拡大と収益化)

個人が古事記・日本書紀をテーマに、X・Instagram・note を連携させて**認知拡大 → 信頼 → 収益化**へ進める戦略をまとめます。

## 全体像

```
[認知]  X(拡散) ・ Instagram(ビジュアル)
   ↓ プロフィール/固定投稿/ストーリーズ
[信頼]  note(深掘り) ・ 無料記事・原文解説
   ↓ メール/メンバーシップ/有料記事
[収益]  有料記事・電子書籍・講座・書籍紹介・グッズ
```

## 意思決定の原則

1. **資産(読者・記事・書籍)を積む**: 仕様変更に左右されるプラットフォーム収益に依存しない。
2. **一次資料と信頼**: 古典の解説では**正確さ**が最大の差別化。
3. **小さく検証 → 拡大**: 1シリーズで型を作ってから展開。
4. **継続可能な頻度**: 燃え尽きを避ける。
5. **権利と配慮の遵守**: [legal-compliance](../01-common/legal-compliance.md)、[09-sensitivity](../05-theme-kojiki/09-sensitivity.md)

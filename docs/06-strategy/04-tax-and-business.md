# 個人の収益と税務・事業の基礎

> **一般的な整理です。個別の判断は税務署・税理士へ。** 法令・数値は国税庁(https://www.nta.go.jp/)で最新を確認してください。

## 収益が出たら考えること

| 論点 | 概要(⚪ 要確認) |
|---|---|
| 所得区分 | 事業所得、雑所得など。継続性・規模・帳簿の有無で判断される |
| 確定申告 | 会社員の副業の所得が年20万円を超える場合などに必要となる、と一般に言われる。条件は国税庁で確認 |
| 開業届 | 事業として行う場合に提出。青色申告承認申請書と合わせて検討 |
| 青色申告 | 帳簿付けの要件を満たすと特典がある |
| 帳簿 | 売上・経費・領収書を継続して記録 |
| 消費税・インボイス | 売上規模により課税事業者になる。登録の判断は専門家へ |
| 住民税・社会保険 | 副業の扱いは勤務先・自治体で異なる場合あり |
| 就業規則 | 会社員は副業の可否を確認 |

## 経費になり得る例(⚪ 判断は専門家へ)

書籍(資料代)、通信費、ソフトウェア(フォント・編集)、取材交通費、機材。**事業との関連と按分**を記録。

## 記録の仕方

1. 売上: 入金日・サービス・金額・手数料を月次で記録。
2. 経費: 領収書・明細を保存。品目と用途を書く。
3. 公開リポジトリには**実額を書かない**。非公開の表計算で管理。

## プラットフォームからの支払い

- note、各社の収益は**支払調書・明細**の有無、源泉徴収の有無を各サービスの規約で確認(#5, #6)。
- 海外サービス経由の収益は、源泉税・税務書類(W-8BEN 等)の手続きがあり得る(⚪ 要確認)。

## 法的な表記

- 継続的な物販・有料サービスは、**特定商取引法に基づく表記**の要否を確認。個人の住所・電話番号の公開が課題になる場合、サービス側の代替手段を確認。
- 利用規約・プライバシーポリシーを自サイトで用意する場合は、雛形を専門家に確認。

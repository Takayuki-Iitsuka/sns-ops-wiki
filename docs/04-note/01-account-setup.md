# note 初期設定

> **このページで分かること**: note のアカウントを作ってから、最初の記事を出すまでに済ませておく設定と、その理由。
>
> **対象**: note をこれから始める初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[README(note の概要)](README.md)

## 概要

note(ノート)は、文章を中心に画像・音声・動画も載せられる、日本発のクリエイター向け発信サービスです。
X や Instagram のように「流れていく」投稿よりも、**あとから検索されて読まれ続ける記事**を積み上げるのに向いています。

初期設定で大事なのは次の3点です。

1. **誰が・何を書く場所か**が一目で分かるプロフィールにする。
2. **アカウントを乗っ取られない**ように守る(2段階認証)。
3. 有料販売をするなら、**お金の受け取り**と**法律上の表記**を先に確認する。

あとから変えにくい項目(note ID など)もあるため、最初に落ち着いて決めるのがおすすめです。

## 用語

| 用語 | 意味 |
|---|---|
| クリエイター名 | 画面に表示される名前。あとから変更しやすい(⚪) |
| note ID | `note.com/(ID)` の形で URL になる文字列。変更すると URL が変わる(⚪ 変更可否・影響は要確認) |
| クリエイターページ | 自分の記事一覧・プロフィールが並ぶページ |
| ヘッダー画像 | クリエイターページ上部の横長画像 |
| マガジン | 記事をまとめる「本棚」のような機能。連載やテーマ別の整理に使う |
| 2段階認証(2FA, two-factor authentication) | パスワードに加えて確認コードを求める仕組み。乗っ取り対策 |
| 特定商取引法に基づく表記 | 通信販売をする事業者が、氏名・連絡先などを表示する法律上のルール |

## 手順

アプリやブラウザの画面名・ボタン名は変わる可能性があります(⚪ 表記は要確認)。迷ったら [note ヘルプセンター](https://www.help-note.com/hc/ja) で機能名を検索してください。

### 1. アカウント登録

1. note のサイトまたはアプリを開き、会員登録を選びます。
2. メールアドレス、または外部アカウント連携で登録します(⚪ 連携できるサービスは要確認)。
3. **運用専用のメールアドレス**を使うのがおすすめです。個人用と分けると、担当の交代や通知の整理が楽になります。

### 2. クリエイター名と note ID を決める

- クリエイター名は「何の人か」が分かる名前にします。例: 「週末パン作りの○○」「地域の店 △△商店」。
- note ID は URL になります。**短く、読みやすく、他の SNS と揃える**のが基本です。
- ID を変更すると、過去に共有したリンクが切れる可能性があります(⚪ 要確認)。最初に決めたら変えない前提で選びます。

### 3. プロフィールを整える

| 項目 | 推奨 | 確度 |
|---|---|---|
| プロフィール画像 | 正方形で用意。小さく表示されても判別できる顔・ロゴ | ⚪ |
| 自己紹介文 | 誰向け・何を書く・実績・更新頻度・連絡先 | ⚪ |
| ヘッダー画像 | 比率 1.91:1、1280×670px を用意 | 🟡 [画像仕様](03-media-specs.md) |
| SNS リンク | X・Instagram など、活動中のアカウント | ⚪ |

自己紹介文の例(汎用):

```
週末に作るパンのレシピと、失敗から学んだコツを書いています。
初心者向けに「材料・道具・手順・失敗例」をセットで紹介します。
更新: 毎週土曜。お仕事の相談は X の DM へ。
```

### 4. セキュリティと通知

1. **2段階認証**を有効にします([アカウントのセキュリティ](../01-common/account-security.md))。
2. 通知・メールの受け取り設定を見直します。コメント通知は残し、宣伝メールは必要に応じて止めます。
3. SNS 連携(X など)の設定で、**記事公開時に自動投稿されるか**を確認します(⚪ 機能の有無・名称は要確認)。意図しない自動投稿を防ぐためです。

### 5. 有料販売をする場合の準備

| 項目 | 内容 | 確度 | 出典 |
|---|---|---|---|
| 売上の受け取り | 振込先口座の登録。前月末までの未振込売上が合計 1,000円以上で振込申請できる | 🟡 | [note ヘルプ(売上金を受け取る)](https://www.help-note.com/hc/ja/articles/360010430873) |
| 本人確認 | 必要な場面と手順は要確認 | ⚪ | #6 |
| 特定商取引法に基づく表記 | 有料販売では必要になる場合がある | ⚪ | [法令・表示](../01-common/legal-compliance.md) |

手数料や価格の範囲は [07-monetization](07-monetization.md) にまとめています。

## 設計(アカウントの方針)

| 項目 | 方針 | 確度 |
|---|---|---|
| テーマ | 1アカウント1テーマが読者に伝わりやすい | ⚪ |
| マガジン | 連載や話題別に記事をまとめる | ⚪ |
| 固定記事 | 自己紹介・目次記事をトップに置く | ⚪ |
| 更新頻度 | 無理なく続けられる頻度を先に決める(例: 週1) | ⚪ |

## 具体例

| 良い例 | 悪い例 |
|---|---|
| 名前・ID・アイコンが X と同じで、同じ人だと分かる | SNS ごとに名前もアイコンもばらばら |
| 自己紹介に「誰向け・何が読める・更新日」 | 「よろしくお願いします」だけ |
| 最初に「はじめに」記事を書いて固定 | 記事が増えても入口がなく、読者が迷う |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 個人用メールで登録し、通知に埋もれる | 運用専用メールに変更する(変更手順は公式ヘルプで確認 ⚪) |
| ID を思いつきで決め、後で変えたくなる | 変更前に、過去のリンクがどうなるかを公式で確認する |
| 2段階認証をせず乗っ取られる | すぐ設定。復旧手順は [危機対応](../01-common/crisis-response.md) |
| 有料記事を出してから振込先がないことに気づく | 販売前に口座登録と振込条件を確認する |

## 注意点

- パスワードや確認コードは他人に教えません。共同運用は共有アカウントではなく、権限を分けられる仕組みがあるかを確認します(⚪)。
- 住所・電話番号などの個人情報をプロフィールに書かないでください([個人情報](../01-common/privacy-and-personal-info.md))。

## チェックリスト

# note 初期設定

## 手順チェックリスト

1. **アカウント登録**: メールまたは外部アカウント連携。運用専用メールを推奨。
2. **クリエイター名・note ID**: ID は URL になるため、変更可否・影響を確認 ⚪。
3. **プロフィール画像**: 正方形。
4. **自己紹介**: 誰向け・何を書く・実績・連絡先。
5. **クリエイターページのヘッダー画像**: 比率 1.91:1、1280×670 を用意 🟡 → [03-media-specs](03-media-specs.md)
6. **SNS 連携**: X 等のアカウントを連携し、公開時の自動投稿などの設定を確認 ⚪
7. **2段階認証**: [account-security](../01-common/account-security.md)
8. **通知・メール設定**
9. **収益受け取りの設定**（有料販売をする場合）: 本人確認、振込先 ⚪ #6
10. **特定商取引法に基づく表記**: 有料販売では必要になる場合がある ⚪ [legal](../01-common/legal-compliance.md)

## 設計

| 項目 | 方針 |
|---|---|
| テーマ | 1アカウント1テーマが読者に伝わりやすい（⚪） |
| マガジン | 連載や話題別に記事をまとめる |
| 固定記事 | 自己紹介・目次記事をトップに ⚪ |

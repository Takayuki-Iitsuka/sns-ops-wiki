# note 投稿ルート

> **このページで分かること**: note で記事を書いて公開するまでの手順、マガジンの作り方、有料記事・メンバーシップの基本的な流れ。
>
> **対象**: 初心者  **先に読むページ**: [01-account-setup](01-account-setup.md)

## 概要

note の投稿は、現在は**「記事」に一本化**されつつあります。
以前はテキスト・画像・つぶやき・音声・動画の5種類から選ぶ方式でしたが、「どれを選べばよいか分かりにくい」という声を受けて、2025年(皇紀2685年・令和7年)5月29日から段階的に統合されました(🟡 [投稿形式の統合について](https://www.help-note.com/hc/ja/articles/47459837469081))。

| 時期 | 変更 | 確度 |
|---|---|---|
| 2025年5月29日〜 | 投稿形式の統合を開始 | 🟡 |
| 2025年6月9日 | 「画像」「動画」の投稿形式が終了。画像・動画は記事本文に配置・埋め込みできる | 🟡 |
| (日付は要確認) | 「つぶやき」の投稿形式が終了 | 🟡 |
| 2025年7月28日 | 「音声」の投稿形式が終了 | 🟡 |

→ 初心者は「**記事の中に、文章・画像・動画の埋め込みを自由に並べる**」と覚えれば十分です。

## 用語

| 用語 | 意味 |
|---|---|
| 見出し画像 | 記事の一番上と一覧・SNS 共有時に出る横長画像 |
| 公開設定 | ハッシュタグ・マガジン・価格・公開日時などを決める画面 |
| 有料ライン | 有料記事で「ここから先は購入者だけ読める」境目 |
| マガジン | 記事をまとめる機能。無料・有料・定期購読などの種類がある(⚪ 種類と条件は要確認) |
| 予約投稿 | 公開日時を指定する機能。note プレミアムの機能とされる(🟡 [料金](../40-pricing/04-other-services.md)) |
| 下書き | 公開前に保存した記事。読者には見えない |
| OGP(Open Graph Protocol) | SNS で URL を共有したときにカードとして出るタイトル・画像の仕組み |

## 投稿の種類と使い所

| 種類 | 概要 | 使い所 | 確度 |
|---|---|---|---|
| 記事 | 文章・画像・埋め込みを並べる基本形式 | 解説・体験談・作品紹介 | 🟡 |
| マガジン | 記事の束 | 連載・テーマ別 | ⚪ |
| 有料記事 | 一部または全文を有料に | ノウハウ・テンプレ販売 | 🟡 |
| メンバーシップ | 月額課金のサークル | ファン化・継続支援 | 🟡 |
| (旧)画像・つぶやき・音声・動画 | 統合で終了。記事の中に配置する | — | 🟡 |

## 手順 1: 記事を書いて公開する

1. 画面の「投稿」ボタンから記事を新規作成します(⚪ ボタン名は変わる可能性)。
2. **見出し画像**を設定します(→ [03-media-specs](03-media-specs.md)。推奨 1280×670px 🟡)。
3. タイトルを入力します。読者の悩みと得られる結果が分かるタイトルにします。
4. 本文を書きます。見出し・箇条書き・引用・区切り線を使い、スマホで読みやすくします([04-text-hashtags](04-text-hashtags.md))。
5. 画像を挿入し、必要なら X・YouTube などを埋め込みます。
6. **下書き保存**して、プレビューでスマホ表示を確認します。
7. 「公開設定」を開き、次を決めます。
   - ハッシュタグ(公開設定の欄に入力、または本文中に `#単語` 🟡 [ハッシュタグを設定する](https://www.help-note.com/hc/ja/articles/360011358913))
   - 追加するマガジン
   - 有料にするか(価格と有料ラインの位置)
   - 公開日時(予約投稿 🟡)
8. 「投稿」を押して公開します。
9. 公開後、X・Instagram などで告知します([集客の流れ](../30-strategy/02-funnel.md))。

## 手順 2: マガジンを作る

1. クリエイターページまたはメニューからマガジン作成を選びます(⚪ 場所は要確認)。
2. マガジン名・説明・ヘッダー画像(1.91:1 🟡)を設定します。
3. 既存の記事を追加します。新しい記事は公開設定で追加できます。
4. 有料マガジンにする場合は価格を設定します。価格の範囲は下の表を参照。

マガジン名の例: 「はじめてのパン作り(全10回)」「店主の仕入れ日記 2026」。**中身がひと言で分かる名前**にします。

## 手順 3: 有料記事を作る

1. 記事を書き、無料で見せる部分と有料部分を決めます。
2. 公開設定で「有料」を選び、価格を入力します(🟡 [有料記事を書く](https://www.help-note.com/hc/ja/articles/360008882894))。
3. **有料ライン**を本文の境目に置きます。有料ラインは記事の編集画面でも設定できるとされます(🟡)。
4. 返金に関する設定(返金を受け付けるか)があれば確認します(🟡 同上の検索要約に返金の切り替えの記載)。
5. 公開前にプレビューで「購入前の見え方」を確認します。

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| 価格の範囲(記事・マガジン・メンバーシップ、通常の会員) | 100円〜50,000円 | 🟡 | [価格の設定](https://www.help-note.com/hc/ja/articles/360011270114) |
| 価格の上限(プレミアム会員・note pro 会員) | 100,000円 | 🟡 | 同上 |
| 手数料 | [07-monetization](07-monetization.md) を参照 | 🟡 | — |

## 手順 4: メンバーシップを始める

1. プロフィールアイコンのメニューから「メンバーシップ」を選び、開始します(🟡 [メンバーシップをつくる](https://www.help-note.com/hc/ja/articles/22752829171225))。
2. 活動内容・プラン名・説明を書きます。あとから変更できるとされます(🟡)。
3. **審査**を通過したあとに、プランの価格を設定して公開します(🟡)。
4. 公開できるプランは最大5つ、作成できるプランは最大1,000個(🟡)。
5. **一度決めた会費は途中で変えられない**とされます(🟡)。変えるにはプランを作り直す必要があるため、価格は慎重に決めます。
6. 初月無料の機能があります(🟡)。

設計の考え方は [継続課金の設計](../10-creator-economy/05-membership-design.md) を参照してください。

## 具体例: 記事構成のテンプレ(⚪)

```
タイトル: 読者の悩み + 解決(具体的な数字)
  例: 「はじめてのパン作りで失敗しない3つのポイント」
導入: 誰向けか・何が分かるか(3行)
本文: 見出し3〜5つ
まとめ: 要点 + 次の行動(次の記事・マガジンへのリンク)
(有料の場合)無料部分で価値を示し、有料ラインを設定
```

## 有料記事の設計

- 無料部分で**結論の一部と目次**を見せる。
- 有料部分は**読者が実行できる具体物**(手順・テンプレ・事例)。
- 価格は価値と市場に合わせ、価格範囲の制約は公式で確認 #6(現在の記載は上の表 🟡)。

| 良い有料記事 | 悪い有料記事 |
|---|---|
| 無料部分に「この記事で手に入るもの」の一覧 | 無料部分が前置きだけで中身が分からない |
| 有料部分にテンプレ・チェックリスト・具体例 | 無料記事と同じ内容を言い換えただけ |
| 「誰には向かないか」も書いてある | 「誰でも必ず稼げる」などの誇大表現 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 下書きのつもりで公開してしまった | 公開設定の前に必ずプレビュー。公開してしまったら非公開化・修正を検討 |
| ハッシュタグを公開設定に入れたら公開された | 下書きのまま保存したいときは本文に `#単語` で書く方法がある(🟡) |
| 有料ラインの位置がずれ、大事な部分が無料で見えていた | 公開前にログアウト状態・別アカウントで見え方を確認 |
| メンバーシップの価格を後から変えたくなった | 会費は変更できないとされる(🟡)。新プランを作って移行を案内 |
| 予約投稿ができない | 予約投稿は note プレミアムの機能とされる(🟡)。契約状況を確認 |

## 注意点

- 投稿形式の統合で、古い解説記事の「画像投稿」「つぶやき」の手順は使えない場合があります。
- 有料記事の表現は [10-policies](10-policies.md) の禁止事項・誇大表示に注意してください。
- 他の SNS と同じ文章をそのまま貼るより、note では**詳細・背景・手順**を足すと価値が出ます。

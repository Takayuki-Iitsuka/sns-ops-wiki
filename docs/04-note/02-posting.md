# note 投稿ルート

## 投稿の種類

| 種類 | 概要 | 使い所 |
|---|---|---|
| テキスト記事 | 長文記事 | 解説・体験談 |
| 画像 | 画像中心 | 作品・図解 |
| つぶやき | 短文 | 日常・告知 |
| 音声 / 動画 | 配信 | インタビュー等 |
| マガジン | 記事の束 | 連載・テーマ別 |
| 有料記事 | 一部または全文を有料に | ノウハウ販売 |
| メンバーシップ | 月額課金 | ファン化 |

## 基本手順（記事）

1. 「投稿」→ 記事を選ぶ。
2. **見出し画像**を設定（→ [03-media-specs](03-media-specs.md)）。
3. タイトル、本文を書く（見出し、箇条書き、引用、区切り線）。
4. 画像・埋め込み（X 等）を挿入。
5. 「公開設定」: ハッシュタグ、マガジン追加、**有料設定（有料ラインの位置・価格）**、公開日時。
6. 公開（予約投稿に対応 ⚪ 要確認）。
7. 公開後に X 等で告知。

## 記事構成のテンプレ（⚪）

```
タイトル: 読者の悩み＋解決（具体的な数字）
導入: 誰向けか・何が分かるか
本文: 見出し3〜5つ
まとめ: 要点＋次の行動
（有料の場合）無料部分で価値を示し、有料ラインを設定
```

## 有料記事の設計

- 無料部分で**結論の一部と目次**を見せる。
- 有料部分は**読者が実行できる具体物**（手順・テンプレ・事例）。
- 価格は価値と市場に合わせ、価格範囲の制約は公式で確認 #6。

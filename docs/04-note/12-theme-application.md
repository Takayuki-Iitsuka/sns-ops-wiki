# note での古事記・日本書紀の発信設計

テーマ全体は [05-theme-kojiki](../05-theme-kojiki/README.md)。

## note の役割

**深掘りと資産と収益**。X・Instagram で入口を作り、note で原文・異伝・研究史まで掘る。

## マガジン構成(案)

| マガジン | 内容 | 公開 |
|---|---|---|
| はじめに | 自己紹介、使い方、目次 | 無料 |
| 古事記を読む | シリーズA | 無料→有料(まとめ) |
| 記紀を比べる | シリーズC | 有料検討 |
| 神名辞典 | シリーズD | 無料サンプル＋有料 |
| 暦と記紀 | シリーズE | 無料 |
| 読書ガイド | 参考文献紹介(PR 表記) | 無料 |

## 記事の型

- 無料: 導入、あらすじ、入口の情報。
- 有料: 原文対照、異伝比較、語釈、研究史の整理、画像・図解のまとめ。

構成テンプレは [post-templates](../05-theme-kojiki/06-post-templates.md)。

## 画像

- 見出し画像 1280×670(🟡)。タイトル文字は中央に。
- 縦書きの原文は画像化して挿入。**代替の文字(キャプション)も本文に書く**([05-alt-text](05-alt-text.md))。

## 収益

- 手数料・価格範囲・メンバーシップの条件は **未確認**(#5, #6)。確認後に価格を設計。
- 電子書籍化: 連載の完結後に再編集。現代語訳は自作。

## 注意

- 引用は必要最小限、出典付き。
- 事実・解釈・信仰の区別。
- 更新履歴を記事末尾に(古い記事の修正を明示)。

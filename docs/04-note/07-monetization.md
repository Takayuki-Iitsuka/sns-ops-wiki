# note の収益化

> **手数料率・価格範囲・振込条件は公式で未確認です** (#5, #6)。数値を推測で記載しません。

## 手段（⚪ 概要）

| 手段 | 概要 |
|---|---|
| 有料記事 | 単品販売。無料部分と有料部分を分ける |
| マガジン（有料） | 複数記事のセット販売や購読 |
| メンバーシップ | 月額課金、限定コンテンツ・コミュニティ |
| サポート | 読者からの投げ銭 |
| note 広告・企業案件 | 条件は要確認 |
| 外部収益 | 自サイト・物販・アフィリエイト（規約要確認） |

## 確認する項目（公式ヘルプ）

1. 販売手数料（プラットフォーム手数料・決済手数料）
2. 価格の下限・上限
3. 振込の最低額・締め日・振込手数料
4. 本人確認・銀行口座
5. 特定商取引法に基づく表記の要否
6. 禁止コンテンツ（情報商材のルール等）
7. 返金・キャンセル

## 設計の考え方（⚪）

- 無料記事で信頼を作り、有料記事で成果物（テンプレ・事例）を提供。
- メンバーシップは**更新頻度・限定性・コミュニティ**を設計し、解約理由を減らす。
- 税務: 収益は所得になる。[monetization-comparison](../01-common/monetization-comparison.md)

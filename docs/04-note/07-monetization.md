# note の収益化

> **このページで分かること**: note でお金を得る方法(有料記事・マガジン・メンバーシップ・チップ)と、手数料・価格の範囲・振込の流れ。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [02-posting](02-posting.md)

> **手数料率・価格範囲・振込条件は、公式ヘルプの本文を直接取得できていません**(#5, #6)。下の値は公式ヘルプの検索要約(🟡)です。比較記事では「プラットフォーム利用料 10%(税抜)+決済手数料」とされています(🟡 個人ブログ系 [出典](https://app-tatsujin.com/note-fee-structure-comparison-2025/))。契約・価格設計の前に、必ず note の公式ヘルプで確認してください。

## 概要

note では、無料の会員でも有料記事やメンバーシップを始められるとされます(🟡)。
売上からは「事務手数料(決済の手数料)」と「プラットフォーム利用料」が引かれ、振込のたびに振込手数料がかかります(🟡)。
**いくら売れたら、手元にいくら残るか**を先に計算しておくと、価格を決めやすくなります。

## 用語

| 用語 | 意味 |
|---|---|
| 事務手数料 | 購入者の決済手段(カードなど)に応じた手数料 |
| プラットフォーム利用料 | note の利用料。事務手数料を引いた額にかかる(🟡) |
| 振込手数料 | 売上を口座に振り込むたびにかかる手数料 |
| 売上確定日 | その月の売上金額が確定する日 |
| 定期購読マガジン | 月額で記事を届けるマガジン(⚪ 提供条件は要確認) |
| メンバーシップ | 月額で参加するサークル。複数プランを作れる |
| チップ(サポート) | 読者からの投げ銭 |

## 手段(⚪ 概要)

| 手段 | 概要 | 向いている内容 |
|---|---|---|
| 有料記事 | 単品販売。無料部分と有料部分を分ける | テンプレ・手順・事例 |
| マガジン(有料) | 複数記事のセット販売や購読 | 連載・講座 |
| メンバーシップ | 月額課金、限定コンテンツ・コミュニティ | ファン化・継続支援 |
| チップ(サポート) | 読者からの投げ銭 | 無料記事への応援 |
| note 広告・企業案件 | 条件は要確認 | — |
| 外部収益 | 自サイト・物販・アフィリエイト(規約要確認) | [アフィリエイト](../10-creator-economy/04-affiliate.md) |

## 手数料と条件(🟡 公式ヘルプの検索要約)

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| 事務手数料(クレジットカード) | 5% | 🟡 | [手数料](https://www.help-note.com/hc/ja/articles/360011358873) |
| 事務手数料(携帯キャリア決済) | 15% | 🟡 | 同上 |
| 事務手数料(PayPay) | 7% | 🟡 | 同上 |
| 事務手数料の決まり方 | 購入者が使った決済手段による(クリエイターの登録内容ではない) | 🟡 | 同上 |
| プラットフォーム利用料(有料記事・有料マガジン・チップ・メンバーシップ) | 事務手数料を引いた額の 10% | 🟡 | 同上 |
| プラットフォーム利用料(定期購読マガジン) | 20% | 🟡 | 同上 |
| 振込手数料 | 1回 270円 | 🟡 | 同上 |
| 価格の範囲(通常の会員) | 100円〜50,000円(記事・マガジン・メンバーシップ) | 🟡 | [価格の設定](https://www.help-note.com/hc/ja/articles/360011270114) |
| 価格の上限(プレミアム・note pro) | 100,000円 | 🟡 | 同上 |
| 振込申請の条件 | 前月末までの未振込売上が合計 1,000円以上 | 🟡 | [売上金を受け取る](https://www.help-note.com/hc/ja/articles/360010430873) |
| 売上確定日と振込日 | 毎月2日に確定。2日〜20日の申請分を当月末(最終営業日)に振込 | 🟡 | 同上 |
| メンバーシップのプラン | 公開は最大5つ。会費は途中で変更不可。審査あり。初月無料機能あり | 🟡 | [メンバーシップをつくる](https://www.help-note.com/hc/ja/articles/22752829171225) |

### 計算例(上の 🟡 の値で計算)

1,000円の有料記事がクレジットカードで1件売れた場合:

| 段階 | 計算 | 金額 |
|---|---|---|
| 売上 | — | 1,000円 |
| 事務手数料 | 1,000 × 5% | −50円 |
| プラットフォーム利用料 | (1,000 − 50)× 10% | −95円 |
| 手元に残る売上 | 1,000 − 50 − 95 | 855円 |
| 振込(この1件だけを振り込む場合) | 855 − 270 | 585円 |

検索要約でも同じ計算例(振込額 585円)が示されています(🟡)。
振込手数料は1回ごとなので、**少額で何度も振り込むより、ある程度まとめて申請する**ほうが手取りは増えます。
消費税・端数処理の扱いは公式で確認してください(⚪)。

## 手順: 有料販売を始めるまで

1. 振込先口座を登録します([01-account-setup](01-account-setup.md))。
2. 特定商取引法に基づく表記が必要かを確認します([法令・表示](../01-common/legal-compliance.md))。
3. 無料記事を数本書き、読者の反応(スキ・コメント)を見ます。
4. 反応の良いテーマで、**成果物(テンプレ・手順・事例)**がある有料記事を作ります([02-posting](02-posting.md) 手順3)。
5. 価格を決めます。最初は低め(例: 数百円)から試し、反応を見て調整するのが一般的です(⚪)。
6. 売上が出たら、毎月2日以降に売上を確認し、必要に応じて振込申請します(🟡)。
7. 売上・手数料・経費を記録します([税務と事業](../30-strategy/04-tax-and-business.md))。

## 確認する項目(公式ヘルプ)

1. 販売手数料(プラットフォーム手数料・決済手数料)→ 上の表(🟡)
2. 価格の下限・上限 → 上の表(🟡)
3. 振込の最低額・締め日・振込手数料 → 上の表(🟡)
4. 本人確認・銀行口座(⚪)
5. 特定商取引法に基づく表記の要否(⚪)
6. 禁止コンテンツ(情報商材のルール等)(⚪ [10-policies](10-policies.md))
7. 返金・キャンセル(⚪)

## 設計の考え方(⚪)

- 無料記事で信頼を作り、有料記事で成果物(テンプレ・事例)を提供。
- メンバーシップは**更新頻度・限定性・コミュニティ**を設計し、解約理由を減らす([継続課金の設計](../10-creator-economy/05-membership-design.md))。
- 税務: 収益は所得になる。[monetization-comparison](../01-common/monetization-comparison.md)
- 他サービス(FANBOX・BOOTH・KDP)との比較は [クリエイターエコノミー](../10-creator-economy/README.md)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 価格だけ見て、手取りを計算していない | 上の計算例で手取りを出す |
| 少額で毎月振込申請し、手数料で目減り | まとめて申請する |
| メンバーシップの会費を後で変えたくなった | 変更不可とされる(🟡)。新プランを作り案内する |
| 有料部分に誇大な効果をうたう | 成果の保証表現をしない([10-policies](10-policies.md)) |
| 売上の記録をしていない | 月次で記録する([11-checklist](11-checklist.md)) |

## 注意点

- 手数料・条件は変わることがあります。値は必ず公式ヘルプで最新を確認してください(#5, #6)。
- note プレミアム・note pro の料金は [その他サービスの料金](../40-pricing/04-other-services.md) を参照してください。

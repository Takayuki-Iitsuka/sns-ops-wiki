# note の画像説明文

## 状況

note の画像に代替テキスト（alt text）を設定する機能の有無・手順は **未確認** です（→ [要検証リスト](../00-meta/verification-queue.md) に追記予定）。

## 暫定の対応（⚪）

画像の直下や直前に**キャプション（図の説明）を本文として書く**:

- 図表は本文にも要点を書く（画像が見えなくても内容が伝わる）。
- 見出し画像はタイトルで内容が分かるようにする。

共通原則: [alt-text](../01-common/alt-text.md)

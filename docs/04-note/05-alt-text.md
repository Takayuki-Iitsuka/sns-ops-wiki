# note の画像説明文

> **このページで分かること**: note の画像に代替テキスト(alt text)を付けられるかの現状と、確実にできる代わりの方法、説明文の書き方。
>
> **対象**: 初心者  **先に読むページ**: [alt text 詳細ガイド(共通)](../01-common/alt-text.md)

## 概要

alt text(代替テキスト)は、画像の内容を文字で説明するものです。
目が見えにくい人が使う**スクリーンリーダー(画面読み上げソフト)**が読み上げるほか、通信が遅く画像が表示されないときにも役立ちます。

note については、次のような状況です。

- 2022年(皇紀2682年・令和4年)4月のアップデートで、画像の代替テキスト(alt 属性)を設定できるようになったと報じられています(🟡 [Impress Watch](https://www.watch.impress.co.jp/docs/news/1402352.html))。
- ただし、現在の PC・アプリそれぞれでの具体的な操作手順は、公式ヘルプ本文で未確認です(⚪ #16)。

そのため、このページでは「**機能があれば使う。どちらにしても本文で説明する**」という二段構えをおすすめします。

## 用語

| 用語 | 意味 |
|---|---|
| alt text(代替テキスト) | 画像の代わりに読まれる説明文 |
| スクリーンリーダー | 画面の文字を音声で読み上げるソフト |
| キャプション | 画像の下に表示する説明文。全員に見える |
| 装飾画像 | 内容を持たない飾りの画像。説明は短く、または不要 |

## 手順

### A. 代替テキスト欄がある場合(⚪ 表記は要確認)

1. 記事の編集画面で、挿入した画像を選びます。
2. 画像のメニューに「代替テキスト」などの入力欄があるか確認します。
3. 画像の内容を1〜2文で入力します(書き方は下の「具体例」)。
4. 公開後、可能ならスクリーンリーダー(スマホの読み上げ機能)で確認します。

### B. 確実にできる方法: 本文で説明する(⚪)

画像の直下や直前に**キャプション(図の説明)を本文として書く**:

- 図表は本文にも要点を書く(画像が見えなくても内容が伝わる)。
- 見出し画像はタイトルで内容が分かるようにする。
- 画像の中の文字(手順・数値)は、本文にも同じ内容を書く。

共通原則: [alt-text](../01-common/alt-text.md)

## 具体例

| 画像 | 良い説明 | 悪い説明 |
|---|---|---|
| 焼き上がったパンの写真 | 「表面がきつね色に焼けた丸いパン。断面に大きめの気泡が見える。」 | 「画像」「パン」 |
| 手順の図解 | 「生地をこねる3ステップ。1. 粉と水を混ぜる、2. 10分こねる、3. 丸めて休ませる。」 | 「図解です」 |
| 店の外観 | 「青い看板の小さな店の入り口。入口横に営業時間の札。」 | 「お店」 |
| 区切りの飾り線 | (説明は不要、または「区切り線」) | 長い説明を付ける |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 説明が「画像」「写真」だけ | 何が写っていて、なぜ載せたかを書く |
| 画像内の文字を本文に書いていない | 手順・数値は本文にも書く |
| 説明が長すぎる | 1〜2文に。詳しい内容は本文へ |
| 見出し画像だけで内容を伝えている | タイトルと導入文で同じ内容を伝える |

## 注意点

- note の画像に代替テキストを設定する機能の現在の手順は**未確認**(#16)。確認できるまでは、**画像の直下にキャプション**を書き、図表は**本文にも要点**を書く。
- 見出し画像はタイトルで内容が分かるようにする。
- 人物が写る写真では、個人を特定できる情報を説明文に書かない([個人情報](../01-common/privacy-and-personal-info.md))。
- 詳細: [alt-text 詳細ガイド](../01-common/alt-text.md)。

# note 運用チェックリスト

## 初期設定

- [ ] 2段階認証
- [ ] プロフィール・自己紹介・ヘッダー画像(1280×670 を用意 🟡)
- [ ] SNS 連携・公開時の自動投稿の設定を確認
- [ ] 収益受け取りの設定(有料販売時)・特定商取引法に基づく表記の要否([legal](../01-common/legal-compliance.md))
- [ ] 入口記事(はじめに・目次)の作成と固定

## 記事の公開前

- [ ] 典拠(巻・段)と底本を明記([source-texts](../05-theme-kojiki/01-source-texts.md))
- [ ] 見出し画像(1280×670)と本文中の画像の権利([image-sources](../01-common/image-sources-and-copyright.md))
- [ ] 神名・年の表記が統一
- [ ] 事実・解釈・信仰の区別([sensitivity](../05-theme-kojiki/09-sensitivity.md))
- [ ] 参考文献(書名・編者・出版社・刊行年)
- [ ] 広告・PR(書籍紹介など)の表記
- [ ] 有料記事: 無料部分で価値を示し、有料ラインの位置を確認
- [ ] ハッシュタグ・マガジンへの追加

## 公開後

- [ ] X・Instagram で告知
- [ ] コメントへの返信
- [ ] 1週間後に閲覧・スキ・流入元・購入率を記録

## 月次

- [ ] 記事の更新(誤り・リンク切れ)
- [ ] 目次記事の更新

# note 運用チェックリスト

> **このページで分かること**: note の運用で「やり忘れ」を防ぐための確認項目を、初期設定・公開前・公開後・月次の順にまとめたもの。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [01-account-setup](01-account-setup.md)、[02-posting](02-posting.md)

## 概要

チェックリストは、慣れてきたころに起きる「うっかり」(画像の権利確認漏れ、PR 表示忘れ、振込申請忘れなど)を防ぐ道具です。
各項目の詳しい説明はリンク先のページにあります。印刷するか、メモアプリにコピーして使ってください。

## 用語

| 用語 | 意味 |
|---|---|
| 公開設定 | ハッシュタグ・マガジン・価格・公開日時を決める画面 |
| 有料ライン | 有料記事の無料部分と有料部分の境目 |
| 流入元 | 読者がどこから来たか |
| 購入率 | 有料記事を見た人のうち購入した人の割合 |

## 使い方

1. 初期設定は、アカウントを作ったときに1回だけ確認します。
2. 「記事の公開前」は**毎回**確認します。
3. 「公開後」は公開当日と1週間後に確認します。
4. 「月次」は毎月決まった日(例: 月初)に確認します。

## 初期設定

- [ ] 2段階認証([account-security](../01-common/account-security.md))
- [ ] プロフィール・自己紹介・ヘッダー画像(1280×670 を用意 🟡 [画像仕様](03-media-specs.md))
- [ ] SNS 連携・公開時の自動投稿の設定を確認
- [ ] 収益受け取りの設定(有料販売時)・特定商取引法に基づく表記の要否([legal](../01-common/legal-compliance.md))
- [ ] 入口記事(はじめに・目次)の作成と固定
- [ ] 運用専用のメールアドレスで登録した

## 記事の公開前

- [ ] 出典・参考文献を明記
- [ ] 見出し画像(1280×670)と本文中の画像の権利([image-sources](../01-common/image-sources-and-copyright.md))
- [ ] 画像に説明(代替テキストまたはキャプション)を付けた([05-alt-text](05-alt-text.md))
- [ ] 固有名詞・年の表記が統一
- [ ] 事実・解釈・意見の区別([sensitive-topics](../01-common/sensitive-topics-and-accuracy.md))
- [ ] 参考文献(書名・著者・出版社・刊行年)
- [ ] 広告・PR(書籍・商品紹介など)の表記
- [ ] 有料記事: 無料部分で価値を示し、有料ラインの位置を確認
- [ ] 有料記事: 価格が範囲内(通常 100円〜50,000円 🟡 [07-monetization](07-monetization.md))
- [ ] ハッシュタグ・マガジンへの追加
- [ ] スマホのプレビューで読みやすさを確認
- [ ] 誇大表現(「必ず」「絶対」)がない([10-policies](10-policies.md))

## 公開後

- [ ] X・Instagram で告知
- [ ] SNS で共有したときのカード(見出し画像)の表示を確認
- [ ] コメントへの返信
- [ ] 1週間後に閲覧・スキ・流入元・購入率を記録([08-analytics](08-analytics.md))

## 月次

- [ ] 記事の更新(誤り・リンク切れ)
- [ ] 目次記事の更新
- [ ] 収益・経費の記録([tax-and-business](../30-strategy/04-tax-and-business.md))
- [ ] 売上の確認と振込申請(毎月2日に確定、前月末までの未振込売上 1,000円以上で申請可 🟡 [売上金を受け取る](https://www.help-note.com/hc/ja/articles/360010430873))
- [ ] 手数料を差し引いた手取りの確認(🟡 [手数料](https://www.help-note.com/hc/ja/articles/360011358873))
- [ ] メンバーシップの参加者数・解約数の記録
- [ ] 来月の記事の予定を決める

## 年次

- [ ] 利用規約・ガイドラインを読み直す
- [ ] 記事のバックアップ(本文テキスト)を取る([バックアップ](../01-common/data-backup-and-portability.md))
- [ ] 確定申告の準備([税務と事業](../30-strategy/04-tax-and-business.md))

## 具体例: 公開前チェックの使い方

「パン作りの道具紹介」記事を出す場合:

1. 道具の写真は自分で撮影したもの → 権利 OK。
2. 商品リンクにアフィリエイトを使っている → 冒頭に「PR」を追記。
3. 「これがあれば必ず成功」→「失敗が減りました」に言い換え。
4. プレビューで画像が縦長すぎる → トリミングして再アップロード。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| チェックリストが長くて使わなくなる | 「公開前」だけでも毎回使う。慣れたら項目を自分用に減らす |
| 振込申請を忘れる | 毎月の予定表に「売上確認」を入れる |
| PR 表示を告知投稿で忘れる | 告知文のテンプレに PR 欄を入れておく |

## 注意点

- 数値(画像サイズ・価格範囲・振込条件)は 🟡 です。変更されることがあるので、公式ヘルプで定期的に確認してください。

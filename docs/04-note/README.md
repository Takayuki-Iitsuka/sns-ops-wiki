# note

文章・画像・音声・動画を投稿できる、日本発のクリエイター向け発信プラットフォーム。長文の解説、有料コンテンツ、継続課金に向く（⚪）。

## 特徴

| 項目 | 内容 |
|---|---|
| 主な形式 | 記事（テキスト）、つぶやき、画像、音声、動画、マガジン |
| 強み | 長文・資産性、有料販売、メンバーシップ、ストック型 |
| 弱み | 拡散力は X・Instagram より限定的、導線設計が必要 |
| 向く用途 | 深い解説、ノウハウ販売、ファン化 |

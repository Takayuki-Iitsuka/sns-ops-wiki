# note

> **このページで分かること**: note がどんなサービスで、何に向いているか。このフォルダのページをどの順で読めばよいか。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[サービスの選び方](../01-common/choosing-platforms.md)

## 概要

文章・画像・音声・動画を投稿できる、日本発のクリエイター向け発信プラットフォーム。長文の解説、有料コンテンツ、継続課金に向く(⚪)。

投稿形式は 2025年(皇紀2685年・令和7年)から「記事」に統合され、画像や動画は記事の中に配置する形になりました(🟡 [投稿形式の統合](https://www.help-note.com/hc/ja/articles/47459837469081))。
X や Instagram で興味を持った人に、**詳しい内容を読んでもらう「受け皿」**として使うのが代表的な使い方です([集客の流れ](../30-strategy/02-funnel.md))。

## 用語

| 用語 | 意味 |
|---|---|
| 記事 | note の基本の投稿。文章・画像・埋め込みを並べる |
| マガジン | 記事をまとめる機能 |
| メンバーシップ | 月額課金のサークル |
| スキ | いいねに当たる反応 |
| note プレミアム / note pro | 有料の機能プラン(個人向け / 法人向け 🟡 [料金](../40-pricing/04-other-services.md)) |

## 特徴

| 項目 | 内容 |
|---|---|
| 主な形式 | 記事(テキスト中心。画像・動画・音声は記事内に配置 🟡)、マガジン、メンバーシップ |
| 強み | 長文・資産性、有料販売、メンバーシップ、ストック型 |
| 弱み | 拡散力は X・Instagram より限定的、導線設計が必要 |
| 向く用途 | 深い解説、ノウハウ販売、ファン化 |
| 手数料の目安 | プラットフォーム利用料 10%+事務手数料(決済手段による)ほか(🟡 [07-monetization](07-monetization.md)) |

## 向いている人・向いていない人(⚪)

| 向いている | 向いていない |
|---|---|
| 文章で説明するのが好き | 短い動画だけで発信したい |
| 1つのテーマを深く書ける | 毎日たくさんの人に一気に拡散したい |
| 将来、有料記事や継続課金をしたい | 文章を書く時間がまったく取れない |

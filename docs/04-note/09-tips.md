# note のコツ（経験則 ⚪）

1. **見出し画像とタイトルが入口**: 一覧と SNS 共有で最初に見られる。
2. **目次記事（まとめ記事）を作る**: 過去記事の導線が整う。
3. **1記事1テーマ**。長すぎたらシリーズ化。
4. **更新頻度は無理のない範囲で固定**（週1等）。
5. **X・Instagram で告知し、note に詳細を置く**: [posting-workflow](../01-common/posting-workflow.md) の再利用。
6. **有料は成果物を明確に**: 手順・テンプレ・チェックリスト。
7. **公開後に読み直し**: 誤字・リンク・数値の更新。古い情報は「更新履歴」を記載。

## 避けること

- 出典のない数字の断定
- 他人の文章・画像の無断転載
- 煽りタイトルで中身が薄い有料記事

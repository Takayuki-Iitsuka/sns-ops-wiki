# note の分析

> **このページで分かること**: note の数字(ビュー・スキ・購入数など)をどこで見て、どう次の記事の改善につなげるか。
>
> **対象**: 初心者  **先に読むページ**: [分析と KPI(共通)](../01-common/analytics-kpi.md)

## 概要

分析(アナリティクス、analytics)は「数字を見て、次に何を変えるかを決める」ための作業です。
数字を眺めて一喜一憂するのではなく、**1つの仮説 → 1つの変更 → 結果の確認**を繰り返すのがコツです。
note では、クリエイター用のダッシュボード(管理画面)でアクセス状況や販売実績を確認できます(⚪ 項目名・場所は要確認)。

## 用語

| 用語 | 意味 |
|---|---|
| ダッシュボード | 数字をまとめて見る管理画面 |
| ビュー(閲覧数) | 記事が表示された回数 |
| 流入元 | 読者がどこから来たか(X・検索・note 内など) |
| 購入率(CVR, conversion rate) | 有料記事を見た人のうち購入した人の割合 |
| 解約率(チャーン, churn) | メンバーのうち、その月にやめた人の割合 |
| KPI(Key Performance Indicator、重要業績評価指標) | 目標に向かって進んでいるかを測る指標 |

## 見る場所 ⚪

クリエイター用のダッシュボード(アクセス解析・販売実績)。項目名は要確認。
売上の確認と振込申請は、ブラウザではダッシュボードの売上管理、アプリでは売上・振込・販売管理の画面から行うとされます(🟡 [売上金を受け取る](https://www.help-note.com/hc/ja/articles/360010430873))。

## 主な指標

| 指標 | 意味 | 使い方 |
|---|---|---|
| ビュー(閲覧数) | 記事の閲覧 | 到達。タイトル・見出し画像の効果 |
| スキ数 | 反応 | 内容評価 |
| コメント数 | 会話 | 関心 |
| フォロワー増 | 継続して読みたい人の増加 | 継続的な読者 |
| 流入元 | X / 検索 / note内 / 外部 | 導線の改善 |
| 有料記事の購入数・購入率 | 無料閲覧に対する購入割合 | 無料部分と価格の改善 |
| メンバー数・解約率 | 継続課金の健康状態 | 継続設計 |

※どの指標がダッシュボードで見られるかは要確認(⚪)。見られない指標は手元の表で記録します。

## 手順: 月1回の振り返り

1. 毎月同じ日(例: 月初)に、先月公開した記事の数字を表に写します。
2. 次の列を作ります: 公開日 / タイトル / ビュー / スキ / コメント / 流入元の上位 / (有料)購入数。
3. **上位3記事と下位3記事**を比べ、違い(タイトル・テーマ・告知の有無)を書き出します。
4. 違いから仮説を1つ立てます(例: 「数字入りのタイトルはビューが多い」)。
5. 翌月はその仮説を1つだけ試します。
6. 結果を同じ表に記録します。

記録表の例:

| 公開日 | タイトル | ビュー | スキ | 流入元上位 | メモ |
|---|---|---|---|---|---|
| 11/2 | 失敗しない3つのポイント | (数値) | (数値) | X | 告知を2回した |
| 11/9 | パン作りの道具 | (数値) | (数値) | note 内 | タグを見直した |

## 見方

- 流入元が X 中心なら、タイトルとOGP(見出し画像)を磨く。
- 購入率が低ければ、無料部分で価値を見せる、有料ラインの位置を見直す。
- 検索からの流入が少なければ、タイトルと見出しに読者が検索しそうな言葉を入れる([検索最適化](../01-common/search-optimization.md))。
- スキは多いがフォローが増えないなら、記事末尾に「他の記事」「マガジン」への案内を置く。
- メンバーの解約が続くなら、更新頻度と特典の約束を見直す([継続課金の設計](../10-creator-economy/05-membership-design.md))。

## 具体例: 仮説と変更

| 気づき | 仮説 | 次に試すこと |
|---|---|---|
| ビューは多いが購入が少ない | 無料部分で中身が伝わっていない | 無料部分に目次と「手に入るもの」を追加 |
| X からの流入が少ない | 告知の投稿が分かりにくい | 告知に見出し画像と要点3つを入れる |
| 古い記事が今も読まれる | 検索から来ている | 内容を更新し、関連記事へのリンクを追加 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 毎日数字を見て疲れる | 週1か月1に決める |
| 一度に複数のことを変え、何が効いたか分からない | 1回に1つだけ変える |
| ビューだけを目標にする | 目的(フォロー・購入)に近い指標も見る |
| 数字を記録しておらず比べられない | 月次の記録表を作る |

## 注意点

- 公開する数字(売上の実数など)は慎重に。発信で使うときは比率や桁にとどめる方法もあります。
- 外部の解析ツールを使う場合は、規約と個人情報の扱いを確認します(⚪)。
- リンクの効果測定は [リンクと UTM](../01-common/link-in-bio-and-utm.md) を参照してください。

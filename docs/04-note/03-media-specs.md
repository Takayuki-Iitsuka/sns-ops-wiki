# note 画像仕様

> **このページで分かること**: note の見出し画像・ヘッダー画像・本文中の画像を、どのサイズで作ればきれいに表示されるか。
>
> **対象**: 初心者  **先に読むページ**: [02-posting](02-posting.md)

## 概要

note では、**見出し画像**が記事の「顔」です。
記事一覧、検索結果、X などで共有したときのカード(OGP)に表示されるため、クリックされるかどうかを大きく左右します。
推奨サイズと違う画像は、表示時に**自動でトリミング(切り抜き)**されます(🟡)。文字が端で切れないよう、余白を取って作るのがコツです。

## 用語

| 用語 | 意味 |
|---|---|
| アスペクト比(縦横比) | 横と縦の長さの比。1.91:1 は「横が縦の約1.9倍」の横長 |
| px(ピクセル) | 画像の大きさの単位 |
| トリミング | 画像の一部を切り取って表示すること |
| OGP | SNS で URL を共有したときに出るカード。note では見出し画像が使われる(⚪) |
| セーフエリア | 切り抜かれても見える中央の安全な範囲 |

## 登録画像の推奨(公式ヘルプの検索要約 🟡)

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| 見出し画像の推奨サイズ | **1280 × 670px**(約1.91:1) | 🟡 | [360000231642](https://www.help-note.com/hc/ja/articles/360000231642) |
| 画像の容量 | **1枚あたり最大10MB** | 🟡 | 同上 |
| 推奨サイズと異なる画像 | 表示時にトリミングされる | 🟡 | 同上 |
| クリエイターページ・マガジンヘッダー | 比率 1.91:1。1280×670 を用意 | 🟡 | 同上 |
| 見出し画像の指定 | 画像記事・つぶやき記事の一番上に置いた画像が自動選択される仕組み | 🟡 | [900000061623](https://www.help-note.com/hc/ja/articles/900000061623) |
| Canva 連携 | 2025年(皇紀2685年・令和7年)12月1日に終了。Canva で保存→note にアップロード | 🟡 | 検索要約 |
| ファイル形式 | 未確認 | ⚪ #12 | — |

> 上記は公式ヘルプの検索要約からの情報で、全項目の一覧表は未取得です。`360000231642` の本文で、項目ごと(プロフィール画像、ヘッダー等)の確認が必要です。
>
> 補足(🟡): 「画像」「つぶやき」の投稿形式は 2025年の投稿形式の統合で終了しました([統合について](https://www.help-note.com/hc/ja/articles/47459837469081))。上の「一番上の画像が自動選択」の仕組みが現在の記事でも同じかは要確認です(⚪)。

## 実務のおすすめ(⚪)

| 用途 | サイズ例 | 形式の目安 | ポイント |
|---|---|---|---|
| 見出し画像 | 1280×670 | JPEG(写真)/ PNG(文字・図) | タイトル文字は中央に、上下左右に余白 |
| 本文中の画像 | 幅1280px程度 | JPEG / PNG | 縦長すぎる画像はスマホでスクロールが長くなる |
| 図解 | 幅1280px程度 | PNG | 文字が潰れない大きさ(スマホで読めるか確認) |
| クリエイターヘッダー | 1280×670 | JPEG / PNG | スマホとPCで切れ方が違う可能性。中央に要素を寄せる |
| プロフィール画像 | 正方形(例: 400×400 以上) | JPEG / PNG | 丸く切り抜かれる前提で中央に顔・ロゴ |

形式(JPEG/PNG など)の対応は公式では未確認です(#12)。迷ったら JPEG か PNG にしておくと無難です(⚪)。
書き出し設定の目安は [書き出しプリセット](../01-common/export-presets.md) を参照してください。

## 手順: 見出し画像を作る

1. 画像編集ツール(Canva など、[ツール一覧](../01-common/tools.md))で **1280×670px** の新規キャンバスを作ります。
2. 中央の約 8割の範囲(セーフエリア ⚪)に、タイトル文字や主役の写真を置きます。
3. 文字は**スマホの一覧で小さく表示されても読める大きさ**にします。3〜12文字程度の短いキャッチが目安です(⚪)。
4. 背景と文字の色の差(コントラスト)をはっきりさせます。
5. JPEG または PNG で書き出し、**10MB 以下**(🟡)になっているか確認します。
6. note の記事編集画面で見出し画像として登録し、プレビューで切れ方を確認します。
7. 公開後、X などで URL を共有して、カードの表示も確認します。

## 具体例

| 良い例 | 悪い例 |
|---|---|
| 中央に大きく「失敗しない3つのコツ」 | 端ぎりぎりまで文字があり、切り抜かれて読めない |
| 写真+短い文字で内容が分かる | 小さな文字で長文を詰め込む |
| シリーズで色・配置を統一 | 記事ごとにデザインがばらばらで同じ連載と分からない |

## 見出し画像が重要な理由

- 一覧・SNS共有(OGP)で表示される主要な視覚要素。
- 文字を入れる場合は小さい表示でも読めること。
- 連載ではデザインを揃えると「続きの記事」だと気づいてもらいやすい(⚪)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 正方形の画像を使い、上下が大きく切れた | 1.91:1 で作り直す |
| 文字がぼやける | 小さい画像を拡大しない。元から 1280px 幅で作る |
| アップロードできない | 容量(10MB 🟡)と形式を確認。写真は JPEG で圧縮 |
| 他人の写真を使ってしまった | 権利を確認する([画像の出典と著作権](../01-common/image-sources-and-copyright.md)) |

## 注意点

- 見出し画像には代替テキストを付けられるか未確認です。タイトルで内容が分かるようにします([05-alt-text](05-alt-text.md))。
- 写真に人物が写る場合は肖像権・プライバシーに注意します([個人情報](../01-common/privacy-and-personal-info.md))。

## チェックリスト

- [ ] 見出し画像は 1280×670px(🟡)
- [ ] 文字は中央寄せ・余白あり・スマホで読める
- [ ] 1枚 10MB 以下(🟡)
- [ ] 画像の権利を確認した
- [ ] 公開後に SNS のカード表示を確認した

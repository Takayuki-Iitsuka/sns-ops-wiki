# note 画像仕様

## 登録画像の推奨（公式ヘルプの検索要約 🟡）

| 項目 | 値 | 確度 |
|---|---|---|
| 見出し画像の推奨サイズ | **1280 × 670px**（約1.91:1） | 🟡 |
| 画像の容量 | **1枚あたり最大10MB** | 🟡 |
| 推奨サイズと異なる画像 | 表示時にトリミングされる | 🟡 |
| クリエイターページ・マガジンヘッダー | 比率 1.91:1。1280×670 を用意 | 🟡 |
| 見出し画像の指定 | 画像記事・つぶやき記事の一番上に置いた画像が自動選択される仕組み | 🟡 |
| Canva 連携 | 2025年(皇紀2685年・令和7年)12月1日に終了。Canva で保存→note にアップロード | 🟡 |
| ファイル形式 | 未確認 | ⚪ #12 |

> 上記は公式ヘルプの検索要約からの情報で、全項目の一覧表は未取得です。`360000231642` の本文で、項目ごと（プロフィール画像、ヘッダー等）の確認が必要です。

## 実務のおすすめ（⚪）

| 用途 | サイズ例 |
|---|---|
| 見出し画像 | 1280×670。タイトル文字は中央に、左右上下に余白 |
| 本文中の画像 | 幅1280px程度。縦長は読みやすさに注意 |
| 図解 | PNG。文字が潰れない大きさ |
| クリエイターヘッダー | 1280×670 |

## 見出し画像が重要な理由

- 一覧・SNS共有（OGP）で表示される主要な視覚要素。
- 文字を入れる場合は小さい表示でも読めること。

# note のコメント・反応

共通方針: [comments-and-engagement](../01-common/comments-and-engagement.md)

## 反応の種類 ⚪

| 反応 | 概要 |
|---|---|
| スキ（いいね） | 記事への好意 |
| コメント | 感想・質問 |
| フォロー | 更新通知 |
| サポート | 投げ銭（収益化） |
| 引用・メンション | 他記事への言及 |

## コツ

- コメントには**記事の改善**につながる質問への回答を優先。
- 他のクリエイターの記事を読み、具体的な感想を書く（宣伝のみは避ける）。
- 読者からの質問を次の記事のテーマにする。
- コメント欄のルール（誹謗中傷・宣伝）を明示しておく。

# note 本文・ハッシュタグ

> **このページで分かること**: note の本文を読みやすく書くコツ、見出し・装飾・埋め込みの使い方、ハッシュタグの付け方。
>
> **対象**: 初心者  **先に読むページ**: [02-posting](02-posting.md)

## 概要

note の読者の多くはスマホで記事を読みます(⚪)。
そのため、**流し読みできる構成**(見出し・箇条書き・短い段落)が読了率を左右します。
ハッシュタグは、記事を「テーマ別の一覧」や検索に載せるための目印です。数を増やすより、**内容に合う言葉を選ぶ**ことが大切です。

## 用語

| 用語 | 意味 |
|---|---|
| 見出し(大見出し・小見出し) | 記事の章タイトル。目次の項目になる |
| 目次 | 見出しから作られる記事内の案内(⚪ 自動生成の条件は要確認) |
| 埋め込み | X の投稿や YouTube 動画を記事内に表示する機能 |
| ハッシュタグ | `#` から始まるキーワード。同じタグの記事一覧につながる |
| 読了率 | 最後まで読まれた割合(note で見られるかは要確認 ⚪) |

## 本文の仕様

| 項目 | 内容 | 確度 |
|---|---|---|
| 文字数 | 長文可。上限は要確認 | ⚪ |
| 見出し | 大見出し・小見出し。目次が自動生成される ⚪ | ⚪ |
| 装飾 | 太字、引用、箇条書き、コードブロック、区切り線 | ⚪ |
| 埋め込み | X、YouTube 等の外部埋め込み | ⚪ |
| 外部リンク | 可。有料部分への誘導方針に注意 | ⚪ |
| エディタの機能一覧 | 公式ヘルプ「エディタ(投稿画面)でできること」で確認 | 🟡 [360012426133](https://www.help-note.com/hc/ja/articles/360012426133) |

## ハッシュタグ

| 項目 | 内容 | 確度 | 出典 |
|---|---|---|---|
| 設定方法1 | 記事編集画面右上の「公開設定」→ハッシュタグ欄に単語を入力 | 🟡 | [ハッシュタグを設定する](https://www.help-note.com/hc/ja/articles/360011358913) |
| 設定方法2 | 本文中に `#`(半角シャープ)+単語を書く | 🟡 | 同上 |
| 下書きのまま付けたい | 本文に書く方法が案内されている | 🟡 | 同上 |
| 上限 | 未確認 | ⚪ #13 | — |
| 効果 | テーマ別一覧・検索に表示 | ⚪ | — |

共通の考え方: [hashtags](../01-common/hashtags.md)

### タグ選びの手順

1. 記事の**主題**を1語で表すタグを1つ決めます(例: `#パン作り`)。
2. **読者の目的**を表すタグを足します(例: `#初心者向け` `#レシピ`)。
3. note 内で実際にそのタグを検索し、記事が集まっているか、内容が合っているかを見ます。
4. 関係の薄い人気タグは付けません(読者が離れ、信頼を下げます)。
5. 迷ったら 3〜5個程度から始めます(⚪ 経験則。上限は未確認 #13)。

## 書き方のコツ(⚪)

1. **タイトルに読者の悩みと結果**(数字を入れる)。
2. 導入3行で「誰向け・何が分かる」。
3. 見出しで流し読みできる構成。
4. 1文を短く。スマホ表示を前提に改行。
5. 画像で補足、箇条書きで整理。
6. 段落は 2〜4文で区切ります。スマホでは長い段落が「壁」に見えます。
7. 専門用語には一言説明を添えます。
8. 最後に**次に読む記事**やマガジンへのリンクを置きます。

文章全般のコツは [文章の書き方](../01-common/writing-guide.md) を参照してください。

## 具体例

タイトルの例:

| 良い例 | 悪い例 |
|---|---|
| はじめてのパン作りで失敗しない3つのポイント | パンについて |
| 小さな店がSNSで来店を増やした5つの工夫(実例つき) | 絶対に売上が10倍になる方法 |

導入文の例:

```
この記事は、パン作りを始めたばかりの人向けです。
発酵がうまくいかない原因と、家でできる対策を3つ紹介します。
読み終わるころには、次の休日に試す手順が決まっているはずです。
```

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 見出しがなく、長文が続く | 3〜5個の見出しで区切る |
| 太字だらけで、どこが大事か分からない | 太字は1段落に1か所まで(⚪ 目安) |
| ハッシュタグを大量に付ける | 内容に合うものだけに絞る |
| 埋め込みが多く、表示が重い | 必要なものだけにし、リンクで代替する |
| 外部の購入ページへ強く誘導する | 規約・方針を確認([10-policies](10-policies.md)) |

## 注意点

- 引用は「必要最小限」「出典を明記」「本文が主」の形にします([画像の出典と著作権](../01-common/image-sources-and-copyright.md))。
- 検索から読まれやすくする考え方は [検索最適化](../01-common/search-optimization.md) を参照してください。

## チェックリスト

- [ ] タイトルで「誰の・何が・どうなる」が分かる
- [ ] 導入3行で対象と内容を説明した
- [ ] 見出しで構成を区切った
- [ ] ハッシュタグは内容に合うものだけ
- [ ] 最後に次の行動(関連記事・マガジン)を置いた

# note 本文・ハッシュタグ

## 本文

| 項目 | 内容 | 確度 |
|---|---|---|
| 文字数 | 長文可。上限は要確認 | ⚪ |
| 見出し | 大見出し・小見出し。目次が自動生成される ⚪ | ⚪ |
| 装飾 | 太字、引用、箇条書き、コードブロック、区切り線 | ⚪ |
| 埋め込み | X、YouTube 等の外部埋め込み | ⚪ |
| 外部リンク | 可。有料部分への誘導方針に注意 | ⚪ |

## ハッシュタグ

| 項目 | 内容 | 確度 |
|---|---|---|
| 設定 | 公開設定で追加 | ⚪ |
| 上限 | 未確認 | ⚪ #13 |
| 効果 | テーマ別一覧・検索に表示 | ⚪ |

共通の考え方: [hashtags](../01-common/hashtags.md)

## 書き方のコツ（⚪）

1. **タイトルに読者の悩みと結果**（数字を入れる）。
2. 導入3行で「誰向け・何が分かる」。
3. 見出しで流し読みできる構成。
4. 1文を短く。スマホ表示を前提に改行。
5. 画像で補足、箇条書きで整理。

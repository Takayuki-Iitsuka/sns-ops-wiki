# note のルール・ポリシー

> **このページで分かること**: note で記事・有料コンテンツを出すときに気をつけるルールと、違反を指摘されたときの対応。
>
> **対象**: 初心者  **先に読むページ**: [法令・表示(共通)](../01-common/legal-compliance.md)

一次資料: note の利用規約、ガイドライン(入口: https://www.help-note.com/hc/ja 。作成時は bot 確認で本文を取得できず、未確認 #28)。

## 概要

ルールには大きく2種類あります。

1. **note のルール**(利用規約・ガイドライン): note 上で何を出してよいか。
2. **法律**(著作権法、景品表示法、特定商取引法など): note に限らず守るべきもの。

特に**有料記事**は「お金を払って読むもの」なので、内容と説明が食い違うとトラブルになりやすくなります。
このページの内容は一般論(⚪)です。具体的な禁止事項は必ず公式の規約で確認してください。

## 用語

| 用語 | 意味 |
|---|---|
| 利用規約 | サービスを使う人が守る約束 |
| ガイドライン | 規約を分かりやすく説明した指針 |
| 誇大表示 | 実際より良く見せる表現。「必ず」「誰でも」など |
| ステルスマーケティング(ステマ) | 広告であることを隠した宣伝。2023年(皇紀2683年・令和5年)10月1日から景品表示法違反(✅ [消費者庁](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/)) |
| 引用 | 他人の著作物を、条件を守って自分の文章に載せること |
| 情報商材 | ノウハウなどを有料で売る商品。トラブルが多い分野とされる(⚪) |

## 注意領域(⚪ 一般論)

| 領域 | 要点 | 運用での注意 |
|---|---|---|
| 禁止コンテンツ | 違法・公序良俗違反など(詳細は公式) | 差別的・攻撃的な宗教/政治の主張 |
| 有料コンテンツ | 情報商材等の扱い、誇大表現に注意 | 効果・成果の保証表現をしない |
| 著作権 | 引用の要件、画像・音楽の権利 | 引用は必要最小限、出典を明記 |
| 広告・PR | [legal-compliance](../01-common/legal-compliance.md) | 書籍・商品紹介のアフィリエイト。広告と分かる表示を |
| 医療・健康・投資 | 断定や勧誘表現の規制 | 効果効能を保証しない |
| 個人情報 | 他人の情報を載せない | 取材先・協力者・購入者 |
| 生成 AI | 規約・表示は要確認 | [ai-usage-policy](../01-common/ai-usage-policy.md) |

## 手順: 公開前のルール確認

1. **権利**: 文章・画像・音楽に他人のものが含まれていないか確認します([画像の出典と著作権](../01-common/image-sources-and-copyright.md)、[音楽](../01-common/music-and-licensing.md))。
2. **表現**: 「必ず」「絶対」「100%」などの言葉を使っていないか検索します。
3. **広告**: 企業から依頼・提供を受けた内容なら、冒頭に「PR」「広告」と書きます。アフィリエイトリンクがある場合も同様です。
4. **個人情報**: 写真やスクリーンショットに他人の名前・顔・メッセージが写っていないか確認します。
5. **有料記事の場合**: 下の「追加確認」を行います。

## 有料記事を出すときの追加確認

1. 無料部分と有料部分で、**内容の誇大表示**がないか。
2. 返金・キャンセルの扱い(note の規定)。返金の設定項目があれば確認(🟡 [02-posting](02-posting.md))。
3. 特定商取引法に基づく表記の要否([legal](../01-common/legal-compliance.md))。
4. 画像・引用部分の権利。
5. 「誰に向かないか」「効果には個人差がある」など、期待しすぎを防ぐ説明があるか(⚪)。

## 具体例: 表現の言い換え

| 避けたい表現 | 言い換え例 |
|---|---|
| 誰でも必ず月10万円稼げる | 私が試した方法と、そのときの結果を紹介します |
| これだけで病気が治る | 体験した感想です。症状がある場合は医療機関に相談してください |
| (広告なのに表示なし)おすすめの商品 | 【PR】〇〇社から商品提供を受けて紹介しています |

## 違反時

1. 通知・運営からの連絡を記録。
2. 問い合わせ窓口から事実を説明、修正を実施。
3. 重大な場合に備え、**記事のバックアップ**(本文テキスト)を非公開で保存([バックアップ](../01-common/data-backup-and-portability.md))。
4. 読者に影響がある場合(有料記事の内容変更など)は、記事内やお知らせで説明します。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| ネットで拾った画像を使った | 削除・差し替え。今後は素材サイトのライセンスを確認 |
| 引用が本文より長い | 引用は必要最小限にし、自分の解説を主にする |
| 案件の記事に PR 表示を忘れた | すぐ追記し、告知投稿にも表示を足す |
| 他人のスクリーンショットをそのまま掲載 | 名前・アイコンを隠すか、許可を取る |

## 注意点

- このページは法的助言ではありません。判断に迷う場合は公式窓口や専門家に相談してください。
- ルールは変わります。年に1回は規約を読み直す習慣をつけましょう。

## チェックリスト

- [ ] 権利(文章・画像・音楽)を確認した
- [ ] 誇大表現がない
- [ ] 広告・アフィリエイトの表示がある
- [ ] 個人情報が写っていない
- [ ] (有料)返金・特定商取引法の表記を確認した
- [ ] 記事のバックアップを取っている

# note のルール・ポリシー

一次資料: note の利用規約、ガイドライン（入口: https://www.help-note.com/hc/ja）。

## 注意領域 ⚪

| 領域 | 要点 |
|---|---|
| 禁止コンテンツ | 違法・公序良俗違反など（詳細は公式） |
| 有料コンテンツ | 情報商材等の扱い、誇大表現に注意 |
| 著作権 | 引用の要件、画像・音楽の権利 |
| 広告・PR | [legal-compliance](../01-common/legal-compliance.md) |
| 医療・健康・投資 | 断定や勧誘表現の規制 |
| 個人情報 | 他人の情報を載せない |

## 違反時

- 記事の非公開化、機能制限、アカウント停止。問い合わせ窓口を使う。

# TikTok 初期設定と投稿

> **このページで分かること**: TikTok アカウントの作り方、プロフィールの整え方、個人/ビジネスアカウントの違い、プライバシー設定、投稿の種類。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[アカウントの安全](../01-common/account-security.md)

> **確度について**: TikTok の公式ヘルプ(support.tiktok.com)は 2026年(皇紀2686年・令和8年)11月3日時点で www.tiktok.com/support へ転送され、この作業環境からは本文を取得できませんでした。このページの UI 名称・条件は ⚪(一般知識)または 🟡(二次資料)です。アプリの表示を優先してください(#32)。

## 概要

TikTok は、スマホの縦型動画を中心にしたサービスです。**フォロワーが少なくても「おすすめ」フィードに表示される機会がある**とされ、始めたばかりでも反応を得やすいのが特徴です(⚪)。そのぶん、最初のプロフィールと設定が「この人の動画をもっと見たい」と思われるかを左右します。

投稿・編集の具体的な手順は [08-posting-and-editing](08-posting-and-editing.md) にまとめています。

## 用語

| 用語 | 意味 |
|---|---|
| おすすめ(For You) | 興味に合わせて自動で動画が流れるメインのフィード |
| ユーザー名(@) | `@example` の形の固有 ID。URL やメンションに使われる |
| 名前 | プロフィールに表示される名前。ユーザー名とは別 |
| 個人アカウント / ビジネスアカウント | 個人のクリエイター向け / 企業・店舗向け。使える音源や機能が違う(⚪) |
| 非公開アカウント | 承認したフォロワーだけが動画を見られる設定 |
| デュエット / Stitch(ステッチ) | 他人の動画と並べて撮る / 他人の動画の一部を引用して続きを撮る機能 |
| TikTok Studio | 投稿の管理や分析を行うクリエイター向けの画面(🟡 名称・提供範囲は要確認) |

## 手順 1: アカウントを作る(⚪ 表記は変わる可能性)

1. アプリをインストールして開き、「プロフィール」を開きます。
2. 「登録」を選び、**電話番号またはメールアドレス**で登録します(Google・Apple などのアカウントでも登録できる場合があります)。
3. 生年月日を入力します。**年齢要件**(一般に13歳以上とされる ⚪)を守ります。年齢によって使える機能が変わります。
4. 確認コードを入力し、パスワードを設定します。
5. ユーザー名を決めます(後から変更できますが、変更の間隔に制限があるとされます ⚪ 要確認)。

> **運用のおすすめ**: お店やチームの運用なら、個人の連絡先ではなく**運用専用のメールアドレス**で登録し、2段階認証をオンにします([account-security](../01-common/account-security.md))。

## 手順 2: プロフィールを整える

| 項目 | 書き方 | 例(料理アカウント) |
|---|---|---|
| プロフィール画像 | 顔・ロゴを中央に。小さくても分かるもの | お店のロゴ |
| 名前 | 何の人か分かる言葉を入れる | 「5分おかず|作り置き」 |
| ユーザー名 | 短く、覚えやすく、他サービスと揃える | `@example_kitchen` |
| 自己紹介(bio) | **誰向けに何を、どの頻度で**。1〜2行 | 「平日5分で作れるおかずを毎日19時に投稿」 |
| リンク | プロフィールにリンクを置ける条件(フォロワー数・アカウントの種類など)は変わる ⚪ 要確認 | [link-in-bio](../01-common/link-in-bio-and-utm.md) |

## 手順 3: アカウントの種類を選ぶ

| 種類 | 向く人 | 主な違い | 確度 |
|---|---|---|---|
| 個人アカウント | 個人クリエイター | Creator Rewards Program の対象は個人アカウント(ビジネスは対象外とする資料) | 🟡 [05](05-monetization.md) |
| ビジネスアカウント | 企業・店舗 | **商用利用できる音源に限られる**(商用音楽ライブラリ)とされる。分析・広告機能 | ⚪ 要確認 |

> 店舗の宣伝に使う場合は、個人アカウントでも流行の楽曲を広告的に使うと権利の問題になり得ます。商用で使える音源かを確認します([music-and-licensing](../01-common/music-and-licensing.md))。

## 手順 4: プライバシーと安全の設定(⚪ 表記は変わる可能性)

「プロフィール」→ 右上のメニュー →「設定とプライバシー」から次を確認します。

1. **アカウントの公開範囲**: 公開 / 非公開。発信目的なら公開。
2. **コメント**: 全員 / フォロワー / オフ。フィルター(NG ワード)も設定([04-engagement](04-engagement.md))。
3. **デュエット・Stitch・ダウンロード**: 誰に許可するか。
4. **ダイレクトメッセージ**: 受け取る相手。知らない人からの DM は制限が安全。
5. **セキュリティ**: 2段階認証、ログイン中の端末の確認。

## 投稿の種類

| 種類 | 概要 | 確度 |
|---|---|---|
| 動画 | 縦型。撮影/アップロード/編集 | ⚪ |
| フォト投稿 | 複数画像+音楽(カルーセル型)。最大35枚とする資料 | 🟡 [02](02-media-specs.md) |
| ライブ | 配信。ギフト(投げ銭)。18歳以上などの条件 | 🟡 [05](05-monetization.md) |
| ストーリー | 24時間で消える投稿 | ⚪ |
| 長尺動画 | 10分〜(一部アカウントで60分とする資料 🟡) | 🟡 |

## 投稿手順(概要)

1. 「＋」から撮影/アップロード。
2. 編集(カット、字幕、エフェクト、音源)。
3. キャプション、ハッシュタグ、カバー、公開範囲、コメント許可、位置、**AI 生成コンテンツの表示** ⚪。
4. 広告・PR は**ブランドコンテンツのスイッチ**(有料プロモーション表示) ⚪ [legal](../01-common/legal-compliance.md)。
5. 投稿/予約(予約機能の提供範囲は要確認)。

詳しくは [08-posting-and-editing](08-posting-and-editing.md)。

## 設計(⚪)

- 冒頭1〜3秒で興味を作る。ループする構成も有効。
- 1動画1メッセージ。短いほど完走率が上がりやすい。
- 長尺は「解説+字幕+章立て」。
- 流行音源は**商用利用の可否**を確認。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 個人の電話番号で作り、担当交代で困った | 運用専用の連絡先に変更し、2段階認証を設定 |
| ビジネスアカウントで流行の曲が使えない | 商用で使える音源から選ぶ。仕様は ⚪ 要確認 |
| プロフィールが空で、動画を見ても フォローされない | 名前と bio に「何の人か」を書く |
| 知らない人からの DM が多い | DM の受信範囲を狭める |

## 注意点

- 年齢を偽って登録しません。未成年の場合、利用できる機能が制限されます(⚪)。
- ユーザー名・名前で他人や企業になりすますことは禁止です(⚪ [07](07-policies-and-checklist.md))。
- パスワードや確認コードは共有しません。

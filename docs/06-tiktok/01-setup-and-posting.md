# TikTok 初期設定と投稿

## 初期設定

1. **アカウント作成**: 運用専用のメール/電話。2段階認証([account-security](../01-common/account-security.md))。
2. **ユーザー名・名前・プロフィール画像・bio**: 何の動画か一目で分かる1行。
3. **アカウントの種類**: 個人/ビジネス。ビジネスアカウントは**商用で使える音源が限られる**(⚪ 要確認)。
4. **プライバシー**: 公開/非公開、コメント・DM・デュエットの許可。
5. **リンク**: プロフィールリンクの条件(フォロワー数など)は要確認 ⚪。
6. **年齢の設定**: 年齢要件を守る。
7. **クリエイターツール**: アナリティクス(プロ/クリエイターの切替が必要な場合 ⚪)。

## 投稿の種類

| 種類 | 概要 |
|---|---|
| 動画 | 縦型。録画/アップロード/編集 |
| フォト投稿 | 複数画像+音楽(カルーセル型) |
| ライブ | 配信。ギフト(投げ銭) |
| ストーリー | 24時間 |
| 長尺動画 | 10分〜(一部アカウントで60分とする資料 🟡) |

## 投稿手順

1. 「＋」から撮影/アップロード。
2. 編集(カット、字幕、エフェクト、音源)。
3. キャプション、ハッシュタグ、カバー、公開範囲、コメント許可、位置、**AI 生成コンテンツの表示** ⚪。
4. 広告・PR は**ブランドコンテンツのスイッチ**(有料プロモーション表示) ⚪ [legal](../01-common/legal-compliance.md)。
5. 投稿/予約(予約機能の提供範囲は要確認)。

## 設計(⚪)

- 冒頭1〜3秒で興味を作る。ループする構成も有効。
- 1動画1メッセージ。短いほど完走率が上がりやすい。
- 長尺は「解説+字幕+章立て」。
- 流行音源は**商用利用の可否**を確認。

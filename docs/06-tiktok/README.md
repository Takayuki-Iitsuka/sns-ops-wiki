# TikTok

> **このページで分かること**: TikTok の特徴、向いている用途、このフォルダのページの読む順番。
>
> **対象**: 初心者  **先に読むページ**: [はじめての SNS 運用](../00-meta/beginners-guide.md)、[サービスの選び方](../01-common/choosing-platforms.md)

## 概要

縦型短尺動画の発見(おすすめフィード)に強く、**フォロワーが少なくても拡散されやすい**とされるサービスです(⚪)。クリエイター向けの報酬プログラム(Creator Rewards)、ライブギフト、TikTok Shop などの収益手段があります。

## 特徴

| 項目 | 内容 |
|---|---|
| 形式 | 縦型動画、フォト投稿、ライブ、ストーリー |
| 強み | 新規流入の大きさ、音源・エフェクト文化、短時間で試せる |
| 弱み | 制作頻度、トレンドの速さ、収益プログラムの条件変動、規制・地域差 |
| 向く用途 | 認知拡大、商品紹介、教育系ショート |
| 収益化の入口 | Creator Rewards(フォロワー1万人などとする資料 🟡)、TikTok Shop(日本は 2025-06-30 開始 🟡) |

## 用語

| 用語 | 意味 |
|---|---|
| おすすめ(For You) | 興味に合わせて動画が流れるメインのフィード |
| デュエット / Stitch | 他人の動画と並べる / 引用して続ける機能 |
| Creator Rewards Program | 1分以上の動画への報酬プログラム |
| TikTok Shop | アプリ内の EC 機能 |

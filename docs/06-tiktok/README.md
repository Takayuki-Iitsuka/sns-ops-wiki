# TikTok

縦型短尺動画の発見(おすすめフィード)に強く、**フォロワーが少なくても拡散されやすい**とされるサービスです(⚪)。クリエイター向けの報酬プログラム(Creator Rewards)、ライブギフト、TikTok Shop などの収益手段があります。

## 特徴

| 項目 | 内容 |
|---|---|
| 形式 | 縦型動画、フォト投稿、ライブ、ストーリー |
| 強み | 新規流入の大きさ、音源・エフェクト文化、短時間で試せる |
| 弱み | 制作頻度、トレンドの速さ、収益プログラムの条件変動、規制・地域差 |
| 向く用途 | 認知拡大、商品紹介、教育系ショート |

# TikTok の分析とコツ

> **このページで分かること**: アナリティクスの開き方、主な指標の意味、数字が悪いときの直し方、最初の1か月の検証の進め方。
>
> **対象**: 初心者  **先に読むページ**: [analytics-kpi](../01-common/analytics-kpi.md)

共通: [analytics-kpi](../01-common/analytics-kpi.md)

> **確度について**: 公式ヘルプの本文は 2026年(皇紀2686年・令和8年)11月3日時点で取得できませんでした。メニュー名と指標名は ⚪(表記は変わる可能性)です。

## 概要

TikTok の分析画面(アナリティクス)では、投稿ごとの再生数・視聴時間・反応と、フォロワーの属性が分かります。TikTok はフォロワー以外にも表示されやすいため、**「最後まで見られたか」「どこから見られたか」**を見ると、次に作る動画の手がかりになります(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| 再生数(視聴数) | 動画が再生された回数 |
| 平均視聴時間 | 1回の再生あたり、平均で何秒見られたか |
| 完全視聴率 | 最後まで見られた再生の割合 |
| 流入元(トラフィックソース) | おすすめ、フォロー中、検索、プロフィールなど、どこから見られたか |
| エンゲージメント | いいね・コメント・シェア・保存などの反応 |

## アナリティクスの開き方(⚪ 表記は変わる可能性)

1. 「プロフィール」→ 右上のメニュー →「TikTok Studio」(または「クリエイターツール」)を開きます。
2. 「アナリティクス」を選びます。期間(7日・28日など)を切り替えられます。
3. 動画ごとの詳細は、各動画の画面で「その他」や分析のマークから開きます。
4. パソコンのブラウザからも見られるとされます(🟡 名称・範囲は要確認)。

ビジネスアカウントや一部の機能では、表示される項目が異なる場合があります(⚪)。

## 指標(⚪)

| 指標 | 意味 | 使い方 |
|---|---|---|
| 再生数 | 視聴回数 | 露出 |
| 平均視聴時間 | 1回あたりの視聴時間 | 構成の評価 |
| 完全視聴率 | 最後まで見られた割合 | 長さと内容の適合 |
| 保存・シェア・コメント | 反応の質 | 有用性 |
| 流入元 | おすすめ/フォロー/検索/プロフィール | 発見経路 |
| フォロワー増 | 動画ごとの寄与 | 型の評価 |
| 視聴者の属性 | 年齢・地域・時間帯 | 内容・時間 |

## 症状 → 対処(⚪)

| 症状 | 考えられる原因 | 対処 |
|---|---|---|
| 再生数が少ない | 冒頭で離脱され、おすすめに広がらない | 最初の1〜2秒に結論か問いを置く |
| 平均視聴時間が短い | 前置きが長い、展開が遅い | 不要な間を削る、テンポを上げる |
| 完全視聴率が低い | 長すぎる | 同じ内容を短く作り直す |
| 再生は多いがフォローが増えない | プロフィールが弱い、単発の内容 | シリーズ化、bio を具体的に |
| 検索からの流入が少ない | キャプション・字幕に検索語がない | 1行目と画面内の文字に検索語を入れる([03](03-text-hashtags-alt.md)) |
| 保存が多い | 役に立つ内容 | 同じ型で続編を作る |

## コツ(⚪ 経験則)

1. 冒頭で**結論か問い**を示す。
2. 字幕を入れる(音なし視聴)。
3. **同じ型のシリーズ**で認知を作る。
4. 反応の良い動画を**別の切り口**で作り直す。
5. 毎日投稿よりも**型の検証**を優先(最初の1か月は3パターンを各5本)。
6. 動画の最後に**次の行動**(フォロー・プロフィール・保存)を1つだけ。
7. 他サービスに再利用するときは、**透かし(TikTok ロゴ)付き動画の転載を避け**、元データから書き出す。

## 最初の1か月の検証の進め方(⚪ 運用例)

1. 型を3つ決めます(例: A「1分解説」、B「ビフォーアフター」、C「よくある失敗」)。
2. 各5本、合計15本を4週間で投稿します。
3. 投稿から7日後に、平均視聴時間・完全視聴率・保存・フォロワー増を表に記録します。
4. 4週目に、最も成績の良い型を「主力」、2番目を「実験枠」にします。
5. 翌月は主力7割・実験3割で投稿します。

記録には [weekly-review](../../templates/weekly-review.md) を使います。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 投稿直後の再生数だけで判断 | 24時間後と7日後の2回で判断(⚪) |
| 毎回違うことをして型が見えない | 1つの型を5本は続ける |
| バズった1本を追いかける | 平均の底上げを優先する |

## チェックリスト(週次)

- [ ] 投稿ごとに平均視聴時間・完全視聴率・保存を記録
- [ ] 流入元の内訳(おすすめ・検索・プロフィール)を確認
- [ ] 次の投稿で変える点を1つだけ決めた

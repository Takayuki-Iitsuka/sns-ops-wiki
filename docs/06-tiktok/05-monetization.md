# TikTok の収益化

> **このページで分かること**: Creator Rewards Program・ライブギフト・サブスクリプション・TikTok Shop・ブランド案件など収益手段の全体像、報告されている条件、始め方、注意点。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [01-setup-and-posting](01-setup-and-posting.md)、[収益化の比較](../01-common/monetization-comparison.md)

> **条件は公式で未確認**です。TikTok は国別の対象リストを公開していない/頻繁に更新するため、二次資料の値は参考程度です (#33)。公式ヘルプ(support.tiktok.com)は 2026年(皇紀2686年・令和8年)11月3日時点で www.tiktok.com/support へ転送され、newsroom.tiktok.com とともにこの作業環境からは本文を取得できませんでした。公式ニュースルームの内容は検索結果の要約によるため 🟡 です。

## 概要

TikTok で収益を得る方法は、大きく「**TikTok から報酬を受け取る**(Creator Rewards Program、ライブギフト)」「**商品を売る・紹介する**(TikTok Shop)」「**外部の取引**(ブランド案件、自分の商品への誘導)」の3つです。条件や対象地域が変わりやすいので、**アプリ内の「TikTok Studio」や「クリエイターツール」の収益化メニューに表示される内容**を最終判断にしてください(⚪ メニュー名は変わる可能性)。

## 用語

| 用語 | 意味 |
|---|---|
| Creator Rewards Program | 条件を満たした1分以上の動画に報酬が出るプログラム。前身は Creativity Program Beta(🟡) |
| ライブギフト | ライブ中に視聴者が贈る有料アイテム。ダイヤモンドなどに換算される(⚪) |
| サブスクリプション | 視聴者が月額で支援し、限定特典を受け取る仕組み |
| TikTok Shop | アプリ内で商品の発見から購入まで完結する EC 機能 |
| アフィリエイト | 他社の商品を紹介し、売れた分の報酬を受け取る仕組み |
| RPM | 1,000回視聴あたりの報酬(⚪ 一般的な定義) |
| GMV | 流通総額(売上の合計) |

## 手段(🟡 二次資料)

| 手段 | 概要 | 報告されている条件 | 日本 |
|---|---|---|---|
| Creator Rewards Program | **1分超**の高品質・オリジナル動画に対する報酬 | フォロワー 10,000人、直近30日で 10万回視聴、18歳以上、良好な状態、対象地域 | 対象とする資料が多い |
| ライブギフト | ライブ中の投げ銭 | 年齢・フォロワー等の条件 | 要確認 |
| サブスクリプション | 月額課金 | 条件 | 要確認 |
| TikTok Shop(連携) | 商品販売/アフィリエイト | 地域・審査 | **2025年(皇紀2685年・令和7年)6月30日に提供開始**(🟡 公式ニュースルームの検索要約) |
| ブランド案件 | 企業との取引 | PR 表記必須 | — |
| 外部誘導 | プロフィールリンクで note・書籍・通販へ | リンクの条件 | — |

- 1000視聴あたり報酬(RPM)は約 $0.40〜$1.00 とする計算サイト(日本は約 $0.55 とする資料)があるが、**公式は固定値を公表していない** 🟡。
- 最低出金額は約 15,000円とする資料 🟡。

## Creator Rewards Program の詳細(🟡)

| 項目 | 報告されている内容 | 確度 |
|---|---|---|
| 開始 | 日本の公式ニュースルームで、Creativity Program Beta を経て **2024年(皇紀2684年・令和6年)3月**に正式開始と案内 | 🟡 検索要約 |
| 年齢 | 18歳以上 | 🟡 |
| フォロワー | 10,000人以上 | 🟡 |
| 視聴回数 | 直近30日で10万回以上 | 🟡 |
| アカウント | **個人アカウント**(ビジネスアカウントは対象外とする資料) | 🟡 |
| 対象動画 | **1分以上のオリジナル動画**。おすすめフィードで1,000回以上の有効な視聴とする資料(一部のみ) | 🟡 |
| 対象外とされるもの | デュエット、Stitch、フォトモードの投稿 | 🟡 |
| 報酬の要素 | オリジナリティ、再生時間、検索価値、エンゲージメントなど | 🟡 |

**始め方(⚪ 表記は変わる可能性)**

1. 「プロフィール」→ メニュー →「TikTok Studio」または「クリエイターツール」を開きます。
2. 「収益化」から Creator Rewards Program を選び、条件の達成状況を確認します。
3. 条件を満たしていれば申し込み、規約に同意します。
4. 報酬の受け取り方法(支払い情報)を登録します。

## TikTok Shop(日本。🟡 報道)

- 日本の TikTok Shop では、**GMV(流通総額)の約6割がライブ経由**と報じられている。
- 参加条件・手数料は公式で確認(#33)。
- 公式ニュースルームでは、**2025年6月30日に日本で提供開始**、ショップタブは数か月後に導入、TikTok Shop 広告は同年7月中に利用開始予定と案内されています(🟡 検索要約)。

**参加の形(⚪ 一般的な整理)**

| 立場 | やること |
|---|---|
| 販売者(セラー) | 自社の商品を登録して販売する。事業者としての審査がある |
| クリエイター(アフィリエイト) | 他社の商品を動画・ライブで紹介し、成果報酬を受け取る |

## 設計(⚪)

1. **1分超の動画**を作る方針ならば、構成を長尺向けに。
2. 報酬に依存せず、**他サービスへの誘導**で自前の資産を作る([funnel](../30-strategy/02-funnel.md))。
3. 音源・素材の権利がクリアな動画のみ収益化の対象になる点に注意。

## 具体例: イラストのアカウントの収益の組み立て(⚪)

1. 30秒の制作過程動画で認知を広げる。
2. 1分超の「描き方の解説」動画を週2本(Creator Rewards の対象を意識)。
3. 月1回のライブで質問に答え、ギフトを受け取る。
4. プロフィールのリンクから作品の販売ページへ誘導する。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| ビジネスアカウントで Creator Rewards を探した | 個人アカウントが対象とする資料。切り替えの影響を確認(🟡) |
| 1分未満の動画ばかりで報酬が出ない | 対象は1分以上とされる(🟡)。構成を見直す |
| 他人の動画の切り抜きで報酬を狙った | オリジナルでない動画は対象外とされ、権利侵害にもなる |
| PR を表示せずに案件を投稿した | ブランドコンテンツの表示をオンにする([legal](../01-common/legal-compliance.md)) |

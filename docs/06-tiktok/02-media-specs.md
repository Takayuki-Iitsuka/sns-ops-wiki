# TikTok 動画・画像仕様

> **このページで分かること**: TikTok に投稿する動画・写真の比率・解像度・長さ・容量の目安、画面の安全領域、書き出し設定。
>
> **対象**: 初心者  **先に読むページ**: [動画の基本](../01-common/video-basics.md)

> すべて二次資料(🟡)。ファイルサイズ・長さは**端末・アップロード方法・アカウントで変わる**ため、公式で確認 (#32)。公式ヘルプ(support.tiktok.com)は 2026年(皇紀2686年・令和8年)11月3日時点で www.tiktok.com/support へ転送され、本文を取得できませんでした。

## 概要

TikTok はスマホの全画面で見られる**縦型 9:16** が基本です。横長の動画も投稿できますが、上下に黒い帯が出て小さく見えます(⚪)。迷ったら「**1080×1920・MP4・H.264・30fps**」で書き出してください。画面の下と右にはボタンやキャプションが重なるので、文字はその外に置きます。

## 用語

| 用語 | 意味 |
|---|---|
| 9:16 | 縦長の比率。スマホの全画面に合う |
| 解像度 | 画像の縦横のピクセル数。1080×1920 など |
| 安全領域 | ボタンや文字に隠れない画面の範囲 |
| H.264 / AAC | 一般的な映像 / 音声の圧縮方式 |
| fps | 1秒あたりのコマ数 |

## 動画

| 項目 | 値 | 確度 |
|---|---|---|
| 比率・解像度 | 9:16、1080×1920 | 🟡 |
| 形式 | MP4 / MOV。推奨は H.264 映像+AAC 音声 | 🟡 |
| 長さ | 最大 10分(一部アカウントや Web で 60分とする資料) | 🟡 |
| 長さ(補足) | **アップロードは最大60分、アプリ内撮影は10分**とする資料が多いが、アプリ内撮影を3分とする資料もあり不一致。選択時にアプリが表示する上限を優先 | 🟡 |
| 容量 | モバイル 約72MB(Android)/ 約288MB(iOS)、Web 1GB〜と資料により不一致 | 🟡 |
| 広告用 | 5〜60秒、500MB 以下 | 🟡 |
| フレームレート | 24〜60fps | ⚪ |

> 60分のアップロードは 2024年(皇紀2684年・令和6年)に一部地域・一部ユーザーでテストされていたと報じられています(🟡)。全員が使えるとは限りません。

## フォト投稿

| 項目 | 値 | 確度 |
|---|---|---|
| 比率 | 9:16 を基本(1:1、4:5 も可とされる) | ⚪ |
| 解像度 | 1080×1920 | ⚪ |
| 形式 | JPEG / PNG | ⚪ |
| 枚数 | **最大35枚**とする資料が複数(2枚以上) | 🟡 |

## カバー・プロフィール

| 項目 | 値 | 確度 |
|---|---|---|
| カバー | 動画の1コマまたは画像。プロフィールの一覧は縦長で切り抜かれる | ⚪ |
| プロフィール画像 | 正方形、円形切り抜き | ⚪ |

**カバーのコツ(⚪)**: 一覧では上下が少し切れるので、文字は中央に置きます。シリーズは色と文字の位置を揃えると、プロフィールが「目次」のように見えます。

## 安全領域(⚪)

画面の**下約15%・右約15%・上約10%**にUI(キャプション、ボタン、検索)が重なる。字幕・主要要素はこの外に。

**1080×1920 での目安(⚪ 上の割合から計算)**

| 位置 | 避ける範囲の目安 |
|---|---|
| 上 | 約190px |
| 下 | 約290px |
| 右 | 約160px |

アプリの「プレビュー」で、文字がボタンやキャプションに重ならないか必ず確認します。

## 書き出し

[export-presets](../01-common/export-presets.md)。比較は [video-specs-comparison](../01-common/video-specs-comparison.md)。

**書き出しの例(⚪)**

| 用途 | 設定 |
|---|---|
| 一般的な動画 | MP4 / H.264 / 1080×1920 / 30fps / AAC |
| 動きの多い動画 | 同上で 60fps |
| 横長の素材 | 9:16 のキャンバスに配置し、上下に文字を入れて余白を活用 |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 字幕がキャプションに隠れる | 下約15%を空ける |
| 横長の動画が小さく見える | 9:16 に再編集する |
| 画質が落ちた | 1080×1920 で書き出し、アップロード時の画質設定(高画質アップロード)を確認(⚪) |
| 長い動画が選べない | アカウントの上限を確認。アプリの表示が優先 |

## チェックリスト

- [ ] 9:16、1080×1920 で書き出した
- [ ] 文字・顔が安全領域の内側
- [ ] カバーの文字は中央
- [ ] 長さはアプリに表示される上限内

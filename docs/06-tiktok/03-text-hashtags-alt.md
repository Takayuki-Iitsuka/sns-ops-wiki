# TikTok キャプション・ハッシュタグ・字幕

> **このページで分かること**: キャプションの書き方と文字数の現状、ハッシュタグの選び方、字幕・画面内テキストの作り方、アクセシビリティ。
>
> **対象**: 初心者  **先に読むページ**: [08-posting-and-editing](08-posting-and-editing.md)、[hashtags](../01-common/hashtags.md)

> **確度について**: 公式ヘルプの本文は 2026年(皇紀2686年・令和8年)11月3日時点で取得できませんでした。文字数などの数値は二次資料で不一致です(#32)。

## 概要

TikTok では、動画を見る前に**画面内のテキスト**、見た後に**キャプション**が読まれます。TikTok 内で検索する人も多く、動画内の言葉・字幕・キャプションが見つけてもらう手がかりになるとされます(⚪)。短く、具体的に、何の動画かを伝えることが基本です。

## 用語

| 用語 | 意味 |
|---|---|
| キャプション | 投稿に付ける説明文。動画の下に表示される |
| オンスクリーンテキスト | 動画の画面上に置く文字 |
| 自動キャプション | 音声から自動生成される字幕 |
| ハッシュタグ | `#` を付けた語。タップすると同じタグの動画一覧が開く |
| シリーズタグ | 自分のシリーズ専用に作るハッシュタグ(例 `#5分おかず`) |

## キャプション

| 項目 | 内容 | 確度 |
|---|---|---|
| 文字数 | 数千字まで拡張された報道があるが、**未確認** | ⚪ #32 |
| 文字数(補足) | 動画のキャプションを **2,200文字**とする文字数カウンターの資料、フォト投稿の説明を **4,000文字**とする資料(開発者向け API の仕様由来とされ、アプリ内の上限とは別の可能性)があり不一致 | 🟡 |
| 構成 | 1行目に要点、次にタグ | ⚪ |
| 検索 | TikTok は**動画内の言葉・字幕・キャプションを検索に使う**とされる | ⚪ |

**書き方の手順(⚪)**

1. 1行目: 動画の要点を**検索されそうな言葉**で書く(例「鶏むね肉をしっとり焼くコツ」)。
2. 2行目: 補足(分量、所要時間、注意点)。
3. 3行目: 問いかけ(「どの方法を試したいですか?」)で、コメントのきっかけを作る。
4. 最後: ハッシュタグ3〜5個。

**例**

| 良い例 | 悪い例 |
|---|---|
| 鶏むね肉をしっとり焼くコツ3つ。2枚分、15分。どれから試しますか? #鶏むね #作り置き #時短レシピ | 見て!!! #fyp #おすすめ #バズりたい #viral #いいね |

## ハッシュタグ

- 3〜5個程度を目安(⚪ 公式の推奨は未確認)。
- 構成: 大きな話題タグ1 + 具体タグ1〜2 + 自分のシリーズタグ1。
- 無関係な流行タグは付けない(スパム扱いのリスク)。

**選び方の手順(⚪)**

1. 検索欄に候補の語を入れ、関連する語と動画の多さを見る。
2. 大きすぎる語(例 `#料理`)と、具体的な語(例 `#鶏むねレシピ`)を組み合わせる。
3. シリーズタグを毎回付け、プロフィールから辿れるようにする。
4. 1か月ごとに、反応の良かった投稿のタグを見直す。

共通: [hashtags](../01-common/hashtags.md)

## 字幕・テキスト

- 動画内テキスト(オンスクリーン)で冒頭に主題を示す。
- 自動字幕は誤りを確認して修正。
- 色・コントラスト、安全領域([02-media-specs](02-media-specs.md))。

**字幕の作り方(⚪ 表記は変わる可能性)**

1. 編集画面で「キャプション」(自動字幕)を選び、言語を選んで生成します。
2. 一覧で誤字・固有名詞・数字を直します。
3. 文字の大きさ・色を調整し、下約15%と右約15%を避けて配置します。
4. 外部の編集アプリで字幕を焼き込む場合は、アプリ側の自動字幕と二重にならないようにします。

## アクセシビリティ

- 動画の要点をキャプションにも書く。
- 点滅や激しい動きを避ける。
- フォト投稿は画像内の文字をキャプションにも書く([alt-text](../01-common/alt-text.md))。
- 音なしで見る人のために、字幕かテキストを必ず入れる(⚪)。
- 白い文字には縁取りか影を付け、明るい背景でも読めるようにする。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| キャプションがタグだけ | 1行目に要点を文章で書く |
| 自動字幕の誤字を放置 | 公開前に全文を確認 |
| 流行タグを大量に付けた | 内容と関係あるタグ3〜5個に絞る |
| 字幕がボタンに重なった | 安全領域を確認([02](02-media-specs.md)) |

## チェックリスト

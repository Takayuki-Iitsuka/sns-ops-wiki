# TikTok 投稿・編集の手順

> **このページで分かること**: アプリでの撮影・アップロード・編集・投稿の流れ、フォト投稿、下書きと予約、投稿画面の各設定の意味、パソコンからの投稿。
>
> **対象**: 初心者  **先に読むページ**: [01-setup-and-posting](01-setup-and-posting.md)

> **確度について**: TikTok の公式ヘルプ本文は、2026年(皇紀2686年・令和8年)11月3日時点でこの作業環境から取得できませんでした。ボタン名・画面の構成は ⚪(一般知識)で、**アプリの更新で変わる可能性**があります(#32)。

## 概要

TikTok の投稿は「**素材を用意 → 編集 → 投稿画面で設定 → 投稿(または予約)**」の4段階です。アプリの中で撮影から編集まで完結できますが、凝った編集は別の編集アプリで書き出してからアップロードする方法もあります([動画編集アプリ](../01-common/video-editing-apps.md))。

## 用語

| 用語 | 意味 |
|---|---|
| 音源(サウンド) | 動画に付ける音楽・音声。他人の動画の音を使うこともできる |
| エフェクト | 顔や画面に付ける加工・特殊効果 |
| テキスト読み上げ | 画面の文字を合成音声で読む機能 |
| 自動キャプション | 音声から自動で字幕を作る機能 |
| カバー | プロフィールの一覧に表示される動画の表紙 |
| 下書き | 投稿前の動画を保存しておく場所(自分だけが見られる) |
| ブランドコンテンツ | 企業から対価を受けて作った PR 投稿。開示の設定がある |

## 手順 1: 撮影またはアップロードする(⚪)

1. 画面下の「＋」をタップします。
2. **撮影する場合**: 長さ(秒数)を選び、赤い撮影ボタンを押します。複数回に分けて撮影し、つなげることもできます。
3. **アップロードする場合**: 「アップロード」から端末内の動画・写真を選びます。
4. 選べる長さの上限はアカウントや端末で異なります。アプリが表示する上限を確認します(🟡 [02-media-specs](02-media-specs.md))。

## 手順 2: 編集する(⚪)

| 編集 | できること | コツ |
|---|---|---|
| カット・トリミング | 不要な部分を削る | 最初の「えーと」や間を削る |
| テキスト | 画面に文字を置く。表示時間も指定 | 冒頭に主題を大きく。安全領域の内側に([02](02-media-specs.md)) |
| 自動キャプション | 音声から字幕を作る | 誤字を必ず確認・修正 |
| 音源 | 楽曲・効果音を付ける。音量を調整 | 話し声がある動画は BGM を小さく |
| エフェクト・フィルター | 加工・色調整 | 内容の邪魔にならない範囲で |
| ボイスオーバー | 後から声を録音して重ねる | 静かな場所で録る |

## 手順 3: 投稿画面で設定する(⚪)

| 項目 | 内容 | 初心者の目安 |
|---|---|---|
| キャプション | 動画の説明文 | 1行目に要点([03-text-hashtags-alt](03-text-hashtags-alt.md)) |
| ハッシュタグ | `#` を付けた語 | 3〜5個(⚪) |
| メンション | `@ユーザー名` で他の人を紹介 | 許可を得た相手のみ |
| カバーを選択 | 一覧に出る表紙 | 文字入りの1コマを選ぶ |
| 位置情報 | 場所を付ける | 自宅の近くは付けない([privacy](../01-common/privacy-and-personal-info.md)) |
| 公開範囲 | 全員 / フォロワー / 友達 / 自分のみ | 確認用は「自分のみ」で投稿 |
| コメント・デュエット・Stitch の許可 | 動画ごとに設定 | 荒れやすい話題はコメントを制限 |
| AI 生成コンテンツ | AI で作った・大きく加工した内容を示すラベル | 現実的な AI 映像はオン([07](07-policies-and-checklist.md)) |
| コンテンツの開示(ブランドコンテンツ) | 企業からの対価がある PR を示す | 案件なら必ずオン([legal](../01-common/legal-compliance.md)) |

## 手順 4: 投稿する・予約する・下書きに保存する(⚪)

1. **投稿**: 設定を確認して「投稿」をタップします。
2. **下書き**: 「下書き」を選ぶと自分だけが見られる場所に保存されます。アプリを削除すると下書きが消える場合があるので、元データは端末にも残します(⚪)。
3. **予約投稿**: 予約機能の提供範囲(アプリか、パソコン向けの TikTok Studio か)は変わります(🟡 要確認)。

## フォト投稿の手順(⚪)

1. 「＋」→「アップロード」で写真を複数選びます(最大35枚とする資料 🟡)。
2. 「写真」モードを選び、音源・テキストを付けます。
3. タイトルとキャプションを書きます。**画像内の文字はキャプションにも書く**と、読み上げ機能の利用者にも伝わります([alt-text](../01-common/alt-text.md))。
4. 投稿します。

## パソコンから投稿する(🟡)

- ブラウザの TikTok(TikTok Studio)からアップロードできるとされます。ブラウザからは**動画全体がアップロードされ、長さを切りたい場合はアプリで編集する**とする資料があります(🟡)。
- 編集アプリで書き出した完成版(9:16、1080×1920)を上げる運用に向きます。

## 具体例: 地域の店の1本(30秒)

| 秒 | 内容 |
|---|---|
| 0〜2 | 「今日だけの限定パン、残り10個です」と文字+焼きたての映像 |
| 2〜20 | 作る工程を3カットで |
| 20〜27 | 断面のアップ、価格のテキスト |
| 27〜30 | 「営業時間はプロフィールに」 |

キャプション例: `毎朝7時に焼き上がる限定パン。売り切れ次第終了です。 #パン屋 #〇〇市グルメ #焼きたて`(地域名は自分の地域に置き換える)

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 投稿後に誤字に気付いた | 投稿後に動画の中身は直せない場合が多い(⚪)。「自分のみ」で投稿して確認する習慣を |
| 字幕がボタンに隠れた | 安全領域の内側に配置([02](02-media-specs.md)) |
| 下書きが消えた | 元動画を端末やクラウドにも保存([data-backup](../01-common/data-backup-and-portability.md)) |
| 他サービスの透かし入り動画を上げた | 元データから書き出し直す |

## チェックリスト

- [ ] 冒頭2秒で主題が分かる
- [ ] 字幕・テキストの誤字と位置を確認
- [ ] 音源は商用利用の可否を確認(ビジネスアカウントは特に)
- [ ] キャプション1行目に要点、ハッシュタグ3〜5個
- [ ] 位置情報・映り込みに個人情報がない
- [ ] AI 生成・ブランドコンテンツの表示を確認

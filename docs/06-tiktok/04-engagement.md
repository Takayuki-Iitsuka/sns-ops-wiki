# TikTok のコメント・ライブ・コミュニティ

> **このページで分かること**: コメントへの返信(動画で返信を含む)、コメントの管理、デュエット・Stitch の使い方と許可設定、ライブ配信の基本、未成年への配慮。
>
> **対象**: 初心者  **先に読むページ**: [comments-and-engagement](../01-common/comments-and-engagement.md)

共通: [comments-and-engagement](../01-common/comments-and-engagement.md)

> **確度について**: 公式ヘルプの本文は 2026年(皇紀2686年・令和8年)11月3日時点で取得できませんでした。機能名・条件は ⚪/🟡 です。

## 概要

TikTok では、コメント・デュエット・Stitch を通じて、視聴者が**動画の続きを一緒に作る**ような交流が起きます。特に「コメントに動画で返信」は、質問がそのまま次の企画になるため、初心者でも投稿のネタ切れを防げます(⚪)。一方で若い利用者が多いため、安全への配慮が欠かせません。

## 用語

| 用語 | 意味 |
|---|---|
| 動画で返信 | コメントを画面に表示した状態で、返事の動画を撮る機能 |
| デュエット | 他人の動画と自分の動画を左右に並べる |
| Stitch(ステッチ) | 他人の動画の冒頭数秒を引用し、続けて自分の動画を流す |
| コメントフィルター | NG ワードなどでコメントを自動で非表示・保留にする設定 |
| ピン留め | コメントを一番上に固定する |
| ギフト | ライブ中に視聴者が贈る有料アイテム(投げ銭) |
| モデレーター | ライブのコメント管理を手伝う人 |

## 機能(⚪)

| 機能 | 使い方 |
|---|---|
| コメント返信(動画で返信) | 質問に動画で答える。ネタが連鎖する |
| デュエット/ステッチ | 他の動画と並べる/引用する。許可設定を確認 |
| コメントフィルター | NG ワード、保留 |
| ピン留め | 良いコメントを上部に |
| ライブ | リアルタイム、ギフト |
| コミュニティ/グループ | 提供状況は要確認 |

## 手順 1: コメントを管理する(⚪ 表記は変わる可能性)

1. 「プロフィール」→ メニュー →「設定とプライバシー」→「プライバシー」→「コメント」を開きます。
2. コメントできる人(全員 / フォロワー / オフなど)を選びます。
3. **フィルター**: スパムや不快なコメントのフィルター、**キーワードのフィルター**(NG ワード)をオンにし、語を登録します。
4. 個別のコメントは長押しで、返信・ピン留め・削除・報告・その人のブロックができます。

## 手順 2: コメントに動画で返信する(⚪)

1. 返信したいコメントの「返信」付近にある動画(カメラ)のマークをタップします。
2. コメントが画面に貼られた状態で撮影します。
3. 通常の投稿と同じように編集・投稿します。

**例**: 「冷凍で何日もちますか?」というコメントに、保存容器を見せながら15秒で答える。

## 手順 3: デュエット・Stitch を使う・許可する(⚪)

- **使う**: 他人の動画の「シェア」→「デュエット」または「Stitch」。
- **許可する**: 動画ごとの投稿設定、または「設定とプライバシー」で、誰に許可するかを選びます。
- 他人の動画を使うときは、**相手を尊重する内容**にします。からかい・晒し目的の使用は、いじめ・嫌がらせのポリシー違反になり得ます([07](07-policies-and-checklist.md))。

## ライブ配信の基本(🟡)

| 項目 | 内容 | 確度 |
|---|---|---|
| 年齢 | 18歳以上が基準とする資料 | 🟡 |
| フォロワー | 以前は1,000人、現在はより少ない人数(50人とする資料)と、時期により変動 | 🟡 不一致 |
| パソコン配信 | 専用ソフト「TikTok LIVE Studio」の利用とする資料。条件はスマホより厳しいとされる | 🟡 |
| ギフトの受け取り | 条件はアプリで確認 | ⚪ 要確認 |

アプリの「＋」に「LIVE」が表示されない場合は、条件を満たしていないか、制限を受けている可能性があります(🟡)。

**ライブの進め方(⚪)**

1. 前日までに動画やストーリーで日時を告知します。
2. 信頼できる人をモデレーターにし、NG ワードを登録します。
3. 冒頭で「今日の内容」を伝え、途中から来た人にも数分ごとに繰り返します。
4. 終わりに次回の予定を伝えます。

詳しくは [live-streaming](../01-common/live-streaming.md)。

## 運用のコツ

1. 質問コメントを**次の動画のネタ**にする。
2. 否定的なコメントには短く冷静に。拡大するなら [crisis-response](../01-common/crisis-response.md)。
3. ライブは**定時**に行い、告知を事前に出す。
4. 他者の動画を使うデュエット/ステッチは、相手への敬意と権利に配慮。
5. 公開後しばらくは通知を確認し、早めに返信する(⚪)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 荒らしに長文で反論した | 返信せず、削除・ブロック・報告 |
| 自分の動画が悪意のある Stitch に使われた | 報告し、Stitch の許可範囲を狭める |
| ライブボタンが出ない | 年齢・フォロワー・制限の有無を確認(🟡) |
| NG ワードの登録漏れ | よく来るスパムの言い回しを定期的に追加 |

## 注意

- 若年ユーザーが多く、**未成年への配慮**(連絡先交換を促さない、個人情報を求めない)を徹底。
- ライブ中に視聴者へギフトを強く求める言い方は避けます(⚪)。
- 視聴者の顔や名前を、本人の許可なく動画に使いません([privacy](../01-common/privacy-and-personal-info.md))。

# TikTok のルールとチェックリスト

一次資料: コミュニティガイドライン、利用規約、クリエイター報酬プログラムのポリシー(TikTok ヘルプ。本文は未取得 #33)。

## 注意領域(⚪ 一般論)

| 領域 | 要点 | 運用での注意 |
|---|---|---|
| コミュニティガイドライン | 違反は削除・制限 | 暴力・ヘイト・誤情報・未成年の保護 |
| 著作権・音源 | 商用アカウントは音源が限定される場合あり | 権利クリアな音源 |
| 低品質/オリジナルでない | 報酬対象外 | 他人の動画の転載禁止 |
| AI 生成コンテンツ | ラベル表示の要件あり ⚪ | [ai-usage-policy](../01-common/ai-usage-policy.md) |
| 広告・PR | ブランドコンテンツの開示 | [legal-compliance](../01-common/legal-compliance.md) |
| 医療・金融 | 断定・勧誘は規制対象 | [sensitive-topics](../01-common/sensitive-topics-and-accuracy.md) |
| 地域の規制 | 国・地域により提供状況が変わる | 要確認 |

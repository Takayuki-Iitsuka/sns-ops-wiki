# TikTok のルールとチェックリスト

> **このページで分かること**: コミュニティガイドラインの違反と「ストライク」の仕組み、AI 生成コンテンツのラベル、PR の開示、違反時の対応、投稿ごとのチェックリスト。
>
> **対象**: 初心者  **先に読むページ**: [legal-compliance](../01-common/legal-compliance.md)

一次資料: コミュニティガイドライン、利用規約、クリエイター報酬プログラムのポリシー(TikTok ヘルプ。本文は未取得 #33)。2026年(皇紀2686年・令和8年)11月3日時点で support.tiktok.com と newsroom.tiktok.com はこの作業環境から取得できず、公式ニュースルームの内容は検索結果の要約(🟡)です。

## 概要

TikTok では、**コミュニティガイドライン**(禁止される内容)と**利用規約**が全員に適用され、収益化するとさらに報酬プログラムのポリシーが加わります。違反すると、動画の削除、おすすめに表示されにくくなる制限、機能の停止、アカウントの永久停止につながります。若い利用者が多いため、安全と未成年の保護が特に重視されます(⚪)。

## 用語

| 用語 | 意味 |
|---|---|
| コミュニティガイドライン | TikTok で禁止されている内容の決まり |
| ストライク(違反の記録) | 違反ごとにアカウントに付く記録。累積すると永久停止(🟡) |
| おすすめ対象外 | 削除はされないが、おすすめフィードに表示されなくなること(⚪) |
| AI 生成コンテンツ(AIGC) | AI で作った・大きく加工した画像・動画・音声 |
| C2PA / コンテンツクレデンシャル | 画像・動画の出所や編集履歴を記録する業界標準。TikTok は AI ラベルの自動付与に使う(🟡) |
| ブランドコンテンツ | 企業から対価を受けた PR 投稿 |

## ストライクの仕組み(🟡 公式ニュースルーム 2023年2月の発表の検索要約)

2023年(皇紀2683年・令和5年)2月の公式発表として、次のように報告されています。

- 違反ごとにストライクが付き、**90日後に記録から消える**。
- ポリシー全体、または**特定の機能(コメント、LIVE など)や特定のポリシー(いじめ・嫌がらせなど)**の中でしきい値に達すると、**永久停止**。
- しきい値は害の大きさで異なり、ヘイト的な思想はスパムより厳しい。具体的な回数は公表されていない。
- 永久停止が近いクリエイターには通知する。

現行の仕組みは公式ヘルプで要確認です(#33)。

## AI 生成コンテンツのラベル(🟡 公式ニュースルーム 2024年5月の発表の検索要約)

- 現実的な AI 生成コンテンツを投稿するときは、**クリエイターが AI 生成である旨を表示する**よう求められている。
- 2024年(皇紀2684年・令和6年)5月、**C2PA のコンテンツクレデンシャル**を使い、他のサービスで作られた AI 画像・動画に自動でラベルを付ける取り組みを開始(音声にも拡大予定とされた)。
- 投稿画面の「AI 生成コンテンツ」の設定でラベルを付けられる(⚪ 表記は変わる可能性)。

詳細: [ai-rules-by-platform](../01-common/ai-rules-by-platform.md)、[ai-usage-policy](../01-common/ai-usage-policy.md)。

## 注意領域(⚪ 一般論)

| 領域 | 要点 | 運用での注意 |
|---|---|---|
| コミュニティガイドライン | 違反は削除・制限 | 暴力・ヘイト・誤情報・未成年の保護 |
| 著作権・音源 | 商用アカウントは音源が限定される場合あり | 権利クリアな音源([music-and-licensing](../01-common/music-and-licensing.md)) |
| 低品質/オリジナルでない | 報酬対象外 | 他人の動画の転載禁止 |
| AI 生成コンテンツ | ラベル表示の要件あり(🟡 上記) | [ai-usage-policy](../01-common/ai-usage-policy.md) |
| 広告・PR | ブランドコンテンツの開示 | [legal-compliance](../01-common/legal-compliance.md) |
| 医療・金融 | 断定・勧誘は規制対象 | [sensitive-topics](../01-common/sensitive-topics-and-accuracy.md) |
| 地域の規制 | 国・地域により提供状況が変わる | 要確認 |
| 危険な行為・チャレンジ | まねされると危険な行為 | 安全な内容に。未成年が見る前提で |
| 個人情報 | 自分・他人の住所、学校、連絡先 | 映り込みも確認([privacy](../01-common/privacy-and-personal-info.md)) |

## 違反の通知を受けたとき(⚪)

1. 通知の内容(日時、対象の動画、理由)をスクリーンショットで記録します。
2. 該当するガイドラインを読み、何が問題か確認します。
3. 誤判定と考えるなら、通知から**異議申し立て(再審査)**を行います。
4. 正当なら、同じ型の過去動画も見直します。
5. ストライクが残る期間(🟡 90日)は、同じ種類の内容を避けます。
6. 他のサービスに連絡手段を残しておきます([data-backup](../01-common/data-backup-and-portability.md))。

## チェックリスト

**投稿前**
- [ ] 9:16、1080×1920、字幕は安全領域内([02-media-specs](02-media-specs.md))
- [ ] 冒頭3秒に主題
- [ ] 音源・素材の権利
- [ ] AI 生成・PR の開示
- [ ] 個人情報・未成年が写っていないか
- [ ] キャプションとタグ(3〜5個)
- [ ] 位置情報を付けすぎていない
- [ ] 医療・金融などは断定せず、出典を確認

**投稿後**
- [ ] コメントへの返信
- [ ] 24時間・7日後に完全視聴率・保存を記録

**月次**
- [ ] 報酬プログラム条件の達成状況([05-monetization](05-monetization.md))
- [ ] 違反の通知・制限がないか確認
- [ ] 規約・仕様の変更を [verification-queue](../00-meta/verification-queue.md) に追記

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 流行の曲を店の宣伝に使った | 商用で使える音源に差し替える |
| AI で作ったリアルな映像にラベルを付けなかった | 投稿設定でラベルをオンにする |
| 他人の動画を無断で転載した | 削除し、元の投稿者の許可と出典表示を |
| 同じ違反を短期間に繰り返した | ストライクが累積し永久停止の恐れ(🟡)。投稿を止めて原因を確認 |

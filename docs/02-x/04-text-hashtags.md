# X 文字数・ハッシュタグ・メンション・リンク

> **このページで分かること**: X の文字数の数え方(日本語・絵文字・URL)、ハッシュタグ・メンション・リンクの使い方と文章のコツ。
>
> **対象**: 初心者  **先に読むページ**: [02-posting](02-posting.md)

## 概要

X の文字数は「見た目の文字数」ではなく **重み付き(weighted)** で数えます。日本語は1字を2と数えるため、英語の半分しか書けません。この仕組みを知らないと「あと少しなのに投稿できない」ことが起きます。

ハッシュタグやメンションは、届く範囲を広げる道具ですが、使いすぎると読みにくくなり、スパムと受け取られることもあります。

## 用語

| 用語 | 意味 |
|---|---|
| weighted length(重み付き文字数) | 文字の種類ごとに 1 か 2 で数えた合計 |
| CJK(Chinese, Japanese, Korean、中日韓の文字) | ひらがな・カタカナ・漢字など。X では 1字=2 |
| hashtag(ハッシュタグ) | `#` + 語句。同じ話題の投稿を探しやすくする |
| mention(メンション) | `@ユーザー名` を本文に書き、相手に知らせること |
| t.co(短縮 URL) | X が URL を自動で置き換える短縮形式 |
| CTA(Call To Action、行動の呼びかけ) | 「保存してね」「詳細はリンクへ」など |

## 手順 / 仕様

### 文字数の数え方(✅ 公式の開発者文書)

| 文字の種類 | 1字の重み | 1ポストの上限の目安 | 確度 |
|---|---|---|---|
| 英数字・記号(Latin) | 1 | 280字 | ✅ |
| 日本語(CJK) | **2** | **140字** | ✅ |
| 絵文字 | **2**(肌色・結合した絵文字も2) | 140個 | ✅ |
| その他の Unicode | 2(既定) | 種類による | ✅ |
| URL | 長さに関係なく **23** | — | ✅ |
| 返信の先頭に自動で付く @ユーザー名 | **数えない** | — | ✅ |
| 自分で追加した @ユーザー名 | 通常どおり数える | — | ✅ |
| 添付した画像・動画 | **0** | — | ✅ |
| ハッシュタグ | 通常どおり数える(`#` も含む) | — | ✅ |

出典: [docs.x.com Counting Characters](https://docs.x.com/fundamentals/counting-characters.md)。

- 長文ポストは Premium で拡張され、**最大25,000字** と公式ヘルプにある(🟡 [X Premium how to](https://help.x.com/en/using-x/x-premium-how-to) の検索要約)。
- タイムラインでは長文の冒頭だけが表示され、「さらに表示」で続きが開く形式とされる(🟡 解説記事)。

#### 計算例

| 本文 | 計算 | 合計 |
|---|---|---|
| `今日のパン`(5字) | 5×2 | 10 |
| `今日のパン🍞` | 10+2 | 12 |
| `詳細 https://example.com/very/long/path` | 2×2+1(空白)+23 | 28 |

### ハッシュタグ

| 項目 | 内容 | 確度 |
|---|---|---|
| 上限 | 明確な上限は未確認。公式ヘルプは「好きなだけ使える」としつつ推奨数を示す | 🟡 |
| 推奨 | **1投稿2個まで** を公式ヘルプが推奨(ベストプラクティス) | 🟡 [How to use hashtags](https://help.x.com/en/using-x/how-to-use-hashtags) |
| 位置 | 文中どこでも可。文末にまとめる、または文中の重要語に付ける | 🟡 / ⚪ |
| スペース・記号 | タグの中に **スペースや句読点を入れると正しく機能しない** | 🟡 同上 |
| 公開範囲 | 公開アカウントのタグ付き投稿は、そのタグを検索した誰でも見られる | 🟡 同上 |
| 日本語 | 前後にスペースを入れて区切る。記号の混在に注意 | ⚪ |

共通の考え方: [hashtags](../01-common/hashtags.md)

#### ハッシュタグの付け方の手順

1. 投稿のテーマを一言で表す語を決める(例: `#作り置き`)。
2. X の検索でそのタグを検索し、**実際に使われているか・荒れていないか** を確認する。
3. 本文の最後に、前に半角スペースを入れて付ける。
4. タグの中に空白・句読点(`、` `。` `!`)を入れない。
5. 2個以内に絞る(🟡 公式の推奨)。

### メンション・リプライ

- @ID を付けると相手に通知される。大量メンションはスパム扱いのリスク。
- 返信の先頭の @ID は表示ルールが変わることがある。会話を狙った相手に届けたいときは、通知設定と合わせて確認。
- 返信の先頭に自動で付く @ID は文字数に数えない(✅)。
- 文頭を `@` で始めた通常ポストは、表示範囲が限られると言われることがある(⚪ 公式根拠は未確認)。迷ったら `@` を文頭に置かない。

### リンク

- 外部リンクは表示されやすさに影響する可能性があるとの意見もあるが、**公式根拠は未確認** ⚪。リンクは返信に置く運用もあるが、必須ではない。
- 短縮URLは実際の遷移先が分かる形が望ましい。広告・アフィリエイトのリンクは PR 表記 ([legal](../01-common/legal-compliance.md))。
- URL はどんなに長くても 23字として数えるため、自分で短縮サービスを使う必要はありません(✅)。
- API で投稿する場合は **URL を含む投稿の単価が高い**(✅ [料金ページ](https://docs.x.com/x-api/getting-started/pricing.md)。詳細は [20-api/02-x-api](../20-api/02-x-api.md))。
- 計測には UTM パラメータを付ける([link-in-bio-and-utm](../01-common/link-in-bio-and-utm.md))。

## 文章のコツ（⚪）

1. 1行目で価値を伝える。
2. 改行で読みやすく。
3. 1投稿1メッセージ。
4. 具体的な数字・事例。
5. 最後に CTA を1つだけ置く(「保存」「返信で教えて」など)。
6. 専門用語は避けるか、短く言い換える([writing-guide](../01-common/writing-guide.md))。

## 効率的な使い方(🟡)

実務の目安は**1〜3個**。数字のみのタグは不可。詳細は [hashtags](../01-common/hashtags.md)。公式ヘルプの推奨は「2個まで」(🟡)なので、迷ったら2個以内にします。

## 具体例

| | 本文 | コメント |
|---|---|---|
| 良い例 | `鶏むね肉がしっとりする下ごしらえは「砂糖をもみ込む」だけ。\n10分置いてから焼くと固くなりにくいです。\n#作り置き` | 1行目で結論。タグ1つ |
| 悪い例 | `#料理 #レシピ #作り置き #時短 #節約 #鶏むね 今日のごはん` | タグが多く、内容が後ろに追いやられている |
| 悪い例 | `#週末 パン 作り`(タグの中にスペース) | `#週末` しかタグにならない |

## よくある失敗と対処

| 失敗 | 原因 | 対処 |
|---|---|---|
| 日本語140字ちょうどなのに投稿できない | 絵文字・記号・URL の分が加算 | 絵文字は2、URL は23で再計算 |
| ハッシュタグが青くならない | タグ内にスペース・句読点 | 記号を外す。数字だけのタグにしない |
| メンションした相手から反応がない | 相手の通知設定・関係性 | 何度も送らない。大量メンションはスパム扱いのリスク |
| 長文が途中で切れて見える | 長文は冒頭のみ表示(🟡) | 冒頭140字に要点を入れる |

## 注意点

- 文字数の数え方は X 公式の開発者文書(✅)に基づきます。アプリの表示とずれる場合はアプリの表示を優先してください。
- 無関係な話題のハッシュタグを付けるのは、スパムとみなされる恐れがあります([10-policies](10-policies.md))。

## チェックリスト

- [ ] 重み付きで 280 以内(日本語は約140字)
- [ ] ハッシュタグは2個以内、スペース・句読点なし
- [ ] メンションは必要な相手だけ
- [ ] リンクの遷移先・PR 表記を確認した
- [ ] 1行目で要点が伝わる

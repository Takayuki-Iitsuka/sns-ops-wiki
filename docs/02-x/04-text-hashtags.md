# X 文字数・ハッシュタグ・メンション・リンク

## 文字数 ⚪

- 標準は 280 文字単位。日本語（全角）は 1 字を 2 とカウントし、**実質 140 字**程度。URL・絵文字は別カウント。
- 長文ポストは Premium で拡張される ⚪。
- 正確なルールは公式で確認 (#15)。

## ハッシュタグ

| 項目 | 内容 | 確度 |
|---|---|---|
| 上限 | 明確な上限は未確認 | ⚪ |
| 推奨 | 1〜2個程度が読みやすい | ⚪ |
| 位置 | 文末にまとめる、または文中の重要語に付ける | ⚪ |
| 日本語 | スペースを入れて区切る。記号の混在に注意 | ⚪ |

共通の考え方: [hashtags](../01-common/hashtags.md)

## メンション・リプライ

- @ID を付けると相手に通知される。大量メンションはスパム扱いのリスク。
- 返信の先頭の @ID は表示ルールが変わることがある。会話を狙った相手に届けたいときは、通知設定と合わせて確認。

## リンク

- 外部リンクは表示されやすさに影響する可能性があるとの意見もあるが、**公式根拠は未確認** ⚪。リンクは返信に置く運用もあるが、必須ではない。
- 短縮URLは実際の遷移先が分かる形が望ましい。広告・アフィリエイトのリンクは PR 表記 ([legal](../01-common/legal-compliance.md))。

## 文章のコツ（⚪）

1. 1行目で価値を伝える。
2. 改行で読みやすく。
3. 1投稿1メッセージ。
4. 具体的な数字・事例。

## 効率的な使い方(🟡)

実務の目安は**1〜3個**。数字のみのタグは不可。詳細は [hashtags](../01-common/hashtags.md)。

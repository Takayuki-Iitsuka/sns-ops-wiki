# X Subscriptions(クリエイター向け月額購読)

> **このページで分かること**: X の Subscriptions(月額購読)の仕組み、申請の条件と手数料の報告値、購読者に何を届けるかの設計。
>
> **対象**: X で一定のフォロワーがいて、ファンから継続的な支援を受けたい人。**先に読むページ**: [X の収益化](07-monetization.md)、[収益化の比較](../01-common/monetization-comparison.md)

> フォロワーが**月額でクリエイターを購読**し、購読者限定のコンテンツを受け取る仕組み(旧称 Super Follows)。広告収益の分配([07-monetization](07-monetization.md))とは**別の制度**で、条件・手数料も別です。
> **取得状況**: `help.x.com` と `legal.x.com` の本文は取得できず(403 / 名前解決不可)、**検索結果に出た公式ヘルプの要約**に基づきます(🟡)。申請前に必ず公式で確認してください(#64〜#66)。

## 用語

| 用語 | 意味 |
|---|---|
| subscription(サブスクリプション、月額購読) | 毎月定額を払って、特定のクリエイターを支援・購読すること |
| subscriber(購読者) | 月額購読をしているファン |
| subscriber-only post(購読者限定ポスト) | 購読者だけが読めるポスト |
| in-app purchase(アプリ内購入) | iPhone・Android のアプリ経由の支払い。ストアの手数料がかかることがある |
| payout(支払い、払い出し) | 売上がクリエイターの口座に振り込まれること |

## 1. 位置づけ

| 項目 | 内容 | 確度 |
|---|---|---|
| 何か | 購読者(Subscriber)が月額を支払い、クリエイターの限定コンテンツを見られる | 🟡 |
| 旧称 | Super Follows → Subscriptions に改称 | 🟡 |
| 広告収益分配との違い | 分配は「インプレッションに応じた広告収益」、Subscriptions は「ファンからの直接課金」 | ⚪ |
| 購入できる場所 | iOS、Android、Web | 🟡 |
| 申請できる地域 | 「要件を満たす、すべての国/地域のクリエイター」と公式ヘルプが説明(日本を明示する記述は未確認) | 🟡 |

## 2. 資格要件(🟡 不一致あり #64)

| 出どころ | 要件 |
|---|---|
| 検索で得た公式ポリシー(ja)の要約 | 18歳以上、メールアドレス認証済み、プロフィール情報がすべて表示されている、**過去3か月で 500万以上のオーガニックインプレッション**、本人確認(ID verification)の完了。**満たしても承認されるとは限らない** |
| 検索で得た公式ヘルプ(en)の断片 | 18歳以上、**フォロワー 500人以上**、過去30日のアクティブ、決済事業者が対応する国 |
| 第三者の 2026年向けガイド | Premium 契約、認証済み、18歳以上、税務情報の登録。500人・500万インプレッションの併記もあり |

- **資料間で数値が食い違う**。「フォロワー 500人 / 30日アクティブ」は旧要件、「500万インプレッション / 3か月」は新要件の可能性が高いが、**未確認**。
- 広告収益分配の旧条件(Premium、認証済みフォロワー 500人以上、500万インプレッション)と**混同しやすい**。別制度として確認する。
- 申請は設定の収益化メニューから(場所は ⚪。UI は変わる)。

## 3. 手数料・収益分配(🟡 #65)

| 項目 | 内容 | 確度 |
|---|---|---|
| 取り分 | **生涯収入が 5万ドルに達するまで、アプリ内購入手数料を差し引いた後の最大 97%** | 🟡 公式ヘルプの要約 |
| 5万ドル到達後 | 取り分は**最大 80%** | 🟡 |
| アプリ内購入手数料 | Apple は購読料の 30%(Apple の規約により変動) | 🟡 |
| 詳細 | 「サブスクリプションクリエイター利用規約」に定められている | 🟡 |
| 最低支払額・支払い頻度・税務書類 | 未確認 | ⚪ |

> 「X が 30% を取る」という公式の記述は**確認できていません**。30% は Apple のアプリ内購入手数料として出てくる数字です。Web 経由の購入は別になる可能性がありますが、未確認です。

### 試算の考え方(⚪)

```
実際の取り分 ≒ 購読料 − アプリ内購入手数料(購入経路による) − 決済・税 → ×最大97%(生涯5万ドルまで)
```

購読者が iOS で購入するか Web で購入するかで手取りが変わるため、**購入経路ごとの取り分を公式の収益画面で確認**する。

## 5. API で見える情報(✅ docs.x.com のデータ辞書)

| フィールド | 内容 |
|---|---|
| `subscription` | ユーザーが**認証済みユーザーを購読しているか**に関する情報 |
| `subscription_type` | 認証済みユーザー自身の **X Premium の種別**(`None`/`Basic`/`Premium`/`PremiumPlus`)。**他人については常に `None`**。Subscriptions の購読とは**別物** |
| `verified_type`、`is_identity_verified` | 認証の種別、本人確認済みか |

- 購読者限定ポストを示す Post のフィールドは、**データ辞書には見当たらない**(`scopes` は広告向け)。API で購読者限定ポストを投稿・取得できるかは**未確認**。
- 購読者の一覧や売上を API で取るのは、公式文書で確認できていない(#66)。収益はアプリの画面で確認する。

## 6. ポリシー・禁止事項(🟡)

- 「サブスクリプション ポリシー」(`help.x.com/ja/rules-and-policies/subscriptions-policy`)があり、**要件を満たさなければクリエイターになれない**と明記(検索要約)。
- 購読者限定でも **X のルール(安全性・センシティブコンテンツ・著作権)は全面的に適用**される(⚪)。限定公開は「規約の対象外」ではない。
- 購読者に約束した内容(頻度・特典)を満たせない場合の返金・苦情は、クリエイターの信用に直結する(⚪)。

## 7. 運用設計(⚪)

| 項目 | 目安 |
|---|---|
| 提供価値 | 公開ポストと**差が分かる**ものにする(制作過程、先行公開、質問への回答、データ・素材) |
| 頻度 | 無理のない頻度を**事前に宣言**(週1回など)。続かない約束は避ける |
| 価格 | 低価格で始めて、特典が固まってから見直す。値上げは既存購読者への影響を考える |
| 移行先 | プラットフォーム依存を避けるため、メール・note・FANBOX 等への導線も持つ([membership-design](../10-creator-economy/05-membership-design.md)) |
| 重複 | note メンバーシップ・FANBOX と**同じ特典を二重に作らない**(運用負荷)。[monetization-comparison](../01-common/monetization-comparison.md) |
| 税務 | 継続収入は所得。海外からの支払いの扱いは [tax-and-business](../30-strategy/04-tax-and-business.md) |

## 8. 注意点

- 条件・手数料・名称は**頻繁に変わる**。この表の数値は検索要約(🟡)で、**実行前に公式の最新ページを必ず確認**。
- 第三者のブログの条件は古いことが多い(例: フォロワー 500人 / 30日)。
- 購読者限定に誘導する際の**広告表記**は [legal-compliance](../01-common/legal-compliance.md)。
- 広告収益分配との関係: [07-monetization](07-monetization.md)(Original Content Rewards)。料金(Premium など): [40-pricing/01-x-and-grok](../40-pricing/01-x-and-grok.md)。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 始めたものの、限定コンテンツを出す余裕がなくなる | 開始前に「毎週・毎月出せるもの」を3つ決め、1か月分を作り置きしてから始める |
| 無料の投稿と限定コンテンツの差が分かりにくい | 無料は「入口」、限定は「深い解説・制作の裏側・先行公開」など役割を分ける。→ [メンバーシップの設計](../10-creator-economy/05-membership-design.md) |
| 手数料の報告値をそのまま計画に使う | 公式で確認できるまでは幅を持たせて計算する(🟡 #65)。税金も考える。→ [税務](../30-strategy/04-tax-and-business.md) |
| 規約に合わない内容を限定公開にする | 限定コンテンツにも X のルールが適用される(§6) |

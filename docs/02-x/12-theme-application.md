# X での古事記・日本書紀の発信設計

テーマ全体は [05-theme-kojiki](../05-theme-kojiki/README.md)。ここでは X 向けの具体策。

## X の役割

**入口と交流**。短い問い・場面・用語で興味を引き、詳しくは Instagram・note へ。

## 形式の割り当て

| 柱 | X での形式 |
|---|---|
| 物語のあらすじ | スレッド(5〜7ポスト)、画像1〜4枚 |
| 神名・用語辞典 | 画像1枚＋短文、シリーズ化 |
| 古事記 vs 日本書紀 | 画像2枚(左右比較)または引用ポスト |
| 原文を読む | 原文の画像＋訓読＋一言 |
| 暦と行事 | 当日・前日の短文 |
| 学びの記録 | 日常ポスト、質問への返信 |

## 週のリズム例

[content-calendar](../05-theme-kojiki/05-content-calendar.md) の週リズムを基準に、X は**毎日1〜2投稿**を上限として設計する。

## 注意

- 日本語は文字数が少なくなる([04-text-hashtags](04-text-hashtags.md))。
- スレッドは**1本目が勝負**。冒頭で問いと価値を示す。
- 神・皇室に関する話題で**議論が荒れやすい**。返信制限・ミュートの活用([06-engagement](06-engagement.md))。
- 収益導線は全体の1〜2割([funnel](../06-strategy/02-funnel.md))。

## 画像サイズの具体案(⚪、公式の許容範囲内の設計)

| 型 | 推奨サイズ | 備考 |
|---|---|---|
| 場面カード/比較カード(1枚) | 1600×900(16:9) | X の「2:1〜3:4」の範囲内 🟡 |
| 神名カード(正方形) | 1200×1200 | 縮小表示でも読める |
| 縦長(原文の縦書き) | 1200×1600(3:4) | 範囲の端。上下の欠けに注意 |

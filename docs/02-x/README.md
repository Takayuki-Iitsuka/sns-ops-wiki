# X(旧 Twitter)

短文・即時性・拡散(リポスト)に強い。日本では利用者が多く、速報・話題・コミュニティ形成に向く(⚪)。

## 特徴

| 項目 | 内容 |
|---|---|
| 主な形式 | 短文ポスト、画像、動画、GIF、投票、スレッド |
| 強み | 拡散力、リアルタイム性、検索 |
| 弱み | 流れが速い、炎上リスク、アルゴリズムと有料機能の影響 |
| 向く用途 | 認知、情報発信、交流、告知 |

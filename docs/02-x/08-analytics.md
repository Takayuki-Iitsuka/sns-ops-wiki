# X の分析

> **このページで分かること**: X のアナリティクスで見る指標の意味、計算方法、週次の振り返り手順。
>
> **対象**: 投稿を始めて2〜4週間の初心者  **先に読むページ**: [analytics-kpi](../01-common/analytics-kpi.md)

共通: [analytics-kpi](../01-common/analytics-kpi.md)

## 概要

分析の目的は「数字を眺めること」ではなく、**次に何を投稿するかを決めること** です。最初は指標を3つに絞ると続けやすくなります(⚪)。

| 目的 | まず見る指標 |
|---|---|
| 届いているか | インプレッション |
| 興味を持たれたか | プロフィールクリック、ブックマーク |
| 行動につながったか | リンククリック |

## 用語

| 用語 | 意味 |
|---|---|
| impression(インプレッション) | ポストが画面に表示された回数。**同じ人が2回見ても2回** と数える(✅) |
| engagement(エンゲージメント) | クリック・返信・いいねなどの反応の合計 |
| engagement rate(エンゲージメント率) | エンゲージメント ÷ インプレッション |
| organic(オーガニック) | 広告ではない通常の表示 |
| promoted(プロモーション) | 広告として表示された分 |
| KPI(Key Performance Indicator、重要業績評価指標) | 目標の達成度を測る指標 |

## 見る場所 ⚪

- 各ポストの「アナリティクスを表示」
- アカウント全体のアナリティクス（提供範囲は契約形態で異なる可能性。要確認）

アプリのボタン名や、無料アカウントで見られる範囲は ⚪ 要確認です。

## 主な指標

| 指標 | 意味 | 使い方 |
|---|---|---|
| インプレッション | 表示回数 | 届き具合 |
| エンゲージメント | クリック・返信・いいね等の合計 | 反応全体 |
| エンゲージメント率 | エンゲージメント ÷ インプレッション | 質の比較 |
| プロフィールクリック | ポストからプロフィールを開いた回数 | 興味 |
| リンククリック | ポスト内の URL が押された回数 | 行動 |
| 保存（ブックマーク） | ブックマークされた回数 | 後で読みたい価値 |

### 公式の指標の定義(✅ docs.x.com Metrics)

| 指標 | 公開/非公開 | 定義 |
|---|---|---|
| インプレッション | 公開 | 画面に表示された回数。ユニーク(重複なし)ではない |
| いいね・返信 | 公開 | それぞれの数 |
| リポスト | 公開 | リポストの数。**引用ポストは含まない** |
| 引用 | 公開 | 引用ポストの数 |
| ブックマーク | 公開 | ブックマークされた数 |
| リンククリック・プロフィールクリック・エンゲージメント | **非公開**(本人のみ) | 本人のポストについて取得できる |
| 動画の再生 | 公開(再生数)/ 非公開(0%・25%・50%・75%・100% 到達) | どこまで見られたか |

- API で非公開の指標が取れるのは **投稿から30日以内** のポストだけ(✅)。月1回の集計だと取りこぼすので、**週1回** 記録するのがおすすめです。
- 編集したポストは **版ごとに指標が分かれる**(✅ [Edit Posts](https://docs.x.com/x-api/fundamentals/edit-posts.md))。編集が多いと数字が分散します。
- 広告を出したポストは、オーガニックとプロモーションに分かれる(✅)。

出典: [docs.x.com Metrics](https://docs.x.com/x-api/fundamentals/metrics.md)。

## 手順 / 仕様

### 週次で見ること

1. 上位3投稿と下位3投稿の違い
2. 時間帯・形式（画像/テキスト/スレッド）の比較
3. フォロワー増減とトリガーになった投稿

[週次レビュー雛形](../../templates/weekly-review.md)

### 週次レビューの具体的な手順(⚪)

1. 毎週同じ曜日・時間に、直近7日のポストを一覧にする。
2. 表計算シートに「日付・形式・テーマ・インプレッション・エンゲージメント・ブックマーク・リンククリック」を記録する。
3. エンゲージメント率を計算する。
4. 上位3つと下位3つに印を付け、違い(1行目、画像の有無、時間帯)を一言で書く。
5. 次週に試すことを **1つだけ** 決める(例: 「画像付きを増やす」)。
6. 4週続けたら、月の傾向をまとめる。

### 計算例

| ポスト | インプレッション | エンゲージメント | エンゲージメント率 |
|---|---|---|---|
| A(画像あり) | 2,000 | 80 | 80 ÷ 2,000 = **4.0%** |
| B(テキストのみ) | 5,000 | 100 | 100 ÷ 5,000 = **2.0%** |

- B の方が多くの人に届いたが、A の方が反応の割合は高い、と読めます。
- 数値は説明用の架空の例です。

### API で自動集計する場合(✅)

- 自分のアカウントのデータ取得(Owned Reads)は **$0.001/件**(2026年(皇紀2686年・令和8年)4月20日から ✅ [料金ページ](https://docs.x.com/x-api/getting-started/pricing.md))。
- 詳細は [20-api/02-x-api](../20-api/02-x-api.md)、ダッシュボードの考え方は [analytics-kpi](../01-common/analytics-kpi.md)。

## 具体例

| 気づき(例) | 次の行動 |
|---|---|
| 手順の画像4枚の投稿だけブックマークが多い | 週2回は手順画像にする |
| 夜の投稿のインプレッションが朝の半分 | 2週間、朝と昼に寄せて比べる |
| リンククリックが少ない | リンクの前に「何が得られるか」を1行足す |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| フォロワー数だけを見て一喜一憂 | 投稿ごとの反応を見る |
| 1回の結果で結論を出す | 同じ条件で2〜4週比べる |
| 月末にまとめて記録し、非公開指標が取れない | 週1回記録する(API の非公開指標は30日以内 ✅) |
| 何でも変えて原因が分からない | 1週に変えるのは1つだけ |

## 注意点

- 指標の定義は API 文書(✅)に基づきます。アプリの画面の表示名・集計方法は異なる場合があります(⚪)。
- 実際の数値(非公開の運用数値)はこのリポジトリに書かず、手元の表に記録してください。

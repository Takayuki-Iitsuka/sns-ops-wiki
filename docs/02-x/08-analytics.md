# X の分析

共通: [analytics-kpi](../01-common/analytics-kpi.md)

## 見る場所 ⚪

- 各ポストの「アナリティクスを表示」
- アカウント全体のアナリティクス（提供範囲は契約形態で異なる可能性。要確認）

## 主な指標

| 指標 | 意味 | 使い方 |
|---|---|---|
| インプレッション | 表示回数 | 届き具合 |
| エンゲージメント | クリック・返信・いいね等の合計 | 反応全体 |
| エンゲージメント率 | エンゲージメント ÷ インプレッション | 質の比較 |
| プロフィールクリック | | 興味 |
| リンククリック | | 行動 |
| 保存（ブックマーク） | | 後で読みたい価値 |

## 週次で見ること

1. 上位3投稿と下位3投稿の違い
2. 時間帯・形式（画像/テキスト/スレッド）の比較
3. フォロワー増減とトリガーになった投稿

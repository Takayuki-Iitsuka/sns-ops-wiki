# X のルール・ポリシー

規約は頻繁に更新されます。公式の「Xルール」「利用規約」を一次資料として確認 (入口: https://help.x.com/ja)。

## 注意すべき領域 ⚪

| 領域 | 要点 |
|---|---|
| スパム・プラットフォーム操作 | 自動化、大量フォロー、同一内容の連投、複数アカウントでの水増し |
| 嫌がらせ・ヘイト | 禁止 |
| センシティブメディア | 設定が必要な場合あり |
| 著作権 | 権利者からの申立てで削除あり |
| なりすまし | 禁止。パロディはラベル要件あり |
| 広告・案件 | [legal-compliance](../01-common/legal-compliance.md) |
| 自動化ボット | ラベル・規約要件 |

## 違反したとき

- 警告・投稿削除・機能制限・アカウント凍結。異議申立てフォームを使う。

# X のコツ（経験則 ⚪）

> **このページで分かること**: プロフィール・投稿・交流で、初心者がすぐ試せるコツと、避けるべきこと。
>
> **対象**: 初心者  **先に読むページ**: [02-posting](02-posting.md)、[04-text-hashtags](04-text-hashtags.md)

## 概要

このページの内容は、ほとんどが **経験則(⚪)** です。「必ず伸びる方法」はありません。ここに書いたことは **仮説** として試し、[08-analytics](08-analytics.md) で自分のアカウントのデータを見て判断してください。

規約に関わる部分(自動化・スパム)だけは公式資料(✅)に基づきます。

## 用語

| 用語 | 意味 |
|---|---|
| hook(フック) | 1行目で読者を引き付ける一言 |
| content pillar(コンテンツの柱) | アカウントで繰り返し扱う2〜4個のテーマ |
| CTA(Call To Action、行動の呼びかけ) | 「保存して」「返信で教えて」など |
| A/B テスト | 1つの条件だけ変えて、2つを比べる方法 |

## プロフィール

- 「誰の何の役に立つか」を1行目に。固定ポストで代表作を見せる。
- 表示名に「何の人か」を短く入れる(例: `佐藤|地域の店の販促`)。
- 固定ポストは「自己紹介+人気投稿へのリンク」にする。

## 投稿

1. **1行目が勝負**: 結論・数字・問いから始める。
2. **画像は読みやすく**: スマホの縮小表示で文字が読めるか確認。
3. **スレッドは予告→本編→まとめ**。
4. **同じ内容の連投を避ける**。規約上スパムになり得る。
5. **時間帯は仮説→検証**: 自分のフォロワーのデータで判断。

### 1行目の型(⚪)

| 型 | 例 |
|---|---|
| 結論 | `作り置きは「冷ましてから蓋をする」だけで日持ちが変わります。` |
| 数字 | `パン屋を10年続けて分かった、売り切れを減らす3つの工夫。` |
| 問い | `イラストの線画、何で描いていますか?` |
| 失敗談 | `開店初月、告知を1回もしなかった結果…` |

### コンテンツの柱を決める手順(⚪)

1. 自分が続けられるテーマを5つ書き出す。
2. フォロワーが知りたいことと重なるものを2〜4個残す。
3. 曜日ごとに割り当てる(例: 月=コツ、水=制作過程、金=お知らせ)。
4. 4週間続けて、反応の良い柱を増やす([content-planning](../01-common/content-planning.md))。

### スレッドの型(⚪)

1. 1本目: 「この先で何が分かるか」を予告する。
2. 2〜5本目: 1本につき1つのポイント。画像があれば添える。
3. 最後: まとめと CTA(「保存して見返してください」)。

## 交流

- 影響力のあるアカウントの投稿に、価値ある補足を返信（宣伝や自己紹介のみは避ける）。
- 引用ポストで学びを共有し、元投稿者に敬意を。
- 自分のポストへの返信には、できるだけ早く返す([06-engagement](06-engagement.md))。
- 同じテーマの人をリストにまとめ、毎日数件ずつ丁寧に反応する。

## 避けること

- 煽り、釣りタイトル
- 無関係なハッシュタグの大量付与
- 自動フォロー/自動リプライの乱用（規約違反の恐れ）
- 他人の画像・文章の無断転載

### 公式の開発者ガイドラインで禁止・制限されていること(✅)

| 行為 | 扱い |
|---|---|
| 自動いいね(キーワード・タグ・スケジュールで) | **禁止**。いいねは本人の操作である必要がある |
| 複数アカウントで同じ内容を投稿 | スパム・プラットフォーム操作 |
| 新しいフォロワーへの自動 DM | **禁止** |
| ブラウザ自動操作・スクレイピング | **永久凍結** の対象。自動化は公式 API のみ |

出典: [docs.x.com 開発者ガイドライン](https://docs.x.com/developer-guidelines.md)。ハッシュタグは公式ヘルプが「2個まで」を推奨(🟡 [How to use hashtags](https://help.x.com/en/using-x/how-to-use-hashtags))。

## 試し方(A/B テストの手順 ⚪)

1. 変える条件を1つだけ決める(例: 画像あり/なし)。
2. それ以外(時間帯・テーマ・長さ)をできるだけ揃える。
3. 各5本以上投稿する。
4. インプレッションとエンゲージメント率を比べる。
5. 差が小さければ「違いはない」と判断して次の条件へ。

## 具体例

| 改善前 | 改善後 | 変えた点 |
|---|---|---|
| `今日はパンを焼きました。` | `くるみパン、11時に焼き上がります。今日は30個です。` | 用件と数字を先に |
| `イラスト描きました #イラスト #絵 #art #illustration #お絵描き` | `夕方の商店街を描きました。光の色を3回塗り直しています。#イラスト` | 説明を足し、タグを1つに |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 毎日違うテーマで、何のアカウントか伝わらない | コンテンツの柱を2〜4個に絞る |
| 伸びた投稿の真似を連投した | 同じ内容の連投はスパムの恐れ。切り口を変える |
| 他人の投稿に宣伝だけの返信をした | 返信は補足や感想など価値のある内容に |
| 一度伸びなかっただけでやめた | 4週間は続けて傾向を見る |

## 注意点

- 「この時間に投稿すると伸びる」などの一般論は根拠が確認できないものが多いです(⚪)。
- 外部ツールの自動化機能は、規約に違反していないか必ず確認してください([10-policies](10-policies.md))。

## チェックリスト

- [ ] 1行目が結論・数字・問いのどれかになっている
- [ ] コンテンツの柱が2〜4個に決まっている
- [ ] 同じ内容を連投していない
- [ ] 自動いいね・自動 DM を使っていない
- [ ] 試していることを1つだけに絞っている

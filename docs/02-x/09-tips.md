# X のコツ（経験則 ⚪）

## プロフィール

- 「誰の何の役に立つか」を1行目に。固定ポストで代表作を見せる。

## 投稿

1. **1行目が勝負**: 結論・数字・問いから始める。
2. **画像は読みやすく**: スマホの縮小表示で文字が読めるか確認。
3. **スレッドは予告→本編→まとめ**。
4. **同じ内容の連投を避ける**。規約上スパムになり得る。
5. **時間帯は仮説→検証**: 自分のフォロワーのデータで判断。

## 交流

- 影響力のあるアカウントの投稿に、価値ある補足を返信（宣伝や自己紹介のみは避ける）。
- 引用ポストで学びを共有し、元投稿者に敬意を。

## 避けること

- 煽り、釣りタイトル
- 無関係なハッシュタグの大量付与
- 自動フォロー/自動リプライの乱用（規約違反の恐れ）
- 他人の画像・文章の無断転載

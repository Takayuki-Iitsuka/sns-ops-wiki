# X のコメント（返信）運用

> **このページで分かること**: 返信・引用・ミュート・ブロック・非表示などの機能と、返信の書き方、荒れたときの対応。
>
> **対象**: 初心者〜中級者  **先に読むページ**: [02-posting](02-posting.md)

共通方針: [comments-and-engagement](../01-common/comments-and-engagement.md)

## 概要

X は「会話」が中心のサービスです。返信に丁寧に応えると、フォロワーとの信頼が育ちます。一方で、拡散力が強いぶん **荒れる(炎上する)** こともあります。

返信運用の基本は次の3つです。

1. **返す**: 質問・感想には、できる範囲で返事をする。
2. **守る**: 返信の範囲・非表示・ミュート・ブロックで、自分と読者を守る。
3. **記録する**: よく来る質問はメモして、投稿や固定ポストに反映する。

## 用語

| 用語 | 意味 |
|---|---|
| engagement(エンゲージメント) | いいね・返信・リポストなどの反応の総称 |
| hide reply(返信の非表示) | 自分のポストへの返信を隠す。隠した返信も追加の操作で見られる |
| mute(ミュート) | 相手の投稿を見えなくする。相手には通知されない |
| block(ブロック) | 相手との接点を断つ |
| report(通報) | 規約違反を運営に知らせる |
| list(リスト) | アカウントをまとめて見る機能 |
| community(コミュニティ) | 特定テーマの集まり |
| DM(Direct Message、ダイレクトメッセージ) | 個別のメッセージ |

## X 特有のポイント

| 機能 | 使い方 |
|---|---|
| 返信制限 | 投稿ごとに返信できる人を絞る（荒れ対策） ⚪ |
| 引用ポスト | 反論・補足を公開で行える。煽りに注意 |
| ミュート | 通知を止める。相手に通知されない |
| ブロック | 相手との接点を断つ |
| 通報 | 規約違反を運営へ報告 |
| リスト | フォローせず情報を整理・監視 |
| コミュニティ | 特定テーマの集まり。運営ルールを確認 ⚪ |
| DM | 個別連絡。営業の連投は避ける |

## 手順 / 仕様

### 機能の仕様

| 項目 | 値・内容 | 確度 | 出典 |
|---|---|---|---|
| 返信の範囲の選択肢 | フォロー中 / メンションした人 / 購読者 / 認証済み(API の `reply_settings`) | ✅ | [Create or Edit Post](https://docs.x.com/x-api/posts/create-or-edit-post.md) |
| 返信の範囲の既定 | すべてのアカウント | 🟡 | [help.x.com 会話について](https://help.x.com/en/using-x/x-conversations) |
| 返信の範囲の効果 | 制限されるのは返信だけ。いいね・リポストは可能 | 🟡 | 同上 |
| 返信の非表示 | **自分のポストへの返信** を隠せる。隠した返信は追加のクリックで見られる | ✅ | [Hide Replies](https://docs.x.com/x-api/posts/hide-replies/introduction.md) |
| API での自動返信 | 元の投稿者があなたを @メンションまたは引用した場合のみ返信可(2026年(皇紀2686年・令和8年)2月23日から) | ✅ | [changelog](https://docs.x.com/changelog.md)、[20-api/02-x-api](../20-api/02-x-api.md) |

### 返信の範囲を変える手順(⚪ 表記は変わる可能性)

1. 投稿画面の「すべてのアカウントが返信できます」(地球儀アイコン)を押す。
2. 範囲を選ぶ(例: フォローしているアカウント)。
3. 投稿後に変える場合は、ポストの「…」メニューから「返信できるアカウントを変更」を選ぶ(🟡)。

### 返信を非表示にする手順(⚪)

1. 隠したい返信の「…」メニューを開く。
2. 「返信を非表示にする」を選ぶ。
3. 隠した返信は、ポストの「非表示の返信」から確認・元に戻せる。

### ミュート・ブロック・通報の使い分け

| 状況 | おすすめ | 理由 |
|---|---|---|
| 少し合わないが悪意はない | ミュート | 相手に気づかれず、関係を壊さない |
| 同じ相手から繰り返し攻撃的な返信 | ブロック | 接点を断つ |
| 脅迫・差別・なりすまし・スパム | 通報+ブロック | 規約違反は運営に知らせる |
| 自分のポストの返信欄だけ荒れている | 返信の非表示+範囲の変更 | 他の読者を守る |

## 返信のコツ

- 最初の1時間は返信できる時間を確保する。
- 長い議論は避け、2往復で切り上げる判断をする。
- 炎上の兆候（引用ポストで急に拡散）: 反論を急がず、事実確認→必要なら訂正ポスト1本にまとめる。
- 感謝 → 答え → 次の行動の順で短く返す(⚪)。
- 同じ質問が3回来たら、答えを投稿にして固定ポストやスレッドにまとめる(⚪)。

### 自動化するときのルール(✅ 開発者ガイドライン)

| 行為 | 扱い |
|---|---|
| キーワードに反応して誰にでも自動返信 | **禁止**(求められていない接触) |
| 自分のポストに返信した人への自動返信 | 条件付きで可(1回まで) |
| AI が生成した返信の自動投稿 | X の **事前承認が必要** |
| 新しいフォロワーへの自動 DM | **禁止**(フォロワーでも求められていない接触) |
| 自動いいね | **禁止** |

出典: [docs.x.com 開発者ガイドライン](https://docs.x.com/developer-guidelines.md)。

## 具体例

### 返信の文例

| 場面 | 文例 |
|---|---|
| 感想への返事 | `ありがとうございます!作ってもらえてうれしいです。次は卵の作り置きを紹介しますね。` |
| 質問への返事 | `ご質問ありがとうございます。冷蔵で3日を目安にしています。詳しい保存方法は固定ポストにまとめています。` |
| 誤りの指摘 | `ご指摘ありがとうございます。確認したところ、〇〇の記載が誤っていました。訂正ポストを出しました。` |
| 答えられない質問 | `個別のご相談にはお答えできないのですが、よくある質問を固定ポストにまとめています。` |

### 避けたい返信

- 皮肉・煽り(「ちゃんと読みましたか?」)
- 宣伝だけの返信(他人のポストに自分の商品リンクだけを返す)
- 深夜の感情的な長文

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 批判に即反論して引用で広がった | 一度離れ、事実確認してから1本にまとめる([crisis-response](../01-common/crisis-response.md)) |
| 返信が多すぎて追いつかない | 返す基準を決める(質問は返す、感想はいいねで返す など) |
| ブロックした相手が別アカウントで来た | 通報し、返信の範囲を狭める |
| 宣伝 DM を一斉送信してしまった | すぐ止める。自動 DM は規約で禁止 |

## 注意点

- 返信も公開情報です。取引先・個人の情報を書かない([privacy](../01-common/privacy-and-personal-info.md))。
- 他人の画面写真を晒す行為は、嫌がらせとみなされる恐れがあります([10-policies](10-policies.md))。
- 機能の名称・場所は変わります(⚪)。

## チェックリスト

- [ ] 投稿後1時間の返信時間を確保した
- [ ] 荒れそうな話題は返信の範囲を狭めた
- [ ] ミュートするキーワードを最新にした
- [ ] よくある質問をメモした
- [ ] 自動返信・自動 DM を使っていない

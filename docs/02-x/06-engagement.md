# X のコメント（返信）運用

共通方針: [comments-and-engagement](../01-common/comments-and-engagement.md)

## X 特有のポイント

| 機能 | 使い方 |
|---|---|
| 返信制限 | 投稿ごとに返信できる人を絞る（荒れ対策） ⚪ |
| 引用ポスト | 反論・補足を公開で行える。煽りに注意 |
| ミュート | 通知を止める。相手に通知されない |
| ブロック | 相手との接点を断つ |
| 通報 | 規約違反を運営へ報告 |
| リスト | フォローせず情報を整理・監視 |
| コミュニティ | 特定テーマの集まり。運営ルールを確認 ⚪ |
| DM | 個別連絡。営業の連投は避ける |

## 返信のコツ

- 最初の1時間は返信できる時間を確保する。
- 長い議論は避け、2往復で切り上げる判断をする。
- 炎上の兆候（引用ポストで急に拡散）: 反論を急がず、事実確認→必要なら訂正ポスト1本にまとめる。

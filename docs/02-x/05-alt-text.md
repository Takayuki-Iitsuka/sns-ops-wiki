# X の画像説明文(ALT)

> **このページで分かること**: X の画像に ALT(代替テキスト)を付ける手順、書き方、例、API で付ける方法。
>
> **対象**: 初心者  **先に読むページ**: [02-posting](02-posting.md)、[alt-text 詳細ガイド](../01-common/alt-text.md)

## 概要

alt text(代替テキスト、ALT)は、画像の内容を文章で説明したものです。目の不自由な人が使う **スクリーンリーダー(画面読み上げソフト)** が読み上げるほか、通信が遅く画像が表示されないときにも役立ちます。

X では ALT を付けた画像に「ALT」の表示が出て、誰でも説明を読めます(⚪ 表示は変わる可能性)。**本文の文字数を使わない** ので、画像内の文字(スクリーンショットや図の文字)を書き起こす場所としても便利です。

## 用語

| 用語 | 意味 |
|---|---|
| alt text(代替テキスト、ALT) | 画像の内容を説明する文章 |
| screen reader(スクリーンリーダー) | 画面の内容を音声で読み上げるソフト |
| decorative image(装飾画像) | 情報を持たない飾りの画像 |
| media metadata(メディアのメタデータ) | 画像に付ける付加情報。API では ALT もこれに含まれる |

## 手順 / 仕様

### 設定手順 ⚪

ボタン名は変わる可能性があります(⚪)。

1. 画像を添付する。
2. 画像上の「ALT」または「説明を追加」を選ぶ。
3. 説明文を入力して保存。画像ごとに設定する。
4. 4枚添付した場合は、画像を切り替えながら **4枚それぞれ** に入力する。
5. 投稿前に、各画像に「ALT」が付いているかプレビューで確認する。

### 仕様

| 項目 | 内容 | 確度 |
|---|---|---|
| 文字数上限 | **1,000字**(API の Create Media Metadata の `alt_text` の最大長) | ✅ docs.x.com(アプリ上の上限も同じかは未確認) |
| 画像ごと | 4枚それぞれ設定可 | ⚪ |
| 本文の文字数 | ALT は本文の文字数に含まれない | ⚪(ALT は本文と別のメタデータとして付与 ✅ API) |
| GIF・動画 | 付けられるかはアプリで確認 | ⚪ 要確認 |
| 投稿後の追加・修正 | 可否は未確認 | ⚪ 要確認 |

## 書き方

共通原則は [alt-text](../01-common/alt-text.md)。X では本文の字数を使わないので、**画像内の文字は ALT に書く**のが有効（スクリーンショットなど）。

書くときの順番(⚪ 一般的な考え方):

1. **何の画像か**(写真・イラスト・スクリーンショット・グラフ)
2. **主役は何か**(人・物・場所)
3. **伝えたいこと**(本文と合わせて何が分かればよいか)
4. **画像内の文字**(必要な部分を書き起こす)

| ポイント | 説明 |
|---|---|
| 本文と重複させない | 本文に書いたことは短くまとめ、画像でしか分からない情報を書く |
| 「画像」から始めなくてよい | 読み上げで「画像」と伝わるため、「〜の画像」は省略してよい(⚪) |
| 長すぎない | 1,000字まで書けても、要点は最初の1〜2文に |
| 装飾画像 | 情報がない飾りなら、短く済ませる |

## 例

> スクリーンショット。SNS運用の週次カレンダーで、月曜は「X: 告知」、水曜は「note: 記事公開」、金曜は「Instagram: 画像3枚」と入力されている。

### 種類別の例

| 画像の種類 | ALT の例 |
|---|---|
| 料理写真 | `白い角皿に盛った鶏むね肉のソテー。表面はきつね色で、横にブロッコリーとミニトマトが添えてある。` |
| 店頭の告知 | `店頭の黒板。「本日 くるみパン 11時・15時 焼き上がり」と白いチョークで書かれている。` |
| グラフ | `棒グラフ。1月から6月のフォロワー数で、1月の120人から6月の480人まで毎月増えている。` |
| イラスト | `水彩風のイラスト。夕方の商店街を、傘を差した子どもが歩いている。全体にオレンジ色の光。` |

### 良い例・悪い例

| | 例 | 理由 |
|---|---|---|
| 悪い例 | `写真` | 何も伝わらない |
| 悪い例 | `おいしそう!` | 感想だけで内容がない |
| 良い例 | `焼きたての丸いパン6個がかごに並んでいる。表面に白い粉がかかっている。` | 見た目が想像できる |

## API で付ける場合(✅ docs.x.com)

- **Create Media Metadata** で `alt_text`(**最大1,000字**)を設定。**$0.005/回**。
- 手順: メディアをアップロードして `media_id` を得る → メタデータで alt を付与 → `POST /2/tweets` に `media_ids` を渡す。
- 画像4枚なら 4 回(= $0.02)。月30枚で $0.15([06-cost-planning](../40-pricing/06-cost-planning.md))。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 4枚のうち1枚目だけ ALT を付けた | 画像を切り替えて全部に付ける |
| 画像内の文字を書き起こしていない | 図解・スクショは文字を ALT に書く |
| ハッシュタグや宣伝文を ALT に入れた | ALT は画像の説明だけにする |
| AI に作らせた ALT をそのまま使い、内容が違った | 必ず自分で画像と見比べて直す([ai-usage-policy](../01-common/ai-usage-policy.md)) |

## 注意点

- 画像に写った個人情報(名前・住所・顔)を ALT で詳しく書かない([privacy](../01-common/privacy-and-personal-info.md))。
- アプリでの上限(1,000字)は API と同じかが未確認です(⚪)。長い説明は1,000字以内に収めておくと安全です。

## チェックリスト

- [ ] すべての画像に ALT を付けた
- [ ] 画像内の文字を書き起こした
- [ ] 本文と同じことを繰り返していない
- [ ] 要点が最初の1〜2文にある
- [ ] 個人情報を書いていない

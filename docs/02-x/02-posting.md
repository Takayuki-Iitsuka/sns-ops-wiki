# X 投稿ルート

## 投稿の種類

| 種類 | 概要 | 使い所 |
|---|---|---|
| テキストポスト | 文字のみ | 意見・速報・日常 |
| 画像ポスト | 最大4枚 🟡 | 解説、成果物 |
| GIF | アニメーション | 軽い表現。画像と併用不可 🟡 |
| 動画 | 動画投稿 | 実演・告知 |
| スレッド | 連続ポスト | 長い解説 |
| 引用(quote) | 他ポストを引用して意見 | 解説・批評 |
| 返信(reply) | 会話 | 交流 |
| 投票(poll) | 選択肢投票 | 意見収集 |
| 長文ポスト | Premium で長文 ⚪ | 要確認 |
| 予約投稿 | 日時指定 ⚪ | 提供範囲・条件は要確認 |

## 基本手順(Web / アプリ)

1. 投稿ボタンを押す。
2. 本文を入力。画像は追加ボタンから選択(最大枚数は 🟡 4枚)。
3. 画像に **ALT** を追加（→ [05-alt-text](05-alt-text.md)）。
4. 返信できる人の範囲を選ぶ（全員/フォロー中/メンションした人など ⚪）。
5. 投稿。必要なら固定。

## スレッドの作り方

- 1本目で価値を伝え、続きを読む理由を示す。
- 各ポストは単体で意味が通るように。
- 最後に要約と CTA(フォロー/保存/リンク)。

## 投稿のタイミング

- フォロワーが見る時間帯を [分析](08-analytics.md) で検証して決める。一般論は ⚪ なので鵜呑みにしない。

## 削除・編集

- 削除は可能。編集機能の可否・時間制限は ⚪ 要確認。

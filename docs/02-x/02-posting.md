# X 投稿ルート

> **このページで分かること**: X で使える投稿の種類と、投稿・スレッド・投票・予約・編集・削除の手順。
>
> **対象**: 初心者  **先に読むページ**: [01-account-setup](01-account-setup.md)

## 概要

X の投稿は「本文+(必要なら)画像・動画・投票」の組み合わせです。最初は **テキスト+画像1枚** から始め、慣れたらスレッドや投票を試すのがおすすめです(⚪)。

投稿前に決めることは3つだけです。

1. **何を伝えるか**(1投稿1メッセージ)
2. **何を添付するか**(画像・動画・投票のどれか)
3. **誰が返信できるか**(返信の範囲)

## 用語

| 用語 | 意味 |
|---|---|
| composer(投稿画面) | 文章を書く入力画面 |
| draft(下書き) | 投稿せずに保存した文章 |
| scheduled post(予約投稿) | 日時を指定して自動で公開されるポスト |
| poll(投票) | 選択肢から選んでもらう投稿 |
| reply settings(返信の範囲) | そのポストに誰が返信できるかの設定 |
| edit(編集) | 公開後に本文を直すこと。回数と時間に制限がある |

## 投稿の種類

| 種類 | 概要 | 使い所 | 確度 |
|---|---|---|---|
| テキストポスト | 文字のみ。日本語は約140字 | 意見・速報・日常 | ✅ 文字数([04](04-text-hashtags.md)) |
| 画像ポスト | **最大4枚** | 解説、成果物 | ✅(API) |
| GIF | アニメーション。**写真と併用不可**(GIF 1つのみ) | 軽い表現 | ✅(API) |
| 動画 | 動画1本。長さは契約で異なる | 実演・告知 | ✅(API)[03](03-media-specs.md) |
| スレッド | 自分への返信で続ける連続ポスト | 長い解説 | ⚪ |
| 引用(quote) | 他ポストを引用して意見 | 解説・批評 | ✅(API に `quote_tweet_id`) |
| 返信(reply) | 会話 | 交流 | ✅ |
| 投票(poll) | **選択肢2〜4個、各25字まで、期間5分〜7日** | 意見収集 | ✅(API) |
| 長文ポスト | Premium で **最大25,000字** | 長い解説 | 🟡 |
| 予約投稿 | 日時指定。**Web 版で使えるとする解説が多い** | 定時の告知 | 🟡 |
| コミュニティへの投稿 | 特定のコミュニティ内に投稿 | テーマ別の交流 | ✅(API に `community_id`) |

出典: 投票・引用・コミュニティは [Create or Edit Post](https://docs.x.com/x-api/posts/create-or-edit-post.md)、長文は [X Premium how to](https://help.x.com/en/using-x/x-premium-how-to)(🟡)。

## 手順 / 仕様

### 基本の投稿手順(Web / アプリ)

ボタン名は変わる可能性があります(⚪)。

1. 投稿ボタン(「+」や「ポストする」)を押す。
2. 本文を入力する。右下の残り文字数の表示を確認する。
3. 画像は追加ボタンから選択する(最大4枚 ✅)。
4. 画像に **ALT** を追加する(→ [05-alt-text](05-alt-text.md))。
5. 返信できる人の範囲を選ぶ(下の表)。
6. 誤字・リンク・画像の向きを確認して投稿する。
7. 必要ならプロフィールに固定する。

### 返信の範囲(だれが返信できるか)

| 設定 | 内容 | 確度 | 出典 |
|---|---|---|---|
| 既定 | 「すべてのアカウント(Everyone)」が返信可能 | 🟡 | [help.x.com 会話について](https://help.x.com/en/using-x/x-conversations) |
| 選べる範囲(API の値) | `following`(フォロー中)、`mentionedUsers`(メンションした人)、`subscribers`(購読者)、`verified`(認証済み) | ✅ | [Create or Edit Post](https://docs.x.com/x-api/posts/create-or-edit-post.md) |
| 制限の効果 | 制限されるのは **返信だけ**。いいね・リポストは誰でもできる | 🟡 | help.x.com(検索要約) |
| 投稿後の変更 | 公開後も範囲を変更できる | 🟡 | 同上 |

アプリでの表示名(例「フォローしているアカウント」)は ⚪ 表記が変わる可能性があります。

### スレッドの作り方

1. 1本目を書き、「+」(ポストを追加)で2本目以降をつなげる(⚪ 表記)。
2. 1本目で価値を伝え、続きを読む理由を示す。
3. 各ポストは単体で意味が通るように書く。
4. 最後に要約と CTA(Call To Action、行動の呼びかけ。フォロー/保存/リンク)を置く。
5. 投稿後に抜けがあれば、最後のポストに自分で返信して追加する。

### 投票の作り方

1. 投稿画面で投票アイコンを選ぶ(⚪ 表記)。
2. 質問を本文に書き、選択肢を **2〜4個**、各 **25字以内** で入力する(✅)。
3. 期間を **5分〜7日** の範囲で設定する(✅ API の `duration_minutes` は 5〜10080分)。
4. 投票付きのポストは **編集できない** ので、公開前に必ず見直す(✅)。

### 予約投稿(🟡)

1. Web 版(x.com)の投稿画面で、カレンダー+時計のアイコンを選ぶ(🟡 [解説記事](https://www.idownloadblog.com/2020/07/01/schedule-tweet-on-twitter/))。
2. 日付と時刻を選んで確定する。
3. 予約済みのポストは投稿画面の「未送信のポスト」などから確認・変更できる(🟡)。
4. 予約したポストは **公開後に編集できない** 種類に含まれる(✅ [Edit Posts](https://docs.x.com/x-api/fundamentals/edit-posts.md))。

予約できる最大期間・モバイルアプリでの可否は ⚪ 要確認です。API を使う予約は [20-api/02-x-api](../20-api/02-x-api.md)。

### 編集(✅ 公式の開発者文書)

| ルール | 内容 |
|---|---|
| 期間 | 投稿から **30分以内** |
| 回数 | **最大5回** |
| 履歴 | 編集のたびに新しい ID ができ、履歴が残る |
| 削除 | どの版を削除しても、編集の連鎖全体が削除される |
| 編集できないもの | 広告(プロモーション)、**投票付き**、他人への返信、リポスト(引用は可)、コミュニティの投稿、共同投稿、**予約投稿** |

出典: [docs.x.com Edit Posts](https://docs.x.com/x-api/fundamentals/edit-posts.md)。アプリで編集を使える契約の条件(Premium のみか)は ⚪ 要確認です。

### 削除

1. ポストの「…」メニューから「削除」を選ぶ(⚪ 表記)。
2. 削除は取り消せません。誤りの訂正は、削除より **訂正ポスト** の方が信頼につながることがあります(⚪)。
3. 他人が保存した画面写真(スクリーンショット)は消せません。

### 開示のための設定(✅ API の項目)

| 項目 | 用途 |
|---|---|
| `paid_partnership` | 有料の提携(PR)であることを示す |
| `made_with_ai` | AI で生成したメディアを含むことを示す |

アプリでの設定場所は ⚪ 要確認。PR 表記の考え方は [legal-compliance](../01-common/legal-compliance.md)。

## 投稿のタイミング

- フォロワーが見る時間帯を [分析](08-analytics.md) で検証して決める。一般論は ⚪ なので鵜呑みにしない。
- 最初の2週間は「朝・昼・夜」で同じ形式の投稿を出し分け、インプレッションを比べると傾向がつかめます(⚪)。

## 具体例

### 良い投稿の例(地域の店)

```
本日のおすすめは「くるみパン」です。
11時と15時に焼き上がります。

・1個 280円
・売り切れ次第終了
・店内は禁煙です

#〇〇駅
```

- 1行目で用件、2行目で行動に必要な情報、最後にタグ1つ。

### 投票の例(料理アカウント)

- 質問: 「来週の作り置き、どれが知りたい?」
- 選択肢: 「鶏むね肉」「卵」「きのこ」「豆腐」(各25字以内)
- 期間: 1日

## よくある失敗と対処

| 失敗 | 原因 | 対処 |
|---|---|---|
| 文字数オーバーで投稿できない | 日本語は1字=2で数える | [04-text-hashtags](04-text-hashtags.md) で数え方を確認し、スレッドに分ける |
| 投票の選択肢に誤字 | 投票付きは編集不可 | 削除して作り直す。公開前に音読して確認 |
| 予約投稿を直したい | 予約投稿は公開後に編集不可 | 公開前に予約一覧から修正する |
| 画像の一部が切れた | 比率が範囲外 | [03-media-specs](03-media-specs.md) の比率に合わせる |
| 返信が荒れた | 返信範囲が「全員」 | 公開後に範囲を狭める([06-engagement](06-engagement.md)) |

## 注意点

- 削除・編集の制限は変わることがあります。重要な告知は、下書き段階で第三者に確認してもらうと安全です。
- 同じ文面の連投はスパムとみなされる恐れがあります([10-policies](10-policies.md))。
- 編集しても、公開直後に見た人には元の文面が見えています。

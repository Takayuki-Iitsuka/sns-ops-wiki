# X 初期設定

## 手順チェックリスト

1. **アカウント作成**: メールアドレスまたは電話番号。運用専用のメールを使う。
2. **ユーザー名(@ID)と表示名**: @ID は変更可能だが、変更するとURLが変わる。表示名は検索されやすい名前＋肩書き。
3. **プロフィール画像**: 推奨 400×400px、2MB以内、JPEG/PNG/GIF 🟡 → [03-media-specs](03-media-specs.md)
4. **ヘッダー画像**: 横長。具体的な推奨寸法は ⚪ 未確認(→ [要検証リスト](../00-meta/verification-queue.md))。中央に重要要素を置く。
5. **自己紹介(bio)**: 誰向けに何を発信するか／実績／リンク。ハッシュタグは入れすぎない。
6. **固定ポスト(ピン留め)**: 自己紹介代わりの代表ポスト。
7. **2段階認証**: [account-security](../01-common/account-security.md)
8. **プライバシー設定**: 公開/非公開、DM の受信範囲、タグ付け、位置情報、検索のためのメール/電話番号での発見可否。
9. **通知設定**: 運用時に必要な通知のみ。
10. **ミュート・ブロック設定**: 事前に NG ワードをミュート登録。
11. **センシティブな内容の設定**: 自分の投稿の表示設定を確認。

## 用途別アカウント設計

| 用途 | 方針 |
|---|---|
| 個人 | 人柄が分かる発信。プロフィールに明記 |
| 事業 | 運用担当者・方針を決める。ログイン情報の共有を避ける |
| 複数アカウント | 相互の関係と目的を明確にする。規約（複数アカウントの扱い）を確認 |

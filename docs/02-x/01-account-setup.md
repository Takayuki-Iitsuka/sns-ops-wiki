# X 初期設定

> **このページで分かること**: X のアカウントを作り、プロフィール・安全・プライバシーの設定を済ませるまでの手順。
>
> **対象**: 初心者  **先に読むページ**: [X 概要](README.md)、[アカウントの安全](../01-common/account-security.md)

## 概要

X では、初めて見た人の多くがプロフィールを見て「フォローするか」を決めます。最初の設定は一度きりの作業ですが、**プロフィール・安全設定・プライバシー**を最初に整えておくと、あとで困ることが大きく減ります。

作業の全体像は次の通りです(所要時間の目安は1〜2時間 ⚪)。

1. 準備(メールアドレス、名前、画像)
2. アカウント作成
3. プロフィールの設定
4. 安全(2段階認証)
5. プライバシー・通知・ミュート
6. 固定ポストの用意

## 用語

| 用語 | 意味 |
|---|---|
| username(ユーザー名、@ID、ハンドル) | `@` から始まる固有の名前。URL(`x.com/ユーザー名`)にも使われる |
| display name(表示名) | プロフィールの一番上に太字で出る名前。日本語も使える |
| bio(自己紹介) | プロフィールの説明文 |
| header(ヘッダー画像) | プロフィール上部の横長の画像。バナーとも呼ぶ |
| pinned post(固定ポスト) | プロフィールの一番上に固定表示されるポスト |
| 2FA(Two-Factor Authentication、2段階認証) | パスワードに加えて、もう1つの確認(認証アプリなど)を求める仕組み |

## 準備するもの

| もの | ポイント |
|---|---|
| メールアドレス | **運用専用**のものを用意する。個人のメールと分けると引き継ぎが楽 |
| 電話番号 | 本人確認や復旧に使うことがある(必須かどうかは登録時の画面に従う ⚪) |
| 名前・ユーザー名の案 | 3案ほど用意(既に使われている場合がある) |
| プロフィール画像 | 正方形。小さく表示されても分かるもの |
| ヘッダー画像 | 横長(3:1) |
| 自己紹介文の下書き | 160字以内で用意しておく |
| パスワード管理 | パスワードマネージャーに保存する([account-security](../01-common/account-security.md)) |

## 手順 / 仕様

### 1. アカウント作成

画面の表記は変わることがあります(⚪ 表記は変わる可能性)。

1. アプリまたは Web(x.com)で「アカウントを作成」を選ぶ。
2. 名前、メールアドレス(または電話番号)、生年月日を入力する。
3. 届いた確認コードを入力する。
4. パスワードを設定する(他サービスと使い回さない)。
5. ユーザー名を決める(あとで変更可能。ただし変更すると URL が変わる)。

> 年齢制限など登録条件は公式の利用規約で確認してください(⚪ 要確認。`help.x.com` は自動取得できません)。

### 2. プロフィールの仕様

| 項目 | 値 | 確度 | 出典 |
|---|---|---|---|
| ユーザー名(@ID) | 一般に **最大15文字**(古いアカウントには例外あり) | ✅ | [docs.x.com Data Dictionary](https://docs.x.com/x-api/fundamentals/data-dictionary.md) |
| 表示名 | 一般に **最大50文字**(変更の可能性ありと明記) | ✅ | 同上 |
| 自己紹介(bio) | **最大160文字** | 🟡 | [help.x.com プロフィールの設定](https://help.x.com/en/managing-your-account/how-to-customize-your-profile) |
| プロフィール画像 | 推奨 **400×400px**、最大 **2MB**、JPEG/PNG/GIF | 🟡 | 同上、[03-media-specs](03-media-specs.md) |
| ヘッダー画像 | 推奨 **1500×500px**(3:1) | 🟡 | 同上 |
| アニメーション GIF | プロフィール画像・ヘッダーには **使えない** | 🟡 | 同上(検索要約) |

### 3. プロフィールを書く手順

1. **表示名**: 「名前+何の人か」が一目で分かる形にする。例: `山田|週末パン作り`。
2. **自己紹介**: 次の3点を入れる。
   - 誰に向けて
   - 何を発信するか
   - 実績・信頼の根拠(あれば)
3. **リンク**: ブログや note など、1つの入口にまとめる([link-in-bio-and-utm](../01-common/link-in-bio-and-utm.md))。
4. **プロフィール画像**: 顔・ロゴなど、小さくても認識できるもの。
5. **ヘッダー画像**: 中央に重要な要素を置く。左下はプロフィール画像と重なるので文字を置かない(🟡)。
6. ハッシュタグは入れすぎない(読みにくくなる)。

### 4. 安全の設定

1. **2段階認証** を有効にする。SMS より認証アプリが推奨されることが多い(⚪)。詳細は [account-security](../01-common/account-security.md)。
2. バックアップコードを **紙かパスワードマネージャー** に保管する(リポジトリやチャットに書かない)。
3. 連携アプリ(外部サービスに与えた権限)を確認し、使っていないものを外す。

### 5. プライバシー・通知・ミュートの設定

設定の場所はアプリの「設定とプライバシー」配下にあります(⚪ 表記は変わる可能性)。

| 設定 | 初心者のおすすめ | 理由 |
|---|---|---|
| 公開/非公開(鍵) | 発信が目的なら **公開** | 非公開だとフォロワー以外に届かない |
| DM の受信範囲 | 最初は **フォロー中の人のみ** など狭めに | 迷惑 DM を防ぐ |
| 写真へのタグ付け | 必要がなければ制限 | 意図しない紐付けを防ぐ |
| 位置情報 | **オフ** | 生活圏が推測されるのを防ぐ([privacy](../01-common/privacy-and-personal-info.md)) |
| メール/電話番号での検索 | 事業用なら **オフ** を検討 | 個人の連絡先との紐付けを防ぐ |
| 通知 | 返信・メンションなど必要なものだけ | 通知疲れを防ぐ |
| ミュートするキーワード | 事前に NG ワードを登録 | 荒れた話題を見ずに済む |
| センシティブな内容 | 自分の投稿の表示設定を確認 | 意図せず警告表示されるのを防ぐ |

### 6. 固定ポストを作る

1. 自己紹介代わりの代表ポストを1本作る(例: 「このアカウントでは〇〇を発信しています。人気の投稿まとめ↓」)。
2. ポストのメニューから「プロフィールに固定」を選ぶ(⚪ 表記は変わる可能性)。
3. 3か月に1回は見直す。

### 7. 自動投稿(bot)アカウントにする場合

| 要件 | 確度 | 出典 |
|---|---|---|
| プロフィールに **「Automated(自動化)」ラベル** を表示する | ✅ | [docs.x.com 開発者ガイドライン](https://docs.x.com/developer-guidelines.md) |
| bio に bot であることと運営者を書く(例: 「Bot by @運営者」) | ✅ | 同上 |
| 人が管理するアカウントと関連付ける | ✅ | 同上 |
| ラベルは管理者アカウントを接続して表示する設定 | 🟡 | [help.x.com 自動化ラベル](https://help.x.com/en/using-x/automated-account-labels) |

詳しくは [10-policies](10-policies.md) と [20-api/08-automation-and-tools](../20-api/08-automation-and-tools.md)。

## 用途別アカウント設計

| 用途 | 方針 |
|---|---|
| 個人 | 人柄が分かる発信。プロフィールに明記 |
| 事業 | 運用担当者・方針を決める。ログイン情報の共有を避ける |
| 複数アカウント | 相互の関係と目的を明確にする。規約（複数アカウントの扱い）を確認 |

## 具体例

### 自己紹介(bio)の例

| | 例 | コメント |
|---|---|---|
| 良い例 | `平日10分で作れる作り置きレシピを毎朝投稿。管理栄養士。保存して献立に使ってください。レシピ集は下のリンクから` | 誰向け・何を・根拠・行動が揃っている |
| 良い例 | `駅前の小さなパン屋です。焼き上がり時間と売り切れ情報をお知らせします。営業 8〜18時(月曜定休)` | 地域の店。来店に必要な情報がある |
| 悪い例 | `よろしくお願いします!` | 何のアカウントか分からない |
| 悪い例 | `#料理 #レシピ #作り置き #時短 #節約 #お弁当 …` | タグだけで読みにくい |

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 個人のメールで登録し、担当交代で困った | 運用専用メールに変更し、引き継ぎ表を作る |
| 2段階認証のバックアップコードを紛失 | ログインできるうちに再発行し、安全な場所に保管 |
| ユーザー名を何度も変えて、以前の URL が無効に | 名刺・サイトに載せたら原則変えない。変えるなら告知する |
| ヘッダーの文字がプロフィール画像で隠れた | 左下を避けて中央にまとめる |
| 位置情報付きで投稿してしまった | 投稿を削除し、位置情報の設定をオフにする |

## 注意点

- パスワード・バックアップコードを **共有ドキュメントやチャットに書かない**。
- 他人や組織と誤解される名前・画像を使わない(なりすましの禁止。[10-policies](10-policies.md))。
- 登録条件や設定項目は変わります。設定画面の表示を優先してください。

## チェックリスト

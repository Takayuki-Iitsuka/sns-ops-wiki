## 情報の信頼度表示

各ページ先頭の front matter と本文の数値に、次の確度ラベルを付けています。詳細は [出典方針](docs/00-meta/source-policy.md)。

| ラベル | 意味 |
|---|---|
| ✅ | 公式(一次資料)で確認済み |
| 🟡 | 二次資料(解説記事等)のみ。公式で要確認 |
| ⚪ | 一般的な知識・経験則。出典未確認 |

> **重要**: 仕様・収益化条件は頻繁に変わります。2026年11月3日の作成時点では、実行環境の制約により公式ヘルプへ直接アクセスできなかったため、**多くの数値が 🟡/⚪ です**。確認待ちの項目は [verification-queue.md](docs/00-meta/verification-queue.md) に集約しています。

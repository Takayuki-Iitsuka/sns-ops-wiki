# 画像チェックリスト(書き出し前)

## 使い方

1. 画像を書き出す(保存する)**直前**に、上から順に確認します。
2. 当てはまらない項目(例: 人物が写っていない画像の「人物」)は飛ばして構いません。
3. 投稿先ごとのサイズ・比率は [画像の仕様比較](../docs/01-common/image-specs-comparison.md) と [書き出しプリセット](../docs/01-common/export-presets.md) で確認します。数値はサービスの仕様変更で変わるため、表の確度ラベル(✅🟡⚪)を見てください。
4. 確認できたら [投稿計画シート](post-plan.md) の該当欄に記入します。

| 用語 | 意味 |
|---|---|
| aspect ratio(アスペクト比、縦横比) | 横:縦 の比。例: 4:5 は縦長 |
| safe area(安全領域) | トリミングされても欠けない中央部分 |
| Exif(撮影情報) | 写真に含まれる撮影日時・位置情報など |
| contrast(コントラスト) | 文字と背景の明るさの差。差が小さいと読みにくい |

## 記入例(架空: 地域の店の新商品の告知画像)

- [x] 投稿先の比率・サイズに合わせた(Instagram フィード 4:5)
- [x] 重要な要素が中央80%に入っている(商品名と価格を中央に配置)
- [x] スマホ表示で文字が読める(実機で確認)
- [x] 位置情報(Exif)を削除した(店の住所は公開情報だが、自宅で撮影したため削除)
- [x] 代替テキストを用意した(「白い皿に載ったいちごのタルト。上に『期間限定』の文字」)
- [ ] 広告・PR 表記 → 自分の店の商品なので不要と判断

## 記入用

- [ ] 投稿先の比率・サイズに合わせた([比較表](../docs/01-common/image-specs-comparison.md))
- [ ] 重要な要素が中央80%(安全領域)に入っている
- [ ] 形式(JPEG/PNG)と容量が上限内
- [ ] スマホ表示で文字が読める
- [ ] 誤字脱字がない
- [ ] 権利OK(自作・許諾・ライセンス明記)
- [ ] 人物・ナンバー・住所・位置情報(Exif)を確認
- [ ] 代替テキスト(alt text)を用意した
- [ ] 広告・PR 表記が必要か確認した
- [ ] ファイル名規則に従った(`YYYYMMDD_媒体_用途_連番`)

## スマートフォンでの見え方・ALT(追加)

- [ ] 本文の文字は 1080px 幅で **44px 以上**(補足 36px 以上)([mobile-viewing-optimization](../docs/01-common/mobile-viewing-optimization.md))
- [ ] 1行 18〜20字以内、コントラスト 4.5:1 以上
- [ ] 一覧・グリッドのサムネイルで主題が分かる(YouTube サムネイルの文字は 100px 以上)
- [ ] ライト/ダークモード、屋外の明るさで確認
- [ ] ALT を書いた([alt-text 詳細ガイド](../docs/01-common/alt-text.md)、[alt-text-log](alt-text-log.md))
- [ ] 実機(iPhone/Android)で確認、VoiceOver/TalkBack で読み上げ

## よくある見落とし

| 見落とし | 対処 |
|---|---|
| パソコンの大きな画面だけで確認 | 必ずスマートフォンの実機で見る |
| 写真の位置情報が残っている | 書き出し時に位置情報を削除する設定にする([個人情報](../docs/01-common/privacy-and-personal-info.md)) |
| フリー素材のライセンスを記録していない | 権利台帳に入手元とライセンスを記録([画像の権利](../docs/01-common/image-sources-and-copyright.md)) |

# 画像チェックリスト(書き出し前)

- [ ] 投稿先の比率・サイズに合わせた([比較表](../docs/01-common/image-specs-comparison.md))
- [ ] 重要な要素が中央80%(安全領域)に入っている
- [ ] 形式(JPEG/PNG)と容量が上限内
- [ ] スマホ表示で文字が読める
- [ ] 誤字脱字がない
- [ ] 権利OK(自作・許諾・ライセンス明記)
- [ ] 人物・ナンバー・住所・位置情報(Exif)を確認
- [ ] 代替テキスト(alt text)を用意した
- [ ] 広告・PR 表記が必要か確認した
- [ ] ファイル名規則に従った(`YYYYMMDD_媒体_用途_連番`)

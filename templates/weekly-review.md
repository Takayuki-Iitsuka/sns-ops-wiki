# 週次レビュー

## 使い方

1. 毎週決まった曜日に 15〜30分で記入します(例: 月曜の朝に先週分)。
2. 各サービスの分析画面(インサイト・アナリティクス)を開き、先週と今週の**傾向**を比べます。
3. 良かった投稿・良くなかった投稿を1〜2本ずつ選び、「なぜそうなったか」の**仮説**を書きます。
4. 次週の施策は**最大3つ**に絞ります。多すぎると実行できません。
5. 4週分たまったら [月次レビュー](monthly-review.md) にまとめます。
6. **公開リポジトリに実数を書かない**でください。ここに書く場合は比率・増減の向き(↑ → ↓)・桁のみにします。

指標の定義と計算方法は [目標・KPI・ロードマップ](../docs/30-strategy/01-goals-kpi-roadmap.md) を参照してください。サービスごとに数え方が違うため、**同じサービスの中で比べます**。

## 記入例(架空: イラストアカウント、X)

期間: 2026-11-02 〜 2026-11-08

| 指標 | 先週 | 今週 | 変化 |
|---|---|---|---|
| インプレッション | 4桁 | 4桁 | ↑(やや増) |
| エンゲージメント率 | 2%台 | 3%台 | ↑ |
| フォロワー増減 | +少数 | +少数 | → |
| 返信率 | 全件返信 | 全件返信 | → |
| 今週の費用 | 0円 | 0円 | → |

| 投稿 | 理由の仮説 |
|---|---|
| 完成イラスト+制作過程の動画(良かった) | 過程が見えると反応が増える |
| 文字だけの告知(良くなかった) | 画像がなく、タイムラインで目に留まらなかった |

次週の施策:

1. 制作過程の動画をもう2本試す(同じ時間帯)
2. 告知には完成イラストを添える
3. 固定投稿を作品一覧に更新する

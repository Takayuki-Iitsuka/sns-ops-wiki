# メディアキット(媒体資料)

## 使い方

1. 企業から案件の相談が来たとき、または受け付けを始めるときに作ります。1〜2ページに収めます。
2. このファイルをコピーし、**非公開の場所**(手元の文書、PDF など)で記入します。企業に渡す資料には実数を書いてよいですが、**このリポジトリには実数・顧客名を書かない**でください。
3. 数字には必ず「**いつ時点か**」(例: 2026年(皇紀2686年・令和8年)10月末時点、直近90日の平均)を書きます。
4. 3か月ごとに数字と実績を更新します。
5. 作り方の考え方・料金・契約の確認事項は [案件とメディアキット](../docs/30-strategy/07-sponsorship-and-media-kit.md) を参照してください。

| 用語 | 意味 |
|---|---|
| media kit(メディアキット、媒体資料) | 発信者の特徴・読者像・実績・料金の目安をまとめた資料 |
| reach(リーチ) | 投稿を見たユニークアカウント数 |
| engagement rate(エンゲージメント率) | 反応の数 ÷ 表示回数(またはリーチ)。どちらで割ったかを明記する |
| secondary use(二次利用) | 企業が投稿や素材を自社の広告・サイトなどで使うこと |
| exclusivity(競合排除) | 一定期間、同業他社の案件を受けない約束 |
| PR 表記 | 広告であることを一目で分かるように示す表記([法令](../docs/01-common/legal-compliance.md)) |

## 記入例(架空。実在の人物・企業ではありません)

| 項目 | 内容 |
|---|---|
| 名前・アカウント | 〇〇キッチン(Instagram `@example_cooking`、note) |
| 発信テーマ | 一人暮らし向けの作り置きレシピ。30分以内・材料5つ以内 |
| 強み | 手順を5枚の図解で見せるカルーセル。保存されやすい |
| 読者像 | 20〜30代が中心、一人暮らし、平日の料理時間が短い人(インサイトの傾向) |
| 成果の目安 | 平均リーチ:〇桁/投稿、保存率:〇%前後(2026年10月末時点、直近90日) |
| 提供メニュー | Instagram カルーセル1本、リール1本、note 記事1本(組み合わせ可) |
| 実績 | 調理器具の紹介(許可を得て記載)、料理メディアへの寄稿 |
| 条件 | 修正2回まで、下書き確認あり、PR 表記必須、二次利用は別途相談 |
| 料金 | 制作内容に応じてお見積り(税抜表示) |
| 請求 | 請求書発行可。インボイス登録:あり / なし |
| 連絡先 | 仕事用のメールアドレス(個人のアドレスは載せない) |

### 請求書に書く項目のメモ(インボイス登録している場合)

インボイス(適格請求書)には決まった記載事項があります(✅ [国税庁 インボイス制度の概要](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice_about.htm))。

- [ ] 交付先(企業)の氏名・名称
- [ ] 自分の氏名・名称と登録番号
- [ ] 取引年月日
- [ ] 取引内容
- [ ] 税率ごとの対価の合計と適用税率
- [ ] 税率ごとの消費税額等

詳しくは [消費税とインボイス](../docs/30-strategy/08-consumption-tax-and-invoice.md)。登録するかどうかは税務署・税理士に相談してください。

## 渡す前のチェック

- [ ] 数字に時点を書いた
- [ ] 実績は相手の許可を得たものだけ
- [ ] 個人の住所・電話番号など不要な個人情報を載せていない
- [ ] PR 表記をすることを条件に書いた
- [ ] 税込/税抜を明記した

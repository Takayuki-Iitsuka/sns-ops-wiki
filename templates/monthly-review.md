# 月次レビュー

## 使い方

1. 毎月はじめに、前月分を 60分程度で記入します。
2. 前月の [週次レビュー](weekly-review.md) 4〜5回分を横に並べて、**1か月の傾向**を見ます。
3. 「目標の進み具合」「投稿の柱の偏り」「導線」「費用と収益」「検証した仮説」の5つを点検します。
4. 最後に、来月の重点(最大3つ)と、やめること(1つ)を決めます。
5. **公開リポジトリに実数を書かない**でください。費用・収益・フォロワーなどの実数は、非公開の表計算などに記録します。ここには比率・増減の向き(↑ → ↓)・桁のみ書きます。

参考: [目標・KPI・ロードマップ](../docs/30-strategy/01-goals-kpi-roadmap.md)、[導線設計](../docs/30-strategy/02-funnel.md)、[費用の見積り](../docs/40-pricing/06-cost-planning.md)、[税務](../docs/30-strategy/04-tax-and-business.md)

| 用語 | 意味 |
|---|---|
| 行動目標 | 自分で必ずできる目標(投稿数など) |
| 柱(コンテンツの柱) | 発信テーマの大きな分類。例: レシピ / 道具 / 季節の話題 |
| 仮説 | 「〜すれば〜になるはず」という検証前の考え |
| 固定費 / 変動費 | 毎月同じ額の費用 / 使った量で変わる費用 |

## 記入例(架空: 料理アカウント、2026年(皇紀2686年・令和8年)11月分)

| 点検項目 | 内容 |
|---|---|
| 行動目標の達成 | 週3投稿 → 12本中11本(ほぼ達成) |
| KPI の傾向 | 保存率 ↑、プロフィールアクセス →、リンククリック ↓ |
| 柱の偏り | レシピ 8本 / 道具 2本 / 季節 1本(季節が少ない) |
| 導線 | 入口記事の閲覧は横ばい。プロフィールの一言が古かった |
| 費用 | 固定費のみ(AI 1つ)。変動費なし |
| 収益 | まだなし(S0 段階) |
| 検証した仮説 | 「1枚目に所要時間を書くと保存率が上がる」→ 4本中3本で上がった。継続 |
| 来月の重点 | ①季節の柱を週1本 ②プロフィールの一言を更新 ③入口記事におすすめ記事を追加 |
| やめること | 反応が低い「文字だけの告知」 |

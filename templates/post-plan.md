# 投稿計画シート

## 使い方

1. 投稿1本ごとに、このシートを1枚コピーします(表計算や手元のメモに写しても構いません)。
2. 「目的」と「1投稿1メッセージ」を**最初に**書きます。本文はその後に書きます。
3. 画像を使う場合は、[画像チェックリスト](image-checklist.md) と [ALT テキスト記録表](alt-text-log.md) も使います。
4. 投稿から1週間後に「結果」欄を記入し、[週次レビュー](weekly-review.md) に転記します。
5. **公開リポジトリに実数を書かない**でください。結果は比率・傾向(高い/普通/低い)で書くか、非公開の場所に保存します。

| 用語 | 意味 |
|---|---|
| CTA / call to action(行動喚起) | 「保存して」「プロフィールのリンクから」など、次の行動を促す一文 |
| alt text(代替テキスト) | 画像の内容を文字で説明するテキスト([詳細](../docs/01-common/alt-text.md)) |
| 1投稿1メッセージ | 1つの投稿で伝えることを1つに絞る考え方 |

## 記入例(架空: 料理アカウント)

| 項目 | 内容 |
|---|---|
| 投稿日時 | 2026-11-10 19:00 |
| サービス | Instagram |
| 形式 | カルーセル(5枚) |
| 目的 | 関心(保存してもらう) |
| 読者 | 平日に料理の時間が取れない一人暮らしの人 |
| 1投稿1メッセージ | 日曜に30分で3品作り置きできる |
| 本文 | 1行目「日曜30分で、平日3日分のおかず」。手順は画像に、本文は要点と保存の目安 |
| ハッシュタグ | 3〜5個(分野・形式・地域など)([ハッシュタグ](../docs/01-common/hashtags.md)) |
| 画像(ファイル名・比率) | `20261110_ig_carousel_01.jpg` 〜 `_05.jpg`、4:5 |
| 代替テキスト(alt text) | 各画像に固有の説明を記入(ALT 記録表に記録) |
| リンク | なし(プロフィールの入口記事へ誘導) |
| 広告・PR 表記の要否 | 不要(自分の商品・提供品なし) |
| CTA | 「保存して日曜に見返してください」 |
| 確認者 | 自分(翌朝に読み直し) |

## 投稿前の最終確認

- [ ] 目的と 1投稿1メッセージが一致している
- [ ] 誤字脱字、事実・数字の出典を確認した
- [ ] 画像の権利と alt text を確認した
- [ ] 広告・PR に当たる場合は一目で分かる表記を付けた([法令](../docs/01-common/legal-compliance.md))
- [ ] CTA は1つだけ

# ALT テキスト記録表

画像を作る時に、alt を同時に書いて記録します([詳細ガイド](../docs/01-common/alt-text.md))。

## 使い方

1. 画像を作ったら、**その場で** alt text(代替テキスト)を書きます。後回しにすると忘れます。
2. 1枚につき1行記録します。長さは多くの場合 80〜150字が目安です([詳細ガイド](../docs/01-common/alt-text.md))。カルーセル(複数枚の投稿)は、**1枚ずつ別の行**にします。
3. 「本文との分担」欄には、本文で説明していることと alt で説明することの分け方を書きます(同じ文を繰り返さないため)。
4. 投稿後、スマートフォンの読み上げ機能(iPhone の VoiceOver、Android の TalkBack)で聞いて確認し、「確認」欄に印を付けます。
5. 下の「チェック」を見ながら書きます。

| 用語 | 意味 |
|---|---|
| alt text(代替テキスト) | 画像の内容を文字で説明するテキスト。目の不自由な人の読み上げや、画像が表示されないときに使われる |
| screen reader(スクリーンリーダー、読み上げ機能) | 画面の文字を音声で読み上げる機能 |
| carousel(カルーセル) | 複数枚の画像をスワイプで見せる投稿 |

## チェック

- [ ] 見えているものを事実で書いた(主観・宣伝を除いた)
- [ ] 画像内の文字を全文書いた(本文にあれば要約)
- [ ] 「画像」「写真」で始めていない
- [ ] 80〜150字(複雑な図は本文に詳細)
- [ ] 人物の特定・属性の推測を書いていない
- [ ] カルーセルは各画像に固有の alt
- [ ] AI 生成画像は「AI 生成」と明記
- [ ] 実機で読み上げを確認した

> 文字数の目安や各サービスの設定方法は [alt-text 詳細ガイド](../docs/01-common/alt-text.md) を参照してください。サービスごとの上限は仕様変更で変わることがあります。
